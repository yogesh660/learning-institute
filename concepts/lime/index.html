01 The idea

Complex models like deep neural networks or gradient-boosted trees are globally non-linear and uninterpretable. LIME explains why a model made a specific prediction on sample x by approximating the local decision boundary with an interpretable surrogate model.

Modern machine learning architectures—such as 100-tree gradient boosted ensembles or deep neural networks—excel at predictive accuracy by learning highly complex, convoluted non-linear decision boundaries. However, in credit risk underwriting, healthcare pathology, and judicial sentencing, stakeholders demand to know why a specific decision was reached: "Why was this customer denied a loan?"

While explaining the global behaviour of a black-box model across all of multi-dimensional feature space is practically impossible, explaining a single localised prediction is entirely feasible. Marco Tulio Ribeiro, Sameer Singh, and Carlos Guestrin (2016) introduced LIME: Local Interpretable Model-Agnostic Explanations.

LIME is grounded in the geometric observation that even the most tortuous non-linear manifold looks flat and linear if you zoom in closely enough onto a tiny local neighbourhood. To explain prediction $f(x)$, LIME draws random perturbations in the immediate vicinity of $x$, observes the black-box outputs for these perturbed samples, weights each sample by its exponential distance to $x$, and fits a simple, interpretable surrogate model (typically a sparse linear model).

The learned surrogate weights $w$ represent local feature importances: showing which features pushed the model toward the prediction, which features pushed against it, and by how much, providing human-understandable explanations for any black-box model.

In everyday terms

Imagine looking at a globe of the Earth. Globally, the Earth is an intricate curved sphere covered in mountains and ocean trenches (the complex global black-box model). But if you step out of your front door and look down at your local town square, the ground is so locally flat that you can map it with a simple 2D architectural blueprint (the local linear surrogate). LIME constructs that local flat blueprint for any specific decision.

03 The maths

  1. LIME General Optimisation Objective

    \operatorname{explanation}(x) = \arg\min_{g \in \mathcal{G}} \mathcal{L}(f, g, \pi_x) + \Omega(g)

    Balances local fidelity loss L (how accurately surrogate g approximates black-box f weighted by proximity pi_x) with model complexity Omega(g) (e.g. limiting to K non-zero features).

  2. Exponential Proximity Kernel

    \pi_x(z) = \exp\left(-\frac{D(x, z)^2}{\sigma^2}\right)

    Assigns decaying importance to perturbed samples based on their Euclidean distance D(x, z) to instance x, governed by kernel width parameter sigma.

  3. Weighted Least Squares Surrogate Fit

    w^* = \left( Z^T W Z \right)^{-1} Z^T W y_{\mathrm{blackbox}}, \quad W = \operatorname{diag}(\pi_x(z_1), \dots, \pi_x(z_M))

    Closed-form weighted least squares solution for surrogate linear weights, where Z is the design matrix of perturbations and W contains proximity weights.

04 Key takeaways

  • Model-agnostic interpretability framework: explains individual predictions of any black-box classifier or regressor.
  • Grounded in local surrogate models: approximates complex global decision boundaries with a local linear surrogate model.
  • Generates synthetic perturbations in the vicinity of instance $x$, querying the black-box to observe boundary behaviour.
  • Exponential proximity kernel $\pi_x(z) = \exp(-D(x, z)^2 / \sigma^2)$ ensures local fidelity by weighting near neighbours heavily.
  • Output weights provide localised feature attribution: showing how much each feature contributed to pushing the decision over the threshold.

05 In code

python
import numpy as np
from sklearn.ensemble import RandomForestClassifier

# Tabular LIME from scratch
class SimpleTabularLIME:
    def __init__(self, predict_fn, n_samples=1000, kernel_width=0.75):
        self.predict_fn = predict_fn
        self.n_samples = n_samples
        self.kernel_width = kernel_width
        
    def explain_instance(self, x, feature_names=None):
        p = len(x)
        if feature_names is None:
            feature_names = [f"Feature_{i}" for i in range(p)]
            
        # 1. Generate perturbations around x
        perturbations = np.random.normal(loc=x, scale=0.5, size=(self.n_samples, p))
        # Ensure exact instance is included
        perturbations[0] = x
        
        # 2. Query black-box predictions (target class 1 probability)
        blackbox_probs = self.predict_fn(perturbations)
        if blackbox_probs.ndim > 1:
            blackbox_probs = blackbox_probs[:, 1]
            
        # 3. Compute Euclidean distance and exponential proximity weights
        dists = np.linalg.norm(perturbations - x, axis=1)
        weights = np.exp(-(dists**2) / (self.kernel_width**2))
        
        # 4. Weighted Ridge/OLS Linear Regression
        # Centred design matrix
        Z = np.column_stack([np.ones(self.n_samples), perturbations])
        W = np.diag(weights)
        
        # Solve (Z^T W Z + lambda I) w = Z^T W y
        ZTW = Z.T @ W
        ridge_reg = 1e-4 * np.eye(p + 1)
        w_surrogate = np.linalg.solve(ZTW @ Z + ridge_reg, ZTW @ blackbox_probs)
        
        intercept = w_surrogate[0]
        coefs = w_surrogate[1:]
        
        explanation = sorted(zip(feature_names, coefs), key=lambda item: abs(item[1]), reverse=True)
        return explanation, intercept

# Train a complex non-linear Random Forest on synthetic loan data
np.random.seed(42)
n_train = 500
features = ['Income', 'DebtRatio', 'CreditScore', 'EmploymentYears']

# Non-linear approval rule with interactions
X_train = np.random.uniform(1, 10, (n_train, 4))
latent_score = 0.5 * X_train[:, 0] - 1.2 * X_train[:, 1] + 1.5 * np.log(X_train[:, 2]) + 0.3 * X_train[:, 3]
y_train = (latent_score > np.median(latent_score)).astype(int)

rf_model = RandomForestClassifier(n_estimators=100, max_depth=10, random_state=42)
rf_model.fit(X_train, y_train)

# Instance to explain: High income, but high debt ratio!
x_applicant = np.array([8.5, 8.0, 4.0, 5.0])
prob_approval = rf_model.predict_proba(x_applicant.reshape(1, -1))[0, 1]

lime_explainer = SimpleTabularLIME(rf_model.predict_proba, n_samples=1500, kernel_width=1.0)
exp, base = lime_explainer.explain_instance(x_applicant, feature_names=features)

print(f"Applicant Black-Box Approval Probability: {prob_approval * 100:.1f}%")
print(f"Local Linear Surrogate Base Intercept:   {base:.3f}")
print("\nLocal Feature Importances (LIME Weights):")
for feat, weight in exp:
    direction = "Supports (+)" if weight > 0 else "Opposes (-)"
    print(f"  {feat:18s}: {weight:+.4f} -> {direction}")

Common pitfalls

  • Sampling instability: Because perturbations are drawn randomly, running LIME multiple times on the same instance can produce slightly varying explanations.
  • Sensitivity to kernel width sigma: If $\sigma$ is too small, the surrogate overfits a tiny neighbourhood; if too large, the surrogate tries to linearise a globally curved boundary, failing local fidelity.
  • Out-of-distribution perturbations: Drawing uniform or Gaussian perturbations around correlated tabular features can create impossible synthetic points (e.g. pregnant males or age 15 with 20 years work experience).

06 Check yourself

Q1Why does LIME fit a linear model on local perturbations rather than fitting a global linear model on the entire dataset?

Why: Globally, black-box boundaries are non-linear and cannot be captured by a single hyperplane. Locally around an individual point, linear approximations achieve high fidelity.

Q2What is the role of the exponential proximity kernel pi_x(z) in LIME?

Why: The proximity kernel ensures local fidelity: distant perturbations carry near-zero weight, forcing the linear surrogate to fit the boundary immediately surrounding x.
