Partial Least Squares and Principal Component Regression

Solve severe multicollinearity and high dimensions by projecting features onto low-dimensional latent subspaces: compare unsupervised PCR with covariance-maximising supervised PLS.

01 The idea

When predictors outnumber samples (p >> n) or exhibit collinearity, OLS is rank-deficient or unstable. PCR projects onto top variance directions without looking at the target; PLS finds latent components that simultaneously maximise covariance between predictors and the target.

In modern high-dimensional settings—such as spectroscopy in chemometrics, genomics, or financial factor models—we frequently encounter hundreds or thousands of features with high inter-correlation, often exceeding sample size ($p \gg n$). Under these conditions, the ordinary least squares covariance matrix $X^T X$ is singular or ill-conditioned, blowing up coefficient variances and destroying generalisation.

Principal Component Regression (PCR) addresses this problem via a two-stage pipeline: first, perform Principal Component Analysis (PCA) on feature matrix $X$ to extract the top $k$ orthogonal principal components; second, fit an ordinary least squares regression using these $k$ components as predictors. Because components are orthogonal, multicollinearity vanishes completely, and dimension is reduced from $p$ to $k$.

However, PCR has a fundamental structural vulnerability: PCA is entirely unsupervised. It constructs components that maximise variance within $X$, paying zero attention to the response $y$. If the variance in $X$ is dominated by background sensor drift or irrelevant noise, PCR selects high-variance noise directions while discarding low-variance directions that actually contain the predictive signal.

Partial Least Squares (PLS) regression resolves this flaw by making the latent component extraction supervised. Instead of maximising variance $\operatorname{Var}(X w)$, PLS finds weight vectors $w$ that maximise squared sample covariance $\operatorname{Cov}(X w, y)^2$. By balancing feature variance with target correlation, PLS achieves equal or superior predictive performance to PCR using significantly fewer latent components.

In everyday terms

Imagine scouting a football team. PCR watches players practice alone in an empty field, selecting the players who run the greatest distance and move the fastest (unsupervised feature variance). But some of those players might be running aimlessly without passing or shooting at goal. PLS scouts players during an active match against an opponent, selecting the players whose runs directly result in goals and assists (covariance between player movement and match score).

03 The maths

  1. PCR Estimator

    T_k = X V_k, \quad \hat{\gamma} = (T_k^T T_k)^{-1} T_k^T y, \quad \hat{\beta}_{\mathrm{PCR}} = V_k (T_k^T T_k)^{-1} T_k^T y

    PCR projects predictors onto the first k eigenvectors of sample covariance X^T X, effectively performing OLS on orthogonal latent scores.

  2. PLS Objective Function

    \max_{\|w\| = 1} \operatorname{Cov}(X w, y)^2 = \max_{\|w\| = 1} \operatorname{Var}(X w) \operatorname{Corr}(X w, y)^2

    PLS simultaneously balances feature variance with response correlation, ensuring latent directions carry both strong descriptive spread and predictive power.

  3. NIPALS Deflation Equations

    t_m = X_m w_m, \quad p_m = \frac{X_m^T t_m}{t_m^T t_m}, \quad X_{m+1} = X_m - t_m p_m^T, \quad y_{m+1} = y_m - t_m \frac{y_m^T t_m}{t_m^T t_m}

    Subtracting the outer product of score t_m and loading p_m orthogonalises remaining feature space, preventing duplicate information in subsequent components.

04 Key takeaways

  • PCR performs unsupervised PCA on features followed by OLS on the top $k$ principal components, eliminating multicollinearity.
  • Vulnerability of PCR: PCA maximises feature variance without regard to $y$; if predictors with high variance carry no signal, PCR fails.
  • PLS performs supervised latent component extraction, finding directions that maximise squared covariance $\operatorname{Cov}(X w, y)^2$.
  • PLS typically matches or beats PCR using substantially fewer components because every extracted component is steered toward the response.
  • Both methods require careful standardisation of features prior to decomposition and selection of component count $k$ via cross-validation.

05 In code

python
import numpy as np

# Principal Component Regression (PCR) vs Partial Least Squares (PLS) from scratch
np.random.seed(42)
n_samples = 80
n_features = 20

# Create collinear high-dimensional features
latent = np.random.normal(0, 1, (n_samples, 3))
# Features: 10 correlate with latent 0, 5 with latent 1, 5 are high-variance noise
X_signal = latent @ np.random.normal(0, 1, (3, 15))
X_noise = np.random.normal(0, 3.0, (n_samples, 5))  # High variance noise!
X = np.hstack([X_signal, X_noise])
# True response depends ONLY on latent[0] (low total variance compared to noise)
y = 3.0 * latent[:, 0] - 2.0 * latent[:, 1] + np.random.normal(0, 0.5, n_samples)

# Standardise X and centre y
X_std = (X - np.mean(X, axis=0)) / np.std(X, axis=0)
y_std = y - np.mean(y)

# 1. PCR Implementation (Unsupervised SVD)
def fit_pcr(X, y, k):
    U, S, Vt = np.linalg.svd(X, full_matrices=False)
    V_k = Vt[:k, :].T
    T_k = X @ V_k
    gamma = np.linalg.lstsq(T_k, y, rcond=None)[0]
    beta_pcr = V_k @ gamma
    return beta_pcr

# 2. PLS Implementation (Supervised NIPALS)
def fit_pls(X, y, k):
    n, p = X.shape
    X_m = X.copy()
    y_m = y.copy()
    
    W = np.zeros((p, k))
    P = np.zeros((p, k))
    q = np.zeros(k)
    
    for m in range(k):
        # Weight vector: covariance with target
        w_m = X_m.T @ y_m
        w_m /= np.linalg.norm(w_m)
        t_m = X_m @ w_m
        t_norm_sq = t_m @ t_m
        
        p_m = (X_m.T @ t_m) / t_norm_sq
        q_m = (y_m @ t_m) / t_norm_sq
        
        # Deflate
        X_m -= np.outer(t_m, p_m)
        y_m -= t_m * q_m
        
        W[:, m] = w_m
        P[:, m] = p_m
        q[m] = q_m
        
    # Compute regression coefficients beta_pls
    # beta = W (P^T W)^{-1} q
    beta_pls = W @ np.linalg.inv(P.T @ W) @ q
    return beta_pls

# Compare PCR and PLS with k=3 components
k = 3
beta_pcr = fit_pcr(X_std, y_std, k)
beta_pls = fit_pls(X_std, y_std, k)

pred_pcr = X_std @ beta_pcr
pred_pls = X_std @ beta_pls

r2_pcr = 1.0 - np.sum((y_std - pred_pcr)**2) / np.sum(y_std**2)
r2_pls = 1.0 - np.sum((y_std - pred_pls)**2) / np.sum(y_std**2)

print(f"Dataset shape: {X.shape} (high multicollinearity + high-variance noise)")
print(f"PCR (k={k}) R^2: {r2_pcr:.4f} (dragged down by high-variance noise features)")
print(f"PLS (k={k}) R^2: {r2_pls:.4f} (targets predictive covariance)")

Common pitfalls

  • Failing to standardise features: PCA and PLS are scale-sensitive; features with large arbitrary numerical ranges dominate components regardless of predictive power.
  • Assuming PCR components are predictive: The first principal component has maximal variance, but may have zero correlation with the response target.
  • Information leakage in cross-validation: Decompositions (both PCA and PLS) must be computed strictly inside each training fold, not on the entire dataset.

06 Check yourself

Q1What is the fundamental difference in the objective function between PCR and PLS?

Why: PCR extracts components via PCA to maximise feature variance alone; PLS extracts components that simultaneously maximise feature variance and correlation with target y.

Q2Why might PCR perform poorly when high-variance sensor noise is added to a dataset?

Why: Because PCA is unsupervised, it orders components strictly by variance. High-variance noise dominates the first principal components, pushing the predictive signal into discarded lower components.
