Image Pyramids and Scale Space: Gaussian Blurring, Laplacians, and Multiscale Representation

Representing visual structures across continuous spatial scales using Gaussian scale spaces, Laplacian bandpass pyramids, and octave downsampling.

01 The idea

Real-world objects do not exist at a single fixed scale: a car can appear as a 20-pixel dot on the horizon or a 2,000-pixel structure occupying the entire camera frame. Computer vision algorithms that operate at a single pixel resolution cannot recognise objects across distances. Gaussian scale space theory and image pyramids provide mathematically principled frameworks for analyseing images across multiple spatial resolutions.

Scale space theory (Witkin, Koenderink) proves that the only linear, shift-invariant, isotropic scale-space operator that does not create new spurious features (extrema) as scale expands is the Gaussian kernel: $L(x, y; \sigma) = I(x, y) * G(x, y; \sigma)$.

As standard deviation $\sigma$ increases, high-frequency details (fine edges, texture noise) are progressively suppressed, leaving stable coarse structures.

A Gaussian Pyramid discretizes continuous scale space by alternating Gaussian blurring with dyadic spatial subsampling (downsampling by $2\times$), creating a pyramid of progressively smaller image octaves.

A Laplacian Pyramid computes the difference between adjacent Gaussian levels, isolating distinct frequency octaves (bandpass filtering). This decomposition enables seamless multi-band image blending (e.g. stitching panoramic photos without visible seams) and feature detection (SIFT Difference of Gaussians).

In everyday terms

Imagine viewing an oil painting in an art gallery. When standing 10 centimeters away, you see high-frequency brush stroke textures and canvas fabric threads, but cannot perceive the overall subject. As you walk backwards 5 meters, fine texture blurs away, revealing the broad low-frequency forms of trees, hills, and a cathedral. An image pyramid captures all viewing distances simultaneously.

02 Step by step

  1. Configure pyramid octaves and scales: Select number of pyramid levels $K$ based on image resolution and minimum detectable object size.
  2. Apply Gaussian smoothing: Convolve image with a symmetric Gaussian blur kernel (typically $5 \times 5$ binomial kernel).
  3. Downsample (Subsample): Discard every other row and column ($2\times$ spatial decimation) to produce the next Gaussian pyramid octave $G_{k+1}$.
  4. Compute Laplacian bandpass level: Upsample $G_{k+1}$ back to $G_k$'s dimensions and subtract: $L_k = G_k - \operatorname{Up}(G_{k+1})$.
  5. Detect scale-space extrema: Search across $3 \times 3 \times 3$ scale-space volumes (spatial coordinates and adjacent scale levels) to identify scale-invariant keypoint candidates.
  6. Reconstruct original image: Reconstruct losslessly by recursively adding upsampled levels: $G_k = L_k + \operatorname{Up}(G_{k+1})$.

03 The maths

  1. Linear Scale-Space Definition

    L(x, y; \sigma) = I(x, y) * G(x, y; \sigma), \quad G(x, y; \sigma) = \frac{1}{2\pi\sigma^2} \exp\left( -\frac{x^2 + y^2}{2\sigma^2} \right)

    Convolution with a Gaussian kernel uniquely satisfies the causality axiom: no new local extrema can be created as scale $\sigma$ increases.

  2. Laplacian Pyramid Bandpass Decomposition

    L_k = G_k - \operatorname{Expand}(G_{k+1}), \quad k \in \{0, 1, \dots, K-1\}

    Each Laplacian level $L_k$ isolates the bandpass frequency information lost between consecutive Gaussian octaves.

  3. Difference-of-Gaussians (DoG) Approximation

    D(x, y; \sigma, k) = L(x, y; k\sigma) - L(x, y; \sigma) \approx (k - 1)\sigma^2 \nabla^2 L(x, y; \sigma)

    Difference of Gaussians provides an efficient approximation to the scale-normalised Laplacian of Gaussian (LoG) operator.

04 Key takeaways

  • Scale-space theory represents images across continuous scales without introducing artificial artifacts.
  • Gaussian blurring is the unique linear scale-space kernel that guarantees no new extrema are created.
  • A Gaussian pyramid combines blurring with $2\times$ downsampling to represent octaves efficiently.
  • Laplacian pyramids decompose images into bandpass frequency layers, enabling seamless multi-band blending.

05 In code

python
import numpy as np

def gaussian_downsample_2x(image: np.ndarray) -> np.ndarray:
    """Blur and subsample image by 2x (single octave downstep)."""
    # 3x3 simple Gaussian kernel
    kernel = np.array([
        [1, 2, 1],
        [2, 4, 2],
        [1, 2, 1]
    ], dtype=np.float32) / 16.0
    
    # 2D convolution (valid padding)
    h, w = image.shape
    blurred = np.zeros_like(image)
    for i in range(1, h - 1):
        for j in range(1, w - 1):
            blurred[i, j] = np.sum(image[i-1:i+2, j-1:j+2] * kernel)
            
    # Subsample every second row and column
    return blurred[::2, ::2]

# Create 16x16 test pattern
img = np.random.uniform(0, 255, size=(16, 16)).astype(np.float32)

# Build 3-level Gaussian Pyramid
g0 = img
g1 = gaussian_downsample_2x(g0)
g2 = gaussian_downsample_2x(g1)

print("Gaussian Pyramid Dimensions across Octaves:")
print(f"Level 0 (Base):    {g0.shape}")
print(f"Level 1 (Octave 1): {g1.shape}")
print(f"Level 2 (Octave 2): {g2.shape}")
print("Subsampling preserves coarse structures while drastically reducing resolution!")

Common pitfalls

  • Downsampling without blurring (Aliasing): Subsampling pixels directly without pre-filtering with a low-pass Gaussian filter introduces severe high-frequency Moiré aliasing artifacts.
  • Memory overhead of non-subsampled scale space: Maintaining full image resolution across all scale levels consumes massive RAM; octave decimation is essential for scalability.
  • Edge effects during convolution: Failing to handle image boundaries properly causes dark borders to propagate and contaminate upper pyramid levels.

06 Check yourself

Q1Why is the Gaussian kernel mathematically unique in scale-space theory?

Why: Scale-space axioms prove that the Gaussian kernel is the only linear filter that does not introduce new spurious peaks or valleys as smoothing increases.

Q2What occurs if you downsample an image by $2\times$ without first applying a low-pass Gaussian blur filter?

Why: By the Nyquist-Shannon sampling theorem, subsampling without low-pass filtering causes frequencies above the new Nyquist limit to fold back as aliasing.

Q3What is a Laplacian Pyramid used for in multi-resolution image processing?

Why: A Laplacian pyramid stores differences between adjacent Gaussian levels, isolating frequency octaves for seamless multi-band blending and texture synthesis.
