MDPs and Bellman equations

Markov Decision Processes (MDPs) provide the foundational mathematical framework for reinforcement learning and sequential decision-making under uncertainty. Defined by states, actions, transition probabilities, rewards, and a temporal discount factor, an MDP formalises how an agent's choices influence both immediate gains and future trajectories. The Bellman Expectation and Optimality equations decompose value functions into recursive relationships, enabling exact policy evaluation and optimal control via dynamic programming.

01 The idea

Should an autonomous robot pick up an immediate small reward right now, or invest time navigating a dangerous maze to unlock a massive treasure later? Sequential decision-making requires balancing immediate gratification against long-term consequences under environmental uncertainty. Markov Decision Processes and the Bellman equations turn this philosophical dilemma into precise recursive linear algebra.

The Markov Property: "The future is independent of the past given the present." Formally, the transition probability P(S_{t+1} = s' | S_t = s, A_t = a, S_{t-1}, ...) depends strictly on the current state s and action a. You do not need to know the entire historical route the agent took to arrive at state s; all relevant predictive information is compressed into the current state description.

Discounted returns and temporal patience: The total return G_t is the sum of discounted future rewards: G_t = sum_{k=0}^inf gamma^k R_{t+k+1}. The discount factor gamma in [0, 1) serves three roles: mathematically, it bounds infinite sums so infinite-horizon returns converge; economically, it reflects preference for immediate returns; and practically, it models environmental risk (the future may terminate at rate 1 - gamma).

The recursive beauty of the Bellman decomposition: How much is being in a state worth? Richard Bellman realised that the value of state s can be decomposed into two clean parts: the immediate reward expected from the next step, plus the discounted value of wherever you land next: V(s) = Reward + gamma * V(s'). This recursive decomposition turns an intractable infinite-horizon summation into local one-step expectations.

In everyday terms

Think of planning your retirement investments. If you evaluate your net worth at age 65 by simulating every single daily coffee purchase for the next forty years, the combinatorial calculation is overwhelming. Bellman's insight is the recursive budget equation: your net worth at the end of this year is simply your savings earned this year (immediate reward), plus your net worth at the start of next year compounded by market interest (gamma * V(s')). By planning one year at a time backwards from retirement, you solve the entire forty-year financial plan effortlessly.

03 The maths

  1. The Markov property condition

    \mathbb{P}(S_{t+1} = s', R_{t+1} = r \mid S_t, A_t, S_{t-1}, A_{t-1}, \dots, S_0, A_0) = \mathbb{P}(S_{t+1} = s', R_{t+1} = r \mid S_t, A_t)

    The future dynamics depend solely on current state $S_t$ and action $A_t$, establishing the state as a sufficient statistic for decision-making.

  2. Bellman Expectation Equation for V^pi

    V^\pi(s) = \sum_{a \in \mathcal{A}} \pi(a \mid s) \sum_{s' \in \mathcal{S}} P(s' \mid s, a) \left[ R(s, a, s') + \gamma V^\pi(s') \right]

    The value of state $s$ under policy $\pi$ equals the expected immediate reward plus the discounted expected value of the successor state $s'$, averaged across policy action choices and environmental transitions.

  3. Bellman Optimality Equations for V* and Q*

    \begin{aligned} V^*(s) &= \max_{a \in \mathcal{A}} \sum_{s' \in \mathcal{S}} P(s' \mid s, a) \left[ R(s, a, s') + \gamma V^*(s') \right] \\ Q^*(s, a) &= \sum_{s' \in \mathcal{S}} P(s' \mid s, a) \left[ R(s, a, s') + \gamma \max_{a' \in \mathcal{A}} Q^*(s', a') \right] \end{aligned}

    The optimal state value $V^*(s)$ selects the action that achieves maximum expected return. The Bellman optimality operator $T^*$ is a $\gamma$-contraction mapping in the infinity norm, guaranteeing convergence to a unique optimal fixed point.

04 Key takeaways

  • A Markov Decision Process formalises decision-making via states S, actions A, transitions P, rewards R, and discount gamma.
  • The Markov property asserts that future transitions depend strictly on current state and action, independent of history.
  • Bellman equations decompose value functions into immediate reward plus discounted downstream successor values.
  • Bellman expectation equations are linear systems for fixed policies; Bellman optimality equations are non-linear systems solved via dynamic programming.
  • The contraction mapping theorem guarantees that value iteration converges to a unique optimal value function V* and optimal policy pi*.

05 In code

python
import numpy as np

class SimpleGridworldMDP:
    """
    3-state linear MDP: State 0 <-> State 1 <-> State 2 (Terminal Goal).
    Demonstrates Bellman Expectation and Optimality evaluation.
    """
    def __init__(self, gamma=0.9):
        self.num_states = 3
        self.gamma = gamma
        self.actions = ["Left", "Right"]
        
    def step(self, state, action):
        """Returns (next_state, reward, is_terminal)."""
        if state == 2:
            return 2, 0.0, True  # Goal state
            
        if action == "Right":
            next_state = min(2, state + 1)
            reward = 10.0 if next_state == 2 else 0.0
        elif action == "Left":
            next_state = max(0, state - 1)
            reward = 0.0
            
        return next_state, reward, (next_state == 2)

    def value_iteration(self, theta=1e-4):
        """Solve Bellman Optimality Equation via Value Iteration."""
        V = np.zeros(self.num_states)
        
        while True:
            delta = 0.0
            V_new = np.copy(V)
            
            for s in range(self.num_states - 1):  # Skip terminal state 2
                q_values = []
                for a in self.actions:
                    s_prime, r, _ = self.step(s, a)
                    # Bellman Optimality update: r + gamma * V(s')
                    q_val = r + self.gamma * V[s_prime]
                    q_values.append(q_val)
                    
                # V*(s) = max_a Q*(s, a)
                V_new[s] = max(q_values)
                delta = max(delta, abs(V_new[s] - V[s]))
                
            V = V_new
            if delta < theta:
                break
                
        return V

    def extract_policy(self, V):
        """Extract optimal greedy policy pi*(s) from V*."""
        policy = {}
        for s in range(self.num_states - 1):
            best_action = None
            best_q = -float('inf')
            for a in self.actions:
                s_prime, r, _ = self.step(s, a)
                q = r + self.gamma * V[s_prime]
                if q > best_q:
                    best_q = q
                    best_action = a
            policy[s] = best_action
        return policy

mdp = SimpleGridworldMDP(gamma=0.9)
optimal_V = mdp.value_iteration()
optimal_pi = mdp.extract_policy(optimal_V)

print(f"MDP Discount factor gamma: {mdp.gamma}")
print("Solved Bellman Optimality Values V*(s):")
for s in range(mdp.num_states):
    print(f"  State {s}: V*(s) = {optimal_V[s]:.2f}")

print("\nExtracted Optimal Policy pi*(s):")
for s, act in optimal_pi.items():
    print(f"  State {s} -> Action: '{act}' (moves towards Goal at State 2)")

Common pitfalls

  • Violating the Markov property: If a state representation omits velocity in a physics simulator, the state is non-Markovian because future positions depend on unobserved speed. Always ensure states contain sufficient information.
  • Setting gamma = 1 in continuing tasks: In non-terminating environments without absorbing states, setting gamma = 1 causes returns to diverge to infinity, breaking dynamic programming convergence.
  • Conflating V(s) and Q(s, a): V(s) measures the value of being in a state before choosing an action; Q(s, a) measures the value of executing specific action a from state s. Q-values allow direct policy extraction without transition model P.
  • Curse of dimensionality in tabular MDPs: Tabular Bellman equations require iterating over all |S| states. For complex problems with continuous or high-dimensional states (e.g. Atari video frames), tabular methods must be replaced by deep Q-networks (DQN).

06 Check yourself

Q1What does the Markov property formally state regarding an environment's state transition dynamics?

Why: The Markov property asserts that current state S_t contains all necessary information to predict the next state S_{t+1}. The historical trajectory is irrelevant given current state and action.

Q2What role does the discount factor gamma in [0, 1) play in infinite-horizon Markov Decision Processes?

Why: In non-terminating tasks, summing unweighted rewards yields infinite returns. The discount factor gamma < 1 ensures that the geometric series sum_{k=0}^inf gamma^k R converges to a finite bound.

Q3Why does Value Iteration converge to the unique optimal value function V*?

Why: The Bellman optimality operator T* satisfies ||T* V - T* U||_inf <= gamma ||V - U||_inf. Since gamma < 1, T* is a contraction mapping. By Banach's fixed-point theorem, repeated application converges to the unique fixed point V*.
