01 The idea

Market basket analysis discovers customer purchasing patterns: "Customers who buy beer also buy nappies." The Apriori algorithm prunes exponential search spaces using downward closure to find high-lift association rules.

In retail, e-commerce, and transaction processing, businesses analysee market baskets to discover which products are purchased together: "Customers who purchase pasta and olive oil also buy garlic 78% of the time." These insights drive supermarket shelf placement, bundle pricing, and web cross-selling.

Formally, an Association Rule takes the form $X \implies Y$, where $X$ (antecedent) and $Y$ (consequent) are disjoint itemsets. However, in a supermarket with 10,000 distinct items, searching through all possible item combinations requires exploring $2^{10,000}$ candidate itemsets—a number vastly greater than the number of atoms in the observable universe.

In 1994, Rakesh Agrawal and Ramakrishnan Srikant revolutionized pattern mining by introducing the Apriori Algorithm. The algorithm is powered by the Apriori Principle (the Downward Closure Property of Support): if an itemset is frequent, all of its subsets must also be frequent. Conversely, if any itemset ${A, B}$ is infrequent, any superset ${A, B, C}$ is guaranteed to be infrequent and can be immediately pruned from the search tree.

Apriori proceeds level by level: generating 1-itemsets, pruning those below minimum support, joining surviving items to form candidate 2-itemsets, and repeating until no larger frequent itemsets exist. Discovered rules are evaluated using three core metrics: Support (frequency), Confidence (conditional probability), and Lift (strength of association above random independence).

In everyday terms

Imagine scouting a sports tournament with 1,000 athletes to find trios of athletes who can lift a 500kg boulder together. Before testing all 166 million possible three-person combinations, the coach tests every single athlete individually. If Athlete 14 cannot even lift a 20kg pebble alone, the coach instantly eliminates every single pair and trio that includes Athlete 14. The downward closure property prunes the tournament search tree to a manageable fraction.

03 The maths

  1. Support, Confidence, and Lift Metrics

    \operatorname{supp}(X) = \frac{\sigma(X)}{N}, \quad \operatorname{conf}(X \implies Y) = \frac{\operatorname{supp}(X \cup Y)}{\operatorname{supp}(X)}, \quad \operatorname{lift}(X \implies Y) = \frac{\operatorname{conf}(X \implies Y)}{\operatorname{supp}(Y)}

    Support measures how frequently the itemset appears in the database. Confidence measures conditional probability P(Y|X). Lift measures how much more often X and Y co-occur than expected if they were statistically independent.

  2. The Apriori Downward-Closure Property

    \forall X, Y: \; X \subseteq Y \implies \operatorname{supp}(Y) \le \operatorname{supp}(X)

    Support is monotonically decreasing with itemset size. If subset X is infrequent (supp(X) < minsup), then superset Y is guaranteed to be infrequent.

  3. Rule Lift Interpretation

    \operatorname{lift}(X \implies Y) = \frac{P(X, Y)}{P(X) P(Y)} \; \begin{cases} > 1 & \text{Positive correlation (complimentary)} \\ = 1 & \text{Statistical independence} \\ < 1 & \text{Negative correlation (substitutes)} \end{cases}

    Lift > 1 indicates that purchasing X actively increases the probability of purchasing Y; lift < 1 indicates mutual exclusivity.

04 Key takeaways

  • Classic market basket analysis algorithm for uncovering frequent co-occurring itemsets in transactional databases.
  • Apriori principle: if an itemset is frequent, all of its subsets must also be frequent; if any subset is infrequent, all supersets are infrequent.
  • Prunes exponential search spaces ($2^{|I|}$) level by level without scanning entire databases repeatedly.
  • Evaluated via Support (frequency), Confidence (conditional probability), and Lift (statistical association above independence).
  • Lift > 1 indicates positive correlation; lift < 1 indicates substitute items; lift = 1 indicates statistical independence.

05 In code

python
import numpy as np
from itertools import combinations

# The Apriori Algorithm for Frequent Itemset Mining from scratch
def get_frequent_itemsets(transactions, min_support=0.3):
    n_trans = len(transactions)
    # 1. Count frequent 1-itemsets (L1)
    item_counts = {}
    for t in transactions:
        for item in t:
            item_counts[item] = item_counts.get(item, 0) + 1
            
    L1 = {frozenset([item]): count / n_trans for item, count in item_counts.items() if count / n_trans >= min_support}
    
    all_frequent = dict(L1)
    current_L = L1
    k = 2
    
    while current_L:
        # Candidate generation: join step
        candidates = set()
        itemsets = list(current_L.keys())
        for i in range(len(itemsets)):
            for j in range(i + 1, len(itemsets)):
                union = itemsets[i] | itemsets[j]
                if len(union) == k:
                    # Prune step: all subsets of size k-1 must be in current_L
                    subsets_valid = all(frozenset(s) in current_L for s in combinations(union, k - 1))
                    if subsets_valid:
                        candidates.add(union)
                        
        # Count support for candidates
        cand_counts = {c: 0 for c in candidates}
        for t in transactions:
            t_set = set(t)
            for c in candidates:
                if c.issubset(t_set):
                    cand_counts[c] += 1
                    
        current_L = {c: count / n_trans for c, count in cand_counts.items() if count / n_trans >= min_support}
        all_frequent.update(current_L)
        k += 1
        
    return all_frequent

def generate_rules(frequent_itemsets, min_confidence=0.6):
    rules = []
    for itemset, supp_both in frequent_itemsets.items():
        if len(itemset) >= 2:
            # Test all non-empty subsets as antecedents
            for r in range(1, len(itemset)):
                for antecedent in combinations(itemset, r):
                    antecedent = frozenset(antecedent)
                    consequent = itemset - antecedent
                    supp_ant = frequent_itemsets.get(antecedent, 0)
                    if supp_ant > 0:
                        conf = supp_both / supp_ant
                        supp_cons = frequent_itemsets.get(consequent, 0)
                        lift = conf / supp_cons if supp_cons > 0 else 0
                        if conf >= min_confidence:
                            rules.append((list(antecedent), list(consequent), supp_both, conf, lift))
    return rules

# Synthetic supermarket transaction dataset (10 transactions)
transactions = [
    ['milk', 'bread', 'butter'],
    ['bread', 'butter'],
    ['milk', 'bread'],
    ['beer', 'nappies', 'crisps'],
    ['beer', 'nappies'],
    ['beer', 'crisps'],
    ['milk', 'bread', 'butter', 'jam'],
    ['bread', 'jam'],
    ['beer', 'nappies', 'bread'],
    ['milk', 'butter']
]

freq_itemsets = get_frequent_itemsets(transactions, min_support=0.30)
rules = generate_rules(freq_itemsets, min_confidence=0.60)

print(f"Total Transactions: {len(transactions)}")
print(f"Discovered Frequent Itemsets (Support >= 30%): {len(freq_itemsets)}")
print("\n--- Discovered High-Confidence Association Rules ---")
for ant, cons, supp, conf, lift in rules:
    print(f"  {ant} => {cons}")
    print(f"    Support: {supp*100:.1f}% | Confidence: {conf*100:.1f}% | Lift: {lift:.2f}")

Common pitfalls

  • Multiple database scans: Standard Apriori requires $K$ full sequential database scans for itemsets of maximum size $K$; FP-growth solves this with a single pass using trie structures.
  • Spurious rules from high-support items: If an item (like milk or bread) appears in 95% of baskets, almost any rule predicting milk has high confidence, but lift is near 1.0 (zero true association).
  • Low minimum support combinatorial explosion: Setting minsup too low generates millions of candidate itemsets, overwhelming CPU memory and compute.

06 Check yourself

Q1According to the Apriori principle (downward closure), what can be safely inferred if the itemset {Beer, Diapers} is found to have support below minimum support?

Why: Because support is monotonically non-increasing as items are added, no superset can ever appear more frequently than its constituent subsets.

Q2What does an association rule with Lift = 1.0 indicate?

Why: Lift is defined as P(X, Y) / (P(X)P(Y)). When lift equals 1.0, the joint occurrence matches the product of marginals, indicating zero association.
