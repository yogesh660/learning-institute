01 The idea

Developed by Teuvo Kohonen, Self-Organising Maps map high-dimensional complex manifolds onto a discrete, low-dimensional (typically 2D) grid of neurons while preserving spatial topology.

Exploring high-dimensional datasets with dozens or hundreds of features is difficult because human visual perception is confined to two and three dimensions. Standard linear projection methods like PCA can obliterate non-linear manifolds, while k-means clustering segments data without revealing the geometric relationships between cluster centroids.

Developed by Finnish neuroscientist Teuvo Kohonen in the 1980s, Self-Organising Maps (SOMs) provide a unique blend of vector quantisation, non-linear dimensionality reduction, and clustering. A SOM consists of a regular low-dimensional lattice of neurons (typically a 2D rectangular or hexagonal grid). Each neuron $i$ holds a weight vector $m_i$ possessing the identical dimensionality as the input data.

Learning occurs through an unsupervised competitive learning process inspired by retinotopic mapping in the cerebral cortex. When an input vector $x$ is presented, all neurons compete. The neuron whose weight vector is closest to $x$ in Euclidean space is declared the Best Matching Unit (BMU).

Unlike k-means—which updates only the winning centroid—a SOM updates both the BMU and its spatial topological neighbours on the 2D grid. The magnitude of the update decays with both topological grid distance (via a Gaussian neighbourhood kernel) and training iteration time. Consequently, neighbouring neurons on the 2D grid are pulled toward similar regions of high-dimensional space, preserving topological neighbourhood relations.

In everyday terms

Imagine a flexible 2D rubber mesh laid out across a flat table. You drop points of molten solder in a 3D glass room above the table. For every drop of solder, you find the closest point on the rubber mesh (the BMU) and tug it upwards toward the solder drop. Because the rubber sheet is elastic, pulling the winning point also stretches neighbouring sections of the mesh upwards. Over thousands of tugs, the 2D rubber sheet drapes itself smoothly across the 3D contour of solder points.

03 The maths

  1. Best Matching Unit (BMU) Selection

    c = \arg\min_{i \in \mathcal{V}} \|x(t) - m_i(t)\|_2

    Competitive step: the winner c is the neuron in lattice V with minimal Euclidean distance to input vector x(t).

  2. Weight Vector Update Rule

    m_i(t+1) = m_i(t) + \alpha(t) h_{ci}(t) [x(t) - m_i(t)], \quad h_{ci}(t) = \exp\left(-\frac{\|r_c - r_i\|^2}{2 \sigma(t)^2}\right)

    Neuron weights are pulled toward input x(t). The Gaussian spatial kernel h_ci(t) weights adaptation by the Euclidean distance between neuron coordinates r_c and r_i on the 2D lattice.

  3. Quantisation and Topographic Errors

    \mathrm{QE} = \frac{1}{n} \sum_{k=1}^n \|x_k - m_{c(k)}\|, \quad \mathrm{TE} = \frac{1}{n} \sum_{k=1}^n u(x_k), \quad u(x_k) = \begin{cases} 0 & \text{if 1st & 2nd BMU are adjacent} \\ 1 & \text{otherwise} \end{cases}

    Quantisation error (QE) measures reconstruction fidelity. Topographic error (TE) measures the proportion of samples whose 1st and 2nd BMUs are not lattice neighbours, quantifying topology preservation.

04 Key takeaways

  • Unsupervised competitive neural network that projects high-dimensional data onto a low-dimensional topological grid (typically 2D).
  • Best Matching Unit (BMU) competition: the neuron closest in Euclidean distance to the input sample wins the iteration.
  • Topological preservation: the BMU and its spatial lattice neighbours are updated together via a decaying Gaussian neighbourhood kernel.
  • U-matrix (Unified Distance Matrix) visualises clustering boundaries by calculating Euclidean distance between adjacent neurons.
  • Quantisation error measures geometric distortion, while topographic error evaluates the proportion of broken neighbourhood relationships.

05 In code

python
import numpy as np

# 2D Self-Organising Map (SOM) from scratch
class SelfOrganisingMap:
    def __init__(self, grid_size=(8, 8), input_dim=3, lr=0.5, sigma=2.0):
        self.rows, self.cols = grid_size
        self.n_neurons = self.rows * self.cols
        self.input_dim = input_dim
        self.lr_initial = lr
        self.sigma_initial = sigma
        
        # Initialise weights randomly in [0, 1]
        self.weights = np.random.uniform(0, 1, (self.rows, self.cols, self.input_dim))
        
        # 2D coordinates of neurons on the grid
        self.grid_coords = np.array([[[r, c] for c in range(self.cols)] for r in range(self.rows)])
        
    def find_bmu(self, x):
        # Compute Euclidean distance from x to all neurons
        diff = self.weights - x
        dist_sq = np.sum(diff**2, axis=-1)
        bmu_idx = np.unravel_index(np.argmin(dist_sq), (self.rows, self.cols))
        return bmu_idx
        
    def fit(self, X, n_epochs=100):
        n_samples = len(X)
        total_steps = n_epochs * n_samples
        step = 0
        
        for epoch in range(n_epochs):
            # Shuffle data
            indices = np.random.permutation(n_samples)
            for idx in indices:
                x = X[idx]
                step += 1
                
                # Decaying learning rate and radius
                decay = np.exp(-step / total_steps)
                lr = self.lr_initial * decay
                sigma = max(self.sigma_initial * decay, 0.5)
                
                # Find BMU
                bmu_r, bmu_c = self.find_bmu(x)
                bmu_pos = np.array([bmu_r, bmu_c])
                
                # Compute grid distance from BMU to all neurons
                grid_dist_sq = np.sum((self.grid_coords - bmu_pos)**2, axis=-1)
                
                # Gaussian neighbourhood kernel
                h = np.exp(-grid_dist_sq / (2 * sigma**2))
                
                # Update weights
                self.weights += lr * h[:, :, None] * (x - self.weights)

# Synthetic 3D RGB colour cluster data (Red, Green, Blue, Yellow)
np.random.seed(42)
reds = np.random.uniform([0.7, 0, 0], [1, 0.3, 0.3], (25, 3))
greens = np.random.uniform([0, 0.7, 0], [0.3, 1, 0.3], (25, 3))
blues = np.random.uniform([0, 0, 0.7], [0.3, 0.3, 1], (25, 3))
yellows = np.random.uniform([0.7, 0.7, 0], [1, 1, 0.3], (25, 3))
X_colours = np.vstack([reds, greens, blues, yellows])

som = SelfOrganisingMap(grid_size=(6, 6), input_dim=3, lr=0.5, sigma=2.0)
som.fit(X_colours, n_epochs=50)

# Calculate Quantisation Error
dists = []
for x in X_colours:
    bmu_r, bmu_c = som.find_bmu(x)
    dists.append(np.linalg.norm(x - som.weights[bmu_r, bmu_c]))
qe = np.mean(dists)

print(f"SOM Lattice Dimensions: {som.rows}x{som.cols} ({som.n_neurons} neurons)")
print(f"Input Data: {X_colours.shape} (RGB colour vectors)")
print(f"Average Quantisation Error: {qe:.4f}")
print("Top-left neuron weight (RGB):  ", som.weights[0, 0].round(3))
print("Bottom-right neuron weight (RGB):", som.weights[-1, -1].round(3))

Common pitfalls

  • Scale sensitivity: SOMs rely on Euclidean distance; unscaled features with large numerical magnitudes dominate BMU selection and corrupt maps.
  • Dead neurons from poor initialisation: Random weight initialisation can leave peripheral neurons outside the data support that never win competition; PCA initialisation prevents dead neurons.
  • Computational scaling: Standard SOM scales as $O(n \cdot N_{\mathrm{neurons}} \cdot d)$ per epoch, becoming sluggish on massive datasets.

06 Check yourself

Q1What is the crucial mechanism that allows a Self-Organising Map to preserve topology unlike standard k-means clustering?

Why: In k-means, only the winning centroid is updated. In a SOM, the BMU and its topological neighbours on the 2D lattice are pulled toward the sample, preserving spatial topology.

Q2What does the U-matrix (Unified Distance Matrix) represent in a trained SOM visualisation?

Why: The U-matrix displays distances between neighbouring neuron weight vectors; high-distance ridges signify boundaries separating distinct clusters.
