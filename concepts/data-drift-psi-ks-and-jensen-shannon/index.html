01 The idea

Machine learning models assume that production inputs follow the same probability distribution as the training data. In reality, seasonal changes, consumer trends, sensor wear, and upstream schema modifications cause input distributions to shift—a phenomenon known as data drift or covariate shift. Population Stability Index (PSI), the Kolmogorov–Smirnov (KS) test, and Jensen–Shannon divergence quantify feature drift without requiring target labels.

Suppose a credit risk model is trained on loan applications submitted in 2021, when applicant incomes averaged £45,000 and the median applicant age was 42. In 2024, the bank launches a student mobile app. Suddenly, 60% of incoming applicants are aged 18 to 24 with part-time incomes under £15,000. Even if the model's software pipeline runs without throwing exceptions, the inputs have shifted into a sparse, unrepresentative region of the training feature space. The model is forced to extrapolate, leading to erratic credit score decisions. This is data drift: the input distribution P(X) has changed, even if the underlying definition of credit default P(Y | X) has not yet been observed.

Population Stability Index (PSI) is the industry standard in financial risk and credit scoring for measuring feature drift. You partition the reference training feature into 10 quantile bins (deciles), each containing exactly 10% of training data. You then pass the latest batch of production observations through those exact same bin cutoffs and compute the actual proportion in each bin. For each bin, PSI calculates (Actual - Reference) multiplied by ln(Actual / Reference). Summing across all bins yields the overall PSI. An industry rule of thumb treats PSI below 0.1 as stable, 0.1 to 0.2 as moderate drift, and 0.2 or greater as significant drift requiring investigation or retraining.

Continuous features can also be monitored without binning using the two-sample Kolmogorov–Smirnov (KS) test, which measures the maximum vertical discrepancy between the empirical cumulative distribution functions (CDFs) of training and production samples. For general probability distributions, Jensen–Shannon (JS) divergence provides a smoothed, symmetric, bounded measure based on Kullback–Leibler divergence that gracefully handles differences in feature support.

02 Step by step

  1. Establish reference baseline distribution: record quantile boundaries (e.g. deciles) and empirical CDFs on the validated training or holdout test partition.
  2. Sample current production window: aggregate incoming production feature vectors over an operational monitoring window (e.g. daily or weekly).
  3. Compute Population Stability Index (PSI): bin the current data using the baseline quantile thresholds and evaluate the sum of binned divergence terms.
  4. Apply Kolmogorov–Smirnov test on continuous features: compute the maximum distance $D$ between empirical CDFs and evaluate the statistical p-value.
  5. Trigger alert hierarchies: flag features with $\text{PSI} \ge 0.1$ for automated tracking, and escalate features with $\text{PSI} \ge 0.2$ for root-cause analysis and potential model retraining.

03 The maths

  1. Population Stability Index (PSI)

    \text{PSI} = \sum_{k=1}^K \left( \hat{p}_{\text{curr}, k} - \hat{p}_{\text{ref}, k} \right) \cdot \ln\left( \frac{\hat{p}_{\text{curr}, k}}{\hat{p}_{\text{ref}, k}} \right)

    Where $K$ is the number of bins (typically 10 reference deciles), $\hat{p}_{\text{ref}, k}$ is the baseline proportion in bin $k$, and $\hat{p}_{\text{curr}, k}$ is the current production proportion. Laplace smoothing prevents division by zero when a production bin contains zero samples.

  2. Two-sample Kolmogorov–Smirnov statistic

    D_{n, m} = \sup_x \left| F_{\text{ref}, n}(x) - F_{\text{curr}, m}(x) \right|

    Where $F_{\text{ref}, n}(x)$ and $F_{\text{curr}, m}(x)$ represent empirical cumulative distribution functions of reference and production samples of sizes $n$ and $m$. $D_{n, m}$ measures the supreme absolute divergence between the two empirical curves.

  3. Jensen–Shannon Divergence (JSD)

    \text{JSD}(P \parallel Q) = \frac{1}{2} D_{\text{KL}}(P \parallel M) + \frac{1}{2} D_{\text{KL}}(Q \parallel M), \qquad M = \frac{1}{2}(P + Q)

    Where $D_{\text{KL}}$ is the Kullback–Leibler divergence and $M$ is the average distribution. Unlike standard KL divergence, Jensen–Shannon divergence is strictly symmetric, bounded between $0$ and $\ln(2)$, and well-defined across overlapping supports.

04 Key takeaways

  • Data drift detects shifts in input feature distributions P(X) immediately, without waiting for delayed ground-truth target labels.
  • PSI decile bins must be derived strictly from the reference training set and held static during monitoring.
  • Standard PSI thresholds: below 0.1 indicates stability, 0.1 to 0.2 indicates moderate change, and 0.2+ signals critical distribution drift.

05 In code

python
import numpy as np

def calculate_psi(ref, curr, num_bins=10):
    # Quantile bins derived strictly from reference baseline
    quantiles = np.linspace(0, 100, num_bins + 1)
    bins = np.percentile(ref, quantiles)
    bins[0] -= 1e-6
    bins[-1] += 1e-6
    
    ref_counts = np.histogram(ref, bins=bins)[0]
    curr_counts = np.histogram(curr, bins=bins)[0]
    
    # Laplace smoothing prevents log(0) and division by zero
    p_ref = (ref_counts + 1e-4) / (len(ref) + 1e-4 * num_bins)
    p_curr = (curr_counts + 1e-4) / (len(curr) + 1e-4 * num_bins)
    
    psi = np.sum((p_curr - p_ref) * np.log(p_curr / p_ref))
    return psi

np.random.seed(42)
reference = np.random.normal(50.0, 10.0, size=1000)
prod_stable = np.random.normal(50.2, 9.8, size=500)     # Stable
prod_drifted = np.random.normal(55.0, 12.0, size=500)    # Drifted

psi_stable = calculate_psi(reference, prod_stable)
psi_drifted = calculate_psi(reference, prod_drifted)

print(f"Baseline vs Stable Production:  PSI = {psi_stable:.3f} (< 0.1 stable)")
print(f"Baseline vs Drifted Production: PSI = {psi_drifted:.3f} (>= 0.2 significant drift)")

Common pitfalls

  • Recomputing quantile bins dynamically on current production data instead of applying fixed reference training cutoffs.
  • Zero-count crash in PSI: if a production bin has 0 records, the log term diverges to negative infinity without Laplace or epsilon smoothing.
  • Assuming absence of data drift implies absence of model decay: concept drift can degrade predictions even when input distributions P(X) remain completely static.

06 Check yourself

Q1What is the primary advantage of monitoring data drift (covariate shift) over monitoring model accuracy metrics in production?

Why: Ground-truth outcome labels (such as loan defaults or cancer diagnoses) often take weeks or months to arrive. Data drift alerts engineering teams to distribution changes immediately upon inference.

Q2When computing Population Stability Index (PSI), how must the bin boundaries be established?

Why: PSI measures how current data shifts relative to the reference standard. The bin boundaries must remain fixed to the baseline reference quantiles so each reference bin represents an expected 10% share.

Q3A production feature produces a PSI value of 0.26 when compared against training data. What action should the engineering team take according to industry conventions?

Why: Industry rules of thumb define PSI >= 0.2 as significant distribution drift that demands immediate root-cause investigation, schema validation, and potential retraining.
