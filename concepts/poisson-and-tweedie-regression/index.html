01 The idea

Ordinary least squares assumes constant Gaussian error variance and produces negative predictions for counts and costs. Poisson and Tweedie regression model positive, skewed, and zero-inflated targets using tailored exponential dispersion families.

Standard linear regression encounters serious failures when the target variable is a non-negative count (such as daily website sign-ups, hospital admissions, or insurance claims) or a continuous monetary payout with an exact point mass at zero (such as warranty repair payouts or customer credit defaults). OLS can produce negative predicted values, predicts fractional values for discrete events, and violates homoscedasticity because variance typically grows with the expected value.

Poisson regression addresses discrete count data by placing the response within the generalised Linear Model (GLM) framework. Using a log link function $\log(\mu_i) = x_i^T \beta$, the conditional mean $\mu_i = \exp(x_i^T \beta)$ is guaranteed to remain strictly positive. The model assumes an equi-dispersion property: the conditional variance equals the conditional mean, $\operatorname{Var}(Y_i \mid x_i) = \mu_i$. When empirical data violates this assumption—frequently due to unobserved heterogeneity causing overdispersion (variance exceeding the mean)—analysts upgrade to Quasi-Poisson or Negative Binomial regression.

In insurance pricing and marketing spend modelling, target variables often exhibit a compound nature: many observations are exactly zero (no insurance claim filed), but when non-zero, the cost is a continuous, heavily right-skewed positive monetary sum. Modelling this requires a compound Poisson-gamma distribution, formalised as a Tweedie distribution with power parameter $p \in (1, 2)$.

Under the Tweedie family, variance scales as $\operatorname{Var}(Y) = \phi \mu^p$. When $p = 0$, the family recovers the Gaussian distribution; $p = 1$ is the Poisson; $p = 2$ is the Gamma; and $p = 3$ is the Inverse Gaussian. For $1 < p < 2$, the Tweedie distribution seamlessly models zero-inflated continuous responses without requiring cumbersome two-stage hurdle models.

In everyday terms

Imagine predicting insurance claims for a fleet of haulage trucks. Most trucks go an entire year without an incident (generating zero payouts). But when a crash occurs, repairs cost thousands of pounds with a long right-skewed tail. A Gaussian model predicts negative £500 payouts for safe drivers, while a pure Gamma model cannot tolerate exact zero payouts. A compound Poisson-gamma Tweedie model matches the reality: a Poisson draw determines how many accidents occur, and an independent Gamma draw sets the severity of each claim.

03 The maths

  1. Poisson Log-Likelihood and Score Equation

    \ell(\beta) = \sum_{i=1}^n \left( y_i x_i^T \beta - \exp(x_i^T \beta) - \log(y_i!) \right), \quad \nabla_\beta \ell(\beta) = \sum_{i=1}^n (y_i - \mu_i) x_i = 0

    The score equation shows that maximum likelihood estimates match the weighted sum of residuals to zero. The Hessian is strictly negative definite, guaranteeing a unique global optimum.

  2. Tweedie Variance Function and Power Parameter

    \operatorname{Var}(Y) = \phi \cdot V(\mu) = \phi \cdot \mu^p, \quad p = \frac{q - 2}{q - 1} \in (1, 2)

    For p in (1, 2), Y is represented as the sum of N independent Gamma random variables where N is Poisson-distributed, creating a valid probability density with a positive point mass at Y = 0.

  3. Tweedie Deviance Function

    d(y, \mu) = 2 \left( \frac{y^{2-p}}{(1-p)(2-p)} - \frac{y \mu^{1-p}}{1-p} + \frac{\mu^{2-p}}{2-p} \right)

    The unit deviance measures distance between observed response y and fitted expectation mu, replacing residual sum of squares during loss optimisation and cross-validation.

04 Key takeaways

  • Poisson regression models discrete non-negative counts $y \in \{0, 1, 2, \dots\}$ using a log link function that guarantees positive predicted means.
  • Equi-dispersion assumption: Poisson assumes $\operatorname{Var}(Y) = \mathbb{E}[Y]$. Overdispersion (variance > mean) requires Quasi-Poisson or Negative Binomial models.
  • Tweedie distributions parameterised by power parameter $p \in (1, 2)$ represent a compound Poisson-gamma process with an exact point mass at zero and continuous positive tail.
  • Eliminates the need for awkward log(y + 1) heuristics or separate two-stage classification/regression pipelines in insurance and marketing pricing.
  • Estimated via Iteratively Reweighted Least Squares (IRLS), which converges rapidly due to global convexity of exponential dispersion deviance.

05 In code

python
import numpy as np

# Poisson GLM via Iteratively Reweighted Least Squares (IRLS) from scratch
np.random.seed(42)
n_samples = 500

# Synthetic features and true rate parameters
x1 = np.random.normal(0, 1, n_samples)
x2 = np.random.uniform(-1, 1, n_samples)
X = np.column_stack([np.ones(n_samples), x1, x2])

true_beta = np.array([1.2, 0.6, -0.4])
mu_true = np.exp(X @ true_beta)
# Sample Poisson counts
y = np.random.poisson(mu_true)

# IRLS Algorithm for Poisson GLM with Log Link
beta = np.zeros(X.shape[1])
max_iters = 20
tol = 1e-8

for it in range(max_iters):
    eta = X @ beta
    mu = np.exp(eta)
    
    # Weight matrix W and working response z
    # For Poisson log link: W_ii = mu_i, z_i = eta_i + (y_i - mu_i) / mu_i
    W = mu
    z = eta + (y - mu) / mu
    
    # Weighted least squares update: (X^T W X) beta_new = X^T W z
    XTW = X.T * W
    beta_new = np.linalg.solve(XTW @ X, XTW @ z)
    
    diff = np.max(np.abs(beta_new - beta))
    beta = beta_new
    if diff < tol:
        break

# Compute standard errors from Fisher information matrix
cov_matrix = np.linalg.inv(X.T @ (X * mu[:, None]))
se_beta = np.sqrt(np.diag(cov_matrix))

# Compute Pearson dispersion statistic to check for overdispersion
pearson_chi2 = np.sum((y - mu)**2 / mu)
dispersion = pearson_chi2 / (n_samples - len(beta))

print(f"True coefficients:     {true_beta}")
print(f"Estimated Poisson beta: {beta.round(4)}")
print(f"Standard errors:        {se_beta.round(4)}")
print(f"Pearson dispersion:     {dispersion:.3f} (approx 1 indicates no overdispersion)")

# Tweedie 1.5 Compound Poisson-Gamma Simulation
# When y has point mass at zero and positive continuous payout
p = 1.5
n_claims = np.random.poisson(lam=0.3, size=200)
severity = np.where(n_claims > 0, np.random.gamma(shape=2.0, scale=500.0, size=200), 0.0)
print(f"Tweedie data zero fraction: {np.mean(severity == 0)*100:.1f}%")
print(f"Mean non-zero claim: £{np.mean(severity[severity > 0]):.2f}")

Common pitfalls

  • Applying standard OLS to log(y + 1): Adding arbitrary pseudo-counts introduces arbitrary bias depending on measurement units, distorting slope estimates.
  • Ignoring overdispersion in Poisson regression: When data has variance greater than the mean, Poisson point estimates remain consistent but standard errors are severely underestimated, producing false-positive p-values.
  • Overlooking exposure periods: When observations span differing intervals (e.g. 1 month vs 12 months), failing to include $\log(exposure)$ as an offset estimates average counts rather than true rates.

06 Check yourself

Q1Why is Tweedie regression with power parameter p = 1.5 particularly suited for insurance claim payouts?

Why: Tweedie distributions with 1 < p < 2 represent compound Poisson-gamma distributions, giving a discrete probability at zero combined with continuous Gamma payouts for non-zero events.

Q2What should a modeller do if the Pearson dispersion statistic chi^2 / (n - p) for a fitted Poisson GLM equals 4.8?

Why: A dispersion statistic of 4.8 indicates severe overdispersion (variance is almost 5 times the mean). Standard Poisson SEs are heavily underestimated; Negative Binomial or Quasi-Poisson correction is required.
