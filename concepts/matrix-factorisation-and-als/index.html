01 The idea

High-dimensional user-item interaction matrices are riddled with missing entries, confounding classical SVD and neighbourhood methods. Matrix factorisation projects both users and items into a shared $k$-dimensional latent vector space where inner products predict unobserved interactions. Alternating Least Squares (ALS) solves the non-convex joint optimisation problem by alternately fixing user vectors to solve for item vectors and vice versa via exact closed-form quadratic ridge regressions.

Imagine describing movies not by hundreds of messy genre tags, but along two fundamental psychological axes: seriousness versus comedy, and action versus cerebral dialogue. If we could assign every movie a 2-dimensional coordinate along these axes, and similarly position each moviegoer along the same preference axes, predicting whether a user will enjoy a film becomes as simple as a dot product: $\text{preference} \times \text{attribute}$. A viewer who loves high-octane comedy will score high positive values on films positioned at those exact coordinates.

In real applications, we do not hand-craft or label these latent dimensions. Instead, matrix factorisation discovers them automatically from the raw interaction matrix $R \approx U V^T$. For $m$ users and $n$ items, each user $u$ is mapped to a latent vector $p_u \in \mathbb{R}^k$ and each item $i$ to $q_i \in \mathbb{R}^k$, where $k \ll \min(m, n)$ (typically 20 to 100). The predicted rating is $\hat{r}_{u, i} = \mu + b_u + b_i + p_u^T q_i$, incorporating global, user, and item baseline biases to isolate true affinity from systematic scale differences.

Because 99% of entries in $R$ are unobserved, classical Singular Value Decomposition (SVD) cannot be directly applied without imputing zeros (which falsely asserts users hate everything they have not yet seen). Jointly optimising $U$ and $V$ over known entries is non-convex. However, when user vectors $U$ are held fixed, the objective function becomes strictly convex and quadratic in $V$—amounting to an independent ridge regression for every item. Alternating Least Squares (ALS) leverages this: hold $U$ constant and solve for $V$ in closed form, then hold $V$ constant and solve for $U$, rapidly converging to a high-quality local minimum.

In everyday terms

Solving a two-variable combination lock by turning dial A while dial B is clamped, then clamping dial A to turn dial B until both slots click into alignment.

02 Step by step

  1. Initialise user latent matrix $U \in \mathbb{R}^{m \times k}$ and item latent matrix $V \in \mathbb{R}^{n \times k}$ with small random Gaussian values.
  2. Compute the global mean $\mu$, user baseline biases $b_u$, and item baseline biases $b_i$ across all observed entries $\mathcal{K}$.
  3. Fix the item embeddings $V$ and item biases $b_i$, and solve for each user's vector $p_u$ and bias $b_u$ via regularised ridge regression over the subset of items rated by user $u$.
  4. Fix the user embeddings $U$ and user biases $b_u$, and solve for each item's vector $q_i$ and bias $b_i$ via regularised ridge regression over the subset of users who rated item $i$.
  5. Repeat the alternating updates until the regularised mean squared error over observed interactions converges below a threshold $\epsilon$.

03 The maths

  1. Regularised matrix factorisation objective

    $$\min_{U, V, b} \sum_{(u, i) \in \mathcal{K}} \Big(r_{u, i} - (\mu + b_u + b_i + p_u^T q_i)\Big)^2 + \lambda \sum_u \big(\|p_u\|_2^2 + b_u^2\big) + \lambda \sum_i \big(\|q_i\|_2^2 + b_i^2\big)$$

    The objective minimises squared reconstruction error exclusively over the set of observed user-item interactions $\mathcal{K}$. The regularisation parameter $\lambda > 0$ penalises large latent weights and extreme biases, preventing overfitting on active users or items with scarce feedback.

  2. Closed-form ALS user update step

    $$p_u = \Big(V_{I_u}^T V_{I_u} + \lambda I_k\Big)^{-1} V_{I_u}^T \tilde{r}_{u, I_u}$$

    Holding item matrix $V$ fixed turns user $u$'s optimisation into regularised linear regression. Here $I_u$ is the set of items rated by user $u$, $V_{I_u} \in \mathbb{R}^{|I_u| \times k}$ is the submatrix of corresponding item vectors, and $\tilde{r}_{u, I_u}$ contains residual ratings after subtracting $\mu + b_u + b_i$. The $k \times k$ matrix inversion is fast and parallelisable across users.

  3. Implicit feedback formulation (Hu, Koren, Volinsky)

    $$\mathcal{L}_{\text{implicit}} = \sum_{u=1}^m \sum_{i=1}^n c_{u, i} \big(p_{u, i} - p_u^T q_i\big)^2 + \lambda \sum_u \|p_u\|_2^2 + \lambda \sum_i \|q_i\|_2^2$$

    For implicit feedback (clicks, watch time), binary preference $p_{u, i} = \mathbf{1}_{r_{u, i} > 0}$ is paired with confidence $c_{u, i} = 1 + \alpha r_{u, i}$. Crucially, the $O(m n)$ sum over all unobserved pairs simplifies because $V^T C^u V = V^T V + V^T (C^u - I) V$, allowing $V^T V$ to be computed once per iteration in $O(n k^2)$, keeping each user update at $O(|I_u| k^2 + k^3)$.

04 Key takeaways

  • Dense semantic representations: maps sparse interaction matrices into compact $k$-dimensional latent spaces that capture latent user tastes and item attributes.
  • Monotonic convergence: each alternating quadratic sub-step is strictly convex and solved in closed form, guaranteeing non-increasing loss at every iteration.
  • Scalable implicit feedback: reformulating the confidence-weighted objective allows training across billions of implicit missing pairs in polynomial time.

05 In code

python
import numpy as np

np.random.seed(42)
R = np.array([[5, 3, 0, 1], [4, 0, 0, 1], [1, 1, 0, 5], [1, 0, 4, 4], [0, 1, 5, 4]], dtype=float)
m, n, k, reg = *R.shape, 2, 0.1
mu, mask = R[R > 0].mean(), R > 0
P, Q = np.random.normal(0, 0.1, (m, k)), np.random.normal(0, 0.1, (n, k))
bu, bi = np.zeros(m), np.zeros(n)

for _ in range(20):
    for u in range(m):
        idx = np.where(mask[u])[0]
        if len(idx):
            Vu, yu = Q[idx], R[u, idx] - mu - bi[idx]
            bu[u] = np.sum(yu - Vu @ P[u]) / (len(idx) + reg)
            P[u] = np.linalg.solve(Vu.T @ Vu + reg * np.eye(k), Vu.T @ (yu - bu[u]))
    for i in range(n):
        idx = np.where(mask[:, i])[0]
        if len(idx):
            Ui, yi = P[idx], R[idx, i] - mu - bu[idx]
            bi[i] = np.sum(yi - Ui @ Q[i]) / (len(idx) + reg)
            Q[i] = np.linalg.solve(Ui.T @ Ui + reg * np.eye(k), Ui.T @ (yi - bi[i]))

R_pred = mu + bu[:, None] + bi[None, :] + P @ Q.T
rmse = np.sqrt(np.mean((R[mask] - R_pred[mask])**2))
print(f"Global mean: {mu:.2f}")
print(f"Training RMSE on observed: {rmse:.4f}")
print(f"Predicted unobserved rating R[0, 2]: {R_pred[0, 2]:.2f}")

Common pitfalls

  • SVD confusion: running standard SVD requires imputing unobserved matrix entries with zeros, corrupting representations by misinterpreting unobserved items as disliked items.
  • Neglecting baseline biases: omitting $b_u$ and $b_i$ forces the latent dot product $p_u^T q_i$ to absorb broad rating scale differences, degrading latent semantic geometry.
  • Overfitting sparse entities: users or items with only one or two ratings easily overfit unless heavy L2 regularisation $\lambda$ is enforced.

06 Check yourself

Q1Why does Alternating Least Squares (ALS) switch between updating user vectors $P$ and item vectors $Q$ rather than optimising both simultaneously via standard least squares?

Why: The product $P Q^T$ couples the variables, making the joint loss surface non-convex with saddle points. Holding $Q$ fixed reduces the problem to an independent, strictly convex ridge regression for each row of $P$, solved exactly in closed form.

Q2What is the role of the user bias $b_u$ and item bias $b_i$ in the formulation $\hat{r}_{u, i} = \mu + b_u + b_i + p_u^T q_i$?

Why: A 4-star rating on a movie whose average is 4.5 by a user whose average is 4.2 actually represents a negative relative preference. Baseline terms capture these systematic shifts, leaving the latent dot product to capture genuine affinity patterns.

Q3How does implicit feedback matrix factorisation (Hu, Koren, Volinsky) handle items that a user has never clicked on or viewed?

Why: In implicit settings, non-interaction could mean the user dislikes the item or simply never saw it. The model assigns zero preference ($p_{ui} = 0$) to all unobserved pairs but assigns them minimal confidence ($c_{ui} = 1$), reserving higher confidence ($1 + \alpha r_{ui}$) for observed interactions.
