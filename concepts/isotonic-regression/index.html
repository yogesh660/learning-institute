01 The idea

When physical domain knowledge dictates that response y must increase monotonically with predictor x, linear models enforce too much rigidity while splines can wiggle. Isotonic regression finds the exact least-squares monotonic fit using piecewise constant steps.

In many scientific and business applications, the relationship between a predictor $x$ and target $y$ is strictly monotonic: dose-response curves in clinical pharmacology (higher drug concentration never decreases toxicity), customer pricing sensitivity, credit score default risk, and probability calibration. However, the exact parametric mathematical form (whether linear, exponential, or sigmoidal) is completely unknown.

Linear regression imposes a rigid straight line, which can fail catastrophically if the true relationship is non-linear. High-degree polynomials or unconstrained smoothing splines can capture curvature, but frequently oscillate or violate monotonicity on unobserved gaps, generating nonsense predictions.

Isotonic regression solves this dilemma through non-parametric shape-constrained estimation. It finds a sequence of fitted values $\hat{y}_i$ that minimises the sum of squared errors $\sum_{i=1}^n w_i (y_i - \hat{y}_i)^2$ subject strictly to the monotonicity ordering constraint: $x_i \le x_j \implies \hat{y}_i \le \hat{y}_j$. The resulting model is a non-decreasing piecewise constant step function that conforms flexibly to arbitrary monotonic shapes without assuming any predefined mathematical curve.

A premier modern application of isotonic regression is classifier calibration. Machine learning models such as Random Forests, Naive Bayes, or boosted trees output raw scores that rank samples effectively but do not represent well-calibrated probabilities. Isotonic regression maps raw classifier scores into calibrated posterior probabilities non-parametrically, outperforming Platt scaling when the distortion is non-sigmoidal.

In everyday terms

Imagine constructing a wheelchair access ramp across a hillside terrain of jagged mounds and dips. You must grade the dirt such that every point on the path is at least as high as all preceding points (monotonic ascent). Whenever you encounter a downward dip, you must shovel soil from the peak into the valley until both settle into a single flat terrace. The Pool Adjacent Violators Algorithm performs exactly this earth-moving process: pooling violating dips into flat monotonic steps.

03 The maths

  1. Constrained Least-Squares Formulation

    \min_{\hat{y}_1, \dots, \hat{y}_n} \sum_{i=1}^n w_i (y_i - \hat{y}_i)^2 \quad \text{subject to} \quad \hat{y}_1 \le \hat{y}_2 \le \dots \le \hat{y}_n

    The quadratic objective is strictly convex, and the constraint set is a closed convex cone (the isotonic cone). This guarantees the existence of a unique global minimiser.

  2. PAVA Pooling Condition

    \bar{y}_{A \cup B} = \frac{\sum_{i \in A} w_i y_i + \sum_{j \in B} w_j y_j}{\sum_{i \in A} w_i + \sum_{j \in B} w_j}

    When group A violates monotonicity with successor B (y_A > y_B), the constrained minimiser across their union is exactly the weighted sample mean of both groups combined.

  3. Probability Calibration Error (ECE)

    \mathrm{ECE} = \sum_{m=1}^M \frac{|B_m|}{n} \left| \operatorname{acc}(B_m) - \operatorname{conf}(B_m) \right|

    Expected Calibration Error measures calibration discrepancy across probability bins B_m. Isotonic calibration fits a non-decreasing mapping from raw model confidence to empirical accuracy.

04 Key takeaways

  • Non-parametric shape-constrained regression: enforces strict monotonicity ($x_i \le x_j \implies \hat{y}_i \le \hat{y}_j$) without assuming any specific mathematical curve.
  • Solved exactly in $O(n)$ time using the Pool Adjacent Violators Algorithm (PAVA).
  • Yields a piecewise constant step function with horizontal plateaus wherever adjacent points were pooled.
  • Widely utilised for classifier probability calibration, non-parametrically mapping raw classifier scores into true posterior probabilities.
  • Highly prone to severe overfitting on small datasets ($n < 1000$) where steps capture noisy spikes; Platt scaling is safer when sample sizes are small.

05 In code

python
import numpy as np

# Pool Adjacent Violators Algorithm (PAVA) from scratch
def isotonic_regression_pava(y, w=None):
    n = len(y)
    if w is None:
        w = np.ones(n, dtype=float)
    else:
        w = np.array(w, dtype=float)
        
    # Stack stores: [weight, sum_wy, y_mean, start_idx, end_idx]
    stack = []
    
    for i in range(n):
        curr_w = w[i]
        curr_sum = w[i] * y[i]
        curr_mean = y[i]
        start_idx = i
        end_idx = i
        
        # Check for monotonicity violation with top of stack
        while stack and stack[-1][2] >= curr_mean:
            prev_w, prev_sum, _, prev_start, _ = stack.pop()
            curr_w += prev_w
            curr_sum += prev_sum
            curr_mean = curr_sum / curr_w
            start_idx = prev_start
            
        stack.append((curr_w, curr_sum, curr_mean, start_idx, end_idx))
        
    # Unpack fitted values
    y_hat = np.zeros(n, dtype=float)
    for block_w, block_sum, block_mean, s, e in stack:
        y_hat[s:e+1] = block_mean
        
    return y_hat

# Synthetic noisy monotonic dose-response curve
np.random.seed(42)
n_samples = 40
x = np.linspace(0, 10, n_samples)
true_response = 1.0 / (1.0 + np.exp(-(x - 5)))  # Sigmoidal response
noise = np.random.normal(0, 0.15, n_samples)
y_noisy = true_response + noise

# Fit isotonic regression
y_iso = isotonic_regression_pava(y_noisy)

# Verify strict monotonicity
is_monotonic = np.all(np.diff(y_iso) >= 0)
mse_raw = np.mean((y_noisy - true_response)**2)
mse_iso = np.mean((y_iso - true_response)**2)

print(f"Number of samples:          {n_samples}")
print(f"Isotonic fit is monotonic:  {is_monotonic}")
print(f"Number of unique flat steps: {len(np.unique(y_iso))}")
print(f"Raw noisy MSE to truth:     {mse_raw:.4f}")
print(f"Isotonic MSE to truth:      {mse_iso:.4f} (noise filtered)")
print(f"First 5 fitted step values: {np.unique(y_iso)[:5].round(3)}")

Common pitfalls

  • Overfitting on small sample sizes: In small datasets, isotonic calibration creates step-like over-fitting where probabilities are squashed onto zero or one plateaus.
  • Out-of-sample extrapolation failure: Isotonic regression cannot extrapolate outside observed ranges of $x$; points below $\min(x)$ or above $\max(x)$ are clamped to boundary step values.
  • Multivariate curse of dimensionality: True multi-dimensional isotonic regression is an NP-hard partial order problem; PAVA applies strictly to 1D ordered arrays.

06 Check yourself

Q1How does the Pool Adjacent Violators Algorithm (PAVA) resolve a monotonicity violation where y_i > y_{i+1}?

Why: When y_i > y_{i+1}, least-squares under ordering constraints forces hat{y}_i = hat{y}_{i+1}; the least-squares optimum for a pooled group is its weighted sample average.

Q2When should a practitioner choose Platt scaling over Isotonic regression for probability calibration?

Why: Platt scaling is parametric (fitting a 2-parameter logistic sigmoid), making it resistant to overfitting on small validation sets, whereas non-parametric isotonic regression overfits small samples.
