Second-Order Optimisation: Newton, BFGS and L-BFGS

Use curvature, not just slope, to choose the step. Newton is fast but expensive; quasi-Newton methods approximate it cheaply.

01 The idea

Gradient descent only knows the slope. Newton’s method also uses the curvature (the Hessian), so on a bowl-shaped function it jumps straight to the bottom. Quasi-Newton methods like BFGS and L-BFGS build up an approximation of the curvature from successive gradients.

In a long, narrow valley, the right step is long along the valley and short across it. The Hessian encodes exactly this: inverting it rescales the gradient so every direction is equally easy. Newton converges in a handful of iterations near the optimum (quadratically).

The catch is cost: a Hessian has $p^2$ entries and inverting it costs $p^3$. BFGS keeps an approximation of the inverse Hessian and updates it from how the gradient changed after each step. L-BFGS goes further and stores only the last $m$ (say 10) pairs of changes, so memory is $O(mp)$. That is why it is scikit-learn’s default solver for logistic regression.

In everyday terms

Gradient descent feels the slope underfoot; Newton also knows how the slope is changing, so it can guess where the bottom is and jump there.

02 Step by step

  1. Compute the gradient $g_t$.
  2. Newton: solve $H_t d = -g_t$. Quasi-Newton: $d = -B_t^{-1}g_t$ using the current approximation.
  3. Line search along $d$ for a step that sufficiently decreases the loss.
  4. Update the curvature approximation from $s_t = \theta_{t+1} - \theta_t$ and $y_t = g_{t+1} - g_t$.

04 The maths

  1. Newton step

    $$\theta_{t+1} = \theta_t - H(\theta_t)^{-1}\nabla J(\theta_t)$$

    Exact for quadratics in one step. Needs $H$ to be positive definite to be a descent direction.

  2. Secant condition and BFGS update

    $$B_{t+1}s_t = y_t, \qquad B_{t+1} = B_t - \frac{B_ts_ts_t^\top B_t}{s_t^\top B_ts_t} + \frac{y_ty_t^\top}{y_t^\top s_t}$$

    The approximation is corrected so it reproduces the gradient change actually observed along the last step.

05 Key takeaways

  • Second-order methods need far fewer iterations, each more expensive.
  • L-BFGS suits smooth, deterministic, medium-sized problems (logistic regression, CRFs).
  • For huge data and mini-batches, first-order methods (SGD, Adam) win.

06 In code

python
import numpy as np
from scipy.optimize import minimize

def rosen(t): return (1 - t[0]) ** 2 + 100 * (t[1] - t[0] ** 2) ** 2
def grad(t): return np.array([-2 * (1 - t[0]) - 400 * t[0] * (t[1] - t[0] ** 2), 200 * (t[1] - t[0] ** 2)])

for method in ["CG", "BFGS", "L-BFGS-B"]:
    res = minimize(rosen, x0=[-1.2, 1.0], jac=grad, method=method)
    print(method, res.nit, "iterations ->", res.x.round(4))

Common pitfalls

  • Using L-BFGS with mini-batches; its curvature estimates need consistent gradients.
  • Expecting Newton to work from far away on non-convex functions without safeguards.

07 Check yourself

Q1Why is L-BFGS practical where Newton’s method is not?

Why: Memory and compute stay linear in $p$.

Q2On a convex quadratic, Newton’s method converges in:

Why: The quadratic model is exact, so the Newton step lands on the minimum.

Q3What is the computational complexity of inverting a full $p \times p$ Hessian matrix in standard Newton's method with $p$ parameters?

Why: Inverting a general $p \times p$ matrix (or solving the linear system $H d = -g$) via Gaussian elimination or Cholesky decomposition costs $O(p^3)$ operations, which becomes prohibitively slow when $p$ exceeds thousands.

Q4What condition must the Hessian matrix $H(\theta_t)$ satisfy to guarantee that the Newton step $d = -H^{-1}\nabla J$ is a descent direction?

Why: For $d$ to be a descent direction, we must have $\nabla J^\top d = -\nabla J^\top H^{-1} \nabla J < 0$ for non-zero gradient. This holds if and only if $H^{-1}$ (and thus $H$) is positive definite.

Q5In L-BFGS, what does the hyperparameter $m$ represent?

Why: L-BFGS avoids saving the full matrix by keeping a memory buffer of the $m$ most recent vector pairs $s_k = \theta_{k+1} - \theta_k$ and $y_k = g_{k+1} - g_k$, typically setting $m \in [5, 20]$.

Q6What is the "secant condition" $B_{t+1} s_t = y_t$ that quasi-Newton methods enforce at each iteration?

Why: Taylor expansion of the gradient gives $\nabla J(\theta + s) - \nabla J(\theta) \approx H s$. The secant condition requires the surrogate Hessian $B_{t+1}$ to reproduce this observed gradient difference along the latest step vector $s_t$.

Q7Why is L-BFGS rarely used for training deep neural networks with stochastic mini-batches, where SGD or Adam are standard?

Why: L-BFGS computes $y_t = g_{t+1} - g_t$. In mini-batch training, $g_{t+1}$ and $g_t$ are evaluated on different batches of data, so $y_t$ reflects batch sampling noise rather than true loss surface curvature.

Q8What is the purpose of a line search (such as satisfying the Wolfe conditions) in quasi-Newton algorithms?

Why: A pure unit Newton step ($d_t$) may overshoot if the local quadratic approximation does not hold globally. Line search selects $\alpha_t$ so that $J(\theta_t + \alpha_t d_t)$ drops sufficiently (Armijo rule) and satisfies the curvature condition ($s_t^\top y_t > 0$).

Q9On a non-convex surface far from any minimum, what risk does standard Newton's method face if the Hessian matrix has negative eigenvalues?

Why: If $H$ is not positive definite, $-H^{-1}\nabla J$ may not be a descent direction. For example, near a local maximum where $H$ is negative definite, the step jumps directly towards the peak!

Q10Consider a 1D quadratic objective $J(\theta) = 3\theta^2 - 12\theta + 7$. Starting from initial guess $\theta_0 = 10$, what are the first derivative $J'(\theta_0)$, the second derivative $J''(\theta_0)$, and the next point $\theta_1$ after one Newton step $\theta_1 = \theta_0 - \frac{J'(\theta_0)}{J''(\theta_0)}$?

Why: Derivative: $J'(\theta) = 6\theta - 12$. At $\theta_0 = 10$, $J'(10) = 60 - 12 = 48$. Second derivative: $J''(\theta) = 6$. Newton step: $\Delta \theta = -\frac{48}{6} = -8$. New iterate: $\theta_1 = 10 - 8 = 2.0$. The true minimum of $3\theta^2 - 12\theta + 7$ is at $\theta^* = 12 / 6 = 2.0$, reaching the exact optimum in one step.

Q11For an optimisation problem with $p = 500$ parameters, how many float values must be stored in memory for the full $p \times p$ Hessian matrix in standard Newton's method, versus the storage needed for $m = 10$ displacement vector pairs in L-BFGS?

Why: Full Hessian: $p^2 = 500 \times 500 = 250{,}000$ floats (or $p(p+1)/2 = 125{,}250$ if symmetric). L-BFGS: stores $m$ vector pairs $(s_k, y_k)$, each of length $p$. Total storage $= 2 \times m \times p = 2 \times 10 \times 500 = 10{,}000$ floats—a 25-fold memory reduction.

Q12In a 2D optimisation problem, suppose the current gradient is $g = \begin{bmatrix} 2 \\ 8 \end{bmatrix}$ and the Hessian is diagonal: $H = \begin{bmatrix} 1 & 0 \\ 0 & 4 \end{bmatrix}$. What is the Newton direction $d = -H^{-1}g$, and how does it compare to the steepest descent direction $-g$?

Why: $H^{-1} = \begin{bmatrix} 1 & 0 \\ 0 & 1/4 \end{bmatrix}$. Thus $d = -H^{-1}g = -\begin{bmatrix} 1(2) \\ (1/4)(8) \end{bmatrix} = \begin{bmatrix} -2 \\ -2 \end{bmatrix}$. Steepest descent direction $-g = \begin{bmatrix} -2 \\ -8 \end{bmatrix}$ is pulled 4 times stronger along the second axis, causing zigzagging. Newton's step normalises by curvature, yielding equal progress along both axes.
