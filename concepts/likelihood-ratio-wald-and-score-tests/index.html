Likelihood-ratio, Wald and score tests

The "Holy Trinity" of classical parametric hypothesis testing consists of the Likelihood-Ratio (LR) test, the Wald test, and the Score (Lagrange Multiplier / Rao) test. Derived from the geometry of the log-likelihood function \ell(\theta), all three tests evaluate null hypotheses of the form H_0: \theta = \theta_0 (or nested model restrictions) and share identical asymptotic chi-squared (\chi^2) distributions under the null. However, they differ radically in computational cost: the Wald test requires fitting only the unconstrained model; the Score test requires fitting only the constrained model under H_0; and the Likelihood-Ratio test requires fitting both models, achieving optimal finite-sample invariance.

01 The idea

Suppose you want to test whether adding 5 interaction terms to a logistic regression model significantly improves its predictive power. Should you compare the drop in log-likelihood (Likelihood-Ratio test), check how many standard errors the estimated parameters sit from zero (Wald test), or evaluate the gradient slope at the restricted baseline without fitting the full model at all (Score test)? Understanding the geometric relationship and computational trade-offs among the "Holy Trinity" is essential for modern statistical inference and econometric modelling.

The Three Views of the Likelihood Surface: Imagine the log-likelihood curve \ell(\theta) plotted against parameter \theta, with the unconstrained maximum likelihood estimate at the peak \hat{\theta}, and the restricted null value at \theta_0: - Likelihood-Ratio (LR) Test: Looks at vertical height: how much lower is the log-likelihood at the null compared to the peak? 2 * [\ell(\hat{\theta}) - \ell(\theta_0)]. - Wald Test: Looks at horizontal distance: how far is \hat{\theta} from \theta_0, weighted by the estimated curvature (Fisher Information) at the peak? (\hat{\theta} - \theta_0)^2 * I(\hat{\theta}). - Score (Rao) Test: Looks at slope (gradient): how steep is the slope of the log-likelihood evaluated at the null point \theta_0? If \theta_0 were truly the maximum, the slope would be zero.

Computational Asymmetry in Large Models: - When fitting the unconstrained model is trivial, the Wald test is fast and convenient (this is why software packages print Wald z-statistics next to every regression coefficient). - When the unconstrained model is massive, complex, or expensive to train (e.g. adding 10,000 genomic features), the Score test is brilliant because you never fit the full model! You only evaluate the gradient at the simple restricted baseline. - The Likelihood-Ratio test requires fitting both models, but achieves transformation invariance: reparameterising \theta as log \theta or e^\theta leaves the LR test statistic identical, whereas the Wald test changes.

Asymptotic Equivalence under the Null: Under H_0 as sample size n approaches infinity, Taylor expansions show that all three test statistics converge to the exact same value and follow a chi-squared distribution with degrees of freedom equal to the number of parameter restrictions: LR ~ W ~ S ~ \chi^2(r).

In everyday terms

Imagine trying to verify whether the summit of a mountain \hat{\theta} is significantly higher than a base camp \theta_0. The LR test measures the vertical elevation drop between the summit and the camp. The Wald test measures the horizontal walking distance from the summit to the camp and multiplies by the summit's terrain curvature. The Score test stands at the base camp and measures the steepness of the upward slope pointing toward the summit without ever hiking up to the top.

03 The maths

  1. Likelihood-Ratio (LR) Test Statistic

    \text{LR} = 2 \left[ \ell(\hat{\theta}) - \ell(\tilde{\theta}) \right] \xrightarrow{d} \chi^2(r)

    The Wilks theorem proves that twice the difference in log-likelihood between the unrestricted maximum \hat{\theta} and restricted maximum \tilde{\theta} converges asymptotically to a chi-squared distribution with degrees of freedom r equal to the number of restrictions.

  2. Wald Test Statistic

    W = (\hat{\theta} - \theta_0)^\top \left[ \widehat{\text{Var}}(\hat{\theta}) \right]^{-1} (\hat{\theta} - \theta_0) = (\hat{\theta} - \theta_0)^\top \mathcal{I}_n(\hat{\theta}) (\hat{\theta} - \theta_0) \xrightarrow{d} \chi^2(r)

    The Wald test evaluates the quadratic distance of the unconstrained estimate \hat{\theta} from the null hypothesis value \theta_0, weighted by the observed Fisher Information matrix \mathcal{I}_n(\hat{\theta}). It requires fitting only the unconstrained model.

  3. Score (Lagrange Multiplier / Rao) Test Statistic

    S = \mathbf{U}(\tilde{\theta})^\top \left[ \mathcal{I}_n(\tilde{\theta}) \right]^{-1} \mathbf{U}(\tilde{\theta}) \xrightarrow{d} \chi^2(r), \qquad \mathbf{U}(\theta) = \nabla_\theta \ell(\theta)

    The Score test evaluates the score vector (gradient) \mathbf{U} evaluated at the restricted estimate \tilde{\theta}. If the null hypothesis is true, \tilde{\theta} is close to the true maximum, so the gradient \mathbf{U}(\tilde{\theta}) should be statistically indistinguishable from zero.

04 Key takeaways

  • The Likelihood-Ratio, Wald, and Score tests form the 'Holy Trinity' of classical parametric testing, all asymptotically chi-squared under H_0.
  • The LR test evaluates vertical log-likelihood difference, the Wald test evaluates horizontal parameter distance, and the Score test evaluates gradient slope at the null.
  • Computational trade-offs: Wald requires fitting only the unconstrained model; Score requires fitting only the constrained model; LR requires fitting both.
  • The Likelihood-Ratio test is invariant to parameter reparameterisation, whereas the Wald test can vary depending on parameter scaling.

05 In code

python
"""
The Holy Trinity of Hypothesis Testing: Likelihood-Ratio, Wald, and Score Tests
Demonstrated on a Poisson Rate Parameter H0: lambda = lambda_0.
"""

import numpy as np
from scipy import stats

# Generate synthetic Poisson count data
np.random.seed(42)
true_lambda = 4.8
n_obs = 60
data = np.random.poisson(lam=true_lambda, size=n_obs)
sum_x = np.sum(data)

# Null hypothesis: lambda = lambda_0
lambda_0 = 4.0

# 1. Unconstrained Maximum Likelihood Estimate
# For Poisson: log L(lambda) = -n*lambda + sum_x * log(lambda) - sum(log(x!))
# MLE lambda_hat = sum_x / n
lambda_hat = sum_x / n_obs

# Fisher Information: I_n(lambda) = n / lambda
# Log-likelihood function (dropping constant factorial terms)
def log_lik(lam):
    return -n_obs * lam + sum_x * np.log(lam)

# 2. Likelihood-Ratio Test
# LR = 2 * [log L(lambda_hat) - log L(lambda_0)]
lr_stat = 2 * (log_lik(lambda_hat) - log_lik(lambda_0))
p_lr = 1 - stats.chi2.cdf(lr_stat, df=1)

# 3. Wald Test
# W = (lambda_hat - lambda_0)^2 * I_n(lambda_hat) = (lambda_hat - lambda_0)^2 * (n / lambda_hat)
i_wald = n_obs / lambda_hat
wald_stat = ((lambda_hat - lambda_0) ** 2) * i_wald
p_wald = 1 - stats.chi2.cdf(wald_stat, df=1)

# 4. Score (Rao / LM) Test
# Score U(lambda) = d log L / d lambda = -n + sum_x / lambda
# Evaluated at lambda_0: U(lambda_0) = -n + sum_x / lambda_0
# Score Stat = [U(lambda_0)]^2 / I_n(lambda_0) = (-n + sum_x / lambda_0)^2 / (n / lambda_0)
score_u0 = -n_obs + (sum_x / lambda_0)
i_score0 = n_obs / lambda_0
score_stat = (score_u0 ** 2) / i_score0
p_score = 1 - stats.chi2.cdf(score_stat, df=1)

print(f"=== Hypothesis Test: H0: lambda = {lambda_0:.1f} vs H1: lambda != {lambda_0:.1f} ===")
print(f"Sample Size n = {n_obs} | Sample Mean (MLE) = {lambda_hat:.3f} | Sample Sum = {sum_x}")
print(f"\n1. Likelihood-Ratio (LR) Test: Stat = {lr_stat:.4f} | p-value = {p_lr:.4f}")
print(f"2. Wald Test:                  Stat = {wald_stat:.4f} | p-value = {p_wald:.4f}")
print(f"3. Score (Rao) Test:           Stat = {score_stat:.4f} | p-value = {p_score:.4f}")

print("\n--- Practical Invariance Check ---")
print("All three test statistics are asymptotically equivalent under H0.")
print(f"Difference |LR - Wald|:  {abs(lr_stat - wald_stat):.4f}")
print(f"Difference |LR - Score|: {abs(lr_stat - score_stat):.4f}")
print("At alpha = 0.05, conclusion across all three tests:", "REJECT H0" if p_lr < 0.05 else "FAIL TO REJECT H0")

Common pitfalls

  • The Hauck-Donner effect in Wald tests: When parameters are very large or separation occurs, estimated standard errors explode faster than coefficients, causing Wald statistics to erroneously shrink toward zero.
  • Assuming tests give identical finite-sample p-values: While asymptotically equivalent, their finite-sample numerical values often differ: typically Wald >= LR >= Score in linear regression.
  • Ignoring boundary constraints: If the null hypothesis lies on the boundary of the parameter space (e.g. variance sigma^2 = 0), the asymptotic distribution is a mixture of chi-squared distributions, not a standard chi-squared.

06 Check yourself

Q1Which of the three classical tests requires estimating ONLY the constrained model under the null hypothesis H_0?

Why: The Score test evaluates the slope (gradient) of the log-likelihood at the restricted parameter estimate \tilde{\theta}. It requires no estimation of the unconstrained model.

Q2What is the primary advantage of the Likelihood-Ratio test over the Wald test in non-linear models?

Why: The height difference between the peak and restricted point on the likelihood surface is completely invariant to how parameters are scaled (e.g. \theta vs \log \theta), whereas the curvature-weighted distance in Wald tests is sensitive to parameterisation.

Q3Under the null hypothesis H_0 with r independent parameter restrictions, what is the asymptotic distribution of the Likelihood-Ratio test statistic?

Why: Wilks' theorem guarantees that 2[\ell(\hat{\theta}) - \ell(\tilde{\theta})] converges asymptotically to \chi^2(r), where r is the number of parameter restrictions.
