Regression Metrics: MAE, RMSE, R², MAPE

How to score a regression model, and what each metric hides. Pick the one that matches the cost of being wrong.

01 The idea

MAE is the average absolute miss. RMSE is the square root of the average squared miss, so big misses count more. $R^2$ compares your errors with always predicting the mean. MAPE expresses errors as percentages.

If every miss costs the same per unit, report MAE. If large misses are disproportionately bad, RMSE. If you need a scale-free number to compare across datasets, $R^2$, but remember a high $R^2$ can still mean large absolute errors when $y$ varies a lot.

MAPE is popular in business because percentages are intuitive, but it explodes when actual values are near zero and penalises over-forecasts more than under-forecasts. Weighted or symmetric versions (WAPE, sMAPE) are safer.

In everyday terms

Grading archers by average distance from the bullseye (MAE), by punishing wild shots extra (RMSE), or by how much better they are than someone aiming at the centre of the wall (R²).

02 Step by step

  1. Decide what a unit of error costs, and whether big errors cost more.
  2. Pick a primary metric accordingly; report a second for context.
  3. Always compare against a naive baseline (mean, last value).
  4. Look at residual plots, not just one number.

03 Try it

A fitted line and its residuals. Drag any point and watch MAE, RMSE, $R^2$ and MAPE react differently.

Things to try
  1. Drag one point far away: RMSE jumps much more than MAE.
  2. Drag a point toward y = 0: MAPE explodes.

04 The maths

  1. Definitions

    $$\mathrm{MAE} = \frac1n\sum|y_i - \hat y_i|, \;\; \mathrm{RMSE} = \sqrt{\frac1n\sum(y_i - \hat y_i)^2}, \;\; R^2 = 1 - \frac{\sum(y_i - \hat y_i)^2}{\sum(y_i - \bar y)^2}$$

    RMSE ≥ MAE always; a large gap means a few big errors.

  2. MAPE and WAPE

    $$\mathrm{MAPE} = \frac{100}{n}\sum\Big|\frac{y_i - \hat y_i}{y_i}\Big|, \qquad \mathrm{WAPE} = 100\frac{\sum|y_i - \hat y_i|}{\sum|y_i|}$$

    WAPE weights errors by volume and does not blow up on small actuals.

05 Key takeaways

  • $R^2$ can be negative on test data.
  • RMSE and MAE are in the target’s units; $R^2$ and MAPE are unitless.
  • The training loss and the reported metric need not be the same.

06 In code

python
import numpy as np
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score, mean_absolute_percentage_error

y = np.array([100, 120, 90, 300, 110]); pred = np.array([105, 115, 100, 220, 112])
print("MAE", mean_absolute_error(y, pred), "RMSE", round(mean_squared_error(y, pred) ** .5, 2),
      "R2", round(r2_score(y, pred), 3), "MAPE", round(100 * mean_absolute_percentage_error(y, pred), 1))

Common pitfalls

  • Using MAPE when actuals can be zero or tiny.
  • Celebrating a high $R^2$ without checking error size in real units.

07 Check yourself

Q1RMSE is much larger than MAE. This suggests:

Why: Squaring amplifies large errors; with equal errors RMSE = MAE.

Q2Why is MAPE risky for intermittent demand?

Why: One week with demand 1 and forecast 5 contributes 400%.

Q3What does the Coefficient of Determination ($R^2$) measure in regression?

Why: $R^2 = 1 - \frac{\mathrm{SS}_{\text{res}}}{\mathrm{SS}_{\text{tot}}}$ compares the residual sum of squares against the total variance around the mean $\bar{y}$. An $R^2$ of $0.80$ means 80% of target variance is captured by the model.

Q4Under what condition does Root Mean Squared Error (RMSE) equal Mean Absolute Error (MAE) exactly?

Why: By the Cauchy-Schwarz inequality, $\sqrt{\frac{1}{n}\sum e_i^2} \ge \frac{1}{n}\sum |e_i|$. Equality holds if and only if all $|e_i|$ are identical constants (e.g. every prediction misses by exactly 3.0 units).

Q5Why can $R^2$ be negative when evaluated on unseen held-out test data?

Why: A naive dummy baseline predicting $\bar{y}$ achieves $R^2 = 0$. If an overfitted model makes severe errors on test data such that $\mathrm{SS}_{\text{res}} > \mathrm{SS}_{\text{tot}}$, it performs worse than the flat mean, resulting in a negative $R^2$.

Q6Why is Weighted Absolute Percentage Error ($\mathrm{WAPE} = 100 \frac{\sum |y_i - \hat{y}_i|}{\sum |y_i|}$) preferred over standard MAPE for retail inventory forecasting with intermittent demand?

Why: If actual sales on Tuesday are $y = 0$, MAPE divides by zero and fails. If sales are $y = 1$ and forecast is $4$, MAPE adds $300\%$. WAPE aggregates errors across all days before dividing by total sales, providing a robust, volume-weighted percentage.

Q7A business stakeholder asks: "Can our regression model have an impressive $R^2 = 0.95$ and still be unacceptable for production deployment?" What is the correct response?

Why: $R^2$ is a relative measure of variance explained, not an absolute error metric. A high $R^2$ on highly dispersed data can still conceal absolute errors that are unacceptable in real-world dollar terms.

Q8What asymmetry bias is inherent in Mean Absolute Percentage Error (MAPE)?

Why: For actual $y = 100$: if forecast is $\hat{y} = 0$, error is $|100 - 0| / 100 = 100\%$. But if forecast is $\hat{y} = 300$, error is $|100 - 300| / 100 = 200\%$. If forecast is $1000$, error is $900\%$. MAPE heavily punishes models that forecast above actuals.

Q9You train two regression models on the same test set. Model A has $\mathrm{MAE} = 10.0$ and $\mathrm{RMSE} = 12.0$. Model B has $\mathrm{MAE} = 8.0$ and $\mathrm{RMSE} = 25.0$. If large individual prediction errors carry catastrophic commercial costs, which model should you choose?

Why: Model B has a lower median/average error on typical points (lower MAE), but its high RMSE ($25.0$) indicates it makes several huge, catastrophic blunders. When severe misses must be avoided, RMSE is the primary selection criterion.

Q10A test set has $n = 4$ observations with actual values $y = [10, 20, 30, 40]$ and predictions $\hat{y} = [10, 22, 28, 44]$. What are the Mean Absolute Error (MAE) and Root Mean Squared Error (RMSE)?

Why: Errors: $e_1 = 10 - 10 = 0$, $e_2 = 20 - 22 = -2$, $e_3 = 30 - 28 = 2$, $e_4 = 40 - 44 = -4$. Absolute errors: $[0, 2, 2, 4]$. $\mathrm{MAE} = (0 + 2 + 2 + 4) / 4 = 8 / 4 = 2.0$. Squared errors: $[0, 4, 4, 16]$. Mean squared error $= (0 + 4 + 4 + 16) / 4 = 24 / 4 = 6.0$. $\mathrm{RMSE} = \sqrt{6.0} \approx 2.449 \approx 2.45$.

Q11For a test set of 3 samples, the true values are $y = [2, 4, 6]$ (mean $\bar{y} = 4.0$, total sum of squares $\mathrm{SS}_{\text{tot}} = (2-4)^2 + (4-4)^2 + (6-4)^2 = 4 + 0 + 4 = 8$). A flawed model predicts $\hat{y} = [6, 4, 2]$. What is the Coefficient of Determination ($R^2$) of this model?

Why: Residuals: $y - \hat{y} \in \{2 - 6, 4 - 4, 6 - 2\} = \{-4, 0, 4\}$. Squared residuals: $(-4)^2 + 0^2 + 4^2 = 16 + 0 + 16 = 32$. $\mathrm{SS}_{\text{res}} = 32$. Therefore $R^2 = 1 - \frac{\mathrm{SS}_{\text{res}}}{\mathrm{SS}_{\text{tot}}} = 1 - \frac{32}{8} = 1 - 4.0 = -3.0$.

Q12A forecast is evaluated across two periods: Period 1 has actual $y_1 = 100$ and prediction $\hat{y}_1 = 120$. Period 2 has actual $y_2 = 10$ and prediction $\hat{y}_2 = 15$. What are the Mean Absolute Percentage Error (MAPE) and the Weighted Absolute Percentage Error (WAPE)?

Why: Percentage errors: Period 1: $\frac{|100 - 120|}{100} = \frac{20}{100} = 20.0\%$. Period 2: $\frac{|10 - 15|}{10} = \frac{5}{10} = 50.0\%$. $\mathrm{MAPE} = \frac{20.0\% + 50.0\%}{2} = 35.0\%$. Total absolute errors $= 20 + 5 = 25$. Total actuals $= 100 + 10 = 110$. $\mathrm{WAPE} = 100 \times \frac{25}{110} \approx 22.727\% \approx 22.7\%$.
