01 The idea

PCA and SVD allow negative values, producing components that cancel each other out destructively. Non-Negative Matrix Factorisation (NMF) constrains factors to strictly non-negative values, yielding intuitive additive parts-based representations.

In countless machine learning domains, the quantities being analysed are physically non-negative: pixel brightness in facial imagery, word occurrence counts in documents, power spectral densities in audio spectrograms, or customer purchase counts. However, classical linear methods like PCA, SVD, and ICA compute basis components that contain negative values.

When SVD reconstructs a facial image, it starts with an average "eigenface" and adds or subtracts strange ghostly basis patterns. These complex destructive cancellations lack human perceptual meaning: human brains recognise faces as additive combinations of parts (eyes, nose, mouth).

Non-Negative Matrix Factorisation (NMF), popularised by Daniel Lee and H. Sebastian Seung in 1999, enforces strict non-negativity on both factor matrices: $V \approx W H$, where $V \in \mathbb{R}_+^{n \times p}$, $W \in \mathbb{R}_+^{n \times k}$, and $H \in \mathbb{R}_+^{k \times p}$.

Because subtraction is mathematically forbidden, the columns of $W$ represent additive basis elements (parts or topics), while the columns of $H$ represent non-negative activation encodings. The resulting decomposition is sparse, highly interpretable, and naturally extracts meaningful parts-based representations without requiring explicit sparsity penalties.

In everyday terms

Imagine painting a landscape with an artist palette. SVD is like an anti-matter paintbrush that can paint both opaque paint and "negative anti-paint" that deletes colour beneath it. NMF operates like real physical paint: you can only add pigment onto the canvas, never subtract. To render a face with NMF, you must layer a nose onto a face shape, then layer eyes and a mouth. Every component corresponds to a real, tangible physical part.

03 The maths

  1. Frobenius Matrix Factorisation Objective

    \min_{W \ge 0, \; H \ge 0} \frac{1}{2} \|V - W H\|_F^2 = \frac{1}{2} \sum_{i=1}^n \sum_{j=1}^p \left(V_{ij} - (WH)_{ij}\right)^2

    Constrained optimisation problem. While non-convex jointly in (W, H), the objective is convex in W with fixed H, and convex in H with fixed W.

  2. Lee–Seung Multiplicative Update Rules

    H_{kj} \leftarrow H_{kj} \frac{(W^T V)_{kj}}{(W^T W H)_{kj}}, \quad W_{ik} \leftarrow W_{ik} \frac{(V H^T)_{ik}}{(W H H^T)_{ik}}

    Multiplicative scaling factor: when numerator equals denominator, the gradient is zero and the update reaches a stationary point. Guaranteed to preserve non-negativity automatically.

  3. Generalised Kullback–Leibler NMF Divergence

    D_{\mathrm{KL}}(V \parallel W H) = \sum_{i, j} \left( V_{ij} \log \frac{V_{ij}}{(WH)_{ij}} - V_{ij} + (WH)_{ij} \right)

    Alternative divergence used for count and audio spectrogram matrices, equivalent to maximum likelihood under Poisson noise assumptions.

04 Key takeaways

  • Factorises non-negative matrix $V \approx W H$ with strictly non-negative factor matrices ($W, H \ge 0$).
  • Disallows destructive subtraction, yielding interpretable additive parts-based representations.
  • Lee–Seung multiplicative update rules ensure non-negativity automatically without Lagrange multiplier projections.
  • Naturally induces sparsity: many entries in $W$ and $H$ converge strictly to zero without $L_1$ penalties.
  • Widely used in topic modelling, gene expression clustering, recommender systems, and audio source separation.

05 In code

python
import numpy as np

# Non-Negative Matrix Factorisation (NMF) from scratch via Lee & Seung Multiplicative Updates
def nmf_lee_seung(V, k, max_iters=200, tol=1e-5):
    n, p = V.shape
    # Initialise W and H with positive random values
    np.random.seed(42)
    W = np.random.uniform(0.1, 1.0, (n, k))
    H = np.random.uniform(0.1, 1.0, (k, p))
    eps = 1e-12
    
    loss_history = []
    
    for it in range(max_iters):
        # 1. Update H: H <- H * (W^T V) / (W^T W H + eps)
        numerator_H = W.T @ V
        denominator_H = (W.T @ W) @ H + eps
        H *= (numerator_H / denominator_H)
        
        # 2. Update W: W <- W * (V H^T) / (W H H^T + eps)
        numerator_W = V @ H.T
        denominator_W = W @ (H @ H.T) + eps
        W *= (numerator_W / denominator_W)
        
        # Compute Frobenius reconstruction loss
        loss = 0.5 * np.sum((V - W @ H)**2)
        loss_history.append(loss)
        
        if it > 0 and abs(loss_history[-2] - loss) < tol:
            break
            
    return W, H, loss_history

# Synthetic Document-Topic Matrix (8 documents x 6 terms)
# 3 documents about Machine Learning, 3 about Gardening, 2 about Cooking
terms = ['gradient', 'neural', 'trees', 'soil', 'flowers', 'recipe']
V = np.array([
    # ML terms       Gardening terms   Cooking
    [ 5,  4,  1,     0,  0,  0],  # Doc 1: ML
    [ 4,  5,  0,     0,  0,  0],  # Doc 2: ML
    [ 6,  4,  2,     0,  0,  1],  # Doc 3: ML
    [ 0,  0,  4,     5,  4,  0],  # Doc 4: Gardening
    [ 0,  0,  3,     4,  5,  0],  # Doc 5: Gardening
    [ 0,  0,  5,     3,  4,  1],  # Doc 6: Gardening
    [ 0,  0,  0,     1,  0,  5],  # Doc 7: Cooking
    [ 0,  1,  0,     0,  1,  6],  # Doc 8: Cooking
], dtype=float)

# Fit NMF with k=3 topics
k = 3
W, H, losses = nmf_lee_seung(V, k=k, max_iters=250)

print(f"Data Matrix V shape: {V.shape}")
print(f"Discovered Basis Matrix W (Docs x Topics): {W.shape}")
print(f"Discovered Component Matrix H (Topics x Terms): {H.shape}")
print(f"Initial Loss: {losses[0]:.2f} -> Final Loss: {losses[-1]:.2f}")
print("All values non-negative:", np.all(W >= 0) and np.all(H >= 0))

print("\nDiscovered Topics (Top Terms in H):")
for t_idx in range(k):
    top_term_indices = np.argsort(H[t_idx])[::-1]
    top_words = [f"{terms[i]} ({H[t_idx, i]:.2f})" for i in top_term_indices[:3]]
    print(f"  Topic {t_idx+1}: {', '.join(top_words)}")

Common pitfalls

  • Non-convexity and local minima: The joint objective is non-convex in $(W, H)$; different random initialisations converge to different local optima.
  • Non-uniqueness of factorisation: If an invertible matrix $B$ exists such that $W B \ge 0$ and $B^{-1} H \ge 0$, then $(W B)(B^{-1} H) = W H$ is an alternative valid factorisation.
  • Strict non-negativity requirement: Cannot process inputs containing negative values; features must be strictly non-negative.

06 Check yourself

Q1Why does Non-Negative Matrix Factorisation produce more interpretable parts-based representations than SVD/PCA on facial images?

Why: In SVD, components contain negative values that subtract features destructively. In NMF, all factors are non-negative, forcing parts to combine purely additively.

Q2How do the Lee–Seung multiplicative updates preserve non-negativity during optimisation?

Why: Because V, W, and H are initialised with positive numbers, all matrix products in the numerator and denominator are positive. Multiplying a positive entry by a positive ratio can never produce a negative number.
