01 The idea

Classical tabular Q-learning fails when state spaces become continuous or high-dimensional. Deep Q-Networks (DQN) pioneered by Mnih et al. bridged deep learning and reinforcement learning by approximating action-value functions with neural networks, stabilizing training through experience replay buffers and frozen target networks.

In standard Q-learning, the Bellman equation updates tabular entries: $Q(s, a) \leftarrow Q(s, a) + \alpha [r + \gamma \max_{a'} Q(s', a') - Q(s, a)]$. When a neural network with parameters $\theta$ replaces the table, two lethal instabilities arise: 1) consecutive observation samples are highly correlated in time, violating the i.i.d. assumption of stochastic gradient descent; and 2) the target values $r + \gamma \max_{a'} Q(s', a'; \theta)$ shift continuously as the network updates, leading to catastrophic feedback loops.

DQN conquered these instabilities with two architectural innovations: Experience Replay (storing transitions $(s, a, r, s')$ in a circular buffer and sampling mini-batches uniformly at random) and Target Networks (using a separate, periodically frozen set of weights $\theta^-$ to calculate Bellman targets).

In everyday terms

Imagine learning to play tennis against a ball machine. If you only practice returning the single ball that was just launched, your muscle memory oscillates erratically. Experience replay is like recording video of hundreds of diverse shots over the past month and reviewing a random shuffle of groundstrokes, volleys, and serves during every practice session to maintain well-rounded reflexes.

02 Step by step

  1. Initialize replay memory buffer $\mathcal{D}$ to capacity $N$ and action-value network $Q(s, a; \theta)$ with random weights.
  2. Initialize target action-value network $Q(s, a; \theta^-)$ with identical weights $\theta^- = \theta$.
  3. For each timestep: select action $a_t$ using $\epsilon$-greedy exploration with respect to $Q(s_t, a; \theta)$.
  4. Execute action $a_t$, observe reward $r_t$ and successor state $s_{t+1}$, and store transition tuple $(s_t, a_t, r_t, s_{t+1}, \text{done})$ in $\mathcal{D}$.
  5. Sample random mini-batch of transitions from $\mathcal{D}$ and compute targets: $y_j = r_j$ if terminal, else $r_j + \gamma \max_{a'} Q(s_{j+1}, a'; \theta^-)$.
  6. Perform gradient descent step on loss $\mathcal{L}(\theta) = (y_j - Q(s_j, a_j; \theta))^2$ and periodically update target weights $\theta^- \leftarrow \theta$.

03 The maths

  1. DQN Loss Function

    \mathcal{L}(\theta) = \mathbb{E}_{(s, a, r, s') \sim \mathcal{D}} \left[ \left( r + \gamma \max_{a'} Q(s', a'; \theta^-) - Q(s, a; \theta) \right)^2 \right]

    Mean squared Bellman error computed over random mini-batches from replay buffer $\mathcal{D}$, using target network $\theta^-$ for stability.

  2. Double DQN Target Formulation

    y^{\text{DoubleDQN}} = r + \gamma Q\left(s', \arg\max_{a'} Q(s', a'; \theta); \theta^-\right)

    Decouples action selection (using online policy $\theta$) from value evaluation (using target network $\theta^-$) to eliminate maximisation bias.

04 Key takeaways

  • Experience replay breaks temporal correlations by shuffling historical transitions into independent training mini-batches.
  • Target networks freeze the evaluation parameters for hundreds of iterations, preventing unstable moving target oscillations.
  • Double DQN eliminates systematic overestimation bias by separating action selection from value estimation.

05 In code

python
import numpy as np

class ReplayBuffer:
    def __init__(self, capacity=1000):
        self.capacity = capacity
        self.buffer = []
        self.idx = 0

    def push(self, s, a, r, s_next, done):
        if len(self.buffer) < self.capacity:
            self.buffer.append(None)
        self.buffer[self.idx] = (s, a, r, s_next, done)
        self.idx = (self.idx + 1) % self.capacity

    def sample(self, batch_size):
        indices = np.random.choice(len(self.buffer), batch_size, replace=False)
        batch = [self.buffer[i] for i in indices]
        s, a, r, s_next, d = zip(*batch)
        return np.array(s), np.array(a), np.array(r), np.array(s_next), np.array(d)

# Simulation: Target Network Bellman Error calculation
np.random.seed(42)
gamma = 0.99
buffer = ReplayBuffer(100)

# Simulate storing transitions
for _ in range(50):
    s = np.random.randn(4)
    a = np.random.choice([0, 1])
    r = 1.0 if s[0] > 0 else 0.0
    s_next = s + np.random.randn(4) * 0.1
    buffer.push(s, a, r, s_next, False)

# Sample batch and compute Double DQN targets
s_b, a_b, r_b, s_next_b, d_b = buffer.sample(8)

# Simulated Q-values from online and target networks
online_q_next = np.random.randn(8, 2)
target_q_next = np.random.randn(8, 2)

# Action selection via online network
best_actions = np.argmax(online_q_next, axis=1)

# Target evaluation via target network
double_targets = r_b + gamma * target_q_next[np.arange(8), best_actions] * (1 - d_b)

print(f"Batch sampled: {len(s_b)} transitions")
print(f"Double DQN Target Values (First 4): {double_targets[:4].round(3)}")

Common pitfalls

  • Failing to update target network weights periodically, causing the network to learn against stale, obsolete policy targets.
  • Using a replay buffer that is too small, discarding rare winning trajectories before the policy can learn from them.

06 Check yourself

Q1Why does standard deep Q-learning suffer from instability without an experience replay buffer?

Why: Transitions gathered sequentially in an interactive environment are correlated; shuffling them in a replay buffer restores the i.i.d. assumption needed for stable SGD.

Q2What is the "moving target problem" in deep reinforcement learning?

Why: When the same weights parameterised both the current estimate and the regression target, every gradient step shifts the target, causing divergence.

Q3How does Double DQN resolve overestimation bias in Q-value estimation?

Why: In standard DQN, the $\max$ operator over noisy estimates systematically overestimates values. Double DQN decouples action choice from value evaluation.
