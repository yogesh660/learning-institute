01 The idea

Data is abundant, but expert annotation is expensive. Active learning flips passive learning on its head: the model actively queries human annotators for labels on the most informative, ambiguous instances.

In conventional passive machine learning, practitioners collect a dataset, randomly sample thousands of instances for human labeling, and train a model. However, random sampling is notoriously wasteful: annotators spend hours labelling obvious, redundant instances (e.g. 5,000 nearly identical images of blue skies) that provide zero new information to the model.

Active Learning reverses the control loop: instead of passively receiving training data, the algorithm actively inspects the unlabelled data pool and selects the most informative, valuable instances to send to human annotators ("oracles"). By focusing annotation budgets exclusively on ambiguous edge cases, active learning often achieves the same accuracy as passive learning using 10% to 20% of the labelling budget.

The most widely deployed family of active learning algorithms is Uncertainty Sampling. The algorithm queries samples where the model current predictions are least certain: Least Confidence (querying points with the lowest top-1 probability), Margin Sampling (querying points where the gap between the top two class probabilities is smallest), and Entropy Sampling (querying points with maximal prediction entropy across all classes).

Beyond single-model uncertainty, Query-by-Committee (QBC) maintains an ensemble of models and queries instances with the greatest committee voting disagreement. To avoid wasting budget on isolated noise outliers, modern active learning couples uncertainty with density-weighted diversity sampling.

In everyday terms

Imagine a student preparing for a medical licensing exam with a professor. A passive student reads random textbook pages cover to cover, spending hours rereading basic definitions they already know cold. An active student solves a diagnostic test, identifies the five specific cardiovascular disease scenarios where their knowledge was most confused and hesitant, and brings precisely those five ambiguous cases to the professor office hours for clarification.

03 The maths

  1. Uncertainty Sampling Strategies

    \begin{aligned} \text{Least Confidence: } & x_{\mathrm{LC}}^* = \arg\max_x \left( 1 - \max_k P(y = k \mid x) \right) \\ \text{Margin Sampling: } & x_{\mathrm{M}}^* = \arg\min_x \left( P(\hat{y}_1 \mid x) - P(\hat{y}_2 \mid x) \right) \\ \text{Entropy Sampling: } & x_{\mathrm{Ent}}^* = \arg\max_x \left( -\sum_{k=1}^K P(y = k \mid x) \log P(y = k \mid x) \right) \end{aligned}

    Three classic uncertainty metrics. Margin sampling focuses specifically on the boundary separating the top two competing classes, outperforming least confidence in multi-class problems.

  2. Query-by-Committee (QBC) Vote Entropy

    x_{\mathrm{QBC}}^* = \arg\max_x \left( -\sum_{k=1}^K \frac{V(k, x)}{C} \log \frac{V(k, x)}{C} \right)

    Measures disagreement among a committee of C diverse models, where V(k, x) is the number of committee members predicting class k for instance x.

  3. Density-Weighted Information Criterion

    x^* = \arg\max_x \left( \phi_A(x) \cdot \left[\frac{1}{|U|} \sum_{u \in U} \operatorname{sim}(x, u)\right]^\beta \right)

    Multiplies informativeness score phi_A(x) by an average similarity density term, preventing the algorithm from querying isolated noise outliers in unpopulated regions.

04 Key takeaways

  • Iterative human-in-the-loop framework: algorithm actively selects the most informative unlabelled instances for annotation.
  • Dramatically reduces labelling costs: frequently matches passive random sampling accuracy using 50% to 80% fewer annotations.
  • Uncertainty sampling queries instances near the decision boundary (least confidence, margin, entropy).
  • Query-by-Committee (QBC) selects instances with maximal disagreement across an ensemble of hypotheses.
  • Density-weighted criteria prevent the algorithm from wasting budget on isolated, uninformative outliers.

05 In code

python
import numpy as np
from sklearn.linear_model import LogisticRegression

# Active Learning: Margin Uncertainty Sampling vs Passive Random Sampling
np.random.seed(42)

# Generate synthetic 2D classification dataset with overlapping margin
n_total = 600
X1 = np.random.normal(loc=[-1.0, -1.0], scale=1.0, size=(n_total // 2, 2))
X2 = np.random.normal(loc=[1.0, 1.0], scale=1.0, size=(n_total // 2, 2))
X = np.vstack([X1, X2])
y = np.array([0]*(n_total // 2) + [1]*(n_total // 2))

# Shuffle
perm = np.random.permutation(n_total)
X, y = X[perm], y[perm]

# Test set for evaluation (200 samples)
X_test, y_test = X[400:], y[400:]
X_pool, y_pool = X[:400], y[:400]

# Initial seed: 10 randomly labelled samples
initial_idx = np.random.choice(len(X_pool), size=10, replace=False)

def run_experiment(query_strategy='margin', n_rounds=8, batch_size=5):
    labelled_idx = list(initial_idx)
    pool_idx = [i for i in range(len(X_pool)) if i not in labelled_idx]
    
    accuracies = []
    
    for r in range(n_rounds):
        # 1. Train model on current labelled set
        clf = LogisticRegression()
        clf.fit(X_pool[labelled_idx], y_pool[labelled_idx])
        acc = np.mean(clf.predict(X_test) == y_test)
        accuracies.append(acc)
        
        # 2. Query next batch
        if query_strategy == 'random':
            chosen = np.random.choice(pool_idx, size=batch_size, replace=False)
        elif query_strategy == 'margin':
            probs = clf.predict_proba(X_pool[pool_idx])
            # Margin between top two classes: |P(class 1) - P(class 0)|
            margins = np.abs(probs[:, 0] - probs[:, 1])
            # Smallest margin = highest uncertainty
            uncertain_order = np.argsort(margins)[:batch_size]
            chosen = [pool_idx[idx] for idx in uncertain_order]
            
        # 3. Add to labelled set
        labelled_idx.extend(chosen)
        pool_idx = [i for i in pool_idx if i not in chosen]
        
    return accuracies

acc_random = run_experiment(query_strategy='random')
acc_active = run_experiment(query_strategy='margin')

sample_sizes = [10 + i * 5 for i in range(len(acc_random))]

print("--- Active Learning vs Passive Random Sampling ---")
print(f"Initial Accuracy (10 samples): {acc_active[0]*100:.1f}%\n")
for sz, r_acc, a_acc in zip(sample_sizes[1:], acc_random[1:], acc_active[1:]):
    print(f"Sample Size {sz:2d} | Random: {r_acc*100:.1f}% | Active Margin: {a_acc*100:.1f}% (Advantage: +{(a_acc - r_acc)*100:+.1f}%)")

final_gap = acc_active[-1] - acc_random[-1]
print(f"\nFinal Accuracy Advantage of Active Learning: +{final_gap*100:.1f}% using identical annotation budget!")

Common pitfalls

  • Sampling bias and blind spots: If the initial seed model completely misses an entire isolated cluster, uncertainty sampling will never query points near it because the model is falsely confident.
  • Cold start problem: When initial labelled data is too sparse ($n < 5$), model predictions are noisy and uncertainty scores are meaningless.
  • Annotation batch correlations: Querying the top $K$ most uncertain points simultaneously often selects $K$ near-duplicate points; batch diversity sampling is required.

06 Check yourself

Q1How does Margin Sampling select the next instance to query for human annotation?

Why: When the gap P(y_1|x) - P(y_2|x) is near zero, the model is balanced on the knife-edge between its top two choices; obtaining a label for this point provides maximal boundary information.

Q2Why is density weighting combined with uncertainty sampling in active learning?

Why: An isolated outlier far from all other points naturally produces high uncertainty. Density weighting ensures queried points reside in populated regions where learning benefits many samples.
