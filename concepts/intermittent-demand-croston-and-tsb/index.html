Intermittent Demand Forecasting: Croston's Method and TSB Formulation

Forecasting sporadic and lumpy demand (spare parts, rare equipment) by decomposing series into non-zero demand size and inter-arrival intervals.

01 The idea

Standard forecasting methods such as ARIMA and exponential smoothing assume demand occurs continuously at every time period. When applied to intermittent or "lumpy" demand (such as aircraft spare parts, high-end enterprise hardware, or specialised medical equipment), continuous models predict fractional demands (e.g. 0.08 units every day), resulting in severe inventory distortion, phantom holding costs, and frequent stockouts.

Intermittent time series are characterised by long sequences of zero values interspersed with occasional positive transactions. Syntetos and Boylan classify demand into four quadrants based on average inter-demand interval ($p$) and squared coefficient of variation ($CV^2$): Smooth, Intermittent, Erratic, and Lumpy.

Croston (1972) proposed decomposing the series into two separate processes: non-zero demand size $z_t$ and inter-arrival time $p_t$ (the number of periods between consecutive orders).

Whenever non-zero demand occurs, both components are updated using single exponential smoothing. When demand is zero, both state variables remain completely unchanged. The forecast per period is the ratio $\hat{y} = z_t / p_t$.

However, Croston's formulation is positively biased. Syntetos-Boylan Approximation (SBA) applies a multiplicative shrinkage factor $(1 - \alpha/2)$ to correct this bias. Furthermore, the Teunter-Syntetos-Babai (TSB) method updates demand probability at every single period (even when demand is zero), allowing the model to quickly detect product obsolescence or sudden end-of-life drops.

In everyday terms

Imagine managing emergency heart defibrillators for a hospital. The hospital does not order 0.05 defibrillators every morning; rather, zero units are ordered for six months, and then suddenly five units are ordered at once when a new wing opens. Croston's method tracks two separate clocks: how long between orders, and how many units are bought when an order finally arrives.

02 Step by step

  1. Classify demand lumpiness: Calculate average inter-arrival interval $p$ and demand size squared coefficient of variation $CV^2$ to confirm intermittent classification.
  2. Decompose series: Separate the historical series into non-zero transaction magnitudes $z_k$ and elapsed periods between transactions $p_k$.
  3. Apply conditional exponential smoothing: Update magnitude state $z_t$ and interval state $p_t$ strictly when demand occurs.
  4. Apply SBA bias correction: Multiply the estimated demand rate by $(1 - \alpha_p / 2)$ to eliminate positive estimation bias.
  5. Or apply TSB formulation: Update demand probability $p_t$ on every time step using smoothing parameter $\beta$ and demand size $z_t$ on non-zero steps using $\alpha$.

03 The maths

  1. Croston Conditional State Updates

    y_t > 0 \implies \begin{cases} z_t = \alpha y_t + (1 - \alpha) z_{t-1} \\ p_t = \alpha q_t + (1 - \alpha) p_{t-1} \end{cases}, \quad y_t = 0 \implies \begin{cases} z_t = z_{t-1} \\ p_t = p_{t-1} \end{cases}

    Demand size $z_t$ and elapsed periods $q_t$ are updated only on positive demand occurrences; states remain frozen during zero periods.

  2. Syntetos-Boylan Approximation (SBA) Debiaising

    \hat{y}_{t+1} = \left( 1 - \frac{\alpha}{2} \right) \frac{z_t}{p_t}

    Corrects for the positive bias inherent in the expectation of the reciprocal ratio $\mathbb{E}[z/p] \ne \mathbb{E}[z]/\mathbb{E}[p]$.

  3. Teunter-Syntetos-Babai (TSB) Obsolescence Update

    d_t = \begin{cases} 1 & \text{if } y_t > 0 \\ 0 & \text{if } y_t = 0 \end{cases}, \quad p_t = \beta d_t + (1 - \beta) p_{t-1}, \quad \hat{y}_{t+1} = p_t \cdot z_t

    TSB updates demand probability $p_t$ every period, allowing the forecast to decay to zero when a product becomes obsolete.

04 Key takeaways

  • Intermittent demand features long zero sequences separated by occasional non-zero orders.
  • Standard ARIMA/ETS models create severe stockout risks by producing noisy fractional estimates.
  • Croston decomposes demand into demand size and inter-demand arrival intervals.
  • TSB updates demand probability every period, making it capable of detecting product obsolescence.

05 In code

python
import numpy as np

def croston_sba(series: np.ndarray, alpha: float = 0.1) -> np.ndarray:
    """Croston method with Syntetos-Boylan Approximation (SBA) bias correction."""
    n = len(series)
    forecast = np.zeros(n)
    
    # Initialise states with first positive demand
    first_idx = np.where(series > 0)[0][0]
    z = float(series[first_idx])
    p = 1.0
    q = 1  # Inter-arrival counter
    
    for t in range(first_idx + 1, n):
        q += 1
        if series[t] > 0:
            z = alpha * series[t] + (1 - alpha) * z
            p = alpha * q + (1 - alpha) * p
            q = 0  # Reset counter
        # SBA forecast rate per period
        forecast[t] = (1.0 - alpha / 2.0) * (z / p)
        
    return forecast

# Intermittent spare parts demand (mostly zeros with sporadic spikes)
np.random.seed(42)
demand = np.array([0, 0, 4, 0, 0, 0, 0, 6, 0, 0, 0, 5, 0, 0, 0, 0, 0, 7, 0, 0])
sba_forecast = croston_sba(demand, alpha=0.15)

print("Observed demand:   ", demand[-6:])
print("SBA rate forecast: ", np.round(sba_forecast[-6:], 3))
# Notice smooth, realistic continuous rate (~0.8 to 1.1 units/period) rather than noisy swings

Common pitfalls

  • Evaluating with MAPE: Mean Absolute Percentage Error divides by actual demand; when actual demand is 0, MAPE produces division by zero.
  • Using unadjusted Croston: The standard Croston ratio $\hat{z}/\hat{p}$ suffers from systematic positive bias; always apply the SBA correction.
  • Failing to recognize obsolescence in Croston: If demand ceases permanently, Croston's states freeze forever, maintaining a positive forecast indefinitely.

06 Check yourself

Q1Why does Mean Absolute Percentage Error (MAPE) fail when evaluating intermittent demand forecasts?

Why: In intermittent demand, the majority of time steps have $y_t = 0$. Dividing by zero renders MAPE undefined or infinite.

Q2What critical flaw in classical Croston does the Teunter-Syntetos-Babai (TSB) formulation solve?

Why: Because Croston updates only when $y_t > 0$, if a product is discontinued, the forecast remains positively frozen forever. TSB updates demand probability on zeros, decaying to zero.

Q3What is the purpose of the Syntetos-Boylan Approximation (SBA) correction factor $(1 - \alpha/2)$?

Why: Because $\mathbb{E}[1/p] > 1/\mathbb{E}[p]$ by Jensen's inequality, the standard Croston ratio overestimates demand. SBA applies $(1 - \alpha/2)$ to debias the estimate.
