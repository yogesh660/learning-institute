Medical Imaging: Modalities, DICOM, Windowing, and 3D Segmentation

Clinical modalities span X-ray/CT (radiodensity in Hounsfield units), MRI (soft-tissue contrasts via magnetic resonance), ultrasound, and digital pathology. DICOM files store multidimensional volumetric scans alongside physical voxel spacing, slice thickness, patient coordinates, and radiometric window centres and widths. Radiometric windowing maps wide dynamic range CT data (e.g. -1000 to +3000 HU) into 8-bit perceptual ranges for soft tissue, bone, or lung parenchyma. 3D volumetric segmentation demands specialised handling of anisotropic slice spacing, volumetric patch-based inference, and loss functions robust to severe class imbalance like Dice and boundary loss.

01 The idea

Medical imaging bridges physical diagnostics and computer vision across CT, MRI, ultrasound, and histopathology. Clinically accurate processing requires handling calibrated physical units (Hounsfield units), radiometric windowing, anisotropic 3D voxels, and specialised volumetric architectures such as 3D U-Net and nnU-Net.

Standard consumer photography captures reflected visible light from 2D surfaces in RGB channels. In medical imaging, radiological instruments scan through anatomical volumes, producing 3D scalar fields where each voxel represents an intrinsic physical property. In computed tomography (CT), voxels measure radiodensity in calibrated Hounsfield Units (HU), where air is -1000 HU, pure water is 0 HU, soft tissues range from +20 to +80 HU, and dense cortical bone exceeds +1000 HU. Because human vision and display systems handle 256 grey levels, radiologists apply radiometric "windowing" to inspect narrow density bands (such as brain parenchyma or pulmonary vessels) without losing contrast. Segmenting anatomical lesions requires models to operate across spatial depth (Z-axis), accounting for non-isotropic voxel spacing where slices may be separated by 3 mm while within-plane resolution is 0.7 mm.

In everyday terms

Imagine an architect surveying a multi-storey skyscraper using ground-penetrating radar. Instead of taking colour snapshots of exterior walls, the radar generates a continuous 3D block of density readings. To inspect rebar within the concrete, the surveyor tunes the screen to filter out hollow drywall and focus entirely on high-density steel. Slicing the block at irregular floor intervals requires spatial interpolation to ensure internal columns align seamlessly across levels.

02 Step by step

  1. Parse DICOM metadata: extract Rescale Slope and Rescale Intercept to convert stored raw pixel values to Hounsfield Units ($HU = \text{pixel} \times \text{slope} + \text{intercept}$).
  2. Inspect physical metadata: extract `PixelSpacing` (dy, dx in mm) and `SliceThickness` (dz in mm) to compute spatial anisotropy.
  3. Resample volumetric grids: interpolate 3D volumes into isotropic spacing (e.g. 1.0 mm x 1.0 mm x 1.0 mm) using spline interpolation for CT images and nearest-neighbour for ground-truth masks.
  4. Apply radiometric windowing: clip and normalise density values according to the target clinical task (e.g. lung window: $WC=-600, WW=1500$; soft tissue: $WC=40, WW=400$).
  5. Train volumetric 3D architectures (e.g. 3D U-Net) using sliding volumetric patches and compound loss functions combining soft Dice loss and binary cross-entropy.

04 Key takeaways

  • Hounsfield units provide physically calibrated radiodensity metrics, making radiometric windowing essential for visualising specific tissue bands.
  • Anisotropic voxel dimensions require volumetric resampling to isotropic grids before standard 3D convolutional architectures can process them effectively.
  • Dice loss and boundary loss counteract severe class imbalance inherent to small anatomical targets within large volumetric background scans.

05 In code

python
import numpy as np

def dicom_to_hounsfield(raw_array, slope, intercept):
    """Converts raw sensor integers to physical Hounsfield units (HU)."""
    return raw_array.astype(np.float32) * slope + intercept

def apply_windowing(hu_image, window_centre, window_width):
    """Maps Hounsfield units to normalised [0, 1] range using radiometric window."""
    lower = window_centre - window_width / 2.0
    upper = window_centre + window_width / 2.0
    clipped = np.clip(hu_image, lower, upper)
    return (clipped - lower) / (upper - lower)

def soft_dice_loss(pred_probs, true_masks, eps=1e-6):
    """Computes soft Dice loss for volumetric binary segmentation."""
    intersection = np.sum(pred_probs * true_masks)
    cardinality = np.sum(pred_probs) + np.sum(true_masks)
    dice_coef = (2.0 * intersection + eps) / (cardinality + eps)
    return 1.0 - dice_coef

# Simulate a 3D chest CT volume (slices, height, width)
np.random.seed(42)
slices, h, w = 16, 64, 64
raw_ct = np.random.randint(0, 4096, size=(slices, h, w), dtype=np.uint16)
slope, intercept = 1.0, -1024.0

# 1. Convert to calibrated Hounsfield Units
hu_volume = dicom_to_hounsfield(raw_ct, slope, intercept)

# 2. Apply Soft-Tissue Window (Centre: 40 HU, Width: 400 HU)
soft_tissue = apply_windowing(hu_volume, window_centre=40, window_width=400)

# 3. Simulate ground truth lesion mask and model prediction
true_lesion = np.zeros((slices, h, w), dtype=np.float32)
true_lesion[6:10, 24:40, 24:40] = 1.0  # Synthetic nodule

# Model prediction with realistic soft probabilities
pred_probs = np.zeros_like(true_lesion)
pred_probs[6:10, 26:38, 26:38] = 0.85
pred_probs[5:11, 22:42, 22:42] += 0.05  # Surrounding uncertainty

loss = soft_dice_loss(pred_probs, true_lesion)
print(f"Calibrated HU Range: [{hu_volume.min():.1f}, {hu_volume.max():.1f}]")
print(f"Normalised Window Range: [{soft_tissue.min():.2f}, {soft_tissue.max():.2f}]")
print(f"Volumetric Soft Dice Loss: {loss:.4f} (Dice Score: {1.0 - loss:.4f})")

Common pitfalls

  • Normalising CT scans with zero-mean unit-variance instead of applying modality-appropriate Hounsfield windowing destroys critical tissue attenuation baselines.
  • Ignoring anisotropic voxel spacing (e.g. 5 mm slice spacing vs 0.5 mm in-plane resolution) leads to distorted spherical convolutional filters across depth.
  • Using standard cross-entropy loss without class balancing when lesions occupy less than 0.1% of the total 3D scan volume, driving the network to predict empty masks.

06 Check yourself

Q1What is the primary physical quantity represented by Hounsfield Units (HU) in a computed tomography (CT) scan?

Why: CT scans measure linear X-ray attenuation coefficients, normalised and scaled into Hounsfield Units where water is 0 HU and air is -1000 HU.

Q2Why must 3D volumetric CT scans frequently be resampled before 3D convolution?

Why: Medical scans often have high in-plane resolution (e.g. 0.7 mm) but larger inter-slice spacing (e.g. 3-5 mm). Resampling to isotropic spacing ensures spatial kernel consistency in all 3 dimensions.

Q3Why is soft Dice loss widely preferred over standard binary cross-entropy in medical lesion segmentation?

Why: In clinical scans, tumours or lesions often occupy a minute fraction (<1%) of voxels. Binary cross-entropy is overwhelmed by background voxels, whereas Dice loss directly optimises set overlap.
