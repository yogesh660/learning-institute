Residual Networks and Skip Connections

Standard deep networks degrade as layers multiply. By reformulating layers to learn residual differences $\mathcal{F}(x) = \mathcal{H}(x) - x$, skip connections establish unbroken gradient superhighways across hundreds of layers.

01 The idea

Before 2015, stacking more than 20 or 30 layers in a deep network caused training accuracy to degrade sharply—not due to overfitting, but because optimisation collapsed completely. Residual Networks (ResNets, He et al. 2015) solved this fundamental architectural hurdle by introducing identity shortcut connections, transforming loss surfaces and enabling stable optimisation across hundreds or thousands of layers.

In a conventional plain network, each stacked layer attempts to approximate an underlying target mapping $\mathcal{H}(x)$. Imagine constructing a 50-layer network when a 20-layer network already suffices for the problem. To match the shallower model's performance, the remaining 30 layers must learn the identity function $\mathcal{H}(x) = x$. However, fitting an exact identity mapping through non-linear weight transformations ($W_2 \sigma(W_1 x)$) is surprisingly difficult for stochastic gradient descent, causing deep plain networks to achieve higher training error than their shallow counterparts.

ResNet reframes the objective: instead of tasking parameterised layers with fitting $\mathcal{H}(x)$ directly, the layers fit the **residual** difference $\mathcal{F}(x) = \mathcal{H}(x) - x$. The original input is then reintroduced via an identity skip connection: $\mathcal{H}(x) = \mathcal{F}(x) + x$. Under this reformulation, if an identity mapping is optimal, the optimiser can simply drive the residual weights towards zero ($\mathcal{F}(x) \to 0$), which standard weight decay achieves naturally.

The profound mathematical consequence occurs during backpropagation. The derivative of a residual block with respect to its input is $\frac{\partial \mathcal{H}}{\partial x} = \frac{\partial \mathcal{F}}{\partial x} + I$. Because of the additive identity matrix $I$, the backpropagated gradient contains an unattenuated term that flows backward through the skip connection completely independent of weight magnitudes. Even if the parameterised gradient $\frac{\partial \mathcal{F}}{\partial x}$ vanishes, the identity pathway ensures gradient signals reach early layers with full fidelity.

In everyday terms

Like an expressway with local detour loops: instead of forcing all traffic through 50 congested city intersections (plain layers), the highway lets traffic cruise unimpeded from start to finish (skip connection), exiting into local workshops (residuals) only when specialized modifications are needed.

02 Step by step

  1. Construct the residual transformation: build two or three convolutional or linear layers with normalisation and non-linear activations ($\mathcal{F}(x)$).
  2. Add the identity shortcut: route the unmodified input $x$ parallel to the transformations and add it element-wise ($y = \mathcal{F}(x) + x$).
  3. Handle dimension changes: when downsampling spatial dimensions or doubling channels, apply a $1 \times 1$ projection convolution on the shortcut path ($y = \mathcal{F}(x) + W_s x$) to align tensor shapes.
  4. Position post-addition activations: apply the non-linear activation (e.g. ReLU or GELU) immediately following the element-wise addition ($\sigma(\mathcal{F}(x) + x)$).
  5. Stack modular stages: assemble residual blocks into hierarchical stages (e.g. 64 → 128 → 256 → 512 channels) to construct deep backbones for vision, speech, or Transformer architectures.

03 The maths

  1. Residual block formulation

    $$\mathcal{H}(x) = \mathcal{F}(x; \{W_i\}) + x$$

    $x$ is the input tensor, $\mathcal{F}$ represents the residual mapping to be learned across parameterised layers $\{W_i\}$, and $\mathcal{H}(x)$ is the output tensor. If the optimal transformation is the identity function, parameter weights shrink to zero ($\mathcal{F} = 0$), leaving $\mathcal{H}(x) = x$ without distortion.

  2. Unattenuated gradient highway across depth

    $$\frac{\partial \mathcal{L}}{\partial x_l} = \frac{\partial \mathcal{L}}{\partial x_L}\frac{\partial x_L}{\partial x_l} = \frac{\partial \mathcal{L}}{\partial x_L} \left( I + \frac{\partial}{\partial x_l}\sum_{k=l}^{L-1} \mathcal{F}_k(x_k) \right)$$

    $x_l$ is the activation at block $l$, and $x_L = x_l + \sum_{k=l}^{L-1} \mathcal{F}_k(x_k)$ is the activation at block $L$. The gradient contains an additive identity component $I$, guaranteeing that the gradient cannot vanish across depth even if the Jacobians of intermediate residual transformations $\frac{\partial \mathcal{F}_k}{\partial x_l}$ approach zero.

04 Key takeaways

  • Residual connections reparameterise layers to learn the differential mapping $\mathcal{F}(x) = \mathcal{H}(x) - x$, making identity functions trivial to approximate.
  • The additive identity term in backpropagation ($\frac{\partial \mathcal{F}}{\partial x} + I$) creates a gradient superhighway, solving the degradation problem in deep networks.
  • Skip connections are standard architecture components across modern deep learning, including ResNets, ConvNeXts, Transformers, and diffusion models.

05 In code

python
import numpy as np

# Simulate gradient propagation across a 10-layer depth
depth = 10
w_scale = 0.5  # Sub-unitary Jacobian weight per layer

# 1. Plain feedforward network: gradients multiply sequentially
grad_plain = 1.0
for _ in range(depth):
    grad_plain *= w_scale  # grad * W

# 2. Residual network: gradients add identity term (W + I)
grad_res = 1.0
for _ in range(depth):
    grad_res *= (w_scale + 1.0)  # grad * (W + I)

print(f"Depth = {depth} layers (layer weight scale = {w_scale}):")
print(f"Plain network backpropagated gradient:    {grad_plain:.6f} (vanished to zero)")
print(f"Residual network backpropagated gradient: {grad_res:.2f} (unbroken gradient flow)")

Common pitfalls

  • Confusing the degradation problem with overfitting: deeper plain networks suffered from higher *training* error, proving it was an optimisation failure, not excessive variance.
  • Adding heavy non-linear operations onto the skip path itself, which obstructs the clean linear flow of gradients.
  • Failing to project shortcut dimensions when spatial resolution or channel depth changes, causing dimension mismatch errors during tensor addition.

06 Check yourself

Q1What was the degradation problem that motivated the invention of ResNets in 2015?

Why: He et al. showed that a 56-layer plain network suffered higher training error than a 20-layer plain network on CIFAR-10. Because the 56-layer network could theoretically mimic the 20-layer network via identity layers, higher training error demonstrated an optimisation breakdown.

Q2Why does backpropagation through a residual block prevent vanishing gradients?

Why: Because $\frac{\partial (\mathcal{F}(x) + x)}{\partial x} = \frac{\partial \mathcal{F}}{\partial x} + I$, the gradient always contains $+ I$, guaranteeing that gradient information reaches early layers even if $\frac{\partial \mathcal{F}}{\partial x}$ is small.

Q3When downsampling feature maps (e.g. stride 2) in a ResNet, what must be done to the skip connection?

Why: Because element-wise addition requires matching spatial height, width, and channel counts, a $1 \times 1$ strided projection convolution is applied to the shortcut path to align dimensions with the residual branch.

Q4Why is it easier for a residual block to learn an identity mapping than a plain layer?

Why: In a residual block $\mathcal{H}(x) = \mathcal{F}(x) + x$, setting weights to zero trivially yields $\mathcal{H}(x) = x$. In a plain network, learning an identity function requires finding precise non-zero weights that cancel non-linear activations.
