01 The idea

How can a neural network learn informative representations without human labels? Autoencoders accomplish unsupervised representation learning by posing an input reconstruction objective: an encoder compresses the input into a low-dimensional latent code, and a decoder attempts to reconstruct the original input from that bottleneck representation.

Suppose you want to describe thousands of different face photographs over a radio channel, but bandwidth restricts you to transmitting only 10 numbers per image. You cannot describe individual pixels. To succeed, those 10 numbers must capture the dominant axes of variance across human faces: head shape, eye spacing, skin tone, hair length, and smile width. The sketch artist on the receiving end uses those 10 parameters to recreate the portrait.

An **Autoencoder** builds this compression pipeline with two mirrored networks: 1. **Encoder** ($z = f_\theta(x)$): Compresses the high-dimensional input $x \in \mathbb{R}^D$ into a lower-dimensional latent bottleneck $z \in \mathbb{R}^d$ ($d \ll D$). 2. **Decoder** ($\hat{x} = g_\phi(z)$): Expands the latent code $z$ back to reconstruct the original input $\hat{x} \approx x$. The network trains by minimising a reconstruction loss (such as Mean Squared Error or Binary Cross-Entropy). If the encoder and decoder were strictly linear, the learned bottleneck would span the exact same subspace as Principal Component Analysis (PCA). But with non-linear activation functions, autoencoders learn curved, non-linear manifolds that linear projections cannot capture.

Beyond simple dimensional bottlenecks, regularised autoencoders prevent trivial memorisation. **Denoising Autoencoders (DAEs)** corrupt the input with noise ($\tilde{x} = x + \epsilon$) and train the decoder to recover the clean original $x$, learning an orthogonal projection field that pushes corrupted points back onto the true data manifold. This makes autoencoders exceptionally useful for anomaly detection: inputs that deviate from the normal training distribution cannot be reconstructed accurately, producing telltale spikes in reconstruction error.

In everyday terms

Like summarising a 500-page historical treatise into a 5-page brief (encoder) and having a historian reconstruct the full event timeline using only those 5 pages (decoder).

02 Step by step

  1. Choose the bottleneck dimension: select latent dimensionality $d$ reflecting the anticipated intrinsic dimensionality of the data manifold.
  2. Construct the encoder network: stack feedforward or convolutional layers tapering down in width from input dimensionality $D$ to latent code $z$.
  3. Construct the decoder network: mirror the encoder architecture, progressively expanding from latent code $z$ back to input dimensionality $D$.
  4. Define the reconstruction criterion: select Mean Squared Error for continuous real-valued features or Binary Cross-Entropy for normalised pixel intensities.
  5. Train and deploy: train end-to-end with the PyTorch training loop; detach the decoder and use the encoder as a feature extractor or anomaly detector.

03 The maths

  1. Autoencoder reconstruction objective

    $$\min_{\theta, \phi} \frac{1}{N}\sum_{i=1}^N \mathcal{L}\Big(x_i, g_\phi\big(f_\theta(x_i)\big)\Big), \quad z_i = f_\theta(x_i), \; \hat{x}_i = g_\phi(z_i)$$

    $f_\theta: \mathbb{R}^D \to \mathbb{R}^d$ is the encoder parameterised by $\theta$, $g_\phi: \mathbb{R}^d \to \mathbb{R}^D$ is the decoder parameterised by $\phi$, and $\mathcal{L}$ is the reconstruction loss. Minimising $\mathcal{L}$ forces $z$ to retain maximum information about $x$.

  2. Relationship to Principal Component Analysis (linear autoencoders)

    $$\text{If } f(x) = W_1 x \text{ and } g(z) = W_2 z, \quad \min_{W_1, W_2} \lVert X - W_2 W_1 X \rVert_F^2 \implies \operatorname{Span}(W_2) = \operatorname{Span}(U_d)$$

    For linear transformations under squared error loss, the global minimum of the autoencoder objective spans the exact same $d$-dimensional subspace as the top $d$ eigenvectors ($U_d$) of PCA. Non-linear activations enable autoencoders to learn non-linear manifolds.

  3. Denoising autoencoder objective

    $$\mathcal{L}_{\text{DAE}}(\theta, \phi) = \mathbb{E}_{x \sim p_{\text{data}}, \tilde{x} \sim q(\tilde{x}|x)}\left[ \lVert x - g_\phi(f_\theta(\tilde{x})) \rVert_2^2 \right]$$

    $q(\tilde{x}|x)$ is a corruption process (such as additive Gaussian noise or random zero-masking). The network learns a vector field that projects corrupted points back onto the true low-dimensional manifold.

04 Key takeaways

  • An undercomplete bottleneck ($d \ll D$) forces the network to discard noise and retain only the highest-variance generative factors of the data.
  • Linear autoencoders under MSE loss span the same subspace as PCA; non-linear activations generalise this to non-linear manifold learning.
  • Reconstruction error acts as an effective unsupervised anomaly detector: novel or corrupted inputs produce high reconstruction loss because they lie off the learned manifold.

05 In code

python
import numpy as np

# Synthetic non-linear manifold in 2D: x2 = sin(x1)
np.random.seed(42)
x1 = np.linspace(-np.pi, np.pi, 25)
x2 = np.sin(x1)
X = np.stack([x1, x2], axis=1)

# Undercomplete autoencoder: 2 inputs -> 1 latent unit -> 2 outputs
W_enc = np.random.randn(2, 1) * 0.5
b_enc = np.zeros(1)
W_dec = np.random.randn(1, 2) * 0.5
b_dec = np.zeros(2)
lr = 0.05

for epoch in range(100):
    # Forward pass: non-linear encoder, linear decoder
    z = np.tanh(X @ W_enc + b_enc)
    X_hat = z @ W_dec + b_dec
    loss = float(np.mean((X - X_hat)**2))
    # Backward pass
    d_out = 2.0 * (X_hat - X) / len(X)
    dW_dec, db_dec = z.T @ d_out, np.sum(d_out, axis=0)
    dz = (d_out @ W_dec.T) * (1.0 - z**2)
    dW_enc, db_enc = X.T @ dz, np.sum(dz, axis=0)
    # Optimiser step
    W_dec -= lr * dW_dec; b_dec -= lr * db_dec
    W_enc -= lr * dW_enc; b_enc -= lr * db_enc

# Evaluate reconstruction on normal point vs anomaly
normal_pt = np.array([[0.0, 0.0]])
anom_pt = np.array([[0.0, 5.0]])  # Lies completely off the manifold

rec_normal = np.tanh(normal_pt @ W_enc + b_enc) @ W_dec + b_dec
err_normal = float(np.mean((normal_pt - rec_normal)**2))

rec_anom = np.tanh(anom_pt @ W_enc + b_enc) @ W_dec + b_dec
err_anom = float(np.mean((anom_pt - rec_anom)**2))

print(f"Final training reconstruction loss: {loss:.4f}")
print(f"Normal point reconstruction error:  {err_normal:.4f}")
print(f"Anomaly reconstruction error:       {err_anom:.4f} (anomaly flagged)")

Common pitfalls

  • Using an overcomplete bottleneck ($d \ge D$) without regularisation (such as sparsity or denoising), allowing the network to trivially learn the identity mapping without extracting features.
  • Using standard autoencoders as generative models: their latent space contains empty gaps and holes; sampling random vectors $z$ produces nonsensical decoded outputs.
  • Minimising Mean Squared Error on complex multimodal image distributions, which encourages decoders to produce blurry, averaged reconstructions.

06 Check yourself

Q1What subspace does a linear autoencoder trained with Mean Squared Error loss learn?

Why: It is a classical theorem that a linear autoencoder with squared reconstruction error converges to the subspace spanned by the principal components of the training data.

Q2Why are standard deterministic autoencoders generally ineffective as generative models?

Why: Standard autoencoders only organise points they have seen during training. The spaces between clusters are unregularised voids; picking a random vector $z$ yields incoherent outputs.

Q3How does a Denoising Autoencoder (DAE) differ from a standard undercomplete autoencoder?

Why: By tasking the network with recovering uncorrupted data from noisy inputs, DAEs learn an orthogonal projection operator that pulls off-manifold points back onto the true data manifold.

Q4How can an autoencoder be applied to unsupervised anomaly detection?

Why: Because the autoencoder is trained to reconstruct normal patterns, anomalous observations that deviate from normal data distributions cannot be compressed and reconstructed accurately, resulting in high reconstruction error.
