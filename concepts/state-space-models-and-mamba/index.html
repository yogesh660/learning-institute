State-Space Models and Mamba: Linear-Time Sequence Modelling via Selective State Spaces

Replacing quadratic self-attention with linear-time continuous state spaces, selective time-varying matrices, and hardware-aware associative scans.

01 The idea

The Transformer's self-attention mechanism is the cornerstone of modern language modelling, but it suffers from a fundamental computational bottleneck: sequence length complexity scales quadratically $O(L^2)$ in compute and memory. Processing 100,000-token contexts in Transformers requires astronomical VRAM. State-Space Models (SSMs), culminating in Mamba (Gu & Dao, 2023), achieve Transformer-grade language quality with linear $O(L)$ scaling and constant-time inference.

Classical Structured State-Space Models (S4) map a continuous 1D input signal $x(t)$ to continuous latent state $h(t) \in \mathbb{R}^N$ and output $y(t)$ via continuous linear differential equations: $h'(t) = \mathbf{A} h(t) + \mathbf{B} x(t)$ and $y(t) = \mathbf{C} h(t)$.

Continuous SSMs are discretized using step size $\Delta$ (Euler or Bilinear transform) into recurrence forms: $h_t = \bar{\mathbf{A}} h_{t-1} + \bar{\mathbf{B}} x_t$. This recurrence enables $O(1)$ constant-time inference per step, like an RNN.

During training, because system matrices $(\mathbf{A}, \mathbf{B}, \mathbf{C})$ were time-invariant (LTI), the entire sequence recurrence can be unrolled into a single global convolution $y = x * \bar{\mathbf{K}}$, computable in $O(L \log L)$ time using Fast Fourier Transforms (FFTs).

However, LTI models cannot perform content-based reasoning (e.g. selectively storing an important token and forgetting trivia). Mamba introduces Selective State Spaces: making $\mathbf{B}, \mathbf{C},$ and $\Delta$ dynamic input-dependent functions of $x_t$. While this breaks global convolution, Mamba preserves parallel training using hardware-aware parallel associative scans implemented in GPU SRAM.

In everyday terms

Imagine reading an epic novel series like War and Peace. A Transformer is like an analyst who re-reads every single previous page from chapter 1 every time they read a new sentence to cross-reference every word. Mamba is like a brilliant detective who maintains a dynamic mental summary notebook: as each new line of dialogue arrives, they update their mental state in constant time, effortlessly remembering vital plot clues without rescanning thousands of earlier pages.

02 Step by step

  1. Input projection: Project input token $x_t$ through linear expansion layers into dimension $D$.
  2. Input-dependent selection: Compute dynamic time-step $\Delta_t = \operatorname{softplus}(\operatorname{Linear}(x_t))$, input matrix $\mathbf{B}_t = \operatorname{Linear}(x_t)$, and output matrix $\mathbf{C}_t = \operatorname{Linear}(x_t)$.
  3. Discretise continuous parameters: Compute discrete transition $\bar{\mathbf{A}}_t = \exp(\Delta_t \mathbf{A})$ and discrete input scale $\bar{\mathbf{B}}_t = \Delta_t \mathbf{B}_t$.
  4. Parallel associative scan (Training): Compute sequence recurrence in $O(\log L)$ parallel depth using associative scan operations directly inside high-speed GPU SRAM.
  5. Recurrent generation (Inference): Execute sequential state update $h_t = \bar{\mathbf{A}}_t h_{t-1} + \bar{\mathbf{B}}_t x_t$ with constant $O(1)$ step latency and zero KV-cache memory expansion.
  6. Output gating & projection: Modulate output with gating branch and project back to model dimension.

03 The maths

  1. Continuous State-Space Differential Equation

    h'(t) = \mathbf{A} h(t) + \mathbf{B} x(t), \quad y(t) = \mathbf{C} h(t)

    Maps 1D continuous driving function $x(t)$ through continuous evolution matrix $\mathbf{A} \in \mathbb{R}^{N \times N}$ and input matrix $\mathbf{B}$.

  2. Zero-Order Hold (ZOH) Discretisation

    \bar{\mathbf{A}} = \exp(\Delta \mathbf{A}), \quad \bar{\mathbf{B}} = (\Delta \mathbf{A})^{-1} (\exp(\Delta \mathbf{A}) - \mathbf{I}) \cdot \Delta \mathbf{B} \approx \Delta \mathbf{B}

    Transforms continuous parameters into discrete recurrence matrices using step size parameter $\Delta$.

  3. Selective Input-Dependent Parameterisation (Mamba)

    \mathbf{B}_t = \mathbf{W}_B x_t, \quad \mathbf{C}_t = \mathbf{W}_C x_t, \quad \Delta_t = \operatorname{softplus}(\mathbf{W}_\Delta x_t + \mathbf{b}_\Delta)

    Parameters $\mathbf{B}, \mathbf{C}, \Delta$ vary dynamically with input $x_t$, allowing the network to filter out noise and selectively store key information.

04 Key takeaways

  • Mamba achieves linear $O(L)$ training time and constant $O(1)$ inference memory per step.
  • Overcomes quadratic $O(L^2)$ attention bottlenecks for long sequence processing.
  • Selective state spaces make transition parameters input-dependent, unlocking selective memory and forgetting.
  • Hardware-aware parallel associative scans compute sequential recurrences efficiently in GPU SRAM.

05 In code

python
import torch
import torch.nn as nn
import torch.nn.functional as F

class MinimalSSM(nn.Module):
    """Educational demonstration of 1D Selective State-Space recurrence."""
    def __init__(self, d_model: int, d_state: int = 16):
        super().__init__()
        self.d_model = d_model
        self.d_state = d_state
        
        # Continuous diagonal A parameter
        self.A_log = nn.Parameter(torch.log(torch.arange(1, d_state + 1, dtype=torch.float32)))
        
        # Linear projections for selective B, C, Delta
        self.x_proj = nn.Linear(d_model, d_state * 2 + 1, bias=False)
        self.out_proj = nn.Linear(d_model, d_model)

    def forward(self, x: torch.Tensor):
        # x shape: [batch, seq_len, d_model]
        batch, seq_len, _ = x.shape
        A = -torch.exp(self.A_log)  # [d_state] (enforce stability: negative real values)
        
        y_out = []
        # Sequential inference recurrence: O(1) memory per step!
        for b in range(batch):
            h = torch.zeros(self.d_model, self.d_state, device=x.device)
            y_seq = []
            for t in range(seq_len):
                x_t = x[b, t]  # [d_model]
                proj = self.x_proj(x_t)
                B_t = proj[:self.d_state]
                C_t = proj[self.d_state:2*self.d_state]
                delta_t = F.softplus(proj[-1:])
                
                # Discretise: A_bar = exp(delta * A), B_bar = delta * B
                A_bar = torch.exp(delta_t * A)  # [d_state]
                B_bar = delta_t * B_t          # [d_state]
                
                # Update latent state
                h = h * A_bar + x_t.unsqueeze(-1) * B_bar
                # Emit output: y = h * C
                y_t = torch.sum(h * C_t, dim=-1)  # [d_model]
                y_seq.append(y_t)
            y_out.append(torch.stack(y_seq))
            
        return self.out_proj(torch.stack(y_out))

ssm = MinimalSSM(d_model=32, d_state=8)
tokens = torch.randn(2, 10, 32)
out = ssm(tokens)
print("SSM Processed sequence shape:", out.shape)
print("Inference scales O(1) in memory: Zero KV-cache footprint!")

Common pitfalls

  • Loss of global associative recall: While Mamba excels at compression and reasoning, standard SSMs struggle with literal verbatim document retrieval compared to full KV-cache attention.
  • Sequential Python implementation slowness: Writing sequential loops in PyTorch is extremely slow; Mamba requires custom CUDA kernels with SRAM associative scans for training throughput.
  • Initialization sensitivity: Initializing matrix $\mathbf{A}$ randomly causes gradient explosion; $\mathbf{A}$ must be initialized with HiPPO (High-order Polynomial Projection) theory.

06 Check yourself

Q1What is the primary computational bottleneck of the Transformer self-attention mechanism that State-Space Models (SSMs) solve?

Why: Pairwise dot-product attention computes an $L \times L$ attention matrix, scaling quadratically $O(L^2)$. SSMs process sequences with linear $O(L)$ complexity.

Q2What crucial breakthrough did Mamba introduce over classical LTI (Linear Time-Invariant) State-Space Models like S4?

Why: Classical S4 used fixed time-invariant matrices, preventing content-dependent memory. Mamba makes matrices input-dependent, enabling selective filtering and forgetting.

Q3How does Mamba's inference memory consumption compare to a Transformer with KV-cache during autoregressive generation?

Why: Transformers store keys and values for every past token in a growing KV-cache. Mamba maintains a fixed-size latent state vector, updating it in $O(1)$ constant time.
