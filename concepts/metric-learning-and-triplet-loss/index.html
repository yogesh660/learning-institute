Deep Metric Learning: Triplet Loss, Siamese Networks, and Online Semi-Hard Mining

Learning semantic embedding spaces where Euclidean distance mirrors similarity using Siamese networks, contrastive loss, and semi-hard triplet mining.

01 The idea

Standard classification models assign inputs to a fixed set of $C$ classes: adding a new class (e.g. enrolling a new employee into a face recognition security system) requires retraining the entire network. Deep Metric Learning directly learns a distance metric: mapping complex inputs (faces, product images, audio snippets) into a continuous embedding space where similar instances are close together and dissimilar instances are far apart.

In deep metric learning, a neural network $f_\theta(x)$ maps an input $x$ to a unit-norm embedding vector on a hypersphere $\|f(x)\|_2 = 1$. The semantic distance between two items is measured directly by Euclidean distance $d(u, v) = \|f(u) - f(v)\|_2$.

Siamese networks process pairs of items $(x_1, x_2)$ through identical shared-weight neural backbones, evaluated using Contrastive Loss which pulls positive pairs together and pushes negative pairs apart beyond a margin $m$.

Triplet Loss (FaceNet; Schroff et al.) evaluates triplets: an Anchor ($a$), a Positive from the same class ($p$), and a Negative from a different class ($n$). The objective enforces: $d(a, p)^2 + \alpha \le d(a, n)^2$, ensuring the negative is at least margin $\alpha$ further from the anchor than the positive.

The critical bottleneck in triplet training is mining informative triplets. Most random triplets are "Easy Negatives" ($d(a, n) \gg d(a, p) + \alpha$), which produce zero loss and zero gradients. Training on "Hard Negatives" ($d(a, n) < d(a, p)$) often causes gradient collapse. The optimal regime is Semi-Hard Negative Mining: selecting negatives that are farther than the positive but still within the margin boundary.

In everyday terms

Imagine a passport border control officer. The officer does not have an internal database memorizing the names of all 8 billion people on Earth (a giant softmax classifier). Instead, the officer looks at your passport photograph and looks at your physical face in person, comparing visual geometric distances to determine if you are the same person or an imposter.

02 Step by step

  1. Structure balanced minibatches: Sample $P$ classes with $K$ instances per class (e.g. $P=16, K=4$; batch size 64) to ensure abundant positive and negative pairs within every batch.
  2. Forward pass and L2 normalisation: Pass all batch images through shared backbone and project onto the unit hypersphere ($L_2$ normalisation).
  3. Compute pairwise distance matrix: Vectorise all-to-all Euclidean distances between batch embeddings in a single GPU matrix operation.
  4. Execute online semi-hard triplet mining: For each anchor-positive pair, identify all negatives satisfying $d(a, p) < d(a, n) < d(a, p) + \alpha$.
  5. Compute margin triplet loss: Evaluate hinge loss on mined semi-hard triplets and backpropagate gradients.
  6. Inference via nearest neighbour: Index enrolled embeddings in a fast vector search database (FAISS) and classify queries via cosine distance.

03 The maths

  1. Triplet Margin Ranking Objective

    \mathcal{L}_{\mathrm{triplet}}(a, p, n) = \max\left( 0, \; \|f(a) - f(p)\|_2^2 - \|f(a) - f(n)\|_2^2 + \alpha \right)

    Enforces that anchor-negative squared distance exceeds anchor-positive squared distance by at least margin $\alpha$.

  2. Semi-Hard Negative Condition

    \|f(a) - f(p)\|_2^2 < \|f(a) - f(n)\|_2^2 < \|f(a) - f(p)\|_2^2 + \alpha

    Semi-hard negatives yield positive loss and non-zero gradients without being so extremely hard that they destabilise early training.

  3. Hypersphere Embedding Unit Norm Constraint

    \hat{z} = \frac{f_\theta(x)}{\|f_\theta(x)\|_2} \implies \|\hat{z}\|_2 = 1, \quad \|u - v\|_2^2 = 2 - 2\cos(u, v)

    Normalising embeddings to unit length makes squared Euclidean distance strictly equivalent to cosine distance.

04 Key takeaways

  • Metric learning learns continuous embedding spaces where geometric distance reflects semantic similarity.
  • Enables open-set recognition (face verification, visual product search) without retraining on new classes.
  • Triplet loss enforces that positive pairs are closer than negative pairs by at least margin $\alpha$.
  • Online semi-hard mining selects informative negative samples that produce non-zero gradients without collapsing.

05 In code

python
import torch
import torch.nn as nn
import torch.nn.functional as F

class TripletMarginLossModule(nn.Module):
    def __init__(self, margin: float = 0.5):
        super().__init__()
        self.margin = margin

    def forward(self, anchor: torch.Tensor, positive: torch.Tensor, negative: torch.Tensor) -> torch.Tensor:
        # 1. Project onto unit hypersphere
        a = F.normalise(anchor, p=2, dim=-1)
        p = F.normalise(positive, p=2, dim=-1)
        n = F.normalise(negative, p=2, dim=-1)
        
        # 2. Compute squared Euclidean distances
        d_ap = torch.sum((a - p) ** 2, dim=-1)
        d_an = torch.sum((a - n) ** 2, dim=-1)
        
        # 3. Triplet loss with margin
        losses = F.relu(d_ap - d_an + self.margin)
        return losses.mean()

# Test triplet loss evaluation
loss_fn = TripletMarginLossModule(margin=0.4)

# Anchor, matching Positive, and non-matching Negative
torch.manual_seed(42)
anchor = torch.randn(4, 128)
positive = anchor + torch.randn(4, 128) * 0.1   # Close to anchor
negative = torch.randn(4, 128)                  # Unrelated random vector

loss = loss_fn(anchor, positive, negative)
print(f"Calculated Triplet Loss: {loss.item():.4f}")
print("Loss drives d(a, p) closer while pushing d(a, n) beyond margin 0.4")

Common pitfalls

  • Omitting L2 embedding normalisation: Without projection onto the unit hypersphere, networks cheat the margin by simply blowing up embedding magnitudes to infinity.
  • Training without mining: Random negative sampling results in 99% easy negatives with zero loss, causing training loss to flatline near zero while representations remain poor.
  • Offline batch generation: Pre-computing fixed triplets on disk creates stale pairs that quickly become easy after a few training epochs; mine triplets online within each batch.

06 Check yourself

Q1Why is Deep Metric Learning preferred over standard $C$-class Softmax classification for facial recognition systems?

Why: In a facial security system, new faces must be enrolled daily. Softmax classifiers have a fixed class count, whereas metric embeddings compare any arbitrary face via distance.

Q2What characterizes a "Semi-Hard Negative" in triplet loss mining?

Why: Semi-hard negatives violate the margin condition, generating positive loss and stable learning gradients without causing optimisation collapse.

Q3Why are output embeddings in metric learning almost always normalised to unit length ($L_2$ norm = 1)?

Why: Without unit normalisation, an unconstrained network can satisfy $d(a, n) - d(a, p) > \alpha$ by multiplying all output vectors by 1,000 without learning meaningful representations.
