Residual Diagnostics and Heteroscedasticity

Diagnose regression failure modes with residual plots, detect non-constant variance using the Breusch–Pagan test, and correct inference with robust standard errors.

01 The idea

The Gauss–Markov theorem guarantees that ordinary least squares estimators are the Best Linear Unbiased Estimator (BLUE) only when errors are homoscedastic and uncorrelated. When residual variance expands or contracts across predictor ranges (heteroscedasticity), OLS coefficient estimates remain unbiased, but standard errors become severely distorted, invalidating confidence intervals and hypothesis tests. Systematic residual diagnostics and White's heteroscedasticity-consistent standard errors restore valid statistical inference.

Imagine predicting annual household expenditure on restaurant dining based on household income. For families earning £25,000 per year, dining spending is tightly constrained between £500 and £1,500 (small error variance). For affluent families earning £250,000 per year, dining spending varies wildly: some families cook gourmet meals at home and spend £2,000, while others dine out constantly and spend £30,000 (huge error variance).

If you plot residuals ($y - \hat{y}$) against fitted values $\hat{y}$, the points do not form a uniform horizontal band. Instead, they fan outward like an opening megaphone—classic heteroscedasticity.

What is the danger? Standard OLS assumes every single data point has identical error variance $\sigma^2$. It treats high-income households (where noise is £15,000) with the exact same credibility as low-income households (where noise is £300). While the estimated slope is still unbiased on average, the standard OLS formula underestimates the true standard error, producing artificially narrow confidence intervals and falsely low p-values. A formal test like the Breusch–Pagan test regresses squared residuals against predictors: if variance scales with income, it yields a significant chi-square statistic ($p < 0.001$). Switching to Huber–White heteroscedasticity-robust standard errors (HC1) corrects the standard error without needing to throw away the linear model.

In everyday terms

Fitting standard OLS under heteroscedasticity is like judging an archer's skill on windy days and calm days equally: it mistakes erratic, windblown shots for reliable evidence unless you account for changing conditions.

02 Step by step

  1. Fit the OLS regression model and compute raw residuals $e_i = y_i - \hat{y}_i$.
  2. Plot residuals against fitted values $\hat{y}_i$ to visually check for non-linearity (curved patterns) and heteroscedasticity (fan shapes).
  3. Plot standardised residuals against theoretical normal quantiles (Q-Q plot) to check for heavy-tailed or skewed errors.
  4. Perform the Breusch–Pagan test: regress squared residuals $e_i^2$ on predictors and compute the LM test statistic $n R^2 \sim \chi^2(p)$.
  5. If heteroscedasticity is detected, compute Huber–White heteroscedasticity-consistent (HC) sandwich covariance matrices (e.g. HC1).
  6. Alternatively, apply variance-stabilising transforms (such as $\log y$) or Weighted Least Squares (WLS) if variance weights are known.

03 The maths

  1. The Homoscedasticity Assumption vs Heteroscedasticity

    $$\text{Homoscedasticity: } \text{Var}(\epsilon_i \mid \mathbf{x}_i) = \sigma^2, \qquad \text{Heteroscedasticity: } \text{Var}(\epsilon_i \mid \mathbf{x}_i) = \sigma_i^2$$

    Under homoscedasticity, the covariance matrix of disturbances is $\boldsymbol{\Sigma} = \sigma^2 \mathbf{I}$, producing the classic textbook variance formula $\text{Var}(\hat{\boldsymbol{\beta}}) = \sigma^2 (\mathbf{X}^T\mathbf{X})^{-1}$. Under heteroscedasticity, the diagonal elements $\sigma_i^2$ vary, turning the true variance into the sandwich form $(\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\boldsymbol{\Sigma}\mathbf{X}(\mathbf{X}^T\mathbf{X})^{-1}$.

  2. The Breusch–Pagan Lagrange Multiplier Test

    $$e_i^2 = \gamma_0 + \gamma_1 x_{i1} + \dots + \gamma_p x_{ip} + u_i \implies \text{LM} = n R_{e^2}^2 \sim \chi^2(p)$$

    The Breusch–Pagan test fits an auxiliary regression of squared residuals $e_i^2$ on the original predictors. Under the null hypothesis of homoscedasticity ($H_0: \gamma_1 = \dots = \gamma_p = 0$), the sample size $n$ multiplied by the auxiliary determination coefficient $R_{e^2}^2$ converges asymptotically to a chi-square distribution with $p$ degrees of freedom.

  3. Huber–White Heteroscedasticity-Consistent (HC1) Standard Errors

    $$\widehat{\text{Var}}_{\text{HC1}}(\hat{\boldsymbol{\beta}}) = \frac{n}{n - p - 1} (\mathbf{X}^T\mathbf{X})^{-1} \left(\sum_{i=1}^n e_i^2 \mathbf{x}_i \mathbf{x}_i^T\right) (\mathbf{X}^T\mathbf{X})^{-1}$$

    The White sandwich estimator places squared sample residuals along the diagonal of the central "meat" matrix. Multiplying by degrees-of-freedom correction $\frac{n}{n - p - 1}$ yields HC1. This estimator converges asymptotically to the true covariance matrix without requiring knowledge of the functional form of heteroscedasticity.

04 Key takeaways

  • Heteroscedasticity does not bias OLS slope estimates; it invalidates standard error formulas, making confidence intervals and p-values untrustworthy.
  • Residual-versus-fitted scatter plots serve as the primary diagnostic: homoscedastic errors display an even horizontal cloud with constant vertical spread.
  • The Breusch–Pagan test provides an objective hypothesis test for linear variance dependence on predictors.
  • Huber–White robust standard errors (HC1) fix inferential hypothesis testing without altering point estimates or discarding data.

05 In code

python
import numpy as np
import scipy.stats as stats

rng = np.random.default_rng(42)
n = 150

# Heteroscedastic data: error variance scales proportionally with x
x = rng.uniform(1.0, 10.0, size=n)
y = 2.0 + 3.0 * x + rng.normal(0.0, 0.8 * x, size=n)
X = np.column_stack([np.ones(n), x])

# OLS point estimates
beta = np.linalg.inv(X.T @ X) @ X.T @ y
e = y - X @ beta

# 1. Breusch-Pagan test for heteroscedasticity
e2 = e**2
beta_aux = np.linalg.inv(X.T @ X) @ X.T @ e2
r2_aux = 1.0 - np.sum((e2 - X @ beta_aux)**2) / np.sum((e2 - np.mean(e2))**2)
lm_stat = n * r2_aux
p_bp = 1.0 - stats.chi2.cdf(lm_stat, df=1)

# 2. Standard OLS SE vs Huber-White HC1 robust SE
cov_ols = (np.sum(e**2) / (n - 2)) * np.linalg.inv(X.T @ X)
cov_hc1 = (n / (n - 2)) * np.linalg.inv(X.T @ X) @ (X.T @ np.diag(e2) @ X) @ np.linalg.inv(X.T @ X)

se_ols = np.sqrt(np.diag(cov_ols))[1]
se_hc1 = np.sqrt(np.diag(cov_hc1))[1]

print(f"Breusch-Pagan LM: {lm_stat:.2f} (p-value: {p_bp:.4e})")
print(f"Slope beta_1:     {beta[1]:.3f}")
print(f"Standard OLS SE:  {se_ols:.3f}")
print(f"Robust HC1 SE:    {se_hc1:.3f}")

Common pitfalls

  • Believing that heteroscedasticity makes regression coefficients biased; coefficients remain completely unbiased and consistent.
  • Throwing away linear regression models upon detecting heteroscedasticity instead of reporting heteroscedasticity-robust standard errors.
  • Running standard Breusch–Pagan tests on non-normal errors without Koenker's studentisation, which inflates false positive rates.
  • Confusing non-linearity with heteroscedasticity: an omitted quadratic term often produces both a curved residual pattern and apparent variance changes.

06 Check yourself

Q1What is the primary statistical consequence of ignoring heteroscedasticity in an OLS regression model?

Why: OLS coefficient estimates remain unbiased under heteroscedasticity, but the textbook formula for $\text{Var}(\hat{\boldsymbol{\beta}})$ is wrong, distorting standard errors and hypothesis tests.

Q2How does a classic residual-versus-fitted values plot look when heteroscedasticity is present?

Why: A widening cone (megaphone shape) indicates that error variance is not constant, but scales with the magnitude of predictions.

Q3What does the Breusch–Pagan test evaluate?

Why: The Breusch–Pagan test regresses squared residuals on the explanatory variables; a significant $R^2$ demonstrates that error variance depends on predictor values.

Q4How do Huber–White robust standard errors (HC1) resolve the problem of heteroscedasticity?

Why: Huber–White sandwich estimators substitute squared sample residuals into the covariance calculation, restoring consistent standard errors without altering regression coefficients.
