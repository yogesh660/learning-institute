01 The idea

Deep neural networks are frequently dismissed as opaque "black boxes": a convolutional network classifies an X-ray as pneumonia, or a Transformer classifies a legal contract as high risk, without revealing which input features drove the decision. Post-hoc interpretability methods bridge this opacity by attributing predictions back to input pixels/tokens (Saliency, Grad-CAM, Integrated Gradients) and dissecting internal layers via probing classifiers.

Gradient-based saliency computes the gradient of target class score $y^c$ with respect to input pixels: $\frac{\partial y^c}{\partial x}$. However, vanilla saliency maps are extremely noisy and suffer from gradient saturation (a feature already fully active has near-zero gradient).

Integrated Gradients (Sundararajan et al.) solves gradient saturation by satisfying the Axiom of Completeness: it integrates gradients along a straight line path from a neutral blank baseline $x'$ (e.g. black image) to input $x$. The sum of all feature attributions equals the exact difference in model output: $\sum_i \text{IG}_i(x) = f(x) - f(x')$.

Grad-CAM (Gradient-weighted Class Activation Mapping; Selvaraju et al.) operates on convolutional feature maps. It averages gradients flowing into convolutional activation channels to weight each feature map, generating coarse, class-discriminative visual heatmaps highlighting which spatial regions triggered the decision.

Probing Classifiers (Linear Probes) analyse representation learning in deep layers (e.g. inside Transformers): freezing the pretrained representations and training a lightweight linear classifier to test whether concepts like grammatical syntax, part of speech, or sentiment are linearly separable at layer $L$.

In everyday terms

Imagine a detective interrogating a witness who claims to identify a suspect in a photo lineup. If the detective simply accepts the witness's verdict without question, the witness might secretly be identifying the suspect based on their background wall colour. Interpretability methods act like heat-vision eye trackers (Grad-CAM) that show where the witness looked, and targeted cognitive tests (probing) that verify what details the witness actually observed.

02 Step by step

  1. Select attribution scope: Choose spatial heatmaps for vision (Grad-CAM), feature attributions for tabular/NLP (Integrated Gradients), or internal concept auditing (Linear Probes).
  2. Define baseline reference (Integrated Gradients): Select a neutral counterfactual baseline $x'$ (e.g. an all-black image or all-zero embedding vector).
  3. Compute path integral (Integrated Gradients): Interpolate $M$ steps along the straight line from $x'$ to $x$; compute input gradients at each step and approximate the integral via Riemann sum.
  4. Compute channel weights (Grad-CAM): Backpropagate target class logit $y^c$ to the final convolutional layer; compute global average pooling across spatial dimensions to yield channel importance $\alpha_k^c$.
  5. Generate Grad-CAM heatmap: Take the linear combination of convolutional activation maps weighted by $\alpha_k^c$, and apply ReLU to isolate features with positive influence.
  6. Train linear probe (Representation Probing): Freeze the backbone model, extract activations at layer $L$ across a probing dataset, and train a logistic regression probe to evaluate concept encoding.

03 The maths

  1. Integrated Gradients Formulation

    \mathrm{IG}_i(x) = (x_i - x'_i) \times \int_0^1 \frac{\partial F(x' + \alpha (x - x'))}{\partial x_i} \, d\alpha

    Integrates gradients along the interpolation path from baseline $x'$ to input $x$, satisfying the Axiom of Completeness.

  2. Axiom of Completeness (Attribution Additivity)

    \sum_{i=1}^D \mathrm{IG}_i(x) = F(x) - F(x')

    The sum of all feature attributions exactly equals the difference between the model output on input $x$ and baseline $x'$.

  3. Grad-CAM Class Activation Mapping

    L_{\mathrm{Grad\text{-}CAM}}^c = \operatorname{ReLU}\left( \sum_k \alpha_k^c A^k \right), \quad \alpha_k^c = \frac{1}{Z} \sum_{i} \sum_{j} \frac{\partial y^c}{\partial A_{ij}^k}

    Weights convolutional feature map $A^k$ by global-average-pooled gradient $\alpha_k^c$, applying ReLU to retain features that positively support class $c$.

04 Key takeaways

  • Interpretability methods open deep network black boxes, providing post-hoc explanations for predictions.
  • Integrated Gradients solves gradient saturation, ensuring attributions sum to the total prediction difference.
  • Grad-CAM weights convolutional feature maps by backpropagated gradients to generate class-specific visual heatmaps.
  • Linear probing evaluates whether internal layer representations linearly encode semantic concepts.

05 In code

python
import torch
import torch.nn as nn
import torch.nn.functional as F

class MiniConvNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv = nn.Conv2d(1, 4, kernel_size=3, padding=1)
        self.fc = nn.Linear(4 * 4 * 4, 2)

    def forward(self, x):
        h = F.relu(self.conv(x))
        out = self.fc(h.view(h.size(0), -1))
        return out, h  # Return logits and final conv activations

def compute_grad_cam(model: nn.Module, x: torch.Tensor, target_class: int):
    """Educational demonstration of Grad-CAM spatial heatmap computation."""
    model.eval()
    logits, activations = model(x)
    score = logits[0, target_class]
    
    # Compute gradients of target class with respect to conv activations
    grads = torch.autograd.grad(score, activations)[0]
    
    # Global average pooling of gradients over spatial dimensions (H, W)
    weights = torch.mean(grads, dim=(2, 3), keepdim=True)  # [1, channels, 1, 1]
    
    # Weighted combination of activation maps
    cam = torch.sum(weights * activations, dim=1, keepdim=True)
    cam = F.relu(cam)  # Isolate positive contributions
    cam = cam - cam.min()
    cam = cam / (cam.max() + 1e-8)  # Normalise between 0 and 1
    return cam.squeeze().detach().numpy()

# Test Grad-CAM on synthetic 4x4 input image
torch.manual_seed(42)
model = MiniConvNet()
input_image = torch.randn(1, 1, 4, 4, requires_grad=True)

Common pitfalls

  • Edge detection artifacts in vanilla saliency: Simple input gradients $\frac{\partial y}{\partial x}$ often act like high-pass edge detectors, highlighting image boundaries rather than semantic features.
  • Poor baseline choice in Integrated Gradients: Choosing an inappropriate baseline (e.g. pure white image when text is white) distorts attribution values; use multiple neutral baselines.
  • Confusing explanation with correctness: A model can produce a beautifully intuitive Grad-CAM explanation while being fundamentally flawed or reliant on confounding correlations.

06 Check yourself

Q1What is the "gradient saturation" problem in vanilla gradient saliency maps, and how does Integrated Gradients solve it?

Why: In saturated non-linearities, local gradients vanish even though the feature is critical. Integrated Gradients accumulates gradients along a path from a blank baseline to the input.

Q2Why does Grad-CAM apply the ReLU activation function to the weighted combination of feature maps?

Why: Grad-CAM applies ReLU because pixels that negatively correlate with the class belong to other categories; ReLU keeps only positive evidence.

Q3What is a "Probing Classifier" (Linear Probe) used for in deep learning analysis?

Why: A linear probe freezes internal layers and trains a simple linear model to see if intermediate activations linearly separate specific attributes (e.g. part of speech, sentiment).
