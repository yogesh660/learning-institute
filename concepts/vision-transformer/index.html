Vision Transformer

The Vision Transformer (ViT, Alexey Dosovitskiy et al., 2020) demonstrated that standard Transformer encoder architectures—designed originally for natural language processing—can be applied directly to computer vision with minimal architectural modifications. By partitioning an image of resolution $H \times W$ into a regular grid of non-overlapping $P \times P$ spatial patches, flattening each patch into a vector, prepending a learnable [CLS] classification token, adding 1D learnable position embeddings, and feeding the token sequence into standard Multi-Head Self-Attention (MHSA) blocks, ViT attains a global receptive field at layer 1. ViT discards convolutional inductive biases (translation equivariance and local connectivity) in exchange for massive representational capacity when pre-trained on large-scale datasets.

01 The idea

For nearly a decade after AlexNet, convolutional neural networks were considered the irreplaceable, biologically inspired foundation of all computer vision. Convolutions enforce two rigid inductive biases: local connectivity (pixels close together interact first) and translation equivariance (the identical filter slides across every spatial location). But in 2020, Google Research asked a radical question: what if we discard convolutions entirely and treat an image simply as a sequence of words? The resulting model—the Vision Transformer (ViT)—not only matched state-of-the-art convolutional networks on ImageNet, but ignited a paradigm shift unifying language, audio, and visual computing under a single self-attention architecture.

Images as sequences of visual words: Transformers are permutation-equivariant sequence models that compute pairwise self-attention between all tokens in an input sequence. Applying self-attention directly to individual raw pixels in a standard $224 \times 224$ image would require computing attention across $N = 224^2 = 50,176$ tokens, creating an intractable $O(N^2)$ memory bottleneck of over 2.5 billion pairwise dot products per layer. ViT bypasses this by grouping pixels into $16 \times 16$ non-overlapping patches. A $224 \times 224$ image decomposes into exactly $(224 / 16) \times (224 / 16) = 14 \times 14 = 196$ patches. Each patch is flattened into a vector of $16 \times 16 \times 3 = 768$ values and linearly projected into an embedding space, creating a sequence of 196 visual tokens perfectly matched to standard Transformer architectures.

Inductive bias versus data scale: Convolutional networks are hard-coded with inductive biases: they inherently assume that spatial locality matters and that visual features behave identically regardless of where they appear. This makes CNNs sample-efficient on modest datasets (such as ImageNet-1k). The Vision Transformer possesses almost no visual inductive bias: self-attention allows any patch to attend to any other patch across the entire canvas from layer 1, and the model must learn 2D spatial relationships entirely from scratch via position embeddings. Consequently, when trained on small datasets, ViT underperforms ResNet. But when pre-trained on massive datasets (ImageNet-21k or JFT-300M), ViT's unconstrained capacity breaks past the performance saturation ceiling of CNNs, achieving superior representation quality.

The [CLS] token and global receptive fields: How does a sequence-to-sequence Transformer output a single image classification label? Borrowing from BERT, ViT prepends a learnable [CLS] (classification) embedding vector to the patch token sequence. Because Multi-Head Self-Attention allows every token to exchange information with all other tokens across all layers, the [CLS] token aggregates global contextual information from the entire image. The final state of the [CLS] token is passed to a simple MLP classification head to output class probabilities.

Positional embeddings and learned 2D topology: Because standard self-attention is permutation-invariant (scrambling the token order produces an identical output set), ViT must inject spatial coordinate information. ViT adds learnable 1D position embeddings $\mathbf{E}_{\text{pos}} \in \mathbb{R}^{(N+1) \times D}$ to the patch tokens before the first encoder block. Remarkably, after pre-training, visualising the cosine similarity of these learned 1D positional vectors reveals that the model autonomously discovers the 2D Euclidean topology of images: patches situated physically near each other in 2D space exhibit highly correlated position embeddings.

In everyday terms

Think of reading an illustrated comic book page. A convolutional neural network reads like an insect crawling across the page through a tiny straw: it can only see a $3 \times 3$ millimetre circle at any moment, slowly aggregating lines into textures, then textures into shapes, and only understanding the full narrative in the final layer. The Vision Transformer is like a human reader who cuts the page into 196 square puzzle tiles and lays them all across a table simultaneously. From the very first glance, the human reader can look directly from a puzzle tile in the top-left corner (a character's eye) to a puzzle tile in the bottom-right corner (a dialogue speech bubble) and connect their meaning instantly. The reader needs to learn how to assemble puzzle pieces from scratch (requiring more practice on thousands of books), but once mastered, they comprehend global narrative composition far more flexibly than an insect crawling through a straw.

03 The maths

  1. Patch sequence projection and embedding construction

    \mathbf{z}_0 = \left[\mathbf{x}_{\text{class}}; \, \mathbf{x}_p^1 \mathbf{E}; \, \mathbf{x}_p^2 \mathbf{E}; \, \dots; \, \mathbf{x}_p^N \mathbf{E}\right] + \mathbf{E}_{\text{pos}}, \quad \mathbf{E} \in \mathbb{R}^{(P^2 C) \times D}, \; \mathbf{E}_{\text{pos}} \in \mathbb{R}^{(N+1) \times D}

    Here $N = HW / P^2$ is the number of image patches, $P$ is patch dimension, $D$ is the Transformer latent embedding width (e.g. $D=768$ in ViT-Base), and $\mathbf{x}_{\text{class}}$ is the learnable classification token.

  2. Multi-Head Self-Attention (MHSA) formulation

    \text{Attention}(Q, K, V) = \operatorname{softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V, \quad \text{MHSA}(X) = \left[\text{head}_1, \dots, \text{head}_h\right] W^O

    Queries $Q$, keys $K$, and values $V$ are linear projections of the input token sequence $\mathbf{z}$. Dividing by $\sqrt{d_k}$ prevents dot products from growing excessively large, preserving stable gradients through the softmax operator.

  3. Encoder block forward recursion

    \mathbf{z}'_l = \text{MHSA}\left(\text{LN}(\mathbf{z}_{l-1})\right) + \mathbf{z}_{l-1}, \quad \mathbf{z}_l = \text{MLP}\left(\text{LN}(\mathbf{z}'_l)\right) + \mathbf{z}'_l, \quad \mathbf{y} = \text{LN}\left(\mathbf{z}_L^0\right)

    ViT employs pre-layer normalisation (applying LayerNorm before MHSA and MLP blocks), which stabilises forward activation propagation and gradient backpropagation in deep architectures. The output prediction $\mathbf{y}$ is extracted from the [CLS] token position $\mathbf{z}_L^0$.

04 Key takeaways

  • The Vision Transformer treats images as sequences of non-overlapping $16 \times 16$ pixel patches processed by a standard Transformer encoder.
  • ViT possesses a global receptive field at layer 1, enabling every image patch to attend to any other patch from the start of computation.
  • ViT lacks convolutional inductive biases (locality and translation equivariance), requiring massive pre-training datasets (ImageNet-21k, JFT-300M) to outperform CNNs.
  • A learnable [CLS] token prepended to the patch sequence aggregates global context for downstream classification.
  • Learnable 1D position embeddings autonomously learn the 2D Euclidean spatial topology of images during pre-training.

05 In code

python
import numpy as np

# Pure NumPy implementation of Vision Transformer (ViT) patch extraction and self-attention
np.random.seed(42)

# Input image dimensions: 1 image, 3 channels, 32x32 pixels
H, W, C = 32, 32, 3
P = 8  # 8x8 patch size
img = np.random.randn(H, W, C).astype(np.float32)

# 1. Patch Extraction and Flattening
# Number of patches: N = (32/8) * (32/8) = 4 * 4 = 16 patches
num_patches_h = H // P
num_patches_w = W // P
N = num_patches_h * num_patches_w
patch_dim = P * P * C  # 8 * 8 * 3 = 192

patches = np.zeros((N, patch_dim), dtype=np.float32)
idx = 0
for r in range(num_patches_h):
    for c in range(num_patches_w):
        patch = img[r*P:(r+1)*P, c*P:(c+1)*P, :]
        patches[idx] = patch.flatten()
        idx += 1

print(f"Input image shape:             {img.shape}")
print(f"Extracted patch tokens shape:  {patches.shape} ({N} patches of length {patch_dim})")

# 2. Linear Projection to Latent Dimension D = 64
D = 64
W_proj = np.random.randn(patch_dim, D).astype(np.float32) * (1.0 / np.sqrt(patch_dim))
tokens = patches @ W_proj  # shape (16, 64)

# 3. Prepend Learnable [CLS] Token
cls_token = np.random.randn(1, D).astype(np.float32) * 0.02
tokens_with_cls = np.vstack([cls_token, tokens])  # shape (17, 64)

# 4. Add Learnable 1D Position Embeddings
pos_embed = np.random.randn(N + 1, D).astype(np.float32) * 0.02
z0 = tokens_with_cls + pos_embed  # shape (17, 64)
print(f"Sequence with [CLS] & PosEmb:  {z0.shape} (17 tokens in D={D})")

# 5. Single Multi-Head Self-Attention (MHSA) layer (2 heads, head_dim = 32)
num_heads = 2
d_k = D // num_heads

# Weight projections for Q, K, V
W_q = np.random.randn(D, D).astype(np.float32) * (1.0 / np.sqrt(D))
W_k = np.random.randn(D, D).astype(np.float32) * (1.0 / np.sqrt(D))
W_v = np.random.randn(D, D).astype(np.float32) * (1.0 / np.sqrt(D))
W_out = np.random.randn(D, D).astype(np.float32) * (1.0 / np.sqrt(D))

Q = z0 @ W_q
K = z0 @ W_k
V = z0 @ W_v

# Scaled Dot-Product Attention: Softmax(Q @ K.T / sqrt(d_k)) @ V
attn_scores = (Q @ K.T) / np.sqrt(d_k)
exp_scores = np.exp(attn_scores - np.max(attn_scores, axis=-1, keepdims=True))
attn_weights = exp_scores / np.sum(exp_scores, axis=-1, keepdims=True)

context = attn_weights @ V
out_mhsa = context @ W_out  # shape (17, 64)

# 6. Extract [CLS] Token Representation for Classification
cls_out = out_mhsa[0]  # First token
print(f"Attention matrix shape:        {attn_weights.shape} (every patch attends to every patch)")
print(f"[CLS] token output vector:     {cls_out.shape} (ready for MLP classification head)")
print(f"Attention from [CLS] to patch 0: {attn_weights[0, 1]:.4f}")
print(f"Attention from [CLS] to patch 15: {attn_weights[0, 16]:.4f}")
print("Verified: Vision Transformer tokenisation and self-attention executed cleanly!")

Common pitfalls

  • Training ViT from scratch on small datasets: Without large-scale pre-training, ViT severely overfits and underperforms ResNet on modest datasets (such as CIFAR-10 or ImageNet-1k) due to the absence of spatial inductive biases.
  • Interpolating position embeddings without scale adjustment: When transferring a pre-trained ViT to a higher image resolution (e.g. $224 \to 384$), the number of patches increases ($196 \to 576$); position embeddings must be bicubically interpolated in 2D to preserve learned spatial coordinates.
  • Quadratic computational scaling with high resolution: Because self-attention scales as $O(N^2)$, reducing patch size from $16 \times 16$ to $8 \times 8$ quadruples the token count $N$, increasing memory consumption and compute sixteen-fold ($O(16\times)$).
  • Omitting the [CLS] token or global pooling: Relying on an unpooled arbitrary token for classification ignores global image context; always use the dedicated [CLS] token or Global Average Pooling across all output tokens.
  • Using standard Post-LayerNorm: Implementing post-layer normalisation rather than Pre-LayerNorm frequently causes gradient instability and divergent training runs in deep Vision Transformers.

06 Check yourself

Q1Why does the Vision Transformer (ViT) divide an image into $16 \times 16$ pixel patches rather than applying self-attention directly to individual raw pixels?

Why: Pairwise self-attention across 50,176 individual pixels requires computing a $50,176 \times 50,176$ attention matrix ($2.5$ billion operations per layer). Grouping pixels into $16 \times 16$ patches yields 196 tokens, rendering self-attention computationally efficient.

Q2Why does ViT typically perform worse than ResNet when trained from scratch on small datasets (like ImageNet-1k) without large-scale pre-training?

Why: Convolutions inherently enforce that neighbouring pixels interact first and that features behave identically across space. ViT has no built-in knowledge of 2D geometry; it must learn spatial topology entirely from data, making it sample-hungry on small datasets.

Q3What is the function of the learnable [CLS] classification token prepended to the patch token sequence in ViT?

Why: Borrowing from BERT, the [CLS] token has no fixed patch assignment. Through stacked self-attention layers, it gathers semantic information from all patches, serving as a unified holistic summary vector for the final classification head.

Q4When fine-tuning a pre-trained ViT model on higher-resolution images (e.g. increasing resolution from $224 \times 224$ to $384 \times 384$), what operation must be applied to the position embeddings?

Why: Higher image resolution produces more patches ($196 \to 576$). Because position embeddings reflect 2D coordinates, 2D bicubic interpolation smoothly stretches the learned coordinate grid to match the new token count while preserving spatial order.
