Conditional Random Fields (CRF): Sequence Labelling and the Forward-Backward Algorithm

Sequence labelling tasks (NER, POS tagging, chunking) require predicting structured sequences of discrete tags for input token sequences. Linear-chain CRFs model the conditional distribution $P(Y|X)$ globally, scoring both emission potentials (token-tag compatibility) and transition potentials (tag-tag continuity). The forward-backward dynamic programming algorithm efficiently computes sequence normalisation factors (partition function $Z(X)$) and state marginal probabilities. The Viterbi algorithm identifies the single highest-scoring global sequence in $\mathcal{O}(T \cdot K^2)$ time during inference.

01 The idea

Conditional Random Fields (CRFs) are discriminative probabilistic graphical models for structured sequence labelling tasks such as Named Entity Recognition and Part-of-Speech tagging. By modelling joint transition dependencies across tag sequences rather than making independent per-token decisions, CRFs eliminate label bias and enforce globally optimal label assignments.

Consider tagging named entities using an IOB scheme (e.g. B-PER for beginning of a person name, I-PER for inside a person name, and O for outside). A local classifier predicting each word's tag independently might predict "I-PER" immediately following "O", which is grammatically invalid according to IOB syntax (an "I-PER" must follow either a "B-PER" or another "I-PER"). This vulnerability—treating interdependent sequential decisions as independent—is called the label bias problem. A Conditional Random Field solves this by scoring the entire sequence of tags simultaneously. It combines local feature emission scores (how well a word matches a tag) with a learned transition matrix (which tags can follow which). When attached as the final decoding layer of a neural network (e.g. BiLSTM-CRF or BERT-CRF), it guarantees that the decoded sequence is both globally optimal and syntactically valid.

In everyday terms

Imagine booking a multi-leg flight itinerary. An independent decision model would choose the cheapest flight for each individual leg, leaving you with an impossible 15-minute layover in a sprawling airport. A CRF acts like an experienced travel booking engine: it evaluates the total trip cost while strictly enforcing valid connection windows between consecutive flights.

02 Step by step

  1. Extract emission representations: compute per-token feature vectors using classical n-gram features or deep neural encodings (BiLSTM or Transformer).
  2. Initialise transition matrix: define a $K \times K$ trainable parameter matrix $A$, initialising impossible transitions (e.g. `O -> I-PER`) with large negative values.
  3. Execute forward algorithm: compute forward potentials $\alpha_t(j)$ in log-space using `logsumexp` to evaluate partition function $Z(\mathbf{x})$.
  4. Calculate sequence score: compute the scalar sum of gold emission scores and gold transition scores for the true target sequence.
  5. Minimise negative log-likelihood: backpropagate gradients from loss $\mathcal{L} = \log Z(\mathbf{x}) - \text{Score}(\mathbf{x}, \mathbf{y}^*)$ through transitions and feature encoders.
  6. Decode optimal sequence: at test time, use the Viterbi dynamic programming algorithm to retrieve the highest-scoring tag sequence $\hat{\mathbf{y}}$.

04 Key takeaways

  • CRFs model the global conditional probability of entire label sequences, eliminating local label bias in structured prediction.
  • The forward algorithm computes the normalisation partition function $Z(\mathbf{x})$ efficiently in $\mathcal{O}(T \cdot K^2)$ time.
  • Combining neural feature encoders with CRF sequence decoding layers ensures valid entity tagging sequences in NLP pipelines.

05 In code

python
import numpy as np

def log_sum_exp(x, axis=-1):
    """Numerically stable log-sum-exp trick."""
    max_val = np.max(x, axis=axis, keepdims=True)
    return np.squeeze(max_val, axis=axis) + np.log(np.sum(np.exp(x - max_val), axis=axis))

def viterbi_decode(emissions, transitions):
    """Computes globally optimal tag sequence via Viterbi decoding.
    
    emissions: shape (T, K) - token-tag emission potentials
    transitions: shape (K, K) - tag_t to tag_{t+1} transition matrix
    """
    T, K = emissions.shape
    viterbi = np.zeros((T, K))
    backpointers = np.zeros((T, K), dtype=int)
    
    # Initialise t = 0
    viterbi[0] = emissions[0]
    
    # Forward recursion
    for t in range(1, T):
        for j in range(K):
            # Prior scores + transition to j + current emission
            scores = viterbi[t - 1] + transitions[:, j] + emissions[t, j]
            best_prev = np.argmax(scores)
            viterbi[t, j] = scores[best_prev]
            backpointers[t, j] = best_prev
            
    # Backtrack best path
    best_path = [np.argmax(viterbi[-1])]
    for t in range(T - 1, 0, -1):
        prev = backpointers[t, best_path[-1]]
        best_path.append(prev)
        
    best_path.reverse()
    return best_path, np.max(viterbi[-1])

# Simulation: Tagging a 4-token sentence with 3 tags: [0: 'O', 1: 'B-PER', 2: 'I-PER']
# Sentence: "Alan Turing visited London"
tags = ['O', 'B-PER', 'I-PER']
T, K = 4, 3

# Simulated emissions (logits from an encoder)
emissions = np.array([
    [0.1,  3.5,  0.2],   # "Alan"   -> strong B-PER
    [0.2,  1.1,  3.0],   # "Turing" -> strong I-PER
    [2.8,  0.1, -1.0],   # "visited"-> strong O
    [0.5,  2.2,  0.1]    # "London" -> candidate B-LOC / entity
])

# Transition matrix A[i, j] representing tag i -> tag j
transitions = np.array([
    [ 1.5,  1.0, -10.0],  # O -> O (good), O -> B-PER (ok), O -> I-PER (INVALID!)
    [ 0.8, -0.5,   2.5],  # B-PER -> O (ok), B-PER -> B-PER, B-PER -> I-PER (strong)
    [ 1.2,  0.2,   1.8]   # I-PER -> O (ok), I-PER -> B-PER, I-PER -> I-PER (ok)
])

best_sequence, total_score = viterbi_decode(emissions, transitions)
decoded_tags = [tags[i] for i in best_sequence]

print("Viterbi Globally Decoded Sequence:")
tokens = ["Alan", "Turing", "visited", "London"]
for token, tag in zip(tokens, decoded_tags):
    print(f"  {token:8} -> {tag}")
print(f"Global Path Score: {total_score:.2f}")

Common pitfalls

  • Computing the partition function $Z(\mathbf{x})$ directly with standard exponential sums, causing arithmetic overflow; always perform calculations in log-space using `logsumexp`.
  • Forgetting to penalise or mask invalid transitions (e.g. padding tokens or grammatically impossible tag sequences like `O -> I-ORG`), allowing illicit tag transitions.
  • Applying CRFs to tasks where adjacent label transitions are independent, adding quadratic computational overhead $\mathcal{O}(K^2)$ with no performance gain.

06 Check yourself

Q1What is the "label bias problem" that CRFs resolve over per-token local classifiers?

Why: Local classifiers normalise probabilities per token, which biases predictions toward states with fewer outgoing transitions and permits syntactically invalid sequences like `O -> I-PER`.

Q2What is the time complexity of the Viterbi algorithm for decoding a sequence of length $T$ across $K$ tag classes?

Why: At each of the $T$ time steps, the algorithm considers all $K$ current tags and checks transitions from all $K$ previous tags, resulting in $\mathcal{O}(T \cdot K^2)$ complexity.

Q3What role does the partition function $Z(\mathbf{x})$ play in a linear-chain CRF?

Why: $Z(\mathbf{x})$ sums the potentials over all possible label sequences, acting as the global normalisation constant so $P(\mathbf{y}|\mathbf{x})$ sums to 1.
