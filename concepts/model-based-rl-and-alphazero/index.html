01 The idea

Model-free reinforcement learning requires millions of environment interactions because it learns purely through trial and error. Model-Based RL constructs an internal predictive model of environment dynamics—predicting next states and rewards—enabling agents to imagine future trajectories, plan via tree search, and achieve superhuman mastery with zero human data, as demonstrated by AlphaZero and MuZero.

In model-free RL, the agent treats the environment as an opaque black box. In Model-Based RL, the agent explicitly models the transition dynamics $s_{t+1} \sim P(s_{t+1}|s_t, a_t)$ and reward function $r_t = R(s_t, a_t)$. With this model, the agent can generate synthetic experience (Dyna architecture) or simulate future action sequences using planning algorithms.

AlphaZero merged deep learning with Monte Carlo Tree Search: a dual-headed neural network takes a board state and simultaneously outputs move probabilities (policy prior $\mathbf{p}$) and expected game outcome (value $v$). MCTS uses the policy prior to guide tree expansion and the value network to evaluate leaf states without expensive rollouts. MuZero took this further by learning an abstract latent dynamics model directly from sensory observations without knowing the true game rules.

In everyday terms

A model-free driver navigates an unfamiliar city by wandering down random streets and bumping into cul-de-sacs until they accidentally find the destination after months. A model-based driver consults a mental map (a World Model), visualises alternative turns in their imagination, and selects the optimal route before ever taking their foot off the brake.

02 Step by step

  1. Learn transition and reward model: train neural networks to predict next latent state $\mathbf{z}_{t+1}$ and scalar reward $r_t$ given current state $\mathbf{z}_t$ and action $a_t$.
  2. Initialize MCTS root node: project current observation into latent state $\mathbf{z}_0$ using representation network $h_\theta$.
  3. Execute neural-guided MCTS: expand search trees using the learned dynamics model $g_\theta$ and evaluate leaf nodes using prediction network $f_\theta$.
  4. Compute search policy $\pi$: set move probabilities proportional to visit counts: $\pi(a|s_0) \propto N(s_0, a)^{1/\tau}$.
  5. Self-play and store games: play matches against self, recording trajectories $(\mathbf{x}_t, \pi_t, z_t)$ where $z_t$ is the final game outcome.
  6. Train network end-to-end: minimise combined loss over policy cross-entropy, value mean-squared error, and reward prediction error.

03 The maths

  1. AlphaZero Joint Loss Function

    \mathcal{L}(\theta) = (z - v)^2 - \boldsymbol{\pi}^T \ln \mathbf{p} + c \|\theta\|^2

    Jointly optimises value prediction $v$ against game outcome $z$, policy prior $\mathbf{p}$ against MCTS search policy $\boldsymbol{\pi}$, and $L_2$ weight decay.

  2. MuZero Recurrent Latent Formulation

    r_k, \mathbf{z}_k = g_\theta(\mathbf{z}_{k-1}, a_k), \quad \mathbf{p}_k, v_k = f_\theta(\mathbf{z}_k)

    Dynamics model $g_\theta$ unrolls future latent states and rewards in imagination without decoding back to raw pixel space.

04 Key takeaways

  • Model-based RL enables agents to imagine future consequences of actions before executing them in the physical world.
  • AlphaZero replaces hand-crafted heuristics with a unified policy-value network guided by MCTS self-play.
  • MuZero plans in abstract latent state space, eliminating the need to model irrelevant visual environment details.

05 In code

python
import numpy as np

class ToyAlphaZeroEvaluator:
    """Demonstrates joint policy-value evaluation and MCTS prior guidance."""
    def __init__(self, action_dim=4):
        self.action_dim = action_dim

    def predict(self, state_vector):
        """Dual-head prediction: policy prior (p) and scalar value (v)."""
        # Simulated forward pass of dual-head ResNet
        raw_logits = np.dot(state_vector, np.ones((len(state_vector), self.action_dim)))
        exp_logits = np.exp(raw_logits - np.max(raw_logits))
        policy_prior = exp_logits / np.sum(exp_logits)
        
        # Value in [-1, +1] representing win/loss expectation
        value = np.tanh(np.sum(state_vector) * 0.1)
        return policy_prior, value

# Test state representation
state = np.array([0.5, -0.2, 1.2, 0.1])
model = ToyAlphaZeroEvaluator(action_dim=4)
p_prior, v_val = model.predict(state)

# MCTS visit count policy target
mcts_visits = np.array([120, 15, 310, 55])
target_policy = mcts_visits / np.sum(mcts_visits)
game_outcome = 1.0  # Player won

# AlphaZero loss calculation
loss_value = (game_outcome - v_val) ** 2
loss_policy = -np.sum(target_policy * np.log(p_prior + 1e-12))
total_loss = loss_value + loss_policy

print(f"Predicted Policy Prior: {p_prior.round(3)}")
print(f"MCTS Search Policy:    {target_policy.round(3)}")
print(f"Predicted Value:        {v_val:.3f} (True Outcome: {game_outcome})")
print(f"AlphaZero Joint Loss:   {total_loss:.4f}")

Common pitfalls

  • Suffering from compounding model errors in long rollout horizons; small imperfections in the transition model multiply exponentially over multi-step planning.
  • Attempting to reconstruct full raw pixel frames in visual world models, wasting model capacity on task-irrelevant background pixels.

06 Check yourself

Q1What is the primary difference between model-free and model-based reinforcement learning?

Why: Model-based methods learn or exploit environment dynamics $P(s'|s, a)$ to simulate future trajectories, enabling predictive planning.

Q2How does MuZero extend AlphaZero to environments where the game rules are completely unknown (e.g. Atari)?

Why: MuZero learns an internal dynamics function operating on latent embeddings, learning to predict task-relevant rewards and policies without explicit rule models.

Q3In AlphaZero's loss function, what acts as the training target for the neural network's policy head?

Why: MCTS search acts as a powerful policy improvement operator; the neural network policy head is trained to mimic the high-quality MCTS visit distribution.
