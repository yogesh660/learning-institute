01 The idea

When large amounts of unlabelled data are available, self-training leverages the model’s own high-confidence predictions to iteratively expand its training dataset, pushing decision boundaries toward low-density regions.

In production machine learning systems, data scientists frequently find themselves with a small labelled dataset $\mathcal{D}_L$ and a massive pool of unlabelled instances $\mathcal{D}_U$. While graph-based methods like label propagation require holding all data in memory, Self-Training (pseudo-labelling) offers an intuitive, scalable bootstrapping paradigm that works with any supervised model—from logistic regression to 100-million parameter vision transformers.

The core self-training loop operates in iterations: first, train a base model on the available labelled data $\mathcal{D}_L$. Second, generate predicted class probabilities on unlabelled instances $u \in \mathcal{D}_U$. Third, filter the predictions using a strict confidence threshold $\tau$ (e.g. $\max_k P(y=k \mid u) \ge 0.95$). Fourth, convert confident predictions into hard "pseudo-labels" $\hat{y} = \arg\max P(y \mid u)$, append them to the training set, and retrain the model from scratch.

Why does training a model on its own predictions work? Mathematically, pseudo-labelling acts as an implicit form of Entropy Minimisation (Grandvalet & Bengio, 2004). By forcing model predictions on unlabelled data to become sharp, discrete one-hot vectors, self-training pushes the decision boundary out of high-density data clusters and into low-density boundary margins.

However, self-training contains an inherent danger: Confirmation Bias. If the initial model makes an incorrect prediction with high confidence (e.g. due to class imbalance or misleading noise), it pseudo-labels the sample incorrectly. In subsequent rounds, the model retrains on its own mistake, reinforcing and compounding the error. Modern algorithms like FixMatch prevent confirmation bias using data augmentation consistency: inferring pseudo-labels on weakly augmented images and enforcing loss on strongly augmented versions.

In everyday terms

Imagine an apprentice botanist learning to identify mushrooms with a guidebook containing only five confirmed photographs. The apprentice walks into a forest of 1,000 unlabelled mushrooms. When they encounter a mushroom that is 99% identical to the guidebook photo of a Chanterelle, they plant a wooden signpost labelled "Chanterelle". They use their newly expanded set of reference mushrooms to identify subtly more ambiguous specimens deeper in the forest, gradually mastering the species.

03 The maths

  1. Confidence Masking and Pseudo-Label Definition

    q_b = \mathbb{I}\left( \max_k p_{\mathrm{model}}(y = k \mid u_b) \ge \tau \right), \quad \hat{y}_b = \arg\max_k p_{\mathrm{model}}(y = k \mid u_b)

    Binary mask q_b filters unlabelled instances, retaining only samples where maximum predicted class probability exceeds threshold tau.

  2. Combined Supervised and Pseudo-Label Objective

    \mathcal{L}_{\mathrm{total}} = \frac{1}{B_L} \sum_{i=1}^{B_L} H(y_i, p(x_i)) + \lambda_u \frac{1}{B_U} \sum_{b=1}^{B_U} q_b H(\hat{y}_b, p(u_b))

    Standard cross-entropy loss on labelled data combined with confidence-masked cross-entropy on pseudo-labelled unlabelled instances weighted by lambda_u.

  3. Connection to Entropy Minimisation

    \mathcal{H}(p) = -\sum_{k=1}^K p_k \log p_k \to 0

    Training on hard one-hot pseudo-labels forces class probabilities toward 0 or 1, minimising conditional entropy and driving decision boundaries into low-density margins.

04 Key takeaways

  • Bootstraps models on unlabelled data by treating high-confidence predictions as ground-truth pseudo-labels.
  • Model-agnostic and highly scalable: works with any supervised base classifier without graph memory bottlenecks.
  • Enforces entropy minimisation: pushes classification decision boundaries into low-density regions between clusters.
  • Confidence thresholding $\tau \in [0.90, 0.98]$ prevents noisy ambiguous predictions from corrupting training data.
  • Forms the foundation of state-of-the-art semi-supervised deep learning frameworks like FixMatch and noisy student training.

05 In code

python
import numpy as np
from sklearn.linear_model import LogisticRegression

# Self-Training with Confidence Thresholding from scratch
np.random.seed(42)

# Generate synthetic binary dataset (2 clusters in 2D space)
n_samples = 400
X1 = np.random.normal(loc=[-1.5, 0], scale=0.8, size=(n_samples // 2, 2))
X2 = np.random.normal(loc=[1.5, 0], scale=0.8, size=(n_samples // 2, 2))
X = np.vstack([X1, X2])
y_true = np.array([0]*(n_samples // 2) + [1]*(n_samples // 2))

# Tiny initial labelled seed: ONLY 10 SAMPLES (5 per class)
# Remaining 390 samples are unlabelled!
n_labelled = 10
labelled_idx = np.concatenate([np.random.choice(n_samples // 2, n_labelled // 2, replace=False),
                               np.random.choice(np.arange(n_samples // 2, n_samples), n_labelled // 2, replace=False)])
unlabelled_idx = np.setdiff1d(np.arange(n_samples), labelled_idx)

# Initial baseline model trained on only 10 samples
baseline_model = LogisticRegression()
baseline_model.fit(X[labelled_idx], y_true[labelled_idx])
acc_baseline = np.mean(baseline_model.predict(X[unlabelled_idx]) == y_true[unlabelled_idx])

# Self-Training Loop
current_labelled_idx = labelled_idx.copy()
current_unlabelled_idx = unlabelled_idx.copy()
current_y = y_true.copy()

confidence_threshold = 0.90
max_cycles = 5

for cycle in range(max_cycles):
    # 1. Fit model on currently labelled pool
    clf = LogisticRegression()
    clf.fit(X[current_labelled_idx], current_y[current_labelled_idx])
    
    # 2. Predict probabilities on unlabelled pool
    if len(current_unlabelled_idx) == 0:
        break
    probs = clf.predict_proba(X[current_unlabelled_idx])
    max_probs = np.max(probs, axis=1)
    pseudo_labels = np.argmax(probs, axis=1)
    
    # 3. Filter by confidence threshold
    confident_mask = max_probs >= confidence_threshold
    if not np.any(confident_mask):
        break
        
    newly_labelled_indices = current_unlabelled_idx[confident_mask]
    current_y[newly_labelled_indices] = pseudo_labels[confident_mask]
    
    # 4. Update pools
    current_labelled_idx = np.concatenate([current_labelled_idx, newly_labelled_indices])
    current_unlabelled_idx = current_unlabelled_idx[~confident_mask]

# Final model evaluation
final_model = LogisticRegression()
final_model.fit(X[current_labelled_idx], current_y[current_labelled_idx])
acc_final = np.mean(final_model.predict(X[unlabelled_idx]) == y_true[unlabelled_idx])

print(f"Dataset: {n_samples} total samples ({n_labelled} initial labelled, {len(unlabelled_idx)} unlabelled)")
print(f"Baseline Accuracy (10 labelled samples only): {acc_baseline * 100:.1f}%")
print(f"Self-Training Confident Pseudo-labels added:   {len(current_labelled_idx) - n_labelled} samples")
print(f"Final Self-Trained Accuracy:                   {acc_final * 100:.1f}%")
print(f"Accuracy Improvement: +{(acc_final - acc_baseline) * 100:.1f}% via self-training!")

Common pitfalls

  • Confirmation bias: If an initial model makes a high-confidence erroneous prediction, it trains on its own blunder in subsequent iterations, entrenching the mistake.
  • Class imbalance amplification: Models tend to be more confident in dominant majority classes, pseudo-labelling more majority samples and starving minority classes; class-balanced thresholding is vital.
  • Static threshold collapse: A fixed threshold $\tau = 0.95$ may be too strict in early epochs (zero pseudo-labels added) or too lenient in late epochs; curriculum pseudo-labelling dynamically adjusts $\tau$.

06 Check yourself

Q1What is "confirmation bias" in the context of self-training and pseudo-labelling?

Why: Confirmation bias occurs when the model incorporates its own erroneous pseudo-labels into training, reinforcing the error and cementing corrupted decision boundaries.

Q2Why does training on high-confidence pseudo-labels improve classification performance?

Why: By forcing confident unlabelled predictions to hard one-hot pseudo-labels, the loss encourages low-entropy predictions, pushing boundaries into low-density gaps between clusters.
