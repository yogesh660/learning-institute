01 The idea

Many modern regularised machine learning objectives take composite form: a smooth convex loss f(x) plus a non-smooth convex regulariser g(x). Proximal gradient algorithms split the optimisation, combining gradient descent on f with the proximal operator of g.

In modern machine learning, objectives frequently take a composite structure: $\min_x F(x) = f(x) + g(x)$, where $f(x)$ is a convex, continuously differentiable loss function (such as mean squared error, logistic loss, or neural cross-entropy), and $g(x)$ is a convex but non-smooth regulariser (such as the $L_1$ norm $\|x\|_1$ for feature sparsity, nuclear norm for matrix completion, or indicator functions for box constraints).

Standard gradient descent cannot be applied because $g(x)$ lacks derivatives at kinks (e.g. at $x=0$ in the $L_1$ norm). Subgradient methods can handle non-differentiable points, but suffer from a notoriously sluggish convergence rate of $O(1/\sqrt{k})$ and rarely produce exact sparse zeros.

Proximal Gradient Methods resolve this by operator splitting. At each iteration, the algorithm takes a standard gradient step along the smooth loss $f$, and then passes the resulting intermediate point through the Proximal Operator of $g$: $x_{k+1} = \operatorname{prox}_{\gamma g}(x_k - \gamma \nabla f(x_k))$. The proximal operator $\operatorname{prox}_{\gamma g}(v) = \arg\min_x \left( g(x) + \frac{1}{2\gamma} \|x - v\|^2 \right)$ balances minimising the regulariser $g$ while staying close to the gradient step $v$.

When applied to $L_1$ regularisation, this yields the Iterative Shrinkage-Thresholding Algorithm (ISTA), which converges at rate $O(1/k)$. Amir Beck and Marc Teboulle (2009) introduced Fast ISTA (FISTA), which incorporates Nesterov momentum acceleration to achieve the optimal theoretical rate $O(1/k^2)$ for first-order composite optimisation.

In everyday terms

Imagine sculpting an intricate marble statue. The smooth loss function f is an artist using a coarse polishing cloth to buff out broad curves. The non-smooth regulariser g is an artisan wielding a sharp chisel that clips off unwanted chunks to carve sharp, crisp geometric edges. The proximal gradient method alternates between the two: polish smoothly with the cloth, then immediately chisel with the proximal operator.

03 The maths

  1. The Proximal Operator

    \operatorname{prox}_{\gamma g}(v) = \arg\min_{x} \left( g(x) + \frac{1}{2 \gamma} \|x - v\|_2^2 \right)

    Resolves non-smooth objective by finding a compromise between minimising penalty g(x) and proximity to candidate vector v.

  2. Proximal Gradient (ISTA) Update

    x_{k+1} = \operatorname{prox}_{\gamma g}\left(x_k - \gamma \nabla f(x_k)\right)

    Iterative Shrinkage-Thresholding Algorithm. Alternates a gradient descent step on smooth term f with the proximal mapping of non-smooth term g.

  3. FISTA Nesterov Momentum Acceleration

    y_{k+1} = x_k + \frac{t_{k-1} - 1}{t_k} (x_k - x_{k-1}), \quad t_k = \frac{1 + \sqrt{1 + 4 t_{k-1}^2}}{2}

    Accelerates convergence rate from O(1/k) to the optimal Nesterov theoretical limit O(1/k^2) for first-order composite optimisation.

04 Key takeaways

  • Optimises composite objectives $F(x) = f(x) + g(x)$ combining smooth convex loss $f$ with non-smooth convex regulariser $g$.
  • Alternates a forward gradient step on $f$ with the backward proximal operator of $g$: $x_{k+1} = \operatorname{prox}_{\gamma g}(x_k - \gamma \nabla f(x_k))$.
  • For $L_1$ regularisation, the proximal operator equals the analytical soft-thresholding operator (ISTA).
  • FISTA incorporates Nesterov momentum acceleration, boosting convergence rate from $O(1/k)$ to the optimal theoretical limit $O(1/k^2)$.
  • Applies broadly to Lasso, Elastic Net, group lasso, nuclear norm matrix completion, and constrained optimisation.

05 In code

python
import numpy as np

# Proximal Gradient Methods: ISTA vs FISTA from scratch on Lasso
np.random.seed(42)
n_samples = 200
n_features = 80

# True sparse signal (only 5 active coefficients)
X = np.random.normal(0, 1, (n_samples, n_features))
true_beta = np.zeros(n_features)
true_beta[[5, 12, 28, 45, 60]] = [2.0, -1.5, 3.2, -2.8, 1.0]
y = X @ true_beta + np.random.normal(0, 0.4, n_samples)

# Smooth loss: f(beta) = 0.5 * ||y - X beta||^2
# Non-smooth penalty: g(beta) = lambda * ||beta||_1
lambda_reg = 15.0

# Lipschitz constant of nabla f: L = max eigenvalue of X^T X
L = np.linalg.norm(X.T @ X, 2)
gamma = 1.0 / L  # Step size

def soft_threshold(v, thresh):
    return np.sign(v) * np.maximum(0.0, np.abs(v) - thresh)

def objective(beta):
    return 0.5 * np.sum((y - X @ beta)**2) + lambda_reg * np.sum(np.abs(beta))

# 1. Standard ISTA (O(1/k) convergence)
n_iters = 120
beta_ista = np.zeros(n_features)
loss_ista = []

for k in range(n_iters):
    # Gradient of smooth loss: nabla f(beta) = -X^T (y - X beta)
    grad_f = -X.T @ (y - X @ beta_ista)
    # Gradient step followed by proximal soft-thresholding
    v = beta_ista - gamma * grad_f
    beta_ista = soft_threshold(v, gamma * lambda_reg)
    loss_ista.append(objective(beta_ista))

# 2. Fast ISTA (FISTA) with Nesterov Momentum (O(1/k^2) convergence)
beta_fista = np.zeros(n_features)
beta_prev = np.zeros(n_features)
y_aux = np.zeros(n_features)
t = 1.0
loss_fista = []

for k in range(n_iters):
    # Gradient step evaluated at auxiliary momentum point y_aux
    grad_f = -X.T @ (y - X @ y_aux)
    v = y_aux - gamma * grad_f
    beta_fista = soft_threshold(v, gamma * lambda_reg)
    
    # Nesterov momentum update
    t_next = (1.0 + np.sqrt(1.0 + 4.0 * t**2)) / 2.0
    y_aux = beta_fista + ((t - 1.0) / t_next) * (beta_fista - beta_prev)
    
    beta_prev = beta_fista.copy()
    t = t_next
    loss_fista.append(objective(beta_fista))

min_obj = min(loss_fista[-1], loss_ista[-1])
print(f"Dataset: {n_samples} samples x {n_features} features (5 active)")
print(f"Step size gamma = 1/L = {gamma:.6f}")
print(f"\nAfter {n_iters} iterations:")
print(f"  ISTA Objective:  {loss_ista[-1]:.3f} (Distance to min: {loss_ista[-1] - min_obj:.4f})")
print(f"  FISTA Objective: {loss_fista[-1]:.3f} (Distance to min: {loss_fista[-1] - min_obj:.4f})")
print(f"Iterations to reach loss < {loss_ista[-1]:.1f}:")
print(f"  ISTA:  {n_iters} iterations")
fista_match_iter = next(i + 1 for i, l in enumerate(loss_fista) if l <= loss_ista[-1])
print(f"  FISTA: {fista_match_iter} iterations ({n_iters / fista_match_iter:.1f}x speedup via momentum!)")

Common pitfalls

  • Step size exceeding 1/L: Setting step size $\gamma > 1/L$ (where $L$ is the Lipschitz constant of $\nabla f$) causes proximal gradient steps to diverge.
  • Non-convex regularisers: If $g(x)$ is non-convex (e.g. $L_0$ pseudo-norm), the proximal operator may have multiple local solutions, forfeiting global convergence guarantees.
  • Non-monotone FISTA energy spikes: Standard Nesterov momentum in FISTA can produce temporary objective energy spikes; monotone FISTA (MFISTA) restores strict monotonic descent.

06 Check yourself

Q1What is the theoretical convergence rate of FISTA compared to standard ISTA for composite convex optimisation?

Why: By incorporating Nesterov momentum extrapolation, FISTA improves the convergence rate from O(1/k) to O(1/k^2), which is the proven optimal first-order bound.

Q2What does the proximal operator prox_{gamma g}(v) compute geometrically?

Why: From its definition prox(v) = argmin_x { g(x) + (1/(2 gamma)) ||x - v||^2 }, it acts as an implicit step compromising between the regulariser g and distance to v.
