01 The idea

As foundation models scale in capability, ensuring they remain safe, controllable, and aligned with human intent becomes paramount. AI Alignment addresses the challenge of building systems that pursue intended goals rather than unintended proxies, while Mechanistic Interpretability reverse-engineers the internal computational circuits, representations, and polysemantic features inside neural networks.

AI Alignment decomposes into two fundamental challenges: 1) Outer Alignment: did we formulate the right objective function? (e.g. optimising pure click-through rates leads models to promote sensationalist outrage); 2) Inner Alignment: did the neural network internalise our intended goal, or did it learn a deceptive sub-goal that happens to score well during training (goal misgeneralisation or deceptive alignment)?

Because deep neural networks operate as opaque matrices of billions of floating-point numbers, we cannot verify alignment simply by inspecting weight tensors. Mechanistic Interpretability seeks to reverse-engineer neural networks into human-interpretable computer programs: decomposing polysemantic neurons into monosemantic features using Sparse Autoencoders (SAEs), mapping attention induction heads, and steering generation dynamically using activation addition (steering vectors).

In everyday terms

Imagine attempting to understand an alien spacecraft. Alignment is ensuring that when you pull the steering yoke to the left, the ship turns left instead of exploding or hijacking your controls. Mechanistic interpretability is opening up the spaceship's engine bay with an oscilloscope and reverse-engineering the wiring schematics to understand how electrical currents flow between components.

02 Step by step

  1. Identify alignment vulnerabilities: audit for reward hacking, sycophancy, power-seeking tendencies, and deceptive reasoning in out-of-distribution environments.
  2. Train Sparse Autoencoders (SAEs): train sparse autoencoders on internal residual stream activations to disentangle polysemantic superposition into monosemantic feature directions.
  3. Trace attention induction heads: detect transformer attention head pairs that copy and paste patterned sequences, executing in-context learning.
  4. Extract steering vectors: compute the difference vector $\mathbf{v}_{\text{steer}} = \mathbf{h}_{\text{honest}} - \mathbf{h}_{\text{dishonest}}$ between paired contrastive completions.
  5. Apply activation steering: add $\alpha \cdot \mathbf{v}_{\text{steer}}$ to the intermediate residual stream during forward passes to steer behaviour without fine-tuning weights.
  6. Evaluate safety margin: test robustness under red-teaming attacks and assess whether safety interventions impose a performance tax on general reasoning.

03 The maths

  1. Sparse Autoencoder (SAE) Monosemantic Objective

    \mathcal{L}_{\text{SAE}}(\mathbf{x}) = \| \mathbf{x} - \mathbf{W}_{\text{dec}} \mathbf{f}(\mathbf{x}) \|_2^2 + \lambda \| \mathbf{f}(\mathbf{x}) \|_1, \quad \mathbf{f}(\mathbf{x}) = \text{ReLU}(\mathbf{W}_{\text{enc}}(\mathbf{x} - \mathbf{b}_{\text{dec}}) + \mathbf{b}_{\text{enc}})

    Reconstructs residual stream $\mathbf{x}$ using an overcomplete sparse feature dictionary $\mathbf{f}(\mathbf{x})$ penalised by $L_1$ sparsity regularisation.

  2. Activation Steering (Representation Engineering)

    \mathbf{h}_l' = \mathbf{h}_l + \alpha \cdot \mathbf{v}_{\text{concept}}

    Intervenes directly on layer $l$ hidden state by injecting directional concept vector $\mathbf{v}_{\text{concept}}$ with intervention strength $\alpha$.

04 Key takeaways

  • Outer alignment formulates correct objectives; inner alignment ensures neural networks internalise intended goals without deceptive sub-goals.
  • Mechanistic interpretability aims to reverse-engineer neural networks into human-auditable computational circuits.
  • Sparse autoencoders resolve polysemantic superposition, and activation steering allows direct control over model representations during inference.

05 In code

python
import numpy as np

class ActivationSteeringToy:
    """Demonstrates representation engineering and activation steering on residual states."""
    def __init__(self, dim=4):
        self.dim = dim

    def extract_steering_vector(self, positive_states, negative_states):
        """Computes mean difference vector for a target behavioural concept."""
        mean_pos = np.mean(positive_states, axis=0)
        mean_neg = np.mean(negative_states, axis=0)
        vector = mean_pos - mean_neg
        return vector / (np.linalg.norm(vector) + 1e-8)

    def forward_with_steering(self, hidden_state, steering_vector, alpha=1.5):
        """Injects steering vector into hidden state during inference."""
        steered_state = hidden_state + alpha * steering_vector
        return steered_state

# Simulation: Steer model from 'hallucination/dishonesty' toward 'truthfulness'
np.random.seed(42)
d = 4

# Hidden states when answering truthfully vs dishonestly
honest_states = np.array([
    [1.2, 0.8, -0.4, 0.9],
    [1.5, 0.7, -0.2, 1.1],
    [1.3, 0.9, -0.5, 0.8]
])
dishonest_states = np.array([
    [-0.5, 0.2, 1.2, -0.8],
    [-0.7, 0.1, 1.4, -0.6],
    [-0.4, 0.3, 1.1, -0.9]
])

steering_sim = ActivationSteeringToy(dim=d)
v_truth = steering_sim.extract_steering_vector(honest_states, dishonest_states)

# Ambiguous query state that leans slightly dishonest
neutral_state = np.array([0.1, 0.2, 0.8, -0.2])
steered_state = steering_sim.forward_with_steering(neutral_state, v_truth, alpha=2.0)

print(f"Extracted Truthfulness Steering Vector: {v_truth.round(3)}")
print(f"Original Neutral Activation:           {neutral_state.round(3)}")
print(f"Steered Output Activation:              {steered_state.round(3)}")

Common pitfalls

  • Assuming an aligned model during evaluation will remain aligned in deployment; models can exhibit "deceptive alignment", acting cooperative until opportunities emerge.
  • Injecting steering vectors with excessive strength $\alpha$, which corrupts syntactic fluency and causes gibberish generation.

06 Check yourself

Q1What is the distinction between "outer alignment" and "inner alignment"?

Why: Outer alignment is about specifying the right objective; inner alignment is about whether the trained model genuinely internalises that objective without goal misgeneralisation.

Q2Why do neurons in deep neural networks exhibit "polysemanticity" (responding to multiple unrelated concepts)?

Why: Superposition theory explains that networks compress vast numbers of features into fewer dimensional spaces by packing features as non-orthogonal linear combinations.

Q3How does activation steering (representation engineering) alter model behaviour during inference?

Why: Activation addition directly shifts residual stream activations along desired conceptual axes (e.g. honesty, refusal, sentiment) during forward inference.
