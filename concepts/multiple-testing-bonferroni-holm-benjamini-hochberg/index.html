01 The idea

When testing hundreds of features, genome variants, or concurrent A/B test variations, standard significance thresholds collapse under the weight of multiplicity. Testing 100 null hypotheses at $\alpha = 0.05$ produces an average of five false discoveries by pure chance. Multiple testing corrections adjust p-values to control either the strict probability of even a single false alarm (Family-Wise Error Rate) or the expected proportion of false alarms among all declared discoveries (False Discovery Rate).

Suppose a machine learning team evaluates 10 new candidate features for a credit scoring model, running an individual hypothesis test for each feature at the conventional $\alpha = 0.05$ threshold. The resulting raw p-values from smallest to largest are: $[0.001, 0.006, 0.012, 0.024, 0.038, 0.082, 0.150, 0.290, 0.440, 0.810]$. Without any adjustment, five features pass the threshold ($p \le 0.05$). But if all 10 candidate features were actually useless noise, the probability of finding at least one false positive is $1 - (1 - 0.05)^{10} \approx 40.1\%$.

To protect against false discoveries, we can choose between two paradigms:

First, Family-Wise Error Rate (FWER): if a single false claim is unacceptable (such as approving an ineffective drug), we require that the probability of any false positive across all 10 tests remains $\le 5\%$. The Bonferroni correction multiplies each p-value by $m = 10$. Now only the first feature survives ($0.001 \times 10 = 0.010 \le 0.05$), while the second becomes $0.006 \times 10 = 0.060 > 0.05$. The Holm step-down method improves on Bonferroni by stepping down the multiplier $(10, 9, 8, \dots)$, but still declares only 1 discovery. Second, False Discovery Rate (FDR): in exploratory data science and feature selection, demanding zero false positives is overly conservative and discards valuable signal. Benjamini and Hochberg (1995) proposed controlling the expected proportion of false positives among all declared discoveries. Applying the Benjamini–Hochberg procedure declares three discoveries ($p \le [0.010, 0.030, 0.040]$), recovering three legitimate features while strictly capping false discoveries.

In everyday terms

FWER methods are like a zero-tolerance airport security checkpoint where a single false alarm grounds all flights; FDR methods are like an automated spam filter that accepts a small, manageable percentage of spam in the inbox in exchange for never missing important emails.

02 Step by step

  1. Assemble all $m$ raw p-values from the family of tests and sort them in ascending order: $p_{(1)} \le p_{(2)} \le \dots \le p_{(m)}$.
  2. Choose the appropriate error control criterion: FWER for confirmatory decisions, or FDR for exploratory screening and feature selection.
  3. For conservative FWER control, apply Bonferroni: reject hypotheses where $p_{(i)} \le \alpha / m$.
  4. For uniformly superior FWER control without additional assumptions, apply Holm's step-down method: compare $p_{(i)}$ against $\alpha / (m - i + 1)$ sequentially, stopping at the first non-rejection.
  5. For balanced FDR control, apply Benjamini–Hochberg: find the largest rank $k$ where $p_{(k)} \le \frac{k}{m} Q$, and reject all hypotheses from rank 1 through $k$.
  6. Report adjusted p-values alongside original unadjusted statistics to maintain full scientific transparency.

03 The maths

  1. Family-Wise Error Rate and Bonferroni Inequality

    $$\text{FWER} = P(V \ge 1) \le \sum_{i=1}^{m_0} P(\text{Reject } H_{0,i} \mid H_{0,i} \text{ true}) \le m_0 \frac{\alpha}{m} \le \alpha$$

    Here $V$ is the number of false rejections (Type I errors), $m$ is total hypotheses tested, and $m_0 \le m$ is the number of true nulls. By Boole's union bound, testing each hypothesis at significance level $\alpha / m$ ensures the family-wise error rate remains $\le \alpha$ under any dependency structure.

  2. Holm's Sequentially Rejective Step-Down Method

    $$\text{Step } i: \quad p_{(i)} \le \frac{\alpha}{m - i + 1}$$

    Holm's method sorts p-values in ascending order and tests sequentially: $p_{(1)}$ against $\alpha / m$, $p_{(2)}$ against $\alpha / (m - 1)$, and so on. As soon as a p-value fails its criterion, testing terminates and all remaining hypotheses are retained. Holm controls FWER at level $\alpha$ under arbitrary dependence while being strictly more powerful than Bonferroni.

  3. Benjamini–Hochberg False Discovery Rate (FDR)

    $$\text{FDR} = E\left[\frac{V}{\max(R, 1)}\right] \le Q \implies k = \max\left\{i : p_{(i)} \le \frac{i}{m} Q\right\}, \quad \text{Reject } H_{(1)}, \dots, H_{(k)}$$

    Here $V$ is false rejections, $R$ is total rejections, and $Q$ is target FDR level. Sorting p-values and finding the largest index $k$ whose p-value falls below the rank line $\frac{i}{m} Q$ guarantees that the expected proportion of false discoveries does not exceed $Q$ under independent or positively dependent test statistics.

04 Key takeaways

  • The family-wise error rate (FWER) controls the probability of making at least one false discovery; the false discovery rate (FDR) controls the expected proportion of false discoveries among rejected hypotheses.
  • Bonferroni is universally valid under any dependence structure, but becomes severely underpowered when testing hundreds or thousands of hypotheses.
  • Holm's step-down procedure is always at least as powerful as Bonferroni and carries zero extra assumptions; there is virtually no statistical reason to use classic Bonferroni over Holm.
  • The Benjamini–Hochberg procedure dramatically increases statistical power in high-dimensional settings by tolerating a controlled rate of false positives.

05 In code

python
import numpy as np
import scipy.stats as stats

# Raw p-values from 10 parallel A/B tests or candidate features
p_vals = np.array([0.001, 0.006, 0.012, 0.024, 0.038, 0.082, 0.150, 0.290, 0.440, 0.810])
m = len(p_vals)
alpha = 0.05

# 1. Bonferroni: multiply by total tests m
p_bonf = np.minimum(p_vals * m, 1.0)

# 2. Holm step-down: multiply by (m - rank) and enforce monotonicity
p_holm = np.maximum.accumulate(np.minimum(p_vals * (m - np.arange(m)), 1.0))

# 3. Benjamini-Hochberg (FDR control)
p_bh = stats.false_discovery_control(p_vals, method='bh')

print(f"Raw p-values:        {p_vals}")
print(f"Bonferroni adjusted: {np.round(p_bonf, 3)}")
print(f"Holm adjusted:       {np.round(p_holm, 3)}")
print(f"BH adjusted (FDR):   {np.round(p_bh, 3)}")
print(f"Discoveries at alpha={alpha} -> Unadjusted: {np.sum(p_vals <= alpha)}, "
      f"Bonferroni: {np.sum(p_bonf <= alpha)}, Holm: {np.sum(p_holm <= alpha)}, "
      f"Benjamini-Hochberg: {np.sum(p_bh <= alpha)}")

Common pitfalls

  • Using Bonferroni correction in large-scale feature selection ($m > 1,000$), which obliterates statistical power and results in severe Type II errors.
  • Failing to apply any multiplicity correction when examining dozens of subgroup breakdowns or metrics in A/B tests.
  • Interpreting FDR adjusted p-values as posterior probabilities that a specific hypothesis is null; FDR is a property of the collective discovery set.
  • Applying multiple testing corrections after cherry-picking which tests to report; corrections require knowing the total number of tests executed.

06 Check yourself

Q1What is the crucial difference between Family-Wise Error Rate (FWER) and False Discovery Rate (FDR)?

Why: FWER bounds $P(V \ge 1) \le \alpha$, demanding near-certainty of zero false discoveries. FDR bounds $E[V / \max(R, 1)] \le Q$, tolerating a small fraction of false discoveries to boost power.

Q2Why should practitioners generally prefer Holm's step-down procedure over the classical Bonferroni correction?

Why: Holm's step-down method guarantees the same FWER protection as Bonferroni without any additional assumptions, but uses smaller multipliers for subsequent ranks, making it uniformly more powerful.

Q3In the Benjamini–Hochberg procedure with $m$ tests and target FDR $Q$, what is the rejection criterion for the sorted p-values $p_{(1)} \le \dots \le p_{(m)}$?

Why: The Benjamini–Hochberg step-up procedure identifies the largest index $k$ satisfying $p_{(k)} \le \frac{k}{m} Q$ and declares all hypotheses $1, \dots, k$ significant.

Q4If you evaluate 20 orthogonal features with independent tests at $\alpha = 0.05$ without multiplicity correction, what is the probability of at least one false positive if all features are pure noise?

Why: The probability of at least one false alarm across 20 independent true null tests is $1 - (1 - 0.05)^{20} = 1 - 0.95^{20} \approx 1 - 0.3585 = 0.6415$ (or 64.2%).
