01 The idea

When high-dimensional data lives on a curved manifold, Euclidean straight-line distance cuts through empty space. Isomap uses a k-nearest-neighbour graph and Dijkstra shortest paths to estimate true geodesic distances along the manifold, embedding them via Classical MDS.

How can you construct a map of European cities if you only possess a table of driving distances between them, with zero knowledge of their GPS coordinates? This is the domain of Multidimensional Scaling (MDS): given an $n \times n$ matrix of pairwise dissimilarities $D$, find a configuration of points in low-dimensional space $\mathbb{R}^d$ (typically $d=2$) whose Euclidean distances match the input dissimilarities as closely as possible.

Classical MDS (Principal Coordinate Analysis, PCoA) solves this in closed form: it squares the distances, performs double centring to construct an inner product Gram matrix $B = -\frac{1}{2} H D^2 H$, and extracts coordinates via eigendecomposition. If the input dissimilarities are exact Euclidean distances, Classical MDS is mathematically identical to PCA.

However, when data lies on a complex non-linear manifold (such as the famous "Swiss roll" or "S-curve"), Euclidean distance measured through ambient high-dimensional space is deceptive: two points on adjacent layers of the rolled spiral have a tiny straight-line distance through empty air, but are far apart along the surface of the manifold.

Isomap (Isometric Feature Mapping, Tenenbaum et al., 2000) resolves this by replacing straight-line Euclidean distance with true geodesic distance (distance along the manifold surface). It builds a $k$-nearest neighbour graph connecting local adjacent points, computes all-pairs shortest paths through the graph via Dijkstra or Floyd–Warshall to estimate geodesic distances, and applies Classical MDS to embed the unrolled manifold into 2D.

In everyday terms

Imagine a rolled-up silk carpet with two ants standing on it: Ant A on the outer layer, Ant B directly beneath it on the inner layer. A straight ruler piercing through the fabric says they are 5 millimetres apart (Euclidean distance). But to actually walk to each other without biting through the silk, Ant A must crawl 3 metres around the spiral (geodesic distance). Isomap measures the crawl distance along the fabric, then unrolls the carpet flat on the floor.

03 The maths

  1. Classical MDS Double Centring Formula

    B = -\frac{1}{2} H D^2 H, \quad H = I_n - \frac{1}{n} \mathbf{1}_n \mathbf{1}_n^T

    Converts a matrix of squared pairwise Euclidean distances D^2 into an origin-centred inner product Gram matrix B = X X^T.

  2. Classical MDS Coordinate Extraction

    Y = V_d \Lambda_d^{1/2}, \quad B = V \Lambda V^T

    Eigendecomposition of Gram matrix B yields optimal low-dimensional coordinates Y minimising the Strain objective function.

  3. Geodesic Graph Distance Approximation

    d_{\mathcal{M}}(x_i, x_j) \approx d_G(i, j) = \min_{p = (v_0, \dots, v_m)} \sum_{k=0}^{m-1} \|v_k - v_{k+1}\|_2

    In the limit of infinite data density, shortest path distance through the k-NN graph converges asymptotically to the true Riemannian geodesic distance along manifold M.

04 Key takeaways

  • Multidimensional Scaling (MDS) finds a low-dimensional Euclidean embedding that preserves a given matrix of pairwise distances.
  • Classical MDS converts squared pairwise distances into an inner product Gram matrix via double centring $B = -\frac{1}{2} H D^2 H$.
  • Isomap unrolls non-linear manifolds by substituting straight-line Euclidean distances with shortest-path geodesic distances across a $k$-NN graph.
  • Guaranteed to find true isometric manifold embeddings asymptotically as data density approaches infinity.
  • Highly sensitive to topological short-circuiting: noisy points or an overly large $k$ bridge adjacent layers, collapsing the unrolled manifold.

05 In code

python
import numpy as np
from scipy.sparse.csgraph import floyd_warshall

# Isomap from scratch (k-NN graph + Floyd-Warshall + Classical MDS)
def isomap_from_scratch(X, n_neighbors=8, n_components=2):
    n = len(X)
    
    # 1. Compute pairwise Euclidean distances
    dists_sq = np.sum(X**2, axis=1)[:, None] + np.sum(X**2, axis=1)[None, :] - 2 * (X @ X.T)
    dists = np.sqrt(np.maximum(dists_sq, 0))
    
    # 2. Build k-NN adjacency graph
    adj_matrix = np.full((n, n), np.inf)
    for i in range(n):
        # Find k nearest neighbors (excluding self)
        nn_indices = np.argsort(dists[i])[1:n_neighbors+1]
        for j in nn_indices:
            adj_matrix[i, j] = dists[i, j]
            adj_matrix[j, i] = dists[i, j]  # Undirected graph
            
    # 3. Compute all-pairs shortest paths (Geodesic distance approximation)
    D_geo = floyd_warshall(adj_matrix, directed=False)
    
    # Check for disconnected components
    if np.any(np.isinf(D_geo)):
        raise ValueError("Graph is disconnected; increase n_neighbors.")
        
    # 4. Classical MDS on geodesic distance matrix
    # Double centreing: B = -0.5 * H (D^2) H
    H = np.eye(n) - np.ones((n, n)) / n
    B = -0.5 * H @ (D_geo**2) @ H
    
    # Eigendecomposition
    eigenvals, eigenvecs = np.linalg.eigh(B)
    idx = np.argsort(eigenvals)[::-1]
    eigenvals = eigenvals[idx]
    eigenvecs = eigenvecs[:, idx]
    
    # Extract top d coordinates: Y = V_d * sqrt(Lambda_d)
    top_evals = np.maximum(eigenvals[:n_components], 0)
    Y = eigenvecs[:, :n_components] * np.sqrt(top_evals)
    
    return Y, D_geo

# Generate synthetic Swiss Roll manifold
np.random.seed(42)
n_points = 250
phi = np.random.uniform(1.5 * np.pi, 4.0 * np.pi, n_points)
height = np.random.uniform(0, 10, n_points)
x = phi * np.cos(phi)
y = height
z = phi * np.sin(phi)
X_swiss = np.column_stack([x, y, z])

# Run Isomap
Y_embedded, D_geo = isomap_from_scratch(X_swiss, n_neighbors=10, n_components=2)

# Verify correlation between unrolled 1st dimension and true manifold parameter phi
corr_with_phi = np.abs(np.corrcoef(Y_embedded[:, 0], phi)[0, 1])

print(f"Swiss Roll 3D shape: {X_swiss.shape}")
print(f"Isomap 2D Embedding shape: {Y_embedded.shape}")
print(f"Max Euclidean distance through air:    {np.max(np.linalg.norm(X_swiss[0] - X_swiss, axis=1)):.2f}")
print(f"Max Geodesic distance along manifold: {np.max(D_geo[0]):.2f} (captures unrolling!)")
print(f"Correlation between 1st Isomap axis and true unrolled spiral (phi): {corr_with_phi:.4f}")

Common pitfalls

  • Topological short-circuiting: If $k$ is too large or noise bridges adjacent folds of a manifold, a false shortcut is created that corrupts all geodesic paths.
  • Disconnected components: If $k$ is too small, the graph fragments into disconnected subgraphs, yielding infinite shortest path distances.
  • Computational scaling: All-pairs shortest paths via Floyd-Warshall scales as $O(n^3)$; Landmark Isomap (L-Isomap) is required for datasets with $n > 5,000$.

06 Check yourself

Q1Why does Isomap construct a k-NN graph before applying Classical MDS?

Why: Euclidean distance cuts through empty space across manifold folds. By traversing local nearest neighbours, graph shortest paths approximate the true manifold geodesic distance.

Q2What is the mathematical role of the double centring matrix H = I - (1/n) 1 1^T in Classical MDS?

Why: From the identity d_{ij}^2 = ||x_i||^2 + ||x_j||^2 - 2 x_i^T x_j, double centring cancels out the row and column squared norms, leaving exactly the inner product matrix B.
