01 The idea

Deep neural networks achieve superhuman accuracy on benchmark test sets, yet they can be reliably fooled by imperceptible, adversarially crafted noise. Adding tiny, invisible perturbations to an image of a panda can cause a state-of-the-art classifier to predict "gibbon" with 99.9% confidence. Adversarial machine learning studies these fundamental vulnerabilities, creating attacks (FGSM, PGD) and defenses (Adversarial Training) to build reliable, safety-critical AI systems.

Adversarial examples arise from the high-dimensional geometry of neural networks. While activations are non-linear, deep networks operate with high-dimensional linear dot products $w^T x$. If an attacker shifts each of $D=10,000$ input dimensions by an imperceptible epsilon $\epsilon = 0.005$ in the direction of the weight vector, the cumulative activation shifts by $\epsilon \sum |w_i|$, which can be massive.

The Fast Gradient Sign Method (FGSM; Goodfellow et al.) computes an adversarial perturbation in a single gradient step: $x_{\mathrm{adv}} = x + \epsilon \cdot \operatorname{sign}(\nabla_x \mathcal{L}(\theta, x, y))$. It steps in the direction that maximises loss while constraining the maximum change per pixel within the $L_\infty$ ball $\|x_{\mathrm{adv}} - x\|_\infty \le \epsilon$.

Projected Gradient Descent (PGD; Madry et al.) is the multi-step iterative extension of FGSM: taking multiple small steps with step size $\alpha$ and projecting back onto the $\epsilon$-ball after each step. PGD represents the "universal first-order adversary"—the strongest possible attack using local gradient information.

Defending against adversarial attacks cannot rely on heuristic obfuscation (which merely hides gradients without true robustness). The gold standard defense is Adversarial Training: framing training as a robust Min-Max optimisation problem $\min_\theta \mathbb{E} [ \max_{\delta \in \mathcal{S}} \mathcal{L}(\theta, x + \delta, y) ]$, training the network on worst-case PGD perturbations.

In everyday terms

Imagine a high-security facial recognition lock at a military base. To the human eye, an operative wearing an ordinary pair of sunglasses looks completely normal. But microscopic, mathematically calculated iridescent patterns on the sunglass frames reflect light in an exact wave pattern that flips the security system's deep neural network weights, causing the scanner to identify the operative as the base general.

02 Step by step

  1. Define threat model and perturbation budget: Specify the perturbation norm ($L_\infty$ or $L_2$) and budget $\epsilon$ (e.g. $\epsilon = 8/255$ for 8-bit images).
  2. Compute input gradients: Pass clean image $x$ through network, compute classification loss $\mathcal{L}(f_\theta(x), y)$, and evaluate gradient with respect to input: $\nabla_x \mathcal{L}$.
  3. Generate FGSM perturbation: Multiply the sign of the input gradient by $\epsilon$: $\delta = \epsilon \cdot \operatorname{sign}(\nabla_x \mathcal{L})$.
  4. Execute multi-step PGD attack: Iterate $K$ steps ($K \approx 10\text{--}40$): step by $\alpha \cdot \operatorname{sign}(\nabla_x \mathcal{L})$, clip to the $\epsilon$-ball around $x$, and clip to valid image bounds $[0, 1]$.
  5. Implement adversarial training: In every training minibatch, generate on-the-fly PGD adversarial perturbations and update model weights $\theta$ on the perturbed inputs.
  6. Evaluate robust vs clean accuracy: Measure clean test accuracy (on unperturbed images) alongside robust test accuracy against white-box and black-box PGD attacks.

03 The maths

  1. Fast Gradient Sign Method (FGSM)

    x_{\mathrm{adv}} = x + \epsilon \cdot \operatorname{sign}\left( \nabla_x \mathcal{L}(\theta, x, y) \right), \quad \|x_{\mathrm{adv}} - x\|_\infty \le \epsilon

    Shifts input $x$ by $\epsilon$ in the direction of steepest loss ascent, bounded by maximum per-pixel perturbation $\epsilon$.

  2. Projected Gradient Descent (PGD) Iteration

    x^{(t+1)} = \Pi_{x + \mathcal{S}}\left( x^{(t)} + \alpha \cdot \operatorname{sign}\left( \nabla_x \mathcal{L}(\theta, x^{(t)}, y) \right) \right)

    Iterative multi-step attack with step size $\alpha$, projecting ($\Pi$) back into the valid $\epsilon$-neighbourhood $\mathcal{S}$ after each step.

  3. Robust Min-Max Adversarial Training Objective

    \min_\theta \mathbb{E}_{(x, y) \sim \mathcal{D}}\left[ \max_{\|\delta\|_p \le \epsilon} \mathcal{L}\left( f_\theta(x + \delta), \; y \right) \right]

    Finds network parameters $\theta$ that minimise the expected loss on the worst-case adversarial perturbation $\delta$ within budget $\epsilon$.

04 Key takeaways

  • Adversarial examples fool neural networks using imperceptible, mathematically targeted perturbations.
  • FGSM computes adversarial noise in a single step using the sign of the input gradient.
  • Projected Gradient Descent (PGD) is a powerful multi-step iterative attack that bounds perturbations to an $\epsilon$-ball.
  • Adversarial training frames learning as a min-max game, training on worst-case perturbations to build genuine robustness.

05 In code

python
import torch
import torch.nn as nn
import torch.nn.functional as F

def fgsm_attack(image: torch.Tensor, epsilon: float, data_grad: torch.Tensor) -> torch.Tensor:
    """Generate adversarial example using Fast Gradient Sign Method (FGSM)."""
    # 1. Extract element-wise sign of the input gradients
    sign_data_grad = data_grad.sign()
    
    # 2. Shift image in direction of loss ascent
    perturbed_image = image + epsilon * sign_data_grad
    
    # 3. Clip to maintain valid pixel range [0, 1]
    perturbed_image = torch.clamp(perturbed_image, 0.0, 1.0)
    return perturbed_image

# Test FGSM attack on toy linear classifier
torch.manual_seed(42)
x = torch.tensor([[0.5, 0.2]], requires_grad=True)
true_label = torch.tensor([0])

# Model that predicts class 0 if x[0] > x[1]
weights = torch.tensor([[2.0, -2.0]])  # Logit for class 0
logits = x @ weights.T
loss = F.cross_entropy(logits, true_label)
loss.backward()

print("Original prediction logit for Class 0:", round(logits.item(), 3))
print("Input gradient wrt loss:", x.grad.numpy())

# Apply FGSM perturbation with epsilon = 0.15
x_adv = fgsm_attack(x, epsilon=0.15, data_grad=x.grad)
logits_adv = x_adv @ weights.T

print("Adversarial input coordinates:", x_adv.detach().numpy())
print("Adversarial logit for Class 0: ", round(logits_adv.item(), 3))
print("Prediction confidence successfully degraded by tiny perturbation!")

Common pitfalls

  • Gradient masking / obfuscation: Techniques that make gradients noisy (e.g. random input resizing) create a false sense of security; attackers easily bypass them with Expectation Over Transformation (EOT).
  • The clean vs robust accuracy trade-off: Adversarial training typically reduces standard clean accuracy by 2%–8% because the model must learn smoother, wider decision boundaries.
  • Testing robustness only with FGSM: Defending against single-step FGSM does not protect against multi-step PGD attacks; always evaluate against PGD and AutoAttack.

06 Check yourself

Q1Why are deep neural networks vulnerable to adversarial examples even when the perturbation $\epsilon$ on each individual pixel is imperceptibly small?

Why: In high dimensions, shifting $D$ inputs by $\epsilon$ in the direction of weight signs accumulates to an aggregate pre-activation change of $\epsilon \sum |w_i|$, which easily flips decisions.

Q2What is the Fast Gradient Sign Method (FGSM)?

Why: FGSM takes one step along the sign of the gradient of the loss with respect to the input, maximising loss within the $L_\infty$ ball $\epsilon$.

Q3What is the mathematically grounded method for making neural networks genuinely robust against first-order adversarial attacks?

Why: Adversarial training solves the robust min-max problem $\min_\theta \max_\delta \mathcal{L}$, forcing the network to maintain low loss within the entire $\epsilon$-neighbourhood.
