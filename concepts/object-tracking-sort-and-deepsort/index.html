01 The idea

Object detection processes each video frame in isolation: it identifies three cars in frame 10 and three cars in frame 11, but has no concept of identity: which box in frame 11 corresponds to car #1? Multi-Object Tracking (MOT) bridges this temporal gap, maintaining consistent persistent identities across occlusions, camera movements, and object intersections using the Tracking-by-Detection paradigm (SORT, DeepSORT).

Multi-Object Tracking operates primarily via the Tracking-by-Detection paradigm: an external object detector (YOLO) runs on each frame, producing bounding boxes. The tracker assigns these detections to existing active track trajectories.

SORT (Simple Online and Realtime Tracking; Bewley et al., 2016) models object kinematics using a linear Kalman Filter. State vector $\mathbf{x} = [u, v, s, r, \dot{u}, \dot{v}, \dot{s}]^T$ predicts the next frame's bounding box position based on constant velocity motion. The Hungarian algorithm then associates predicted positions with new detections using bounding box Intersection-over-Union (IoU) distance.

While SORT runs at 260 FPS on CPU, it fails catastrophically during occlusions: when an object is blocked by a tree or another person for 10 frames, velocity drift causes the tracker to lose track or switch identities (ID Switch).

DeepSORT (Wojke et al., 2017) resolves occlusions by adding Deep Visual Appearance Re-Identification (Re-ID). A deep CNN extracts a 128-D cosine embedding from each detection crop. Association combines motion distance (Mahalanobis distance) with visual appearance distance (cosine distance between embedding galleries), allowing the tracker to recover lost identities even after long occlusions.

In everyday terms

Imagine a referee at a high-speed basketball match. When players scramble together in a tight huddle under the hoop and separate, the referee does not lose track of which player is player #23. The referee tracks two cues: where the player was moving (momentum/velocity physics—Kalman filtering), and what the player looks like (facial features and team jersey—Deep Re-ID appearance matching).

02 Step by step

  1. Run frame detector: Run high-accuracy real-time detector (YOLO) to output bounding box coordinates and confidence scores.
  2. Predict track state via Kalman Filter: For each active track, propagate the linear Kalman motion model forward one time step to predict current-frame bounding boxes.
  3. Extract deep appearance embeddings (DeepSORT): Pass detected bounding box image crops through a lightweight CNN to extract 128-D unit-norm Re-ID visual feature vectors.
  4. Compute cost matrix: Calculate distance matrix combining Mahalanobis motion distance and visual cosine distance against track feature galleries.
  5. Solve assignment via Hungarian algorithm: Match active tracks to new detections using matching cascade (prioritising recently seen tracks).
  6. Manage track lifecycle: Promote tentative tracks to confirmed status after 3 consecutive hits; mark lost tracks as deleted if unobserved for $A_{\max}$ consecutive frames (e.g. 30 frames).

03 The maths

  1. Linear Kalman Filter State Update

    \mathbf{x}_{k|k-1} = \mathbf{F} \mathbf{x}_{k-1|k-1}, \quad \mathbf{P}_{k|k-1} = \mathbf{F} \mathbf{P}_{k-1|k-1} \mathbf{F}^T + \mathbf{Q}

    Projects track state mean $\mathbf{x}$ and covariance uncertainty $\mathbf{P}$ forward in time using constant velocity transition matrix $\mathbf{F}$.

  2. Squared Mahalanobis Motion Distance

    d^{(1)}(i, j) = (\mathbf{d}_j - \mathbf{y}_i)^T \mathbf{S}_i^{-1} (\mathbf{d}_j - \mathbf{y}_i)

    Measures standard deviation distance between detection $\mathbf{d}_j$ and track Kalman state $\mathbf{y}_i$ accounting for covariance uncertainty $\mathbf{S}_i$.

  3. Deep Visual Cosine Distance Gate

    d^{(2)}(i, j) = \min\left( \left\{ 1 - r_j^T r_k^{(i)} \;\middle|\; r_k^{(i)} \in \mathcal{R}_i \right\} \right)

    Measures minimum cosine distance between detection appearance descriptor $r_j$ and the gallery of the last $L_{\mathrm{gallery}}$ descriptors $\mathcal{R}_i$ for track $i$.

04 Key takeaways

  • Multi-Object Tracking (MOT) maintains consistent identities across video frames.
  • Tracking-by-detection decouples detection (YOLO) from temporal association (SORT).
  • SORT uses a Kalman filter for motion forecasting and the Hungarian algorithm for IoU matching.
  • DeepSORT adds a deep appearance Re-ID network, preventing identity switches during long occlusions.

05 In code

python
import numpy as np
from scipy.optimise import linear_sum_assignment

def associate_detections_to_tracks(predicted_boxes: np.ndarray, detected_boxes: np.ndarray, iou_threshold: float = 0.3):
    """Associate tracks to detections using IoU distance and Hungarian algorithm."""
    # Compute pairwise IoU matrix: [num_tracks, num_dets]
    num_tracks = len(predicted_boxes)
    num_dets = len(detected_boxes)
    
    cost_matrix = np.zeros((num_tracks, num_dets))
    for t in range(num_tracks):
        for d in range(num_dets):
            # Simplified mock IoU calculation
            dist = np.linalg.norm(predicted_boxes[t] - detected_boxes[d])
            cost_matrix[t, d] = dist  # Lower distance is better match
            
    track_idx, det_idx = linear_sum_assignment(cost_matrix)
    
    matches = []
    for t, d in zip(track_idx, det_idx):
        if cost_matrix[t, d] < 20.0:  # Distance gating threshold
            matches.append((t, d))
            
    return matches

# Simulate: 2 active track predictions vs 2 new frame detections
tracks = np.array([[100.0, 100.0], [250.0, 300.0]])  # Track 0, Track 1
dets   = np.array([[102.0,  99.0], [248.0, 305.0]])  # Det 0, Det 1

matches = associate_detections_to_tracks(tracks, dets)
for t, d in matches:
    print(f"Track ID {t} successfully matched with Detection {d}!")
print("Identity persistence maintained across frames!")

Common pitfalls

  • ID switching during cross-overs: When two people walk past each other and cross paths, pure IoU tracking easily swaps their track IDs; appearance Re-ID is critical.
  • Kalman filter breakdown under camera motion: If the camera itself moves wildly (e.g. a bumpy drone), the constant velocity assumption breaks; integrate camera motion compensation (CMC).
  • Excessive track gallery memory: Allowing appearance galleries $\mathcal{R}_i$ to grow indefinitely exhausts RAM; cap galleries to the last 50–100 frames per track.

06 Check yourself

Q1What is the primary operational weakness of SORT (Simple Online and Realtime Tracking) that DeepSORT solves?

Why: SORT only uses geometric IoU overlap. If an object is occluded for several frames, the Kalman filter drifts, losing the ID. DeepSORT remembers visual appearance vectors.

Q2What does the Kalman Filter do within the SORT and DeepSORT tracking pipelines?

Why: The Kalman filter tracks spatial velocity and position, projecting where an object is expected to appear in the next frame before matching.

Q3What is the "Matching Cascade" in DeepSORT?

Why: Recently observed tracks have lower uncertainty; matching them first prevents long-lost tracks with high covariance from stealing recent detections.
