Logistic regression inference: odds ratios, Wald tests

Statistical inference in logistic regression moves beyond binary classification accuracy to evaluate parameter uncertainty, hypothesis testing, and quantitative risk interpretation. Because logistic regression models the log-odds (logit) of an outcome as a linear combination of predictors \ln(\frac{p}{1-p}) = \mathbf{x}^\top \boldsymbol{\beta}, exponentiating coefficients yields Odds Ratios (\text{OR} = \exp(\beta_j)). Hypothesis tests rely on the asymptotic normality of maximum likelihood estimators via Wald z-tests, profile likelihood confidence intervals, and likelihood-ratio deviance tests.

01 The idea

In medical trials or credit scoring, predicting whether a patient recovers or a borrower defaults is only half the battle. Regulatory compliance and clinical decision-making demand rigorous statistical inference: Does a new drug reduce the odds of relapse by a statistically significant margin, and what is the exact 95% confidence interval on that effect size? Unlike linear regression where coefficients represent direct additive changes, logistic regression operates on the multiplicative scale of odds ratios. Understanding Wald inference, odds ratios, and deviance is essential for rigorous applied data science.

From Probabilities to Odds to Log-Odds: - Probability p in (0, 1) is bounded and non-linear. - Odds p / (1 - p) in (0, inf) measures the ratio of success probability to failure probability. An odds of 3.0 means success is 3 times more likely than failure. - Log-odds ln(p / (1 - p)) in (-inf, inf) maps odds onto the unbounded real line, allowing linear modelling: logit(p) = \beta_0 + \beta_1 x_1 + ...

Interpreting the Odds Ratio exp(\beta_j): If feature x_j increases by 1 unit, the log-odds increases by \beta_j. Therefore, the odds are multiplied by exp(\beta_j)! - If \beta_j = 0, exp(\beta_j) = 1.0: feature has zero association with the outcome. - If \beta_j = 0.693, exp(\beta_j) = 2.0: each 1-unit increase doubles the odds of the outcome (100% increase in odds). - If \beta_j = -0.693, exp(\beta_j) = 0.5: each 1-unit increase cuts the odds of the outcome in half (50% reduction in odds).

Wald Inference and the Hauck-Donner Effect: The Wald test statistic z = \hat{\beta}_j / SE(\hat{\beta}_j) tests H_0: \beta_j = 0. However, in extreme cases (e.g. near-perfect separation), the estimated standard error explodes faster than the coefficient, causing the Wald statistic to paradoxically drop toward zero! In critical applications, profile likelihood intervals and likelihood-ratio deviance tests should always be inspected.

In everyday terms

Think of betting at a horse racing track. The track does not quote probabilities like 0.75; it quotes betting odds like 3 to 1. If a horse's jockey changes and the trainer says the new jockey improves performance with an odds ratio of 2.0, your 3-to-1 odds become 6-to-1 odds. Exponentiating logistic regression coefficients is literally finding the multiplier that scales betting odds.

03 The maths

  1. Logit Transformation and Odds Ratio Formulation

    \text{logit}(p) = \ln\left(\frac{p}{1 - p}\right) = \beta_0 + \sum_{j=1}^k \beta_j x_j \implies \text{OR}_j = \frac{\text{Odds}(x_j + 1)}{\text{Odds}(x_j)} = \exp(\beta_j)

    The logit function linearises binary probabilities. Because the link function is logarithmic in the odds ratio, adding 1 unit to predictor x_j multiplies the outcome odds by \exp(\beta_j), holding all other covariates constant.

  2. Asymptotic Covariance and Wald z-Statistic

    \text{Cov}(\hat{\boldsymbol{\beta}}) \approx \left( \mathbf{X}^\top \mathbf{W} \mathbf{X} \right)^{-1}, \quad \mathbf{W} = \text{diag}\big( \hat{p}_i (1 - \hat{p}_i) \big), \qquad z_j = \frac{\hat{\beta}_j}{\text{SE}(\hat{\beta}_j)} \xrightarrow{d} \mathcal{N}(0, 1)

    The inverse of the negative Hessian (observed Fisher Information) yields the asymptotic covariance matrix of parameter estimates. The Wald z-statistic evaluates individual coefficient significance against standard normal critical thresholds.

  3. Model Deviance and Likelihood-Ratio Goodness-of-Fit

    D = -2 \sum_{i=1}^n \left[ y_i \ln \hat{p}_i + (1 - y_i) \ln(1 - \hat{p}_i) \right], \qquad G = D_{\text{null}} - D_{\text{model}} \sim \chi^2(k)

    Deviance measures unexplained variation analogous to residual sum of squares in OLS. The drop in deviance G between the null model (intercept only) and fitted model follows a \chi^2 distribution with k degrees of freedom, testing overall model utility.

04 Key takeaways

  • Logistic regression models log-odds; exponentiating coefficients yields multiplicative Odds Ratios: OR = exp(\beta_j).
  • An Odds Ratio > 1 indicates increased probability of outcome per unit predictor increase; OR < 1 indicates decreased odds.
  • Wald z-tests test individual parameter significance using the inverse Fisher Information covariance matrix.
  • Deviance measures goodness-of-fit; the drop in deviance from the null model tests overall model predictive validity.

05 In code

python
"""
Logistic Regression Statistical Inference Engine
Demonstrating IRLS maximum likelihood estimation, Fisher Information,
Wald z-tests, Odds Ratios, and Deviance goodness-of-fit.
"""

import numpy as np
from scipy import stats

class LogisticRegressionInference:
    def __init__(self, add_intercept: bool = True):
        self.add_intercept = add_intercept
        self.beta = None
        self.cov_matrix = None
        self.se = None

    def fit(self, X: np.ndarray, y: np.ndarray, max_iter: int = 50, tol: float = 1e-7):
        if self.add_intercept:
            X = np.column_stack([np.ones(len(X)), X])
        
        n_samples, n_features = X.shape
        beta = np.zeros(n_features)

        # Iteratively Reweighted Least Squares (Newton-Raphson)
        for iteration in range(max_iter):
            p = 1.0 / (1.0 + np.exp(-np.clip(X @ beta, -30, 30)))
            # Weight matrix W = diag(p * (1 - p))
            w = p * (1.0 - p)
            # Prevent zero division
            w = np.maximum(w, 1e-12)
            
            # Gradient: X^T (y - p)
            gradient = X.T @ (y - p)
            # Hessian: -X^T W X
            hessian = -X.T @ (w[:, np.newaxis] * X)
            
            # Newton-Raphson update: beta_new = beta - H^-1 * g
            delta = np.linalg.solve(-hessian, gradient)
            beta += delta
            
            if np.max(np.abs(delta)) < tol:
                break

        self.beta = beta
        # Asymptotic covariance is inverse Fisher Information = (-H)^-1
        self.cov_matrix = np.linalg.inv(-hessian)
        self.se = np.sqrt(np.diagonal(self.cov_matrix))
        self.p_fitted = 1.0 / (1.0 + np.exp(-np.clip(X @ beta, -30, 30)))
        self.X_design = X
        self.y = y

    def summary(self, feature_names=None):
        if feature_names is None:
            feature_names = [f"x{i}" for i in range(len(self.beta))]
            if self.add_intercept:
                feature_names[0] = "Intercept"

        z_scores = self.beta / self.se
        p_values = 2.0 * (1.0 - stats.norm.cdf(np.abs(z_scores)))
        odds_ratios = np.exp(self.beta)
        or_ci_lower = np.exp(self.beta - 1.96 * self.se)
        or_ci_upper = np.exp(self.beta + 1.96 * self.se)

        # Deviance
        eps = 1e-12
        p_safe = np.clip(self.p_fitted, eps, 1 - eps)
        model_deviance = -2.0 * np.sum(self.y * np.log(p_safe) + (1.0 - self.y) * np.log(1.0 - p_safe))
        
        y_mean = np.mean(self.y)
        null_deviance = -2.0 * np.sum(self.y * np.log(y_mean) + (1.0 - self.y) * np.log(1.0 - y_mean))
        g_stat = null_deviance - model_deviance
        df = len(self.beta) - 1
        p_model = 1.0 - stats.chi2.cdf(g_stat, df=df)

        print("=== Logistic Regression Statistical Summary ===")
        header = f"{'Variable':14s} | {'Coef':8s} | {'StdErr':8s} | {'z-value':8s} | {'p-value':8s} | {'OddsRatio':10s} | {'95% CI on OR':16s}"
        print(header)
        print("-" * len(header))
        for j, name in enumerate(feature_names):
            ci_str = f"[{or_ci_lower[j]:.3f}, {or_ci_upper[j]:.3f}]"
            row = f"{name:14s} | {self.beta[j]:8.4f} | {self.se[j]:8.4f} | {z_scores[j]:8.3f} | {p_values[j]:8.4f} | {odds_ratios[j]:10.4f} | {ci_str:16s}"
            print(row)

        print("-" * len(header))
        print(f"Null Deviance:     {null_deviance:.2f}")
        print(f"Residual Deviance: {model_deviance:.2f}")
        print(f"Model Chi-Square:  {g_stat:.2f} (df={df}, p-value = {p_model:.4e})")

# Demonstration on synthetic clinical trial data
# Outcome: Disease recovery (1 = yes, 0 = no)
# Predictor 1: Treatment dosage in mg
# Predictor 2: Patient baseline age in years
np.random.seed(42)
N = 250
dosage = np.random.uniform(1.0, 5.0, N)
age = np.random.normal(50.0, 10.0, N)

# True model: logit = -2.0 + 0.8 * dosage - 0.04 * age
true_logits = -2.0 + 0.8 * dosage - 0.04 * age
true_probs = 1.0 / (1.0 + np.exp(-true_logits))
recovery = np.random.binomial(1, true_probs)

X_data = np.column_stack([dosage, age])
model = LogisticRegressionInference(add_intercept=True)
model.fit(X_data, recovery)
model.summary(feature_names=["Intercept", "Dosage (mg)", "Age (years)"])

Common pitfalls

  • Interpreting Odds Ratios as relative risks: Odds Ratios only approximate Relative Risk when the baseline outcome is rare (< 5%); for common outcomes, Odds Ratios substantially exaggerate effect sizes.
  • The Hauck-Donner failure in Wald tests: With quasi-complete or perfect data separation, coefficients grow large while standard errors explode, causing Wald statistics to fall paradoxically to zero.
  • Adding Odds Ratios instead of multiplying: Odds Ratios operate on a multiplicative scale; two 1-unit increases multiply odds by OR^2, not 2*OR.

06 Check yourself

Q1In a logistic regression model, what does an estimated coefficient of beta_1 = 0.693 for a binary treatment variable imply?

Why: Because the link function is the log-odds, exponentiating the coefficient yields the odds multiplier: exp(0.693) = 2.0, meaning the odds of the outcome double under treatment.

Q2What paradoxical behaviour can occur in Wald tests when data exhibits near-perfect separation (the Hauck-Donner effect)?

Why: In separated data, the likelihood becomes flat asymptotically. The curvature (information) vanishes, driving standard errors to extreme values and causing Wald tests to fail. Profile likelihood or LR tests must be used instead.

Q3How is overall model significance evaluated in logistic regression?

Why: The difference G = D_null - D_model is a likelihood-ratio test statistic that follows a \chi^2 distribution with degrees of freedom equal to the number of non-intercept predictors.
