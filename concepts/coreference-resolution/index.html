Coreference Resolution: Mention Detection, Pairwise Scoring, and SpanBERT

Coreference resolution identifies mentions (spans of text) and partitions them into clusters referring to identical entities. Coreference encompasses diverse linguistic phenomena: anaphora (pronoun referring back to antecedent), cataphora (pronoun preceding referent), and apposition. Classic approaches rely on mention-pair classification or mention-ranking models evaluated across MUC, $B^3$, and CEAF metrics. Modern end-to-end neural systems (e.g. SpanBERT coref) jointly extract candidate spans and predict antecedent link probabilities without pipelined syntactic parsers.

01 The idea

Coreference Resolution groups all mentions in a text that refer to the same real-world entity into coherent equivalence clusters. Resolving pronouns ("she", "it"), noun phrases ("the company"), and proper names ("Alphabet") is vital for document comprehension, question answering, and automated summarisation.

Consider the sentence: "Dr Marie Curie visited Paris. She conducted research there because the city offered excellent laboratories." Who does "She" refer to? Marie Curie. What does "the city" and "there" refer to? Paris. Humans resolve these referential connections effortlessly. For a computer, however, "Marie Curie", "She", "Paris", "there", and "the city" are distinct strings of characters. If a question answering system is asked "Where did Marie Curie conduct research?", it cannot answer unless it connects "there" and "the city" back to "Paris". Coreference resolution solves this problem: it scans the document, identifies all noun phrases and pronouns (mentions), and links them into clusters that refer to the exact same underlying real-world entity.

In everyday terms

Imagine reading a detective novel where a character is referred to variably as "the inspector", "John", "he", "the veteran detective", and "the man in the raincoat". As a reader, your brain maintains a single mental dossier for this character, pinning each moniker onto the same bulletin board profile. Coreference resolution builds and maintains these entity dossiers computationally.

02 Step by step

  1. Extract candidate text spans: enumerate all contiguous word sequences up to a maximum span width (e.g. 10 tokens).
  2. Encode span representations: compute contextual token embeddings (SpanBERT) and apply self-attention pooling over internal span words.
  3. Prune candidate mentions: compute unary mention scores $s_m(i)$ and prune top spans to maintain $\lambda T$ candidates, discarding non-entity phrases.
  4. Score candidate antecedent pairs: compute relational pairwise compatibility scores $s(i, j)$ between surviving spans.
  5. Decode coreference clusters: assign each span to its highest scoring antecedent, linking spans into directed trees and taking transitive closures to form final entity clusters.
  6. Evaluate CoNLL metric: compute the unweighted average of MUC, $B^3$, and $\text{CEAF}_{\phi_4}$ F1 scores.

04 Key takeaways

  • Coreference resolution connects pronouns and variant noun phrases to their canonical real-world entity referents.
  • End-to-end models jointly score mention spans and pairwise antecedent links via contextual transformer encoders.
  • The standard CoNLL metric combines MUC, $B^3$, and CEAF scores to evaluate clustering fidelity across diverse entity types.

05 In code

python
import numpy as np

def resolve_coreference_toy(mentions, pairwise_matrix):
    """Clusters mentions into entities using antecedent link argmax."""
    N = len(mentions)
    clusters = {i: [i] for i in range(N)}
    parent = list(range(N))
    
    def find(i):
        if parent[i] == i:
            return i
        parent[i] = find(parent[i])
        return parent[i]
        
    def union(i, j):
        root_i = find(i)
        root_j = find(j)
        if root_i != root_j:
            parent[root_i] = root_j
            
    # For each mention i > 0, find best antecedent j < i
    for i in range(1, N):
        scores = pairwise_matrix[i, :i]
        best_j = np.argmax(scores)
        # Threshold for linking
        if scores[best_j] > 0.0:
            union(i, best_j)
            
    # Aggregate into clusters
    final_clusters = {}
    for i in range(N):
        root = find(i)
        if root not in final_clusters:
            final_clusters[root] = []
        final_clusters[root].append(mentions[i])
        
    return list(final_clusters.values())

# Mentions extracted from: "Marie Curie arrived in Paris. She loved the capital city."
mentions = [
    "Marie Curie",     # 0
    "Paris",           # 1
    "She",             # 2
    "the capital city" # 3
]

# Simulated pairwise affinity matrix (row = mention i, col = candidate antecedent j)
pairwise_scores = np.array([
    [ 0.0,  0.0,  0.0,  0.0],
    [-2.0,  0.0,  0.0,  0.0],
    [ 4.5, -3.0,  0.0,  0.0],  # "She" -> strong link to "Marie Curie"
    [-3.0,  5.2, -2.5,  0.0]   # "the capital city" -> strong link to "Paris"
])

clusters = resolve_coreference_toy(mentions, pairwise_scores)

print("Discovered Coreference Entity Clusters:")
for idx, cluster in enumerate(clusters, 1):
    print(f"  Cluster {idx}: {cluster}")

Common pitfalls

  • Conflating apposition or predicative nominals ("Barack Obama, the president") as separate entities rather than coreferent mentions of the same individual.
  • Evaluating models solely on pronoun resolution (Winograd schemas), ignoring complex nominal coreference chains involving lexical variation.
  • Suffering cubic computational complexity $\mathcal{O}(N^3)$ without span pruning; unrestricted pairwise comparison over all text spans explodes on long documents.

06 Check yourself

Q1What is the primary objective of coreference resolution?

Why: Coreference resolution clusters mentions (names, pronouns, definite noun phrases) across a text that refer to the identical underlying entity.

Q2What is the official CoNLL evaluation score for coreference resolution systems?

Why: The standard CoNLL metric averages the F1 scores of three complementary clustering metrics: MUC (link-based), $B^3$ (mention-based), and $\text{CEAF}_{\phi_4}$ (entity-based).

Q3Why does SpanBERT achieve superior performance over standard BERT on coreference resolution tasks?

Why: SpanBERT masks contiguous spans of tokens and introduces a span boundary objective (SBO), training representations to summarise full multi-word mentions from their boundary tokens.
