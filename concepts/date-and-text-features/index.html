Date and Text Features: Engineering Tabular Signals from Unstructured Inputs

Extracting high-value cyclical calendar signals and bag-of-words or embedding representations for tabular machine learning models.

01 The idea

Tabular machine learning models cannot directly process raw timestamps or free-form text strings. Converting calendar timestamps into cyclical trigonometric components and holiday indicators, while extracting term statistics, TF-IDF weights, or dense pretrained embeddings from text fields, unlocks high-signal tabular predictors without full deep language model infrastructure.

Raw dates contain rich multi-scale periodicity: intraday hour (24-hour cycle), day of week (7-day cycle), day of month (payday effects), month of year (seasonal cycle), and boolean holiday flags.

Treating cyclical calendar variables as simple integers (e.g. mapping hours to $0, 1, \dots, 23$) introduces a severe false discontinuity: hour 23 and hour 0 appear 23 units apart despite being consecutive 60-minute neighbours. Sine and cosine trigonometric encodings $\sin(2\pi t / T)$ and $\cos(2\pi t / T)$ map time onto a smooth continuous 2D circle where 23:59 wraps seamlessly into 00:00.

Text fields in tabular datasets (product descriptions, customer support tickets, error logs) range from short categorical phrases to long paragraphs. Lightweight tabular text engineering uses token length, uppercase character ratios, punctuation counts, and n-gram TF-IDF representations.

Alternatively, passing short text through a small pretrained sentence transformer generates dense 384-dimensional embeddings, which can be compressed via TruncatedSVD or PCA into 8–16 dense numerical columns for gradient boosted decision trees.

In everyday terms

Imagine a shopkeeper tracking sales notes. A timestamp like "2026-12-25 09:30" means little to an arithmetic equation until separated into "Christmas Day", "Friday", "Morning rush", and "Month 12". Similarly, a customer review saying "the battery melted immediately" is useless as a string, but highly predictive once flagged with high-severity sentiment terms and n-gram keyword counts.

02 Step by step

  1. Calendar component decomposition: Extract year, month, day, day of week, day of year, hour, and is_weekend booleans from canonical UTC timestamps.
  2. Trigonometric cyclical encoding: Transform periodic variables (hour, day of week, month) into paired sine and cosine coordinates to preserve circle topology.
  3. Calendar event enrichment: Join country-specific public holiday calendars, commercial sales events (e.g. Black Friday), and financial reporting period closes.
  4. Text surface feature extraction: Compute character lengths, word counts, uppercase letter ratios, exclamation frequencies, and language identification.
  5. Dense text representation: Compute TF-IDF matrices (with n-gram range (1, 2) and minimum document frequency threshold) or SVD-reduced sentence embeddings, concatenating them with tabular feature arrays.

03 The maths

  1. Cyclical Periodic Coordinate Projection

    x_{\sin} = \sin\left(\frac{2\pi t}{T}\right), \quad x_{\cos} = \cos\left(\frac{2\pi t}{T}\right)

    Projects periodic index $t \in [0, T)$ onto the 2D unit circle, ensuring Euclidean distance between boundary values $t=0$ and $t=T-1$ reflects true temporal proximity.

  2. Circular Euclidean Distance Invariance

    \|(\sin\theta_1 - \sin\theta_2)^2 + (\cos\theta_1 - \cos\theta_2)^2\| = 2 - 2\cos(\theta_1 - \theta_2) = 4\sin^2\left(\frac{\theta_1 - \theta_2}{2}\right)

    The Euclidean distance between two points in projected sinusoidal space is a monotonic function of the angular difference along the cycle.

  3. Term Frequency-Inverse Document Frequency (TF-IDF)

    \mathrm{tfidf}(t, d, D) = \mathrm{tf}(t, d) \times \ln\left(\frac{1 + |D|}{1 + |\{d \in D : t \in d\}|}\right) + 1

    Measures the informational specificity of token $t$ in document $d$ relative to the entire tabular corpus $D$.

04 Key takeaways

  • Trigonometric sine/cosine encodings eliminate artificial boundary gaps between consecutive cyclical times (e.g. 23:59 and 00:00).
  • Decomposing dates into hierarchical calendar units (day of week, holiday flag, quarter) reveals seasonality to tree algorithms.
  • Text fields can be efficiently represented using word counts, TF-IDF weights, or SVD-reduced sentence embeddings.
  • Always fit text vectorisers and normalisers exclusively on training data to prevent out-of-fold vocabulary leakage.

05 In code

python
import numpy as np
import pandas as pd
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.decomposition import TruncatedSVD

# Sample tabular data with timestamps and customer support notes
df = pd.DataFrame({
    'timestamp': pd.to_datetime([
        '2026-01-01 23:45:00',
        '2026-01-02 00:15:00',
        '2026-07-15 14:30:00'
    ]),
    'ticket_text': [
        'Payment gateway returned fatal timeout error',
        'Unable to complete purchase during checkout timeout',
        'How do I update my profile mailing address'
    ]
})

# 1. Cyclical hour encoding
hours = df['timestamp'].dt.hour + df['timestamp'].dt.minute / 60.0
df['hour_sin'] = np.sin(2 * np.pi * hours / 24.0)
df['hour_cos'] = np.cos(2 * np.pi * hours / 24.0)

# 2. Text feature extraction: character count and TF-IDF
df['text_len'] = df['ticket_text'].str.len()
tfidf = TfidfVectorizer(max_features=10, stop_words='english')
tfidf_matrix = tfidf.fit_transform(df['ticket_text'])

# Reduce text dimensionality for tabular inclusion
svd = TruncatedSVD(n_components=2, random_state=42)
text_dense = svd.fit_transform(tfidf_matrix)
df['text_svd_1'] = text_dense[:, 0]
df['text_svd_2'] = text_dense[:, 1]

print(df[['hour_sin', 'hour_cos', 'text_len', 'text_svd_1']])
# Observe hour 23:45 and 00:15 have nearly identical trigonometric coordinates

Common pitfalls

  • Using only sine without cosine: Sine alone creates an ambiguous mapping where two distinct times of day (e.g. 06:00 and 18:00) share the exact same value.
  • High-dimensional sparse text vectors in tree models: Passing raw 50,000-column TF-IDF matrices to LightGBM or XGBoost causes memory thrashing; reduce via SVD first.
  • Ignoring local time when calculating "hour of day": UTC 02:00 corresponds to mid-morning in Tokyo but late evening in London.

06 Check yourself

Q1Why is it necessary to include both sine and cosine terms when cyclically encoding hours of the day?

Why: The sine function is non-monotonic on $[0, 2\pi)$, producing identical values for distinct hours (e.g. $\sin(\pi/4) = \sin(3\pi/4)$). Paired sine and cosine coordinates uniquely identify every point on the circle.

Q2What is the most effective way to include free-text descriptions into a gradient boosted tree model alongside tabular columns?

Why: Gradient boosted trees handle a moderate number of continuous dense signals well. Compressing text representations with SVD or sentence embeddings preserves semantic variance without overwhelming tree splits.

Q3What issue arises when integer encoding the month of the year (1 to 12) in distance-based algorithms like k-NN?

Why: In linear integer encoding, 12 and 1 have an artificial distance of 11, obscuring winter seasonality across year boundaries.
