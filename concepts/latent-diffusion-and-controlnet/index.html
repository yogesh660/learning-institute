01 The idea

Pixel-space diffusion models generate breathtaking visual fidelity, but denoising thousands of high-resolution RGB pixels directly is computationally agonizing: generating a single image requires hundreds of seconds on high-end GPUs. Latent Diffusion Models (LDM / Stable Diffusion; Rombach et al., 2022) shift the diffusion process into a perceptually compressed latent space. ControlNet (Zhang et al., 2023) then adds precise spatial conditioning (edges, poses, depth), unlocking controllable visual synthesis.

Digital images contain massive perceptual redundancy: high-frequency noise that the human eye barely notices consumes 90% of pixel compute. Latent Diffusion Models decouple generation into two stages: Perceptual Compression (handled by an autoencoder / VAE) and Semantic Generation (handled by a latent diffusion U-Net).

The VAE compresses an image $x \in \mathbb{R}^{3 \times H \times W}$ by an $8\times$ spatial downsampling factor into a low-dimensional latent representation $z \in \mathbb{R}^{4 \times (H/8) \times (W/8)}$, cutting compute volume by $64\times$.

The diffusion process (forward noising and reverse denoising) operates entirely within this compact latent space $z$. Cross-attention mechanisms inside the U-Net inject text prompts encoded by CLIP or T5.

Standard text-to-image diffusion lacks spatial control: prompt engineering ("a person jumping") cannot dictate exact hand positions or camera angles. ControlNet clones the trainable U-Net encoder weights, applies "zero convolutions" (convolutions initialised with zero weights and biases), and injects spatial conditions (Canny edges, depth maps, OpenPose human skeletons) without disrupting the original model's generative prior.

In everyday terms

Imagine a painter creating a mural. Working in pixel space is like carving microscopic details into millions of individual grains of sand. Working in latent diffusion is like drawing a compressed, high-level artist's cartoon sketch where one stroke captures an entire cheekbone. ControlNet acts as an architect's blue tracing paper laid over the sketch: it locks down the exact structural lines and proportions so the painter can add colours and textures without altering the pose.

02 Step by step

  1. Perceptual compression: Encode training image $x$ into compact latent representation $z_0 = \mathcal{E}(x)$ using a pretrained VAE encoder.
  2. Forward latent noising: Sample timestep $t \sim \mathcal{U}(1, T)$ and Gaussian noise $\epsilon$; add noise to latent: $z_t = \sqrt{\bar{\alpha}_t} z_0 + \sqrt{1 - \bar{\alpha}_t} \epsilon$.
  3. Encode conditioning signals: Encode text prompt via CLIP text encoder into cross-attention sequence; encode spatial guide (e.g. Canny edge map) via ControlNet encoder.
  4. Denoise via U-Net: Predict added noise $\epsilon_\theta(z_t, t, c_{\mathrm{text}}, c_{\mathrm{control}})$ using cross-attention and zero-convolution residuals.
  5. Reverse sampling: Iteratively denoise latent from pure Gaussian noise $z_T \sim \mathcal{N}(0, \mathbf{I})$ down to clean latent $z_0$ using fast ODE solvers (DDIM, DPM-Solver) in 20–30 steps.
  6. Decode to pixel space: Reconstruct high-resolution RGB image through VAE decoder: $\hat{x} = \mathcal{D}(z_0)$.

03 The maths

  1. Latent Diffusion Mean Squared Error Objective

    \mathcal{L}_{\mathrm{LDM}} = \mathbb{E}_{\mathcal{E}(x), \; \epsilon \sim \mathcal{N}(0, \mathbf{I}), \; t}\left[ \left\| \epsilon - \epsilon_\theta\left( z_t, \; t, \; \tau_\theta(y) \right) \right\|^2 \right]

    Trains U-Net $\epsilon_\theta$ to predict the noise added to compressed latent $z_t$, conditioned on text prompt embedding $\tau_\theta(y)$.

  2. ControlNet Zero-Convolution Formulation

    \mathbf{y}_{\mathrm{ctrl}} = \mathcal{F}(\mathbf{x}; \; \Theta) + \mathcal{Z}\left( \mathcal{F}_{\mathrm{clone}}\left( \mathbf{x} + \mathcal{Z}(\mathbf{c}; \; \Theta_{z1}); \; \Theta_{\mathrm{clone}} \right); \; \Theta_{z2} \right)

    Zero convolutions $\mathcal{Z}$ start with weights and biases initialized to exact zero, ensuring ControlNet outputs zero initially and preserves base model capability.

  3. Classifier-Free Guidance (CFG) Latent Extrapolation

    \tilde{\epsilon}_\theta(z_t, c) = \epsilon_\theta(z_t, \varnothing) + s \cdot \left( \epsilon_\theta(z_t, c) - \epsilon_\theta(z_t, \varnothing) \right), \quad s > 1.0

    Pushes the predicted noise vector away from the unconditional prediction $\varnothing$ towards the conditioned prompt $c$ by guidance scale $s$.

04 Key takeaways

  • Latent Diffusion compresses images into compact latent space via a VAE, cutting compute by $64\times$.
  • The diffusion denoising U-Net operates entirely within latent space, conditioned on text via cross-attention.
  • ControlNet adds structural spatial conditioning (depth, edges, human pose) to pretrained diffusion models.
  • Zero convolutions preserve base model generation capabilities at step zero, enabling stable progressive fine-tuning.

05 In code

python
import torch
import torch.nn as nn

class ZeroConv2d(nn.Module):
    """Zero-convolution layer used in ControlNet: initialized to exact zero."""
    def __init__(self, channels: int):
        super().__init__()
        self.conv = nn.Conv2d(channels, channels, kernel_size=1)
        # Initialize weights and bias strictly to zero!
        nn.init.zeros_(self.conv.weight)
        nn.init.zeros_(self.conv.bias)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return self.conv(x)

# Demonstrate ControlNet residual injection without initial disruption
x_latent = torch.randn(1, 64, 32, 32)
condition_map = torch.randn(1, 64, 32, 32)  # E.g. Canny edge embedding

zero_conv = ZeroConv2d(channels=64)
# At step 0 of training, zero_conv output is strictly zero!
control_signal = zero_conv(condition_map)

# Residual addition preserves base model state perfectly
fused_latent = x_latent + control_signal
assert torch.equal(x_latent, fused_latent), "Zero convolution must produce zero output at initialization!"
print("Zero convolution verified: Base model functions identically at step 0!")

Common pitfalls

  • VAE decoding compression artifacts: If the VAE compression factor is set too aggressive (e.g. $f=32$), fine textures (human fingers, small text) cannot be reconstructed by the decoder.
  • High guidance scale saturation: Setting Classifier-Free Guidance (CFG) scale $s > 15$ causes severe over-saturation, contrast clipping, and unnatural plastic skin artifacts.
  • Conditioning mismatch in ControlNet: Providing a condition resolution that does not match the image aspect ratio stretches spatial features, distorting generated anatomy.

06 Check yourself

Q1Why does Latent Diffusion (Stable Diffusion) run significantly faster than pixel-space diffusion models like DALL-E 1?

Why: Pixel diffusion processes $3 \times 512 \times 512 = 786,432$ values per step. Latent diffusion processes $4 \times 64 \times 64 = 16,384$ values—a 48x reduction in tensor size.

Q2What is the purpose of "Zero Convolutions" in the ControlNet architecture?

Why: By initializing weights and biases to zero, ControlNet outputs zero on day one, guaranteeing that training begins from the stable base model state without harmful weight destruction.

Q3What role does Classifier-Free Guidance (CFG) play during latent diffusion reverse sampling?

Why: CFG computes predictions with and without the prompt, extrapolating along the difference vector: $\epsilon = \epsilon_{\mathrm{uncond}} + s(\epsilon_{\mathrm{cond}} - \epsilon_{\mathrm{uncond}})$.
