Promptable Foundation Models for Vision: Segment Anything (SAM)

Zero-shot promptable visual segmentation using heavyweight image encoders, interactive prompt conditioning (points, boxes, text), and lightweight real-time mask decoders.

01 The idea

Traditionally, image segmentation models were trained for narrow closed vocabularies: an autonomous vehicle model segmenting 19 urban driving classes could not segment a medical cell or a manufacturing screw. The Segment Anything Model (SAM; Kirillov et al., Meta AI, 2023) established the first general-purpose visual foundation model for segmentation: capable of zero-shot segmentation of any arbitrary object via interactive prompts (points, bounding boxes, or rough masks).

SAM reframes segmentation as a Promptable Task: given an image and any prompt (foreground/background positive/negative click points, bounding boxes, or coarse masks), the model must return a valid segmentation mask.

To enable real-time web browser interaction ($< 50$ms), SAM decouples computation into two asymmetric stages: 1) Heavyweight Image Encoder: a massive Vision Transformer (ViT-H with 632M parameters) runs once per image on the server, generating an information-dense image embedding; 2) Lightweight Mask Decoder: runs in under 50ms (even on client CPU/WebGL), cross-attending prompt tokens with the precomputed image embedding.

Resolving Ambiguity: When a user clicks on a person's wrist wearing a watch, does the click prompt mean the watch dial, the entire watch, or the person? SAM solves ambiguity by predicting three valid candidate masks simultaneously (sub-part, part, whole), along with estimated IoU confidence scores.

Data Engine: SAM was trained on the SA-1B dataset—over 1.1 billion high-quality masks across 11 million diverse images—using an iterative data engine (model-assisted annotation $\to$ semi-automatic annotation $\to$ fully automatic grid annotation).

In everyday terms

Imagine a master woodcarver with a magic chisel. Instead of carving only wooden horses, the chisel responds to simple pointing gestures: you point your finger at an eagle in a block of oak (point prompt) or draw a rough chalk box around a tree branch (bounding box prompt), and the chisel instantly carves out the exact, millimetre-perfect 3D boundary in under 50 milliseconds.

02 Step by step

  1. Precompute image embedding (Heavyweight Encoder): Pass $1024 \times 1024$ image through Vision Transformer (ViT) to extract a $64 \times 64 \times 256$ spatial feature embedding (run once).
  2. Encode interactive prompt (Prompt Encoder): Represent point clicks as positional encodings plus learned positive/negative embeddings; represent bounding boxes as corner coordinate pairs.
  3. Two-way cross-attention (Lightweight Decoder): Run two-way cross-attention blocks where prompt tokens attend to image embeddings and image embeddings attend to prompt tokens.
  4. Predict multi-mask ambiguity outputs: Emit three candidate masks at different semantic hierarchies (e.g. subpart, part, whole) via transposed convolutions.
  5. Compute IoU confidence score: A dedicated MLP head predicts the expected Intersection-over-Union (IoU) of each predicted mask with the true object.
  6. Interactive refinement: Allow users to click additional points to correct ambiguous boundaries, updating the mask in real time.

03 The maths

  1. SAM Promptable Multi-Mask Loss Formulation

    \mathcal{L}_{\mathrm{SAM}} = \min_{k \in \{1, 2, 3\}} \left[ 20 \cdot \mathcal{L}_{\mathrm{focal}}(m_k, y) + \mathcal{L}_{\mathrm{dice}}(m_k, y) \right] + \| \mathrm{IoU}_k - \operatorname{IoU}(m_k, y) \|^2

    Computes focal loss and Dice loss strictly against the best-matching predicted mask $k$, backpropagating error through the most accurate hierarchy level.

  2. Positional Prompt Coordinate Embedding

    \mathbf{e}_{\mathrm{point}} = \operatorname{PosEmbed}(x, y) + \mathbf{w}_{\mathrm{type}}, \quad \mathbf{w}_{\mathrm{type}} \in \{\mathbf{w}_{\mathrm{pos}}, \; \mathbf{w}_{\mathrm{neg}}\}

    Encodes spatial click coordinates $(x, y)$ using Fourier sinusoidal positional embeddings combined with learned positive/negative category tokens.

  3. Dice Similarity Loss for Mask Boundaries

    \mathcal{L}_{\mathrm{dice}}(p, y) = 1 - \frac{2 \sum_i p_i y_i + \epsilon}{\sum_i p_i + \sum_i y_i + \epsilon}

    Measures spatial overlap between predicted sigmoid probabilities $p$ and binary ground truth $y$, robust against extreme background pixel imbalance.

04 Key takeaways

  • SAM established promptable zero-shot foundation models for visual segmentation.
  • Asymmetric architecture: heavy ViT image encoder runs once; lightweight mask decoder runs in $<50$ms.
  • Supports diverse interactive prompts: foreground/background clicks, bounding boxes, or text.
  • Resolves semantic ambiguity by predicting three hierarchical masks (subpart, part, whole) with IoU scores.

05 In code

python
import torch
import torch.nn as nn
import torch.nn.functional as F

class MiniSAMDecoder(nn.Module):
    """Educational demonstration of SAM's lightweight prompt-conditioned mask decoder."""
    def __init__(self, embed_dim: int = 256, num_masks: int = 3):
        super().__init__()
        self.num_masks = num_masks
        # Cross-attention layer between prompt tokens and image embeddings
        self.cross_attn = nn.MultiheadAttention(embed_dim, num_heads=8, batch_first=True)
        # Transpose convolution to upsample 64x64 embedding -> 256x256 mask logits
        self.upsample = nn.Sequential(
            nn.ConvTranspose2d(embed_dim, 64, kernel_size=2, stride=2),
            nn.ReLU(),
            nn.ConvTranspose2d(64, num_masks, kernel_size=2, stride=2)
        )

    def forward(self, image_embedding: torch.Tensor, prompt_tokens: torch.Tensor):
        # image_embedding: [batch, 256, 64, 64]
        # prompt_tokens:   [batch, num_prompts, 256] (e.g. click coordinates)
        batch, c, h, w = image_embedding.shape
        img_flat = image_embedding.flatten(2).permute(0, 2, 1)  # [batch, 4096, 256]
        
        # Cross-attention: prompt queries attend to image keys/values
        attn_out, _ = self.cross_attn(query=prompt_tokens, key=img_flat, value=img_flat)
        
        # Modulate image embedding with prompt summary
        prompt_summary = attn_out.mean(dim=1).view(batch, c, 1, 1)
        modulated_feat = image_embedding + prompt_summary
        
        # Emit 3 hierarchical candidate masks (subpart, part, whole)
        masks = self.upsample(modulated_feat)  # [batch, 3, 256, 256]
        return masks

# Simulate real-time inference: Precomputed image embedding + 1 user click prompt
decoder = MiniSAMDecoder(embed_dim=256, num_masks=3)
img_emb = torch.randn(1, 256, 64, 64)       # Computed once on server
click_prompt = torch.randn(1, 1, 256)        # Single user click

out_masks = decoder(img_emb, click_prompt)
print(f"Precomputed server embedding: {img_emb.shape}")
print(f"Interactive decoder mask shape: {out_masks.shape} (3 hierarchical candidates)")
print("Decoder runs in <50ms per user interaction!")

Common pitfalls

  • Re-running the heavy image encoder on every click: The 632M parameter ViT encoder takes 200–500ms; caching the $64 \times 64$ embedding is mandatory for interactive real-time prompt updates.
  • Semantic classification absence: SAM predicts pure object boundaries (class-agnostic binary masks); it does not assign semantic class labels (e.g. "dog", "car"); pair with CLIP for semantic labelling.
  • Transparent or camouflaged objects: SAM struggles with objects with subtle refractive boundaries (clear glass windows, transparent bottles) where contrast edges are minimal.

06 Check yourself

Q1Why does the Segment Anything Model (SAM) decouple its architecture into a heavy image encoder and a lightweight mask decoder?

Why: The image embedding is computed once and cached. When a user clicks to add points, only the tiny decoder runs, allowing instant real-time response.

Q2How does SAM handle semantic ambiguity when a user clicks on an object that could mean a part or the whole (e.g. clicking on a car tire)?

Why: Ambiguity is intrinsic to promptable segmentation. SAM outputs 3 masks at different semantic levels (e.g. tire rim, tire, full car) so users or downstream logic can pick the right level.

Q3Does SAM natively predict semantic class labels (such as "cat", "chair", or "bicycle") for its segmented masks?

Why: SAM is class-agnostic: it identifies "what is an object" and cuts out its contour. Semantic labeling is achieved by cropping the mask and querying an open-vocabulary model like CLIP.
