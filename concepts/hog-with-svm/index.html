01 The idea

Before deep convolutional networks achieved dominance on ImageNet, the Histogram of Oriented Gradients (HOG) paired with a Linear Support Vector Machine (Dalal & Triggs, 2005) was the gold standard for pedestrian and object detection. By capturing localized edge direction distributions invariant to illumination changes, HOG provides a fast, interpretable descriptor that remains widely used in real-time embedded vision and robotics.

The central premise of HOG is that local object appearance and shape can be characterized by the distribution of local intensity gradients, even without precise knowledge of the underlying pixel values.

The image is divided into small connected spatial cells (e.g. $8 \times 8$ pixels). For every pixel in a cell, the horizontal and vertical gradients are computed via 1D centered point derivatives $[-1, 0, 1]$. The gradient magnitude acts as a vote, and the gradient orientation determines which orientation bin (typically 9 bins from $0^\circ$ to $180^\circ$, unsigned) receives the vote.

To provide invariance to illumination and shadowing, adjacent cells are grouped into larger spatial blocks (e.g. $2 \times 2$ cells of $16 \times 16$ pixels). The concatenated cell histograms within a block are normalised using $L_2$-norm with clipping ($L_2$-Hys), creating robust, contrast-invariant block descriptors.

A dense multi-scale sliding window detector slides a fixed-size detection window (e.g. $64 \times 128$ pixels) across an image pyramid, scoring each window with a pre-trained Linear SVM $w^T x + b > 0$. Overlapping detections are merged using Non-Maximum Suppression (NMS).

In everyday terms

Imagine drawing a quick charcoal sketch of a person walking. You do not need to shade in skin tones or cloth patterns; what makes a human instantly recognisable is the silhouette—the vertical lines of the torso and legs, the round curve of the head, and the diagonal angles of swinging arms. HOG captures this structural silhouette by tallying up the directions of edge strokes across small grid squares.

02 Step by step

  1. Gradient computation: Filter image with 1D horizontal and vertical kernels $[-1, 0, 1]$ and $[-1, 0, 1]^T$ to compute gradient magnitude $r$ and orientation $\theta$.
  2. Spatial cell histogram voting: Partition image into $8 \times 8$ pixel cells; vote gradient magnitudes into 9 angular orientation bins ($0^\circ$ to $180^\circ$) using bilinear interpolation.
  3. Block normalisation: Group cells into overlapping $2 \times 2$ blocks (16x16 pixels); compute $L_2$-norm over the 36-dimensional block vector and normalise to suppress contrast variations.
  4. Concatenate window descriptor: Concatenate all normalised block vectors across the $64 \times 128$ detection window (producing a 3,780-dimensional feature vector).
  5. Classify via Linear SVM: Compute dot product between feature vector and learned SVM hyperplane weights; score windows above threshold $\tau$.
  6. Non-Maximum Suppression (NMS): Filter out redundant overlapping bounding boxes, preserving only highest-confidence detections.

03 The maths

  1. Pixel Gradient Magnitude and Orientation

    r(x, y) = \sqrt{I_x(x, y)^2 + I_y(x, y)^2}, \quad \theta(x, y) = \arctan\left( \frac{I_y(x, y)}{I_x(x, y)} \right) \pmod{180^\circ}

    Computes edge intensity $r$ and unsigned angular orientation $\theta \in [0^\circ, 180^\circ)$ from directional image derivatives.

  2. Block L2-Hys Normalisation

    \mathbf{v}_{\mathrm{norm}} = \frac{\mathbf{v}}{\sqrt{\|\mathbf{v}\|_2^2 + \epsilon^2}}, \quad \tilde{v}_i = \min(v_{\mathrm{norm}, i}, \; 0.2), \quad \mathbf{v}_{\mathrm{final}} = \frac{\tilde{\mathbf{v}}}{\sqrt{\|\tilde{\mathbf{v}}\|_2^2 + \epsilon^2}}

    Normalises block feature vector $\mathbf{v}$, clips large outlier components at 0.2 to limit dominant gradient saturation, and re-normalises.

  3. Linear SVM Scoring Decision Boundary

    f(\mathbf{x}) = \mathbf{w}^T \mathbf{x} + b \ge 0 \implies \text{Object Detected}

    Evaluates the linear dot product between the concatenated 3,780-D HOG descriptor $\mathbf{x}$ and the SVM weight vector $\mathbf{w}$.

04 Key takeaways

  • HOG captures structural shape and silhouettes via local distributions of intensity gradient orientations.
  • Unsigned gradient bins ($0^\circ$ to $180^\circ$) capture edge orientation regardless of light/dark transition order.
  • Overlapping block normalisation provides robustness against illumination changes and shadows.
  • Paired with Linear SVM, HOG provides fast pedestrian detection without deep neural networks.

05 In code

python
import numpy as np

def compute_simple_hog_cell(cell_img: np.ndarray, num_bins: int = 9) -> np.ndarray:
    """Compute gradient orientation histogram for an 8x8 pixel cell."""
    # Compute 1D central differences
    gx = np.zeros_like(cell_img, dtype=np.float32)
    gy = np.zeros_like(cell_img, dtype=np.float32)
    
    gx[:, 1:-1] = cell_img[:, 2:] - cell_img[:, :-2]
    gy[1:-1, :] = cell_img[2:, :] - cell_img[:-2, :]
    
    mag = np.sqrt(gx**2 + gy**2)
    # Unsigned angle between 0 and 180 degrees
    angle = (np.arctan2(gy, gx) * 180.0 / np.pi) % 180.0
    
    # Vote into orientation bins
    hist = np.zeros(num_bins, dtype=np.float32)
    bin_width = 180.0 / num_bins
    
    for i in range(cell_img.shape[0]):
        for j in range(cell_img.shape[1]):
            b = int(angle[i, j] / bin_width) % num_bins
            hist[b] += mag[i, j]
            
    # L2 normalise cell histogram
    norm = np.linalg.norm(hist) + 1e-6
    return hist / norm

# Sample 8x8 cell with vertical edge
cell = np.zeros((8, 8), dtype=np.float32)
cell[:, 4:] = 255.0  # Sharp vertical edge in middle

hog_hist = compute_simple_hog_cell(cell, num_bins=9)
print("HOG 9-bin orientation histogram:")
print(np.round(hog_hist, 3))
print(f"Dominant orientation bin: {np.argmax(hog_hist)} (captures vertical gradient cleanly!)")

Common pitfalls

  • Scale sensitivity without image pyramids: HOG is not scale invariant; detecting pedestrians at various distances requires constructing a dense image pyramid.
  • Rigid deformation failure: HOG with a single linear SVM struggles with articulated human poses (sitting, crouching, jumping); requires Deformable Part Models (DPM).
  • Signed vs unsigned angles: Using signed angles ($0^\circ$ to $360^\circ$) degrades pedestrian detection because an edge transitioning from dark-to-light has the same structural meaning as light-to-dark.

06 Check yourself

Q1Why does HOG typically use "unsigned" gradient orientations ($0^\circ$ to $180^\circ$) rather than signed orientations ($0^\circ$ to $360^\circ$) for pedestrian detection?

Why: A dark shirt on a light wall has the opposite gradient sign of a light shirt on a dark wall. Unsigned gradients map both to the same orientation, capturing the invariant contour.

Q2What is the purpose of overlapping block normalisation in the HOG descriptor?

Why: In natural scenes, sunlight and shadows scale gradient magnitudes dramatically. Normalising overlapping blocks provides local photometric invariance.

Q3How does a HOG-based detector locate objects of different physical sizes in a photograph?

Why: HOG uses a fixed detection window ($64 \times 128$). Detecting objects at various scales requires resizing the image repeatedly into a scale-space image pyramid.
