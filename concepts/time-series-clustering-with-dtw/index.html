01 The idea

Euclidean distance fails on time series when temporal patterns are out of phase or stretched in duration. Dynamic Time Warping non-linearly aligns the time axes of two sequences to measure true morphological similarity.

When clustering temporal sequences—such as electrocardiogram (ECG) heartbeats, smart-meter energy consumption profiles, gesture accelerometry, or financial stock trajectories—standard distance metrics fail. Euclidean distance strictly pairs sample $x_i(t)$ with sample $x_j(t)$ at the identical time index $t$. If one heartbeat is delayed by 50 milliseconds, or if one speaker pronounces a vowel twice as slowly, Euclidean distance reports a colossal distance even though the underlying morphological shapes are identical.

Dynamic Time Warping (DTW) overcomes this rigid lock-step assumption by warping the time dimension non-linearly. It allows multiple consecutive points in one sequence to match a single point in another, accommodating local tempo variations, phase shifts, and differing sequence lengths.

The optimal alignment is determined via dynamic programming, constructing an $n \times m$ cost matrix where entry $(i, j)$ represents the minimal accumulated distance along a valid warping path from start $(1, 1)$ to end $(n, m)$. Valid paths must satisfy boundary conditions, monotonicity (time cannot flow backwards), and continuity (no time steps can be skipped).

To prevent pathological warping (where a single point in one sequence is matched to an entire plateau in another) and to accelerate computation from $O(n^2)$ to $O(n \cdot w)$, practitioners apply global window constraints like the Sakoe–Chiba band. When clustering collections of time series, k-means is adapted using DTW Barycentre Averaging (DBA) to iteratively compute the optimal average centroid sequence.

In everyday terms

Imagine comparing two musicians playing the identical trumpet solo. The first musician plays briskly in 4/4 time; the second plays with rubato, lingering on the high notes and rushing through the arpeggios. Comparing their sound waves sample-by-sample with Euclidean distance concludes they are playing completely different songs. Dynamic Time Warping acts like an expert conductor, stretching and compressing the time axis so each note aligns with its counterpart, recognising the identical melody.

03 The maths

  1. Dynamic Programming Recurrence

    D(i, j) = (x_i - y_j)^2 + \min \begin{cases} D(i - 1, j) & \text{(insertion / warp Y)} \\ D(i, j - 1) & \text{(deletion / warp X)} \\ D(i - 1, j - 1) & \text{(match)} \end{cases}

    Accumulated cost matrix recursion. Each step chooses the minimal cost preceding step to find the optimal global warping path.

  2. Warping Path Constraints

    W = (w_1, \dots, w_K), \quad w_1 = (1, 1), \; w_K = (n, m), \quad w_k = (i, j) \implies w_{k+1} \in \{(i+1, j), (i, j+1), (i+1, j+1)\}

    Enforces boundary conditions (paths must start at beginning and finish at end) and step size conditions (monotonicity and continuity).

  3. Sakoe–Chiba Warping Window Constraint

    |i - j| \le w

    Restricts the warping path to a corridor of width w around the main diagonal, preventing pathological time distortion and speeding up computation from O(nm) to O(nw).

04 Key takeaways

  • Non-linearly aligns temporal sequences to measure morphological similarity invariant to tempo changes and phase shifts.
  • Replaces rigid one-to-one Euclidean matching with one-to-many warping via dynamic programming in $O(n \cdot m)$ time.
  • Sakoe–Chiba band $|i - j| \le w$ prevents pathological distortions and accelerates calculation to $O(n \cdot w)$.
  • Clustering is performed using k-medoids (PAM) on precomputed distance matrices or k-means with DTW Barycentre Averaging (DBA).
  • Standard benchmark for human gesture recognition, sensor telemetry, ECG cardiology, and speech processing.

05 In code

python
import numpy as np

# Dynamic Time Warping (DTW) with Sakoe-Chiba Band from scratch
def dtw_distance(x, y, window=None):
    n, m = len(x), len(y)
    if window is None:
        window = max(n, m)
    else:
        window = max(window, abs(n - m))
        
    # Initialise cost matrix with infinity
    dtw_matrix = np.full((n + 1, m + 1), float('inf'))
    dtw_matrix[0, 0] = 0.0
    
    for i in range(1, n + 1):
        for j in range(max(1, i - window), min(m + 1, i + window + 1)):
            cost = (x[i - 1] - y[j - 1])**2
            dtw_matrix[i, j] = cost + min(
                dtw_matrix[i - 1, j],      # Insertion
                dtw_matrix[i, j - 1],      # Deletion
                dtw_matrix[i - 1, j - 1]   # Match
            )
            
    return np.sqrt(dtw_matrix[n, m])

# Generate synthetic time-series with phase shift and tempo differences
np.random.seed(42)
t = np.linspace(0, 4 * np.pi, 60)

# Class 1: Sine wave with random phase shifts
class1_series = [np.sin(t + np.random.uniform(-0.8, 0.8)) + np.random.normal(0, 0.1, len(t)) for _ in range(10)]

# Class 2: Square/Triangle wave
class2_series = [np.sign(np.sin(t + np.random.uniform(-0.8, 0.8))) + np.random.normal(0, 0.1, len(t)) for _ in range(10)]

all_series = class1_series + class2_series
N = len(all_series)

# Compute pairwise DTW distance matrix
dist_matrix = np.zeros((N, N))
for i in range(N):
    for j in range(i + 1, N):
        d = dtw_distance(all_series[i], all_series[j], window=10)
        dist_matrix[i, j] = d
        dist_matrix[j, i] = d

# Simple k-medoids clustering on DTW distance matrix
def k_medoids(dist_mat, k=2, max_iters=20):
    n = dist_mat.shape[0]
    # Initialise medoids randomly
    medoids = np.array([0, N - 1])
    labels = np.zeros(n, dtype=int)
    
    for _ in range(max_iters):
        # Assign samples to closest medoid
        labels = np.argmin(dist_mat[:, medoids], axis=1)
        # Update medoids
        new_medoids = medoids.copy()
        for cluster_id in range(k):
            members = np.where(labels == cluster_id)[0]
            if len(members) > 0:
                sub_dist = dist_mat[np.ix_(members, members)]
                best_member = members[np.argmin(np.sum(sub_dist, axis=1))]
                new_medoids[cluster_id] = best_member
        if np.array_equal(new_medoids, medoids):
            break
        medoids = new_medoids
    return labels, medoids

labels, medoids = k_medoids(dist_matrix, k=2)
true_labels = np.array([0]*10 + [1]*10)
clustering_acc = max(np.mean(labels == true_labels), np.mean(labels == (1 - true_labels)))

print(f"Total time series clustered: {N}")
print(f"DTW distance between phase-shifted identical waves: {dist_matrix[0, 1]:.3f}")
print(f"DTW distance between Sine and Square waves:        {dist_matrix[0, 10]:.3f}")
print(f"k-medoids Clustering Accuracy: {clustering_acc * 100:.1f}%")

Common pitfalls

  • Computational scaling: Pairwise DTW across $N$ time series of length $L$ requires $O(N^2 \cdot L^2)$ operations; LB_Keogh lower bounding is necessary for large datasets.
  • Pathological warping: Without a Sakoe-Chiba or Itakura window constraint, a flat plateau in one series can match dozens of peaks in another, producing artificially low distances.
  • Triangular inequality violation: Standard DTW does not strictly satisfy the triangle inequality, meaning DTW is technically a semi-metric rather than a true metric.

06 Check yourself

Q1Why does Euclidean distance perform poorly compared to DTW when comparing audio speech signals of the same word?

Why: Euclidean distance pairs points strictly by index t. If a speaker lingers on a syllable, waveforms fall out of phase, creating massive point-to-point Euclidean discrepancy.

Q2What is the purpose of enforcing a Sakoe–Chiba band constraint |i - j| <= w in DTW?

Why: The Sakoe-Chiba band restricts warping to a diagonal corridor of width w, preventing extreme time warping blunders and speeding up computation.
