01 The idea

Information theory formalises uncertainty by measuring how many bits are required to encode events drawn from a probability distribution. Shannon entropy quantifies the intrinsic unpredictability of a system, while cross-entropy measures the expected coding length when events from a true distribution are encoded using an estimated model. Cross-entropy serves as the standard loss function for training modern classification models and neural networks.

Imagine receiving daily weather forecasts for the Sahara Desert in July, where it is sunny 99% of days and rains 1%. A message stating "Tomorrow will be sunny" carries almost zero surprise—you could have guessed it with 99% accuracy before opening the email. But a message stating "Tomorrow will rain" carries enormous surprise and high information value.

Claude Shannon formalised this in 1948: an event with probability $p$ yields surprise (information content) proportional to $\log_2(1/p) = -\log_2(p)$ bits. A fair coin flip has $p = 0.5$, providing exactly $-\log_2(0.5) = 1$ bit of surprise. The expected surprise over all possible outcomes is the distribution's entropy $H(P)$. For a fair coin, entropy is $1.0$ bit (maximum uncertainty for two states). For a heavily biased coin with 90% heads and 10% tails, entropy drops to $-0.90\log_2(0.90) - 0.10\log_2(0.10) \approx 0.469$ bits. If a coin lands heads 100% of the time, entropy is $0$ bits—complete certainty.

Now suppose the true coin has $P(\text{Heads}) = 0.90$, but a machine learning model predicts $Q(\text{Heads}) = 0.60$. If we design a communication code optimised for the model's beliefs $Q$, the average number of bits required to transmit outcomes from reality $P$ is the cross-entropy $H(P, Q) = -0.90\log_2(0.60) - 0.10\log_2(0.40) \approx 0.796$ bits. Notice that $0.796 > 0.469$: using the wrong probability model wastes $0.327$ bits per message. Minimising cross-entropy forces the model $Q$ to match ground reality $P$.

In everyday terms

Entropy is the minimum storage space required to pack an uncompressed file; cross-entropy is the actual storage consumed when you compress the file using a compression dictionary tailored for a different language.

02 Step by step

  1. Define a discrete probability distribution $P$ over $K$ outcomes, ensuring non-negativity and $\sum p_k = 1$.
  2. Compute Shannon information content for each event: $I(x) = -\log_2(p(x))$ bits (or nats using natural logarithm).
  3. Calculate Shannon entropy $H(P) = -\sum p(x) \log p(x)$ as the expected information content across the distribution.
  4. For classification models predicting probabilities $Q$, compute cross-entropy $H(P, Q) = -\sum p(x) \log q(x)$.
  5. For one-hot ground truth labels where $p_c = 1$ for true class $c$, simplify cross-entropy to the negative log-likelihood $-\log q_c$.
  6. Compute gradients of cross-entropy loss with respect to model logits to train neural networks via gradient descent.

03 The maths

  1. Shannon Entropy

    $$H(P) = -\sum_{x \in \mathcal{X}} P(x) \log_2 P(x) = E_P[-\log_2 P(X)]$$

    Here $P(x)$ is the probability mass function. When using base 2 logarithm, entropy is measured in bits (shannons); when using natural logarithm $\ln$, it is measured in nats. For $K$ discrete outcomes, entropy is bounded: $0 \le H(P) \le \log_2 K$, achieving zero for deterministic events and maximum entropy for a uniform distribution.

  2. Cross-Entropy

    $$H(P, Q) = -\sum_{x \in \mathcal{X}} P(x) \log_2 Q(x) = E_P[-\log_2 Q(X)]$$

    Here $P(x)$ is the true reference distribution and $Q(x)$ is the approximating model distribution. Cross-entropy quantifies the average number of bits required to encode data from $P$ when using an encoding scheme optimised for $Q$. By Gibbs' inequality, $H(P, Q) \ge H(P)$, with equality if and only if $Q = P$.

  3. Categorical Cross-Entropy Loss in Machine Learning

    $$\mathcal{L}_{\text{CE}} = -\sum_{k=1}^K y_k \ln \hat{y}_k = -\ln \hat{y}_{\text{true}}$$

    In supervised classification, the ground truth distribution $\mathbf{y}$ is a one-hot vector where $y_c = 1$ for the true class and $y_k = 0$ for all $k \ne c$. Cross-entropy simplifies directly to the negative log-likelihood of the true class under model softmax predictions $\hat{\mathbf{y}}$, establishing that minimising cross-entropy is equivalent to maximum likelihood estimation.

04 Key takeaways

  • Entropy measures the fundamental unpredictability of a probability distribution; uniform distributions maximise entropy, while deterministic outcomes minimise it to zero.
  • Cross-entropy measures the expected coding length when reality follows $P$ but messages are compressed using a model distribution $Q$.
  • In machine learning, minimising cross-entropy loss is mathematically identical to maximising the likelihood of the training labels.
  • The difference between cross-entropy and entropy is the Kullback–Leibler divergence: $H(P, Q) = H(P) + D_{\text{KL}}(P \parallel Q)$.

05 In code

python
import numpy as np

# True distribution P vs approximating model Q
p = np.array([0.70, 0.20, 0.10])
q = np.array([1.0 / 3.0, 1.0 / 3.0, 1.0 / 3.0])

# Shannon entropy H(P) in bits
entropy_p = -np.sum(p * np.log2(p))

# Cross-entropy H(P, Q) in bits
cross_entropy_pq = -np.sum(p * np.log2(q))
divergence_bits = cross_entropy_pq - entropy_p

# Binary cross-entropy in nats (standard ML classification loss)
y_true = np.array([1, 0, 1, 1])
y_prob = np.array([0.92, 0.15, 0.78, 0.65])
bce = -np.mean(y_true * np.log(y_prob) + (1 - y_true) * np.log(1.0 - y_prob))

print(f"Entropy H(P):         {entropy_p:.4f} bits")
print(f"Cross-Entropy H(P,Q): {cross_entropy_pq:.4f} bits")
print(f"Excess code length:   {divergence_bits:.4f} bits")
print(f"Sample Binary CE loss: {bce:.4f} nats")

Common pitfalls

  • Taking the logarithm of zero when model predicted probabilities reach exact 0.0; always clamp probabilities with an epsilon $\epsilon \approx 10^{-15}$.
  • Mixing up base 2 logarithms (bits) with natural logarithms (nats); machine learning libraries universally compute losses in nats.
  • Confusing entropy with variance: high-variance continuous variables can have low differential entropy if concentrated into disjoint sharp spikes.
  • Assuming cross-entropy is symmetric: $H(P, Q) \ne H(Q, P)$ because expectations are taken with respect to different reference distributions.

06 Check yourself

Q1What probability distribution over $K$ discrete outcomes achieves the maximum possible Shannon entropy?

Why: When all $K$ outcomes are equally likely, uncertainty is maximised and entropy reaches its upper bound $H(P) = \log_2 K$.

Q2Why is minimising categorical cross-entropy the standard objective for training classification neural networks?

Why: For one-hot target vectors, cross-entropy reduces to $-\ln \hat{y}_{\text{true}}$, which is the negative log-likelihood. Minimising it is exact maximum likelihood estimation.

Q3What is the relationship connecting entropy $H(P)$, cross-entropy $H(P, Q)$, and Kullback–Leibler divergence $D_{\text{KL}}(P \parallel Q)$?

Why: Cross-entropy decomposes into the intrinsic entropy of reality $H(P)$ plus the inefficiency penalty $D_{\text{KL}}(P \parallel Q)$ caused by approximating $P$ with $Q$.

Q4If a fair coin flip has entropy $H = 1.0$ bit, what is the entropy of a completely rigged coin that always lands heads?

Why: When an outcome is certain ($p = 1$), there is zero surprise: $-1 \log_2(1) = 0$ bits.
