Evaluating Embeddings: Similarity, Analogy, and Cultural Bias

Intrinsic evaluation tests geometrical consistency (word similarity datasets, analogy arithmetic), whereas extrinsic evaluation measures downstream task metrics (NER, classification). Word similarity tasks (WordSim-353, SimLex-999) evaluate Spearman rank correlation $\rho$ between human ratings and vector cosine distances. Analogy completion ($\\mathbf{v}_{\\text{king}} - \\mathbf{v}_{\\text{man}} + \\mathbf{v}_{\\text{woman}} \\approx \\mathbf{v}_{\\text{queen}}$) tests linear relational substructures. Bias audits (WEAT, SEAT) quantify cultural, racial, and gender stereotypical associations reflected in cosine geometry.

01 The idea

Evaluating representation quality in vector spaces requires balancing intrinsic geometric benchmarks and extrinsic downstream performance. Intrinsic metrics like word similarity correlation and vector analogies assess semantic structure, while quantitative audits—such as the Word Embedding Association Test (WEAT)—uncover harmful societal biases encoded within distributional geometries.

When you train word or sentence embeddings, how do you know if the resulting vector space is good? There are two primary evaluation philosophies: intrinsic and extrinsic. Extrinsic evaluation measures how well the embeddings perform as features in an actual end-to-end task, such as document classification or entity recognition. Intrinsic evaluation, on the other hand, probes the geometric properties of the vector space directly: do synonyms sit near each other (similarity)? Can vector arithmetic solve relationships like "Paris is to France as Tokyo is to Japan" (analogy)? Crucially, because embeddings learn from human web text, they also internalize human prejudices. Bias testing evaluates whether neutral professions (e.g. "doctor", "nurse") exhibit illicit geometric proximity to specific demographic terms ("he", "she"), enabling debiasing before deployment.

In everyday terms

Evaluating a vector space is like testing a newly forged optical lens. Intrinsic evaluation tests the lens in a laboratory for chromatic aberration, focal sharpness, and distortion. Extrinsic evaluation puts the lens on an actual satellite camera to see if it takes crisp photos of the earth. Bias evaluation checks if the lens has an unwanted colour tint that distorts the true hues of the landscape.

02 Step by step

  1. Select intrinsic benchmark datasets: choose semantic similarity datasets (SimLex-999, MEN) and relational analogy datasets (Google Analogy Test).
  2. Compute cosine similarities: calculate pairwise cosine similarities for all word pairs in the benchmark.
  3. Evaluate Spearman correlation: rank model scores against human annotator ratings and compute rank-order correlation $\rho$.
  4. Evaluate analogy accuracy: solve 3CosAdd vector equations and measure top-1 retrieval accuracy.
  5. Execute WEAT bias audit: define target concept sets and demographic attribute sets to compute effect size $d$ and permutation p-values.

04 Key takeaways

  • Intrinsic evaluation probes semantic geometry via word similarity rankings and linear relational vector analogies.
  • SimLex-999 separates genuine semantic similarity from loose topical association, offering a more rigorous test than older relatedness datasets.
  • Auditing vector geometries with tests like WEAT is critical for detecting and mitigating societal bias prior to real-world deployment.

05 In code

python
import numpy as np

def cosine_similarity(u, v):
    """Computes cosine similarity between two vectors."""
    norm = np.linalg.norm(u) * np.linalg.norm(v)
    return np.dot(u, v) / max(norm, 1e-8)

def evaluate_analogy(vectors, a, b, c):
    """Computes 3CosAdd analogy: b - a + c ~ d."""
    target = vectors[b] - vectors[a] + vectors[c]
    best_word = None
    best_sim = -float('inf')
    
    for word, vec in vectors.items():
        if word in (a, b, c):
            continue
        sim = cosine_similarity(target, vec)
        if sim > best_sim:
            best_sim = sim
            best_word = word
            
    return best_word, best_sim

def weat_effect_size(vectors, X, Y, A, B):
    """Calculates WEAT effect size d between targets X, Y and attributes A, B."""
    def s(w):
        sim_A = np.mean([cosine_similarity(vectors[w], vectors[a]) for a in A])
        sim_B = np.mean([cosine_similarity(vectors[w], vectors[b]) for b in B])
        return sim_A - sim_B
        
    scores_X = [s(x) for x in X]
    scores_Y = [s(y) for y in Y]
    all_scores = scores_X + scores_Y
    
    diff = np.mean(scores_X) - np.mean(scores_Y)
    pooled_std = np.std(all_scores) + 1e-8
    return diff / pooled_std

# Simulated 4D embedding space
np.random.seed(42)
embeddings = {
    "king": np.array([1.0, 0.8, 0.1, 0.2]),
    "man": np.array([0.9, 0.1, 0.1, 0.1]),
    "woman": np.array([0.1, 0.9, 0.1, 0.1]),
    "queen": np.array([0.2, 1.6, 0.1, 0.2]),
    "programmer": np.array([0.8, 0.2, 0.9, 0.1]),
    "homemaker": np.array([0.1, 0.8, 0.1, 0.8])
}

# 1. Analogy completion
d_pred, score = evaluate_analogy(embeddings, "man", "king", "woman")
print(f"Analogy: 'man' is to 'king' as 'woman' is to -> '{d_pred}' (sim: {score:.3f})")

# 2. WEAT Bias Audit (Target: Career vs Family, Attributes: Male vs Female)
X = ["programmer"]
Y = ["homemaker"]
A = ["man"]
B = ["woman"]

d = weat_effect_size(embeddings, X, Y, A, B)
print(f"WEAT Effect Size (Gender Bias in Occupations): d = {d:.3f}")

Common pitfalls

  • Overfitting embeddings to intrinsic word similarity benchmarks that do not correlate well with downstream application performance.
  • Confusing semantic relatedness (e.g. "coffee" and "cup") with true semantic similarity (e.g. "coffee" and "tea"); datasets like SimLex-999 strictly test similarity.
  • Assuming that applying linear projection debiasing completely eliminates societal bias; non-linear probe classifiers often readily reconstruct latent protected attributes.

06 Check yourself

Q1What is the primary distinction between intrinsic and extrinsic evaluation of word embeddings?

Why: Intrinsic evaluation tests vector space properties (word similarity correlations, analogy arithmetic), whereas extrinsic evaluation measures utility in downstream tasks like sentiment classification.

Q2What does the Word Embedding Association Test (WEAT) measure?

Why: WEAT adapts the Implicit Association Test to word embeddings, measuring whether neutral concept words show differential geometric proximity to specific demographic or gender words.

Q3Which correlation coefficient is standardly used to evaluate model word similarity against human rankings?

Why: Spearman's rank-order correlation evaluates monotonic relationship between human rankings and model cosine similarities, making it robust to non-linear rating scales.
