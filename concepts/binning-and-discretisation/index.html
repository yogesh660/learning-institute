Converting continuous variables into discrete intervals using uniform, quantile, k-means, and supervised decision tree binning strategies.

01 The idea

Continuous features often exhibit non-linear relationships, extreme outliers, or multimodal distributions that linear and generalised additive models struggle to capture directly. Discretisation maps continuous scales into discrete ordinal or categorical bins, introducing non-linear step responses, dampening outlier sensitivity, and producing interpretable scorecards.

Discretisation partitions the domain of a continuous variable $X$ into $K$ intervals $[b_{k-1}, b_k)$, assigning each observation a discrete bin index or one-hot indicator. This effectively replaces a single continuous parameter with $K$ piecewise constant basis functions.

Unsupervised discretisation relies solely on feature distributions. Equal-width (uniform) binning divides the range into intervals of identical length, but is vulnerable to outliers compressing the vast majority of data into one bin. Equal-frequency (quantile) binning places an identical number of samples in every bin, making it robust against heavy tails and skewness.

Clustering-based binning (e.g. 1D k-means) clusters values into natural density modes, setting cut points midway between cluster centroids.

Supervised discretisation uses the target variable $y$ to determine optimal cutoffs. A single-variable decision tree finds split thresholds that maximise mutual information or minimise impurity with respect to $y$, directly isolating regions of differing risk or class probability.

In everyday terms

Consider categorising human ages for life insurance. Rather than forcing a single rigid linear relationship across all ages from 0 to 100, insurers split ages into distinct brackets: 18–25, 26–40, 41–60, and 60+. Within each bucket, risk is relatively uniform, and the risk premium can step up discretely without requiring complex high-degree polynomial curves.

02 Step by step

  1. Assess variable distribution: Inspect histograms, skewness, and kurtosis to determine whether the feature is uniform, bell-shaped, or heavily tailed.
  2. Select binning strategy: Choose equal-frequency for skewed distributions, equal-width for uniformly bounded metrics, or decision tree binning for non-linear target associations.
  3. Compute cut points on training data only: Fit bin edges $\{b_0, b_1, \dots, b_K\}$ strictly on the training partition to avoid data leakage.
  4. Handle boundary conditions: Ensure the outer edges extend to $(-\infty, \infty)$ so unseen minimum or maximum values in production do not produce missing values.
  5. Encode discrete intervals: Encode bins as ordinal integers (for tree models) or one-hot dummy variables (for linear models and credit scorecards).

03 The maths

  1. Equal-Width (Uniform) Interval Partitioning

    w = \frac{\max(X) - \min(X)}{K}, \quad b_k = \min(X) + k \cdot w, \quad k \in \{0, 1, \dots, K\}

    Equal-width binning divides the total observed range into $K$ intervals of fixed length $w$.

  2. Equal-Frequency (Quantile) Partitioning

    b_k = Q_X\left(\frac{k}{K}\right), \quad P(X \in [b_{k-1}, b_k)) = \frac{1}{K}

    Quantile binning places bin edges at percentiles such that each of the $K$ bins contains exactly $1/K$ of the empirical probability mass.

  3. Piecewise Constant Basis Expansion

    f(X) = \sum_{k=1}^K w_k \cdot \mathbb{I}(X \in [b_{k-1}, b_k))

    Linear models fit a separate weight $w_k$ to each bin indicator $\mathbb{I}$, learning arbitrary piecewise constant step functions without explicit polynomial features.

04 Key takeaways

  • Discretisation converts continuous variables into discrete bins, enabling linear models to learn non-linear step responses.
  • Quantile (equal-frequency) binning handles heavy-tailed skewed distributions without collapsing all samples into one bin.
  • Cut points must always be calculated strictly on the training set and applied unchanged to validation and test sets.
  • Supervised binning using decision tree splits finds thresholds that directly optimise class separation.

05 In code

python
import numpy as np
from sklearn.preprocessing import KBinsDiscretizer

# Generate skewed continuous data (e.g. income or transaction amounts)
np.random.seed(42)
income = np.random.exponential(scale=35000, size=1000).reshape(-1, 1)

# Fit quantile-based discretisation (5 bins with equal sample frequency)
quantile_bin = KBinsDiscretizer(n_bins=5, encode='ordinal', strategy='quantile')
binned_q = quantile_bin.fit_transform(income)

# Fit uniform (equal-width) discretisation
uniform_bin = KBinsDiscretizer(n_bins=5, encode='ordinal', strategy='uniform')
binned_u = uniform_bin.fit_transform(income)

print("Quantile cut points:\n", np.round(quantile_bin.bin_edges_[0], 1))
print("Quantile bin counts:\n", np.bincount(binned_q.flatten().astype(int)))
print("Uniform bin counts (heavily imbalanced):\n", np.bincount(binned_u.flatten().astype(int)))
# Notice quantile creates balanced ~200 items/bin, while uniform starves upper bins

Common pitfalls

  • Information loss: Discretisation discards fine-grained intra-bin variance, treating all values within an interval as completely identical.
  • Arbitrary boundary artifacts: Two data points on opposite sides of a cut boundary (e.g. 49.9 and 50.1) receive different representations, while 50.1 and 69.9 receive the same.
  • Calculating quantile thresholds on the combined dataset before train/test splitting, causing target leakage.

06 Check yourself

Q1What is the primary vulnerability of equal-width (uniform) binning when applied to skewed distributions?

Why: In a skewed distribution with extreme outliers, the span $(\max - \min)$ is dominated by rare values, leaving nearly all normal observations compressed into the first interval.

Q2Why does quantile binning generally outperform equal-width binning for financial variables like wealth or income?

Why: Quantile binning places cutoffs at empirical percentiles, ensuring balanced sample support across all bins regardless of distribution skewness.

Q3What must an engineer ensure when deploying a fitted discretiser to production inference?

Why: Production features may exhibit values lower than the training minimum or higher than the maximum. Infinite bounds prevent out-of-range errors.
