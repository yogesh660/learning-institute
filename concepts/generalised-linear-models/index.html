01 The idea

Ordinary least squares assumes continuous, normally distributed responses with constant variance—an assumption that fails catastrophically for click counts, hospital lengths of stay, or failure probabilities. Generalised Linear Models (GLMs) unify regression by connecting a linear predictor to any distribution in the exponential dispersion family via a monotonic link function. This flexible framework powers Poisson regression for event counts, Gamma regression for positive right-skewed durations, and logistic regression for binary classification.

Suppose an online streaming service predicts the number of support tickets $Y$ a customer submits per month based on their subscription tenure and monthly usage hours. Because ticket counts are discrete non-negative integers ($0, 1, 2, \dots$), fitting a standard linear regression model produces nonsensical predictions: for low-usage users, the line predicts negative tickets! Furthermore, count variance naturally scales with the mean (Poisson dispersion), violating the constant variance assumption of OLS.

GLMs solve this with three modular components: a random component choosing an outcome distribution from the exponential dispersion family (such as Poisson for counts or Bernoulli for binary outcomes); a systematic linear predictor $\eta = \beta_0 + \beta_1 x_1 + \dots + \beta_p x_p$; and a link function $g(\mu) = \eta$ that bridges expected response $\mu = E[Y]$ onto the unbounded real line $(-\infty, \infty)$.

For count data, the log link $g(\mu) = \ln(\mu)$ ensures that the expected count $\mu = \exp(\mathbf{x}^T\boldsymbol{\beta})$ remains strictly positive for every possible input. Exponentiating coefficients transforms additive changes in $x$ into multiplicative rate ratios: an estimated slope of $\hat{\beta}_1 = 0.417$ means each additional unit of $x$ multiplies expected ticket volume by $\exp(0.417) \approx 1.517$ (a 51.7% increase).

In everyday terms

A GLM is like an electrical transformer: the linear predictor produces raw voltage across the real line, and the link function transforms it down into the exact physical voltage (probability, count, or positive duration) required by the appliance.

02 Step by step

  1. Identify the response variable's data type and support: binary ($y \in \{0, 1\}$), integer counts ($y \in \{0, 1, 2, \dots\}$), or positive continuous durations ($y > 0$).
  2. Select an appropriate distribution from the exponential dispersion family: Bernoulli, Poisson, Negative Binomial, or Gamma.
  3. Choose a monotonic link function $g(\mu)$ that maps the expected mean domain onto $(-\infty, \infty)$ (e.g. logit for binary, log for counts).
  4. Formulate the log-likelihood function across observations: $\ell(\boldsymbol{\beta}) = \sum \ln f(y_i; \theta_i, \phi)$.
  5. Estimate parameters via Iteratively Reweighted Least Squares (IRLS) using Fisher scoring until convergence.
  6. Assess model goodness-of-fit using deviance statistics and evaluate individual predictor significance via Wald or likelihood-ratio tests.

03 The maths

  1. The Exponential Dispersion Family

    $$f(y; \theta, \phi) = \exp\left(\frac{y\theta - b(\theta)}{a(\phi)} + c(y, \phi)\right)$$

    Here $\theta$ is the natural parameter, $b(\theta)$ is the cumulant generator function, $\phi$ is the dispersion parameter, and $a(\phi)$ and $c(y, \phi)$ are known scaling functions. The mean and variance follow directly: $E[Y] = \mu = b'(\theta)$ and $\text{Var}(Y) = b''(\theta) a(\phi) = V(\mu) a(\phi)$, where $V(\mu)$ is the characteristic variance function.

  2. The Three GLM Components and Link Functions

    $$\eta_i = \mathbf{x}_i^T\boldsymbol{\beta}, \qquad g(\mu_i) = \eta_i \iff \mu_i = g^{-1}(\mathbf{x}_i^T\boldsymbol{\beta})$$

    The systematic component $\eta_i$ is a linear combination of explanatory features. The link function $g(\cdot)$ maps the expected mean $\mu_i$ onto the linear predictor. Common canonical links include the identity link $g(\mu) = \mu$ for Gaussian OLS, the logit link $g(\mu) = \ln\left(\frac{\mu}{1-\mu}\right)$ for Bernoulli classification, and the log link $g(\mu) = \ln(\mu)$ for Poisson count regression.

  3. Iteratively Reweighted Least Squares (IRLS)

    $$\boldsymbol{\beta}^{(t+1)} = (\mathbf{X}^T\mathbf{W}_t\mathbf{X})^{-1}\mathbf{X}^T\mathbf{W}_t\mathbf{z}_t, \qquad W_{ii} = \frac{1}{V(\mu_i)(g'(\mu_i))^2}$$

    GLMs are fitted using Fisher scoring, which simplifies to weighted least squares with weights $W_{ii}$ inversely proportional to variance and squared link derivative. The working response vector $\mathbf{z}_t = \boldsymbol{\eta}_t + (\mathbf{y} - \boldsymbol{\mu}_t) \odot g'(\boldsymbol{\mu}_t)$ updates parameters iteratively until log-likelihood changes drop below tolerance.

04 Key takeaways

  • GLMs unify linear regression, logistic regression, and Poisson regression under a single rigorous maximum-likelihood framework.
  • The link function transforms the expected value $\mu = E[Y]$, NOT the raw response variable $y$; regressing $\ln(y)$ in OLS produces biased estimates compared to a log-link GLM.
  • GLM parameters are estimated via Iteratively Reweighted Least Squares (IRLS), which converges rapidly to the global maximum likelihood estimator for canonical links.
  • Overdispersion occurs when count variance exceeds the Poisson mean ($\text{Var}(Y) > \mu$); it must be addressed using Negative Binomial or quasi-Poisson models.

05 In code

python
import numpy as np

rng = np.random.default_rng(42)
n = 120

# Synthetic count data: true log-linear rate log(mu) = 0.5 + 0.4*x
x = rng.uniform(0.0, 5.0, size=n)
true_beta = np.array([0.5, 0.4])
X = np.column_stack([np.ones(n), x])
mu_true = np.exp(X @ true_beta)
y = rng.poisson(mu_true)

# Fit Poisson GLM using IRLS (Newton-Raphson with log link)
beta = np.array([0.0, 0.0])
for iteration in range(10):
    eta = X @ beta
    mu = np.exp(eta)
    W = np.diag(mu)
    z = eta + (y - mu) / mu
    beta = np.linalg.inv(X.T @ W @ X) @ X.T @ W @ z

rate_ratio = np.exp(beta[1])
print(f"True beta:      {true_beta}")
print(f"Estimated beta: [{beta[0]:.3f}, {beta[1]:.3f}]")
print(f"Rate ratio exp(beta_1): {rate_ratio:.3f} (per unit increase in x)")

Common pitfalls

  • Log-transforming counts with zeros ($\ln(y + 1)$) and fitting OLS instead of fitting a Poisson GLM, which introduces substantial bias and heteroscedasticity.
  • Failing to check for overdispersion in Poisson models, leading to severely deflated standard errors and inflated false positive rates.
  • Confusing link functions with response transformations: $g(E[Y]) \ne E[g(Y)]$.
  • Using identity links on non-negative count data, leading to negative rate predictions and convergence failures during IRLS optimisation.

06 Check yourself

Q1What is the crucial mathematical difference between fitting a GLM with a log link versus fitting OLS on $\ln(Y)$?

Why: Because the logarithm is concave, $E[\ln(Y)] \le \ln(E[Y])$ by Jensen's inequality. Log-transforming the response biases predictions downward, whereas a log-link GLM models $\ln(E[Y])$ directly.

Q2In a Poisson GLM with a log link, how is a slope coefficient $\hat{\beta}_1 = 0.30$ substantively interpreted?

Why: Because $\ln(\mu) = \beta_0 + \beta_1 x$, exponentiating gives $\mu = e^{\beta_0} e^{\beta_1 x}$. An increase of 1 in $x$ multiplies $\mu$ by $e^{\beta_1}$.

Q3Which canonical link function pairs with the Bernoulli distribution in generalised linear modelling?

Why: The logit link maps probability $\mu \in (0, 1)$ to unbounded log-odds $(-\infty, \infty)$ and serves as the canonical link for the Bernoulli distribution.

Q4What numerical algorithm is universally employed to compute maximum likelihood parameter estimates in GLMs?

Why: IRLS implements Fisher scoring for exponential families, transforming maximum likelihood optimisation into a sequence of weighted least squares regressions that converge in few iterations.
