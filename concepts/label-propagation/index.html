01 The idea

In many real-world applications, labelling data requires expensive human domain experts, leaving 99% of data unlabelled. Label propagation constructs a nearest-neighbour affinity graph, propagating known labels across high-density manifolds.

In modern machine learning, collecting unlabelled data is virtually free—scraping millions of web pages, sensor logs, or satellite images. However, obtaining high-quality ground truth labels requires human domain experts (e.g. radiologists annotating MRIs or fraud specialists reviewing transactions), which is slow and expensive. Semi-Supervised Learning (SSL) exploits the structure of unlabelled data to dramatically improve model accuracy from a tiny handful of labelled examples.

Graph-based semi-supervised learning rests on the Cluster / Manifold Assumption: high-density regions of data form continuous clusters or manifolds, and points lying on the same manifold are overwhelmingly likely to share the identical class label.

Pioneered by Xiaojin Zhu and Zoubin Ghahramani (2002), Label Propagation connects all data points (both labelled and unlabelled) into an undirected affinity graph $W$, where edge weights $W_{ij} = \exp(-\|x_i - x_j\|^2 / (2\sigma^2))$ reflect local similarity.

Label Propagation models probability diffusion: known labels act as source electrodes, pumping probability mass through graph edges into unlabelled nodes. At each iteration, unlabelled nodes update their belief to the weighted average of their neighbours beliefs, while labelled nodes are clamped to their ground-truth values. The process converges to a unique closed-form Harmonic Function satisfying the graph Laplace equation $\Delta f = 0$. Zhou et al. introduced Label Spreading, which incorporates normalised Graph Laplacians and soft clamping to tolerate noisy labels.

In everyday terms

Imagine a network of dry irrigation canals connecting hundreds of rice fields in a valley. Only two fields at opposite ends have water pumps: one pumps blue fertilizer water, the other pumps yellow dye water. As water flows through the connecting canals, nearby fields quickly absorb the blue or yellow liquid. At equilibrium, every field settles into a stable shade of green, teal, or blue depending strictly on the network conductivity between them.

03 The maths

  1. Label Propagation Equilibrium Equation

    Y_U = (I_u - P_{UU})^{-1} P_{UL} Y_L, \quad P = D^{-1} W

    Closed-form solution for unlabelled node label distributions. The matrix inverse exists and is strictly positive because P_UU is sub-stochastic.

  2. Harmonic Energy Minimisation

    \mathcal{E}(f) = \frac{1}{2} \sum_{i, j=1}^n W_{ij} (f_i - f_j)^2 = f^T L f \quad \text{subject to } f_L = y_L

    The equilibrium solution minimises Dirichlet harmonic energy on the graph Laplacian L = D - W, ensuring smooth variation along the data manifold.

  3. Label Spreading Soft-Clamping Update (Zhou et al.)

    F^{(t+1)} = \alpha S F^{(t)} + (1 - \alpha) Y, \quad S = D^{-1/2} W D^{-1/2}

    Normalised graph Laplacian iteration with clamping parameter alpha in (0, 1) balancing neighbour diffusion with fidelity to initial labels, conferring robustness to label noise.

04 Key takeaways

  • Graph-based semi-supervised learning that propagates label probabilities from labelled seeds across the data manifold.
  • Rests on the Cluster/Manifold assumption: points connected by high-density paths share identical class labels.
  • Converges to a unique harmonic function minimising graph Dirichlet energy $\mathcal{E}(f) = f^T L f$.
  • Label Spreading introduces normalised Graph Laplacians and soft clamping, conferring robustness against corrupted labels.
  • Achieves high classification accuracy on complex non-linear manifolds using less than 1% labelled training data.

05 In code

python
import numpy as np

# Label Propagation from scratch on Two Concentric Moons
# We have 200 total samples, but ONLY 2 LABELLED SAMPLES (one per class)!
np.random.seed(42)
n_samples = 100

# Generate 2 moons dataset
theta = np.linspace(0, np.pi, n_samples)
moon1_x = np.cos(theta) + np.random.normal(0, 0.08, n_samples)
moon1_y = np.sin(theta) + np.random.normal(0, 0.08, n_samples)

moon2_x = 1.0 - np.cos(theta) + np.random.normal(0, 0.08, n_samples)
moon2_y = 0.5 - np.sin(theta) + np.random.normal(0, 0.08, n_samples)

X = np.vstack([np.column_stack([moon1_x, moon1_y]),
               np.column_stack([moon2_x, moon2_y])])
y_true = np.array([0]*n_samples + [1]*n_samples)
n_total = len(X)

# Assign ONLY 2 KNOWN LABELS: sample 0 is Class 0, sample 100 is Class 1
# All other 198 samples are unlabelled (-1)
y_semi = np.full(n_total, -1)
y_semi[0] = 0
y_semi[n_samples] = 1

# 1. Compute RBF Affinity Matrix W
gamma = 20.0
dists_sq = np.sum(X**2, axis=1)[:, None] + np.sum(X**2, axis=1)[None, :] - 2 * (X @ X.T)
W = np.exp(-gamma * np.maximum(dists_sq, 0))
np.fill_diagonal(W, 0.0)  # No self-loops

# 2. Row-normalise to create transition matrix P = D^{-1} W
D = np.sum(W, axis=1)
D[D == 0] = 1e-12
P = W / D[:, None]

# 3. Label matrix Y (one-hot encoding)
Y = np.zeros((n_total, 2))
Y[0, 0] = 1.0
Y[n_samples, 1] = 1.0

# 4. Label Propagation Iteration
labelled_indices = [0, n_samples]
unlabelled_indices = [i for i in range(n_total) if i not in labelled_indices]

Y_curr = Y.copy()
for it in range(50):
    # Propagate: Y <- P * Y
    Y_new = P @ Y_curr
    # Clamp labelled points strictly to ground truth
    Y_new[0] = [1.0, 0.0]
    Y_new[n_samples] = [0.0, 1.0]
    
    if np.max(np.abs(Y_new - Y_curr)) < 1e-5:
        break
    Y_curr = Y_new

# Predicted classes on unlabelled instances
pred_labels = np.argmax(Y_curr, axis=1)
accuracy_unlabelled = np.mean(pred_labels[unlabelled_indices] == y_true[unlabelled_indices])

print(f"Total dataset: {n_total} samples (Two Moons manifold)")
print(f"Number of labelled samples provided: 2 (1.0% supervision!)")
print(f"Number of unlabelled samples to infer: {len(unlabelled_indices)}")
print(f"Label Propagation Accuracy on Unlabelled Data: {accuracy_unlabelled * 100:.1f}%")
print("Conclusion: Label propagation successfully navigated the curved manifold from 2 single points!")

Common pitfalls

  • Affinity graph sensitivity: Highly sensitive to graph construction (RBF parameter $\gamma$ or $k$-NN count); poor choice connects disconnected manifolds (short-circuiting) or fragments the graph.
  • Label imbalance bias: If one class has significantly more labelled seeds, its probability mass floods unlabelled nodes; class mass normalisation (CMN) is required.
  • Scalability bottleneck: Full graph propagation requires $O(n^2)$ memory and $O(n^3)$ inversion time, demanding sparse $k$-NN approximations or landmark graphs for large datasets.

06 Check yourself

Q1Why can Label Propagation classify complex curved non-linear manifolds (like Two Moons) using only 2 labelled examples?

Why: By constructing an affinity graph along dense geometric corridors, label probabilities flow naturally through the manifold curves, classifying points based on path connectivity.

Q2What is the primary difference between Label Propagation and Zhou et al.’s Label Spreading?

Why: Label Propagation strictly clamps labelled nodes to initial values. Label Spreading uses soft clamping with parameter alpha, allowing labelled nodes to update and filter noisy annotations.
