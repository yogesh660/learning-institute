01 The idea

First-order gradient descent crawls slowly along narrow ravines. Newton’s method uses the second derivative (Hessian matrix) to fit a local osculating paraboloid, jumping directly to the minimum with quadratic convergence.

First-order optimisation methods like Gradient Descent navigate parameter space using only local slope information (the gradient vector $\nabla f$). When an objective function has ill-conditioned curvature—such as a long, narrow canyon where one direction is 1,000 times steeper than another—gradient descent bounces helplessly between the canyon walls, requiring tens of thousands of tiny steps to make forward progress.

Newton’s method (also known as the Newton–Raphson method) solves this by incorporating second-order curvature information via the Hessian matrix $\nabla^2 f(x)$, whose entries represent all second-order partial derivatives $\frac{\partial^2 f}{\partial x_i \partial x_j}$.

At each step, Newton’s method fits a second-order Taylor polynomial (a local quadratic bowl) to the objective function: $f(x + \Delta x) \approx f(x) + \nabla f(x)^T \Delta x + \frac{1}{2} \Delta x^T \nabla^2 f(x) \Delta x$. By calculating the exact stationary point of this quadratic approximation, the Newton step jumps directly to the bowl minimum: $\Delta x = -[\nabla^2 f(x)]^{-1} \nabla f(x)$.

When near the minimum, Newton’s method achieves local quadratic convergence: the error at step $t+1$ is proportional to the square of the error at step $t$ ($\|e_{t+1}\| \le M \|e_t\|^2$), doubling the number of correct decimal places at every single iteration. However, inverting the $p \times p$ Hessian matrix costs $O(p^3)$ time, motivating Quasi-Newton algorithms like BFGS and L-BFGS that iteratively build curvature approximations from gradient changes.

In everyday terms

Imagine hiking down a foggy mountain peak at night. Gradient descent feels the slope beneath your boots and takes a step in the steepest downward direction, frequently stumbling into rocky gullies. Newton’s method shines a radar beam into the fog that scans the 3D bowl shape of the entire valley floor, calculating the exact GPS coordinates of the valley base and walking directly there in a few giant strides.

03 The maths

  1. Second-Order Taylor Approximation

    f(x + \Delta x) \approx f(x) + \nabla f(x)^T \Delta x + \frac{1}{2} \Delta x^T \nabla^2 f(x) \Delta x

    Local quadratic model of the objective function. Differentiating with respect to Delta x and setting to zero yields the optimal step.

  2. Newton Step Equation

    \Delta x = -[\nabla^2 f(x)]^{-1} \nabla f(x) = -H^{-1} g

    The unconstrained Newton step. Scales and rotates the gradient by the inverse Hessian, automatically compensating for anisotropic curvature.

  3. Quadratic Convergence Rate

    \|x_{t+1} - x^*\| \le M \|x_t - x^*\|^2

    In the neighbourhood of a strict local minimum, the distance to the optimum squares at each iteration, achieving extreme precision in fewer than 10 steps.

04 Key takeaways

  • Second-order optimisation algorithm that uses the Hessian matrix to capture local quadratic curvature.
  • Scales and rotates search directions by the inverse Hessian: $\Delta x = -[\nabla^2 f(x)]^{-1} \nabla f(x)$.
  • Achieves quadratic local convergence ($\|e_{t+1}\| \le M \|e_t\|^2$), doubling accuracy precision at each step near the minimum.
  • Eliminates the oscillations in narrow ravines that cripple first-order gradient descent.
  • Inverting the $p \times p$ Hessian costs $O(p^3)$, motivating Quasi-Newton methods like BFGS and L-BFGS.

05 In code

python
import numpy as np

# Newton's Method vs Gradient Descent on the Rosenbrock Banana Function
# f(x, y) = (1 - x)^2 + 100 * (y - x^2)^2 (classic ill-conditioned valley)
def rosenbrock(v):
    x, y = v[0], v[1]
    return (1.0 - x)**2 + 100.0 * (y - x**2)**2

def rosenbrock_grad(v):
    x, y = v[0], v[1]
    df_dx = -2.0 * (1.0 - x) - 400.0 * x * (y - x**2)
    df_dy = 200.0 * (y - x**2)
    return np.array([df_dx, df_dy])

def rosenbrock_hessian(v):
    x, y = v[0], v[1]
    d2f_dx2 = 2.0 - 400.0 * y + 1200.0 * x**2
    d2f_dxdy = -400.0 * x
    d2f_dy2 = 200.0
    return np.array([[d2f_dx2, d2f_dxdy],
                     [d2f_dxdy, d2f_dy2]])

# 1. Newton's Method with Backtracking Line Search
x_newton = np.array([-1.2, 1.0])
newton_history = [x_newton.copy()]

for it in range(30):
    g = rosenbrock_grad(x_newton)
    if np.linalg.norm(g) < 1e-8:
        break
    H = rosenbrock_hessian(x_newton)
    
    # Regularise Hessian if not positive definite
    eigvals = np.linalg.eigvalsh(H)
    if np.min(eigvals) <= 1e-4:
        H += np.eye(2) * (1e-3 - np.min(eigvals))
        
    # Solve H delta_x = -g
    delta_x = np.linalg.solve(H, -g)
    
    # Backtracking Armijo Line Search
    alpha = 1.0
    while rosenbrock(x_newton + alpha * delta_x) > rosenbrock(x_newton) + 1e-4 * alpha * np.dot(g, delta_x):
        alpha *= 0.5
        if alpha < 1e-10: break
        
    x_newton += alpha * delta_x
    newton_history.append(x_newton.copy())

# 2. Gradient Descent with Tuned Step Size
x_gd = np.array([-1.2, 1.0])
lr = 0.0015
gd_history = [x_gd.copy()]

for it in range(1000):
    g = rosenbrock_grad(x_gd)
    if np.linalg.norm(g) < 1e-8:
        break
    x_gd -= lr * g
    gd_history.append(x_gd.copy())

print(f"True Global Minimum: [1.000, 1.000] with f = 0.000")
print(f"\nNewton's Method:")
print(f"  Converged to: {x_newton.round(5)} in {len(newton_history)-1} iterations!")
print(f"  Final value:  {rosenbrock(x_newton):.2e}")

print(f"\nGradient Descent:")
print(f"  Reached:      {x_gd.round(5)} after {len(gd_history)-1} iterations (struggling in curved valley)")
print(f"  Final value:  {rosenbrock(x_gd):.4f}")

Common pitfalls

  • Computational scaling with dimension: Computing and inverting the $p \times p$ Hessian scales as $O(p^3)$ time and $O(p^2)$ memory, becoming unusable for millions of neural network weights.
  • Saddle points and maxima in non-convex functions: If the Hessian has negative eigenvalues, the standard Newton step jumps toward local maxima or saddle points; Hessian regularisation is mandatory.
  • Overshooting without line search: Pure Newton steps (step size $\alpha = 1$) can jump across non-quadratic regions into explosive divergence; backtracking line search is required for global stability.

06 Check yourself

Q1Why does Newton’s method navigate narrow curved ravines vastly faster than Gradient Descent?

Why: In ill-conditioned ravines, the Hessian inverse H^{-1} shrinks steps along steep directions and expands steps along flat valleys, steering the update directly toward the minimum.

Q2What is the primary computational drawback of Newton’s method in high-dimensional deep learning?

Why: For a neural network with 100 million parameters, storing the Hessian requires 40 petabytes of RAM, and inverting it would require 10^24 operations.
