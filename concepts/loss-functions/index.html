Loss Functions: How Models Measure Mistakes

MSE, MAE, Huber, log-loss and hinge: what each one punishes, and how that choice shapes the model you get.

01 The idea

The loss function is where you tell the model what a mistake costs. Squared loss hates big errors, absolute loss treats all errors evenly, log-loss hates confident wrong answers, hinge loss only cares about getting the margin right.

Minimising squared error gives the conditional mean; minimising absolute error gives the conditional median. That is why MSE is pulled by outliers and MAE is not. Huber is squared near zero and absolute far away: the best of both.

For classification, log-loss (cross-entropy) penalises a 0.99 prediction for the wrong class with $-\log 0.01 \approx 4.6$, a huge penalty, which pushes models toward calibrated probabilities. Hinge loss is zero once a point is correctly classified with margin at least 1, so it ignores easy points, which is why SVMs depend only on support vectors.

In everyday terms

A teacher’s marking scheme: does a big mistake cost a lot more than a small one, the same, or does only being on the right side of the line matter?

02 Step by step

  1. Regression: start with squared error; switch to Huber or MAE when outliers matter; use quantile (pinball) loss for prediction intervals.
  2. Classification: log-loss when you need probabilities; hinge for maximum-margin classifiers.
  3. Make sure the loss you train on matches what the business penalises.

04 The maths

  1. Regression losses

    $$\ell_{\text{MSE}} = (y - \hat y)^2, \quad \ell_{\text{MAE}} = |y - \hat y|, \quad \ell_\delta = \begin{cases}\tfrac12 e^2 & |e| \le \delta\\ \delta(|e| - \tfrac12\delta) & \text{otherwise}\end{cases}$$

    Their gradients tell the story: $2e$ grows without limit, $\operatorname{sign}(e)$ is constant, Huber is capped at $\pm\delta$.

  2. Classification losses (margin $m = y\,f(x)$, $y \in \{-1, 1\}$)

    $$\ell_{\text{log}} = \log(1 + e^{-m}), \quad \ell_{\text{hinge}} = \max(0, 1 - m), \quad \ell_{0/1} = \mathbb 1[m \le 0]$$

    Both log and hinge are convex upper bounds of the 0/1 loss, which we cannot optimise directly.

  3. Quantile (pinball) loss

    $$\ell_\tau(e) = \max(\tau e,\; (\tau - 1)e)$$

    Minimised by the $\tau$-th conditional quantile; used for prediction intervals with boosting.

05 Key takeaways

  • MSE → mean, MAE → median, pinball → quantile.
  • Convex surrogate losses make classification trainable.
  • The loss decides which errors the model will sacrifice to fix others.

06 In code

python
import numpy as np

e = np.linspace(-3, 3, 7)
mse, mae = e ** 2, np.abs(e)
huber = np.where(np.abs(e) <= 1, 0.5 * e ** 2, np.abs(e) - 0.5)
m = np.linspace(-2, 2, 5)                         # classification margins y*f(x)
log_loss, hinge = np.log1p(np.exp(-m)), np.maximum(0, 1 - m)
print(np.c_[e, mse, mae, huber]); print(np.c_[m, log_loss, hinge])

Common pitfalls

  • Training with MSE on data with heavy outliers and blaming the model.
  • Using accuracy as a training signal; it has zero gradient almost everywhere.

07 Check yourself

Q1Which loss is minimised by predicting the median?

Why: The derivative of $\sum|y_i - c|$ is zero where half the points are above $c$ and half below.

Q2Hinge loss for a correctly classified point with margin 2 is:

Why: $\max(0, 1 - 2) = 0$: points beyond the margin contribute nothing.

Q3Which parameter value is chosen by minimising the Mean Squared Error (MSE) loss on a univariate continuous variable?

Why: Differentiating $\sum (y_i - c)^2$ with respect to $c$ yields $-2\sum(y_i - c) = 0 \implies c = \frac{1}{n}\sum y_i$, which is the sample mean.

Q4Why is the Huber loss function preferred over pure MSE in regression problems where outliers are present?

Why: MSE squares large errors, so an outlier with $e = 100$ produces a loss of $10{,}000$ and huge gradients. Huber loss caps the gradient at $\pm \delta$ for $|e| > \delta$, giving robustness while remaining smooth at zero.

Q5What is the quantile (pinball) loss function used for in machine learning?

Why: Quantile (pinball) loss $\ell_\tau(e) = \max(\tau e, (\tau - 1)e)$ is minimised by the $\tau$-th quantile of the conditional distribution $P(y \mid x)$, enabling asymmetric interval forecasting.

Q6For a binary classification instance with true label $y = +1$ and raw model score $f(x) = -2.0$ (giving margin $m = y f(x) = -2.0$), what is the hinge loss $\ell_{\text{hinge}} = \max(0, 1 - m)$?

Why: $\ell_{\text{hinge}} = \max(0, 1 - m) = \max(0, 1 - (-2.0)) = \max(0, 3.0) = 3.0$. Because the prediction is on the wrong side of the decision boundary, the loss penalises both the margin violation and the classification error.

Q7What is the gradient of the Absolute Error loss $\ell(y, \hat{y}) = |y - \hat{y}|$ with respect to error $e = y - \hat{y}$ for $e \ne 0$?

Why: The derivative of $|e|$ is $+1$ for $e > 0$ and $-1$ for $e < 0$. Unlike MSE whose gradient $2e$ explodes for large errors, MAE exerts a constant push of $\pm 1$ on parameters, providing outlier resistance.

Q8Why does training a neural network using hinge loss rather than log-loss (cross-entropy) fail to produce well-calibrated posterior probabilities $P(y=1 \mid x)$?

Why: Once a sample satisfies $y f(x) \ge 1$, hinge loss is exactly zero whether $f(x) = 1.0$ or $f(x) = 100.0$. It cares only about finding a separating margin, not about calibrated probability scores.

Q9A regression model is trained on a dataset containing 1,000 clean observations and 5 severe recording errors (outliers 100 times larger than normal). Why does an MSE-trained model perform poorly on the 1,000 clean observations?

Why: MSE penalises errors quadratically. The penalty for an error of 100 is $10{,}000$, whereas for an error of 1 it is only 1. To minimise total MSE, the optimiser drastically moves parameters to reduce the 5 giant errors, sacrificing fit on normal points.

Q10For a residual error $e = y - \hat{y} = 4.0$ with Huber loss threshold $\delta = 2.0$, what is the Huber loss $\ell_\delta(e) = \delta(|e| - \frac{1}{2}\delta)$?

Why: Since $|e| = 4.0 > \delta = 2.0$, we use the linear tail formula: $\ell_\delta(e) = \delta(|e| - \frac{1}{2}\delta) = 2.0(4.0 - \frac{1}{2}(2.0)) = 2.0(4.0 - 1.0) = 2.0(3.0) = 6.0$. (In contrast, pure MSE would yield $e^2 = 16.0$).

Q11Under quantile loss $\ell_\tau(e) = \max(\tau e, (\tau - 1)e)$ with target quantile $\tau = 0.80$, what are the losses for an underprediction where $e = y - \hat{y} = +10.0$ and an overprediction where $e = -10.0$?

Why: For $e = +10.0$: $\ell_{0.8}(10) = \max(0.8 \times 10, (0.8 - 1) \times 10) = \max(8.0, -2.0) = 8.0$. For $e = -10.0$: $\ell_{0.8}(-10) = \max(0.8 \times (-10), -0.2 \times (-10)) = \max(-8.0, 2.0) = 2.0$. Underpredicting the 80th percentile is penalised 4 times more heavily than overpredicting it ($0.80 / 0.20 = 4$).

Q12For a binary classification example with true label $y = +1$ and model score $f(x) = 0$, what are the 0/1 loss $\ell_{0/1} = \mathbb{1}[y f(x) \le 0]$, the hinge loss $\ell_{\text{hinge}} = \max(0, 1 - y f(x))$, and the logistic loss $\ell_{\text{log}} = \ln(1 + e^{-y f(x)})$? (Recall $\ln(2) \approx 0.693$).

Why: Here margin $m = y f(x) = 1 \times 0 = 0$. $\ell_{0/1} = \mathbb{1}[0 \le 0] = 1$. $\ell_{\text{hinge}} = \max(0, 1 - 0) = 1.0$. $\ell_{\text{log}} = \ln(1 + e^0) = \ln(1 + 1) = \ln(2) \approx 0.693$. Both convex surrogates are continuous upper bounds that penalise this boundary-case uncertainty.
