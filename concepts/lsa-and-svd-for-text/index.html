LSA and SVD for text

Latent Semantic Analysis (LSA), also known as Latent Semantic Indexing (LSI) in information retrieval, applies Truncated Singular Value Decomposition (SVD) to high-dimensional term-document or term-term matrices. By decomposing a sparse matrix into orthonormal singular vectors and singular values, LSA projects words and documents into a low-dimensional continuous latent semantic space. This rank reduction discovers hidden semantic topics, resolves synonymy by mapping distinct surface words to common latent dimensions, and mitigates the curse of dimensionality.

01 The idea

Search for "physician" in a traditional keyword search engine, and you will miss every document that exclusively uses the word "doctor". Lexical matching fails because human language is plagued by synonymy (different words describing the exact same concept) and polysemy (one word possessing multiple meanings). Latent Semantic Analysis solves this by decomposing term-document matrices: it discovers the latent conceptual axes connecting vocabulary words, enabling documents to match search queries even when they share zero exact keywords.

The curse of sparse lexical matrices: In standard Bag of Words and TF-IDF representations, each word corresponds to an orthogonal basis axis. If a vocabulary contains 50,000 words, every document is a 50,000-dimensional vector. Because orthogonal vectors have zero dot product, "canine" and "dog" are mathematically as unrelated as "canine" and "refrigerator". We need a mathematical lens that compresses orthogonal lexical dimensions into dense semantic concepts.

Singular Value Decomposition as latent concept discovery: SVD factorises any rectangular matrix X into three constituent matrices: X = U * Sigma * V^T. The left singular vectors U define term loadings across latent concepts; the diagonal singular values Sigma rank the semantic importance and variance of each concept; and the right singular vectors V represent document coordinates along those same conceptual axes.

Low-rank truncation and noise filtering: The Eckart-Young-Mirsky theorem proves that keeping only the top k largest singular values produces the best possible rank-k approximation of the original matrix under Frobenius and spectral norms. Truncating to k dimensions (typically k = 100 to 300) discards idiosyncrasies and lexical noise, preserving global semantic correlations and merging synonymous words into shared topic coordinates.

In everyday terms

Imagine you are an astronomer mapping a distant star cluster. You have raw observations tracking the positions of 100,000 individual twinkling stars. When you plot them directly, the data is an overwhelming, noisy cloud of coordinates. SVD is like discovering the primary gravitational axes of rotation for the entire galaxy: instead of tracking 100,000 independent stars, you discover that 95% of their motion is governed by just three primary elliptical gravitational planes. By describing each star by its position along these three core planes (low-rank latent space), you filter out astronomical telescope jitter and immediately see the underlying spiral structure of the galaxy.

03 The maths

  1. Singular Value Decomposition (SVD) matrix factorisation

    X = U \Sigma V^T

    Here $X \in \mathbb{R}^{m \times n}$ is the term-document matrix ($m = |V|, n = D$), $U \in \mathbb{R}^{m \times m}$ contains orthonormal eigenvectors of $X X^T$, $V \in \mathbb{R}^{n \times n}$ contains orthonormal eigenvectors of $X^T X$, and $\Sigma \in \mathbb{R}^{m \times n}$ contains square roots of non-zero eigenvalues (singular values $\sigma_1 \ge \sigma_2 \ge \dots \ge 0$).

  2. Optimal low-rank approximation (Eckart-Young-Mirsky Theorem)

    X_k = U_k \Sigma_k V_k^T = \arg\min_{\operatorname{rank}(A) \le k} \|X - A\|_F

    Keeping the top $k$ singular values minimises the reconstruction error under the Frobenius norm $\|X - X_k\|_F = \sqrt{\sum_{i=k+1}^{\min(m, n)} \sigma_i^2}$, retaining maximal variance while discarding noise.

  3. Query folding into latent semantic space

    \mathbf{q}_k = \Sigma_k^{-1} U_k^T \mathbf{q}

    A new sparse query vector $\mathbf{q} \in \mathbb{R}^{|V|}$ is projected into the $k$-dimensional latent space by multiplying by $U_k^T$ and scaling by inverse singular values $\Sigma_k^{-1}$, allowing direct cosine comparison against precomputed document rows in $V_k$.

04 Key takeaways

  • Latent Semantic Analysis applies truncated SVD to compress sparse term-document matrices into low-dimensional semantic representations.
  • The Eckart-Young-Mirsky theorem guarantees that truncated SVD provides the mathematically optimal rank-k approximation under Frobenius and spectral norms.
  • LSA resolves synonymy: words with similar co-occurrence patterns map to shared coordinates along latent semantic axes.
  • Unseen queries are projected into the latent space via the fold-in equation q_k = Sigma_k^{-1} * U_k^T * q.
  • A core limitation of LSA is polysemy: each word receives a single linear vector that conflates disparate meanings (e.g. "bank" financial vs riverbank).

05 In code

python
import numpy as np
import re
from collections import Counter

class LatentSemanticAnalysis:
    """
    Self-contained Latent Semantic Analysis (LSA) implementation
    using TF-IDF term-document weighting and truncated SVD.
    """
    def __init__(self, k_components=2):
        self.k = k_components
        self.vocab = []
        self.word2idx = {}
        self.U_k = None
        self.Sigma_k = None
        self.V_k = None
        self.doc_embeddings = None

    def _tokenize(self, text):
        return [w.lower() for w in re.findall(r'\b[a-zA-Z]+\b', text)]

    def fit(self, corpus):
        # 1. Build vocabulary
        doc_tokens = [self._tokenize(doc) for doc in corpus]
        all_words = sorted(list(set(w for tokens in doc_tokens for w in tokens)))
        self.vocab = all_words
        self.word2idx = {w: i for i, w in enumerate(self.vocab)}
        
        V = len(self.vocab)
        D = len(corpus)
        
        # 2. Build TF-IDF Term-Document Matrix (V x D)
        X = np.zeros((V, D), dtype=float)
        
        # Compute Document Frequencies
        df = Counter()
        for tokens in doc_tokens:
            unique_in_doc = set(tokens)
            for w in unique_in_doc:
                df[w] += 1
                
        # Fill TF-IDF values
        for d, tokens in enumerate(doc_tokens):
            tf = Counter(tokens)
            for w, count in tf.items():
                row = self.word2idx[w]
                # Log-normalized TF * Smooth IDF
                tf_val = 1.0 + np.log(count)
                idf_val = np.log((D + 1.0) / (df[w] + 1.0)) + 1.0
                X[row, d] = tf_val * idf_val
                
        # 3. Truncated SVD via full SVD
        # X = U * Sigma * V^T
        U, s, Vt = np.linalg.svd(X, full_matrices=False)
        
        # Keep top k components
        self.U_k = U[:, :self.k]             # (V x k)
        self.Sigma_k = np.diag(s[:self.k])   # (k x k)
        self.V_k = Vt[:self.k, :].T          # (D x k)
        
        # Latent document coordinates
        self.doc_embeddings = self.V_k * s[:self.k]
        
    def transform_query(self, query):
        """Fold new query into k-dimensional latent space."""
        tokens = self._tokenize(query)
        q_vec = np.zeros(len(self.vocab), dtype=float)
        for w in tokens:
            if w in self.word2idx:
                q_vec[self.word2idx[w]] += 1.0
                
        # q_k = Sigma_k^{-1} * U_k^T * q
        inv_sigma = np.linalg.inv(self.Sigma_k)
        q_k = inv_sigma @ (self.U_k.T @ q_vec)
        return q_k

    def rank_documents(self, query):
        q_k = self.transform_query(query)
        q_norm = np.linalg.norm(q_k)
        if q_norm == 0.0:
            return [(d, 0.0) for d in range(len(self.doc_embeddings))]
            
        scores = []
        for d_idx, d_vec in enumerate(self.doc_embeddings):
            d_norm = np.linalg.norm(d_vec)
            cos_sim = np.dot(q_k, d_vec) / (q_norm * d_norm) if d_norm > 0 else 0.0
            scores.append((d_idx, float(cos_sim)))
            
        scores.sort(key=lambda x: x[1], reverse=True)
        return scores

# Sample corpus: Machine learning vs Planetary astronomy
documents = [
    "Machine learning neural networks optimize loss functions with gradient descent.",
    "Deep learning models recognize computer vision patterns and speech sequences.",
    "Supervised learning algorithms predict continuous targets from labeled training sets.",
    "Jupiter is a giant gas planet orbited by dozens of icy moons.",
    "Mars has a thin atmosphere and robotic rovers exploring planetary craters.",
    "Saturn possesses prominent planetary rings composed of water ice and cosmic dust."
]

lsa = LatentSemanticAnalysis(k_components=2)
lsa.fit(documents)

print(f"Matrix shape: {len(lsa.vocab)} terms x {len(documents)} documents")
print(f"Truncated rank k: {lsa.k} latent dimensions")
print(f"Top 2 singular values: {np.diag(lsa.Sigma_k)}")

test_query = "planetary astronomy spacecraft"
print(f"\nQuery: '{test_query}' (notice: words 'astronomy' and 'spacecraft' are out of vocabulary!)")
rankings = lsa.rank_documents(test_query)
for rank, (doc_idx, score) in enumerate(rankings[:3], 1):
    print(f"  {rank}. [Similarity: {score:+.4f}] Doc {doc_idx}: '{documents[doc_idx]}'")

Common pitfalls

  • Applying SVD to raw unweighted term counts: Raw word counts cause high-frequency stop words to dominate the primary singular vectors. Always weight matrices with TF-IDF or PPMI prior to SVD.
  • Full SVD computation on large vocabularies: Computing complete SVD takes O(min(m^2 n, m n^2)) time, which fails on millions of documents. Use randomized truncated SVD or iterative Krylov methods (such as Lanczos).
  • Choosing truncation rank k incorrectly: Setting k too small (e.g. k = 5) discards vital distinguishing topics; setting k too large (e.g. k = 5,000) retains noisy, ungeneralisable lexical variations. Optimal k typically falls between 100 and 300.
  • Interpretability challenges: Unlike non-negative matrix factorisation (NMF) or LDA where topics are strictly positive word probability distributions, SVD produces signed real numbers with arbitrary polarities that can be hard to interpret.

06 Check yourself

Q1According to the Eckart-Young-Mirsky theorem, what property does truncated SVD guarantee for a matrix X?

Why: The Eckart-Young-Mirsky theorem proves that the rank-k matrix reconstructed by keeping the top k singular values achieves the minimum possible reconstruction error ||X - X_k|| under both Frobenius and operator norms.

Q2How does Latent Semantic Analysis address the problem of synonymy in information retrieval?

Why: Synonyms like "physician" and "doctor" co-occur with similar context words ("hospital", "patient", "cure"). SVD combines these co-occurrence correlations into shared latent singular vectors, giving synonyms similar continuous representations.

Q3What is a major limitation of LSA when representing polysemous words (words with multiple distinct meanings)?

Why: Because LSA assigns one static vector per vocabulary word, a word like "bank" has its financial sense and riverbank sense conflated into a single compromised vector positioned between financial and geographical concept clusters.
