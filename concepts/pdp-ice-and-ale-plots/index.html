01 The idea

Global feature importance scores like PFI and SHAP reveal which features matter, but they do not show the direction or functional shape of those relationships. Partial Dependence Plots (PDP) and Individual Conditional Expectation (ICE) curves map how model predictions shift as a target feature varies across its domain. Accumulated Local Effects (ALE) plots resolve the catastrophic extrapolation errors that plague PDPs when features are strongly correlated, providing robust, unpolluted visualisations of complex machine learning models.

Suppose a real estate model predicts house prices using square footage and number of bedrooms. You want to understand: "If a house gains 500 square feet, how much does its predicted price increase?" A Partial Dependence Plot (PDP) answers this by taking every house in your dataset, artificially overwriting its square footage with a specific grid value (e.g. 2,000 sq ft), predicting all prices, and calculating the overall average. By repeating this across a grid of sizes, PDP draws a smooth curve showing the general relationship between area and price.

However, PDP has two major blind spots. First, it averages away individual differences. If an extra bedroom increases value for large suburban family homes but decreases value for urban studio flats, the upward and downward slopes cancel each other out, leaving PDP with a flat, deceptive horizontal line. Individual Conditional Expectation (ICE) fixes this by plotting a separate curve for every individual house. Instead of a single averaged line, ICE renders a bundle of trajectories, immediately revealing whether all houses react similarly or if distinct subgroups diverge.

The second flaw of PDP is extrapolation on correlated data. Square footage and bedroom count are tightly correlated: 5-bedroom homes are almost never 400 square feet. Yet PDP forces that exact combination into the model, generating nonsensical predictions that contaminate the curve. Accumulated Local Effects (ALE) eliminates this by computing prediction differences strictly within narrow local conditional slices of data (e.g. houses between 1,900 and 2,100 sq ft) and accumulating those differences along the axis, keeping the evaluation entirely within real-world data distributions.

In everyday terms

Inspecting medical treatment responses: PDP shows the average patient improvement, ICE plots each patient's individual vital trajectory to catch adverse subgroup reactions, and ALE evaluates responses strictly within appropriate age cohorts rather than dosing toddlers with adult regimens.

02 Step by step

  1. Select the feature of interest $x_S$ (e.g. continuous predictor or low-cardinality discrete variable) and define a grid of evaluation values across its range.
  2. Compute ICE trajectories: for each instance $i$ in the dataset, substitute its feature value with each grid point $z_k$ while preserving all other features $x_C^{(i)}$, and evaluate the model prediction $\hat{f}(z_k, x_C^{(i)})$.
  3. Generate the PDP curve: compute the pointwise arithmetic mean of all ICE curves across each grid point: $\bar{f}_S(z_k) = \frac{1}{n} \sum_{i=1}^n \hat{f}(z_k, x_C^{(i)})$.
  4. Detect interactions in ICE: look for non-parallel or crossing ICE curves; parallel trajectories confirm additive effects, while diverging lines indicate strong interactions with other features.
  5. Compute ALE plots if features are correlated: partition $x_S$ into narrow intervals, calculate local prediction differences for instances falling inside each interval, and accumulate the average differences across bins.
  6. Centre the curves: centre ALE at zero so the vertical axis reflects the deviation from the overall dataset mean prediction.

03 The maths

  1. Partial Dependence Plot (PDP) formulation

    $$\hat{f}_{S}(x_S) = \mathbb{E}_{X_C}\big[ \hat{f}(x_S, X_C) \big] = \frac{1}{n} \sum_{i=1}^n \hat{f}\big(x_S, \, x_C^{(i)}\big)$$

    where $x_S$ is the feature subset under inspection and $X_C$ represents all other conditioning features. By evaluating the sample average over all $n$ background instances $x_C^{(i)}$, PDP marginalises out the effect of conditioning variables. When $X_S$ and $X_C$ are correlated, this marginalisation forces predictions in unobserved feature spaces.

  2. Individual Conditional Expectation (ICE) curves

    $$\hat{f}_{S}^{(i)}(x_S) = \hat{f}\big(x_S, \, x_C^{(i)}\big), \qquad \hat{f}_S(x_S) = \frac{1}{n} \sum_{i=1}^n \hat{f}_S^{(i)}(x_S)$$

    An ICE plot displays the $n$ individual lines $\hat{f}_S^{(i)}$ simultaneously. Centred ICE (c-ICE) anchors each line at zero at the minimum grid point: $\hat{f}_{S,\text{cent}}^{(i)}(x_S) = \hat{f}_S^{(i)}(x_S) - \hat{f}_S^{(i)}(x_{S,\min})$, removing baseline offset differences to highlight heterogeneous slopes.

  3. Accumulated Local Effects (ALE) formulation

    $$\hat{f}_{ALE}(x_S) = \int_{z_0}^{x_S} \mathbb{E}_{X_C \mid X_S = z_S}\left[ \frac{\partial \hat{f}}{\partial X_S}(z_S, X_C) \right] dz_S - c$$

    where $c$ is a centring constant ensuring $\mathbb{E}[\hat{f}_{ALE}(X_S)] = 0$. ALE computes the conditional gradient (or finite differences in empirical bins) strictly among instances whose feature value $X_S$ actually lies near $z_S$, eliminating the unobserved extrapolation errors of PDP.

04 Key takeaways

  • PDP reveals average marginal feature relationships; ICE exposes individual subgroup heterogeneity and interaction effects.
  • Parallel ICE lines indicate pure additive effects; intersecting or diverging lines indicate strong interactions.
  • ALE plots prevent dangerous extrapolation errors when features are correlated by evaluating local conditional differences.
  • Centred ICE (c-ICE) subtracts instance baselines to isolate heterogeneous response slopes.

05 In code

python
import numpy as np

# Model with interaction: f(x1, x2) = x1 * x2 (where x2 in {-1, +1})
rng = np.random.default_rng(42)
n = 60
x1 = rng.uniform(-2, 2, n)
x2 = rng.choice([-1.0, 1.0], size=n)
y = x1 * x2

# Evaluation grid for feature x1
grid = np.linspace(-2, 2, 9)

# Compute ICE curves for all instances
ice_curves = np.zeros((n, len(grid)))
for i in range(n):
    for g_idx, val in enumerate(grid):
        ice_curves[i, g_idx] = val * x2[i]

# PDP is the pointwise average of ICE curves
pdp = np.mean(ice_curves, axis=0)

print(f"Grid values: {[round(float(v), 1) for v in grid]}")
print(f"PDP values:  {[round(float(v), 2) for v in pdp]}")
print(f"ICE curve instance 0 (x2={x2[0]:.0f}): {[round(float(v), 2) for v in ice_curves[0]]}")
print(f"ICE curve instance 1 (x2={x2[1]:.0f}): {[round(float(v), 2) for v in ice_curves[1]]}")

Common pitfalls

  • PDP extrapolation on correlated features: Averaging predictions across synthetic combinations that cannot exist in reality distorts the partial dependence curve with nonsensical model extrapolations.
  • Hidden interactions in flat PDPs: A flat horizontal PDP line does not guarantee that a feature has no effect; equal numbers of positive and negative subgroup effects cancel out to zero unless inspected via ICE.
  • Computational cost of ICE: For large datasets ($n > 100{,}000$), computing predictions across $n$ instances for $K$ grid points requires $n \times K$ model inferences, requiring subsampling to 500 or 1,000 curves.
  • Misinterpreting ALE centring: ALE curves are centred around zero; the vertical axis represents difference from average prediction, not the absolute prediction scale.

06 Check yourself

Q1Why can a Partial Dependence Plot (PDP) show a completely flat horizontal line even when a feature has a massive impact on predictions?

Why: PDP computes the average prediction across all instances. If a feature interacts with another variable such that it increases predictions for half the dataset and decreases them for the other half, the average remains flat. ICE plots unmask these hidden interactions.

Q2What critical flaw in Partial Dependence Plots (PDP) does Accumulated Local Effects (ALE) solve?

Why: When features are correlated (such as height and weight), PDP pairs extreme values together that never appear in reality. ALE computes differences only within narrow local intervals of real data, avoiding out-of-distribution extrapolation.

Q3How does an Individual Conditional Expectation (ICE) plot differ from a Partial Dependence Plot (PDP)?

Why: PDP is the point-by-point average of all individual ICE curves. Viewing the individual ICE curves exposes whether all samples follow the average trend or whether distinct clusters of instances diverge.

Q4What visual pattern in an ICE plot indicates that a feature has purely additive effects with zero interactions with other features?

Why: If a feature operates additively ($f(x_1, x_2) = g(x_1) + h(x_2)$), changing $x_1$ shifts the prediction by the exact same amount regardless of $x_2$. This makes all ICE curves vertical translations of one another (parallel).
