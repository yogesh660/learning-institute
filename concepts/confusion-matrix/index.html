01 The idea

For a binary classifier at a chosen threshold, every prediction is a true positive (TP), false positive (FP), false negative (FN) or true negative (TN). Accuracy, precision, recall, specificity and F1 are all ratios of these four counts.

The matrix forces you to look at the two kinds of mistake separately. In fraud detection a false negative (missed fraud) may cost a thousand times a false positive (an extra check). In spam filtering a false positive (a lost real email) is the expensive one. Accuracy blends them together and hides this.

The counts depend on the threshold. Moving it trades FPs for FNs. That is the idea behind ROC and precision–recall curves.

In everyday terms

A smoke alarm: it can ring for a real fire (TP), ring for toast (FP), stay silent in a fire (FN) or stay silent when all is well (TN).

02 Step by step

  1. Pick a threshold and turn scores into labels.
  2. Count TP, FP, FN, TN on held-out data.
  3. Compute the rates that matter for your costs.
  4. Repeat across thresholds to choose the operating point.

03 Try it

Two overlapping score distributions: real negatives (violet) and real positives (cyan). Slide the threshold and watch the four cells of the matrix update.

Things to try
  1. Find the threshold that catches 90% of positives. How many false positives does it cost?
  2. Turn on imbalance (5% positives) and see how accuracy stays high while recall collapses.

04 The maths

  1. Rates from the matrix

    $$\text{Accuracy} = \frac{TP + TN}{N}, \;\; \text{Recall (TPR)} = \frac{TP}{TP + FN}, \;\; \text{Specificity} = \frac{TN}{TN + FP}, \;\; \text{FPR} = \frac{FP}{FP + TN}$$

    Recall asks "of the real positives, how many did we catch?". FPR asks "of the real negatives, how many did we wrongly flag?".

05 Key takeaways

  • With 1% positives, predicting "negative" always gives 99% accuracy and catches nothing.
  • Always state the threshold alongside the matrix.
  • Normalise rows to read per-class rates.

06 In code

python
from sklearn.metrics import confusion_matrix, ConfusionMatrixDisplay
import matplotlib.pyplot as plt

proba = model.predict_proba(X_te)[:, 1]
cm = confusion_matrix(y_te, proba >= 0.5)          # [[TN, FP], [FN, TP]]
tn, fp, fn, tp = cm.ravel()
print(f"TP={tp} FP={fp} FN={fn} TN={tn}")
ConfusionMatrixDisplay(cm, display_labels=["negative", "positive"]).plot(); plt.show()

Common pitfalls

  • Reporting accuracy on imbalanced data.
  • Forgetting scikit-learn’s layout: rows are true labels, columns predicted, negatives first.
