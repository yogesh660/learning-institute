01 The idea

Logic and knowledge representation enable automated reasoning systems to infer new truthful assertions from established premises. Moving from propositional logic to expressive First-Order Logic (FOL) with universal and existential quantifiers, symbolic inference engines employ unification, Conjunctive Normal Form (CNF) conversion, and Robinson's resolution refutation to prove theorems and query structured ontologies.

Statistical machine learning models identify correlation patterns from numbers, but struggle with strict deductive reasoning, compositional semantics, and explaining why a conclusion follows. Symbolic logic provides a sound and complete framework for deductive truth: if your knowledge base contains true axioms and your inference engine uses valid inference rules, every derived statement is guaranteed to be true.

Propositional logic models binary facts ($P \implies Q$), but cannot express objects, properties, and relationships. First-Order Logic (FOL) introduces constants (Socrates), variables ($x$), predicates (Human($x$)), functions, and quantifiers ($\forall x$ for all $x$, $\exists x$ there exists $x$). Robinson's Resolution theorem proves whether an assertion logically follows by converting all knowledge to CNF and showing that the negated theorem leads to an empty clause (contradiction).

In everyday terms

Knowledge representation is like a strict legal courtroom. A witness cannot simply say "I have a hunch the defendant was there." Every claim must be codified into formal legal statutes (axioms). When the prosecution presents statements A and B, the judge uses universal laws of evidence (modus ponens and resolution) to deduce whether guilt is logically inevitable.

02 Step by step

  1. Knowledge formalisation: translate domain assertions into First-Order Logic sentences with predicates and quantifiers.
  2. Eliminate implications: rewrite $P \implies Q$ as $\neg P \lor Q$ and $P \iff Q$ as $(\neg P \lor Q) \land (\neg Q \lor P)$.
  3. Move negations inward: apply De Morgan's laws and quantifier negation rules ($\neg \forall x P \equiv \exists x \neg P$).
  4. Skolemisation: eliminate existential quantifiers by replacing them with Skolem constants or functions.
  5. Convert to Conjunctive Normal Form (CNF): distribute disjunctions over conjunctions to produce a set of clauses (disjunction of literals).
  6. Execute resolution refutation: negate the goal query, add it to the clause database, and repeatedly apply resolution with unification until deriving the empty clause $\square$.

03 The maths

  1. Resolution Inference Rule

    \frac{A \lor B, \quad \neg B \lor C}{A \lor C}

    Eliminates complementary literals $B$ and $\neg B$ from two clauses to deduce the resolvent clause.

  2. Unification and Most General Unifier (MGU)

    \theta = \text{MGU}(P(x, f(a)), \, P(y, f(z))) \implies \theta = \{x / y, \, z / a\}

    Finds the most general variable substitution $\theta$ that makes two first-order logic terms identical.

04 Key takeaways

  • First-Order Logic allows expressive reasoning over objects, properties, and universal/existential quantifiers.
  • Robinson's Resolution rule operates over Conjunctive Normal Form clauses, providing a sound and complete refutation procedure.
  • Modern knowledge graphs and ontologies (OWL, RDF) formalise domain knowledge for structured neuro-symbolic reasoning.

05 In code

python
def resolve(clause1, clause2):
    """Resolves two CNF clauses by eliminating complementary literals."""
    resolvents = []
    for lit1 in clause1:
        neg_lit1 = lit1[1:] if lit1.startswith('~') else '~' + lit1
        if neg_lit1 in clause2:
            # Resolvent is union minus the complementary pair
            new_clause = (set(clause1) - {lit1}) | (set(clause2) - {neg_lit1})
            resolvents.append(frozenset(new_clause))
    return resolvents

def resolution_prover(knowledge_base, goal_query):
    """Proves goal via resolution refutation by deriving empty clause."""
    # KB: Socrates is human (H). If human, mortal (M): ~H v M
    # Goal: Socrates is mortal (M) -> Negate goal: ~M
    clauses = set(knowledge_base)
    negated_goal = frozenset({'~' + goal_query})
    clauses.add(negated_goal)
    
    new = set()
    while True:
        clause_list = list(clauses)
        for i in range(len(clause_list)):
            for j in range(i + 1, len(clause_list)):
                c1, c2 = clause_list[i], clause_list[j]
                resolvents = resolve(c1, c2)
                for r in resolvents:
                    if len(r) == 0:
                        return True, "Contradiction derived! Empty clause [] proves goal."
                    new.add(r)
        if new.issubset(clauses):
            return False, "No contradiction found. Goal does not entail."
        clauses.update(new)

# Knowledge Base in CNF: Human(socrates), ~Human(x) v Mortal(x)
kb = [
    frozenset({'Human'}),
    frozenset({'~Human', 'Mortal'})
]

success, explanation = resolution_prover(kb, 'Mortal')
print(f"Theorem Proving Result: {success}")
print(f"Explanation: {explanation}")

Common pitfalls

  • Forgetting that First-Order Logic is semi-decidable; if an entailment is false, resolution may run indefinitely without halting.
  • Improper Skolemisation when replacing existential quantifiers that appear inside the scope of universal quantifiers by omitting the function argument.

06 Check yourself

Q1What is the refutation strategy in automated theorem proving with resolution?

Why: Resolution refutation is proof by contradiction: if the negation of the goal combined with true axioms leads to a contradiction (empty clause), the original goal must be true.

Q2What does Skolemisation accomplish during conversion to Conjunctive Normal Form (CNF)?

Why: Skolemisation removes existential quantifiers by asserting that the entity whose existence is guaranteed can be denoted by a specific Skolem constant or function.

Q3Why can Propositional Logic not represent assertions like "All humans are mortal"?

Why: Propositional logic treats facts as indivisible true/false atoms; it cannot represent universal generalisations over sets of objects.
