Word Sense Disambiguation: Lesk Algorithm, WordNet, and Supervised Disambiguation

Polysemy (related meanings, e.g. "mole" as skin spot vs underground animal) and homonymy (unrelated identical words, e.g. financial vs river "bank") require computational sense selection. WordNet organizes English lexicon into synsets (sets of cognitive synonyms) linked by semantic relations such as hypernyms, hyponyms, and meronyms. The Simplified Lesk algorithm scores candidate synsets by counting lexical overlap between synset definitions/examples and context words in the target sentence. Supervised WSD treats sense selection as classification using sense-annotated corpora (e.g. SemCor) or cross-encoder similarity over synset glosses.

01 The idea

Word Sense Disambiguation (WSD) identifies which specific semantic meaning of a polysemous word is active in a given text snippet. Grounded in lexical knowledge bases like WordNet, foundational approaches such as the Lesk algorithm exploit overlap between dictionary definitions and surrounding context words, leading to modern supervised cross-encoder classification.

When humans read "The bass was delicious with butter and garlic", we instantly know "bass" refers to a fish, not a low-frequency musical instrument or a singing voice. We do this by cross-referencing surrounding context clues ("delicious", "butter", "garlic") with our internal mental encyclopaedia. Word Sense Disambiguation (WSD) is the computational task of picking the correct dictionary definition (or "sense") from a set of candidates. The classic Lesk algorithm mimics this process using dictionary definitions: it looks up all definitions of "bass" in a dictionary (like WordNet) and compares them against the surrounding words in the sentence. The sense whose definition and example sentences share the highest word overlap with the context is selected as the winning meaning.

In everyday terms

Imagine a detective holding several identity profiles for suspects sharing the same alias. To find out which suspect committed a crime at a marina, the detective compares words found at the crime scene (tackle, dock, bait) with each suspect's resume. The suspect whose resume mentions boats and fish is identified as the person in question.

02 Step by step

  1. Extract candidate senses: query WordNet or a lexical database for all candidate synsets of the ambiguous target word.
  2. Preprocess context sentence: tokenise, strip common stopwords, and lemmatise surrounding words to their base forms.
  3. Retrieve glosses and examples: compile the text definitions and usage examples for each candidate sense.
  4. Compute lexical overlap: calculate the token intersection count between the lemmatised context and each sense's gloss.
  5. Select maximum overlap sense: pick the sense with the highest count, falling back to WordNet's most frequent sense (MFS) in case of a tie.

04 Key takeaways

  • Word Sense Disambiguation resolves polysemy by assigning ambiguous tokens to discrete, structured sense definitions.
  • The Lesk algorithm provides an intuitive overlap heuristic using dictionary definitions, expandable via hypernym and relational graph traversal.
  • Modern supervised systems combine cross-encoders with synset glosses to achieve high disambiguation accuracy on complex natural text.

05 In code

python
def simplified_lesk(word, sentence, sense_dict):
    """Performs Word Sense Disambiguation using the Simplified Lesk algorithm.
    
    sense_dict: dictionary mapping sense_id to {'definition': str, 'examples': list}
    """
    stopwords = {"the", "a", "an", "is", "was", "with", "and", "in", "on", "at", "to", "for", "of"}
    
    # 1. Clean context words
    context_tokens = set([
        t.lower().strip(".,!?") for t in sentence.split() 
        if t.lower().strip(".,!?") not in stopwords and t.lower() != word.lower()
    ])
    
    best_sense = None
    max_overlap = -1
    overlap_words = []
    
    # 2. Iterate through candidate senses
    for sense_id, data in sense_dict.items():
        gloss_text = data['definition'] + " " + " ".join(data.get('examples', []))
        gloss_tokens = set([
            t.lower().strip(".,!?") for t in gloss_text.split()
            if t.lower().strip(".,!?") not in stopwords
        ])
        
        # Calculate set intersection
        shared = context_tokens.intersection(gloss_tokens)
        overlap_count = len(shared)
        
        if overlap_count > max_overlap:
            max_overlap = overlap_count
            best_sense = sense_id
            overlap_words = list(shared)
            
    return best_sense, max_overlap, overlap_words

# Candidate senses for the ambiguous noun 'bass'
bass_senses = {
    "bass.n.01 (fish)": {
        "definition": "the lean flesh of a saltwater or freshwater fish used for food",
        "examples": ["grilled bass with fresh herbs and lemon"]
    },
    "bass.n.02 (music)": {
        "definition": "an adult male singing voice or low pitch musical instrument like bass guitar",
        "examples": ["he played the bass guitar in a rock rhythm band"]
    }
}

target_sentence = "The grilled bass served with lemon and garlic was fresh and delicious"
chosen_sense, overlap, words = simplified_lesk("bass", target_sentence, bass_senses)

print(f"Target Sentence: '{target_sentence}'")
print(f"Ambiguous Word: 'bass'")
print(f"Selected Sense:  {chosen_sense}")
print(f"Overlap Score:   {overlap} (Shared tokens: {words})")

Common pitfalls

  • Relying strictly on exact word matches in dictionary definitions; if a gloss uses "marine animal" and the sentence says "saltwater fish", standard Lesk produces zero overlap without semantic similarity.
  • Failing to handle the "Most Frequent Sense" (MFS) baseline; in many domains, the top WordNet sense accounts for over 60% of all occurrences, making it hard to beat without robust supervised training.
  • Attempting all-words WSD using brute-force combinatorial search; evaluating combinations of senses across all words in a paragraph leads to exponential complexity $\mathcal{O}(K^N)$.

06 Check yourself

Q1What is the core mechanism of the classic Simplified Lesk algorithm for Word Sense Disambiguation?

Why: Simplified Lesk identifies the correct sense by calculating the number of shared words between the surrounding context and the textual definitions (glosses) of the candidate senses.

Q2What is a "synset" in the WordNet lexical database?

Why: In WordNet, words that express the same meaning are grouped into a synset (synonym set), representing a specific conceptual node in a semantic graph.

Q3Why is the "Most Frequent Sense" (MFS) considered such a formidable baseline in WSD evaluation?

Why: Lexical frequency distributions follow Zipfian dynamics where one primary meaning often accounts for 60-80% of occurrences, making the majority-class heuristic difficult for unsupervised methods to surpass.
