01 The idea

Before deep learning end-to-end representation learning, image retrieval and scene classification adapted techniques directly from natural language processing. Just as documents are represented as a "bag of words" based on dictionary term frequencies, an image can be represented as a Bag of Visual Words (BoVW). By clustering invariant local descriptors (SIFT) into a discrete visual vocabulary, BoVW converts variable numbers of local keypoints into fixed-length vectors for standard classifiers.

Local feature detectors (like SIFT) extract variable numbers of 128-dimensional descriptors per image (e.g. 500 vectors for one image, 2,000 for another). Standard machine learning classifiers (SVMs, Random Forests) require a fixed-length feature vector.

BoVW constructs a Visual Codebook (vocabulary) of size $K$ by clustering millions of SIFT descriptors extracted across a training corpus using K-Means. Each cluster centroid represents a "visual word" (e.g. an eye corner, a bicycle spoke, or a leafy texture).

For a new query image, its local descriptors are assigned to the nearest visual word centroid. The image is represented as a $K$-dimensional histogram of visual word frequencies, weighted using TF-IDF to down-weight ubiquitous background textures (like flat sky or grass).

The primary limitation of standard BoVW is the complete loss of spatial layout (a face with a mouth above the eyes has the same histogram as a normal face). Spatial Pyramid Matching (Lazebnik et al.) overcomes this by partitioning the image into increasingly fine sub-grids ($1 \times 1, 2 \times 2, 4 \times 4$) and concatenating weighted histograms across spatial resolutions.

In everyday terms

Imagine categorising architecture styles (gothic cathedrals vs modern skyscrapers). You do not look at every single brick; instead, you build a mental vocabulary of architectural motifs: "pointed arches", "stained-glass rosettes", "flying buttresses", and "steel I-beams". Describing a cathedral simply involves tallying the frequency of these visual motifs: an image with 5 pointed arches and 2 rosettes is classified as Gothic, regardless of where they appear.

02 Step by step

  1. Extract local invariant descriptors: Run SIFT, SURF, or ORB across all training images to extract millions of 128-D local feature vectors.
  2. Construct visual vocabulary (Codebook): Cluster sampled descriptors into $K$ centroids (typically $K \in [500, 5000]$) using K-Means.
  3. Quantise image features: For each test image, map each extracted descriptor to its nearest visual word centroid in Euclidean distance.
  4. Compute TF-IDF histogram: Accumulate frequency counts into a $K$-dimensional histogram; weight by Inverse Document Frequency (IDF) and normalise.
  5. Construct Spatial Pyramid (SPM): Subdivide image into $1 \times 1$, $2 \times 2$, and $4 \times 4$ grids; compute BoVW histograms within each grid cell and concatenate with geometric weights.
  6. Train linear classifier: Train a Support Vector Machine with Histogram Intersection Kernel or linear solver on the final fixed-length vectors.

03 The maths

  1. Vector Quantisation to Visual Words

    w(x_i) = \operatorname*{arg\,min}_{k \in \{1, \dots, K\}} \| x_i - \mathbf{c}_k \|_2^2

    Quantises continuous local descriptor $x_i \in \mathbb{R}^{128}$ to the index of the nearest codebook centroid $\mathbf{c}_k$.

  2. Spatial Pyramid Match Kernel Weighting

    \mathcal{K}_{\mathrm{SPM}}(X, Y) = \mathcal{I}_L + \sum_{l=0}^{L-1} \frac{1}{2^{L-l}} \left( \mathcal{I}_l - \mathcal{I}_{l+1} \right)

    Weights matches at finer spatial resolutions $l$ exponentially higher than coarse global matches, where $\mathcal{I}$ is histogram intersection.

  3. Histogram Intersection Kernel

    \mathcal{I}(\mathbf{h}_A, \mathbf{h}_B) = \sum_{k=1}^K \min\left( h_{A, k}, \; h_{B, k} \right)

    Measures non-linear overlap between two normalised visual word frequency histograms.

04 Key takeaways

  • Bag of Visual Words converts variable numbers of local keypoints into fixed-length feature vectors.
  • A visual codebook is constructed by clustering SIFT descriptors using K-Means.
  • TF-IDF weighting down-weights common non-informative textures like uniform sky.
  • Spatial Pyramid Matching restores spatial layout by computing histograms across hierarchical sub-grids.

05 In code

python
import numpy as np
from sklearn.cluster import MiniBatchKMeans

# Simulate extracting 100 SIFT-like descriptors across training images
np.random.seed(42)
descriptors_corpus = np.random.randn(500, 128).astype(np.float32)

# 1. Build Visual Vocabulary of K=8 words via K-Means
vocab_size = 8
kmeans = MiniBatchKMeans(n_clusters=vocab_size, random_state=42, n_init='auto')
kmeans.fit(descriptors_corpus)

# 2. Represent a new test image with 20 detected local descriptors
test_descriptors = np.random.randn(20, 128).astype(np.float32)

# Quantise descriptors to nearest visual words
word_assignments = kmeans.predict(test_descriptors)

# 3. Construct Bag of Visual Words histogram
bovw_hist = np.bincount(word_assignments, minlength=vocab_size).astype(np.float32)
# L1 normalise frequency vector
bovw_hist /= np.sum(bovw_hist)

print("Visual Vocabulary Centroids Shape:", kmeans.cluster_centers_.shape)
print("Quantised Visual Words Assigned:  ", word_assignments[:10])
print("Final BoVW Histogram Representation (K=8):")
print(np.round(bovw_hist, 3))
print("Image converted to fixed-length 8-D vector ready for SVM classification!")

Common pitfalls

  • Codebook undersizing or oversizing: If $K$ is too small (e.g. 50), words are too coarse to distinguish objects; if $K$ is too large (e.g. 100,000), quantisation noise prevents matches.
  • Loss of spatial layout in naive BoVW: Standard BoVW treats an image as an unstructured bag; spatial pyramids are mandatory to preserve scene composition.
  • K-Means clustering scalability: Clustering 10 million SIFT descriptors with standard K-Means is computationally prohibitive; use MiniBatchKMeans or Approximate K-Means (FLANN).

06 Check yourself

Q1What is the primary motivation for constructing a "Bag of Visual Words" representation of an image?

Why: Different images yield different numbers of keypoints (e.g. 150 vs 1,200). BoVW maps descriptors to fixed $K$-dimensional codebook histograms, enabling standard SVM/RF classification.

Q2How does Spatial Pyramid Matching (SPM) overcome the primary limitation of the classical Bag of Visual Words model?

Why: Standard BoVW discards spatial relationships completely. Spatial pyramids partition the image into hierarchical sub-regions, preserving spatial context.

Q3What is a "visual word" in the BoVW pipeline?

Why: A visual word is a centroid in 128-D descriptor space representing a prototypical local visual patch or edge pattern.
