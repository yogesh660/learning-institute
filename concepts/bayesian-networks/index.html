01 The idea

A joint distribution over N discrete variables requires 2^N - 1 parameters, causing exponential intractability. Bayesian Networks exploit conditional independence encoded in directed graphs to factorise joint probabilities into compact local conditional probability tables (CPTs).

A full joint probability distribution over $N$ binary random variables requires specifying $2^N - 1$ independent probability values. For a medical diagnostic system or financial risk engine with 50 variables, storing the joint distribution would require over $10^{15}$ parameters—vastly exceeding the capacity of any computer and requiring impossible amounts of training data.

Fortunately, real-world random variables are not all directly dependent on each other: lung cancer depends directly on smoking and radon exposure, but is conditionally independent of age given smoking history and cellular DNA damage. Bayesian Networks (pioneered by Judea Pearl in the 1980s) formalise these structural independencies using Directed Acyclic Graphs (DAGs).

In a Bayesian Network, each node represents a random variable, and directed edges represent direct probabilistic or causal dependencies. The fundamental local Markov property dictates that each node $X_i$ is conditionally independent of all its non-descendants given its parents: $P(X_1, \dots, X_n) = \prod_{i=1}^n P(X_i \mid \operatorname{Parents}(X_i))$.

This factorization slashes parameter complexity from exponential $O(2^N)$ to linear or polynomial $O(N \cdot 2^k)$, where $k$ is the maximum number of parents per node. Furthermore, Pearl's graphical d-separation criterion provides an exact topological algorithm to read off whether any two sets of variables are conditionally independent given observed evidence, enabling exact probabilistic inference via Variable Elimination or Belief Propagation.

In everyday terms

Imagine a corporate hierarchy with a CEO, department managers, team leads, and interns. If an intern needs to know company policy on travel expenses, they ask their direct team lead. Once the team lead gives the instruction, knowing the personal mood of the CEO or the managers in other departments provides zero additional information. The team lead acts as the parent node, shielding the intern from all non-descendants.

03 The maths

  1. Bayesian Network Joint Factorisation Chain Rule

    P(X_1, \dots, X_n) = \prod_{i=1}^n P(X_i \mid \operatorname{Pa}(X_i))

    The joint probability factorises into the product of local conditional distributions for each node conditioned only on its immediate parent set Pa(X_i).

  2. The Three Canonical d-Separation Motifs

    \begin{aligned} \text{Chain: } & A \to B \to C & (A \perp C \mid B) \\ \text{Fork: } & A \leftarrow B \to C & (A \perp C \mid B) \\ \text{Collider: } & A \to B \leftarrow C & (A \perp C \mid \emptyset, \; A \not\perp C \mid B) \end{aligned}

    Chains and forks are blocked when middle node B is observed. Colliders are naturally blocked, but become UNBLOCKED (active) when collider B or its descendant is observed (explaining away).

  3. Variable Elimination Factor Marginalisation

    \phi_{\mathrm{new}}(Y) = \sum_{X} \prod_{k \in \mathcal{F}_X} \phi_k(X, Y)

    Inference operation: multiplies all probability factors involving variable X and sums out X, leaving a reduced factor over remaining variables Y.

04 Key takeaways

  • Compactly parameterises complex joint distributions using Directed Acyclic Graphs (DAGs) and local conditional probabilities.
  • Reduces exponential parameter complexity $O(2^N)$ to polynomial scale by exploiting conditional independence.
  • The local Markov property guarantees each variable is independent of non-descendants given its parents.
  • d-separation provides a topological algorithm to determine conditional independence across chains, forks, and colliders.
  • Colliders ($A \to B \leftarrow C$) exhibit "explaining away": observing $B$ induces conditional dependence between independent causes $A$ and $C$.

05 In code

python
import numpy as np

# Exact Variable Elimination on a Classic 4-Node Bayesian Network
# Structure: Burglar (B) -> Alarm (A) <- Earthquake (E)
#                          Alarm (A) -> JohnCalls (J)

# 1. Define Prior and Conditional Probability Tables (CPTs)
# B in {0, 1}, E in {0, 1}, A in {0, 1}, J in {0, 1}
P_B = np.array([0.999, 0.001])         # P(B=0), P(B=1)
P_E = np.array([0.998, 0.002])         # P(E=0), P(E=1)

# P(A=1 | B, E): shape (2, 2) where index is [B, E]
P_A_given_BE = np.array([
    [0.001, 0.290],  # B=0: E=0 -> 0.001, E=1 -> 0.29
    [0.940, 0.950]   # B=1: E=0 -> 0.940, E=1 -> 0.95
])

# P(J=1 | A): shape (2,) where index is [A]
P_J_given_A = np.array([0.05, 0.90])   # A=0 -> 0.05, A=1 -> 0.90

# 2. Query: What is P(Burglary = 1 | JohnCalls = 1)?
# P(B, J=1) = sum_E sum_A P(B) * P(E) * P(A | B, E) * P(J=1 | A)

joint_B_J = np.zeros(2)

for b in [0, 1]:
    prob_b = 0.0
    for e in [0, 1]:
        for a in [0, 1]:
            # P(B=b)
            p_b = P_B[b]
            # P(E=e)
            p_e = P_E[e]
            # P(A=a | B=b, E=e)
            p_a = P_A_given_BE[b, e] if a == 1 else (1.0 - P_A_given_BE[b, e])
            # P(J=1 | A=a)
            p_j = P_J_given_A[a]
            
            prob_b += p_b * p_e * p_a * p_j
    joint_B_J[b] = prob_b

# Normalise by P(J=1)
posterior_B_given_J = joint_B_J / np.sum(joint_B_J)

# 3. Demonstrate "Explaining Away" (Collider behaviour)
# What if we now observe Earthquake = 1? Does P(Burglary = 1) drop?
joint_B_J_E = np.zeros(2)
for b in [0, 1]:
    prob_b = 0.0
    e = 1  # Given Earthquake = 1
    for a in [0, 1]:
        p_b = P_B[b]
        p_e = P_E[e]
        p_a = P_A_given_BE[b, e] if a == 1 else (1.0 - P_A_given_BE[b, e])
        p_j = P_J_given_A[a]
        prob_b += p_b * p_e * p_a * p_j
    joint_B_J_E[b] = prob_b

posterior_B_given_J_E = joint_B_J_E / np.sum(joint_B_J_E)

print(f"Prior P(Burglary = 1):                {P_B[1]:.4f} (0.1%)")
print(f"Posterior P(Burglary = 1 | JohnCalls=1): {posterior_B_given_J[1]:.4f} ({posterior_B_given_J[1]*100:.1f}%)")
print(f"Posterior P(Burglary = 1 | JohnCalls=1, Earthquake=1): {posterior_B_given_J_E[1]:.4f} ({posterior_B_given_J_E[1]*100:.1f}%)")
print(f"Explaining Away Effect: Learning Earthquake occurred reduced Burglary probability by {((posterior_B_given_J[1] - posterior_B_given_J_E[1])/posterior_B_given_J[1])*100:.1f}%")

Common pitfalls

  • Confusing conditional independence with marginal independence: In a collider ($A \to B \leftarrow C$), $A$ and $C$ are marginally independent, but conditioning on $B$ makes them dependent.
  • Inference complexity on loopy graphs: Exact inference via variable elimination or junction tree is NP-hard in general graphs with high tree-width, requiring approximate MCMC or loopy belief propagation.
  • Causal over-interpretation: A Bayesian network models statistical conditional independence; inferring true causal counterfactuals requires Pearl do-calculus and intervention assumptions.

06 Check yourself

Q1In the collider structure A -> B <- C, what happens to the independence between A and C when B is observed?

Why: In a collider, A and C are marginally independent. Observing the common effect B creates an explaining-away coupling: knowing A occurred explains B, lowering the probability of C.

Q2How does a Bayesian Network reduce the number of parameters required to specify a joint distribution over N binary variables?

Why: Instead of storing all 2^N - 1 states, each node only stores probabilities conditioned on its immediate parents, reducing complexity to O(N * 2^k) where k is max parent count.
