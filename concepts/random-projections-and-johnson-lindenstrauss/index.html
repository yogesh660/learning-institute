01 The idea

Computing PCA on millions of points in 10,000 dimensions is computationally prohibitive. The Johnson–Lindenstrauss lemma proves that projecting onto a surprisingly small random subspace preserves all pairwise distances within a factor of (1 +- epsilon).

Modern machine learning applications routinely process data in ultra-high dimensions: 100,000-word TF-IDF document vectors, 1,536-dimensional neural embeddings, or high-throughput biological mass spectrometry. In these spaces, computing exact Principal Component Analysis (PCA) requires covariance matrix operations and SVD scaling as $O(n d^2)$, which is computationally crushing for large datasets.

Remarkably, the geometry of high-dimensional Euclidean space contains an extraordinary mathematical property: two random vectors drawn uniformly in high dimensions are almost guaranteed to be nearly orthogonal to each other. This geometric phenomenon is the foundation of Random Projections.

In 1984, William B. Johnson and Joram Lindenstrauss proved their celebrated lemma: any collection of $n$ points in Euclidean space $\mathbb{R}^d$ can be projected into a lower-dimensional subspace $\mathbb{R}^k$ such that all pairwise Euclidean distances are preserved within a factor of $(1 \pm \epsilon)$, provided that $k \ge O(\epsilon^{-2} \log n)$.

The most profound consequence of the Johnson–Lindenstrauss lemma is that target dimension $k$ depends strictly on the number of points $n$ and the tolerance $\epsilon$, and is entirely independent of the original dimension $d$! Even more practically, Dimitris Achlioptas (2003) proved that the random projection matrix does not even need Gaussian entries: simple sparse ternary distributions ($R_{ij} \in \{-1, 0, +1\}$) provide identical guarantees while replacing matrix multiplications with fast integer additions.

In everyday terms

Imagine projecting 1,000 glass statues in a dark room by shining a lantern to cast their 2D shadows onto a flat wall. If you align the lantern along one specific axis, statues might block each other or cast squashed shadows. But if you position the lantern at a completely random angle in 3D space, the shadows cast on the wall almost never overlap, faithfully preserving the relative distances between every statue in the room.

03 The maths

  1. The Johnson–Lindenstrauss (JL) Lemma

    (1 - \epsilon) \|u - v\|_2^2 \le \|f(u) - f(v)\|_2^2 \le (1 + \epsilon) \|u - v\|_2^2 \quad \forall u, v \in X

    Guarantees that a linear mapping f preserves all pairwise Euclidean distances within a relative distortion factor epsilon.

  2. Theoretical Target Dimension Bound

    k \ge \frac{4 \log n}{\frac{\epsilon^2}{2} - \frac{\epsilon^3}{3}} = O\left(\frac{\log n}{\epsilon^2}\right)

    The required target dimension k depends only on sample size n and tolerance epsilon, completely independent of original dimension d.

  3. Achlioptas Sparse Random Projection Matrix

    R_{ij} = \sqrt{\frac{3}{k}} \times \begin{cases} +1 & \text{with prob } 1/6 \\ 0 & \text{with prob } 2/3 \\ -1 & \text{with prob } 1/6 \end{cases}

    Ternary random projection matrix where two-thirds of entries are zero, accelerating projection computation by 3x and enabling database sparse arithmetic.

04 Key takeaways

  • Embeds high-dimensional points into a lower-dimensional subspace while preserving pairwise distances within $(1 \pm \epsilon)$ distortion.
  • The Johnson–Lindenstrauss lemma dictates target dimension $k = O(\epsilon^{-2} \log n)$, which is completely independent of input dimension $d$.
  • Data-independent and training-free: the projection matrix is drawn purely at random, requiring zero optimisation or SVD factorisation.
  • Achlioptas sparse projection achieves identical theoretical guarantees while keeping two-thirds of matrix entries at zero.
  • Widely used in nearest-neighbour search indexing (Locality Sensitive Hashing, LSH), streaming algorithms, and compressed sensing.

05 In code

python
import numpy as np

# Random Projections: Gaussian vs Achlioptas Sparse from scratch
np.random.seed(42)

# Generate 500 samples in d = 2,000 dimensions
n_samples = 500
d_features = 2000
X = np.random.normal(0, 1, (n_samples, d_features))

# Calculate theoretical JL target dimension for epsilon = 0.20
epsilon = 0.20
# k >= 4 * log(n) / (eps^2 / 2 - eps^3 / 3)
k_bound = int(np.ceil((4 * np.log(n_samples)) / (epsilon**2 / 2 - epsilon**3 / 3)))
k = 300  # Target dimension (compressed from 2,000 to 300)

# 1. Gaussian Random Projection Matrix: R_ij ~ N(0, 1/k)
R_gaussian = np.random.normal(0, 1.0 / np.sqrt(k), (d_features, k))
X_proj_gauss = X @ R_gaussian

# 2. Achlioptas Sparse Random Projection Matrix (s = 3)
# 2/3 of entries are 0, entries are +sqrt(3/k) or -sqrt(3/k)
s = 3
rand_draw = np.random.uniform(0, 1, (d_features, k))
R_sparse = np.zeros((d_features, k))
R_sparse[rand_draw < 1.0 / (2 * s)] = np.sqrt(s / k)
R_sparse[rand_draw > 1.0 - 1.0 / (2 * s)] = -np.sqrt(s / k)
X_proj_sparse = X @ R_sparse

# Evaluate pairwise distance distortion across 1,000 random pairs
n_pairs = 1000
idx_u = np.random.choice(n_samples, n_pairs)
idx_v = np.random.choice(n_samples, n_pairs)
valid = idx_u != idx_v
idx_u, idx_v = idx_u[valid], idx_v[valid]

# Original squared distances
dist_orig_sq = np.sum((X[idx_u] - X[idx_v])**2, axis=1)

# Projected squared distances
dist_gauss_sq = np.sum((X_proj_gauss[idx_u] - X_proj_gauss[idx_v])**2, axis=1)
dist_sparse_sq = np.sum((X_proj_sparse[idx_u] - X_proj_sparse[idx_v])**2, axis=1)

# Distortion ratios: ||f(u) - f(v)||^2 / ||u - v||^2
ratio_gauss = dist_gauss_sq / dist_orig_sq
ratio_sparse = dist_sparse_sq / dist_orig_sq

print(f"Original dimension: {d_features} -> Projected dimension: {k} ({(1 - k/d_features)*100:.1f}% reduction)")
print(f"Theoretical JL target bound (eps={epsilon}): k >= {k_bound}")
print(f"Target distortion range: [{1 - epsilon:.2f}, {1 + epsilon:.2f}]")

print(f"\nGaussian Projection  - Mean ratio: {np.mean(ratio_gauss):.3f}, 99% interval: [{np.percentile(ratio_gauss, 0.5):.3f}, {np.percentile(ratio_gauss, 99.5):.3f}]")
print(f"Sparse Achlioptas   - Mean ratio: {np.mean(ratio_sparse):.3f}, 99% interval: [{np.percentile(ratio_sparse, 0.5):.3f}, {np.percentile(ratio_sparse, 99.5):.3f}]")
print(f"Sparse Matrix Sparsity: {np.mean(R_sparse == 0)*100:.1f}% zeros (3x faster multiplication!)")

Common pitfalls

  • Inner product distortion vs Euclidean distance: While JL preserves Euclidean distances $|u - v|$, preserving dot products $u^T v$ requires normalising vectors to unit length.
  • Only applies to Euclidean ($L_2$) norm: The JL lemma does not hold for Manhattan ($L_1$), Chebyshev ($L_\infty$), or general $L_p$ norms.
  • Extreme sample size scaling: Because $k \propto \log n$, if $n$ is hundreds of millions, the required $k$ might exceed the original dimension $d$.

06 Check yourself

Q1What is the most surprising property of the target dimension k in the Johnson–Lindenstrauss lemma?

Why: The JL lemma bound k >= O(log(n) / eps^2) contains no dependence on original dimension d, allowing 1,000,000-dimensional data to be compressed to the same k as 1,000-dimensional data.

Q2Why is Achlioptas sparse random projection computationally faster than Gaussian random projection?

Why: The Achlioptas ternary distribution has 2/3 zeros and entries in {-1, 0, +1}, turning dense floating-point matrix multiplications into fast sparse integer additions.
