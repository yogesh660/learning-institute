GPT and decoder-only models

Generative Pre-trained Transformer (GPT) models established the decoder-only architecture as the dominant paradigm for modern Large Language Models (LLMs). By training on the standard autoregressive language modelling objective—predicting the next token given preceding context—GPT models scale cleanly with compute, data, and parameters. Using causal lower-triangular attention masking to enforce temporal directionality, GPT unifies natural language generation, reasoning, and few-shot in-context learning without requiring task-specific architecture modifications.

01 The idea

Before GPT-3, the dominant paradigm in machine learning was task-specific fine-tuning: you pre-trained a model, threw away its output head, and trained a new classifier on thousands of human-annotated examples for each specific task. GPT proved a startling alternative: if you train a sufficiently large decoder-only Transformer on the simple task of predicting the next word across internet-scale text, the model spontaneously develops the ability to translate languages, answer factual questions, write computer code, and reason through logic puzzles purely by prompting it with a few demonstration examples.

Autoregressive factorization and the chain rule of probability: The joint probability of any sequence of words factorises exactly using the chain rule of probability: P(w_1, ..., w_T) = prod_{t=1}^T P(w_t | w_

Causal attention masking: In standard self-attention, token i computes dot products with all tokens j in the sequence. To prevent information leakage from future tokens (w_{i+1}, ..., w_T), causal attention adds an upper-triangular mask of negative infinity (-inf) to the attention logits before the softmax step. Because exp(-inf) = 0, every token is mathematically prevented from looking ahead, guaranteeing valid autoregressive generation.

The emergence of in-context learning through scale: As language models grew from GPT-1 (117M parameters) to GPT-2 (1.5B) and GPT-3 (175B), their capabilities underwent a qualitative shift. Rather than updating model weights via gradient descent, users could steer the model's behaviour at inference time simply by prepending natural language instructions and a few input-output demonstrations (few-shot prompting). The model recognizes the pattern and completes the prompt accordingly.

In everyday terms

Think of reading an enthralling mystery novel. As you turn each page, you constantly anticipate what happens next based strictly on the clues you have read so far. You are never allowed to peek ahead at the final chapter (causal masking). If you read ten thousand mystery novels in this manner, you do not merely learn vocabulary: you learn the laws of physics, human psychology, forensic detective procedure, and dramatic narrative structure—because accurately guessing the next word requires understanding the world that generated the text.

03 The maths

  1. Autoregressive sequence log-likelihood objective

    \mathcal{L}_{\text{AR}}(\theta) = -\sum_{t=1}^T \log P(w_t \mid w_1, w_2, \dots, w_{t-1}; \theta)

    The causal language modelling objective trains network parameters $\theta$ to maximise the log-probability of every token conditioned strictly on its preceding context tokens, evaluated across the entire training corpus.

  2. Causal masked multi-head self-attention

    \operatorname{Attention}(Q, K, V) = \operatorname{softmax}\left( \frac{Q K^T}{\sqrt{d_k}} + M \right) V, \quad M_{i, j} = \begin{cases} 0 & j \le i \\ -\infty & j > i \end{cases}

    The additive mask $M \in \mathbb{R}^{T \times T}$ contains $-\infty$ in its strict upper triangle. When passed through the softmax exponentiation, $\exp(-\infty) = 0$, ensuring future tokens receive exactly zero attention weight.

04 Key takeaways

  • GPT models use a decoder-only Transformer architecture trained autoregressively on next-token prediction.
  • Causal lower-triangular masking prevents tokens from attending to future positions, ensuring temporal validity.
  • During training, teacher forcing enables parallel evaluation of all sequence positions in a single forward pass.
  • Scaling model parameters, dataset volume, and training compute yields emergent capabilities like few-shot in-context learning.
  • At inference time, Key-Value (KV) caching preserves past key and value vectors, avoiding redundant O(T^2) recomputations.

05 In code

python
import numpy as np

class MiniCausalAttention:
    """
    Simulation of Causal (Autoregressive) Multi-Head Self-Attention
    with lower-triangular masking and next-token generation.
    """
    def __init__(self, d_model=4):
        self.d_model = d_model
        
    def causal_attention(self, Q, K, V):
        """
        Compute causal masked self-attention.
        Q, K, V shapes: (seq_len, d_model)
        """
        T = Q.shape[0]
        # Scaled dot-product: (T x T)
        scores = np.dot(Q, K.T) / np.sqrt(self.d_model)
        
        # Upper-triangular mask of -inf
        mask = np.triu(np.full((T, T), -np.inf), k=1)
        masked_scores = scores + mask
        
        # Softmax over columns
        exp_scores = np.exp(masked_scores - np.max(masked_scores, axis=-1, keepdims=True))
        attn_weights = exp_scores / np.sum(exp_scores, axis=-1, keepdims=True)
        
        output = np.dot(attn_weights, V)
        return output, attn_weights

def sample_next_token(logits, temperature=0.7):
    """Temperature sampling over vocabulary logits."""
    scaled = logits / max(temperature, 1e-5)
    exp_l = np.exp(scaled - np.max(scaled))
    probs = exp_l / np.sum(exp_l)
    return np.random.choice(len(probs), p=probs), probs

# Sample sequence of 4 tokens
vocab = ["The", "neural", "network", "generates", "text", "smoothly"]
tokens = ["The", "neural", "network", "generates"]
T = len(tokens)

np.random.seed(42)
d = 4
mock_embeddings = np.random.randn(T, d)

attn_layer = MiniCausalAttention(d_model=d)
output, weights = attn_layer.causal_attention(mock_embeddings, mock_embeddings, mock_embeddings)

print(f"Causal Attention Weights Matrix (shape {T}x{T}):")
print("Notice strict zeros in upper triangle (tokens cannot look to the future):\n")
for i, tok in enumerate(tokens):
    row_str = " ".join([f"{w:6.3f}" for w in weights[i]])
    print(f"  Token {i} ('{tok:<9}'): [ {row_str} ]")

# Next-token prediction head simulation
mock_head_weights = np.random.randn(d, len(vocab))
last_hidden_state = output[-1]  # Representation of last token ('generates')
next_token_logits = np.dot(last_hidden_state, mock_head_weights)

sampled_idx, probs = sample_next_token(next_token_logits, temperature=0.7)
print(f"\nNext Token Predictions given: '{' '.join(tokens)}'")
for v_idx, word in enumerate(vocab):
    print(f"  P('{word}'): {probs[v_idx]:.4f}")
print(f"\nSampled next token: '{vocab[sampled_idx]}'")

Common pitfalls

  • Neglecting causal masking in decoder training: Forgetting to apply the upper-triangular mask allows the model to see future tokens during self-attention, causing training loss to drop to zero while rendering generation completely broken.
  • Quadratic inference slowdown without KV caching: Generating a sequence of length T by re-encoding all preceding tokens at every step takes O(T^2) operations. Always maintain a KV cache during generation to achieve O(1) step complexity.
  • Greedy decoding degradation: Pure greedy argmax decoding (temperature = 0) frequently causes generative models to enter degenerate repetitive loops. Use nucleus (top-p) sampling with p in [0.9, 0.95] for creative text.
  • Context window truncation without sliding buffers: Passing prompts longer than the model's context window (e.g. 2,048 or 4,096 tokens) triggers out-of-bounds indexing; ensure prompts are truncated or use rotary positional embeddings (RoPE) with context extension.

06 Check yourself

Q1Why do decoder-only GPT models apply a causal lower-triangular mask to the self-attention matrix?

Why: If tokens could attend to future positions, next-token prediction would be trivial because the model would simply copy the answer from position t+1. The causal mask forces attention weights on positions j > i to zero.

Q2What is the primary operational advantage of maintaining a Key-Value (KV) cache during autoregressive inference?

Why: Because past tokens never change, their K and V projections are identical at every generation step. Storing them in a KV cache allows the model to compute attention for just the single newly generated token, yielding massive inference speedups.

Q3How does few-shot in-context learning in GPT-3 differ from standard fine-tuning?

Why: In-context learning is entirely gradient-free at inference time. The model relies on its pre-trained pattern recognition capabilities to condition on prompt demonstrations and infer the required mapping without parameter updates.
