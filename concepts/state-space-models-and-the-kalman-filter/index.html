01 The idea

Whether tracking satellite orbits, estimating vehicle velocity from GPS, or forecasting latent macroeconomic trends, real-world signals are obscured by measurement noise. The Kalman filter recursively computes the exact minimum mean squared error Bayesian estimate of hidden states.

A state-space model represents a dynamical system across time using two core components: a hidden state vector $x_t$ that evolves dynamically according to physical laws or autoregressive processes, and an observed measurement vector $y_t$ that reflects noisy, incomplete linear projections of that hidden state. The transition equation $x_t = F_t x_{t-1} + B_t u_t + w_t$ governs state progression with process noise $w_t \sim \mathcal{N}(0, Q_t)$, while the measurement equation $y_t = H_t x_t + v_t$ captures observations subject to sensor noise $v_t \sim \mathcal{N}(0, R_t)$.

The challenge is that neither process dynamics nor sensor readings are immaculate. If you rely solely on forward physics (process model), errors accumulate unbounded over time. If you rely solely on instantaneous sensor measurements, high-frequency measurement noise corrupts estimates. The Kalman filter provides the mathematically optimal fusion: it combines the dynamical prediction with the incoming sensor measurement, weighting each strictly in proportion to their relative inverse uncertainties.

The filter operates as a two-phase recursive algorithm: Predict and Update. In the Predict phase, the state estimate and error covariance are projected forward one step in time using system dynamics $F_t$ and process noise $Q_t$. In the Update phase, an incoming measurement $y_t$ is compared against predicted observation $H_t \hat{x}_{t \mid t-1}$ to form the innovation (or measurement residual) $\tilde{y}_t$. The Kalman gain $K_t$ balances prior uncertainty $P_{t \mid t-1}$ against measurement noise $R_t$, steering the posterior state estimate toward whichever source is cleaner.

Under linear dynamics and Gaussian noise distributions, the Kalman filter is the exact optimal Bayesian posterior estimator, producing the exact conditional mean and covariance at every time step. Even when noise distributions are non-Gaussian, the Kalman filter remains the Best Linear Unbiased Estimator (BLUE).

In everyday terms

Imagine steering a yacht through thick coastal fog at midnight. Your nautical dead-reckoning equations predict your position based on compass heading and engine throttle (the dynamic state prediction), but sea currents steadily drift your vessel off course (process noise). Every five minutes, a lighthouse flash briefly illuminates a shoreline buoy (noisy sensor measurement). The Kalman filter is the seasoned navigator who compares the dead-reckoning position against the momentary glimpse of the buoy, shifting the helm by an optimal correction that yields the most accurate position on the chart.

03 The maths

  1. State-Space Formulation

    x_t = F_t x_{t-1} + B_t u_t + w_t, \quad y_t = H_t x_t + v_t, \quad w_t \sim \mathcal{N}(0, Q_t), \; v_t \sim \mathcal{N}(0, R_t)

    Linear Gaussian state-space model relating unobserved hidden state x_t to observable measurements y_t via transition matrix F_t and observation matrix H_t.

  2. Predict Step (Prior Distribution)

    \hat{x}_{t \mid t-1} = F_t \hat{x}_{t-1 \mid t-1}, \quad P_{t \mid t-1} = F_t P_{t-1 \mid t-1} F_t^T + Q_t

    Extrapolates state mean and covariance forward in time prior to incorporating measurement at step t, compounding existing uncertainty with process noise Q_t.

  3. Update Step (Kalman Gain and Posterior)

    K_t = P_{t \mid t-1} H_t^T (H_t P_{t \mid t-1} H_t^T + R_t)^{-1}, \quad \hat{x}_{t \mid t} = \hat{x}_{t \mid t-1} + K_t (y_t - H_t \hat{x}_{t \mid t-1})

    Kalman gain K_t minimises the trace of posterior covariance matrix P_{t|t}. When sensor noise R_t is small, K_t approaches H^{-1} trusting measurement; when R_t is massive, K_t approaches 0 trusting prediction.

04 Key takeaways

  • Recursive online Bayesian estimator: processes observations sequentially without needing to store past history.
  • Optimal under Gaussian noise: minimises Mean Squared Error (MMSE) across all estimators for linear Gaussian models.
  • BLUE under non-Gaussian noise: Best Linear Unbiased Estimator even when noise distributions deviate from Gaussianity.
  • The Kalman gain K_t dynamically balances model prediction against sensor noise based on their relative covariances.
  • Forms the foundation for non-linear state estimation: Extended Kalman Filter (EKF via Jacobians) and Unscented Kalman Filter (UKF via sigma points).

05 In code

python
import numpy as np

# 1D Kinematic Tracking: Position and Velocity
# True physics: constant velocity with random acceleration shocks
np.random.seed(42)
dt = 0.1
n_steps = 100

# State transition matrix F: [position, velocity]^T
F = np.array([[1.0, dt],
              [0.0, 1.0]])

# Measurement matrix H: observe position only
H = np.array([[1.0, 0.0]])

# Noise covariances
q_var = 0.1   # Process noise acceleration variance
Q = np.array([[0.25 * dt**4, 0.5 * dt**3],
              [0.5 * dt**3, dt**2]]) * q_var
r_var = 4.0   # Measurement noise variance (noisy sensor)
R = np.array([[r_var]])

# Simulate true trajectory and noisy measurements
true_state = np.array([0.0, 5.0])  # Initial: pos=0m, vel=5m/s
true_positions = []
noisy_measurements = []

for _ in range(n_steps):
    process_shock = np.random.multivariate_normal([0, 0], Q)
    true_state = F @ true_state + process_shock
    sensor_noise = np.random.normal(0, np.sqrt(r_var))
    measurement = H @ true_state + sensor_noise
    
    true_positions.append(true_state[0])
    noisy_measurements.append(measurement[0])

# Kalman Filter Estimation
x_hat = np.array([0.0, 0.0])       # Initial estimate
P = np.array([[10.0, 0.0],
              [0.0, 10.0]])        # High initial uncertainty

estimated_positions = []
estimated_velocities = []

for y_t in noisy_measurements:
    # --- Predict Step ---
    x_pred = F @ x_hat
    P_pred = F @ P @ F.T + Q
    
    # --- Update Step ---
    y_meas = np.array([y_t])
    innovation = y_meas - H @ x_pred
    S = H @ P_pred @ H.T + R
    K = P_pred @ H.T @ np.linalg.inv(S)
    
    x_hat = x_pred + K @ innovation
    P = (np.eye(2) - K @ H) @ P_pred
    
    estimated_positions.append(x_hat[0])
    estimated_velocities.append(x_hat[1])

# Calculate Root Mean Squared Errors
rmse_noisy = np.sqrt(np.mean((np.array(noisy_measurements) - np.array(true_positions))**2))
rmse_kalman = np.sqrt(np.mean((np.array(estimated_positions) - np.array(true_positions))**2))

print(f"Raw measurement position RMSE: {rmse_noisy:.3f} m")
print(f"Kalman filtered position RMSE: {rmse_kalman:.3f} m")
print(f"Noise reduction: {(1 - rmse_kalman / rmse_noisy) * 100:.1f}%")
print(f"Final velocity estimate: {estimated_velocities[-1]:.3f} m/s (true: {true_state[1]:.3f} m/s)")

Common pitfalls

  • Filter divergence from mis-specified process noise Q: Setting Q unrealistically small causes the filter to overconfidently disregard new measurements, diverging from the true trajectory when accelerations or shocks occur.
  • Numerical instability in covariance update: Repeated subtractions in P_{t|t} = (I - K_t H_t) P_{t|t-1} can lose positive semi-definiteness due to floating-point rounding; Joseph form (I - KH)P(I - KH)^T + KRK^T or square-root Cholesky filtering ensures numerical stability.
  • Non-linear dynamics breakdown: Standard Kalman filtering requires strictly linear F and H; applying it directly to non-linear systems leads to catastrophic divergence.

06 Check yourself

Q1What occurs to the Kalman gain K_t as the measurement noise covariance R_t approaches infinity?

Why: From K_t = P H^T (H P H^T + R)^{-1}, as R -> infinity the inverse matrix vanishes toward zero, driving K_t -> 0. Consequently x_hat = x_pred + 0 = x_pred, ignoring useless sensor data.

Q2Why is the Kalman filter preferred over full batch historical smoothing for real-time robotic navigation?

Why: Because it is Markovian and recursive, the Kalman filter updates state estimates in constant O(1) time and memory per observation, making it ideal for online real-time embedded systems.
