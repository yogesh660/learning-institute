Hallucination and Factuality in LLMs: Detection, Calibration, and Grounding

Hallucinations divide into closed-domain unfaithfulness (contradicting provided source context) and open-domain factual fabrication (violating external world knowledge). Root causes include knowledge boundary deficits in pretraining corpora, exposure bias, out-of-distribution prompts, and sycophantic alignment incentives. Detection frameworks leverage self-consistency sampling, internal hidden-state probes, and automated LLM-as-a-judge fact verification (FactScore). Mitigation techniques combine external retrieval augmentation (RAG), verifiable citations, calibrated decoding temperatures, and constrained generation.

01 The idea

Large language models are probabilistic sequence generators optimised for grammatical fluency rather than factual truth, frequently producing confident but fabricated assertions known as hallucinations. Quantifying factuality requires taxonomy separation (faithfulness vs factual correctness), uncertainty calibration, self-consistency probes, and retrieval grounding.

When an LLM produces text, it does not query an internal database of certified facts; it samples the next token according to conditional likelihood $P(w_t \mid w_{<t})$. A sentence like "Neil Armstrong walked on Mars in 1973" has high syntactic plausibility and uses familiar space-exploration terminology, so the model may assign it high conditional probability if conditioned on ambiguous context. Because the model has no built-in distinction between true historical events and plausible-sounding fiction, it asserts falsehoods with the exact same fluent, authoritative tone as verifiable facts. Measuring and mitigating hallucination requires grounding outputs in retrieved evidence documents and testing whether the model's internal token probabilities reflect true calibration uncertainty.

In everyday terms

Imagine a charismatic student taking an oral exam who has memorized thousands of textbook phrases but never actually conducted an experiment. When asked a difficult question about a subject they do not know, their instinct is to improvise a polished, impressive-sounding answer rather than admit ignorance. Grounding is requiring the student to point to an open textbook page for every single claim they make.

02 Step by step

  1. Extract atomic claims: parse complex generated answers into independent, testable proposition statements (atomic facts).
  2. Retrieve reference evidence: perform dense or hybrid search across authoritative knowledge corpora for each atomic proposition.
  3. Verify entailment: use a fine-tuned NLI model or cross-encoder to classify whether the retrieved text entails, contradicts, or is neutral toward the claim.
  4. Probe generation confidence: measure token-level predictive entropy and logit margins along with semantic self-consistency across diverse decoding paths.
  5. Enforce grounding constraints: instruct the model to produce verifiable citations and refuse generation when retrieval confidence falls below threshold.

04 Key takeaways

  • LLMs generate syntactically plausible sequences without intrinsic awareness of empirical truth.
  • FactScore provides a granular evaluation framework by decomposing responses into testable atomic claims.
  • Grounding generation in external retrieval systems and measuring semantic consistency dramatically reduces hallucination rates.

05 In code

python
import numpy as np

def evaluate_factscore(atomic_claims, knowledge_base):
    """Evaluates factual precision of extracted claims against verified knowledge."""
    supported_flags = []
    
    for claim in atomic_claims:
        subject, predicate, obj = claim
        # Check if relation exists in verified knowledge tuples
        is_supported = any(
            k_sub == subject and k_pred == predicate and k_obj == obj
            for (k_sub, k_pred, k_obj) in knowledge_base
        )
        supported_flags.append(is_supported)
        
    precision = np.mean(supported_flags)
    return precision, supported_flags

def self_consistency_entropy(sampled_answers):
    """Computes semantic agreement entropy across multiple stochastic generations."""
    unique_answers, counts = np.unique(sampled_answers, return_counts=True)
    probs = counts / np.sum(counts)
    entropy = -np.sum(probs * np.log2(probs + 1e-12))
    return entropy, unique_answers[np.argmax(counts)]

# Verified Knowledge Base (Subject, Predicate, Object)
kb = [
    ("Alan Turing", "born_in", "London"),
    ("Alan Turing", "died_in", "Wilmslow"),
    ("Alan Turing", "invented", "Turing Machine")
]

# Model output decomposed into atomic claims
claims_to_audit = [
    ("Alan Turing", "born_in", "London"),      # Factually correct
    ("Alan Turing", "invented", "Turing Machine"), # Factually correct
    ("Alan Turing", "born_in", "Cambridge")     # Hallucinated contradiction!
]

fact_score, flags = evaluate_factscore(claims_to_audit, kb)

# Self-consistency sampling across 5 runs
samples = ["London", "London", "London", "Cambridge", "London"]
entropy, consensus = self_consistency_entropy(samples)

print(f"FactScore Precision: {fact_score * 100:.1f}%")
for claim, passed in zip(claims_to_audit, flags):
    status = "VERIFIED" if passed else "HALLUCINATION"
    print(f"  {claim} -> [{status}]")

print(f"\nSelf-Consistency Consensus Answer: '{consensus}'")
print(f"Sampling Uncertainty Entropy: {entropy:.3f} bits")

Common pitfalls

  • Confusing linguistic fluency with factual veracity; models are frequently most eloquent when delivering complete fabrications.
  • Relying solely on perplexity or generation loss to identify hallucinations; incorrect statements often have low perplexity because they use common words.
  • Evaluating factuality using an LLM judge without providing ground-truth reference material, causing the judge model to hallucinate its own evaluation.

06 Check yourself

Q1What is the primary difference between faithfulness and factual correctness in language generation?

Why: Faithfulness assesses whether the model remains true to the specific reference document provided in the prompt, whereas factual correctness evaluates consistency with external world facts.

Q2How does the FactScore metric measure the factuality of long-form biographical text?

Why: FactScore decomposes complex paragraphs into discrete atomic claims and verifies what fraction of those individual facts are corroborated by reference texts.

Q3Why does self-consistency sampling help identify potential hallucinations in reasoning tasks?

Why: When a model lacks genuine certainty, diverse temperature-sampled generations diverge wildly into different fabrications, producing high entropy and signalling potential hallucinations.
