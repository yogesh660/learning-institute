01 The idea

Why do ensembles of diverse models consistently dominate competitive data science? Ensemble theory formalises how combining multiple learners manipulates the bias-variance trade-off.

The foundational insight of ensemble learning traces back to the Condorcet Jury Theorem of 1785: if a group of independent decision-makers each has a probability $p > 0.5$ of being correct, the probability that a majority vote is correct approaches 1 as jury size grows. In machine learning, combining multiple individual learners produces predictions that are strictly superior to any single constituent model.

However, different ensemble paradigms attack the bias-variance trade-off through fundamentally different mathematical mechanisms. The three major pillars are Bagging, Boosting, and Stacking.

Bagging (Bootstrap Aggregation) attacks Variance. It trains high-variance, low-bias models (such as deep decision trees) independently in parallel on bootstrap resampled datasets. If each individual model has variance $\sigma^2$ and pairwise prediction correlation $\rho$, averaging $B$ models yields ensemble variance $\rho \sigma^2 + \frac{1 - \rho}{B} \sigma^2$. Random Forests reduce $\rho$ by randomly subsampling features at each split, driving variance down toward zero while preserving low bias.

Boosting attacks Bias. It trains shallow, high-bias "weak learners" sequentially. Each subsequent model is trained to predict the residual errors or reweighted mistakes of the preceding ensemble, effectively taking a step along the negative gradient of the loss function in function space.

Stacking (Stacked Generalisation) uses meta-learning. Instead of relying on hand-crafted voting rules, it trains heterogeneous base learners (e.g. a Support Vector Machine, a Random Forest, and a Neural Network) and uses their out-of-fold cross-validated predictions as input features to train a secondary "meta-model" (such as Ridge or Logistic regression).

In everyday terms

Imagine diagnosing a complex medical illness. Bagging is consulting 20 independent cardiologists who each examine different subsets of the patient medical records; averaging their diagnoses cancels out individual eccentricities. Boosting is a consultation where Doctor 1 offers an initial assessment, Doctor 2 investigates only the symptoms Doctor 1 missed, and Doctor 3 resolves remaining ambiguities. Stacking is convening a cardiologist, a neurologist, and an oncologist, then having an experienced chief medical officer synthesise their divergent findings into a final diagnosis.

03 The maths

  1. Bagging Variance Reduction Formula

    \operatorname{Var}\left(\frac{1}{B} \sum_{b=1}^B \hat{f}_b(x)\right) = \rho(x) \sigma^2(x) + \frac{1 - \rho(x)}{B} \sigma^2(x)

    As ensemble size B -> infinity, the second term vanishes, leaving rho * sigma^2. Feature subsampling in Random Forests lowers correlation rho, drastically reducing irreducible ensemble variance.

  2. Gradient Boosting Functional Gradient Step

    f_m(x) = f_{m-1}(x) + \eta \arg\min_{h} \sum_{i=1}^n \left( -\left[\frac{\partial L(y_i, f_{m-1}(x_i))}{\partial f_{m-1}(x_i)}\right] - h(x_i) \right)^2

    Each new weak learner h approximates the negative gradient of the loss function, performing functional gradient descent in prediction space.

  3. Stacking Out-of-Fold Meta-Dataset

    z_{i} = \left[ \hat{f}_1^{-k(i)}(x_i), \; \hat{f}_2^{-k(i)}(x_i), \; \dots, \; \hat{f}_M^{-k(i)}(x_i) \right]^T, \quad \hat{y}_i = g(z_i)

    Meta-features z_i are generated strictly out-of-fold (using models trained on all folds except fold k containing sample i), preventing data leakage and target memorisation in meta-learner g.

04 Key takeaways

  • Ensemble theory proves that combining diverse models produces predictions superior to any individual constituent.
  • Bagging attacks variance: averages independent models trained on bootstrap datasets; Random Forests reduce pairwise correlation $\rho$.
  • Boosting attacks bias: trains weak learners sequentially along the negative gradient of the loss function.
  • Stacking combines heterogeneous models via a secondary meta-model trained on out-of-fold cross-validated predictions.
  • Diversity is paramount: combining identical or highly correlated models provides zero variance reduction and zero boosting gain.

05 In code

python
import numpy as np
from sklearn.tree import DecisionTreeRegressor
from sklearn.linear_model import Ridge
from sklearn.model_selection import KFold

# Comparing Bagging, Boosting, and Stacking from scratch
np.random.seed(42)
n_samples = 400

# Synthetic non-linear data with high noise
X = np.random.uniform(-3, 3, (n_samples, 2))
y = np.sin(X[:, 0]) * np.cos(X[:, 1]) + 0.5 * X[:, 0] + np.random.normal(0, 0.4, n_samples)

n_train = 250
X_train, X_test = X[:n_train], X[n_train:]
y_train, y_test = y[:n_train], y[n_train:]

# 1. Bagging (Variance Reduction)
n_bags = 30
bag_preds = np.zeros((len(X_test), n_bags))
for b in range(n_bags):
    boot_idx = np.random.choice(n_train, size=n_train, replace=True)
    tree = DecisionTreeRegressor(max_depth=8, random_state=b)
    tree.fit(X_train[boot_idx], y_train[boot_idx])
    bag_preds[:, b] = tree.predict(X_test)
pred_bagging = np.mean(bag_preds, axis=1)

# 2. Gradient Boosting (Bias Reduction)
n_boost_trees = 30
learning_rate = 0.1
pred_boost_train = np.full(n_train, np.mean(y_train))
pred_boost_test = np.full(len(X_test), np.mean(y_train))

for m in range(n_boost_trees):
    residuals = y_train - pred_boost_train
    shallow_tree = DecisionTreeRegressor(max_depth=3, random_state=m)
    shallow_tree.fit(X_train, residuals)
    pred_boost_train += learning_rate * shallow_tree.predict(X_train)
    pred_boost_test += learning_rate * shallow_tree.predict(X_test)

# 3. Stacking with Out-of-Fold Meta-Features
kf = KFold(n_splits=5, shuffle=True, random_state=42)
oof_preds = np.zeros((n_train, 2))
test_base_preds = np.zeros((len(X_test), 2))

# Base learner 1: Deep Tree; Base learner 2: Shallow Tree
for tr_idx, val_idx in kf.split(X_train):
    m1 = DecisionTreeRegressor(max_depth=7, random_state=42)
    m2 = DecisionTreeRegressor(max_depth=3, random_state=42)
    m1.fit(X_train[tr_idx], y_train[tr_idx])
    m2.fit(X_train[tr_idx], y_train[tr_idx])
    oof_preds[val_idx, 0] = m1.predict(X_train[val_idx])
    oof_preds[val_idx, 1] = m2.predict(X_train[val_idx])

# Fit full base models on train, predict test
m1_full = DecisionTreeRegressor(max_depth=7, random_state=42).fit(X_train, y_train)
m2_full = DecisionTreeRegressor(max_depth=3, random_state=42).fit(X_train, y_train)
test_base_preds[:, 0] = m1_full.predict(X_test)
test_base_preds[:, 1] = m2_full.predict(X_test)

# Meta-learner: Ridge regression on out-of-fold predictions
meta_learner = Ridge(alpha=1.0)
meta_learner.fit(oof_preds, y_train)
pred_stacking = meta_learner.predict(test_base_preds)

# Single baseline tree
single_tree = DecisionTreeRegressor(max_depth=5, random_state=42).fit(X_train, y_train)
pred_single = single_tree.predict(X_test)

def mse(y_true, y_pred): return np.mean((y_true - y_pred)**2)

print("--- Test Set MSE Comparison ---")
print(f"Single Decision Tree:  {mse(y_test, pred_single):.4f}")
print(f"Bagging (30 trees):    {mse(y_test, pred_bagging):.4f} (Variance reduced)")
print(f"Boosting (30 trees):   {mse(y_test, pred_boost_test):.4f} (Bias reduced)")
print(f"Stacking (Meta-Ridge): {mse(y_test, pred_stacking):.4f} (Optimal synthesis)")

Common pitfalls

  • Target leakage in stacking: Training the meta-learner on in-sample predictions causes extreme overfitting; out-of-fold cross-validation is strictly mandatory.
  • Overfitting in boosting: Unlike bagging, running boosting for too many iterations continues driving training error to zero while test error explodes.
  • Computational latency: Ensembles require evaluating multiple models at inference time, increasing CPU and memory latency in real-time serving.

06 Check yourself

Q1According to the bagging variance formula Var = rho * sigma^2 + ((1 - rho)/B) * sigma^2, why does Random Forest perform feature subsampling at each tree split?

Why: As tree count B -> infinity, the second term approaches zero, leaving rho * sigma^2. Randomly selecting feature subsets decorrelates trees (lowering rho), lowering overall ensemble variance.

Q2Why must the meta-features in Stacking be generated strictly using out-of-fold cross-validation?

Why: In-sample predictions contain training memorisation artifacts. Out-of-fold predictions replicate true test-time behaviour, allowing the meta-learner to learn reliable weights without target leakage.
