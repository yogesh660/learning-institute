01 The idea

While PCA seeks orthogonal axes of maximal variance, Independent Component Analysis (ICA) searches for directions that are statistically independent by maximising non-Gaussianity.

The quintessential motivation for Independent Component Analysis (ICA) is the "cocktail party problem": several people speak simultaneously in a room, and multiple microphones record mixed acoustic signals. Each microphone captures a distinct linear superposition of the speakers voices. Given only the recorded mixtures without knowledge of the speakers locations or room acoustics, can we recover the original isolated vocal tracks? This challenge is known as Blind Source Separation (BSS).

Principal Component Analysis (PCA) fails on this problem. PCA enforces orthogonality and seeks directions of maximum variance. However, uncorrelatedness is purely a second-order linear relationship: two variables can be completely uncorrelated yet strongly dependent. ICA demands statistical independence: the joint probability distribution must factorise into the product of marginals, $p(s_1, \dots, s_m) = \prod_{i=1}^m p_i(s_i)$.

The algorithmic key to ICA is the Central Limit Theorem (CLT). According to the CLT, the sum of independent random variables tends toward a Gaussian distribution: any linear mixture of non-Gaussian source signals will be more Gaussian than the original individual sources. Therefore, to untangle the mixture and isolate the pure sources, we must search for unmixing vectors that maximise the non-Gaussianity of the recovered signals.

Aapo Hyvärinen developed the FastICA algorithm, an efficient fixed-point iteration scheme that measures non-Gaussianity via negentropy (the entropy difference between a distribution and a Gaussian with identical covariance). FastICA whitens data via PCA, then uses fixed-point updates to extract statistically independent components.

In everyday terms

Imagine blending a banana smoothie containing strawberries, blueberries, and bananas. A standard kitchen blender homogenises everything into a uniform purplish paste (the Gaussian mixture). PCA merely tells you the total volume and density of the paste. ICA is like a magical reverse centrifuge that examines the subtle non-uniform textures (non-Gaussianity), unmixing the smoothie back into discrete piles of whole strawberries, blueberries, and bananas.

03 The maths

  1. Linear Mixture and Unmixing Model

    x = A s = \sum_{i=1}^m a_i s_i, \quad \hat{s} = W x = W A s

    Observed signals x are formed by unknown mixing matrix A multiplying independent sources s. The objective is finding unmixing matrix W such that WA approximates a permutation and scaling matrix.

  2. Negentropy Measure of Non-Gaussianity

    J(y) = H(y_{\mathrm{gauss}}) - H(y) \approx k_1 [\mathbb{E}\{G_1(y)\}]^2 + k_2 [\mathbb{E}\{G_2(y)\} - \mathbb{E}\{G_2(\nu)\}]^2

    Gaussian distributions have maximal entropy among all distributions with identical variance. Negentropy J(y) is strictly non-negative and zero if and only if y is Gaussian; maximising negentropy isolates independent components.

  3. FastICA Fixed-Point Update Rule

    w^+ = \mathbb{E}[x g(w^T x)] - \mathbb{E}[g'(w^T x)] w, \quad w \leftarrow \frac{w^+}{\|w^+\|}

    Fixed-point iteration derived from Newton-Raphson optimisation on Kuhn-Tucker conditions under constraint ||w|| = 1. Converges with cubic speed.

04 Key takeaways

  • Decomposes linear mixtures of signals into statistically independent, non-Gaussian components.
  • Exploits the Central Limit Theorem: mixtures are always more Gaussian than independent sources; maximising non-Gaussianity unmixes them.
  • Requires that at most one source distribution is Gaussian (multiple Gaussian sources cannot be separated due to rotational symmetry).
  • FastICA uses a fixed-point iteration derived from negentropy approximations, converging with cubic speed.
  • Possesses intrinsic ambiguities: source variance (scaling) and component ordering cannot be uniquely determined from observed mixtures alone.

05 In code

python
import numpy as np

# FastICA from scratch for Blind Source Separation
np.random.seed(42)
n_samples = 2000
time = np.linspace(0, 8, n_samples)

# 1. Generate two non-Gaussian independent sources
# Source 1: Sinusoidal signal
s1 = np.sin(2 * time)
# Source 2: Square wave signal
s2 = np.sign(np.sin(3 * time))
S = np.column_stack([s1, s2])

# 2. Mix sources with an arbitrary mixing matrix A
A = np.array([[1.0, 1.5],
              [0.8, -0.6]])
X = S @ A.T  # Mixed observed signals

# 3. FastICA Implementation
def fast_ica(X, n_components=2, max_iters=200, tol=1e-6):
    n, p = X.shape
    # Step A: Mean-centreing
    X_mean = np.mean(X, axis=0)
    X_centreed = X - X_mean
    
    # Step B: Whitening via SVD
    cov = (X_centreed.T @ X_centreed) / n
    U, D, _ = np.linalg.svd(cov)
    whitening_matrix = U @ np.diag(1.0 / np.sqrt(D)) @ U.T
    X_white = X_centreed @ whitening_matrix.T
    
    # Contrast function g(u) = tanh(u), g'(u) = 1 - tanh^2(u)
    def g(u): return np.tanh(u)
    def g_prime(u): return 1.0 - np.tanh(u)**2
    
    # Step C: Fixed-point iteration with Gram-Schmidt orthogonalisation
    W = np.zeros((n_components, n_components))
    
    for i in range(n_components):
        w = np.random.normal(size=n_components)
        w /= np.linalg.norm(w)
        
        for it in range(max_iters):
            # w+ = E[x * g(w^T x)] - E[g'(w^T x)] * w
            wx = X_white @ w
            w_new = np.mean(X_white * g(wx)[:, None], axis=0) - np.mean(g_prime(wx)) * w
            
            # Orthogonalise against previously found vectors
            for j in range(i):
                w_new -= (w_new @ W[j]) * W[j]
            w_new /= np.linalg.norm(w_new)
            
            # Check convergence
            if np.abs(np.abs(w_new @ w) - 1.0) < tol:
                w = w_new
                break
            w = w_new
            
        W[i] = w
        
    # Reconstructed independent components
    S_hat = X_white @ W.T
    return S_hat, W

S_recovered, W_est = fast_ica(X, n_components=2)

# Normalise recovered signals to unit variance for correlation check
S_norm = (S - np.mean(S, axis=0)) / np.std(S, axis=0)
S_rec_norm = (S_recovered - np.mean(S_recovered, axis=0)) / np.std(S_recovered, axis=0)

# Check correlation matrix between original and recovered
corr = np.abs(S_norm.T @ S_rec_norm) / len(S)

print(f"Mixing Matrix A:\n{A}")
print(f"\nCorrelation between original and recovered sources:")
print(f"Source 1 max correlation: {np.max(corr[0]):.4f}")
print(f"Source 2 max correlation: {np.max(corr[1]):.4f} (clean separation!)")

Common pitfalls

  • Gaussian source limitation: If two or more independent sources are Gaussian, their joint distribution is spherically symmetric, making rotation indeterminate.
  • Scale and sign ambiguity: The magnitude and sign of recovered sources are unidentifiable ($(-a) \cdot (-s) = a s$); recovered signals must be standardised.
  • Permutation ambiguity: ICA cannot infer the original ordering of sources; component 1 might correspond to source 2 or source 5.

06 Check yourself

Q1Why does Independent Component Analysis require that source distributions are non-Gaussian?

Why: A multivariate Gaussian with identity covariance is spherically symmetric: rotating it yields an identical Gaussian. Without non-Gaussianity, independent directions cannot be distinguished.

Q2What is the relationship between uncorrelatedness and statistical independence in the context of PCA and ICA?

Why: Uncorrelatedness only means E[XY] = E[X]E[Y] (second-order orthogonality). Statistical independence requires p(X, Y) = p(X)p(Y) across all higher-order moments.
