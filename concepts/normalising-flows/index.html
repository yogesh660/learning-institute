Normalising Flows: Exact Likelihood Estimation via Invertible Transformations

Evaluating exact probabilities and generating high-fidelity samples using invertible bijectors (RealNVP) and the change-of-variables theorem.

01 The idea

Generative models generally face a compromise: GANs generate sharp samples but have no tractable likelihood and suffer from mode collapse; VAEs provide tractable lower bounds (ELBO) but generate blurry samples. Normalising Flows achieve both exact analytical probability density evaluation and efficient sampling by transforming simple base distributions (like standard Gaussians) through a sequence of invertible, bijective neural network mappings.

The change-of-variables theorem from calculus states that if $x = f(z)$ where $f$ is an invertible differentiable bijection ($z = f^{-1}(x)$), the probability density function of $x$ is $p_X(x) = p_Z(f^{-1}(x)) \cdot |\det J_{f^{-1}}(x)|$.

By composing $K$ invertible transformations $f = f_K \circ \dots \circ f_1$, a simple base density $z_0 \sim \mathcal{N}(0, \mathbf{I})$ can be warped into arbitrarily complex, multimodal distributions $p_X(x)$.

The primary computational challenge is computing the determinant of the $D \times D$ Jacobian matrix $J_f = \frac{\partial f}{\partial z}$, which in general requires expensive $O(D^3)$ matrix operations.

RealNVP (Dinh et al.) solves this using Affine Coupling Layers: split the vector into two halves $(z_A, z_B)$. Keep $z_A$ unchanged, and transform $z_B$ via $x_B = z_B \odot \exp(s(z_A)) + t(z_A)$, where $s$ and $t$ can be arbitrary complex non-invertible neural networks. This forces the Jacobian to be triangular, making its determinant trivially computable in $O(D)$ time as the product of its diagonal elements $\sum s(z_A)$.

In everyday terms

Imagine sculpting an intricate vase out of a standard lump of grey potter's clay. Every stretching, rolling, and folding motion of your hands is completely reversible: if you record every pull and push, you can mathematically unfold the vase back into the exact original ball of clay. Calculating the density of clay at any point on the vase simply requires tracking how much your hands stretched or compressed the material during each invertible step.

02 Step by step

  1. Select base distribution: Define a tractable prior distribution $p_Z(z)$ (typically standard isotropic Gaussian $\mathcal{N}(0, \mathbf{I})$).
  2. Design invertible coupling layer: Split input channels into $z_A$ and $z_B$. Pass $z_A$ through arbitrary deep networks to predict scale $s$ and translation $t$.
  3. Apply affine forward transformation: Compute $x_A = z_A$ and $x_B = z_B \odot \exp(s(z_A)) + t(z_A)$.
  4. Compute log-determinant: Sum scaling coefficients $\sum_i s(z_A)_i$ in linear $O(D)$ time.
  5. Compose multiple layers with permutations: Alternate channel splits or apply invertible $1 \times 1$ convolutions (Glow) between coupling blocks.
  6. Train via exact negative log-likelihood: Maximise $\log p_X(x) = \log p_Z(f^{-1}(x)) + \sum_{k=1}^K \log |\det J_{f_k^{-1}}|$ directly via gradient descent.

03 The maths

  1. Multivariate Change-of-Variables Theorem

    p_X(x) = p_Z(f^{-1}(x)) \cdot \left| \det\left( \frac{\partial f^{-1}(x)}{\partial x} \right) \right| = p_Z(f^{-1}(x)) \cdot \left| \det\left( \frac{\partial f(z)}{\partial z} \right) \right|^{-1}

    Calculates the exact density of $x$ by evaluating the base Gaussian density of $f^{-1}(x)$ multiplied by the Jacobian determinant volume correction.

  2. RealNVP Affine Coupling Transformation

    \begin{cases} x_{1:d} = z_{1:d} \\ x_{d+1:D} = z_{d+1:D} \odot \exp\left( s(z_{1:d}) \right) + t(z_{1:d}) \end{cases}

    Transforms second partition $z_{d+1:D}$ conditionally based on arbitrary neural networks $s$ and $t$ evaluating the first partition.

  3. Triangular Jacobian Determinant

    J = \begin{bmatrix} \mathbf{I}_d & \mathbf{0} \\ \frac{\partial x_{d+1:D}}{\partial z_{1:d}} & \operatorname{diag}\left(\exp(s(z_{1:d}))\right) \end{bmatrix} \implies \ln |\det J| = \sum_{i=1}^{D-d} s(z_{1:d})_i

    The Jacobian is block triangular; its determinant equals the product of diagonal entries, reducing computation from $O(D^3)$ to $O(D)$.

04 Key takeaways

  • Normalising flows enable exact analytical log-likelihood calculation and efficient sampling.
  • Warp simple Gaussian base densities into complex multimodal distributions via invertible bijections.
  • Affine coupling layers force the Jacobian to be triangular, computing determinants in linear $O(D)$ time.
  • Scale and translation functions $s$ and $t$ can be arbitrary complex, non-invertible neural networks.

05 In code

python
import torch
import torch.nn as nn
import numpy as np

class RealNVPCouplingLayer(nn.Module):
    def __init__(self, dim: int, hidden_dim: int = 64):
        super().__init__()
        self.d = dim // 2
        # Scale (s) and translation (t) can be arbitrary deep networks!
        self.net = nn.Sequential(
            nn.Linear(self.d, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, (dim - self.d) * 2)
        )

    def forward(self, z: torch.Tensor):
        # z -> x (sampling direction)
        z_A, z_B = z[:, :self.d], z[:, self.d:]
        st = self.net(z_A)
        s, t = st[:, ::2], st[:, 1::2]
        s = torch.tanh(s)  # Stabilise scaling
        
        x_A = z_A
        x_B = z_B * torch.exp(s) + t
        x = torch.cat([x_A, x_B], dim=-1)
        log_det_J = torch.sum(s, dim=-1)
        return x, log_det_J

    def inverse(self, x: torch.Tensor):
        # x -> z (density evaluation direction)
        x_A, x_B = x[:, :self.d], x[:, self.d:]
        st = self.net(x_A)
        s, t = st[:, ::2], st[:, 1::2]
        s = torch.tanh(s)
        
        z_A = x_A
        z_B = (x_B - t) * torch.exp(-s)
        z = torch.cat([z_A, z_B], dim=-1)
        log_det_J_inv = -torch.sum(s, dim=-1)
        return z, log_det_J_inv

# Test bijector invertibility
layer = RealNVPCouplingLayer(dim=4)
z_orig = torch.randn(2, 4)
x, log_det = layer(z_orig)
z_rec, _ = layer.inverse(x)

recon_error = torch.max(torch.abs(z_orig - z_rec)).item()
print(f"Coupling Layer Inversion Error: {recon_error:.2e} (Strictly Invertible!)")
print(f"Log Jacobian determinant evaluated in O(D) time: {log_det.detach().numpy()}")

Common pitfalls

  • Dimension preservation restriction: Because bijections require bijective mapping, the latent state $z$ must have the exact same dimensionality as data $x$, causing memory growth for high-resolution images.
  • Unbounded scaling: If scale function $s(z_A)$ outputs large values, $\exp(s)$ causes floating point overflow and numerical instability; constrain outputs with `tanh`.
  • Ignoring channel permutations: Failing to alternate which half of features is transformed leaves half the channels completely unchanged throughout the entire network.

06 Check yourself

Q1What unique advantage do Normalising Flows possess compared to Variational Autoencoders (VAEs) and GANs?

Why: GANs lack likelihood evaluation entirely, and VAEs only compute lower bound approximations (ELBO). Normalising Flows compute exact likelihoods via the change-of-variables theorem.

Q2How does RealNVP make the calculation of the Jacobian determinant computationally tractable in linear $O(D)$ time?

Why: In a triangular matrix, the determinant is the product of the diagonal elements. Affine coupling structures the transformation so the Jacobian is block triangular, evaluating in $O(D)$ steps.

Q3In a RealNVP affine coupling layer, do the sub-networks $s(z_A)$ and $t(z_A)$ that compute scale and translation need to be invertible themselves?

Why: Because $z_A = x_A$ is preserved unchanged, inversion directly computes $s(x_A)$ and $t(x_A)$ in the reverse direction. Thus $s$ and $t$ can be arbitrary complex networks.
