Exploratory Data Analysis (EDA)

Look before you model: distributions, missing values, outliers, relationships and leakage, checked systematically.

01 The idea

EDA is the habit of understanding the data before fitting anything. Most modelling failures are data problems that a few plots and counts would have revealed.

A model only learns what is in the data, including its mistakes. EDA asks a fixed set of questions: What does each column look like? What is missing, and is it missing at random? Are there impossible values? How does each feature relate to the target, and to each other? Is anything suspiciously predictive, the kind of feature that would not be available at prediction time?

Skewed targets (house prices, incomes) often model better after a log transform. Heavy correlations between features warn of multicollinearity. Class imbalance changes which metric you should use. EDA finds these things early, when they are cheap to handle.

02 Step by step

  1. Shape and types: rows, columns, dtypes, ID columns, dates.
  2. Missingness: share missing per column, and whether it correlates with the target.
  3. Univariate distributions: histograms, skew, impossible values, outliers (IQR rule).
  4. Target: balance for classification; skew for regression.
  5. Bivariate: each feature against the target; correlation matrix; VIF for collinearity.
  6. Leakage check: anything recorded after the outcome, or too good to be true.

04 The maths

  1. Skewness

    $$g_1 = \frac{\frac1n\sum_i(x_i - \bar x)^3}{\big(\frac1n\sum_i(x_i - \bar x)^2\big)^{3/2}}$$

    Above about 1 in absolute value is strongly skewed; a log or Box-Cox transform often helps.

  2. IQR outlier rule

    $$x < Q_1 - 1.5\,\mathrm{IQR} \;\;\text{or}\;\; x > Q_3 + 1.5\,\mathrm{IQR}, \qquad \mathrm{IQR} = Q_3 - Q_1$$

    A flag for inspection, not an automatic delete.

  3. Variance inflation factor

    $$\mathrm{VIF}_j = \frac{1}{1 - R_j^2}$$

    $R_j^2$ comes from regressing feature $j$ on all the others. VIF above 5–10 signals collinearity that will destabilise linear models.

05 Key takeaways

  • Every EDA finding should become a decision: drop, transform, impute, engineer, or note as a risk.
  • Split off the test set before deep EDA, so its quirks do not leak into your choices.
  • Missing values are information: "missing income" may itself predict the target.

06 In code

python
import pandas as pd, numpy as np

df = pd.read_csv("datasets/raw/california_housing.csv")
print(df.shape, df.dtypes.value_counts().to_dict())
print(df.isna().mean().sort_values(ascending=False).head())       # missing share
print(df.skew(numeric_only=True).sort_values())                     # skew per column
q1, q3 = df.quantile(0.25), df.quantile(0.75)
print(((df < q1 - 1.5 * (q3 - q1)) | (df > q3 + 1.5 * (q3 - q1))).mean().round(3))  # outlier share
print(df.corr(numeric_only=True)["MedHouseVal"].sort_values())      # relation to target

Common pitfalls

  • Doing EDA on the full dataset, then being surprised the test score is optimistic.
  • Deleting outliers that are real and important (fraud, failures).
  • Imputing with the mean before splitting, which leaks test information into training.

07 Check yourself

Q1A feature has VIF = 12. What does that suggest?

Why: $R_j^2 = 1 - 1/12 \approx 0.92$ of its variance is explained by other features.

Q2Why should the test set be split off before detailed EDA?

Why: Decisions informed by test data make the final score optimistic.

Q3What is data leakage during exploratory data analysis and preprocessing?

Why: Data leakage occurs when a model has access to information during training that would not be legitimately available at test or deployment time, causing spuriously high offline evaluation scores.

Q4Why should an analyst NOT automatically delete all rows flagged as outliers by the $1.5 \times \mathrm{IQR}$ rule?

Why: Outliers can be recording errors, but they can also be authentic, high-impact events like fraudulent transactions or engine failures. Deleting them blinds the model to reality.

Q5In tabular data, why might a high proportion of missing values in a column like "annual income" be valuable information rather than merely a data defect?

Why: Data is often Not Missing At Random (NMAR). For example, applicants concealing income or employment status often have distinct risk profiles, making a "missing indicator" flag highly predictive.

Q6When inspecting a continuous regression target like "house price" or "insurance claim payout", you find a skewness of $g_1 = +2.4$. What transformation is most commonly applied before fitting a linear model?

Why: A skewness above $+1.0$ indicates a heavy right tail. Applying a log transform (or Box-Cox) pulls in extreme values, yielding a more symmetric distribution that aligns better with homoscedasticity assumptions in linear models.

Q7A junior data scientist computes the mean of the "age" column across the entire dataset of 100,000 rows and uses it to impute missing values before splitting into 80,000 train and 20,000 test rows. What is the fundamental problem with this approach?

Why: Any statistic (mean, median, scaling parameters) calculated using test set rows leaks test information into training. Imputation parameters must be computed strictly on the training set and applied to the test set.

Q8In a dataset predicting customer loan default, a feature named "account_collections_status" has an almost perfect correlation ($r = 0.98$) with the target. Investigation reveals this field is populated only after a customer has officially defaulted. What should you do?

Why: Features created or populated downstream of the event being predicted are classic target leaks. While they produce artificially stellar cross-validation scores, they do not exist when scoring new loan applicants.

Q9When checking a binary classification target with 10,000 total observations, you discover 9,900 instances of Class 0 and 100 instances of Class 1. Which evaluation metric should you avoid using as your primary KPI?

Why: With a 99:1 class imbalance, a trivial dummy classifier that always predicts Class 0 achieves 99.0% accuracy despite completely failing to identify any positive cases. Accuracy is deeply misleading here.

Q10In a feature distribution, the first quartile is $Q_1 = 20$ and the third quartile is $Q_3 = 50$. Using Tukey's standard $1.5 \times \mathrm{IQR}$ rule, which of the following values would be flagged as an outlier?

Why: $\mathrm{IQR} = Q_3 - Q_1 = 50 - 20 = 30$. Upper fence $= Q_3 + 1.5\,\mathrm{IQR} = 50 + 1.5(30) = 50 + 45 = 95$. Lower fence $= Q_1 - 1.5\,\mathrm{IQR} = 20 - 45 = -25$. Since $98 > 95$, it falls outside the upper fence and is flagged as an outlier.

Q11When regressing a feature $x_1$ on the other features in a dataset, the resulting coefficient of determination is $R_1^2 = 0.80$. What is the Variance Inflation Factor ($\mathrm{VIF}_1$) for this feature, and does it exceed the standard caution threshold of 5?

Why: $\mathrm{VIF}_1 = \frac{1}{1 - R_1^2} = \frac{1}{1 - 0.80} = \frac{1}{0.20} = 5.00$. A VIF of 5.0 indicates that 80% of the feature's variance is explained by other features, reaching the standard rule-of-thumb threshold (5 to 10) for problematic multicollinearity.

Q12A dataset of $n = 5$ values is $\{2, 4, 4, 4, 6\}$. What are the sample mean $\bar{x}$, the sample variance $s^2 = \frac{1}{n}\sum (x_i - \bar{x})^2$, and the skewness $g_1 = \frac{\frac{1}{n}\sum(x_i - \bar{x})^3}{s^3}$?

Why: Mean: $\bar{x} = (2 + 4 + 4 + 4 + 6) / 5 = 20 / 5 = 4.0$. Deviations: $x_i - \bar{x} \in \{-2, 0, 0, 0, 2\}$. Squared deviations: $\{4, 0, 0, 0, 4\}$. Mean squared deviation $s^2 = (4 + 0 + 0 + 0 + 4) / 5 = 8 / 5 = 1.6$. Cubed deviations: $\{(-2)^3, 0, 0, 0, 2^3\} = \{-8, 0, 0, 0, 8\}$. Sum of cubed deviations is $-8 + 8 = 0$, so $g_1 = 0 / (1.6)^{1.5} = 0.0$. Because the distribution is symmetrically balanced around the mean, the skewness is exactly zero.
