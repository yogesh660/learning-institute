01 The idea

Rating scales (1 to 5 stars), disease staging (mild, moderate, severe), and credit ratings (AAA to D) have meaningful order but unequal interval spacing. Ordinal models preserve ranking without falsely assuming equal distances.

In supervised learning, target variables frequently possess an inherent ordering without possessing a strict metric scale: survey responses (strongly disagree, neutral, agree), customer satisfaction ratings (1 to 5 stars), disease severity stages, or credit bond ratings. Treating these targets with nominal multi-class classification (such as standard multinomial logistic regression) completely discards order information, penalising a 1-star predicted as 2-star identically to a 1-star predicted as 5-star.

Conversely, treating ordinal categories as continuous numbers and applying standard regression falsely assumes that intervals between adjacent categories are identical: that the perceptual difference between 1 and 2 stars is identical to the difference between 4 and 5 stars. Ordinal classification provides the rigorous intermediate framework, respecting relative ranking without imposing arbitrary metric distances.

The standard statistical workhorse is the Proportional Odds model (cumulative logit model). It posits an unobserved continuous latent variable $y^* = x^T \beta + \epsilon$. The observed ordinal category $k \in \{1, 2, \dots, K\}$ is determined by where this latent score falls across a sequence of strictly increasing cut-point thresholds: $\theta_1 < \theta_2 < \dots < \theta_{K-1}$.

The proportional odds property states that feature coefficients $\beta$ are invariant across all cut-points: an increase in feature $x$ shifts the latent distribution uniformly, changing the odds of exceeding threshold $k$ by the same multiplicative factor $\exp(\beta_j)$ regardless of which threshold $k$ is considered. This parsimonious parameterisation requires estimating only $p$ feature weights plus $K-1$ thresholds, avoiding parameter proliferation.

In everyday terms

Imagine categorising runners in a marathon into three medal tiers: Bronze, Silver, and Gold. The underlying running time is a continuous latent variable. Rather than retraining three unrelated models, the race judges place two cut-off clocks along the course: finish before 3 hours for Gold, finish before 4 hours for Silver, otherwise Bronze. An athlete running faster shifts their latent position across all threshold clocks simultaneously.

03 The maths

  1. Cumulative Link / Proportional Odds Formulation

    P(Y \le k \mid x) = \sigma(\theta_k - x^T \beta) = \frac{1}{1 + \exp(-(\theta_k - x^T \beta))}, \quad k = 1, \dots, K-1

    The probability of falling into category k or below is governed by distance between threshold theta_k and linear predictor x^T beta. A positive beta shifts probability toward higher categories.

  2. Category Probabilities

    P(Y = k \mid x) = P(Y \le k \mid x) - P(Y \le k - 1 \mid x), \quad P(Y \le 0) = 0, \; P(Y \le K) = 1

    Each discrete category probability corresponds to the area under the latent logistic curve bounded between adjacent thresholds theta_{k-1} and theta_k.

  3. Quadratic Weighted Kappa (QWK)

    \kappa = 1 - \frac{\sum_{i, j} w_{ij} O_{ij}}{\sum_{i, j} w_{ij} E_{ij}}, \quad w_{ij} = \frac{(i - j)^2}{(K - 1)^2}

    Measures agreement between predicted and true ranks penalising large category discrepancies quadratically, serving as standard evaluation metric in automated grading and disease staging.

04 Key takeaways

  • Preserves inherent rank ordering of discrete targets without assuming arbitrary metric Euclidean distance.
  • Cumulative logit proportional odds model relates features to cumulative probability $P(Y \le k \mid x) = \sigma(\theta_k - x^T \beta)$.
  • Feature weights $\beta$ are shared across all thresholds, requiring only $p + (K - 1)$ parameters compared to $(K - 1) \cdot p$ in multinomial regression.
  • Latent threshold formulation $\theta_1 < \theta_2 < \dots < \theta_{K-1}$ partitions continuous latent response into ordered discrete bins.
  • Performance is best evaluated via distance-aware metrics like Mean Absolute Error (MAE) on ranks or Quadratic Weighted Kappa (QWK).

05 In code

python
import numpy as np
from scipy.optimize import minimize

# Proportional Odds Ordinal Logistic Regression from scratch
np.random.seed(42)
n_samples = 300

# 1. Generate synthetic ordinal data (3 categories: Low, Medium, High)
x1 = np.random.normal(0, 1, n_samples)
x2 = np.random.uniform(-1, 1, n_samples)
X = np.column_stack([x1, x2])

# Latent variable y* = beta1*x1 + beta2*x2 + noise
true_beta = np.array([1.5, -0.8])
latent_y = X @ true_beta + np.random.logistic(0, 1, n_samples)

# True cut-points: theta_1 = -0.5, theta_2 = 1.2
true_thetas = np.array([-0.5, 1.2])
y = np.zeros(n_samples, dtype=int)
y[latent_y > true_thetas[0]] = 1
y[latent_y > true_thetas[1]] = 2

# 2. Cumulative Logit Model Fitting via Maximum Likelihood
K = 3  # Number of classes
def sigmoid(z):
    return 1.0 / (1.0 + np.exp(-np.clip(z, -30, 30)))

def negative_log_likelihood(params, X, y):
    beta = params[:2]
    # Parameterise thresholds with increments to enforce theta_1 < theta_2
    theta = np.array([params[2], params[2] + np.exp(params[3])])
    
    linear_pred = X @ beta
    n = len(y)
    nll = 0.0
    
    for i in range(n):
        k = y[i]
        # P(Y <= k)
        prob_k = sigmoid(theta[k] - linear_pred[i]) if k < K - 1 else 1.0
        prob_prev = sigmoid(theta[k-1] - linear_pred[i]) if k > 0 else 0.0
        prob = max(prob_k - prob_prev, 1e-12)
        nll -= np.log(prob)
        
    return nll

# Initial guess: beta=[0, 0], theta_1=0, increment=0
init_params = np.array([0.0, 0.0, 0.0, 0.0])
res = minimize(negative_log_likelihood, init_params, args=(X, y), method='BFGS')

est_beta = res.x[:2]
est_thetas = np.array([res.x[2], res.x[2] + np.exp(res.x[3])])

# Compute predictions
lin_preds = X @ est_beta
pred_probs = np.zeros((n_samples, K))
for k in range(K):
    p_k = sigmoid(est_thetas[k] - lin_preds) if k < K - 1 else 1.0
    p_prev = sigmoid(est_thetas[k-1] - lin_preds) if k > 0 else 0.0
    pred_probs[:, k] = p_k - p_prev
pred_classes = np.argmax(pred_probs, axis=1)

mae = np.mean(np.abs(y - pred_classes))
acc = np.mean(y == pred_classes)

print(f"True beta:             {true_beta}")
print(f"Estimated beta:        {est_beta.round(3)}")
print(f"True cut-points:       {true_thetas}")
print(f"Estimated cut-points:  {est_thetas.round(3)}")
print(f"Classification accuracy: {acc * 100:.1f}%")
print(f"Mean Absolute Error (ranks): {mae:.3f} (captures distance on ordered scale)")

Common pitfalls

  • Violation of proportional odds assumption: If a feature affects the transition between Mild and Moderate differently than between Moderate and Severe, the assumption fails and partial proportional odds is needed.
  • Threshold ordering collapse: Unconstrained numerical optimisation can allow thresholds to cross ($\theta_{k+1} < \theta_k$), resulting in negative probabilities; reparameterising with positive increments is vital.
  • Evaluating with accuracy: A model predicting class 1 when truth is class 5 receives the exact same penalty as predicting class 2 under 0-1 loss, masking severe directional blunders.

06 Check yourself

Q1Why is standard multinomial logistic regression sub-optimal for customer satisfaction ratings (1 to 5 stars)?

Why: Multinomial logistic regression is nominal; it ignores the ordering of ratings and assigns equal loss to near-misses and extreme ranking blunders.

Q2What is the key geometric interpretation of the cut-points theta_1 < theta_2 < ... < theta_{K-1} in an ordinal model?

Why: In ordinal threshold models, an underlying continuous latent variable y* is partitioned into discrete bins by the ordered boundary thresholds theta_k.
