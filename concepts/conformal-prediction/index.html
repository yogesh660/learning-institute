01 The idea

Standard confidence intervals rely on parametric Gaussian assumptions that fail when distributions are skewed or multimodal. Conformal prediction produces prediction sets with mathematically guaranteed 1 - alpha marginal coverage under any distribution, using any underlying model.

Most machine learning models output point predictions: predicting a house price will be £450,000 or a patient will be diagnosed with Disease A. However, when deployed in medicine, finance, or automated hiring, point predictions hide risk: is the true house price guaranteed to lie between £440,000 and £460,000, or could it be anywhere from £200,000 to £700,000?

Traditional statistical methods construct confidence intervals using rigid parametric assumptions: assuming error residuals are identically normally distributed with constant variance. When real-world data is skewed, heteroscedastic, or multi-modal, these parametric intervals collapse and under-cover reality.

Pioneered by Vladimir Vovk, Alex Gammerman, and Glenn Shafer, Conformal Prediction provides a mathematically rigorous, distribution-free framework for uncertainty quantification. It constructs prediction intervals (in regression) or prediction sets (in classification) that satisfy an exact finite-sample coverage guarantee: $P(Y_{n+1} \in C(X_{n+1})) \ge 1 - \alpha$, for any user-chosen significance level $\alpha$ (e.g. 90% or 95%).

Astonishingly, conformal prediction requires zero parametric assumptions, works on top of any black-box machine learning model (Random Forests, XGBoost, or Deep Neural Networks), and holds for finite sample sizes $n$ without relying on asymptotic $n \to \infty$ limits. The only foundational mathematical assumption is exchangeability (satisfied whenever data is identically and independently distributed, i.i.d.).

In everyday terms

Imagine a dart player practicing in an arcade. Rather than assuming the darts always land in a neat circular Gaussian bell curve around the bullseye, you watch the player throw 100 calibration darts and measure the exact physical distance of each dart from the bullseye. If you want a 90% guarantee for their next throw, you simply take the 90th largest throw distance. Drawing a circle with that exact radius around the next aimed target is guaranteed by pure permutation symmetry to contain the next dart 90% of the time.

03 The maths

  1. Inductive Non-Conformity Score (Absolute Residual)

    s_i = s(x_i, y_i) = |y_i - \hat{f}(x_i)|

    Quantifies how poorly the model prediction matches the ground truth. Higher values denote points that conform poorly to model expectations.

  2. Empirical Conformal Quantile Correction

    \hat{q} = \operatorname{Quantile}\left(\frac{\lceil(n + 1)(1 - \alpha)\rceil}{n}, \; \{s_1, \dots, s_n\}\right)

    The finite-sample correction factor (n+1)/n accounts for the unobserved test sample, ensuring the theoretical coverage guarantee holds exactly in finite samples.

  3. Conformal Validity Coverage Guarantee Theorem

    1 - \alpha \le P\left(Y_{n+1} \in C(X_{n+1})\right) \le 1 - \alpha + \frac{1}{n + 1}

    Rigorous finite-sample mathematical guarantee. The true outcome falls inside the prediction set with probability at least 1 - alpha under exchangeability.

04 Key takeaways

  • Provides mathematically guaranteed finite-sample coverage $P(Y \in C(X)) \ge 1 - \alpha$ without parametric assumptions.
  • Model-agnostic: wraps around any black-box machine learning model (neural nets, gradient boosting, random forests).
  • Relies solely on exchangeability (i.i.d. assumption), holding exactly for finite samples without asymptotic approximations.
  • In regression, outputs prediction intervals; in classification, outputs prediction sets of varying cardinality.
  • Adaptive non-conformity scores (e.g. Conformalised Quantile Regression, CQR) produce variable-width intervals reflecting local heteroscedasticity.

05 In code

python
import numpy as np
from sklearn.ensemble import GradientBoostingRegressor

# Split Conformal Prediction for Regression from scratch
np.random.seed(42)
n_total = 1000

# Synthetic non-linear data with heteroscedastic skewed noise
x = np.random.uniform(0, 10, n_total)
# Variance grows with x, and noise is heavily skewed (exponential)
y_clean = 2.0 * np.sin(x) + 0.5 * x
noise = np.random.exponential(scale=0.3 * (1.0 + 0.2 * x)) - 0.3 * (1.0 + 0.2 * x)
y = y_clean + noise
X = x.reshape(-1, 1)

# Split into: Train (50%), Calibration (25%), Test (25%)
n_train = 500
n_cal = 250
X_train, y_train = X[:n_train], y[:n_train]
X_cal, y_cal = X[n_train:n_train+n_cal], y[n_train:n_train+n_cal]
X_test, y_test = X[n_train+n_cal:], y[n_train+n_cal:]

# 1. Train black-box base model on training set
model = GradientBoostingRegressor(n_estimators=100, random_state=42)
model.fit(X_train, y_train)

# 2. Compute non-conformity scores on calibration set
cal_preds = model.predict(X_cal)
nonconformity_scores = np.abs(y_cal - cal_preds)

# 3. Calculate conformal quantile for 90% coverage (alpha = 0.10)
alpha = 0.10
n = len(X_cal)
# Finite-sample index: ceil((n + 1) * (1 - alpha)) / n
q_level = np.ceil((n + 1) * (1.0 - alpha)) / n
q_hat = np.quantile(nonconformity_scores, q_level, method='higher')

# 4. Form prediction intervals on test set
test_preds = model.predict(X_test)
lower_bounds = test_preds - q_hat
upper_bounds = test_preds + q_hat

# Evaluate empirical coverage on test set
covered = (y_test >= lower_bounds) & (y_test <= upper_bounds)
empirical_coverage = np.mean(covered)

print(f"Target Coverage Level: { (1 - alpha) * 100:.1f}%")
print(f"Calibration set size:  {n_cal} samples")
print(f"Calibrated Conformal Margin (q_hat): ±{q_hat:.3f}")
print(f"Empirical Test Coverage: {empirical_coverage * 100:.1f}% (Guaranteed >= 90.0%!)")
print(f"Average Prediction Interval Width:   {2 * q_hat:.3f}")

Common pitfalls

  • Marginal coverage vs conditional coverage: Standard conformal prediction guarantees average coverage across the entire population, but may under-cover specific localised minority sub-populations.
  • Exchangeability violation in time series: If data exhibits temporal drift, non-stationarity, or autoregressive correlation, exchangeability fails and adaptive conformal prediction is required.
  • Calibration set data taxation: Split conformal prediction requires reserving a clean holdout calibration set, slightly reducing data available for model training.

06 Check yourself

Q1What is the only foundational assumption required for Conformal Prediction coverage guarantees to hold?

Why: Conformal prediction is distribution-free and finite-sample exact; its mathematical proof relies entirely on permutation symmetry (exchangeability) of the calibration and test instances.

Q2Why is the quantile level calculated as ceil((n + 1)(1 - alpha)) / n rather than simply 1 - alpha?

Why: Because the calibration set has n samples and the test point is the (n+1)-th point, rank symmetry requires partitioning probability into n+1 intervals, yielding the exact finite-sample bound.
