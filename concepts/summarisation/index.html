Text Summarisation: Extractive vs Abstractive, ROUGE Metrics, and Faithfulness

Extractive summarisation identifies and stitches together verbatim representative sentences from the original source. Abstractive summarisation generates novel paraphrased sentences, synthesizing ideas much like human writers. ROUGE (Recall-Oriented Understudy for Gisting Evaluation) metrics (ROUGE-1, ROUGE-2, ROUGE-L) evaluate n-gram and longest common subsequence recall against human references. Modern abstractive models suffer from faithfulness errors (introducing unsupported entities or relations), requiring NLI-based consistency auditing.

01 The idea

Text summarisation condenses long documents into concise, salient overviews while preserving key information. The paradigm has evolved from extractive sentence selection (TextRank) to abstractive sequence-to-sequence synthesis (BART, T5, LLMs), evaluated by lexical overlap (ROUGE) and factual faithfulness metrics (FactCC, QAGS).

If you want to summarise a 10-page research paper, you could highlight the 5 most important sentences with a marker and copy them into a bulleted list. That is extractive summarisation: it is factually safe because it never invents new wording, but it can be disjointed and redundant. Alternatively, you could read the paper, digest the concepts, and write a fresh 2-paragraph summary in your own words. That is abstractive summarisation: it is fluent, coherent, and synthesizes concepts, but it introduces the risk of accidentally misattributing quotes or hallucinating claims. Evaluation requires checking both coverage (did you capture the main ideas, measured by ROUGE) and faithfulness (is everything in the summary actually true according to the source text).

In everyday terms

Extractive summarisation is like assembling a photo collage using scissors to cut out original faces and buildings from existing photographs. Abstractive summarisation is hiring an artist to paint a new canvas portrait based on looking at the scene. The painting is smoother and more artistic, but the painter might accidentally paint blue eyes instead of brown eyes.

02 Step by step

  1. Determine summarisation paradigm: select extractive selection for safety-critical domains (legal, medical) or abstractive generation for consumer readability.
  2. Preprocess source document: clean whitespace, segment sentences, and truncate to maximum context window limits.
  3. Encode document context: process source tokens through an encoder-decoder architecture (e.g. BART) or decoder-only prompt harness.
  4. Generate summary: decode target tokens autoregressively using beam search with repetition penalties and length normalisation.
  5. Evaluate lexical overlap: calculate ROUGE-1, ROUGE-2, and ROUGE-L scores against reference summaries.
  6. Verify factual faithfulness: run automated natural language inference (NLI) to flag any hallucinated entities or unsupported causal claims.

04 Key takeaways

  • Extractive summarisation guarantees verbatim fidelity, whereas abstractive summarisation provides fluency and concise synthesis.
  • ROUGE-1, ROUGE-2, and ROUGE-L quantify n-gram and longest common subsequence recall against human reference summaries.
  • Evaluating factual faithfulness via NLI models is essential to prevent hallucinated claims in abstractive summaries.

05 In code

python
def compute_rouge_n(candidate, reference, n=1):
    """Computes ROUGE-N precision, recall, and F1 score."""
    def get_ngrams(text, n):
        words = text.lower().split()
        return [tuple(words[i:i+n]) for i in range(len(words) - n + 1)]
    
    cand_ngrams = get_ngrams(candidate, n)
    ref_ngrams = get_ngrams(reference, n)
    
    if not ref_ngrams or not cand_ngrams:
        return 0.0, 0.0, 0.0
    
    # Count matching n-grams
    ref_counts = {}
    for g in ref_ngrams:
        ref_counts[g] = ref_counts.get(g, 0) + 1
        
    overlap = 0
    cand_counts = {}
    for g in cand_ngrams:
        cand_counts[g] = cand_counts.get(g, 0) + 1
        
    for g, count in cand_counts.items():
        if g in ref_counts:
            overlap += min(count, ref_counts[g])
            
    recall = overlap / len(ref_ngrams)
    precision = overlap / len(cand_ngrams)
    f1 = (2 * precision * recall) / (precision + recall) if (precision + recall) > 0 else 0.0
    return precision, recall, f1

# Example Reference and Model Candidate Summaries
reference = "the company reported record profits driven by strong cloud sales in europe"
candidate = "strong cloud sales helped the company report record profits across european markets"

p1, r1, f1_1 = compute_rouge_n(candidate, reference, n=1)
p2, r2, f1_2 = compute_rouge_n(candidate, reference, n=2)

print(f"Candidate Summary: '{candidate}'")
print(f"Reference Summary: '{reference}'")
print(f"ROUGE-1 -> Precision: {p1:.3f} | Recall: {r1:.3f} | F1: {f1_1:.3f}")
print(f"ROUGE-2 -> Precision: {p2:.3f} | Recall: {r2:.3f} | F1: {f1_2:.3f}")

Common pitfalls

  • Relying exclusively on ROUGE scores; a summary can achieve high ROUGE overlap while introducing factual contradictions that negate the source meaning.
  • Generating summaries that suffer from the "lead bias" of news corpora, where models simply copy the first three sentences because journalists write inverted pyramids.
  • Extractive summarisation producing dangling pronouns (e.g. including a sentence starting with "However, he refused..." without the preceding entity definition).

06 Check yourself

Q1What is the key functional difference between extractive and abstractive summarisation?

Why: Extractive methods extract and arrange verbatim snippets directly from the original document; abstractive methods compose novel sentences that paraphrase the concepts.

Q2Why is ROUGE recall-oriented, in contrast to BLEU which is precision-oriented?

Why: In summarisation, ensuring the summary covers the necessary points found in the reference is paramount, making recall against reference concepts the primary objective.

Q3What does ROUGE-L measure between two summary texts?

Why: ROUGE-L evaluates the Longest Common Subsequence of tokens, rewarding summaries that preserve grammatical word order without requiring exact consecutive n-gram matches.
