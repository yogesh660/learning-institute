01 The idea

How much information is lost when an estimated probability distribution is substituted for ground truth? The Kullback–Leibler (KL) divergence, or relative entropy, quantifies the asymmetric statistical distance between two probability distributions over the same sample space. It acts as the mathematical cornerstone of variational autoencoders, Bayesian inference, and modern policy gradient reinforcement learning algorithms.

Imagine transmitting messages about daily financial market movements where the true probabilities are 70% Bull market, 20% Neutral, and 10% Bear market ($P = [0.70, 0.20, 0.10]$). The optimal Shannon code length for these true states requires an average of $H(P) = -0.7\log_2(0.7) - 0.2\log_2(0.2) - 0.1\log_2(0.1) \approx 1.157$ bits per message.

Now suppose an inexperienced analyst assumes a uniform prior, believing all three outcomes are equally likely at 33.3% each ($Q = [1/3, 1/3, 1/3]$). If you build your transmission code using the analyst's uniform model $Q$, each outcome requires $-\log_2(1/3) \approx 1.585$ bits. When reality sends messages drawn from $P$, the expected message length is $1.585$ bits.

The excess storage wasted per transmission is $1.585 - 1.157 = 0.428$ bits. This exact excess cost—the penalty for using an incorrect distribution $Q$ instead of true distribution $P$—is the Kullback–Leibler divergence $D_{\text{KL}}(P \parallel Q)$. Notice what happens if we reverse the roles: if reality were uniform $Q$, but we mistakenly coded with the analyst's skewed beliefs $P$, the penalty would be $D_{\text{KL}}(Q \parallel P) \approx 0.468$ bits. Because $0.428 \ne 0.468$, KL divergence is not a true mathematical distance metric: it is strictly asymmetric and violates the triangle inequality.

In everyday terms

KL divergence is like the fuel penalty of navigating a ship with an outdated nautical map: if the map slightly misjudges open waters the penalty is modest, but if the map assumes deep ocean where a reef exists, disaster strikes.

02 Step by step

  1. Define discrete probability distributions $P$ and $Q$ over the identical support set $\mathcal{X}$.
  2. Verify absolute continuity: ensure $Q(x) > 0$ whenever $P(x) > 0$; if $P(x) > 0$ and $Q(x) = 0$, $D_{\text{KL}}$ is infinite.
  3. Calculate the log-likelihood ratio (information gain) for each state: $\ln(P(x) / Q(x))$.
  4. Compute the expected log-ratio under distribution $P$: $D_{\text{KL}}(P \parallel Q) = \sum P(x) \ln(P(x) / Q(x))$.
  5. Check Gibbs' inequality: verify that $D_{\text{KL}}(P \parallel Q) \ge 0$, with equality if and only if $P = Q$ almost everywhere.
  6. Use $D_{\text{KL}}$ to regularise model posteriors towards priors, such as in variational autoencoders and trust-region policy optimisation.

03 The maths

  1. Discrete and Continuous KL Divergence

    $$D_{\text{KL}}(P \parallel Q) = \sum_{x \in \mathcal{X}} P(x) \ln\left(\frac{P(x)}{Q(x)}\right) = \int_{-\infty}^{\infty} p(x) \ln\left(\frac{p(x)}{q(x)}\right) dx$$

    Here $P(x)$ is the true or target reference distribution and $Q(x)$ is the approximating distribution. KL divergence can be rewritten as the cross-entropy minus the entropy: $D_{\text{KL}}(P \parallel Q) = H(P, Q) - H(P)$. When using base 2 logarithms, the result is in bits; when using natural logarithms, it is in nats.

  2. Gibbs' Inequality and Non-Negativity

    $$D_{\text{KL}}(P \parallel Q) \ge 0, \qquad D_{\text{KL}}(P \parallel Q) = 0 \iff P = Q \text{ almost everywhere}$$

    By Jensen's inequality and the strict convexity of $-\ln(t)$, $E_P[-\ln(Q/P)] \ge -\ln(E_P[Q/P]) = -\ln(1) = 0$. This fundamental property guarantees that approximating a distribution never reduces expected coding length below the true entropy.

  3. KL Divergence Between Univariate Gaussians

    $$D_{\text{KL}}\left(\mathcal{N}(\mu_1, \sigma_1^2) \parallel \mathcal{N}(\mu_2, \sigma_2^2)\right) = \ln\left(\frac{\sigma_2}{\sigma_1}\right) + \frac{\sigma_1^2 + (\mu_1 - \mu_2)^2}{2\sigma_2^2} - \frac{1}{2}$$

    For continuous Gaussian distributions, KL divergence has a closed-form analytic solution. In Variational Autoencoders (VAEs), this formula measures the divergence between an encoder's latent Gaussian posterior $\mathcal{N}(\mu, \sigma^2)$ and a standard Gaussian prior $\mathcal{N}(0, 1)$, simplifying to $\frac{1}{2}(\sigma^2 + \mu^2 - 1 - \ln \sigma^2)$.

04 Key takeaways

  • KL divergence measures the expected excess surprise or coding inefficiency of using distribution $Q$ to model reality $P$.
  • KL divergence is strictly non-negative ($D_{\text{KL}} \ge 0$) and equals zero if and only if the two distributions are identical.
  • KL divergence is asymmetric: $D_{\text{KL}}(P \parallel Q) \ne D_{\text{KL}}(Q \parallel P)$, meaning it cannot serve as a true distance metric.
  • Forward KL ($D_{\text{KL}}(P \parallel Q)$) penalises $Q$ heavily where $P > 0$, forcing $Q$ to cover all modes (mean-seeking); reverse KL ($D_{\text{KL}}(Q \parallel P)$) penalises $Q > 0$ where $P = 0$, forcing $Q$ to concentrate on a single mode (mode-seeking).

05 In code

python
import numpy as np
import scipy.stats as stats

# Discrete distributions: true market states vs uniform belief
p = np.array([0.70, 0.20, 0.10])
q = np.array([1.0 / 3.0, 1.0 / 3.0, 1.0 / 3.0])

# Forward and reverse KL divergence in bits
kl_forward = stats.entropy(p, q, base=2)
kl_reverse = stats.entropy(q, p, base=2)

# Analytic KL divergence between two univariate Gaussians (nats)
mu1, sig1 = 0.0, 1.0
mu2, sig2 = 1.0, 1.5
kl_gauss = np.log(sig2 / sig1) + (sig1**2 + (mu1 - mu2)**2) / (2.0 * sig2**2) - 0.5

print(f"Forward KL D(P || Q): {kl_forward:.4f} bits")
print(f"Reverse KL D(Q || P): {kl_reverse:.4f} bits")
print(f"Asymmetry delta:      {abs(kl_forward - kl_reverse):.4f} bits")
print(f"Gaussian KL divergence: {kl_gauss:.4f} nats")

Common pitfalls

  • Dividing by zero when $Q(x) = 0$ while $P(x) > 0$, causing divergence to explode to infinity.
  • Treating KL divergence as a symmetric distance metric, causing errors in generative modelling and loss design.
  • Confusing forward KL (zero-avoiding) with reverse KL (zero-forcing) in variational inference and policy optimisation.
  • Overlooking that continuous KL divergence is invariant under coordinate reparameterisation, whereas differential entropy is coordinate-dependent.

06 Check yourself

Q1Why is the Kullback–Leibler divergence not considered a true distance metric in mathematics?

Why: A formal metric must be symmetric ($d(x,y)=d(y,x)$) and satisfy the triangle inequality ($d(x,z) \le d(x,y)+d(y,z)$). KL divergence violates both properties.

Q2What happens to $D_{\text{KL}}(P \parallel Q)$ if there exists an outcome $x$ where $P(x) > 0$ but $Q(x) = 0$?

Why: Because the formula involves $\ln(P(x) / Q(x))$, dividing a positive probability by zero causes the logarithm—and hence the divergence—to become infinite.

Q3In variational inference, how does minimising reverse KL divergence ($D_{\text{KL}}(Q \parallel P)$) affect the approximating distribution $Q$?

Why: Reverse KL penalises positive density in $Q$ where $P$ has low density, forcing $Q$ to compress tightly onto one of the major modes of $P$.

Q4What is the minimum possible value of the Kullback–Leibler divergence $D_{\text{KL}}(P \parallel Q)$?

Why: Gibbs' inequality guarantees $D_{\text{KL}}(P \parallel Q) \ge 0$, with equality holding strictly if and only if $P$ and $Q$ are identical probability distributions.
