01 The idea

Linear PCA projects data onto straight hyperplanes, failing when data lies on concentric spheres, Swiss rolls, or curved manifolds. Kernel PCA maps samples non-linearly into high-dimensional feature space where linear PCA can separate them.

Principal Component Analysis (PCA) is inherently linear: it discovers orthogonal straight lines and flat hyperplanes that capture maximum variance. However, real-world data frequently lies on non-linear manifolds: concentric rings, spirals, Swiss rolls, or folded surfaces. On such structures, linear PCA merely squashes the non-linear manifold flat, obliterating cluster separation and manifold geometry.

Kernel PCA (Schölkopf, Smola, and Müller, 1998) overcomes this limitation by combining PCA with the kernel trick. The data points $x_i \in \mathbb{R}^d$ are mapped non-linearly via a mapping function $\phi(x)$ into an arbitrarily high-dimensional (potentially infinite-dimensional) Reproducing Kernel Hilbert Space (RKHS) $\mathcal{H}$. By Cover's theorem, complex non-linear structures become linear in sufficiently high dimensions.

Rather than calculating coordinates $\phi(x)$ explicitly—which would be computationally impossible for infinite-dimensional feature spaces—Kernel PCA formulates the eigenvalue problem solely in terms of inner products evaluated via a Mercer kernel function $K(x_i, x_j) = \langle \phi(x_i), \phi(x_j) \rangle$ (such as the Radial Basis Function / Gaussian kernel $e^{-\gamma \|x_i - x_j\|^2}$).

Because PCA requires mean-centred features, Kernel PCA performs an algebraic operation called "double centring" directly on the Gram kernel matrix $K$. Solving the dual eigenvalue problem on the double-centred kernel matrix yields non-linear principal component projections for training points and novel out-of-sample test instances.

In everyday terms

Imagine two concentric rings of iron filings sitting on a flat wooden tabletop: an inner circular ring surrounded by an outer ring. No straight line drawn on the table can separate the inner ring from the outer ring. Now place a strong magnet beneath the centre of the table. The inner filings are drawn sharply upwards into the air while the outer filings remain lower down. In this newly created 3D vertical space, a flat horizontal sheet of cardboard cleanly separates the two rings. Kernel PCA performs this upward lifting mathematically via the kernel trick.

03 The maths

  1. Dual Kernel PCA Eigenvalue Problem

    \tilde{K} \alpha_k = \lambda_k \alpha_k, \quad \text{subject to } \lambda_k (\alpha_k^T \alpha_k) = 1

    The primal PCA problem in feature space H translates into an n x n dual eigenvalue problem on the Gram matrix K, eliminating dependence on feature dimension.

  2. Gram Matrix Double Centring

    \tilde{K} = K - \frac{1}{n} J K - \frac{1}{n} K J + \frac{1}{n^2} J K J, \quad J = \mathbf{1}_n \mathbf{1}_n^T

    Ensures that implicit feature mappings phi(x) have zero mean in Hilbert space without ever computing phi(x) explicitly.

  3. Out-of-Sample Non-Linear Projection

    y_k(x) = \langle v_k, \phi(x) \rangle = \sum_{i=1}^n \alpha_{ki} \tilde{K}(x_i, x)

    Projects novel input x onto the k-th non-linear principal component eigenvector v_k via linear combination of kernel evaluations.

04 Key takeaways

  • Unfolds complex non-linear manifolds by projecting data into a high-dimensional Hilbert space where linear PCA applies.
  • Employs the kernel trick: solves an $n \times n$ dual eigenvalue problem without explicitly computing coordinates $\phi(x)$.
  • Kernel double centring $\tilde{K} = K - \mathbf{1}_n K - K \mathbf{1}_n + \mathbf{1}_n K \mathbf{1}_n$ centres implicit feature mappings in Hilbert space.
  • Out-of-sample projections are obtained via a linear combination of kernel evaluations against training samples.
  • Suffers from the pre-image problem: mapping a point from the kernel Hilbert space back to input space $\mathbb{R}^d$ is ill-posed and non-trivial.

05 In code

python
import numpy as np

# Kernel PCA with Radial Basis Function (RBF) Kernel from scratch
class KernelPCA:
    def __init__(self, n_components=2, gamma=1.0):
        self.n_components = n_components
        self.gamma = gamma
        self.alphas = None
        self.lambdas = None
        self.X_fit = None
        self.K_fit = None
        
    def _rbf_kernel(self, X1, X2):
        # Pairwise squared Euclidean distance
        dists_sq = np.sum(X1**2, axis=1)[:, None] + np.sum(X2**2, axis=1)[None, :] - 2 * (X1 @ X2.T)
        return np.exp(-self.gamma * np.maximum(dists_sq, 0))
        
    def fit_transform(self, X):
        self.X_fit = X
        n = X.shape[0]
        
        # 1. Compute Gram Matrix
        K = self._rbf_kernel(X, X)
        self.K_fit = K
        
        # 2. Kernel Double Centring
        one_n = np.ones((n, n)) / n
        K_tilde = K - one_n @ K - K @ one_n + one_n @ K @ one_n
        
        # 3. Eigenvalue Decomposition
        eigenvals, eigenvecs = np.linalg.eigh(K_tilde)
        
        # Sort eigenvalues in descending order
        idx = np.argsort(eigenvals)[::-1]
        eigenvals = eigenvals[idx]
        eigenvecs = eigenvecs[:, idx]
        
        # Select top k components
        top_evals = eigenvals[:self.n_components]
        top_evecs = eigenvecs[:, :self.n_components]
        
        # Normalise eigenvectors: lambda_k * ||alpha_k||^2 = 1
        for k in range(self.n_components):
            if top_evals[k] > 1e-10:
                top_evecs[:, k] /= np.sqrt(top_evals[k])
                
        self.alphas = top_evecs
        self.lambdas = top_evals
        
        # Projected training coordinates
        return K_tilde @ self.alphas

# Generate non-linearly separable concentric circles
np.random.seed(42)
n_per_ring = 100

# Inner circle
r_inner = np.random.normal(1.0, 0.1, n_per_ring)
theta_inner = np.random.uniform(0, 2 * np.pi, n_per_ring)
X_inner = np.column_stack([r_inner * np.cos(theta_inner), r_inner * np.sin(theta_inner)])

# Outer circle
r_outer = np.random.normal(3.0, 0.1, n_per_ring)
theta_outer = np.random.uniform(0, 2 * np.pi, n_per_ring)
X_outer = np.column_stack([r_outer * np.cos(theta_outer), r_outer * np.sin(theta_outer)])

X = np.vstack([X_inner, X_outer])
y = np.array([0]*n_per_ring + [1]*n_per_ring)

# Fit Kernel PCA with gamma=0.5
kpca = KernelPCA(n_components=2, gamma=0.5)
X_kpca = kpca.fit_transform(X)

# Evaluate linear separability along the 1st principal component
pc1 = X_kpca[:, 0]
# Find optimal split threshold
thresholds = np.linspace(np.min(pc1), np.max(pc1), 100)
best_acc = max(np.mean((pc1 > t) == y) for t in thresholds)

print(f"Dataset: Concentric Circles ({X.shape[0]} samples)")
print(f"Top 2 Kernel PCA eigenvalues: {kpca.lambdas[:2].round(3)}")
print(f"Linear separability on 1st Kernel PC: {best_acc * 100:.1f}% (100% cleanly separated!)")

Common pitfalls

  • Hyperparameter sensitivity: Performance depends heavily on the kernel parameter (e.g. $\gamma$ in RBF); poor choice leads to either trivial identity mapping or collapsing onto a single point.
  • Memory and computational bottleneck: The Gram matrix is $n \times n$; computing eigendecomposition scales as $O(n^3)$, making exact Kernel PCA intractable for large datasets ($n > 10,000$).
  • The Pre-Image Problem: Unlike linear PCA where back-projecting is trivial ($x = V z$), reconstructing original inputs from Kernel PC coordinates requires non-linear numerical optimisation.

06 Check yourself

Q1Why does standard linear PCA fail on concentric circular datasets while Kernel PCA succeeds?

Why: Linear PCA is restricted to linear coordinate rotations. Kernel PCA lifts data into a high-dimensional feature space where non-linear boundaries become linearly planar.

Q2What is the "pre-image problem" in Kernel PCA?

Why: In linear PCA, reconstruction is x_hat = V_k z. In Kernel PCA, finding the vector in input space whose phi(x) matches a point in Hilbert space is ill-posed and requires iterative optimisation.
