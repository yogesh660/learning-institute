Instance Segmentation with Mask R-CNN: Extending Faster R-CNN with RoIAlign and Mask FCN

Detecting and segmenting individual object instances simultaneously using Faster R-CNN backbones, RoIAlign, and parallel pixel-level mask FCN heads.

01 The idea

Semantic segmentation classifies every pixel into a category (e.g. "person"), but cannot distinguish between two people standing side by side. Object detection places a bounding box around each person, but cannot capture exact contours. Instance Segmentation achieves both: detecting each individual object instance and predicting a pixel-accurate binary mask for each. Mask R-CNN (He et al., 2017) solved this elegantly by adding a small Fully Convolutional Network mask branch in parallel with Faster R-CNN.

Instance segmentation follows a "Detect then Segment" paradigm: first detect candidate object bounding boxes, and then predict a binary segmentation mask inside each proposed box.

Mask R-CNN extends Faster R-CNN by adding a third parallel output branch for each Region of Interest (RoI): in addition to the classification branch (predicting class $c$) and bounding box regression branch (predicting box deltas), it adds a small Fully Convolutional Network (FCN) predicting a $K \times m \times m$ binary mask (where $m \times m$ is typically $28 \times 28$).

The critical enabler was RoIAlign: Faster R-CNN's original `RoIPool` used integer quantization (rounding $16.7$ to $16$), introducing up to half-pixel misalignments. While harmless for coarse bounding boxes, a 1-pixel shift completely misaligns fine object masks. RoIAlign uses bilinear interpolation at four sampling points per bin, preserving continuous floating-point spatial fidelity.

Decoupling mask and class prediction: For each RoI, the mask branch outputs $K$ independent binary masks (one for each class), without competition between classes. The classification branch independently decides which class label to apply, preventing inter-class competition from corrupting mask quality.

In everyday terms

Imagine a factory quality-control robot inspecting apples on a conveyor belt. Semantic segmentation says: "80% of the belt area is apple". Object detection says: "there are four separate rectangular apple crates". Instance segmentation assigns a distinct numbered label to each individual apple and shrink-wraps an exact plastic clingfilm contour around every single apple skin, isolating bruised spots to sub-millimeter precision.

02 Step by step

  1. Extract multi-scale feature pyramid: Pass image through ResNet with Feature Pyramid Network (FPN) generating feature maps at strides 4, 8, 16, 32.
  2. Generate candidate proposals via RPN: Region Proposal Network proposes high-recall candidate bounding boxes.
  3. Extract aligned RoI features via RoIAlign: Extract continuous $14 \times 14$ feature representations for each proposal using bilinear interpolation without quantization.
  4. Classify and regress box (Standard Faster R-CNN): Pass features through fully connected layers to predict class logits and refined bounding box offsets.
  5. Predict pixel-accurate masks in parallel: Pass $14 \times 14$ features through a 4-layer $3 \times 3$ FCN followed by a $2 \times 2$ deconvolution, emitting $28 \times 28$ binary mask logits for each class.
  6. Paste and threshold mask: Threshold the target class mask at $0.5$ and paste back onto the original image within the predicted bounding box coordinates.

03 The maths

  1. Mask R-CNN Multi-Task Total Loss

    \mathcal{L}_{\mathrm{total}} = \mathcal{L}_{\mathrm{cls}} + \mathcal{L}_{\mathrm{box}} + \mathcal{L}_{\mathrm{mask}}

    Jointly trains classification loss $\mathcal{L}_{\mathrm{cls}}$, bounding box regression $\mathcal{L}_{\mathrm{box}}$, and pixel binary cross-entropy $\mathcal{L}_{\mathrm{mask}}$.

  2. Decoupled Binary Mask Cross-Entropy Loss

    \mathcal{L}_{\mathrm{mask}} = -\frac{1}{m^2} \sum_{i=1}^{m} \sum_{j=1}^{m} \left[ y_{ij} \ln \sigma(s_{ij}^k) + (1 - y_{ij}) \ln (1 - \sigma(s_{ij}^k)) \right]

    Evaluates average binary cross-entropy strictly on the $k$-th mask slice corresponding to ground-truth class $k$, avoiding inter-class competition.

  3. RoIAlign Continuous Bilinear Interpolation

    f(x, y) = \sum_{i, j \in \{0, 1\}} w_{ij} \cdot f(\lfloor x \rfloor + i, \; \lfloor y \rfloor + j), \quad w_{ij} = |1 - i - (x - \lfloor x \rfloor)| \cdot |1 - j - (y - \lfloor y \rfloor)|

    Samples exact continuous sub-pixel coordinates without spatial rounding, eliminating mask boundary quantization artifacts.

04 Key takeaways

  • Mask R-CNN adds a small parallel FCN branch to Faster R-CNN to predict pixel masks.
  • RoIAlign eliminates spatial quantization by sampling four continuous bilinear points per bin.
  • Decouples class and mask prediction: predicts independent binary masks for each category.
  • Represents the industry standard foundation for instance segmentation in robotics and medical imaging.

05 In code

python
import torch
import torch.nn as nn
import torch.nn.functional as F

class MiniMaskBranch(nn.Module):
    """Educational demonstration of Mask R-CNN's FCN mask prediction branch."""
    def __init__(self, in_channels: int = 256, num_classes: int = 4, mask_res: int = 14):
        super().__init__()
        # 4 consecutive conv layers
        self.convs = nn.Sequential(
            nn.Conv2d(in_channels, in_channels, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.Conv2d(in_channels, in_channels, kernel_size=3, padding=1),
            nn.ReLU()
        )
        # Deconvolution (transpose conv) to upsample 14x14 -> 28x28
        self.upsample = nn.ConvTranspose2d(in_channels, in_channels, kernel_size=2, stride=2)
        # 1x1 conv predicting K binary mask channels
        self.mask_head = nn.Conv2d(in_channels, num_classes, kernel_size=1)

    def forward(self, roi_features: torch.Tensor):
        # roi_features from RoIAlign: [num_rois, in_channels, 14, 14]
        h = self.convs(roi_features)
        h = F.relu(self.upsample(h))  # [num_rois, in_channels, 28, 28]
        mask_logits = self.mask_head(h)  # [num_rois, num_classes, 28, 28]
        return mask_logits

# Test mask branch on 2 RoIs (e.g. 2 detected pedestrians)
roi_feat = torch.randn(2, 256, 14, 14)
mask_net = MiniMaskBranch(in_channels=256, num_classes=4)
masks = mask_net(roi_feat)

print(f"Input RoIAlign feature shape: {roi_feat.shape}")
print(f"Output mask logits shape:     {masks.shape} (2 RoIs, 4 classes, 28x28 resolution)")
print("Each class receives an independent binary mask channel, preventing inter-class competition!")

Common pitfalls

  • Using `RoIPool` instead of `RoIAlign`: Using coarse integer RoIPool degrades mask average precision (AP) by up to 10 points due to spatial quantization misalignments.
  • Coupling mask channels with Softmax: Using Softmax across mask channels forces classes to compete for pixels, destroying overlapping mask contours; use per-pixel sigmoid binary cross-entropy.
  • Memory consumption during training: Predicting $28 \times 28$ masks across 512 candidate RoIs per image increases GPU VRAM consumption; tune sampled positive RoIs.

06 Check yourself

Q1What distinguishes Instance Segmentation from Semantic Segmentation?

Why: Semantic segmentation assigns all "person" pixels to one class. Instance segmentation distinguishes Person 1, Person 2, and Person 3 with individual masks.

Q2Why did the authors of Mask R-CNN decouple mask prediction from classification by using per-pixel Sigmoid instead of Softmax across classes?

Why: Decoupling avoids forcing classes to compete for pixels. The network learns pure binary object silhouettes independently for each candidate category.

Q3What was the specific bug in `RoIPool` that RoIAlign fixed in Mask R-CNN?

Why: RoIPool rounded floating coordinates to integers ($x/16$), introducing half-pixel errors that misaligned pixel-level mask boundaries with real object edges.
