01 The idea

MARS automatically uncovers non-linear relationships and high-order feature interactions without requiring manual feature engineering, building an interpretable piecewise linear spline model.

Traditional linear models are constrained by rigid linearity. To capture non-linear patterns, data scientists frequently hand-engineer polynomial features ($x^2, x^3$) or interaction products ($x_1 x_2$). However, polynomial terms have notorious runaway behaviour at boundaries, and searching through all possible interactions among dozens of features creates combinatorial explosion.

Jerome Friedman developed Multivariate Adaptive Regression Splines (MARS) in 1991 to automate non-linear regression and feature interaction discovery. MARS uses mirrored pairs of piecewise linear hinge functions (also known as truncated power functions or hockey-stick functions): $\max(0, x - c)$ and $\max(0, c - x)$, where $c$ is a candidate knot location placed at observed values of predictor $x$.

The algorithm proceeds in two distinct stages. In the Forward Pass, MARS starts with an intercept and iteratively searches across all features and knot locations, greedily adding the pair of hinge functions (or interaction products of existing hinges with new hinges) that yields the greatest reduction in sum of squared errors. This forward greedy expansion intentionally overfits the training data.

In the Backward Pruning Pass, MARS systematically removes basis functions one by one, using Generalised Cross-Validation (GCV) to penalise model complexity. The model that minimises GCV is selected. The resulting model is non-linear, continuous, easily interpretable as localized slopes and interaction terms, and computationally fast.

In everyday terms

Imagine sculpting an irregular wooden contour using a set of wooden wedges and hinges. Rather than bending a stiff steel beam across the whole length (a linear model) or trying to carve an infinitely curved mathematical spiral (a high-degree polynomial), you place joint hinges at key stress points. Each hinge bends linearly in one direction and remains flat in the other. Once you have placed hinges everywhere, you remove the redundant joints until you are left with the cleanest structural framework.

03 The maths

  1. Reflected Hinge Functions

    (x - c)_+ = \max(0, x - c), \quad (c - x)_+ = \max(0, c - x)

    A pair of reflected hinge functions at knot c. For any x, one function is zero while the other is a linear ramp with slope +1 or -1, ensuring continuous piecewise linear approximations.

  2. MARS Model Formulation

    \hat{f}(x) = \beta_0 + \sum_{m=1}^M \beta_m B_m(x), \quad B_m(x) = \prod_{k=1}^{K_m} [s_{km} (x_{v(k, m)} - c_{km})]_+

    The fitted function is a linear combination of basis functions, each consisting of an individual hinge or a product of multiple hinges representing multi-way feature interactions.

  3. Generalised Cross-Validation (GCV) Criterion

    \mathrm{GCV}(M) = \frac{\frac{1}{n} \sum_{i=1}^n (y_i - \hat{f}_M(x_i))^2}{\left(1 - \frac{M + d \cdot (M - 1) / 2}{n}\right)^2}

    GCV penalises model degrees of freedom, where d is an effective cost parameter per knot (typically d = 2 or 3) accounting for the forward search over knot locations.

04 Key takeaways

  • Automates non-linear modelling and interaction detection using reflected piecewise linear hinge functions $\max(0, x - c)$ and $\max(0, c - x)$.
  • Two-stage architecture: greedy forward expansion to capture non-linear patterns followed by backward pruning via GCV to prevent overfitting.
  • Continuous piecewise linearity ensures models do not exhibit wild polynomial runaway oscillations at outer boundaries.
  • Provides inherent interpretability: variable importance can be measured by GCV drop upon removing all basis functions involving that feature.
  • Serves as an effective, interpretable bridge between rigid linear models and black-box gradient-boosted trees.

05 In code

python
import numpy as np

# Multivariate Adaptive Regression Splines (MARS) Forward Step from scratch
np.random.seed(42)
n_samples = 150

# True function: non-linear piecewise with a sharp bend and an interaction
x1 = np.random.uniform(0, 10, n_samples)
x2 = np.random.uniform(0, 10, n_samples)
# Sharp bend at x1=5, interaction between (x1-5)+ and (x2-4)+
y_clean = 2.0 + 1.5 * np.maximum(0, 5.0 - x1) + 3.0 * np.maximum(0, x1 - 5.0) + 1.2 * np.maximum(0, x1 - 5.0) * np.maximum(0, x2 - 4.0)
y = y_clean + np.random.normal(0, 0.5, n_samples)

# Simplified Forward MARS Search
class SimpleMARS:
    def __init__(self, max_terms=7):
        self.max_terms = max_terms
        self.bases = [lambda X: np.ones(len(X))]
        self.basis_names = ["Intercept"]
        self.coef_ = None
        
    def fit(self, X, y):
        n, p = X.shape
        while len(self.bases) < self.max_terms:
            best_rss = float("inf")
            best_pair = None
            best_name = None
            
            # Current design matrix
            B_curr = np.column_stack([b(X) for b in self.bases])
            
            # Search over parent bases, features, and candidate knots
            for b_idx in range(len(self.bases)):
                parent_b = self.bases[b_idx]
                parent_vals = parent_b(X)
                
                for f_idx in range(p):
                    col = X[:, f_idx]
                    knots = np.percentile(col, [25, 50, 75])
                    
                    for c in knots:
                        h_right = parent_vals * np.maximum(0, col - c)
                        h_left = parent_vals * np.maximum(0, c - col)
                        
                        B_cand = np.column_stack([B_curr, h_right, h_left])
                        coefs, residuals, _, _ = np.linalg.lstsq(B_cand, y, rcond=None)
                        rss = np.sum((y - B_cand @ coefs)**2)
                        
                        if rss < best_rss:
                            best_rss = rss
                            best_pair = (
                                lambda X, f=f_idx, c=c, pb=parent_b: pb(X) * np.maximum(0, X[:, f] - c),
                                lambda X, f=f_idx, c=c, pb=parent_b: pb(X) * np.maximum(0, c - X[:, f])
                            )
                            best_name = (f"h(x{f_idx+1}-{c:.1f})", f"h({c:.1f}-x{f_idx+1})")
                            
            if best_pair is not None:
                self.bases.extend(best_pair)
                self.basis_names.extend(best_name)
            else:
                break
                
        # Final OLS fit
        B_final = np.column_stack([b(X) for b in self.bases])
        self.coef_, _, _, _ = np.linalg.lstsq(B_final, y, rcond=None)
        
    def predict(self, X):
        B = np.column_stack([b(X) for b in self.bases])
        return B @ self.coef_

X_data = np.column_stack([x1, x2])
mars = SimpleMARS(max_terms=7)
mars.fit(X_data, y)
preds = mars.predict(X_data)
r2 = 1.0 - np.sum((y - preds)**2) / np.sum((y - np.mean(y))**2)

print(f"MARS Model R^2: {r2:.4f}")
print("Discovered Basis Functions and Coefficients:")
for name, c in zip(mars.basis_names, mars.coef_):
    print(f"  {name:25s}: beta = {c:+.3f}")

Common pitfalls

  • Computational scaling with sample size: Testing all candidate knot locations across every feature scales as $O(n \cdot p \cdot M)$, necessitating knot subsampling for large datasets.
  • Collinearity among basis functions: Reflected hinge pairs and multi-way interaction terms can be highly correlated; backward pruning and SVD-based solvers are essential.
  • Higher-order interaction degradation: Allowing interactions beyond degree 2 or 3 rapidly degrades statistical power and creates uninterpretable models.

06 Check yourself

Q1Why are reflected hinge functions max(0, x - c) and max(0, c - x) preferred over high-degree polynomials for non-linear regression?

Why: High-degree polynomials suffer from Runge phenomenon and extreme runaway oscillations at data boundaries. Reflected hinge functions are localized and bounded linearly.

Q2What role does Generalised Cross-Validation (GCV) play in the MARS algorithm?

Why: GCV provides a fast analytical approximation to leave-one-out cross-validation, penalising the number of knots and basis functions to identify the optimal pruned sub-model.
