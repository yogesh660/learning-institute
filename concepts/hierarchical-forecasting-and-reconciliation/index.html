Hierarchical Forecasting and Coherent Reconciliation: Bottom-Up, Top-Down, and MinT

Ensuring structural consistency across nested aggregation levels (SKU, store, region, national) using optimal linear reconciliation (MinT).

01 The idea

In enterprise demand planning and retail supply chains, time series naturally form hierarchies: individual SKU sales roll up into product categories, store sales roll up into regional markets, and regional markets sum to national revenue. Generating independent forecasts at each level produces incoherent numbers where store-level forecasts do not add up to regional predictions. Hierarchical reconciliation mathematically aligns predictions across the entire tree, guaranteeing coherence while improving overall accuracy.

A hierarchical time series consists of $m$ series at different levels of aggregation, linked by a summing matrix $\mathbf{S} \in \{0, 1\}^{m \times m_b}$, where $m_b$ is the number of bottom-level series. The relationship $\mathbf{y}_t = \mathbf{S} \mathbf{b}_t$ must hold at all times.

Traditional heuristic reconciliation methods include Bottom-Up (forecast only the bottom level and aggregate upwards) and Top-Down (forecast the top series and disaggregate using historical proportions). Bottom-up suffers when bottom series are noisy and sparse; top-down loses sub-category dynamics and product-level seasonality.

Middle-Out blends both by forecasting an intermediate level and projecting both up and down, but remains suboptimal because it ignores correlations between series.

Optimal reconciliation (Hyndman et al., MinT - Minimum Trace) treats reconciliation as a generalised least squares problem. Unreconciled base forecasts $\hat{\mathbf{y}}$ are mapped to coherent forecasts $\tilde{\mathbf{y}} = \mathbf{S} \mathbf{P} \hat{\mathbf{y}}$, where the projection matrix $\mathbf{P} = (\mathbf{S}^T \mathbf{W}^{-1} \mathbf{S})^{-1} \mathbf{S}^T \mathbf{W}^{-1}$ minimises the total forecast error variance across the hierarchy using the base forecast error covariance matrix $\mathbf{W}$.

In everyday terms

Imagine a corporate budget spreadsheet. Department managers create their own expense forecasts, while the regional director forecasts the total regional expenditure. If the individual department line items sum to £12M but the regional director's model forecasts £10M, the finance department cannot balance the books. Reconciliation is an optimal arbitration mechanism that adjusts all numbers simultaneously so that every sub-branch adds up cleanly to its parent total while respecting which forecasts are historically most reliable.

02 Step by step

  1. Define hierarchy structure: Construct the structural summing matrix $\mathbf{S}$ encoding parent-child aggregation relationships across all tiers.
  2. Fit base forecasting models: Independently train optimal time series models (ARIMA, LightGBM, Exponential Smoothing) for every series at every level.
  3. Compute base forecast residuals: Evaluate in-sample or cross-validation residuals to estimate the base error covariance matrix $\mathbf{W}$.
  4. Select covariance approximation: Use sample covariance, diagonal shrinkage, or structural variance scaling if series count $m$ is large.
  5. Compute optimal projection: Calculate reconciliation projection matrix $\mathbf{P}$ and multiply base forecasts $\hat{\mathbf{y}}_h$ to obtain coherent forecasts $\tilde{\mathbf{y}}_h = \mathbf{S} \mathbf{P} \hat{\mathbf{y}}_h$.

03 The maths

  1. Structural Summing Matrix Equality

    \mathbf{y}_t = \begin{bmatrix} \mathbf{u}_t \\ \mathbf{b}_t \end{bmatrix} = \mathbf{S} \mathbf{b}_t, \quad \mathbf{S} = \begin{bmatrix} \mathbf{A} \\ \mathbf{I}_{m_b} \end{bmatrix}

    The structural summing matrix $\mathbf{S}$ maps $m_b$ bottom-level series $\mathbf{b}_t$ to all $m$ series in the hierarchy, where $\mathbf{A}$ contains aggregation weights.

  2. Linear Reconciliation Representation

    \tilde{\mathbf{y}}_h = \mathbf{S} \mathbf{P} \hat{\mathbf{y}}_h, \quad \mathbf{P} \in \mathbb{R}^{m_b \times m}

    Coherent forecasts $\tilde{\mathbf{y}}_h$ are guaranteed to add up because they are formed as a linear combination of base forecasts mapped through summing matrix $\mathbf{S}$.

  3. MinT (Minimum Trace) Optimal Solution

    \mathbf{P}_{\mathrm{MinT}} = (\mathbf{S}^T \mathbf{W}^{-1} \mathbf{S})^{-1} \mathbf{S}^T \mathbf{W}^{-1}

    MinT provides the unique unbiased linear projection that minimises the trace of the reconciled error covariance matrix $\operatorname{Tr}[\operatorname{Var}(\mathbf{y} - \tilde{\mathbf{y}})]$, where $\mathbf{W} = \operatorname{Var}(\mathbf{y} - \hat{\mathbf{y}})$.

04 Key takeaways

  • Hierarchical reconciliation ensures forecasts across all levels of aggregation add up consistently.
  • Base independent forecasts are almost always incoherent due to individual model estimation noise.
  • MinT uses generalised least squares to find the optimal unbiased coherent projection that minimises error variance.
  • Reconciliation consistently improves forecast accuracy compared to isolated single-level forecasts by sharing cross-hierarchy information.

05 In code

python
import numpy as np

# Consider a 2-level hierarchy: Total (T) = Store A (A) + Store B (B)
# Number of total series m = 3, bottom series m_b = 2
# Summing matrix S: [T; A; B] = S * [A; B]
S = np.array([
    [1.0, 1.0],  # Total = A + B
    [1.0, 0.0],  # A = A
    [0.0, 1.0]   # B = B
])

# Base independent forecasts from separate models (incoherent! 80 + 45 = 125 != 130)
y_hat = np.array([130.0, 80.0, 45.0])

# Estimate base error covariance matrix W (assuming diagonal variance for simplicity)
# Total has variance 20, A has variance 10, B has variance 15
W = np.diag([20.0, 10.0, 15.0])
W_inv = np.linalg.inv(W)

# Compute MinT projection matrix: P = (S^T W^-1 S)^-1 S^T W^-1
St_Winv = S.T @ W_inv
P_mint = np.linalg.inv(St_Winv @ S) @ St_Winv

# Reconcile forecasts: y_tilde = S @ P @ y_hat
y_tilde = S @ P_mint @ y_hat

print("Base forecasts (Incoherent): Total=%.1f, A=%.1f, B=%.1f (Sum=%.1f)" % 
      (y_hat[0], y_hat[1], y_hat[2], y_hat[1] + y_hat[2]))
print("Reconciled forecasts (Coherent): Total=%.2f, A=%.2f, B=%.2f (Sum=%.2f)" % 
      (y_tilde[0], y_tilde[1], y_tilde[2], y_tilde[1] + y_tilde[2]))
# Notice the reconciled forecasts satisfy Total = A + B exactly!

Common pitfalls

  • Singular covariance matrix: When $m > n$ (more series than time observations), the sample covariance matrix $\mathbf{W}$ is non-invertible; use diagonal shrinkage.
  • Negative reconciled forecasts: Linear projection can occasionally yield small negative numbers for bottom-level series with near-zero demand; apply non-negative quadratic programming.
  • Ignoring cross-level correlations: Using simple Ordinary Least Squares (OLS) reconciliation assumes all base forecasts have equal variance, which is false since top aggregates have vastly different scales.

06 Check yourself

Q1Why are base forecasts generated independently at different hierarchical levels almost never coherent?

Why: Base models optimise isolated loss functions without imposing structural equality constraints, causing aggregate sums to deviate from parent predictions.

Q2What is the key advantage of MinT (Minimum Trace) over simple Bottom-Up forecasting?

Why: Bottom-up discards all top-level signals and magnifies noisy bottom series. MinT combines information from all levels, weighting them by their inverse covariance.

Q3What role does the summing matrix $\mathbf{S}$ play in hierarchical forecasting?

Why: The summing matrix $\mathbf{S} \in \{0, 1\}^{m \times m_b}$ maps bottom series to all aggregated series such that $\mathbf{y} = \mathbf{S}\mathbf{b}$.
