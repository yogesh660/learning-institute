01 The idea

Standard regression fails when predicting time-to-event outcomes because unfinished durations are right-censored: customers have not yet churned, machines have not yet failed, and patients remain alive at study conclusion. Survival analysis properly accounts for censored observation windows.

In many data science problems, the target variable of interest is the time $T \ge 0$ until an event occurs: customer subscription cancellation (churn), machine component failure, loan default, or clinical relapse. Ordinary regression models encounter a fundamental roadblock: right-censoring. When a customer is still subscribed at the end of a six-month analysis period, their true time-to-churn is unknown—all we know is $T > 6$. Excluding censored cases creates severe survival bias, while treating censored duration as the true event time severely underestimates survival times.

Survival analysis resolves this by modelling two linked mathematical functions: the survival function $S(t) = P(T > t)$, which specifies the probability an individual survives past time $t$, and the hazard function $h(t)$, which quantifies the instantaneous rate of event occurrence at time $t$ conditional on having survived up to time $t$.

The Kaplan–Meier estimator provides the gold-standard non-parametric estimate of the survival curve. At each unique event time $t_i$, it computes the conditional probability of surviving step $t_i$ given the risk set $n_i$ (individuals still alive and uncensored immediately prior to $t_i$): $1 - d_i / n_i$, where $d_i$ is the number of events. The cumulative survival function is the product of these conditional survival probabilities. Greenwood's formula supplies asymptotic standard errors and confidence intervals.

When evaluating the impact of covariates (such as customer tier, contract type, or medical treatment), the Cox Proportional Hazards model provides an elegant semi-parametric regression framework: $h(t \mid x) = h_0(t) \exp(\beta^T x)$. Here, $h_0(t)$ is an arbitrary baseline hazard function that requires no parametric assumptions, while the hazard ratio $\exp(\beta_j)$ quantifies the multiplicative increase in instantaneous risk associated with a unit increase in covariate $x_j$. The coefficients $\beta$ are estimated via Cox's partial likelihood without needing to specify $h_0(t)$.

In everyday terms

Imagine tracking the lifespan of lightbulbs in an office tower over a 12-month study. Some bulbs burn out after 3 months (uncensored events). But at month 12, hundreds of bulbs are still burning bright (right-censored). If you average only the burned-out bulbs, you calculate an artificially dismal lifespan. The Kaplan–Meier estimator treats each burnout as an event against the pool of currently glowing bulbs, accurately charting survival probabilities out to 12 months without discarding surviving bulbs.

03 The maths

  1. Survival and Hazard Relationships

    S(t) = P(T > t) = \exp\left(-\int_0^t h(u) du\right) = \exp(-H(t)), \quad h(t) = \lim_{\Delta t \to 0} \frac{P(t \le T < t + \Delta t \mid T \ge t)}{\Delta t} = -\frac{S'(t)}{S(t)}

    The survival function S(t) and hazard function h(t) are mathematically dual: hazard is the negative derivative of log survival, and cumulative hazard H(t) integrates hazard over time.

  2. Kaplan–Meier Estimator and Greenwood Formula

    \hat{S}(t) = \prod_{t_i \le t} \left(1 - \frac{d_i}{n_i}\right), \quad \widehat{\operatorname{Var}}(\hat{S}(t)) = \hat{S}(t)^2 \sum_{t_i \le t} \frac{d_i}{n_i (n_i - d_i)}

    Product-limit estimator accumulating survival rates over observed failure times. Greenwood formula yields standard error used to construct pointwise confidence intervals.

  3. Cox Proportional Hazards and Partial Likelihood

    h(t \mid x) = h_0(t) \exp(\beta^T x), \quad L(\beta) = \prod_{i=1}^k \frac{\exp(\beta^T x_{(i)})}{\sum_{j \in R(t_{(i)})} \exp(\beta^T x_j)}

    Baseline hazard h_0(t) cancels completely out of the partial likelihood, allowing estimation of covariate effect coefficients beta without making parametric distributional assumptions about event times.

04 Key takeaways

  • Right-censoring occurs when an observation window ends before an event takes place; standard regression creates severe survival bias if censoring is neglected.
  • Survival function S(t) = P(T > t) gives the probability of surviving past t; hazard function h(t) gives the instantaneous event rate conditional on prior survival.
  • The Kaplan–Meier product-limit estimator provides an exact non-parametric step function estimate of S(t) with Greenwood confidence bands.
  • The log-rank test evaluates whether two or more survival curves differ significantly under a non-parametric null hypothesis.
  • Cox proportional hazards model is semi-parametric: it estimates hazard ratios exp(beta) via partial likelihood without specifying the baseline hazard h_0(t).

05 In code

python
import numpy as np

# Kaplan-Meier Estimator and Cox Partial Likelihood from Scratch
np.random.seed(42)
n_samples = 200

# Synthetic customer churn data
# Covariate x: premium subscription tier (1 = premium, 0 = standard)
tier = np.random.binomial(1, 0.4, size=n_samples)
# True baseline hazard: exponential survival, premium reduces hazard by half (beta = -0.693)
true_beta = -0.7
hazard = 0.05 * np.exp(true_beta * tier)
true_survival_time = np.random.exponential(1.0 / hazard)

# Study ends at month 24: right-censoring
study_duration = 24.0
observed_time = np.minimum(true_survival_time, study_duration)
event_occurred = (true_survival_time <= study_duration).astype(int)

# --- Kaplan-Meier Estimation Function ---
def kaplan_meier(durations, events):
    unique_times = np.sort(np.unique(durations[events == 1]))
    s_t = 1.0
    km_table = []
    
    for t in unique_times:
        n_at_risk = np.sum(durations >= t)
        d_events = np.sum((durations == t) & (events == 1))
        s_t *= (1.0 - d_events / n_at_risk)
        km_table.append((t, n_at_risk, d_events, s_t))
    return km_table

km_standard = kaplan_meier(observed_time[tier == 0], event_occurred[tier == 0])
km_premium = kaplan_meier(observed_time[tier == 1], event_occurred[tier == 1])

# --- Cox Proportional Hazards Partial Likelihood ---
def cox_log_partial_likelihood(beta, x, time, event):
    # Sort events in descending order
    order = np.argsort(time)[::-1]
    sorted_time = time[order]
    sorted_event = event[order]
    sorted_x = x[order]
    
    log_lik = 0.0
    risk_sum = 0.0
    for i in range(len(sorted_time)):
        risk_sum += np.exp(beta * sorted_x[i])
        if sorted_event[i] == 1:
            log_lik += beta * sorted_x[i] - np.log(risk_sum)
    return log_lik

# Grid search for maximum partial likelihood estimate beta
betas = np.linspace(-1.5, 0.5, 201)
log_liks = [cox_log_partial_likelihood(b, tier, observed_time, event_occurred) for b in betas]
opt_beta = betas[np.argmax(log_liks)]
hazard_ratio = np.exp(opt_beta)

print(f"Censored observations: {np.sum(event_occurred == 0)} / {n_samples} ({np.mean(event_occurred == 0)*100:.1f}%)")
print(f"Estimated Cox beta: {opt_beta:.3f} (true beta: {true_beta:.3f})")
print(f"Estimated Hazard Ratio: {hazard_ratio:.3f} (premium customers have {(1 - hazard_ratio)*100:.1f}% lower churn hazard)")
print(f"Standard tier 12-month survival: {[s for t, n, d, s in km_standard if t <= 12][-1]:.3f}")
print(f"Premium tier 12-month survival:  {[s for t, n, d, s in km_premium if t <= 12][-1]:.3f}")

Common pitfalls

  • Treating censored observations as event occurrences or dropping them entirely: Dropping censored data removes the longest-lived subjects, skewing average duration downwards.
  • Violation of proportional hazards assumption: Cox models assume hazard ratios exp(beta) remain constant across all time; if a treatment effect decays or inverts over time, the model is mis-specified and needs time-varying covariates or stratification.
  • Informative censoring: Survival analysis assumes censoring is non-informative (unrelated to the event probability); if high-risk subjects selectively drop out of a study, estimates become biased.

06 Check yourself

Q1Why does calculating mean time-to-event via standard linear regression produce biased estimates in right-censored studies?

Why: Right-censoring means event time is strictly greater than study duration. Dropping censored subjects induces survival bias (discards long lifespans), while treating censored time as event time truncates true lifespan downwards.

Q2In a Cox proportional hazards model, what does an estimated hazard ratio exp(beta_j) = 0.65 for a drug treatment indicate?

Why: A hazard ratio of 0.65 represents a multiplicative scaling of the baseline hazard h(t|x) = h_0(t) * 0.65, meaning event hazard is reduced by 1 - 0.65 = 35% relative to the reference group.
