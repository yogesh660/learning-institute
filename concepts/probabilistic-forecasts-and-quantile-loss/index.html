Probabilistic Forecasts and Quantile Loss: Pinball Loss and Prediction Intervals

Predicting asymmetric quantiles (p10, p50, p90) and full predictive distributions using the pinball loss function and conformalised calibration.

01 The idea

A single point forecast (such as predicting "tomorrow's sales will be 150 units") provides zero information about real-world uncertainty, downside risk, or extreme tail exposure. In supply chain inventory, under-predicting demand causes costly stockouts, whereas over-predicting causes inventory holding waste. Probabilistic forecasting models the full probability distribution or specific target percentiles using asymmetric quantile loss (pinball loss).

Standard Mean Squared Error (MSE) loss forces models to predict the conditional mean $\mathbb{E}[y|x]$, which is symmetric and heavily sensitive to outliers. Mean Absolute Error (MAE) predicts the conditional median (p50).

The pinball loss (or tilted absolute value function) $\mathcal{L}_\tau(y, \hat{y})$ penalises under-prediction by weight $\tau$ and over-prediction by weight $(1 - \tau)$, where $\tau \in (0, 1)$ is the target quantile.

Training a regression model (e.g. Quantile LightGBM, Quantile Regression Forests, or a neural network) with pinball loss directly predicts the $\tau$-th conditional quantile $Q_y(\tau | x)$ without assuming Gaussianity or homoscedasticity.

By training three models at $\tau = 0.1, 0.5, 0.9$, an engineer produces a median forecast along with an 80% prediction interval $[Q_{0.1}, Q_{0.9}]$ that dynamically widens during volatile periods and narrows during calm periods.

In everyday terms

Imagine packing a parachute or ordering hospital oxygen tanks. Knowing the "average" air consumption or "average" deployment speed is dangerous; you need to plan for the 99th percentile worst-case scenario. If running out of stock costs ten times more than having excess stock, you should deliberately forecast a high quantile (p90) rather than the symmetric median (p50).

02 Step by step

  1. Define operational cost asymmetry: Calculate relative costs of under-prediction $c_u$ vs over-prediction $c_o$ to select target operational quantile $\tau^* = \frac{c_u}{c_u + c_o}$ (Newsvendor formula).
  2. Select model architecture: Choose a native quantile model such as gradient boosting with `objective="quantile"` or deep neural networks with multiple quantile output heads.
  3. Train across multiple quantile levels: Fit separate models or multi-head objectives for $\tau \in \{0.05, 0.10, 0.50, 0.90, 0.95\}$.
  4. Check for quantile crossing: Post-process predictions to enforce monotonicity ($Q_{\tau_1} \le Q_{\tau_2}$ for $\tau_1 < \tau_2$) using sorting or isotonic rearrangement.
  5. Evaluate calibration and sharpness: Measure empirical coverage (proportion of actuals falling below $Q_\tau$) and interval width (sharpness).

03 The maths

  1. Pinball Loss (Quantile Loss) Function

    \mathcal{L}_\tau(y, \hat{y}) = \max\left( \tau (y - \hat{y}), \; (1 - \tau)(\hat{y} - y) \right) = (y - \hat{y}) \left( \tau - \mathbb{I}(y < \hat{y}) \right)

    Under-predicting ($y > \hat{y}$) incurs penalty $\tau |y - \hat{y}|$, while over-predicting ($y < \hat{y}$) incurs penalty $(1 - \tau) |y - \hat{y}|$.

  2. Conditional Quantile Optimality

    Q_y(\tau | x) = \operatorname*{arg\,min}_{q(x)} \mathbb{E}_{Y|X}\left[ \mathcal{L}_\tau(Y, q(X)) \right]

    Minimising expected pinball loss uniquely yields the true conditional $\tau$-th quantile function of the underlying distribution.

  3. Winkler Score for Prediction Interval Evaluation

    \mathrm{WS}_{\alpha}(l, u, y) = (u - l) + \frac{2}{\alpha} (l - y) \mathbb{I}(y < l) + \frac{2}{\alpha} (y - u) \mathbb{I}(y > u)

    Evaluates $(1 - \alpha)$ prediction intervals $[l, u]$, balancing narrow interval width (sharpness) against severe penalties for coverage violations.

04 Key takeaways

  • Probabilistic forecasting quantifies prediction uncertainty rather than providing a single blind point estimate.
  • Pinball loss asymmetrically penalises under- vs over-predictions to directly target arbitrary percentiles.
  • Heteroscedasticity (varying uncertainty across different regimes) is captured naturally by quantile regression.
  • Prediction intervals should be evaluated for both empirical coverage (calibration) and narrow interval width (sharpness).

05 In code

python
import numpy as np
from sklearn.ensemble import GradientBoostingRegressor

# Generate heteroscedastic synthetic data (noise variance expands with x)
np.random.seed(42)
X = np.sort(np.random.uniform(0, 10, size=500)).reshape(-1, 1)
noise = np.random.normal(0, 0.3 + 0.2 * X.flatten(), size=500)
y = 2.0 * np.sin(X.flatten()) + noise

# Fit 10th, 50th (median), and 90th percentiles using Quantile Gradient Boosting
quantiles = [0.1, 0.5, 0.9]
models = {}
for q in quantiles:
    gbr = GradientBoostingRegressor(loss='quantile', alpha=q, n_estimators=100, max_depth=3)
    gbr.fit(X, y)
    models[q] = gbr

# Predict on new test points
X_test = np.array([[2.0], [5.0], [8.0]])
preds = {q: models[q].predict(X_test) for q in quantiles}

for i, x_val in enumerate(X_test.flatten()):
    p10, p50, p90 = preds[0.1][i], preds[0.5][i], preds[0.9][i]
    print(f"X={x_val:.1f} -> P10: {p10:.2f} | P50 (median): {p50:.2f} | P90: {p90:.2f} | 80% Width: {p90 - p10:.2f}")
# Notice prediction interval width expands substantially as X increases!

Common pitfalls

  • Quantile crossing: Training independent models for p10 and p90 can occasionally result in $\hat{Q}_{0.1}(x) > \hat{Q}_{0.9}(x)$ in sparse regions; apply monotonic sorting.
  • Assuming constant Gaussian error bars: Applying $\pm 1.96 \sigma$ uniformly across all time periods fails when variance is non-constant or skewed.
  • Evaluating quantile models with RMSE: Evaluating a model trained on pinball loss using RMSE evaluates the wrong statistical functional (mean instead of quantile).

06 Check yourself

Q1What quantile does the standard Mean Absolute Error (MAE) loss function implicitly estimate?

Why: MAE is the symmetric pinball loss where $\tau = 0.5$. Minimising expected MAE yields the conditional median.

Q2If under-estimating demand costs £90 in lost customer goodwill while over-estimating costs £10 in storage, which quantile should a retailer forecast according to the Newsvendor problem?

Why: Formula $\tau^* = c_u / (c_u + c_o) = 90 / (90 + 10) = 0.90$. The critical fractile dictates targeting the 90th percentile to minimise total expected costs.

Q3What is "quantile crossing" in independent quantile regression models?

Why: Because independent models are trained separately without joint constraints, prediction curves can intersect in unseen feature regions, violating distribution monotonicity.
