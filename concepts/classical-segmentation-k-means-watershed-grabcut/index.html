01 The idea

Before deep convolutional networks dominated computer vision, image segmentation relied on rigorous mathematical algorithms rooted in graph theory, topographical fluid dynamics, and statistical clustering. Techniques like K-Means colour space clustering, the Watershed transform, and GrabCut provide fast, interpretable, training-free methods for isolating foreground objects, separating touching cells in microscopy, and extracting interactive foreground cutouts.

Image segmentation partitions an image into semantically coherent pixel regions. In classical vision, segmentation operates on low-level cues: pixel colour, intensity gradients, and spatial coordinates.

K-Means segmentation clusters pixels in colour space (such as CIE L*a*b* or RGB) into $K$ discrete colour modes. While fast, raw K-means ignores spatial connectivity, producing noisy, fragmented pixel masks.

The Watershed algorithm treats a greyscale gradient image as a 3D topographic relief map: light pixels are high ridges (boundaries), and dark pixels are low basins. Flooding basins from predefined markers partitions the image into catchment basins. However, raw gradient maps contain thousands of local noise minima, causing severe over-segmentation; marker-controlled watershed solves this by initializing floods strictly from user-defined seeds.

GrabCut (Rother et al.) formulates segmentation as an energy minimisation problem on a graph. Pixels are represented as graph nodes connected to source (Foreground) and sink (Background) terminals. Using Gaussian Mixture Models (GMMs) to model colour distributions and the Max-Flow / Min-Cut theorem, GrabCut iteratively cuts the minimum-cost graph edges, producing clean boundaries with minimal user bounding-box hints.

In everyday terms

Imagine an aerial photograph of mountainous terrain during a rising flood. The Watershed algorithm treats gradient magnitudes as topographical peaks and basins: as water rises simultaneously from every local valley, dams are erected wherever rising ponds touch, perfectly outlining mountain ridges. GrabCut is like stretching an elastic rubber membrane around an object: it finds the minimum-energy boundary that wraps tightly around the subject while cutting through the fewest connecting tissue fibers.

02 Step by step

  1. Select segmentation approach: Choose K-means for colour reduction, marker-controlled watershed for separating touching objects, or GrabCut for interactive object extraction.
  2. Preprocess and filter: Apply bilateral filtering or median blur to suppress high-frequency sensor noise without blurring object edges.
  3. Compute morphological gradients: For watershed, compute Sobel or morphological gradient $\nabla I$ to identify boundary ridges.
  4. Generate seed markers: Apply distance transforms and thresholding to isolate confident object cores and background markers.
  5. Apply graph cut (GrabCut): Initialize foreground/background Gaussian Mixture Models from a user bounding box; iteratively alternate between assigning pixels to GMM components and computing min-cut graph partitioning.
  6. Post-process boundaries: Apply morphological closing and contour smoothing to produce final clean segmentation masks.

03 The maths

  1. GrabCut Energy Minimisation Formulation

    E(\underline{\alpha}, \mathbf{k}, \underline{\theta}, \mathbf{z}) = U(\underline{\alpha}, \mathbf{k}, \underline{\theta}, \mathbf{z}) + V(\underline{\alpha}, \mathbf{z})

    Decomposes segmentation energy into regional data fidelity $U$ (likelihood under GMM colour models) and boundary smoothness $V$ (contrast-dependent penalty for assigning adjacent pixels to different classes).

  2. Boundary Smoothness Edge Penalty

    V(\underline{\alpha}, \mathbf{z}) = \gamma \sum_{(m, n) \in \mathcal{C}} [\alpha_m \ne \alpha_n] \exp\left( -\beta \|z_m - z_n\|^2 \right)

    Penalises boundary cuts between adjacent pixels $(m, n)$, with penalties dropping when crossing sharp colour differences.

  3. Max-Flow / Min-Cut Optimality (Ford-Fulkerson)

    \min_{\mathcal{S}, \mathcal{T}} \operatorname{Capacity}(\mathcal{S}, \mathcal{T}) = \max \operatorname{Flow}(s \to t)

    The globally optimal boundary cut minimising energy $E$ is computed in polynomial time via the maximum network flow algorithm.

04 Key takeaways

  • Classical segmentation partitions images without requiring training labels or deep neural networks.
  • K-Means clusters pixel colours but lacks spatial boundary coherence.
  • Marker-controlled watershed treats gradients as topography, using seed markers to prevent over-segmentation.
  • GrabCut uses Gaussian Mixture Models and graph min-cuts to iteratively segment foreground objects from bounding boxes.

05 In code

python
import numpy as np

def simple_kmeans_color_quantisation(image_rgb: np.ndarray, k: int = 3, max_iter: int = 10) -> np.ndarray:
    """Segment image by clustering pixel colours in RGB space via K-Means."""
    h, w, c = image_rgb.shape
    pixels = image_rgb.reshape(-1, c).astype(np.float32)
    
    # Initialize centroids randomly from pixels
    np.random.seed(42)
    idx = np.random.choice(len(pixels), k, replace=False)
    centroids = pixels[idx]
    
    for _ in range(max_iter):
        # 1. Assign each pixel to nearest centroid
        # [N, K] distance matrix
        dists = np.linalg.norm(pixels[:, None, :] - centroids[None, :, :], axis=-1)
        labels = np.argmin(dists, axis=1)
        
        # 2. Update centroids
        new_centroids = np.array([pixels[labels == i].mean(axis=0) if (labels == i).any() 
                                 else centroids[i] for i in range(k)])
        if np.allclose(centroids, new_centroids, atol=1e-2):
            break
        centroids = new_centroids
        
    quantised = centroids[labels].reshape(h, w, c).astype(np.uint8)
    return quantised, labels.reshape(h, w)

# Test on 8x8 synthetic image with 2 colour regions
img = np.zeros((8, 8, 3), dtype=np.uint8)
img[:4, :] = [200, 30, 30]   # Red foreground
img[4:, :] = [30, 180, 50]   # Green background

segmented_img, mask = simple_kmeans_color_quantisation(img, k=2)
print("Segmented mask unique labels:", np.unique(mask))
print("K-Means cleanly separated the two colour regions without neural networks!")

Common pitfalls

  • Over-segmentation in raw watershed: Applying watershed directly to noisy image gradients without marker seeds produces a fractured mosaic of thousands of tiny useless regions.
  • Colour overlap in GrabCut: If the foreground object shares identical colours with the background (e.g. a green frog on a green leaf), GrabCut cannot separate them using colour GMMs alone.
  • Ignoring spatial coordinates in K-Means: Clustering only $(R, G, B)$ values merges spatially distant pixels that happen to have similar colours; concatenate spatial coordinates $(R, G, B, x, y)$ for spatial compactness.

06 Check yourself

Q1Why does the raw, unseeded Watershed algorithm suffer from severe over-segmentation on natural images?

Why: Every local minimum in the gradient image acts as a seed for a catchment basin. Noise creates hundreds of false minima, fragmenting the image.

Q2How does the GrabCut algorithm achieve fast, globally optimal foreground/background boundary cuts?

Why: GrabCut represents pixel affinities and GMM likelihoods as edge capacities in a flow network. The min-cut separating source from sink is solved via maximum network flow.

Q3What is the primary limitation of pure K-Means colour segmentation?

Why: K-Means clusters pixels purely by $(R, G, B)$ values without spatial awareness: two pixels with the same colour in opposite corners of the image are grouped together.
