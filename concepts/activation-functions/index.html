01 The idea

Without non-linear activation functions, stacking 100 neural network layers collapses mathematically into a single matrix multiplication, incapable of learning anything beyond linear regression. Non-linear activations enable networks to approximate complex continuous functions, but each choice introduces distinct trade-offs between gradient saturation, computational efficiency, and zero-centred outputs. From early saturating sigmoids to ReLU, GELU, and Swish, modern activations are engineered to maintain healthy gradient propagation throughout deep transformer and convolutional backbones.

Imagine building a multi-layer neural network where each layer simply multiplies the input by a weight matrix: h = x W_1 and y = h W_2. Substituting the first equation into the second yields y = x (W_1 W_2) = x W_combined. No matter how many layers you stack, ten billion linear layers are mathematically identical to a single linear layer! The network cannot learn XOR, detect image contours, or model language syntax. Inserting a non-linear activation function between layers shatters this linearity, allowing the network to fold and curve the decision boundary in high-dimensional space.

Early neural networks relied on the sigmoid function, which maps inputs into the range (0, 1). However, when input values become moderately large or small (e.g. |z| > 3), the sigmoid curve becomes almost completely flat. Its derivative tops out at 0.25 and drops to near zero in the wings. When backpropagating through 10 sigmoid layers, multiplying derivatives below 0.25 shrinks the gradient exponentially (0.25^10 is less than 0.000001), causing gradient updates in early layers to vanish entirely.

The Rectified Linear Unit (ReLU) transformed deep learning by providing a constant derivative of 1.0 for all positive inputs, eliminating saturation and accelerating convergence. However, for negative inputs, ReLU outputs zero with a derivative of zero, causing inactive neurons to permanently die when pushed negative. Modern architectures (such as GPT, BERT, and modern vision backbones) employ smooth, non-monotonic activations like GELU (Gaussian Error Linear Unit) and Swish/SiLU, which retain small non-zero curvatures for negative inputs, ensuring continuous gradient flow.

In everyday terms

A sculptor carving marble: linear transformations can only slide, tilt, or stretch a stone slab in straight lines; non-linear activation functions provide the chisels to carve intricate curves, hollows, and detailed lifelike contours.

02 Step by step

  1. Select output layer activation based on task: use Sigmoid for binary classification, Softmax for multi-class classification, and linear identity for regression.
  2. Choose default hidden activation: deploy ReLU as an initial baseline for standard feedforward and convolutional networks.
  3. Address dead neuron issues with LeakyReLU: if a high proportion of ReLU units output zero, introduce a small negative slope alpha = 0.01.
  4. Adopt GELU or Swish/SiLU for state-of-the-art architectures: use GELU for Transformers and language models, and Swish/SiLU for advanced vision networks.
  5. Verify activation statistics during training: monitor mean and variance of hidden layer activations to verify that distributions do not collapse or explode.

03 The maths

  1. Rectified Linear Unit (ReLU) and LeakyReLU

    \text{ReLU}(z) = \max(0, z), \qquad \text{LeakyReLU}(z) = \begin{cases} z & \text{if } z \ge 0 \\ \alpha z & \text{if } z < 0 \end{cases}

    Where $\alpha \ll 1$ (typically $\alpha = 0.01$). ReLU maintains a constant unit derivative $\partial / \partial z = 1$ for positive inputs, completely avoiding positive-side saturation, while LeakyReLU permits a small non-zero gradient $\alpha$ across the negative half-plane.

  2. Gaussian Error Linear Unit (GELU)

    \text{GELU}(z) = z \cdot \Phi(z) = z \cdot P(X \le z) \approx 0.5 z \left( 1 + \tanh\left( \sqrt{\frac{2}{\pi}} \left( z + 0.044715 z^3 \right) \right) \right)

    Where $\Phi(z)$ is the standard Gaussian cumulative distribution function. GELU probabilistically gates the input $z$ by how likely it is to exceed a random draw from $\mathcal{N}(0, 1)$, producing smooth non-monotonic curvature with non-zero gradients everywhere.

  3. Swish / Sigmoid Linear Unit (SiLU)

    \text{Swish}_\beta(z) = z \cdot \sigma(\beta z) = \frac{z}{1 + e^{-\beta z}}, \qquad \frac{d}{dz} \text{Swish}_1(z) = \sigma(z) + z \sigma(z)(1 - \sigma(z))

    Swish smoothly interpolates between linear behaviour at $\beta \to 0$ and ReLU at $\beta \to \infty$. Its non-monotonic dip near $z \approx -1.28$ allows small negative signals to propagate gradients backward.

04 Key takeaways

  • Non-linear activations prevent deep networks from collapsing mathematically into a single linear matrix multiplication.
  • Saturating functions (Sigmoid, Tanh) cause vanishing gradients in deep networks because their derivatives approach zero away from the origin.
  • GELU and Swish/SiLU provide smooth, non-monotonic gradient flow, serving as the standard activations for modern transformers and vision backbones.

05 In code

python
import numpy as np

def sigmoid(z): return 1.0 / (1.0 + np.exp(-np.clip(z, -30, 30)))
def d_sigmoid(z): s = sigmoid(z); return s * (1.0 - s)
def relu(z): return np.maximum(0, z)
def d_relu(z): return (z > 0).astype(float)
def gelu(z): return 0.5 * z * (1.0 + np.tanh(np.sqrt(2.0 / np.pi) * (z + 0.044715 * z**3)))
def d_gelu(z, eps=1e-5): return (gelu(z + eps) - gelu(z - eps)) / (2 * eps)

test_pts = np.array([-3.0, 0.0, 3.0])
print(f"Evaluation points: {test_pts}")
print(f"Sigmoid derivatives: {np.round(d_sigmoid(test_pts), 4)} (vanishes at +/-3.0)")
print(f"ReLU derivatives:    {np.round(d_relu(test_pts), 4)} (constant 1.0 for z>0, dead at z<0)")
print(f"GELU derivatives:    {np.round(d_gelu(test_pts), 4)} (smooth, non-zero negative dip)")

Common pitfalls

  • Using Sigmoid or Tanh in hidden layers of deep neural networks (>5 layers), which severely dampens gradient propagation.
  • The Dying ReLU trap: setting learning rates too high can push weights into regions where neurons output negative values for all dataset samples, permanently killing their gradient.
  • Applying Softmax across the wrong tensor dimension: in multi-head attention or sequence classification, applying Softmax across the batch dimension instead of the class or key dimension breaks learning.

06 Check yourself

Q1What occurs mathematically if all activation functions in a 50-layer deep neural network are replaced with linear identity functions f(z) = z?

Why: Because the composition of linear transformations is always another linear transformation, any number of stacked linear layers collapses mathematically into a single matrix multiplication.

Q2Why does the standard Sigmoid activation function cause vanishing gradients when used across many hidden layers in deep networks?

Why: The derivative of sigmoid is at most 0.25. Multiplying values below 0.25 across multiple layers causes gradients in early layers to vanish exponentially toward zero.

Q3What is a key advantage of GELU and Swish over standard ReLU in deep transformer architectures?

Why: Unlike ReLU's abrupt zero cut-off, GELU and Swish have smooth, non-monotonic curves that allow small negative signals to maintain gentle gradient flow, preventing permanently dead neurons.
