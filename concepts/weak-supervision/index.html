01 The idea

Hand-labelling training datasets is the primary bottleneck in production AI. Weak supervision replaces manual labelling with heuristic labeling functions (LFs), using an unsupervised generative label model to resolve conflicts.

In modern machine learning, hand-labelling millions of training examples is often impossible: data changes dynamically, privacy laws forbid human annotators from viewing sensitive medical records or financial transactions, and expert wages are exorbitant.

Weak Supervision (pioneered by Alexander Ratner, Christopher Ré, and the Stanford Snorkel team in 2017) fundamentally re-engineers data creation: instead of manually hand-labelling individual samples, domain experts write programmatic Labeling Functions (LFs).

A Labeling Function is a short Python script encoding a noisy heuristic: a regular expression pattern, a keyword dictionary lookup, a heuristic threshold on metadata, a legacy third-party model, or distant supervision from an external database. Each LF inspects an unlabelled sample and either outputs a candidate label (e.g. $+1$ or $-1$) or abstains ($0$).

Because human heuristics are imperfect, LFs frequently overlap, conflict, and correlate. Weak supervision resolves these conflicts through a two-stage architecture: first, an unsupervised Generative Label Model observes how LFs agree and disagree across millions of unlabelled samples, estimating the unknown accuracy and correlation of each LF without needing ground-truth labels. The Label Model outputs calibrated probabilistic training labels $P(Y \mid \Lambda)$. Second, an arbitrary end-to-end deep neural network is trained on these probabilistic labels, generalising far beyond the heuristic rules.

In everyday terms

Imagine a murder trial with five flawed witnesses. Witness 1 has poor eyesight; Witness 2 dislikes the defendant; Witness 3 only saw what happened from a distance; Witness 4 heard a loud noise; Witness 5 heard a rumor. A wise judge does not take a simple show of hands. By cross-examining the witnesses and observing which details they consistently agree on across 100 questions, the judge deduces the reliability of each witness without having been at the crime scene, synthesising their testimonies into the truth.

03 The maths

  1. Label Matrix Definition

    \Lambda \in \{-1, 0, +1\}^{n \times m}, \quad \Lambda_{ij} = \lambda_j(x_i)

    Matrix of weak labels from m labeling functions applied to n unlabelled samples. Zero denotes that the labeling function abstained on that sample.

  2. Generative Label Model Factorisation

    P_\theta(\Lambda, Y) = \frac{1}{Z_\theta} \exp\left( \sum_{j=1}^m \theta_j Y \Lambda_j + \sum_{j < k} \theta_{jk} \Lambda_j \Lambda_k \right)

    Ising/Markov Random Field model over latent true label Y and observed weak votes Lambda_j, parameterised by LF accuracies theta_j and pairwise correlations theta_{jk}.

  3. Unsupervised Covariance Matching (Matrix Completion)

    \operatorname{Cov}(\Lambda_j, \Lambda_k) = \mathbb{E}[\Lambda_j \Lambda_k] - \mathbb{E}[\Lambda_j] \mathbb{E}[\Lambda_k] = \mu_j \mu_k \quad (\text{for conditionally independent LFs})

    Because observable covariance between LFs factorises into the product of their latent accuracies mu_j = Cov(Lambda_j, Y), accuracy can be solved without true labels via rank-1 matrix completion.

04 Key takeaways

  • Replaces expensive manual hand-labelling with programmatic Labeling Functions (LFs) encoding heuristics.
  • Unsupervised Generative Label Model learns the accuracy and correlation of each LF without ground-truth labels.
  • Label model aggregates noisy, conflicting, overlapping votes into calibrated probabilistic labels $P(Y \mid \Lambda)$.
  • Downstream discriminative model (neural network or boosted trees) generalises beyond heuristic rules via feature representations.
  • Foundational paradigm of data-centric AI (e.g. Snorkel), enabling rapid iteration and privacy-preserving training on sensitive data.

05 In code

python
import numpy as np
from sklearn.linear_model import LogisticRegression

# Programmatic Weak Supervision (Snorkel-style Label Model) from scratch
np.random.seed(42)
n_samples = 500

# Synthetic spam classification problem
# Ground truth: 1 = Spam, 0 = Ham
# Features: [contains_link, has_dollar_sign, all_caps_title, sender_reputation]
X = np.random.uniform(0, 1, (n_samples, 4))
y_true = ((X[:, 0] * 1.5 + X[:, 1] * 2.0 + X[:, 2] * 1.0 - X[:, 3] * 2.5) > 0.5).astype(int)

# 1. Define 3 noisy Labeling Functions (LFs)
# Votes: 1 (Spam), 0 (Ham), -1 (Abstain)
def lf_dollar(x):
    # If high dollar sign presence, vote Spam; else abstain
    return 1 if x[1] > 0.6 else -1

def lf_link(x):
    # If link present and low sender rep, vote Spam
    if x[0] > 0.7 and x[3] < 0.4: return 1
    if x[0] < 0.2 and x[3] > 0.7: return 0
    return -1

def lf_caps(x):
    # If all caps title, vote Spam
    return 1 if x[2] > 0.8 else -1

# 2. Build Label Matrix Lambda (n x m)
lfs = [lf_dollar, lf_link, lf_caps]
m_lfs = len(lfs)
Lambda = np.zeros((n_samples, m_lfs), dtype=int)

for i in range(n_samples):
    for j in range(m_lfs):
        Lambda[i, j] = lfs[j](X[i])

# 3. Simple Generative Majority / Accuracy-Weighted Label Model
# Calculate empirical agreement rates between LFs to weight reliability
weights = np.zeros(m_lfs)
for j in range(m_lfs):
    # Empirical accuracy estimate using inter-LF agreement
    active_mask = Lambda[:, j] != -1
    agreements = []
    for k in range(m_lfs):
        if j != k:
            overlap = active_mask & (Lambda[:, k] != -1)
            if np.sum(overlap) > 0:
                agreements.append(np.mean(Lambda[overlap, j] == Lambda[overlap, k]))
    weights[j] = np.mean(agreements) if agreements else 0.5

# Compute soft probabilistic labels P(Y=1 | Lambda)
soft_labels = np.zeros(n_samples)
for i in range(n_samples):
    votes = Lambda[i]
    active = votes != -1
    if np.any(active):
        # Weighted log-odds combination
        log_odds = np.sum(weights[active] * (votes[active] * 2 - 1))
        soft_labels[i] = 1.0 / (1.0 + np.exp(-log_odds))
    else:
        soft_labels[i] = 0.50  # Default prior

# 4. Train downstream discriminative model on soft pseudo-labels
downstream_model = LogisticRegression()
# Convert soft labels to binary training targets (p > 0.5)
y_weak = (soft_labels > 0.5).astype(int)
downstream_model.fit(X, y_weak)

preds_downstream = downstream_model.predict(X)
acc = np.mean(preds_downstream == y_true)

lf_coverages = [np.mean(Lambda[:, j] != -1) * 100 for j in range(m_lfs)]

print(f"Total unlabelled samples processed: {n_samples}")
print(f"LF 1 (Dollar) Coverage: {lf_coverages[0]:.1f}%")
print(f"LF 2 (Link)   Coverage: {lf_coverages[1]:.1f}%")
print(f"LF 3 (Caps)   Coverage: {lf_coverages[2]:.1f}%")
print(f"Overall Label Matrix Coverage: {np.mean(np.any(Lambda != -1, axis=1))*100:.1f}%")
print(f"Downstream Model Accuracy (trained on zero human labels!): {acc * 100:.1f}%")

Common pitfalls

  • Correlated labeling functions: If multiple LFs share common dependencies (e.g. three keyword variations of the same rule), naive independent label models double-count their evidence; correlation graphs are required.
  • Low coverage / high abstention: If LFs abstain on 90% of samples, the downstream model receives zero training signal on the majority of data.
  • Heuristic concept drift: As language or data distributions shift over time, hard-coded rules can degrade into high-error noise, requiring continuous LF monitoring.

06 Check yourself

Q1How does a Weak Supervision label model estimate the accuracy of labeling functions without access to ground truth labels?

Why: Observable covariance between pairs of LFs equals the product of their unknown accuracies under conditional independence. Rank-1 matrix completion solves for accuracies without true labels.

Q2Why is a downstream deep neural network trained on weak labels rather than deploying the heuristic labeling functions directly as the production classifier?

Why: LFs only fire on specific keywords or patterns and abstain on everything else. A downstream neural network learns feature representations that generalise to samples the rules never anticipated.
