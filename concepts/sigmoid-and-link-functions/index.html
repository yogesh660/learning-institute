The Sigmoid and Other Link Functions

Functions that map an unbounded linear score to a valid prediction: sigmoid, softmax, probit, log, and the activations of neural nets.

01 The idea

A linear model produces a score $z$ anywhere on the real line. A link function connects that score to the kind of quantity you are predicting: a probability (sigmoid, probit), a count (exponential) or a set of class probabilities (softmax).

In generalised linear models (GLMs), $g(\mathbb E[y]) = w^\top x$: the link $g$ is chosen so the linear predictor lives on an unbounded scale. Logistic regression uses the logit link (inverse: sigmoid). Poisson regression uses the log link (inverse: exponential) so counts stay positive.

The sigmoid saturates: for large $|z|$ its slope $\sigma(z)(1 - \sigma(z))$ is nearly zero. That is fine at a model’s output with the right loss, but stacked in hidden layers it starves gradients, which is why neural nets moved to ReLU. Softmax generalises the sigmoid to many classes.

In everyday terms

An adapter plug: the linear model always speaks "real numbers"; the link converts that into the socket the target needs.

02 Step by step

  1. Decide the target type: binary, multi-class, count, positive real.
  2. Pick the canonical link: logit, softmax, log, identity.
  3. Train with the matching loss (log-loss, cross-entropy, Poisson deviance, squared error).

03 Try it

Plot of the link (or activation) you choose, with its derivative. Slide the input and the temperature.

04 The maths

  1. Sigmoid and its derivative

    $$\sigma(z) = \frac{1}{1 + e^{-z}}, \qquad \sigma'(z) = \sigma(z)\big(1 - \sigma(z)\big) \le \tfrac14$$

    The maximum slope is 0.25, at $z = 0$.

  2. Softmax

    $$\operatorname{softmax}(z)_c = \frac{e^{z_c}}{\sum_{c'}e^{z_{c'}}}$$

    With two classes, softmax reduces to the sigmoid of the difference of the scores.

  3. Probit

    $$p = \Phi(z) = \int_{-\infty}^z\frac{1}{\sqrt{2\pi}}e^{-t^2/2}\,dt$$

    Uses the normal CDF instead; very similar to the sigmoid with $z$ scaled by about 1.7.

05 Key takeaways

  • Pair each link with its matching loss for convex, well-behaved training.
  • Sigmoid in hidden layers causes vanishing gradients; ReLU fixed that.
  • Temperature (dividing $z$ by $T$) sharpens or softens a sigmoid or softmax.

06 In code

python
import numpy as np
z = np.linspace(-6, 6, 7)
sigmoid = 1 / (1 + np.exp(-z))
tanh = np.tanh(z)
logits = np.array([2.0, 1.0, 0.1])
softmax = np.exp(logits - logits.max()); softmax /= softmax.sum()      # subtract max for stability
print(sigmoid.round(3), tanh.round(3), softmax.round(3))

Common pitfalls

  • Computing softmax without subtracting the max: overflow.
  • Using sigmoid activations in deep hidden layers.

07 Check yourself

Q1What is the maximum slope of the sigmoid?

Why: $\sigma(0)(1 - \sigma(0)) = 0.5 \times 0.5$.

Q2Which link keeps predicted counts positive in Poisson regression?

Why: $\mathbb E[y] = e^{w^\top x} > 0$ for any score.

Q3What is the fundamental purpose of a "link function" in Generalised Linear Models (GLMs)?

Why: In GLMs, the linear combination $w^\top x$ can evaluate to any real number in $(-\infty, \infty)$. The link function $g(\mu) = w^\top x$ transforms the parameter $\mu = \mathbb{E}[y \mid x]$ so that predictions respect the natural bounds of the response distribution.

Q4Why did deep neural networks largely replace sigmoid activation functions in hidden layers with Rectified Linear Units (ReLU)?

Why: Because $\sigma'(z) \le 0.25$, multiplying through $L$ hidden layers scales gradients by at most $(0.25)^L$. By layer 10, gradients shrink by a factor of $10^{-6}$ (vanishing gradient). ReLU's derivative is 1 for positive inputs, eliminating saturation.

Q5When computing the softmax function $\operatorname{softmax}(z)_c = \frac{e^{z_c}}{\sum_{j} e^{z_j}}$ on a vector like $z = [1000, 1001, 1002]$, what computational problem occurs, and how is it resolved?

Why: In IEEE 754 float64, $e^{710} = \infty$. Computing $\exp(1000)$ gives infinity, causing invalid arithmetic. Because shifting logits by $\max(z)$ leaves the softmax ratio unchanged, subtracting $\max(z)$ guarantees that the maximum exponent is $e^0 = 1$, preventing overflow.

Q6How does temperature scaling $T > 0$ affect the softmax probability distribution $\operatorname{softmax}(z / T)$?

Why: Dividing by large $T$ compresses logits toward zero ($z/T \approx 0$), making all exponentials $e^0 = 1$ and yielding uniform probabilities ($1/K$). Dividing by small $T \to 0$ magnifies logit differences, so the largest logit dominates completely.

Q7How does the Probit link function $p = \Phi(w^\top x)$ differ from the Logit link function $p = \sigma(w^\top x)$ in binary classification?

Why: Probit models binary outcomes via a latent Gaussian variable: $y^* = w^\top x + \varepsilon$ with $\varepsilon \sim \mathcal{N}(0, 1)$, whereas logit corresponds to $\varepsilon$ following a standard logistic distribution. They produce near-identical decision boundaries up to a scale factor of $\approx 1.7$.

Q8For a multi-class problem with $K = 2$ classes and logit outputs $z = [z_1, z_2]$, what does the softmax probability $\operatorname{softmax}(z)_1$ simplify to?

Why: $\operatorname{softmax}(z)_1 = \frac{e^{z_1}}{e^{z_1} + e^{z_2}} = \frac{e^{z_1}/e^{z_2}}{e^{z_1}/e^{z_2} + 1} = \frac{e^{z_1 - z_2}}{1 + e^{z_1 - z_2}} = \sigma(z_1 - z_2)$. Binary logistic regression is precisely the two-class case of softmax regression.

Q9Why does Generalised Linear Model theory advise pairing each distribution family with its "canonical link" function (such as Bernoulli with logit, Poisson with log, Gaussian with identity)?

Why: The canonical link equates the linear predictor $w^\top x$ to the natural parameter of the exponential family distribution. This ensures that the log-likelihood is strictly concave in $w$, making gradient-based fitting reliably fast and globally optimal.

Q10For a neuron with standard logistic sigmoid activation $\sigma(z) = \frac{1}{1 + e^{-z}}$, suppose the current output is $\sigma(z) = 0.80$. What is the exact value of the derivative $\sigma'(z)$?

Why: The derivative of the sigmoid is $\sigma'(z) = \sigma(z)(1 - \sigma(z))$. With $\sigma(z) = 0.80$, $\sigma'(z) = 0.80 \times (1 - 0.80) = 0.80 \times 0.20 = 0.16$.

Q11A 3-class model outputs raw logits $z = [1.0, 2.0, 3.0]$. Using the numerically stable softmax formulation with $m = \max(z) = 3.0$, the shifted logits are $z - 3.0 = [-2.0, -1.0, 0.0]$. Given $e^{-2} \approx 0.1353$, $e^{-1} \approx 0.3679$, and $e^0 = 1.0$, what is the softmax probability of Class 3?

Why: The sum of exponentiated shifted logits is $S = e^{-2} + e^{-1} + e^0 \approx 0.1353 + 0.3679 + 1.0000 = 1.5032$. The probability for Class 3 is $\frac{e^0}{S} = \frac{1.0000}{1.5032} \approx 0.6652 = 66.5\%$.

Q12In Poisson regression, the expected count is modelled as $\mu = \mathbb{E}[y \mid x] = e^{w_0 + w_1 x_1}$. If intercept $w_0 = 1.0$ and $w_1 = 0.6931$ (where $e^{0.6931} \approx 2.0$), what is the expected count $\mu$ when $x_1 = 2$? (Given $e \approx 2.718$).

Why: Linear predictor $\eta = w_0 + w_1 x_1 = 1.0 + 0.6931(2) = 1.0 + 2\ln(2) = 1.0 + \ln(4)$. Expected count $\mu = e^{1.0 + \ln(4)} = e^{1.0} \times e^{\ln(4)} = e \times 4 = 4e \approx 4 \times 2.71828 = 10.873$.
