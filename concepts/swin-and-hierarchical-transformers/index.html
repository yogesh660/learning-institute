Hierarchical Vision Transformers: Shifted Windows (Swin Transformer) and Linear Scaling

Restoring multi-scale hierarchical feature maps and linear computational complexity to vision transformers using shifted local window attention.

01 The idea

The original Vision Transformer (ViT) treated images as flat sequences of non-overlapping patches, computing global self-attention across all tokens. While effective for image classification, global self-attention scales quadratically with image resolution $O((H \times W)^2)$, making high-resolution dense prediction tasks like object detection and semantic segmentation computationally prohibitive. The Swin Transformer (Liu et al., 2021) reintroduced hierarchical feature pyramids and linear complexity via Shifted Windows.

Standard ViT has two major limitations as a general vision backbone: 1) Quadratic complexity with image size: processing an 800x800 image requires $\approx 2,500$ patches, leading to massive memory usage; 2) Single-scale representations: ViT maintains constant token resolution throughout all layers, lacking the multi-scale feature pyramids that traditional detectors (FPN) use to detect objects at varying scales.

Swin Transformer builds a hierarchical feature representation: starting from small $4 \times 4$ patches, it merges neighbouring patches in deeper layers (e.g. $2\times$ spatial reduction with channel doubling), mirroring the hierarchical pyramid structure of ResNet.

To achieve linear computational complexity $O(M^2 \cdot N)$, Swin computes self-attention strictly within localized non-overlapping windows of fixed size $M \times M$ (typically $7 \times 7$ patches).

To allow cross-window communication without global attention, consecutive Swin layers alternate between standard Window-based Self-Attention (W-MSA) and Shifted Window-based Self-Attention (SW-MSA). In SW-MSA, the window partitioning is shifted by $(\lfloor M/2 \rfloor, \lfloor M/2 \rfloor)$ pixels. A cyclic shift with an attention mask ensures cross-window information sharing with zero extra computation or padding.

In everyday terms

Imagine a team of security guards monitoring a giant wall of 1,000 video screens. In a standard ViT, every guard attempts to watch and cross-reference all 1,000 screens simultaneously, quickly succumbing to cognitive exhaustion. In a Swin Transformer, each guard monitors a local $7 \times 7$ grid of screens. In the next shift, the guards step three screens to the right and down (shifted windows), enabling information to bridge across adjacent monitoring zones while keeping each guard's workload strictly local and constant.

02 Step by step

  1. Patch partition: Divide $H \times W$ image into $4 \times 4$ raw pixel patches, projecting each 48-D patch vector to embedding dimension $C$.
  2. Standard Window Self-Attention (W-MSA): Partition feature map into non-overlapping $M \times M$ windows (e.g. $7 \times 7$); compute multi-head self-attention independently within each window in linear $O(N)$ time.
  3. Shifted Window Self-Attention (SW-MSA): In the subsequent layer, shift window boundaries by $(\lfloor M/2 \rfloor, \lfloor M/2 \rfloor)$ patches to enable cross-window connections.
  4. Cyclic shifting and masked attention: Efficiently compute SW-MSA by cyclically wrapping corner patches and applying a directional attention mask to prevent false cross-boundary attention.
  5. Patch merging (Downsampling): In deeper stages, concatenate $2 \times 2$ neighbouring patches, apply linear projection to double channel dimension ($2C$), and halve spatial resolution ($H/2 \times W/2$).
  6. Downstream task integration: Feed the resulting 4-stage multi-scale feature pyramid into dense prediction heads (U-Net for segmentation, Mask R-CNN for detection).

03 The maths

  1. Window Self-Attention Linear Computational Complexity

    \begin{aligned} \Omega(\text{Global Self-Attention}) &= 4 H W C^2 + 2 (H W)^2 C \quad [O(N^2) \text{ Quadratic}] \\ \Omega(\text{Window Self-Attention}) &= 4 H W C^2 + 2 M^2 H W C \quad [O(N) \text{ Linear in } HW] \end{aligned}

    Window attention scales linearly with total pixel count $HW$ when window size $M$ is fixed (e.g. $M=7$), enabling gigapixel processing.

  2. Relative Position Bias Self-Attention

    \operatorname{Attention}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \operatorname{Softmax}\left( \frac{\mathbf{Q} \mathbf{K}^T}{\sqrt{d}} + \mathbf{B} \right) \mathbf{V}, \quad \mathbf{B} \in \mathbb{R}^{M^2 \times M^2}

    Injects continuous 2D relative position bias matrix $\mathbf{B}$ into the attention logits, parameterised across offset range $[-M+1, M-1]$.

  3. Shifted Window Partition Coordinates

    \left( x', y' \right) = \left( \left( x - \left\lfloor \frac{M}{2} \right\rfloor \right) \bmod W, \; \left( y - \left\lfloor \frac{M}{2} \right\rfloor \right) \bmod H \right)

    Cyclically translates feature maps by half a window width, bridging isolated receptive fields across consecutive network blocks.

04 Key takeaways

  • Swin Transformer reintroduces hierarchical multi-scale pyramids to Vision Transformers.
  • Computes self-attention within local $M \times M$ windows, achieving linear $O(HW)$ complexity.
  • Alternating standard and shifted windows (W-MSA and SW-MSA) enables cross-window communication.
  • Serves as a drop-in replacement for CNN backbones in object detection and semantic segmentation.

05 In code

python
import torch
import torch.nn as nn

def window_partition(x: torch.Tensor, window_size: int = 7) -> torch.Tensor:
    """Partition feature map into non-overlapping local spatial windows."""
    batch, h, w, c = x.shape
    # Reshape: [B, H/M, M, W/M, M, C] -> [num_windows*B, M, M, C]
    x = x.view(batch, h // window_size, window_size, w // window_size, window_size, c)
    windows = x.permute(0, 1, 3, 2, 4, 5).contiguous().view(-1, window_size, window_size, c)
    return windows

def window_reverse(windows: torch.Tensor, window_size: int, h: int, w: int) -> torch.Tensor:
    """Reverse local windows back into full global feature map."""
    batch_num_win = windows.shape[0]
    num_win_h, num_win_w = h // window_size, w // window_size
    batch = batch_num_win // (num_win_h * num_win_w)
    c = windows.shape[-1]
    
    x = windows.view(batch, num_win_h, num_win_w, window_size, window_size, c)
    x = x.permute(0, 1, 3, 2, 4, 5).contiguous().view(batch, h, w, c)
    return x

# Simulate 56x56 feature map with window size M=7
x = torch.randn(2, 56, 56, 96)
M = 7
windows = window_partition(x, window_size=M)
reconstructed = window_reverse(windows, window_size=M, h=56, w=56)

print(f"Original Feature Map: {x.shape}")
print(f"Partitioned Windows:  {windows.shape} (64 windows of 7x7 per batch)")
print("Reversible without data loss?", torch.equal(x, reconstructed))

Common pitfalls

  • Image dimensions not divisible by window size: If $H$ or $W$ is not a multiple of $M$, padding is required; failing to slice off the padding distorts output dimensions.
  • Forgetting the attention mask in cyclic shift: In SW-MSA, cyclic wrapping brings physically distant corners together; omitting the directional attention mask allows spurious attention across unrelated image boundaries.
  • Relative position bias indexing errors: Indexing the $(2M-1) \times (2M-1)$ relative position bias table incorrectly maps wrong spatial offsets to attention heads.

06 Check yourself

Q1Why was the original Vision Transformer (ViT) poorly suited as a general backbone for dense prediction tasks like object detection and high-resolution segmentation?

Why: Dense tasks require high resolutions and multi-scale pyramids (FPN). Standard ViT's $O(N^2)$ attention is too slow, and its single scale cannot detect objects of varying sizes.

Q2How does the Swin Transformer achieve linear computational complexity $O(HW)$ with respect to image resolution?

Why: Because window size $M$ is fixed (e.g. $7 \times 7$), the attention cost per window is constant, and the total cost scales linearly with the number of windows.

Q3What is the purpose of shifting the window partitioning (SW-MSA) in alternating layers of the Swin Transformer?

Why: W-MSA keeps windows isolated. Shifting the window grid by half a window in the next layer groups neighbouring boundary tokens together, facilitating global information exchange.
