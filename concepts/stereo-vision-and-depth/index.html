Inferring 3D scene depth from calibrated binocular camera pairs using epipolar line rectification, disparity cost volumes, and geometric triangulation.

01 The idea

Human depth perception relies heavily on binocular disparity: our two eyes view the world from slightly different vantage points, causing nearby objects to shift dramatically relative to the background. In computer vision, stereo depth estimation formalises this biological phenomenon using epipolar geometry: matching corresponding points across left and right camera feeds to triangulate metric 3D point clouds without active laser sensors.

Consider two cameras separated by horizontal baseline distance $B$. A 3D point $\mathbf{P}$ projects onto image coordinates $x_L$ and $x_R$ in the left and right cameras. The horizontal shift $d = x_L - x_R$ is called Disparity.

From similar triangles, metric depth $Z$ is inversely proportional to disparity: $Z = \frac{f \cdot B}{d}$, where $f$ is the focal length. As an object moves infinitely far away, disparity drops to zero; as an object gets close, disparity expands.

Finding matching points across two arbitrary images is an expensive 2D search. Epipolar Geometry simplifies this: for any point in the left image, its corresponding match in the right image must lie along a single 1D line called the Epipolar Line.

Stereo Rectification applies homographies to both images, warping them so epipolar lines become perfectly horizontal and collinear with pixel rows. This reduces 2D feature matching to an ultra-fast 1D horizontal search along the exact same row ($y_L = y_R$).

Modern stereo algorithms (Semi-Global Matching - SGM, and deep stereo networks like PSMNet / RAFT-Stereo) construct 3D cost volumes comparing pixel similarities across candidate disparities, regularising with smoothness priors to yield dense depth maps.

In everyday terms

Hold your thumb out at arm's length and alternate closing your left and right eyes: your thumb jumps dramatically back and forth against the distant wall. Now look at a distant tree and repeat: the tree barely shifts at all. The size of that horizontal jump is disparity: inversely proportional to distance. By measuring that pixel shift with millimeter precision, a stereo algorithm calculates exact 3D distance.

02 Step by step

  1. Calibrate stereo rig: Perform joint geometric calibration to compute baseline distance vector $\mathbf{t}$ and relative rotation matrix $\mathbf{R}$ between cameras.
  2. Stereo rectification: Compute rectification homographies to align camera optical axes parallel, making epipolar lines collinear with horizontal scanlines.
  3. Compute matching cost volume: For each pixel $(x, y)$, compute matching cost across candidate disparity range $d \in [0, d_{\max}]$ (using Census transform, SAD, or deep feature correlation).
  4. Cost aggregation: Smooth matching costs across multiple 1D path directions (Semi-Global Matching; SGM) to enforce spatial disparity smoothness.
  5. Disparity selection & refinement: Select minimum cost disparity $d^* = \operatorname*{arg\,min}_d C(x, y, d)$ and refine to sub-pixel accuracy via quadratic interpolation.
  6. Triangulate 3D point cloud: Reproject disparity map into calibrated 3D metric coordinates $(X, Y, Z)$ using camera baseline $B$ and focal length $f$.

03 The maths

  1. Fundamental Stereo Depth Triangulation Equation

    Z = \frac{f \cdot B}{d} = \frac{f \cdot B}{x_L - x_R}

    Metric depth $Z$ is strictly inversely proportional to horizontal disparity $d = x_L - x_R$, where $B$ is baseline and $f$ is focal length.

  2. Epipolar Constraint and Essential Matrix

    \mathbf{x}_R^T \mathbf{E} \mathbf{x}_L = 0, \quad \mathbf{E} = [\mathbf{t}]_\times \mathbf{R} = \mathbf{K}_R^T \mathbf{F} \mathbf{K}_L

    Enforces that corresponding rays must intersect in 3D space, constraining matches in the right image to the epipolar line $\mathbf{l}_R = \mathbf{F} \mathbf{x}_L$.

  3. SGM Energy Minimisation Objective

    E(D) = \sum_p C(p, D_p) + \sum_{(p, q) \in \mathcal{N}} P_1 \mathbb{I}(|D_p - D_q| = 1) + \sum_{(p, q) \in \mathcal{N}} P_2 \mathbb{I}(|D_p - D_q| > 1)

    Semi-Global Matching balances matching cost $C$ against penalties for small step disparity changes ($P_1$) and large discontinuous jumps ($P_2$).

04 Key takeaways

  • Stereo vision triangulates metric 3D depth from binocular horizontal disparity.
  • Depth is inversely proportional to disparity: $Z = (f \cdot B) / d$.
  • Epipolar geometry and rectification reduce 2D feature matching to 1D horizontal line searches.
  • Semi-Global Matching (SGM) optimises disparity maps with directional path smoothness constraints.

05 In code

python
import numpy as np

def compute_depth_from_disparity(disparity_map: np.ndarray, focal_length_px: float, baseline_m: float) -> np.ndarray:
    """Convert stereo disparity map into metric depth in meters."""
    # Prevent division by zero for zero or negative disparities
    valid_mask = disparity_map > 0.1
    depth_m = np.zeros_like(disparity_map, dtype=np.float32)
    depth_m[valid_mask] = (focal_length_px * baseline_m) / disparity_map[valid_mask]
    return depth_m

# Camera parameters: Focal length 1000px, Baseline 0.2 meters (20 cm)
f = 1000.0
B = 0.20

# Synthetic disparity observations (in pixels)
# Object A: disparity = 40.0 px (near)
# Object B: disparity = 10.0 px (medium)
# Object C: disparity = 2.0 px  (far)
disparities = np.array([40.0, 10.0, 2.0], dtype=np.float32)
depths = compute_depth_from_disparity(disparities, focal_length_px=f, baseline_m=B)

for d, z in zip(disparities, depths):
    print(f"Disparity: {d:4.1f} px ---> Calculated 3D Depth: {z:5.2f} meters")
# Notice depth scales inversely: 40px -> 5.0m, 10px -> 20.0m, 2px -> 100.0m

Common pitfalls

  • Textureless regions: In plain, textureless surfaces (white walls, calm water), correspondence matching fails because all candidate disparities produce identical matching costs.
  • Repetitive patterns: Barcodes, fences, or window blinds produce multiple identical correlation peaks, causing catastrophic disparity ambiguity.
  • Stereo occlusion: Points visible in the left camera that are occluded from the right camera's viewpoint have no true match; detect occlusions via Left-Right Consistency checks.

06 Check yourself

Q1Why does stereo image rectification represent a crucial preprocessing step before stereo matching?

Why: Without rectification, finding a matching pixel requires searching across an arbitrary tilted 2D epipolar line. Rectification ensures matches lie on the same horizontal row ($y_L = y_R$).

Q2What is the mathematical relationship between disparity $d$ and metric depth $Z$ in a rectified stereo system?

Why: By similar triangles, $Z = (f \cdot B) / d$. As an object approaches the camera, disparity expands; as it moves away, disparity approaches zero.

Q3What is the purpose of a "Left-Right Consistency Check" in stereo depth estimation?

Why: If a pixel is visible to the left camera but blocked from the right, the right-to-left match will pick an unrelated pixel. Consistency checks flag and invalidate these occlusions.
