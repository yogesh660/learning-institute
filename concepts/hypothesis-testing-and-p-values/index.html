01 The idea

Hypothesis testing formalises empirical decision-making by evaluating whether observed data can be credibly explained by pure random chance. The p-value quantifies how extreme the observed evidence is under an assumed null hypothesis, providing an objective benchmark for rejecting baseline models.

Suppose an online store tests a checkout redesign intended to improve purchase completion above the historic 10% rate. In a test run of 500 shoppers using the new design, 65 complete their orders (13.0%). Is this 3 percentage point uplift genuine evidence that the new checkout converts better, or could it easily be a streak of good luck from 500 random customer decisions?

Hypothesis testing tackles this by adopting a sceptical devil's advocate stance known as the null hypothesis ($H_0$): assume the redesign made no difference and the true conversion probability remains exactly 10%, giving an expected count of 50 purchasers. We then construct the sampling distribution of outcomes that pure chance would generate under $H_0$ and ask: how likely is it to see 65 or more purchasers purely by random sampling noise?

Using the standard normal approximation with standard error $\sqrt{0.10 \times 0.90 / 500} \approx 0.0134$, an observed 13% rate sits $2.236$ standard errors above expectation. Under the null hypothesis, obtaining an outcome at least this extreme in either direction occurs with a probability of approximately 0.0253 (a p-value of 2.53%). Because this p-value falls below our pre-established significance threshold of 5% ($\alpha = 0.05$), we reject the null hypothesis and conclude that the conversion increase is statistically significant.

In everyday terms

A hypothesis test operates like a criminal trial: the defendant is presumed innocent (null hypothesis) until the prosecution presents evidence so improbable under innocence that guilt is established beyond reasonable doubt (the significance threshold $\alpha$).

02 Step by step

  1. State the null hypothesis $H_0$ (baseline equality or absence of effect) and the alternative hypothesis $H_1$ (presence of an effect or difference).
  2. Choose a significance threshold $\alpha$ (conventionally 0.05 or 0.01) before inspecting or collecting the experimental data.
  3. Select an appropriate test statistic $T$ whose exact or asymptotic sampling distribution is known when $H_0$ is true.
  4. Compute the observed test statistic $t_{\text{obs}}$ from the collected sample data.
  5. Calculate the p-value: the probability under the null distribution of obtaining a test statistic at least as extreme as $t_{\text{obs}}$.
  6. Make a formal decision: if $p \le \alpha$, reject $H_0$ in favour of $H_1$; if $p > \alpha$, fail to reject $H_0$.

03 The maths

  1. Null and Alternative Hypotheses

    $$H_0: \theta = \theta_0 \quad \text{versus} \quad H_1: \theta \ne \theta_0 \quad (\text{or } H_1: \theta > \theta_0)$$

    Here $\theta$ denotes the true population parameter and $\theta_0$ is the baseline null value. A two-sided alternative ($H_1: \theta \ne \theta_0$) tests for departures in either direction, whereas a one-sided alternative ($H_1: \theta > \theta_0$ or $\theta < \theta_0$) concentrates statistical power entirely on one pre-specified direction. One-sided tests must be justified on rigorous theoretical grounds prior to seeing the data.

  2. The p-Value Definition

    $$p = P(T(\mathbf{X}) \ge t_{\text{obs}} \mid H_0) \quad \text{or} \quad p = 2 \cdot \min\left(P(T \ge t_{\text{obs}} \mid H_0), \, P(T \le t_{\text{obs}} \mid H_0)\right)$$

    The p-value is the conditional probability of obtaining a test statistic $T(\mathbf{X})$ at least as contradictory to $H_0$ as the observed value $t_{\text{obs}}$, calculated assuming $H_0$ is true. For symmetric distributions, a two-sided p-value doubles the one-sided tail probability. Crucially, the p-value is $P(\text{data} \mid H_0)$, not the posterior probability $P(H_0 \mid \text{data})$ of the hypothesis being true.

  3. Uniformity under the Null

    $$p \sim \text{Uniform}(0, 1) \quad \text{when } H_0 \text{ holds}$$

    When the null hypothesis is true and the test statistic is continuous with cumulative distribution function $F_0$, the probability integral transform ensures that the p-value is uniformly distributed across the interval $[0, 1]$. Consequently, the probability of falsely rejecting a true null hypothesis at threshold $\alpha$ is identically $P(p \le \alpha \mid H_0) = \alpha$.

04 Key takeaways

  • The p-value measures compatibility between observed data and the null model; it is never the probability that the null hypothesis is true.
  • Statistical significance is not practical significance: massive datasets make negligible, irrelevant differences yield $p < 0.001$.
  • The decision threshold $\alpha$ must be fixed strictly in advance of data collection to prevent post-hoc rationalisation.
  • Failing to reject the null hypothesis does not prove the null is true; absence of evidence is not evidence of absence.

05 In code

python
import numpy as np
import scipy.stats as stats

# Test whether new checkout conversion exceeds historic 10%
n = 500
p0 = 0.10
observed_conversions = 65
p_hat = observed_conversions / n

# Standard error under the null hypothesis H0
se_null = np.sqrt(p0 * (1.0 - p0) / n)
z_stat = (p_hat - p0) / se_null

# Two-sided p-value from standard normal distribution
p_value = 2.0 * (1.0 - stats.norm.cdf(abs(z_stat)))
alpha = 0.05

print(f"Observed rate: {p_hat:.1%} (n={n})")
print(f"z-statistic: {z_stat:.3f}")
print(f"p-value: {p_value:.4f}")
print(f"Decision at alpha={alpha}: {'Reject H0' if p_value <= alpha else 'Fail to reject H0'}")

Common pitfalls

  • The prosecutor's fallacy: treating $p = 0.02$ as a 2% probability that the null hypothesis is correct. Inverting conditional probabilities requires Bayes' theorem and prior odds.
  • Data dredging and p-hacking: testing dozens of subgroup combinations or stopping data collection early as soon as $p < 0.05$ emerges.
  • Treating $\alpha = 0.05$ as an ontological cliff: interpreting $p = 0.049$ as scientific truth and $p = 0.051$ as complete absence of an effect.
  • Reporting p-values without confidence intervals or effect sizes, hiding whether an effect is commercially or scientifically meaningful.

06 Check yourself

Q1What does a p-value of 0.03 strictly mean in an experimental hypothesis test?

Why: The p-value is the conditional probability $P(\text{data as or more extreme} \mid H_0)$. It says nothing about $P(H_0 \mid \text{data})$ without specifying prior probabilities via Bayes' theorem.

Q2Why does collecting an enormous sample size (e.g. $n = 1,000,000$) create a challenge for interpreting p-values?

Why: Standard error shrinks as $1/\sqrt{n}$. With millions of observations, trivial deviations with zero practical importance easily generate massive test statistics and tiny p-values.

Q3If an analyst carries out a hypothesis test at $\alpha = 0.05$ and finds $p = 0.22$, which conclusion is formally valid?

Why: Failing to reject $H_0$ means the observed data is reasonably consistent with chance; it never proves the null hypothesis holds true.

Q4Under the null hypothesis for a continuous test statistic, what probability distribution does the p-value follow?

Why: By the probability integral transform, any continuous random variable transformed by its own cumulative distribution function follows $\text{Uniform}(0, 1)$. Hence $P(p \le \alpha \mid H_0) = \alpha$.

Q5In statistical hypothesis testing, what role does the null hypothesis ($H_0$) serve?

Why: The null hypothesis acts as the baseline sceptical model (presumption of innocence or absence of effect) that the collected sample data must demonstrate sufficient evidence to reject.

Q6Why must the significance threshold $\alpha$ (e.g. $\alpha = 0.05$) be specified before collecting or analysing experimental data?

Why: Setting $\alpha$ prior to data collection guarantees methodological objectivity and controls the false positive rate. Choosing or adjusting $\alpha$ after inspecting the data introduces confirmation bias and p-hacking.

Q7Suppose an analyst computes a test statistic whose sampling distribution under $H_0$ is symmetric around 0. The one-sided p-value for testing $H_1: \mu > \mu_0$ is found to be $0.02$. If the analyst had instead pre-specified a two-sided test ($H_1: \mu \ne \mu_0$), what would the two-sided p-value be?

Why: For a symmetric null distribution, a two-sided test considers departures in both tails. The two-sided p-value is double the one-sided tail probability: $2 \times 0.02 = 0.04$.

Q8An engineer runs the following code in Python to test whether a model's latency change is significant: z_stat = -2.10 p_value = 2.0 * (1.0 - stats.norm.cdf(abs(z_stat))) Why does the calculation use abs(z_stat) and multiply by 2.0?

Why: abs(z_stat) projects the statistic into the positive tail, 1.0 - stats.norm.cdf(...) evaluates the upper tail probability, and multiplying by 2 accounts for both tails in a two-sided test.

Q9A clinical trial evaluates two competing drugs against a placebo: Drug A yields $p = 0.048$ while Drug B yields $p = 0.052$. What is the main error in concluding that "Drug A is effective, whereas Drug B has no effect"?

Why: As Andrew Gelman highlighted, the difference between "significant" and "not significant" is not necessarily statistically significant. A minute difference ($p = 0.048$ vs $0.052$) reflects routine sampling variance, not an ontological qualitative difference in drug efficacy.

Q10A website tests whether a new banner increases click rates above the historical rate of $p_0 = 0.20$. In a sample of $n = 400$ visitors, 100 click the banner ($\hat{p} = 0.25$). What is the standard error under the null hypothesis, and what is the resulting $z$-test statistic?

Why: Under $H_0$, the standard error is $\operatorname{SE}_0 = \sqrt{p_0(1 - p_0) / n} = \sqrt{0.20 \times 0.80 / 400} = \sqrt{0.16 / 400} = \sqrt{0.0004} = 0.02$. The test statistic is $z = (\hat{p} - p_0) / \operatorname{SE}_0 = (0.25 - 0.20) / 0.02 = 0.05 / 0.02 = 2.50$.

Q11A researcher tests 100 hypotheses where only 10 represent genuine effects (prior probability $P(H_1) = 0.10$). The test has significance level $\alpha = 0.05$ and statistical power of $80\%$ ($1 - \beta = 0.80$). If a randomly selected test yields $p < 0.05$, what is the posterior probability that this significant finding is actually a true effect (the positive predictive value)?

Why: Out of 100 hypotheses, 10 are real ($H_1$) and 90 are null ($H_0$). The test detects $10 \times 0.80 = 8.0$ true positives and falsely rejects $90 \times 0.05 = 4.5$ false positives. Total positive calls = $8.0 + 4.5 = 12.5$. The posterior probability that a positive finding is genuine is $8.0 / 12.5 = 64\%$, demonstrating why $p < 0.05$ does not imply a 95% chance that the hypothesis is true.

Q12An analyst tests 20 completely independent features that are pure Gaussian noise with zero true relationship to an outcome ($H_0$ is true for all 20). If each feature is tested at significance level $\alpha = 0.05$, what is the exact probability that at least one feature produces a falsely significant result ($p \le 0.05$)?

Why: The probability of correctly failing to reject $H_0$ on all 20 independent tests is $(1 - 0.05)^{20} = 0.95^{20} \approx 0.3585$. The family-wise error rate (probability of at least one false positive) is $1 - 0.3585 = 0.6415$ (or roughly $64.2\%$).
