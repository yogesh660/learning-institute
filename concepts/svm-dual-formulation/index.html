01 The idea

While the primal SVM problem searches over feature weights w in high-dimensional space, the dual problem searches over sample weights alpha, revealing that the optimal decision boundary depends exclusively on inner products between support vectors.

The Support Vector Machine (SVM) is founded on the principle of Structural Risk Minimisation: rather than merely separating training data, it searches for the maximum-margin hyperplane that leaves the widest possible buffer zone between classes, guaranteeing the tightest theoretical bound on test generalisation error.

In its Primal formulation, the soft-margin SVM optimises weight vector $w \in \mathbb{R}^d$ and bias $b \in \mathbb{R}$: $\min_{w, b, \xi} \frac{1}{2} \|w\|^2 + C \sum_{i=1}^n \xi_i$ subject to classification margin constraints $y_i (w^T x_i + b) \ge 1 - \xi_i$. However, when we map features non-linearly into infinite-dimensional Hilbert spaces (via Gaussian RBF kernels), weight vector $w$ has infinite dimension, making the primal problem impossible to solve directly.

Convex optimisation duality resolves this brilliantly. By formulating the Lagrangian function with Lagrange multipliers $\alpha_i \ge 0$ and $\mu_i \ge 0$, differentiating with respect to primal variables $(w, b, \xi)$, and setting derivatives to zero, we derive the Wolfe Dual formulation.

The dual problem is an elegant concave quadratic program where the decision variables are the sample multipliers $\alpha_i$, and feature vectors $x_i$ enter strictly via pairwise dot products $x_i^T x_j$. The Karush–Kuhn–Tucker (KKT) complementary slackness conditions prove that $\alpha_i = 0$ for every sample comfortably outside the margin: the optimal decision boundary is defined exclusively by the sparse subset of training points with $\alpha_i > 0$—the Support Vectors! Substituting a Mercer kernel $K(x_i, x_j)$ for the dot product unlocks non-linear boundaries in infinite dimensions.

In everyday terms

Imagine two rival medieval armies facing each other across a battlefield. The primal commander tries to construct a continuous defensive barrier across the entire width of the landscape. The dual general notices that only the front-line soldiers standing along the very edge of contact (the support vectors) determine where the battle line is drawn; all soldiers standing safely 500 metres behind the front line can turn around and go to sleep without shifting the boundary by a single millimetre.

03 The maths

  1. The Wolfe Dual Quadratic Program

    \max_\alpha \sum_{i=1}^n \alpha_i - \frac{1}{2} \sum_{i=1}^n \sum_{j=1}^n \alpha_i \alpha_j y_i y_j K(x_i, x_j) \quad \text{subject to } 0 \le \alpha_i \le C, \; \sum_{i=1}^n \alpha_i y_i = 0

    The dual objective depends solely on pairwise kernel evaluations K(x_i, x_j) and scalar multipliers alpha_i, completely independent of the dimensionality of feature space.

  2. KKT Complementary Slackness Conditions

    \alpha_i \left[ y_i (w^T \phi(x_i) + b) - 1 + \xi_i \right] = 0, \quad \mu_i \xi_i = (C - \alpha_i) \xi_i = 0

    Proves sparsity: alpha_i > 0 occurs strictly when y_i f(x_i) <= 1 (support vectors on or inside the margin). Points with y_i f(x_i) > 1 have alpha_i = 0 and do not affect the boundary.

  3. Primal Weight Recovery via Dual Multipliers

    w = \sum_{i=1}^n \alpha_i y_i \phi(x_i) = \sum_{i \in \mathrm{SV}} \alpha_i y_i \phi(x_i)

    Weight vector w is a linear combination of support vectors alone, proving that SVM predictions are entirely memory-sparse.

04 Key takeaways

  • Convex duality transforms the primal $O(d)$ optimisation over weights into a dual $O(n)$ optimisation over sample multipliers $\alpha_i$.
  • The dual depends solely on pairwise dot products $x_i^T x_j$, enabling the kernel trick $K(x_i, x_j)$ in infinite-dimensional Hilbert spaces.
  • KKT complementary slackness proves sparsity: points with $y_i f(x_i) > 1$ have $\alpha_i = 0$ and exert zero influence on the decision boundary.
  • Only Support Vectors ($\alpha_i > 0$) define the separating hyperplane and margin boundary.
  • Box constraint $0 \le \alpha_i \le C$ controls the penalty: unbounded support vectors ($0 < \alpha_i < C$) lie exactly on the margin boundary.

05 In code

python
import numpy as np
from scipy.optimise import minimise

# Support Vector Machine Dual Solver via Quadratic Programming from scratch
np.random.seed(42)
n_samples = 60

# Generate linearly separable 2D data
X1 = np.random.normal(loc=[-1.5, -1.5], scale=0.7, size=(n_samples // 2, 2))
X2 = np.random.normal(loc=[1.5, 1.5], scale=0.7, size=(n_samples // 2, 2))
X = np.vstack([X1, X2])
y = np.array([-1]*(n_samples // 2) + [1]*(n_samples // 2), dtype=float)

# Linear kernel: K(x_i, x_j) = x_i^T x_j
K = X @ X.T
C = 1.0  # Regularisation penalty

# Dual Objective: min 0.5 * alpha^T (Y K Y) alpha - 1^T alpha
Y = np.outer(y, y)
P = Y * K

def dual_objective(alpha):
    return 0.5 * np.dot(alpha, P @ alpha) - np.sum(alpha)

def dual_grad(alpha):
    return P @ alpha - np.ones_like(alpha)

# Constraints: sum(alpha_i * y_i) = 0 and 0 <= alpha_i <= C
constraints = {'type': 'eq', 'fun': lambda alpha: np.dot(alpha, y), 'jac': lambda alpha: y}
bounds = [(0.0, C) for _ in range(n_samples)]
alpha_init = np.zeros(n_samples)

res = minimise(
    dual_objective,
    x0=alpha_init,
    jac=dual_grad,
    bounds=bounds,
    constraints=constraints,
    method='SLSQP',
    options={'ftol': 1e-9, 'maxiter': 500}
)

alphas = res.x
alphas[alphas < 1e-5] = 0.0  # Numerical threshold for sparsity

# Identify Support Vectors
sv_mask = alphas > 0.0
support_vectors = X[sv_mask]
sv_alphas = alphas[sv_mask]
sv_y = y[sv_mask]

# Reconstruct primal weights: w = sum(alpha_i * y_i * x_i)
w = np.sum((alphas * y)[:, None] * X, axis=0)

# Compute bias b using an unbounded support vector (0 < alpha < C)
unbounded_sv = (alphas > 1e-4) & (alphas < C - 1e-4)
if np.any(unbounded_sv):
    idx = np.where(unbounded_sv)[0][0]
    b = y[idx] - np.dot(w, X[idx])
else:
    b = np.mean(y[sv_mask] - X[sv_mask] @ w)

# Margin width: 2 / ||w||
margin_width = 2.0 / np.linalg.norm(w)

print(f"Total training points: {n_samples}")
print(f"Number of Support Vectors found: {len(support_vectors)} ({len(support_vectors)/n_samples*100:.1f}% sparsity!)")
print(f"Primal weight vector w: [{w[0]:.4f}, {w[1]:.4f}]")
print(f"Primal bias b:          {b:.4f}")
print(f"Geometric margin width: {margin_width:.4f}")

# Check complementary slackness
margins = y * (X @ w + b)
print(f"Min margin for SVs: {np.min(margins[sv_mask]):.4f} (approx 1.0 on margin boundary)")

Common pitfalls

  • Quadratic memory scaling: The Gram kernel matrix $K$ is $n \times n$; standard QP solvers scale as $O(n^3)$ time and $O(n^2)$ memory, requiring Sequential Minimal Optimisation (SMO) for large datasets.
  • Numerical solver precision: Standard off-the-shelf QP solvers can yield small non-zero values ($10^{-7}$) for non-support vectors; thresholding $\alpha_i$ is necessary to recover true sparsity.
  • Bias determination when all SVs are bounded: When all support vectors have $\alpha_i = C$ (high misclassification), bias $b$ cannot be determined from a single point and requires averaging upper/lower bounds.

06 Check yourself

Q1Why does the dual formulation of SVM make the kernel trick possible?

Why: In the dual formulation, feature vectors x appear strictly inside pairwise inner products x_i^T x_j. By Mercer’s theorem, any positive semi-definite kernel K(x_i, x_j) computes this inner product in Hilbert space.

Q2What do the KKT complementary slackness conditions imply about training points that lie safely outside the margin (y_i f(x_i) > 1)?

Why: From alpha_i [y_i f(x_i) - 1 + xi_i] = 0, when a point is safely on the correct side outside the margin (y_i f(x_i) > 1, xi_i = 0), alpha_i must be zero.
