01 The idea

Full gradient descent computes gradients across all p features at every step. Coordinate descent simplifies optimisation by cycling through parameters one by one, solving fast 1D sub-problems in closed form.

When training high-dimensional machine learning models with thousands or millions of parameters, full gradient descent can be computationally unwieldy: each step requires evaluating gradients across all features and carefully selecting a global learning rate. If features vary in curvature, gradient descent oscillates wildly in steep directions while creeping in flat directions.

Coordinate Descent (CD) offers an alternative optimisation strategy: instead of updating all variables simultaneously along a combined gradient vector, update only one coordinate direction at a time while keeping all other $p - 1$ variables rigidly fixed.

At step $j$, the multi-variable problem collapses into a simple one-dimensional scalar optimisation: $\beta_j^* = \arg\min_z f(\beta_1, \dots, \beta_{j-1}, z, \beta_{j+1}, \dots, \beta_p)$. For many common objectives, this 1D sub-problem has an exact closed-form algebraic minimiser, eliminating the need for line searches or learning rate tuning entirely.

Coordinate descent achieves its greatest triumph in $L_1$-regularised problems like Lasso and Elastic Net. The $L_1$ penalty $|\beta_j|$ has a sharp non-differentiable kink at zero that invalidates standard gradient descent. However, along individual coordinate axes, the objective separates cleanly into 1D sub-problems solved analytically via the Soft-Thresholding Operator. This algorithmic breakthrough makes coordinate descent the core computational engine behind glmnet and scikit-learn Lasso.

In everyday terms

Imagine tuning an analog radio receiver with ten dials to eliminate background static. Trying to twist all ten dials simultaneously with both hands is clumsy and throws everything out of alignment. Instead, you hold nine dials completely steady with your fingers, twisting only the first dial back and forth until reception peaks. You freeze the first dial, move to the second dial, and repeat. By cycling through the dials one by one, the signal quickly becomes crystal clear.

03 The maths

  1. Coordinate-Wise Lasso Decomposition

    f(\beta) = \frac{1}{2n} \sum_{i=1}^n \left( y_i - \sum_{k \neq j} x_{ik} \beta_k - x_{ij} \beta_j \right)^2 + \lambda \sum_{k \neq j} |\beta_k| + \lambda |\beta_j|

    Decomposes the objective into terms independent of beta_j plus a simple univariate quadratic and absolute value function in beta_j.

  2. The Soft-Thresholding Operator

    S_\lambda(z) = \operatorname{sign}(z) (|z| - \lambda)_+ = \begin{cases} z - \lambda & \text{if } z > \lambda \\ 0 & \text{if } |z| \le \lambda \\ z + \lambda & \text{if } z < -\lambda \end{cases}

    The exact analytical minimiser of 0.5 (beta_j - z)^2 + lambda |beta_j|. Pulls small coefficients strictly to zero, inducing structural sparsity.

  3. Tseng Separability Convergence Condition

    f(\beta) = g(\beta) + \sum_{j=1}^p h_j(\beta_j)

    Paul Tseng proved that cyclic coordinate descent is guaranteed to converge to a global minimum for composite functions where g is convex and smooth, and the non-smooth part h separates into coordinate-wise terms.

04 Key takeaways

  • Optimises multi-variable objective functions by updating one coordinate at a time, keeping all other variables frozen.
  • Replaces complex multi-variable gradient steps with fast 1D sub-problems that frequently possess exact closed-form algebraic solutions.
  • The foundational solver for Lasso and Elastic Net, using the Soft-Thresholding operator to handle non-differentiable $L_1$ kinks.
  • Guaranteed to converge to the global minimum for convex functions with coordinate-wise separable non-smooth terms (Tseng condition).
  • Requires zero learning rate tuning or line searches when closed-form coordinate updates exist.

05 In code

python
import numpy as np

# Cyclic Coordinate Descent for Lasso from scratch
def coordinate_descent_lasso(X, y, alpha=0.1, max_iters=500, tol=1e-6):
    n, p = X.shape
    beta = np.zeros(p)
    
    # Precalculate column squared norms
    norm_sq = np.sum(X**2, axis=0)
    
    # Initial residual
    r = y - X @ beta
    
    # Soft-thresholding operator
    def soft_thresh(z, thresh):
        return np.sign(z) * np.maximum(0.0, np.abs(z) - thresh)
        
    for it in range(max_iters):
        max_change = 0.0
        
        for j in range(p):
            beta_old = beta[j]
            
            # Partial residual without feature j
            # r_j = r + beta_old * X[:, j]
            # rho_j = X[:, j]^T r_j
            rho_j = np.dot(X[:, j], r) + beta_old * norm_sq[j]
            
            # Analytical update via soft-thresholding
            # Loss: (1 / (2n)) * ||y - X beta||^2 + alpha * ||beta||_1
            # Scaling threshold by n
            thresh = alpha * n
            beta_new = soft_thresh(rho_j, thresh) / norm_sq[j]
            
            # Update residual vector: r <- r - (beta_new - beta_old) * X_j
            delta = beta_new - beta_old
            if delta != 0.0:
                r -= delta * X[:, j]
                beta[j] = beta_new
                max_change = max(max_change, abs(delta))
                
        if max_change < tol:
            break
            
    return beta

# Generate sparse regression problem: 100 samples, 20 features, only 3 active
np.random.seed(42)
n_samples = 150
n_features = 25
X = np.random.normal(0, 1, (n_samples, n_features))
true_beta = np.zeros(n_features)
true_beta[2] = 2.5
true_beta[7] = -1.8
true_beta[15] = 3.0
y = X @ true_beta + np.random.normal(0, 0.5, n_samples)

# Fit Lasso via Coordinate Descent
lambda_reg = 0.15
beta_est = coordinate_descent_lasso(X, y, alpha=lambda_reg)

n_nonzero = np.sum(beta_est != 0)
mse = np.mean((y - X @ beta_est)**2)

print(f"Dataset shape: {X.shape}")
print(f"True non-zero coefficients: indices 2 (2.5), 7 (-1.8), 15 (3.0)")
print(f"Recovered non-zero count:  {n_nonzero} / {n_features}")
print(f"Recovered beta[2]:         {beta_est[2]:.3f}")
print(f"Recovered beta[7]:         {beta_est[7]:.3f}")
print(f"Recovered beta[15]:        {beta_est[15]:.3f}")
print(f"All other 22 features zeroed out: {np.all(beta_est[np.setdiff1d(np.arange(n_features), [2, 7, 15])] == 0)}")

Common pitfalls

  • Non-separable non-smooth penalties: Coordinate descent can get trapped in non-optimal points if non-smooth terms are non-separable (e.g. constraints like $|x_1 - x_2| \le 1$).
  • Correlated features slowing convergence: Highly collinear features create elongated diagonal ravines where coordinate steps make slow zigzagging progress.
  • Memory access inefficiency on column-major data: Cycling across features requires efficient column-wise matrix memory layout; row-major memory causes CPU cache misses.

06 Check yourself

Q1Why is coordinate descent uniquely suited for solving L1-regularised Lasso regression?

Why: While the L1 kink breaks joint gradient descent, along any single coordinate axis the sub-problem has an exact closed-form minimiser given by the soft-thresholding operator.

Q2Under what condition can coordinate descent fail to converge to a stationary point?

Why: If a non-smooth term couples multiple variables (such as non-separable constraints), coordinate descent can get trapped at a corner point where no axis-aligned move reduces loss.
