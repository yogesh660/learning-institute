The Attention Mechanism

Recurrent networks force variable-length sequences through a fixed-size vector bottleneck. Attention lets every position dynamically look up, weight, and aggregate context from all other positions.

01 The idea

The defining constraint of classical sequence models (RNNs and LSTMs) was their sequential information bottleneck: entire sentences had to be compressed into a single hidden vector, causing long-range context to degrade. The attention mechanism—generalised to scaled dot-product self-attention in the Transformer—eliminated this bottleneck by allowing tokens to compute dynamic routing weights over queries, keys, and values.

Imagine searching a library for information about planetary motion. Your search query is the **Query** ($Q$). Every book title on the catalogue shelves is a **Key** ($K$), and the text inside each book is the **Value** ($V$). To find answers, you calculate the semantic similarity between your query and every book title (the dot product $Q K^T$). Titles with high relevance receive large attention weights via a softmax distribution, and your final answer is a weighted blend of the retrieved book contents ($A V$).

In **Self-Attention**, queries, keys, and values all originate from the very same sequence. Each token asks: "Which other tokens in this sentence are relevant to resolving my meaning?" In the sentence "The trophy did not fit into the suitcase because it was too large", the pronoun token "it" computes a strong query-key match with "trophy" (its semantic referent) rather than "suitcase", dynamically pulling contextual features across the sequence regardless of physical separation.

Why is the dot product scaled by $1 / \sqrt{d_k}$? When the key dimension $d_k$ is large (such as 64 or 128), taking the dot product of two independent zero-mean unit-variance vectors produces a result whose variance equals $d_k$. Large dot products push the softmax function into saturated tails where local derivatives collapse to zero. Dividing by $\sqrt{d_k}$ scales the variance back to $1.0$, preserving healthy gradient flow during backpropagation. In **Multi-Head Attention**, this operation runs in parallel across $h$ distinct subspaces, allowing the model to simultaneously attend to syntactic relations, coreference, and local phrases.

In everyday terms

Like a researcher consulting a comprehensive library index: instead of memorising every book before writing an essay, the researcher pulls relevant passages on demand using targeted title lookups.

02 Step by step

  1. Project input embeddings: map input tensor $X \in \mathbb{R}^{T \times d_{\text{model}}}$ into queries $Q = X W_Q$, keys $K = X W_K$, and values $V = X W_V$ using learned linear projections.
  2. Compute pairwise compatibility: calculate the matrix product $S = Q K^T \in \mathbb{R}^{T \times T}$, measuring the unscaled affinity between every query and every key.
  3. Scale by key dimensionality: divide scores by $\sqrt{d_k}$ to prevent variance explosion and preserve softmax gradients in high dimensions.
  4. Apply causal masking if autoregressive: in decoder language models, mask upper-triangular future entries to $-\infty$ so tokens cannot look ahead to future steps during training.
  5. Compute softmax probabilities and context: apply row-wise softmax to produce attention weights $A = \operatorname{softmax}(S / \sqrt{d_k})$, then compute the context matrix $O = A V$.
  6. Merge multi-head projections: concatenate outputs from all $h$ parallel attention heads and project through linear output matrix $W_O$.

03 The maths

  1. Scaled dot-product attention equation

    $$\operatorname{Attention}(Q, K, V) = \operatorname{softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V$$

    $Q \in \mathbb{R}^{T_q \times d_k}$ contains query vectors, $K \in \mathbb{R}^{T_k \times d_k}$ contains key vectors, and $V \in \mathbb{R}^{T_k \times d_v}$ contains values. The softmax normalises across rows of the $T_q \times T_k$ affinity matrix, producing probability distributions that weight the value vectors.

  2. Dot-product variance scaling derivation

    $$\text{If } q_i, k_i \sim \mathcal{N}(0, 1) \text{ i.i.d.}, \quad \operatorname{Var}(q^T k) = \sum_{i=1}^{d_k} \operatorname{Var}(q_i k_i) = d_k \implies \operatorname{Var}\left(\frac{q^T k}{\sqrt{d_k}}\right) = 1$$

    Shows why scaling by $\sqrt{d_k}$ is mathematically necessary. Without division by $\sqrt{d_k}$, large key dimensions inflate dot-product variance to $d_k$, pushing softmax inputs into extreme saturating regimes where gradient magnitudes vanish to zero.

  3. Multi-head attention formulation

    $$\operatorname{MultiHead}(Q, K, V) = \operatorname{Concat}(\text{head}_1, \dots, \text{head}_h) W_O, \quad \text{head}_i = \operatorname{Attention}(Q W_i^Q, K W_i^K, V W_i^V)$$

    $W_i^Q, W_i^K \in \mathbb{R}^{d_{\text{model}} \times d_k}$, $W_i^V \in \mathbb{R}^{d_{\text{model}} \times d_v}$, and $W_O \in \mathbb{R}^{h d_v \times d_{\text{model}}}$. Projecting into $h$ subspaces enables the model to simultaneously attend to information from different representation subspaces at different positions.

04 Key takeaways

  • Attention replaces the sequential recurrence bottleneck of RNNs with an $O(1)$ maximum path length between any two tokens in a sequence.
  • Dividing dot-product scores by $\sqrt{d_k}$ keeps score variance at unit scale, preventing softmax saturation and vanishing gradients.
  • Multi-head attention allows the model to jointly attend to information from diverse representation subspaces (such as grammar, coreference, and syntax) simultaneously.

05 In code

python
import numpy as np

# Scaled dot-product self-attention with causal masking
np.random.seed(42)
T, d_k = 3, 4  # 3 tokens, key dimension 4
Q = np.random.randn(T, d_k)
K = np.random.randn(T, d_k)
V = np.array([[1.0, 0.0], [0.0, 1.0], [1.0, 1.0]])  # (3, 2) values

# 1. Scaled dot-product compatibility scores
scale = np.sqrt(d_k)
scores = (Q @ K.T) / scale

# 2. Apply causal mask: mask upper triangular future steps to -1e9
mask = np.triu(np.ones((T, T)), k=1)
scores = np.where(mask == 1, -1e9, scores)

# 3. Row-wise softmax to calculate attention weights
exp_scores = np.exp(scores - np.max(scores, axis=-1, keepdims=True))
weights = exp_scores / np.sum(exp_scores, axis=-1, keepdims=True)

# 4. Weighted combination of value vectors
context_out = weights @ V

print("Attention weights (row 0: token 0 can only attend to itself):")
print(np.round(weights[0], 4).tolist())
print("Attention weights (row 2: token 2 attends across tokens 0, 1, 2):")
print(np.round(weights[2], 4).tolist())
print("Output context representation for token 0:")
print(np.round(context_out[0], 4).tolist())

Common pitfalls

  • Quadratic memory complexity: computing and storing the $T \times T$ attention matrix scales as $O(T^2)$, creating memory bottlenecks for ultra-long context windows.
  • Omitting the causal mask in generative autoregressive decoders, which leaks future ground-truth tokens during training and ruins next-token generation.
  • Omitting the $\sqrt{d_k}$ scaling denominator, which causes softmax attention distributions to peak prematurely on a single token early in training.

06 Check yourself

Q1Why is the dot product between queries and keys divided by $\sqrt{d_k}$ before applying softmax?

Why: Because the variance of the dot product of two $d_k$-dimensional random vectors is $d_k$, dividing by $\sqrt{d_k}$ scales variance back to 1.0, preventing softmax from saturating where gradients collapse to zero.

Q2In an autoregressive decoder (such as GPT), what is the function of the causal attention mask?

Why: Without causal masking, a generative model could simply look ahead at future tokens during training, trivialising next-token prediction and failing during inference.

Q3How does multi-head attention enhance the representational capacity of a single attention layer?

Why: Multi-head attention projects inputs into $h$ distinct subspaces, enabling parallel heads to track distinct syntactic, positional, or semantic relationships independently.

Q4What is the primary computational bottleneck of standard full self-attention when scaling to very long sequences?

Why: Pairwise interactions between all $T$ queries and $T$ keys require materialising an intermediate $T \times T$ attention weight matrix, making $O(T^2)$ memory and time expensive for long context windows.
