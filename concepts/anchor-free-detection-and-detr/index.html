Modern Object Detection: Anchor-Free Detectors (FCOS) and Detection Transformers (DETR)

Eliminating anchor box hyperparameters and Non-Maximum Suppression using centre-point regression (FCOS) and bipartite matching Transformers (DETR).

01 The idea

For years, object detection was dominated by anchor boxes: practitioners had to manually tune dozens of hyperparameters (anchor scales, aspect ratios, IoU match thresholds), while complex hand-crafted post-processing like Non-Maximum Suppression (NMS) remained mandatory. Anchor-free architectures (FCOS) and Detection Transformers (DETR; Carion et al., 2020) redefined the paradigm, framing object detection as direct point regression or set prediction via bipartite matching.

Anchor-based detectors suffer from fundamental flaws: anchors require heavy heuristic tuning, introduce severe positive-negative sample imbalance, and require non-differentiable NMS post-processing.

FCOS (Fully Convolutional One-Stage Object Detection; Tian et al.) eliminates anchors entirely: it treats every location $(x, y)$ on the feature map inside a ground-truth box as a positive training sample, directly regressing the 4 distances to box edges $(l, t, r, b)$. A novel "Centerness" branch down-weights low-quality bounding boxes far from object centres without anchor boxes.

DETR (DEtection TRansformer; Carion et al.) completely eliminates both anchors and NMS, formulating detection as a direct Set Prediction problem. An image passes through a CNN backbone and a Transformer encoder-decoder. A fixed set of $N$ learned Object Queries interact with image tokens via cross-attention.

During training, DETR uses the Hungarian Algorithm to find a unique, optimal one-to-one Bipartite Matching between the $N$ predictions and ground-truth objects. This one-to-one assignment guarantees that each physical object is predicted by exactly one query, making NMS completely unnecessary.

In everyday terms

Imagine ordering food at a busy restaurant. An anchor-based system is like an over-cautious waiter guessing that you might want 9 possible predefined combinations (small salad, large burger, medium fries) and bringing 9 plates to the table, forcing you to throw away 8 duplicates with a spatula (NMS). DETR is like an intelligent chef who simply receives your table order, glances at the kitchen, and delivers exactly the dishes you requested with zero waste.

02 Step by step

  1. Extract multi-scale features: Pass image through CNN backbone (ResNet) and flatten spatial feature maps into sequence tokens.
  2. Transformer Encoder self-attention: Model global context and pairwise feature dependencies across all spatial locations.
  3. Pass learned Object Queries to Decoder: Provide $N$ fixed learned embedding vectors (e.g. $N=100$) that query image representations via cross-attention.
  4. Predict independent box sets: Feed each of the $N$ output embeddings through shared feed-forward networks (FFNs) to predict category class and normalised box coordinates $(x, y, w, h)$.
  5. Compute optimal Bipartite Matching (Training): Run the Hungarian matching algorithm to find permutation $\sigma \in \mathfrak{S}_N$ minimising matching cost with ground truth.
  6. Direct inference (No NMS): Filter out predictions assigned to the background "no-object" class $\varnothing$; directly emit remaining bounding boxes with zero NMS post-processing.

03 The maths

  1. Optimal Bipartite Matching Cost (Hungarian Algorithm)

    \hat{\sigma} = \operatorname*{arg\,min}_{\sigma \in \mathfrak{S}_N} \sum_{i=1}^N \mathcal{L}_{\mathrm{match}}\left( y_i, \; \hat{y}_{\sigma(i)} \right)

    Finds the permutation $\sigma$ of predictions that minimises the global sum of pairwise classification and bounding box distances.

  2. Pairwise Matching Cost Function

    \mathcal{L}_{\mathrm{match}}(y_i, \hat{y}_\sigma) = -\mathbb{I}(c_i \ne \varnothing) \hat{p}_\sigma(c_i) + \mathbb{I}(c_i \ne \varnothing) \left[ \lambda_{\mathrm{L1}} \| b_i - \hat{b}_\sigma \|_1 + \lambda_{\mathrm{giou}} \mathcal{L}_{\mathrm{GIoU}}(b_i, \hat{b}_\sigma) \right]

    Balances target class probability $\hat{p}(c_i)$ with $L_1$ coordinate error and Generalised IoU (GIoU) loss.

  3. FCOS Centerness Branch Target

    \operatorname{Centerness}^* = \sqrt{\frac{\min(l^*, r^*)}{\max(l^*, r^*)} \times \frac{\min(t^*, b^*)}{\max(t^*, b^*)}}

    Measures how close feature cell $(x, y)$ is to the centre of the bounding box; down-weights peripheral low-quality detections.

04 Key takeaways

  • Anchor-free architectures eliminate complex anchor scale/aspect ratio tuning.
  • FCOS regresses distances to box boundaries directly from positive grid cells.
  • DETR frames object detection as direct Set Prediction using Transformer cross-attention.
  • Hungarian bipartite matching enforces strict one-to-one matching, completely eliminating NMS.

05 In code

python
import torch
import torch.nn as nn
from scipy.optimise import linear_sum_assignment

def toy_bipartite_matching(pred_boxes: torch.Tensor, gt_boxes: torch.Tensor):
    """Educational demonstration of Hungarian bipartite matching used in DETR."""
    # pred_boxes: [N, 4], gt_boxes: [M, 4] where N >= M
    N, M = pred_boxes.size(0), gt_boxes.size(0)
    
    # Compute pairwise L1 cost matrix: [N, M]
    cost_matrix = torch.cdist(pred_boxes, gt_boxes, p=1).detach().numpy()
    
    # Solve optimal one-to-one assignment via Hungarian algorithm
    pred_indices, gt_indices = linear_sum_assignment(cost_matrix)
    
    return pred_indices, gt_indices

# Simulate 5 DETR object queries predicting boxes against 2 ground-truth objects
torch.manual_seed(42)
predictions = torch.tensor([
    [0.10, 0.10, 0.20, 0.20],  # Query 0: Near GT 0
    [0.80, 0.80, 0.15, 0.15],  # Query 1: Far away (background)
    [0.55, 0.50, 0.30, 0.30],  # Query 2: Near GT 1
    [0.12, 0.09, 0.22, 0.21],  # Query 3: Also near GT 0 (competing duplicate)
    [0.90, 0.10, 0.10, 0.10]   # Query 4: Background
])

ground_truth = torch.tensor([
    [0.11, 0.10, 0.21, 0.20],  # GT 0
    [0.50, 0.50, 0.30, 0.30]   # GT 1
])

pred_idx, gt_idx = toy_bipartite_matching(predictions, ground_truth)

print("Hungarian Bipartite Assignment:")
for p, g in zip(pred_idx, gt_idx):
    print(f"Query {p} strictly assigned to Ground Truth {g} (Distance: {torch.dist(predictions[p], ground_truth[g]):.4f})")
print("Duplicate queries receive NO assignment, forcing them to predict background without NMS!")

Common pitfalls

  • Slow training convergence in original DETR: Original DETR required 500 epochs to converge because cross-attention looks everywhere; Deformable DETR solves this by focusing attention locally.
  • Small object detection in DETR: Standard DETR downsamples feature maps by $32\times$, losing fine spatial details of small objects; multi-scale feature pyramids are required.
  • High Hungarian matching cost computation: While fast for small query counts ($N=100$), Hungarian matching scales as $O(N^3)$ on CPU if query counts balloon to thousands.

06 Check yourself

Q1Why does DETR (DEtection TRansformer) not require Non-Maximum Suppression (NMS) post-processing?

Why: Traditional models produce dozens of overlapping duplicate proposals for one object. DETR's bipartite loss penalizes duplicate predictions, forcing only one query to emit the box.

Q2What are "Object Queries" in the DETR architecture?

Why: Object queries are learned vectors that attend to image features via cross-attention, specializing in detecting objects at particular image regions or scales.

Q3What is the role of the "Centerness" branch in the anchor-free FCOS detector?

Why: Locations near object edges produce noisy box predictions. FCOS down-weights these low-quality boxes by multiplying classification scores by predicted centerness.
