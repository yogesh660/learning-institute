01 The idea

While Bayesian networks model directed causal flows, many physical and spatial dependencies (like neighbouring pixels in an image or social ties) are symmetric. Markov Random Fields (MRFs) specify joint distributions as products of maximal clique potentials.

Directed graphical models (Bayesian Networks) are natural for causal processes where time flows forward from cause to effect. However, in spatial and relational systems—such as pixels in a 2D digital image, spatial disease incidence across bordering counties, or spin orientations in a crystal lattice—dependencies are inherently bidirectional and symmetric. Pixel A influences Pixel B just as strongly as Pixel B influences Pixel A.

Markov Random Fields (MRFs), also called Undirected Graphical Models, represent joint probability distributions over undirected graphs $G = (V, E)$. The Markov properties in an MRF state that a variable is conditionally independent of all other nodes in the network given its Markov Blanket (its immediate neighbouring nodes in the graph).

How do we parameterise a joint distribution on an undirected graph? In 1971, John Hammersley and Peter Clifford proved the fundamental theorem of undirected graphical models: any strictly positive probability distribution satisfying the Markov properties factorises as a Gibbs distribution over the maximal cliques of the graph: $P(x) = \frac{1}{Z} \prod_{C \in \mathcal{C}} \psi_C(x_C) = \frac{1}{Z} \exp\left(-\sum_{C} E_C(x_C)\right)$.

Here, $\psi_C(x_C) > 0$ are non-negative potential functions (or clique energy functions $E_C$), and $Z = \sum_x \exp(-E(x))$ is the normalising constant (termed the Partition Function in statistical physics). While the partition function $Z$ is intractable to compute exactly for large grids, algorithms like Iterated Conditional Modes (ICM) or Graph Cuts perform rapid maximum a posteriori (MAP) inference for applications like image denoising and semantic segmentation.

In everyday terms

Imagine a flock of starlings performing a murmur in the evening sky. No single bird is the directed "leader" commanding the others. Instead, each individual starling constantly adjusts its velocity and distance symmetrically relative to its six or seven nearest neighbours. When one bird veers left to avoid a falcon, its neighbours follow, propagating a smooth fluid wave through the entire flock.

03 The maths

  1. Hammersley–Clifford Theorem (Gibbs Distribution)

    P(x) = \frac{1}{Z} \prod_{C \in \mathcal{C}} \psi_C(x_C) = \frac{1}{Z} \exp\left(-\sum_{C \in \mathcal{C}} E_C(x_C)\right), \quad Z = \sum_{x} \exp(-E(x))

    A positive distribution satisfies the local Markov properties of graph G if and only if it factorises over the maximal cliques C of G. Z is the normalising partition function.

  2. Pairwise MRF Energy Formulation (Ising / Potts Model)

    E(x) = \sum_{i \in V} \phi_i(x_i, y_i) + \beta \sum_{(i, j) \in E} \mathbb{I}(x_i \neq x_j)

    Standard energy model for vision: unary term phi_i enforces fidelity to noisy measurement y_i; pairwise Potts penalty beta enforces spatial smoothness among adjacent pixels.

  3. Local Markov Property and Markov Blanket

    P(X_i \mid X_{-i}) = P(X_i \mid X_{\mathcal{N}(i)}) = \frac{\exp(-E_i(x_i) - \sum_{j \in \mathcal{N}(i)} E_{ij}(x_i, x_j))}{\sum_{x'_i} \exp(-E_i(x'_i) - \sum_{j \in \mathcal{N}(i)} E_{ij}(x'_i, x_j))}

    Conditioned on its immediate graph neighbours N(i) (its Markov blanket), node X_i is conditionally independent of all remaining nodes in the graph.

04 Key takeaways

  • Undirected graphical model parameterised by non-negative clique potentials over undirected graph cliques.
  • Ideal for symmetric spatial and relational systems where directed causal arrows do not apply (e.g. image lattices, physical spins).
  • Hammersley–Clifford theorem proves any strictly positive Markov distribution factorises as a Gibbs distribution $P(x) = \frac{1}{Z} \exp(-E(x))$.
  • The normalising partition function $Z = \sum_x \exp(-E(x))$ is computationally intractable in general, summing over exponentially many states.
  • Iterated Conditional Modes (ICM) performs greedy coordinate descent on local node energies, guaranteeing monotonic convergence to a local energy minimum.

05 In code

python
import numpy as np

# Binary Image Denoising using a Markov Random Field (Ising Model) and ICM from scratch
np.random.seed(42)

# 1. Create a synthetic clean 20x20 binary image (+1 and -1)
size = 20
clean_img = -np.ones((size, size), dtype=int)
# Draw a square in the centre
clean_img[5:15, 5:15] = 1

# 2. Corrupt image with 25% random bit-flip noise
noisy_img = clean_img.copy()
flip_mask = np.random.uniform(0, 1, (size, size)) < 0.25
noisy_img[flip_mask] *= -1

# 3. Iterated Conditional Modes (ICM) MAP Inference
# Energy E(x) = -eta * sum_i (x_i * y_i) - beta * sum_{<i, j>} (x_i * x_j)
eta = 2.0   # Data fidelity weight (how much we trust noisy pixel y_i)
beta = 1.5  # Spatial smoothness weight (how much adjacent pixels must agree)

x_state = noisy_img.copy()  # Initial state
max_iters = 10

def compute_total_energy(x, y, eta, beta):
    # Data fidelity term
    data_energy = -eta * np.sum(x * y)
    # Horizontal interactions
    h_energy = -beta * np.sum(x[:, :-1] * x[:, 1:])
    # Vertical interactions
    v_energy = -beta * np.sum(x[:-1, :] * x[1:, :])
    return data_energy + h_energy + v_energy

energy_history = [compute_total_energy(x_state, noisy_img, eta, beta)]

# ICM coordinate descent iterations
for it in range(max_iters):
    changes = 0
    for r in range(size):
        for c in range(size):
            y_val = noisy_img[r, c]
            
            # Sum of 4-connected neighbours
            neighbour_sum = 0
            if r > 0: neighbour_sum += x_state[r - 1, c]
            if r < size - 1: neighbour_sum += x_state[r + 1, c]
            if c > 0: neighbour_sum += x_state[r, c - 1]
            if c < size - 1: neighbour_sum += x_state[r, c + 1]
            
            # Compare local energy for x = +1 vs x = -1
            # E_local(val) = -eta * (val * y_val) - beta * (val * neighbour_sum)
            e_plus = -eta * (1 * y_val) - beta * (1 * neighbour_sum)
            e_minus = -eta * (-1 * y_val) - beta * (-1 * neighbour_sum)
            
            new_val = 1 if e_plus < e_minus else -1
            if new_val != x_state[r, c]:
                x_state[r, c] = new_val
                changes += 1
                
    curr_energy = compute_total_energy(x_state, noisy_img, eta, beta)
    energy_history.append(curr_energy)
    if changes == 0:
        break

# Evaluate error rates
error_noisy = np.mean(clean_img != noisy_img)
error_denoised = np.mean(clean_img != x_state)

print(f"Image dimensions: {size}x{size} (400 binary pixels)")
print(f"Initial Noisy Pixel Error:    {error_noisy * 100:.1f}%")
print(f"MRF Denoised Pixel Error:     {error_denoised * 100:.1f}% (noise eliminated!)")
print(f"Initial Energy: {energy_history[0]:.1f} -> Final Converged Energy: {energy_history[-1]:.1f}")
print("Energy monotonically decreasing:", np.all(np.diff(energy_history) <= 1e-6))

Common pitfalls

  • Intractability of the partition function Z: Computing marginal likelihoods or maximum likelihood parameter gradients requires evaluating $Z$, demanding MCMC or contrastive divergence.
  • ICM local minima trapping: Because ICM is greedy coordinate descent, it can get trapped in sub-optimal local energy minima; Graph Cuts (alpha-expansion) or simulated annealing find global/stronger optima.
  • Over-smoothing boundaries: If the pairwise spatial smoothness weight $\beta$ is set too large, fine edge details and sharp image contours are erased into homogeneous blobs.

06 Check yourself

Q1Why are Markov Random Fields preferred over Bayesian Networks for 2D image pixel grids?

Why: Adjacent pixels mutually influence each other symmetrically. Imposing directed arrows on an image grid creates an artificial ordering and DAG cycles.

Q2What is the primary computational bottleneck when training general Markov Random Fields via Maximum Likelihood?

Why: The partition function Z normalises the distribution. For an N-pixel binary image, Z requires summing over 2^N states, which is computationally intractable for exact likelihood.
