Neural Language Models: From Bengio's N-gram NNLM to Recurrent Language Models

Classical n-gram models struggle with zero-probability counts on unseen test sequences, necessitating complex backoff and smoothing (Kneser-Ney). The Bengio NNLM (2003) maps preceding context words to distributed continuous vectors, concatenating them into a hidden feedforward layer. Distributed representations enable automatic generalisation: learning about "cat walks on a mat" naturally transfers predictive probability to "dog walks on a rug". Computational bottlenecks in computing full vocabulary softmaxes prompted historical innovations like hierarchical softmax and negative sampling.

01 The idea

Classical n-gram language models suffer from severe curse of dimensionality and sparsity, unable to share statistical strength across semantically similar words. Bengio's 2003 Neural Network Language Model (NNLM) introduced distributed word embeddings and continuous hidden layers, revolutionizing statistical language modelling and laying the groundwork for recurrent and transformer architectures.

In classical statistical NLP, an n-gram model predicts the next word by looking up how many times that exact sequence of $n-1$ words appeared in the training library. If the training corpus contains "The cat sat on the rug", but never contains "The dog sat on the carpet", an n-gram model has zero probability for "carpet" following "The dog sat on the". It treats "cat" and "dog", and "rug" and "carpet", as completely unrelated discrete symbols. Bengio's breakthrough was to represent every word as a continuous coordinate in a dense embedding space. In this continuous space, "dog" is near "cat", and "carpet" is near "rug". When the neural network learns parameters that assign high probability to "rug" following "cat", that smooth mathematical function automatically assigns high probability to "carpet" following "dog". This continuous representation conquered the curse of dimensionality.

In everyday terms

Imagine a library catalogue that files every book in completely isolated, unindexed steel lockers. If you find a recipe for chocolate cake in Locker #104, you have no way to find a recipe for vanilla cake except by rummaging through every other locker at random. A neural language model organizes the library along a continuous thematic map where all dessert cookbooks sit on adjacent shelves.

02 Step by step

  1. Extract sliding n-gram windows: construct fixed-length historical context tuples $(w_{t-n+1}, \dots, w_{t-1})$ and target token $w_t$.
  2. Look up distributed embeddings: project discrete token indices into continuous $d$-dimensional embedding vectors.
  3. Concatenate context representations: flatten individual word vectors into a single contiguous context vector.
  4. Compute hidden layer activations: apply linear transformation and non-linear activation (tanh) to model non-linear word interactions.
  5. Project to vocabulary logits: transform hidden representations into $|V|$-dimensional output scores.
  6. Normalise via softmax and optimise: compute cross-entropy loss against the true token and backpropagate gradients into both weights and embeddings.

04 Key takeaways

  • Bengio's NNLM pioneered continuous distributed word embeddings to conquer the combinatorial sparsity of classical n-grams.
  • Projecting discrete words into continuous vector space allows models to generalise seamlessly across synonymous expressions.
  • Softmax vocabulary bottlenecks motivated historical innovations including hierarchical softmax, noise-contrastive estimation, and modern subword tokenisation.

05 In code

python
import numpy as np

def softmax(z):
    """Numerically stable softmax."""
    shift_z = z - np.max(z)
    exp_z = np.exp(shift_z)
    return exp_z / np.sum(exp_z)

class BengioNNLM:
    """Simplified 3-gram Neural Network Language Model."""
    def __init__(self, vocab_size, embedding_dim, hidden_dim):
        np.random.seed(42)
        # Word embedding matrix C
        self.C = np.random.randn(vocab_size, embedding_dim) * 0.1
        # Hidden layer weights (context size = 2 for 3-gram)
        self.H = np.random.randn(hidden_dim, 2 * embedding_dim) * 0.1
        self.d = np.zeros(hidden_dim)
        # Output vocabulary projection
        self.U = np.random.randn(vocab_size, hidden_dim) * 0.1
        self.b = np.zeros(vocab_size)
        
    def forward(self, w1_idx, w2_idx):
        # 1. Lookup and concatenate embeddings
        c1 = self.C[w1_idx]
        c2 = self.C[w2_idx]
        x = np.concatenate([c1, c2])
        
        # 2. Hidden layer with tanh activation
        a = np.tanh(self.d + np.dot(self.H, x))
        
        # 3. Logits and softmax
        logits = self.b + np.dot(self.U, a)
        probs = softmax(logits)
        return probs

# Vocabulary setup
vocab = {"the": 0, "cat": 1, "dog": 2, "sat": 3, "on": 4, "rug": 5, "mat": 6}
inv_vocab = {v: k for k, v in vocab.items()}

model = BengioNNLM(vocab_size=len(vocab), embedding_dim=4, hidden_dim=8)

# Predict next word after context ("the", "cat")
w1, w2 = vocab["the"], vocab["cat"]
probs = model.forward(w1, w2)

print("Predicted Next Word Probabilities for context: ['the', 'cat'] -> ?")
for idx, p in enumerate(probs):
    print(f"  {inv_vocab[idx]:5} -> {p:.4f}")

top_token = inv_vocab[np.argmax(probs)]
print(f"\nMost likely continuation: '{top_token}'")

Common pitfalls

  • Suffering extreme training latency due to full vocabulary softmax computation; when $|V| > 100,000$, standard softmax backpropagation becomes prohibitively slow.
  • Treating context as a fixed window; like n-gram models, early NNLMs cannot access dependencies beyond their predetermined input window size $n-1$.
  • Over-parameterising output projection matrix $\mathbf{U}$, causing models to overfit rapidly on small text corpora.

06 Check yourself

Q1What fundamental limitation of classical n-gram models did Bengio's NNLM solve?

Why: Classical n-grams treat words as discrete, independent symbols. Bengio's continuous word embeddings allow statistical learning from one phrase to generalise smoothly to synonymous phrases.

Q2Where did the primary computational bottleneck lie in Bengio's original 2003 NNLM architecture?

Why: Evaluating the softmax denominator requires computing dot products across all $|V|$ words in the vocabulary for every single token prediction, scaling linearly with dictionary size.

Q3How did Bengio's NNLM handle a context of $n-1$ words in its input layer?

Why: The NNLM looked up the continuous embedding for each context word and concatenated them into a fixed-length vector $\mathbf{x} \in \mathbb{R}^{(n-1)d}$.
