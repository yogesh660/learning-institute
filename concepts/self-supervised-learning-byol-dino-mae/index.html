Modern Self-Supervised Learning: BYOL, DINO Self-Distillation, and Masked Autoencoders (MAE)

Learning visual representations without negative pairs or human labels using bootstrap non-contrastive dynamics (BYOL), vision transformer self-distillation (DINO), and masked patch reconstruction (MAE).

01 The idea

Supervised deep learning depends on millions of costly, biased human annotations. Early contrastive self-supervised methods (SimCLR) eliminated human labels but required massive batch sizes and carefully engineered negative pairs to prevent representation collapse. Modern self-supervised learning (SSL) transcends contrastive pairs: BYOL proves negatives are unnecessary, DINO learns emergent semantic segmentation, and Masked Autoencoders (MAE) reconstruct masked patches directly.

Self-supervised learning aims to extract general-purpose semantic feature representations from unlabelled data that transfer effectively to downstream tasks with minimal fine-tuning.

BYOL (Bootstrap Your Own Latent; Grill et al.) demonstrated that negative pairs are completely optional. It uses an Online network and a Target network. The online network predicts the target network's representation of an augmented view. An asymmetric architecture (an extra predictor MLP on the online branch) combined with an Exponential Moving Average (EMA) momentum target update mathematically prevents representation collapse to constant vectors.

DINO (Self-distillation with no labels; Caron et al.) applies this paradigm to Vision Transformers (ViTs). Using centreing and sharpening operations on the teacher output, DINO avoids collapse while developing striking emergent properties: its self-attention maps naturally segment foreground objects from background clutter without any pixel-level supervision.

Masked Autoencoders (MAE; He et al.) introduce masked visual modelling: masking 75%–80% of image patches and feeding only the 20% visible patches through a deep ViT encoder. A lightweight shallow decoder then reconstructs the missing pixel patches. Because pixel reconstruction forces the model to understand global scene geometry, MAE scales visual pretraining to massive models with extreme compute efficiency.

In everyday terms

Imagine learning to appreciate art. Instead of having a curator hand you flashcards stating "this is a Monet" or comparing two random paintings to explain why they differ, you either study two distorted photographs of the same cathedral and learn what makes the scene invariant (BYOL/DINO), or look at a jigsaw puzzle where 75% of the pieces have been removed and learn to paint in the missing details based on deep structural context (MAE).

02 Step by step

  1. Select SSL paradigm: Choose non-contrastive invariance (BYOL/DINO) for classification/feature extraction or generative reconstruction (MAE) for scalable pretraining.
  2. Generate multi-crop augmentations: In DINO/BYOL, generate two global views (high resolution) and multiple local views (low resolution) per image.
  3. Mask patch tokens (MAE): Split image into $16 \times 16$ non-overlapping patches, randomly mask 75% of patches, and feed strictly the visible 25% tokens into the encoder.
  4. Asymmetric architecture design: In BYOL/DINO, route one view through the online/student network and another through the EMA momentum teacher network.
  5. Apply anti-collapse mechanisms: Apply centreing (subtracting rolling mean) and sharpening (low temperature) to teacher probabilities in DINO; use EMA and online predictor in BYOL.
  6. Update parameters: Backpropagate loss through the online/student network; update target/teacher weights using EMA momentum $\theta_{\mathrm{target}} \leftarrow \tau \theta_{\mathrm{target}} + (1 - \tau) \theta_{\mathrm{online}}$.

03 The maths

  1. BYOL Mean Squared Error Regression Loss

    \mathcal{L}_{\mathrm{byol}} = 2 - 2 \cdot \frac{\langle q_\theta(z_\theta), \; z'_\xi \rangle}{\|q_\theta(z_\theta)\|_2 \; \|z'_\xi\|_2}, \quad z'_\xi = f_\xi(v')

    Minimises the normalised Euclidean distance between the online network prediction $q_\theta(z_\theta)$ and the target network projection $z'_\xi$.

  2. Exponential Moving Average (EMA) Target Dynamics

    \xi_{t+1} = \tau \xi_t + (1 - \tau) \theta_t, \quad \tau \in [0.99, \; 0.999]

    The target parameters $\xi$ smoothly track the online parameters $\theta$ via momentum coefficient $\tau$, preventing collapse by keeping targets slowly evolving.

  3. MAE Masked Pixel Reconstruction Objective

    \mathcal{L}_{\mathrm{mae}} = \frac{1}{|\mathcal{M}|} \sum_{i \in \mathcal{M}} \| p_i - \hat{p}_i \|^2

    Computes Mean Squared Error strictly over masked patch set $\mathcal{M}$, reconstructing normalised raw pixel values.

04 Key takeaways

  • Modern SSL eliminates the need for expensive human labels and complex negative pair mining.
  • BYOL avoids representation collapse using asymmetric online predictors and EMA momentum target encoders.
  • DINO self-distillation on Vision Transformers produces emergent semantic object segmentation in attention maps.
  • MAE masks 75% of visual patches and reconstructs pixels, scaling visual pretraining with high compute efficiency.

05 In code

python
import torch
import torch.nn as nn
import torch.nn.functional as F

class MiniBYOL(nn.Module):
    def __init__(self, backbone: nn.Module, dim: int = 128, momentum: float = 0.99):
        super().__init__()
        # Online network
        self.online_encoder = backbone
        self.online_projector = nn.Linear(dim, dim)
        self.online_predictor = nn.Linear(dim, dim)  # Asymmetric predictor prevents collapse!
        
        # Target network (EMA copy)
        import copy
        self.target_encoder = copy.deepcopy(backbone)
        self.target_projector = copy.deepcopy(self.online_projector)
        self.momentum = momentum
        
        # Freeze target network gradients
        for p in self.target_encoder.parameters():
            p.requires_grad = False
        for p in self.target_projector.parameters():
            p.requires_grad = False

    @torch.no_grad()
    def update_target(self):
        """EMA momentum update of target network parameters."""
        for op, tp in zip(self.online_encoder.parameters(), self.target_encoder.parameters()):
            tp.data = self.momentum * tp.data + (1.0 - self.momentum) * op.data
        for op, tp in zip(self.online_projector.parameters(), self.target_projector.parameters()):
            tp.data = self.momentum * tp.data + (1.0 - self.momentum) * op.data

    def forward(self, v1: torch.Tensor, v2: torch.Tensor):
        # Online forward pass on view 1
        z1 = self.online_projector(self.online_encoder(v1))
        p1 = self.online_predictor(z1)
        
        # Target forward pass on view 2 (no gradients)
        with torch.no_grad():
            z2_target = self.target_projector(self.target_encoder(v2))
            
        # Cosine similarity loss
        p1_norm = F.normalise(p1, dim=-1)
        z2_norm = F.normalise(z2_target, dim=-1)
        loss = 2.0 - 2.0 * (p1_norm * z2_norm).sum(dim=-1).mean()
        return loss

# Test toy BYOL module
encoder = nn.Sequential(nn.Linear(32, 64), nn.ReLU(), nn.Linear(64, 128))
byol = MiniBYOL(encoder, dim=128)
v1, v2 = torch.randn(8, 32), torch.randn(8, 32)
loss = byol(v1, v2)
byol.update_target()
print("BYOL Non-contrastive loss:", round(loss.item(), 4))
print("Negative pairs needed? Exactly 0!")

Common pitfalls

  • Representation collapse in non-contrastive models: Removing the online predictor or backpropagating through the target network causes all embeddings to collapse to identical zero vectors within 10 iterations.
  • Low masking ratios in MAE: Masking only 15%–20% in vision (like BERT in NLP) allows the model to interpolate from adjacent border pixels without learning deep scene semantics; 75%–80% masking is required.
  • Ignoring normalisation in MAE pixel targets: Reconstructing raw unnormalized pixels causes models to focus on high-frequency noise; normalising each patch by its local mean and standard deviation boosts downstream transfer.

06 Check yourself

Q1How does BYOL prevent "representation collapse" (where the model outputs constant vectors for all images) without using negative pairs?

Why: The asymmetric predictor combined with slow EMA momentum updates creates non-equilibrium dynamics that mathematically prevent the trivial constant solution from being a stable fixed point.

Q2Why does Masked Autoencoders (MAE) mask an extremely high percentage (75%–80%) of image patches compared to BERT's 15% token masking?

Why: Visual pixels exhibit high local correlation. Removing 75% of patches removes trivial local interpolation, forcing the network to understand high-level semantics to reconstruct the image.

Q3What striking emergent property is observed in Vision Transformers trained with DINO self-distillation?

Why: DINO's self-distillation dynamics encourage ViT attention heads to automatically isolate foreground objects and semantic boundaries from background pixels without supervision.
