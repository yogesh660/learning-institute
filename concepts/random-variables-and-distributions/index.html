01 The idea

A random variable is not a variable in the algebraic sense, but a deterministic function mapping outcomes of a random process to real numbers. Probability mass functions (PMFs) and probability density functions (PDFs) formalise where those numbers land and how likelihood concentrates across continuous and discrete domains.

Consider rolling a pair of standard dice. The actual physical outcome is an ordered pair like $(3, 5)$ or $(1, 6)$. But as a game designer or gambler, you rarely care about the individual dice faces; you care about their sum. The rule that maps the outcome $(3, 5)$ to the number 8 is a random variable. It turns messy physical events into numbers we can analyse mathematically.

Random variables split into two families. Discrete random variables take separate, countable values: the number of website visits today, or whether an email is spam (0 or 1). We describe them with a Probability Mass Function (PMF), where each individual value has an exact probability, such as $P(X = 3) = 0.25$. Continuous random variables take values on a continuous continuum: the response time of a server in milliseconds, or the height of a person.

For continuous variables, the probability of hitting any single exact number—like a latency of precisely 142.385921... milliseconds—is technically 0. Instead, we use a Probability Density Function (PDF) where the area under the curve between two points gives the probability of landing in that interval. Cumulative Distribution Functions (CDFs) bridge both worlds by reporting the probability of being less than or equal to any threshold.

In everyday terms

A probability density function is like the elevation profile of a mountain: height at a single point does not give you volume, but integrating over an area gives the total mass of rock.

02 Step by step

  1. Define the random variable $X: \Omega \to \mathbb{R}$ by specifying what numeric quantity is extracted from each event.
  2. Determine whether the support of $X$ is discrete (countable integers) or continuous (real intervals).
  3. Assign the appropriate distribution model: PMF $p(x)$ for discrete cases or PDF $f(x)$ for continuous cases.
  4. Verify normalisation: discrete probabilities must sum to 1 ($\sum p(x) = 1$), while continuous density must integrate to 1 ($\int f(x)dx = 1$).
  5. Compute probabilities of intervals by integrating the PDF or evaluating the difference in CDF values: $P(a \le X \le b) = F(b) - F(a)$.

03 The maths

  1. Discrete PMF and Continuous PDF

    $$P(X = x) = p(x), \quad \sum_{x} p(x) = 1 \qquad \text{vs.} \qquad P(a \le X \le b) = \int_a^b f(x)\,dx, \quad \int_{-\infty}^\infty f(x)\,dx = 1$$

    For a discrete variable, $p(x)$ represents the exact point probability. For a continuous variable, $f(x)$ represents probability density; individual points have zero measure ($P(X = x) = 0$), so probabilities are non-zero only over intervals of non-zero width.

  2. Cumulative Distribution Function (CDF)

    $$F(x) = P(X \le x) = \begin{cases} \sum_{t \le x} p(t) & \text{discrete} \\[6pt] \int_{-\infty}^x f(t)\,dt & \text{continuous} \end{cases}$$

    The CDF $F(x)$ is non-decreasing, right-continuous, and satisfies $\lim_{x \to -\infty} F(x) = 0$ and $\lim_{x \to +\infty} F(x) = 1$. By the Fundamental Theorem of Calculus, for continuous variables the PDF is the derivative of the CDF: $f(x) = F'(x)$.

  3. The Gaussian (Normal) Distribution

    $$f(x \mid \mu, \sigma^2) = \frac{1}{\sigma \sqrt{2\pi}} \exp\left(-\frac{(x - \mu)^2}{2\sigma^2}\right)$$

    The bell-shaped normal distribution is parameterised by its mean $\mu$ (centre of mass) and variance $\sigma^2$ (dispersion). By the 68–95–99.7 empirical rule, approximately 68.3% of the density lies within $\mu \pm \sigma$, and 95.4% lies within $\mu \pm 2\sigma$.

04 Key takeaways

  • A probability density $f(x)$ can exceed 1 (unlike a discrete probability), provided the total area under the curve remains 1.
  • The CDF $F(x) = P(X \le x)$ exists for both discrete and continuous variables, making it the most general representation.
  • The Gaussian distribution arises naturally in errors and residuals because sums of independent random variables converge to normality.
  • Quantiles and percentiles are found by inverting the CDF: $x_q = F^{-1}(q)$.

05 In code

python
import numpy as np
from scipy import stats

# Continuous Gaussian distribution
mu, sigma = 100.0, 15.0
dist = stats.norm(loc=mu, scale=sigma)

# Probability of falling within 1 standard deviation [85, 115]
p_1sigma = dist.cdf(mu + sigma) - dist.cdf(mu - sigma)
# Exact density at the mode
density_mode = dist.pdf(mu)
# 95th percentile
p95 = dist.ppf(0.95)

print(f"P(mu - sigma <= X <= mu + sigma) = {p_1sigma:.4f}")
print(f"Density at mode f({mu}) = {density_mode:.5f}")
print(f"95th percentile = {p95:.2f}")

Common pitfalls

  • Interpreting a continuous PDF value $f(x)$ as the probability of observing $x$; point probabilities in continuous distributions are always 0.
  • Forgetting that changing scale or units alters continuous density values, while probabilities remain invariant.
  • Assuming non-negative data is Gaussian, leading to negative predictions or distorted tail estimates where a Poisson, Gamma or Log-normal distribution is appropriate.
  • Confusing the parameter $\sigma$ (standard deviation) with $\sigma^2$ (variance) in software library arguments.

06 Check yourself

Q1For a continuous random variable $X$ with PDF $f(x)$, what is $P(X = 5)$?

Why: The probability of any single real point in a continuous distribution is zero, because the integral of a density over an interval of width zero evaluates to 0.

Q2Can the probability density function $f(x)$ of a continuous distribution ever exceed 1.0?

Why: $f(x)$ is a density, not a probability. For example, a uniform distribution on $[0, 0.5]$ has constant density $f(x) = 2.0$, which integrates to 1.0 over its support.

Q3If $F(x)$ is the cumulative distribution function (CDF) of $X$, how do you compute $P(a < X \le b)$?

Why: $P(a < X \le b) = P(X \le b) - P(X \le a) = F(b) - F(a)$ by definition of the cumulative distribution function.

Q4What proportion of probability mass lies within two standard deviations ($\mu \pm 2\sigma$) of the mean for any Gaussian distribution?

Why: The empirical rule for Gaussian distributions states that approximately 68.3% lies within $\pm 1\sigma$, 95.4% within $\pm 2\sigma$, and 99.7% within $\pm 3\sigma$.

Q5A continuous random variable $X$ is uniformly distributed on the interval $[2, 10]$. What is the value of its probability density function $f(x)$ for $x \in [2, 10]$, and what is $P(4 \le X \le 8)$?

Why: The uniform PDF is $f(x) = 1 / (b - a) = 1 / (10 - 2) = 1/8 = 0.125$. The probability over the sub-interval $[4, 8]$ is the area $\int_4^8 0.125 \, dx = 0.125 \times (8 - 4) = 0.50$.

Q6Mathematically, what is a random variable?

Why: A random variable is formally a function $X: \Omega \to \mathbb{R}$ assigning a numerical value to each outcome in the sample space.

Q7Executing scipy.stats.norm(loc=50, scale=10).ppf(0.50) evaluates to:

Why: The percent point function ppf computes quantiles (inverse CDF). For any symmetric Gaussian distribution, the 50th percentile (median) equals the mean (loc), which is 50.0.

Q8Which of the following functions could NOT be a valid Cumulative Distribution Function (CDF) $F(x)$ for a real-valued random variable?

Why: A CDF must be monotonically non-decreasing ($F(x_1) \le F(x_2)$ whenever $x_1 \le x_2$). A function that decreases violates this axiom and would imply negative probabilities for intervals.

Q9A discrete random variable $X$ takes values in $\{1, 2, 3, 4\}$ with probabilities $P(X=1) = 0.1$, $P(X=2) = 0.3$, and $P(X=3) = 0.4$. What must $P(X=4)$ be for this to be a valid PMF, and what is $P(X \ge 3)$?

Why: Probabilities across all disjoint outcomes must sum to 1: $P(X=4) = 1 - (0.1 + 0.3 + 0.4) = 0.20$. Then $P(X \ge 3) = P(X=3) + P(X=4) = 0.4 + 0.2 = 0.60$.

Q10A continuous random variable $X$ has PDF $f(x) = c x^2$ for $x \in [0, 3]$, and $f(x) = 0$ elsewhere. What is the value of the normalising constant $c$, and what is $P(1 \le X \le 2)$?

Why: Normalising requires $\int_0^3 c x^2 dx = c [x^3 / 3]_0^3 = 9c = 1$, giving $c = 1/9$. Then $P(1 \le X \le 2) = \int_1^2 \frac{1}{9}x^2 dx = \frac{1}{27}(2^3 - 1^3) = 7/27$.

Q11For a standard normal random variable $Z \sim \mathcal{N}(0, 1)$, the PDF mode is $f(0) \approx 0.3989$. If $X \sim \mathcal{N}(100, 0.04)$, where variance $\sigma^2 = 0.04$ (so $\sigma = 0.2$), what is the value of the PDF at its mode $x = 100$?

Why: At the mode $x = \mu$, the exponential factor is $\exp(0) = 1$, leaving $f(\mu) = 1 / (\sigma \sqrt{2\pi})$. Since $\sigma = \sqrt{0.04} = 0.2$, $f(100) \approx 0.3989 / 0.2 = 1.9947$. This neatly illustrates why continuous densities can exceed 1.0.

Q12Suppose the CDF of server response time $T$ (in seconds) is $F(t) = 1 - e^{-\lambda t}$ for $t \ge 0$. Which expression gives the probability density function $f(t)$ and the probability that a response takes strictly longer than 3 seconds?

Why: The PDF is the first derivative of the CDF: $f(t) = F'(t) = \frac{d}{dt}(1 - e^{-\lambda t}) = \lambda e^{-\lambda t}$. The tail probability $P(T > 3)$ is $1 - F(3) = 1 - (1 - e^{-3\lambda}) = e^{-3\lambda}$.
