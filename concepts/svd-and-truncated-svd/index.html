01 The idea

While eigendecomposition applies only to square matrices, Singular Value Decomposition (SVD) factors any rectangular matrix into orthonormal singular vectors and singular values, providing the optimal low-rank matrix approximation.

Every rectangular matrix $X \in \mathbb{R}^{n \times p}$ represents a linear transformation mapping vectors from $\mathbb{R}^p$ to $\mathbb{R}^n$. Geometrically, any linear transformation maps an origin-centred unit hypersphere into a hyper-ellipsoid. The Singular Value Decomposition (SVD) formalises this geometric reality into three elementary operations: an initial orthogonal rotation in $\mathbb{R}^p$, an axis-aligned stretching, and a secondary orthogonal rotation in $\mathbb{R}^n$.

Mathematically, SVD decomposes $X = U \Sigma V^T$, where $U \in \mathbb{R}^{n \times n}$ contains orthonormal left singular vectors (eigenvectors of $X X^T$), $V \in \mathbb{R}^{p \times p}$ contains orthonormal right singular vectors (eigenvectors of $X^T X$), and $\Sigma \in \mathbb{R}^{n \times p}$ is a diagonal matrix of non-negative singular values $\sigma_1 \ge \sigma_2 \ge \dots \ge \sigma_r > 0$ ordered by magnitude.

The foundational power of SVD lies in the Eckart–Young–Mirsky theorem. It proves that keeping only the top $k$ singular values and their corresponding singular vectors—constructing Truncated SVD $X_k = \sum_{i=1}^k \sigma_i u_i v_i^T$—yields the mathematically optimal rank-$k$ approximation of $X$ under both the Frobenius norm and spectral norm.

Truncated SVD is ubiquitous across machine learning: in text mining, applying Truncated SVD to sparse term-document matrices constitutes Latent Semantic Analysis (LSA), compressing thousands of vocabulary words into dense semantic concept vectors; in recommendation systems, it underpins matrix factorisation; in signal processing, it denoises data by truncating small noise singular values.

In everyday terms

Imagine a complex orchestral recording featuring 100 instruments playing at once. SVD decomposes the master audio track into distinct, independent sonic layers ordered by volume. The first few singular vectors capture the massive booming rhythm section and lead vocals (the low-rank signal). The tiny 90th to 100th singular vectors capture the faint rustle of sheet music and background air conditioning (the noise). Truncating the matrix keeps the music intact while eliminating the hiss.

03 The maths

  1. Full Singular Value Decomposition

    X = U \Sigma V^T = \sum_{i=1}^r \sigma_i u_i v_i^T, \quad U^T U = I_n, \; V^T V = I_p, \; \sigma_1 \ge \sigma_2 \ge \dots \ge 0

    Decomposes matrix X into a sum of r rank-1 outer products u_i v_i^T, weighted by descending singular values sigma_i.

  2. Eckart–Young–Mirsky Low-Rank Approximation Theorem

    \min_{\operatorname{rank}(B) = k} \|X - B\|_F = \|X - X_k\|_F = \sqrt{\sum_{i=k+1}^r \sigma_i^2}, \quad X_k = U_k \Sigma_k V_k^T

    Truncated SVD provides the exact best rank-k approximation under Frobenius norm. The minimum achievable reconstruction error equals the square root of discarded singular values squared.

  3. Mathematical Equivalence to PCA

    \operatorname{Cov}(X) = \frac{1}{n - 1} X_c^T X_c = \frac{1}{n - 1} V \Sigma^2 V^T

    When data matrix X_c is mean-centred across rows, the right singular vectors V of X_c are identical to the principal component loading vectors of Cov(X), with eigenvalues lambda_i = sigma_i^2 / (n - 1).

04 Key takeaways

  • Decomposes any rectangular matrix $X \in \mathbb{R}^{n \times p}$ into orthonormal singular vectors and singular values: $X = U \Sigma V^T$.
  • Eckart–Young–Mirsky theorem guarantees that Truncated SVD $X_k = U_k \Sigma_k V_k^T$ is the optimal rank-$k$ approximation under Frobenius and spectral norms.
  • Underpins Latent Semantic Analysis (LSA), transforming sparse high-dimensional term-document matrices into dense low-dimensional semantic representations.
  • Unlike PCA, Truncated SVD does not require centreing data to zero mean, preserving memory sparsity in massive term-document or rating matrices.
  • Right singular vectors $V$ of mean-centred data correspond exactly to principal component directions in PCA.

05 In code

python
import numpy as np

# Truncated SVD and Latent Semantic Analysis (LSA) from scratch
np.random.seed(42)

# Synthetic Term-Document Matrix (6 terms x 8 documents)
# Terms: [algorithm, coding, neural, python, finance, stocks, trading, investment]
terms = ['neural', 'python', 'algorithm', 'finance', 'stocks', 'trading']
docs = [f"Doc_{i+1}" for i in range(8)]

# Docs 0-3 are Tech articles; Docs 4-7 are Finance articles
X = np.array([
    # D1  D2  D3  D4  D5  D6  D7  D8
    [ 3,  2,  4,  3,  0,  0,  0,  0],  # neural
    [ 4,  5,  3,  4,  1,  0,  0,  0],  # python
    [ 2,  3,  4,  2,  0,  1,  0,  0],  # algorithm
    [ 0,  0,  0,  1,  4,  5,  3,  4],  # finance
    [ 0,  0,  0,  0,  5,  4,  5,  3],  # stocks
    [ 0,  1,  0,  0,  3,  4,  4,  5],  # trading
], dtype=float)

# 1. Compute Full SVD: X = U Sigma V^T
U, S, Vt = np.linalg.svd(X, full_matrices=False)
V = Vt.T

# 2. Truncate to rank k=2 (discovering 2 latent concepts: Tech vs Finance)
k = 2
U_k = U[:, :k]
S_k = np.diag(S[:k])
V_k = V[:, :k]

# Low-rank reconstruction
X_reconstructed = U_k @ S_k @ V_k.T

# Frobenius reconstruction error
err_actual = np.linalg.norm(X - X_reconstructed, 'fro')
err_theoretical = np.sqrt(np.sum(S[k:]**2))

# Document representation in 2D latent concept space
doc_coords = V_k @ S_k

print(f"Singular values of term-document matrix: {S.round(2)}")
print(f"Explained variance by top {k} components: {(np.sum(S[:k]**2) / np.sum(S**2))*100:.1f}%")
print(f"Actual Frobenius Error:      {err_actual:.4f}")
print(f"Theoretical Eckart-Young Error: {err_theoretical:.4f} (exact match!)")

print("\nDocument coordinates in 2D Latent Semantic Space:")
for d_name, coord in zip(docs, doc_coords):
    category = "Tech" if coord[0] > coord[1] else "Finance"
    print(f"  {d_name}: [{coord[0]:+5.2f}, {coord[1]:+5.2f}] -> Identified as {category}")

Common pitfalls

  • Confusing SVD with PCA: PCA requires column-centreing first; running SVD without centreing finds directions of maximum energy from the origin, not maximum variance around the mean.
  • Negative values in semantic concepts: SVD generates both positive and negative entries, meaning latent components lack strict parts-based physical interpretability; Non-Negative Matrix Factorisation (NMF) solves this.
  • High memory consumption with dense matrices: Full SVD of an $n \times p$ matrix requires $O(\min(n p^2, n^2 p))$ operations; randomized SVD or Lanczos iterations should be used for large matrices.

06 Check yourself

Q1What does the Eckart–Young–Mirsky theorem establish regarding Truncated SVD?

Why: The Eckart-Young-Mirsky theorem is the bedrock result proving that X_k = U_k Sigma_k V_k^T minimises ||X - B||_F over all matrices B with rank <= k.

Q2Why is Truncated SVD preferred over standard PCA for high-dimensional sparse text data (e.g. TF-IDF matrices)?

Why: Column-centreing in PCA subtracts the mean, converting a 99% sparse matrix into a 100% dense matrix that instantly blows up RAM. Truncated SVD operates directly on sparse formats.
