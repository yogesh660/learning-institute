01 The idea

Classical computer vision models are constrained to a fixed, closed set of pre-determined target categories, requiring costly retraining whenever a new concept is introduced. CLIP (Contrastive Language-Image Pre-training, Radford et al. 2021) overturned this paradigm by training image and text encoders jointly on 400 million internet image-caption pairs, projecting visual and linguistic tokens into a shared semantic space that enables zero-shot classification on arbitrary natural language prompts.

Imagine two independent experts: one inspects photographs (Image Encoder), and the other reads descriptive text captions (Text Encoder). Both experts are tasked with translating their respective inputs into a universal conceptual coordinate system: a 512-dimensional embedding vector on the unit hypersphere.

If the first expert is shown a photograph of a red panda munching on bamboo, and the second reads the caption "A fluffy red panda eating fresh green leaves", their output vectors should point in virtually the exact same direction (exhibiting high cosine similarity near 1.0). Conversely, if the second expert reads "A container ship docked in a busy industrial port", the two vectors should be orthogonal (cosine similarity near 0.0).

**The Dual-Encoder Pipeline**: - Take a mini-batch of $N$ paired images and captions $(I_1, T_1), \dots, (I_N, T_N)$. - Pass images through a vision backbone (such as a ResNet or Vision Transformer) and text through a Transformer language model, $L_2$-normalising both output vectors. - Compute the $N \times N$ cosine similarity matrix $S_{i,j} = v_i^T u_j \cdot e^\tau$. - The $N$ diagonal elements represent matched ground-truth pairs; the $N^2 - N$ off-diagonal elements represent mismatched negative pairings. - A symmetric cross-entropy loss optimises both encoders simultaneously: rows classify the correct text for each image, and columns classify the correct image for each caption.

**Zero-Shot Transfer**: How do you classify a new dataset (like CIFAR-10) without training a single new parameter? You turn class labels into full prompt sentences: "A photo of a {dog}", "A photo of a {cat}", "A photo of a {truck}". Pass all 10 candidate prompts through the text encoder to obtain 10 reference target vectors. Pass an unlabelled image through the image encoder. The predicted class is simply the prompt whose text embedding achieves the highest cosine similarity with the image embedding!

In everyday terms

Like building a universal bilingual dictionary: photographs of objects and their textual descriptions are catalogued under the exact same conceptual library reference number.

02 Step by step

  1. Assemble large-scale paired multimodal data: collect paired images and raw descriptive captions $(I_i, T_i)$ from web-scale sources.
  2. Encode across separate modality backbones: compute image feature vector $v_i = f_{\text{img}}(I_i) \in \mathbb{R}^D$ and text feature vector $u_i = f_{\text{txt}}(T_i) \in \mathbb{R}^D$.
  3. Apply $L_2$ normalisation: project both embeddings onto the unit hypersphere ($\lVert v_i \rVert_2 = 1, \lVert u_i \rVert_2 = 1$).
  4. Compute pairwise multimodal affinity matrix: calculate scaled dot-product matrix $S = (V U^T) \cdot \exp(\tau)$, where $\tau$ is a learnable log-temperature parameter.
  5. Minimise symmetric contrastive cross-entropy: compute cross-entropy along the image dimension (rows) and text dimension (columns), averaging both losses.
  6. Execute zero-shot inference: synthesize prompt embeddings for all target candidate classes, evaluate the unlabelled image vector, and select the class with maximal cosine similarity.

03 The maths

  1. Symmetric multimodal contrastive loss

    $$\mathcal{L}_{\text{CLIP}} = \frac{1}{2}\left( \mathcal{L}_{\text{img}\to\text{txt}} + \mathcal{L}_{\text{txt}\to\text{img}} \right)$$

    The global loss is the unweighted average of two symmetric cross-entropy terms: one classifying the correct caption for each image, and one classifying the correct image for each caption across the $N \times N$ batch matrix.

  2. Directional cross-entropy formulations

    $$\mathcal{L}_{\text{img}\to\text{txt}} = -\frac{1}{N}\sum_{i=1}^N \log \frac{\exp(v_i^T u_i \cdot e^\tau)}{\sum_{j=1}^N \exp(v_i^T u_j \cdot e^\tau)}, \quad \mathcal{L}_{\text{txt}\to\text{img}} = -\frac{1}{N}\sum_{j=1}^N \log \frac{\exp(v_j^T u_j \cdot e^\tau)}{\sum_{i=1}^N \exp(v_i^T u_j \cdot e^\tau)}$$

    $v_i$ is the $L_2$-normalised image representation, $u_j$ is the $L_2$-normalised text representation, and $e^\tau$ is the learned temperature scale. The diagonal elements $v_i^T u_i$ are maximised against all off-diagonal negative candidates.

  3. Zero-shot classification probability

    $$p(y = c | I) = \frac{\exp\big(v_I^T u_c \cdot e^\tau\big)}{\sum_{k=1}^C \exp\big(v_I^T u_k \cdot e^\tau\big)}$$

    Candidate class names $c \in \{1, \dots, C\}$ are wrapped in prompt templates ("A photo of a {class}") and encoded into text vectors $u_c$. Softmax over scaled cosine similarities produces zero-shot posterior class probabilities without task-specific training.

04 Key takeaways

  • CLIP projects visual images and descriptive text into a shared, metric-aligned embedding space where cosine distance reflects semantic affinity.
  • Zero-shot classification operates by treating candidate labels as natural language prompts, removing the need for task-specific classification heads.
  • Prompt engineering (using contextual templates like "A photo of a {label}, a type of pet") substantially improves zero-shot accuracy compared to bare class names.

05 In code

python
import numpy as np

# Simulate zero-shot multimodal classification with CLIP
np.random.seed(42)
D = 4  # Embedding dimensionality

# 3 synthetic candidate text embeddings: Dog, Car, House
text_prompts = ["A photo of a dog", "A photo of a car", "A photo of a house"]
U = np.array([
    [0.9, 0.2, 0.0, 0.1],   # Dog
    [0.1, 0.9, 0.2, 0.0],   # Car
    [0.0, 0.1, 0.9, 0.3]    # House
])
U = U / np.linalg.norm(U, axis=1, keepdims=True)

# Query image embedding (synthetically generated to resemble a dog)
V_img = np.array([[0.85, 0.25, 0.05, 0.1]])
V_img = V_img / np.linalg.norm(V_img, axis=1, keepdims=True)

# Evaluate cosine similarities scaled by temperature scale exp(tau) = 5.0
scale = 5.0
logits = (V_img @ U.T) * scale
probs = np.exp(logits[0]) / np.sum(np.exp(logits[0]))
pred_idx = int(np.argmax(probs))

print(f"Zero-shot classification prediction: '{text_prompts[pred_idx]}'")
print(f"Class probabilities: Dog={probs[0]*100:.1f}%, Car={probs[1]*100:.1f}%, House={probs[2]*100:.1f}%")

Common pitfalls

  • Sensitivity to prompt formulation: evaluating bare single-word labels often underperforms contextual templates ("a photo of a {label}") by 5% to 10% in zero-shot accuracy.
  • Fine-grained spatial or abstract visual tasks: CLIP struggles with counting objects (e.g. "three apples vs four apples"), depth estimation, or reading small text in images.
  • Polysemous label ambiguity: homonyms (such as "crane" the bird vs "crane" the construction equipment) require clarifying context in prompt templates to avoid misclassification.

06 Check yourself

Q1How does CLIP perform zero-shot image classification without fine-tuning on downstream datasets?

Why: Because CLIP aligns vision and language in a shared metric space, candidate classes can be converted to text embeddings ($u_c$) and matched directly against the image embedding ($v_I$) via cosine similarity.

Q2Why does prompt engineering (e.g. using "A photo of a {label}" instead of just "{label}") improve CLIP's zero-shot performance?

Why: Web captions are full descriptive sentences rather than isolated words. A prompt template like "A photo of a dog" provides context and matches the natural language statistics of web pre-training data.

Q3What loss function is used to train CLIP's dual encoders?

Why: CLIP evaluates cross-entropy in two directions: classifying the matching caption among batch alternatives for each image, and classifying the matching image for each caption.

Q4On which of the following tasks does standard CLIP typically struggle without task-specific fine-tuning?

Why: Dual-encoder contrastive training captures global semantic correspondence effectively, but lacks fine-grained spatial and geometric mechanisms required for counting objects or estimating metric depth.
