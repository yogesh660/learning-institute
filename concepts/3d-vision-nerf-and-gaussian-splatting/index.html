01 The idea

Reconstructing continuous, photorealistic 3D worlds from a collection of 2D photographs has been the holy grail of computer vision. Neural Radiance Fields (NeRF; Mildenhall et al., 2020) revolutionized the field by representing 3D scenes as continuous volumetric functions encoded inside neural network weights. 3D Gaussian Splatting (Kerbl et al., 2023) then solved NeRF's agonizingly slow rendering speeds, achieving real-time 100+ FPS novel view synthesis via explicit differentiable 3D ellipsoids.

Given a set of 2D photos with known camera poses (from COLMAP Structure-from-Motion), Novel View Synthesis seeks to render the scene from an unseen camera perspective.

NeRF parameterises a 3D scene as a continuous volumetric function using a Multi-Layer Perceptron (MLP): $F_\theta: (x, y, z, \theta, \phi) \to (r, g, b, \sigma)$, mapping 3D position and 2D viewing direction to RGB colour and volume density $\sigma$. High-frequency details are captured using Fourier Positional Encodings $\gamma(p) = [\sin(2^k \pi p), \cos(2^k \pi p)]$.

To render a pixel, NeRF casts a camera ray $\mathbf{r}(t) = \mathbf{o} + t \mathbf{d}$, samples hundreds of points along the ray, and integrates colours using numerical volume rendering. While photorealistic, rendering a single $1080p$ frame requires querying the MLP billions of times, taking 10–30 seconds per frame.

3D Gaussian Splatting replaces the implicit neural MLP with explicit 3D Gaussians. Each Gaussian possesses 3D position $\mu$, a 3D covariance matrix $\Sigma$ (parameterised by scale and rotation quaternion), opacity $\alpha$, and spherical harmonics (SH) for view-dependent colour. Using tile-based GPU rasterisation, Gaussian Splatting renders photorealistic scenes at 100+ FPS with fast training.

In everyday terms

Imagine sculpting a glowing glass sculpture. NeRF is like having a mathematical equation that calculates the exact colour and smoke density for any $(x, y, z)$ coordinate in mid-air: to photograph the sculpture, a virtual camera shoots rays through every pixel, performing millions of mathematical volume calculations along each laser ray. 3D Gaussian Splatting is like sculpting the scene out of 500,000 tiny semi-transparent glowing fuzzy beads (Gaussians): rendering a photo simply flattens (splats) the beads directly onto the camera lens using high-speed GPU graphics rasterisation.

02 Step by step

  1. Estimate camera poses via SfM: Run COLMAP on multi-view photos to compute intrinsic parameters $\mathbf{K}$, extrinsic poses $[\mathbf{R} \mid \mathbf{t}]$, and sparse 3D point cloud.
  2. Initialize scene representation: For NeRF, initialize continuous coordinate MLP with positional encodings; for 3DGS, initialize 3D Gaussian ellipsoids from the sparse SfM point cloud.
  3. Cast camera rays (NeRF): For target viewpoint, shoot rays $\mathbf{r}(t) = \mathbf{o} + t \mathbf{d}$ through each pixel; sample stratified points along each ray.
  4. Project Gaussians to 2D image plane (3DGS): Project 3D covariance matrices into 2D camera coordinates $\Sigma' = \mathbf{J} \mathbf{W} \Sigma \mathbf{W}^T \mathbf{J}^T$.
  5. Tile-based rasterisation (3DGS): Sort 2D Gaussians by depth; accumulate colour and opacity along pixels using alpha blending in high-speed GPU shared memory.
  6. Optimise parameters: Compute photometric loss $\mathcal{L} = \|I_{\mathrm{rendered}} - I_{\mathrm{ground\_truth}}\|^2$ and backpropagate gradients into Gaussian parameters or MLP weights.

03 The maths

  1. Volumetric Optical Ray Rendering (NeRF)

    C(\mathbf{r}) = \int_{t_n}^{t_f} T(t) \cdot \sigma(\mathbf{r}(t)) \cdot \mathbf{c}(\mathbf{r}(t), \mathbf{d}) \, dt, \quad T(t) = \exp\left( -\int_{t_n}^t \sigma(\mathbf{r}(s)) \, ds \right)

    Accumulates emitted colour $\mathbf{c}$ along camera ray $\mathbf{r}(t)$ weighted by volume density $\sigma$ and cumulative transmittance $T(t)$ (probability that ray traverses without hitting an obstacle).

  2. Fourier Positional Encoding Mapping

    \gamma(p) = \left( \sin(2^0 \pi p), \; \cos(2^0 \pi p), \; \dots, \; \sin(2^{L-1} \pi p), \; \cos(2^{L-1} \pi p) \right)

    Overcomes the spectral bias of deep MLPs, enabling coordinates to represent sharp high-frequency textures and geometric edges.

  3. 3D Gaussian Ellipsoid Covariance Parameterisation

    G(x) = \exp\left( -\frac{1}{2} (x - \mu)^T \Sigma^{-1} (x - \mu) \right), \quad \Sigma = \mathbf{R} \mathbf{S} \mathbf{S}^T \mathbf{R}^T

    Parameterises 3D covariance $\Sigma$ via scaling matrix $\mathbf{S}$ and rotation quaternion $\mathbf{R}$ to enforce positive semi-definiteness.

04 Key takeaways

  • Novel view synthesis reconstructs continuous 3D scenes from a collection of calibrated 2D photos.
  • NeRF models scenes as continuous volumetric functions $(x, y, z, \theta, \phi) \to (\text{RGB}, \sigma)$ in an MLP.
  • Fourier positional encodings overcome spectral bias, enabling MLPs to capture high-frequency detail.
  • 3D Gaussian Splatting uses explicit 3D ellipsoids and tile-based rasterisation for real-time 100+ FPS rendering.

05 In code

python
import numpy as np

def positional_encoding_1d(coords: np.ndarray, num_frequencies: int = 4) -> np.ndarray:
    """Fourier positional encoding mapping scalar coordinates to high-frequency vectors."""
    # Overcomes MLP spectral bias in NeRF (Mildenhall et al., 2020)
    freq_bands = 2.0 ** np.arange(num_frequencies) * np.pi
    # coords shape: [N, 1]
    sin_components = np.sin(coords * freq_bands)
    cos_components = np.cos(coords * freq_bands)
    return np.column_stack([sin_components, cos_components])

# Simulate encoding a 1D spatial coordinate x = 0.35
x_coord = np.array([[0.35]])
encoded_feature = positional_encoding_1d(x_coord, num_frequencies=4)

print(f"Original 1D Coordinate: {x_coord[0, 0]:.2f}")
print(f"Fourier Encoded Shape: {encoded_feature.shape} (8-D sinusoidal vector)")
print("Encoded Vector:", np.round(encoded_feature[0], 3))
print("High-frequency Fourier features allow deep MLPs to represent sharp edges!")

Common pitfalls

  • Camera pose inaccuracy: NeRF and Gaussian Splatting require sub-pixel accurate camera poses from COLMAP; noisy camera poses cause blurry or fractured ghosting artifacts.
  • Agonizingly slow NeRF rendering: Standard vanilla NeRF takes up to 30 seconds to render a single 1080p frame due to ray-marching volume integrals; use Instant-NGP or 3D Gaussian Splatting for real-time speeds.
  • Floaters and artifacts in unconstrained regions: In areas with sparse photographic coverage (e.g. background skies or behind furniture), 3DGS produces floating needle-like artifacts; prune low-opacity Gaussians.

06 Check yourself

Q1Why does NeRF use Fourier Positional Encodings $\gamma(p)$ on spatial coordinates before passing them to the MLP?

Why: Neural Tangent Kernel theory proves standard MLPs easily learn smooth low-frequency functions but struggle with high-frequency details. Fourier encoding bridges this spectral bias.

Q2What is the primary breakthrough of 3D Gaussian Splatting (Kerbl et al., 2023) over original NeRF?

Why: NeRF evaluates an MLP hundreds of times per pixel along each ray. Gaussian Splatting projects explicit 3D Gaussians directly onto the screen, rasterizing in real time.

Q3What does "Volume Density" $\sigma(x, y, z)$ represent in NeRF's volumetric rendering equation?

Why: Density $\sigma$ represents opacity at coordinate $(x, y, z)$. High density means solid matter (ray terminates and emits colour); zero density means empty air (ray passes through).
