01 The idea

Interpreting complex non-linear models requires answering not just what a model predicts, but exactly why it made that specific prediction for an individual instance. Rooted in cooperative game theory (Shapley values), SHAP (SHapley Additive exPlanations) provides the unique mathematical framework that satisfies foundational fairness axioms: local accuracy, missingness, and consistency. By calculating each feature's marginal contribution across all possible coalitions, SHAP unifies local feature attribution with global model interpretability.

Imagine three colleagues—Alice, Bob, and Charlie—collaborating on a freelance consulting project that earns a total bonus of £9,000. If Alice worked alone, the project would have earned £2,000. If Bob worked alone, £3,000. If Alice and Bob worked together, their synergy would have yielded £7,000. Charlie brings niche domain expertise that only becomes valuable when paired with Bob. How do you divide the £9,000 bonus fairly among the three team members?

In 1953, mathematician Lloyd Shapley solved this cooperative game theory dilemma by evaluating each player's marginal contribution across every possible coalition they could join. A player's Shapley value is the weighted average of how much value they add when stepping into a room containing any subset of the other players. In 2017, Scott Lundberg and Su-In Lee recognised that predicting an outcome in machine learning is identical to a cooperative game: the model's prediction is the total payout, and the features are the collaborating players.

For any individual prediction, SHAP calculates how much each feature value pushed the prediction away from the dataset's base expected value $\mathbb{E}[f(X)]$. If a patient has a predicted 35% risk of heart disease compared to the population baseline of 10%, SHAP might reveal that their blood pressure added +18%, their age added +12%, and their active exercise routine subtracted -5%, summing up exactly to the 25% discrepancy. Because SHAP guarantees mathematical additivity, these local explanations can be aggregated globally to create summary plots, interaction matrices, and dependence curves.

In everyday terms

Itemising a restaurant bill where friends shared overlapping appetizers and family-style mains: calculating each diner's fair share by averaging their marginal cost across all combinations of who sat at the table.

02 Step by step

  1. Establish the baseline expectation: compute the base value $\phi_0 = \mathbb{E}[f(X)]$, representing the model's average prediction across the background training distribution.
  2. Select a candidate instance $x$ whose individual model prediction $f(x)$ requires explanation.
  3. Enumerate feature coalitions: evaluate model predictions across all $2^M$ subsets of features, substituting absent features with background expectation values.
  4. Calculate marginal contributions: for feature $i$ and coalition $S$, compute the marginal lift $\Delta(S, i) = f(S \cup \{i\}) - f(S)$.
  5. Compute the weighted Shapley average: weight each marginal contribution by the combinatorial probability of coalition size $|S|$ to yield $\phi_i(x)$.
  6. Verify the efficiency axiom: ensure that the sum of attributions equals the total prediction offset: $\sum_{i=1}^M \phi_i(x) = f(x) - \phi_0$.
  7. Aggregate across the population: stack individual SHAP vectors to construct global beeswarm summary plots, feature importance rankings, and dependency curves.

03 The maths

  1. Classical Shapley value formulation

    $$\phi_i(x) = \sum_{S \subseteq F \setminus \{i\}} \frac{|S|! \, (|F| - |S| - 1)!}{|F|!} \Big( f_x(S \cup \{i\}) - f_x(S) \Big)$$

    where $F$ is the total set of features, $S$ is a feature coalition excluding feature $i$, and $|S|!(|F| - |S| - 1)! / |F|!$ is the combinatorial probability that feature $i$ enters coalition $S$ under a uniformly random permutation of players. $f_x(S) = \mathbb{E}[f(X) \mid X_S = x_S]$ represents the conditional expectation with features in $S$ fixed at their instance values.

  2. Additive feature attribution and efficiency axiom

    $$f(x) = \phi_0 + \sum_{i=1}^M \phi_i(x), \qquad \phi_0 = \mathbb{E}\big[f(X)\big]$$

    Local accuracy (efficiency) guarantees that the sum of all feature attributions $\phi_i(x)$ plus the base value $\phi_0$ recovers the exact model prediction $f(x)$. Unlike heuristic attribution methods (e.g. split counts), SHAP never loses or invents prediction credit.

  3. The four fundamental Shapley axioms

    $$\begin{aligned} \text{Efficiency:} & \quad \sum_{i=1}^M \phi_i(x) = f(x) - \mathbb{E}[f(X)] \\\\ \text{Symmetry:} & \quad f(S \cup \{i\}) = f(S \cup \{j\}) \implies \phi_i = \phi_j \\\\ \text{Dummy (Null):} & \quad f(S \cup \{i\}) = f(S) \implies \phi_i = 0 \\\\ \text{Additivity:} & \quad \phi_i(f + g) = \phi_i(f) + \phi_i(g) \end{aligned}$$

    Shapley proved that the Shapley formula is the unique attribution method satisfying all four axioms simultaneously. If an attribution method violates consistency, altering a model such that a feature contributes more can paradoxically lower that feature's assigned importance.

04 Key takeaways

  • Grounded in cooperative game theory; uniquely satisfies efficiency, symmetry, dummy player, and additivity axioms.
  • Provides both local explanations (instance-level waterfall plots) and global insights (beeswarm summary plots).
  • TreeSHAP computes exact Shapley values in polynomial time $O(T L D^2)$ for tree ensembles.
  • Fairly divides the credit of non-linear feature interactions among participating features.

05 In code

python
import numpy as np
import math
from itertools import combinations

# Model with interaction: f(x) = 2*x0 + 3*x1 + 4*x0*x1 (x2 is dummy)
def f(x):
    return 2.0 * x[0] + 3.0 * x[1] + 4.0 * x[0] * x[1]

x_inst = np.array([1.0, 1.0, 0.5])
base = np.array([0.0, 0.0, 0.0])
M = 3
phi = np.zeros(M)

# Compute exact Shapley values across all 2^M coalitions
for i in range(M):
    rest = [j for j in range(M) if j != i]
    for s_len in range(M):
        for S in combinations(rest, s_len):
            x_wo, x_w = base.copy(), base.copy()
            for j in S:
                x_wo[j] = x_inst[j]
                x_w[j] = x_inst[j]
            x_w[i] = x_inst[i]
            w = math.factorial(len(S)) * math.factorial(M - len(S) - 1) / math.factorial(M)
            phi[i] += w * (f(x_w) - f(x_wo))

print(f"Prediction: {f(x_inst):.2f}")
print(f"Baseline:   {f(base):.2f}")
print(f"SHAP attributions [x0, x1, x2]: {phi.round(2)}")
print(f"Sum of attributions: {np.sum(phi):.2f}")

Common pitfalls

  • Exponential complexity of exact Shapley values: Calculating exact attributions across $M$ features requires evaluating $2^M$ coalitions. For large $M$, models require polynomial TreeSHAP or sampled KernelSHAP approximations.
  • Feature correlation and unrealistic background coalitions: When features are strongly correlated, marginal expectation approximations can query models on impossible feature combinations (e.g. low weight, massive BMI), distorting attribution.
  • Conflating SHAP attributions with causal effects: SHAP explains how the statistical model uses features to make predictions; it does not prove that changing a feature in the real world will causally shift the outcome.
  • Choice of background dataset: In KernelSHAP and TreeSHAP, the baseline value $\phi_0$ depends directly on the chosen background distribution; using a biased reference sample shifts all attribution values.

06 Check yourself

Q1What does the Efficiency axiom guarantee in SHAP feature attribution?

Why: The efficiency (local accuracy) axiom guarantees that the sum of attributions $\sum \phi_i(x)$ perfectly bridges the gap between the expected baseline prediction $\phi_0$ and the instance prediction $f(x)$ with zero unaccounted credit.

Q2Why is TreeSHAP widely preferred over KernelSHAP when explaining tree ensembles like XGBoost and LightGBM?

Why: While model-agnostic KernelSHAP must sample exponential coalitions ($2^M$), TreeSHAP recurses down decision tree paths, tracking conditional feature distributions in polynomial time relative to tree depth and leaf counts.

Q3If a feature has zero marginal impact across every single coalition of features ($f(S \cup \{i\}) = f(S)$ for all $S$), what is its SHAP value according to the Dummy axiom?

Why: The Dummy (or Null player) axiom mandates that if a feature never contributes to altering model predictions in any context, its allocated credit must be strictly 0.

Q4Why must SHAP explanations NOT be treated as direct causal statements about the real world?

Why: SHAP explains the internal decision surface of the mathematical model. If a model predicts health outcomes using hospital visit counts as a correlation proxy, SHAP attributes high importance to visits, but hospital visits do not cause illness.
