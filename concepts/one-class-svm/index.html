01 The idea

In anomaly detection, negative examples are rare, unknown, or infinitely varied. The One-Class SVM trains exclusively on nominal data, learning a tight decision boundary that envelops the normal data distribution.

Supervised classification requires representative training samples from all classes. However, in mission-critical applications—such as credit card fraud detection, industrial wind turbine vibration monitoring, network intrusion detection, or manufacturing defect inspection—anomalies are either exceedingly rare or take completely novel, unimagined forms. Trying to train a standard binary classifier fails because you cannot sample the infinite universe of potential anomalies.

One-Class Classification addresses this challenge by learning strictly from positive, nominal data. Introduced by Bernhard Schölkopf et al. (2001), the One-Class Support Vector Machine (OC-SVM) maps normal training instances into a high-dimensional feature space $\mathcal{H}$ via a kernel function (typically RBF) and seeks a maximum-margin hyperplane that separates the normal data cloud from the coordinate origin.

Geometrically, the origin serves as a proxy for all anomalous patterns. In the dual formulation, the algorithm identifies a sparse subset of normal points as support vectors that define the outer perimeter of the normal data distribution.

A hyperparameter $\nu \in (0, 1]$ controls the trade-off: it acts as an exact upper bound on the fraction of training outliers permitted outside the boundary, and a lower bound on the fraction of support vectors. Alternatively, David Tax and Robert Duin proposed Support Vector Data Description (SVDD), which encloses normal points within a minimum-volume hypersphere of radius $R$; for stationary RBF kernels, SVDD and Schölkopf One-Class SVM are mathematically equivalent.

In everyday terms

Imagine an ancient walled city built on an open plain. The city guards do not know what future invaders will look like (whether bandits, foreign armies, or monsters). Instead of trying to identify enemies, the city architects build a circular stone fortress wall closely enclosing all the lawful citizens homes. Any individual found standing inside the fortress walls is considered a citizen; anyone found outside the perimeter wall is flagged as a stranger.

03 The maths

  1. Schölkopf One-Class SVM Primal Formulation

    \min_{w, \xi, \rho} \frac{1}{2} \|w\|^2 + \frac{1}{\nu n} \sum_{i=1}^n \xi_i - \rho \quad \text{subject to} \quad \langle w, \phi(x_i) \rangle \ge \rho - \xi_i, \; \xi_i \ge 0

    Separates normal mapped data from origin with maximum margin rho. Slack variables xi_i penalise instances falling on the origin side of the separating boundary.

  2. Dual Quadratic Programming Problem

    \min_\alpha \frac{1}{2} \sum_{i=1}^n \sum_{j=1}^n \alpha_i \alpha_j K(x_i, x_j) \quad \text{subject to} \quad 0 \le \alpha_i \le \frac{1}{\nu n}, \; \sum_{i=1}^n \alpha_i = 1

    Dual problem depends only on inner products evaluated via kernel function K(x_i, x_j). The upper bound on alpha_i prevents individual points from disproportionately warping the boundary.

  3. Tax & Duin SVDD Hypersphere Primal

    \min_{R, c, \xi} R^2 + \frac{1}{\nu n} \sum_{i=1}^n \xi_i \quad \text{subject to} \quad \|\phi(x_i) - c\|^2 \le R^2 + \xi_i, \; \xi_i \ge 0

    Encloses normal instances within a minimum-radius hypersphere of centre c and radius R. For RBF kernels with K(x, x) = 1, SVDD yields an identical boundary to Schölkopf formulation.

04 Key takeaways

  • Learns a non-linear decision boundary enclosing normal data, detecting anomalies as points falling outside the boundary.
  • Trained exclusively on nominal data without requiring negative anomaly examples during training.
  • Schölkopf formulation separates normal points from the coordinate origin in RKHS with maximum margin.
  • Hyperparameter $\nu \in (0, 1]$ simultaneously bounds the fraction of training outliers and the fraction of support vectors.
  • When paired with Gaussian RBF kernels, One-Class SVM models complex multi-modal and non-convex normal distributions.

05 In code

python
import numpy as np
from sklearn.svm import OneClassSVM

# One-Class SVM for Novelty and Anomaly Detection
np.random.seed(42)

# 1. Generate normal operational data (2 clusters in 2D space)
n_normal = 300
cluster1 = np.random.normal(loc=[-2, -2], scale=0.6, size=(n_normal // 2, 2))
cluster2 = np.random.normal(loc=[2, 2], scale=0.7, size=(n_normal // 2, 2))
X_train_normal = np.vstack([cluster1, cluster2])

# 2. Generate novel test data containing normal points and extreme anomalies
n_test_normal = 100
n_anomalies = 20
test_normal = np.random.normal(loc=[-2, -2], scale=0.6, size=(n_test_normal, 2))
anomalies = np.random.uniform(low=-6, high=6, size=(n_anomalies, 2))
# Ensure anomalies are outside normal clusters
anomalies = anomalies[np.linalg.norm(anomalies - np.array([-2, -2]), axis=1) > 2.0]
anomalies = anomalies[np.linalg.norm(anomalies - np.array([2, 2]), axis=1) > 2.0][:n_anomalies]

X_test = np.vstack([test_normal, anomalies])
y_test = np.array([1]*len(test_normal) + [-1]*len(anomalies))  # 1 = normal, -1 = anomaly

# 3. Fit One-Class SVM with RBF kernel and nu=0.05
nu = 0.05
oc_svm = OneClassSVM(kernel='rbf', gamma=0.5, nu=nu)
oc_svm.fit(X_train_normal)

# Evaluate predictions (-1 for anomaly, +1 for inlier)
preds_train = oc_svm.predict(X_train_normal)
preds_test = oc_svm.predict(X_test)

train_outlier_rate = np.mean(preds_train == -1)
test_anomaly_detection_rate = np.mean(preds_test[y_test == -1] == -1)
test_normal_retention_rate = np.mean(preds_test[y_test == 1] == 1)

print(f"One-Class SVM fitted with nu = {nu} (target max outlier fraction)")
print(f"Training support vectors count: {len(oc_svm.support_)} / {n_normal} ({len(oc_svm.support_)/n_normal*100:.1f}%)")
print(f"Empirical training outlier fraction: {train_outlier_rate*100:.1f}% (bounded by nu = {nu*100:.1f}%)")
print(f"Test Anomaly Detection Recall:       {test_anomaly_detection_rate*100:.1f}%")
print(f"Test Normal Inlier Precision:        {test_normal_retention_rate*100:.1f}%")

Common pitfalls

  • Sensitivity to RBF parameter gamma: If $\gamma$ is too large, the kernel boundary tightly wraps each individual training sample into isolated islands, causing extreme overfitting and false alarm floods.
  • Contamination in training set: If the training set contains unlabelled anomalies, the boundary expands to enclose them; robust trimming or robust covariance is needed.
  • High-dimensional distance concentration: In ultra-high dimensions ($p > 1000$), Euclidean distances in RBF kernels concentrate, degrading boundary quality; dimensionality reduction should precede OC-SVM.

06 Check yourself

Q1What role does the hyperparameter nu play in the One-Class SVM?

Why: In the nu-SVM formulation, nu strictly upper-bounds the training margin errors (outlier fraction) and lower-bounds the fraction of support vectors.

Q2Why does the One-Class SVM separate data from the origin in feature space?

Why: In RKHS under an RBF kernel, mapped data points cluster away from the origin on a hypersphere. Separating data from the origin encloses the high-density normal region.
