Weight Initialisation: Xavier and He

Calibrating weight variance based on layer fan-in and fan-out to preserve signal variance and prevent vanishing or exploding activations across deep networks.

01 The idea

Initialising neural network weights to all zeros traps neurons in a symmetry lock where every unit computes identical outputs and receives identical gradients. Conversely, initialising weights with uncalibrated random variance causes activations and gradients to either explode exponentially to infinity or vanish to zero as depth increases. Xavier (Glorot) and He (Kaiming) initialisation scale weight variances inversely with layer dimensions, maintaining stable unit-variance signals from the very first training iteration.

Suppose you initialise all weights in a 100-neuron hidden layer to zero. For any input, every single neuron computes identical outputs. During backpropagation, every neuron receives the exact same gradient update. After the optimiser takes a step, all 100 neurons still share identical weights! The network is trapped in symmetry, effectively behaving as a single neuron regardless of width. Breaking symmetry requires initialising weights with random values.

However, choosing random values carelessly creates extreme numerical instability. Consider a layer with 256 inputs initialised from a standard normal distribution N(0, 1). The variance of each neuron's output is roughly 256 times the input variance. Across 10 layers, the signal variance scales by 256^10, causing numbers to explode into NaN overflows within milliseconds. Conversely, initialising with weights that are too small (e.g. standard deviation 0.01) causes variance to decay exponentially to zero, extinguishing the signal completely within a few layers.

In 2010, Xavier Glorot and Yoshua Bengio derived that preserving constant variance forward and backward for linear and symmetric activations (such as Tanh) requires scaling weight variance inversely with the average of fan-in and fan-out: Var(w) = 2 / (D_in + D_out). In 2015, Kaiming He discovered that because ReLU zeroes out negative inputs (halving the transmitted variance), ReLU layers require double the variance: Var(w) = 2 / D_in. This simple correction enabled training deep convolutional networks with over 100 layers without divergence.

In everyday terms

A chain of audio amplifiers: if each amplifier in a 20-stage studio rig multiplies signal volume by 1.5x, the sound deafens into screeching distortion; if each multiplies volume by 0.7x, the sound fades into silence. Xavier and He initialisation set every stage's gain to exactly 1.0x.

02 Step by step

  1. Identify downstream activation non-linearity: check whether the layer uses symmetric/linear activations (Tanh, Sigmoid, Linear) or half-rectifying activations (ReLU, LeakyReLU, GELU).
  2. Compute fan-in and fan-out: calculate input dimensions $D_{\text{in}}$ and output dimensions $D_{\text{out}}$ (multiplying kernel spatial dimensions $k_w \cdot k_h \cdot C_{\text{in}}$ for convolutions).
  3. Apply Xavier/Glorot for Tanh or Sigmoid: draw weights from $\mathcal{N}\left(0, \frac{2}{D_{\text{in}} + D_{\text{out}}}\right)$ or uniform distribution $\mathcal{U}\left(-\sqrt{\frac{6}{D_{\text{in}} + D_{\text{out}}}}, \sqrt{\frac{6}{D_{\text{in}} + D_{\text{out}}}}\right)$.
  4. Apply He/Kaiming for ReLU and GELU: draw weights from $\mathcal{N}\left(0, \frac{2}{D_{\text{in}}}\right)$ to compensate for rectified negative inputs.
  5. Initialise bias vectors to zero: set all bias parameters to constant zero, avoiding arbitrary initial directional offsets.

03 The maths

  1. Forward signal variance propagation

    \text{Var}(y_j) = D_{\text{in}} \cdot \text{Var}(w) \cdot \text{Var}(x)

    Assuming input features $x$ and weights $w$ are mutually independent with mean zero. Preserving unit variance across the transformation ($\text{Var}(y) = \text{Var}(x)$) requires setting $\text{Var}(w) = 1 / D_{\text{in}}$.

  2. Xavier (Glorot) initialisation formula

    \text{Var}(w_{\text{Xavier}}) = \frac{2}{D_{\text{in}} + D_{\text{out}}}, \qquad w \sim \mathcal{N}\left( 0, \sqrt{\frac{2}{D_{\text{in}} + D_{\text{out}}}} \right)

    Taking the harmonic compromise between preserving forward activation variance ($1 / D_{\text{in}}$) and backward gradient variance ($1 / D_{\text{out}}$) guarantees balanced bidirectional signal flow for symmetric activations like Tanh.

  3. He (Kaiming) initialisation for ReLU networks

    \text{Var}(w_{\text{He}}) = \frac{2}{D_{\text{in}}}, \qquad w \sim \mathcal{N}\left( 0, \sqrt{\frac{2}{D_{\text{in}}}} \right)

    Because ReLU clips negative inputs to zero, $\mathbb{E}[(\max(0, x))^2] = \frac{1}{2} \text{Var}(x)$. To balance the 50% loss of signal energy through rectification, the weight variance must be doubled to $2 / D_{\text{in}}$.

04 Key takeaways

  • Initialising weights to constant values locks neurons into identical symmetry, preventing them from learning distinct features.
  • Xavier initialisation balances forward and backward variance for symmetric, linear, and Tanh non-linearities.
  • He initialisation doubles weight variance (2 / D_in) to compensate for ReLU setting half of all activations to zero.

05 In code

python
import numpy as np

np.random.seed(42)
D = 256
n_layers = 10
n_samples = 1000

# Input: standard Gaussian features
X = np.random.normal(0, 1.0, size=(n_samples, D))

def simulate_propagation(init_type):
    current = X.copy()
    for _ in range(n_layers):
        if init_type == "std_normal":
            W = np.random.normal(0, 1.0, size=(D, D))
        elif init_type == "xavier":
            std = np.sqrt(2.0 / (D + D))
            W = np.random.normal(0, std, size=(D, D))
        elif init_type == "he":
            std = np.sqrt(2.0 / D)
            W = np.random.normal(0, std, size=(D, D))
        current = np.maximum(0, np.dot(current, W)) # ReLU activation
    return np.var(current)

var_normal = simulate_propagation("std_normal")
var_xavier = simulate_propagation("xavier")
var_he = simulate_propagation("he")

print(f"10-layer forward ReLU variance:")
print(f"Standard Normal N(0,1): {var_normal:.2e} (explodes to infinity)")
print(f"Xavier initialisation:  {var_xavier:.2e} (vanishes toward zero)")
print(f"He initialisation:      {var_he:.2f} (stable near 1.0)")

Common pitfalls

  • Using Xavier initialisation in deep ReLU networks: after 20 layers, activation variance decays by 0.5^20, causing severe vanishing gradients.
  • Sampling weights from standard normal N(0, 1) without scaling: variance scales with fan-in, causing immediate numerical overflow and NaN weights.
  • Randomly initialising bias vectors: biases should be initialised to zero to avoid introducing arbitrary non-zero offsets before training.

06 Check yourself

Q1Why does initialising all weights in a neural network layer to zero prevent it from learning effectively?

Why: If all weights in a layer are equal, every neuron computes the same output and receives the same gradient update. Breaking this symmetry requires random initialisation.

Q2Why does He (Kaiming) initialisation use a variance of 2 / D_in instead of 1 / D_in?

Why: ReLU zeroes out half of the Gaussian input distribution on average, reducing signal variance by 50%. Multiplying the initial variance by 2 restores the expected signal variance to 1.0.

Q3What happens if you initialise a 30-layer deep neural network with weights drawn from a standard normal distribution N(0, 1)?

Why: With fan-in D, each layer multiplies variance by D. Without scaling by 1/D, variance grows as D^L, leading to rapid numerical explosion and NaN values.
