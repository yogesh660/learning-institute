01 The idea

While Gaussian Process Regression has a closed-form Gaussian posterior, GP classification involves a discrete non-Gaussian likelihood that destroys exact conjugacy. Approximate inference methods (Laplace approximation and Expectation Propagation) yield well-calibrated class probabilities and epistemic uncertainty.

In safety-critical classification domains—such as autonomous vehicle pedestrian detection, medical radiology triage, or financial stress forecasting—predicting a class label is insufficient; the model must communicate how confident it is in its prediction, distinguishing between familiar operational regimes and alien out-of-distribution inputs (epistemic uncertainty).

Gaussian Process Classification (GPC) models classification non-parametrically by placing a Gaussian Process prior over an unobserved continuous latent function $f(x) \sim \mathcal{GP}(m(x), k(x, x'))$. This latent function $f(x)$ represents log-odds scores across input space. To transform latent real numbers into valid probabilities, $f(x)$ is squashed through a sigmoid or probit link function: $\pi(x) = P(y = 1 \mid f(x)) = \sigma(f(x))$.

However, a fundamental mathematical hurdle arises: unlike Gaussian noise in regression, the discrete Bernoulli likelihood $p(y \mid f) = \prod_{i=1}^n \sigma(y_i f_i)$ is non-Gaussian. Multiplying a Gaussian prior $p(f)$ by a non-Gaussian likelihood yields a non-Gaussian posterior distribution $p(f \mid y) = p(y \mid f) p(f) / p(y)$ whose normalising marginal evidence integral is analytically intractable.

To resolve this intractability, GPC employs deterministic approximations. The Laplace Approximation fits a Gaussian $\mathcal{N}(\hat{f}, \Sigma)$ centred at the posterior mode $\hat{f} = \arg\max \log p(f \mid y)$ by taking the second-order Taylor expansion (negative Hessian) of the unnormalized log posterior. Test predictions are obtained by integrating the sigmoid link over the resulting Gaussian predictive distribution.

In everyday terms

Imagine a sound engineer setting an audio volume threshold. The underlying acoustics of the room vary smoothly across different corners (the continuous latent Gaussian process f(x)). A red warning light blinks on whenever the noise exceeds a decibel threshold (the discrete binary observation y in {0, 1}). We cannot measure the exact decibel level directly, only whether the red light blinked. The Laplace approximation acts as an acoustic reconstruction tool, calculating the most probable decibel level and uncertainty bands at every coordinate in the room.

03 The maths

  1. Laplace Approximation Objective and Mode Finding

    \nabla \Psi(f) = -K^{-1} f + (t - \pi), \quad \nabla^2 \Psi(f) = -(K^{-1} + W), \quad W = \operatorname{diag}(\pi_i (1 - \pi_i))

    Gradient and Hessian of unnormalized log posterior over latent vector f, where t_i = (y_i + 1)/2 and pi_i = sigma(f_i). Because W is positive semi-definite, the objective is strictly concave.

  2. Newton Update for Posterior Mode

    f^{\mathrm{new}} = (K^{-1} + W)^{-1} (W f + t - \pi) = K (I + W K)^{-1} (W f + t - \pi)

    Numerically stable mode-finding iteration avoiding inversion of K directly, evaluating Cholesky factorisation on (B = I + W^{1/2} K W^{1/2}).

  3. Probit Sigmoid Approximation for Predictive Class Probability

    \bar{\pi}_* = \mathbb{E}_{f_* \sim \mathcal{N}(\mu_*, \sigma_*^2)}[\sigma(f_*)] \approx \sigma\left(\frac{\mu_*}{\sqrt{1 + \frac{\pi}{8} \sigma_*^2}}\right)

    Convoluting a Gaussian distribution with a sigmoid is analytically intractable, but substituting a cumulative probit link yields this accurate closed-form approximation.

04 Key takeaways

  • Non-parametric Bayesian classification placing a Gaussian Process prior over continuous latent log-odds function $f(x)$.
  • Discrete Bernoulli likelihood breaks conjugacy; exact posterior is non-Gaussian and intractable.
  • Laplace approximation fits a Gaussian distribution around the posterior mode $\hat{f}$ using the negative Hessian of the log posterior.
  • Produces principled epistemic uncertainty: on distant out-of-distribution inputs, latent variance increases and probabilities revert toward 0.50.
  • Provides superior probability calibration compared to uncalibrated neural networks and support vector machines.

05 In code

python
import numpy as np

# Gaussian Process Classifier with Laplace Approximation from scratch
class GPClassifierLaplace:
    def __init__(self, gamma=1.0, max_iters=30, tol=1e-6):
        self.gamma = gamma
        self.max_iters = max_iters
        self.tol = tol
        self.X_train = None
        self.y_train = None
        self.f_hat = None
        self.K = None
        self.W = None
        
    def _rbf_kernel(self, X1, X2):
        dists_sq = np.sum(X1**2, axis=1)[:, None] + np.sum(X2**2, axis=1)[None, :] - 2 * (X1 @ X2.T)
        return np.exp(-self.gamma * np.maximum(dists_sq, 0))
        
    def fit(self, X, y):
        self.X_train = X
        self.y_train = y  # y in {0, 1}
        n = len(X)
        
        # 1. Compute kernel matrix with jitter for numerical stability
        self.K = self._rbf_kernel(X, X) + 1e-6 * np.eye(n)
        
        # 2. Newton-Raphson iteration to find posterior mode f_hat
        f = np.zeros(n)
        for it in range(self.max_iters):
            pi = 1.0 / (1.0 + np.exp(-np.clip(f, -30, 30)))
            # W = diag(pi * (1 - pi))
            w = pi * (1.0 - pi)
            W = np.diag(w)
            
            # Stable Cholesky factorisation of (I + W^{1/2} K W^{1/2})
            W_sqrt = np.diag(np.sqrt(w))
            B = np.eye(n) + W_sqrt @ self.K @ W_sqrt
            L = np.linalg.cholesky(B)
            
            grad = self.y_train - pi
            b = W @ f + grad
            # Solve (K^{-1} + W) f_new = b via Woodbury identity
            a = b - W_sqrt @ np.linalg.solve(L.T, np.linalg.solve(L, W_sqrt @ self.K @ b))
            f_new = self.K @ a
            
            diff = np.max(np.abs(f_new - f))
            f = f_new
            if diff < self.tol:
                break
                
        self.f_hat = f
        self.pi_hat = 1.0 / (1.0 + np.exp(-np.clip(f, -30, 30)))
        self.w_hat = self.pi_hat * (1.0 - self.pi_hat)
        
    def predict_proba(self, X_test):
        n_train = len(self.X_train)
        n_test = len(X_test)
        
        K_star = self._rbf_kernel(self.X_train, X_test)
        K_star_star = self._rbf_kernel(X_test, X_test) + 1e-6 * np.eye(n_test)
        
        # Predictive latent mean: mu_* = K_*^T (y - pi)
        grad = self.y_train - self.pi_hat
        mu_star = K_star.T @ grad
        
        # Predictive latent variance: sigma_*^2
        W_sqrt = np.diag(np.sqrt(self.w_hat))
        B = np.eye(n_train) + W_sqrt @ self.K @ W_sqrt
        L = np.linalg.cholesky(B)
        v = np.linalg.solve(L, W_sqrt @ K_star)
        sigma2_star = np.diag(K_star_star) - np.sum(v**2, axis=0)
        sigma2_star = np.maximum(sigma2_star, 1e-8)
        
        # Probit link approximation for predictive probability
        kappa = 1.0 / np.sqrt(1.0 + np.pi * sigma2_star / 8.0)
        p_star = 1.0 / (1.0 + np.exp(-kappa * mu_star))
        
        return p_star, sigma2_star

# Synthetic non-linear classification dataset
np.random.seed(42)
n_samples = 80
X = np.random.uniform(-3, 3, (n_samples, 2))
# True non-linear boundary: circle x1^2 + x2^2 < 3.0
y = ((X[:, 0]**2 + X[:, 1]**2) < 3.0).astype(int)

gpc = GPClassifierLaplace(gamma=0.5)
gpc.fit(X, y)

# Predict on inlier and far out-of-distribution point
test_points = np.array([
    [0.0, 0.0],    # Firmly inside circle (Class 1)
    [1.8, 1.8],    # Firmly outside circle (Class 0)
    [10.0, 10.0],  # Far out-of-distribution point!
])

probs, latent_vars = gpc.predict_proba(test_points)

print("Gaussian Process Classification (Laplace Approximation):")
print(f"Point [0, 0] (Inside):      P(Y=1) = {probs[0]:.4f}, Latent Var = {latent_vars[0]:.3f} (High certainty)")
print(f"Point [1.8, 1.8] (Outside):  P(Y=1) = {probs[1]:.4f}, Latent Var = {latent_vars[1]:.3f} (High certainty)")
print(f"Point [10, 10] (OOD Alien): P(Y=1) = {probs[2]:.4f}, Latent Var = {latent_vars[2]:.3f} (High uncertainty reverting to 0.50!)")

Common pitfalls

  • Computational scaling: Mode finding and covariance inversion scale as $O(n^3)$ per Newton step, limiting vanilla GPC to a few thousand samples.
  • Laplace mode underestimation: The Laplace approximation fits the curvature at the mode; if the true posterior is skewed or multimodal, Expectation Propagation (EP) is more accurate.
  • Overfitting hyperparameter selection: Optimising marginal likelihood with respect to kernel lengthscales on small datasets can collapse onto narrow lengthscales.

06 Check yourself

Q1Why does Gaussian Process Classification require approximate inference (such as Laplace approximation) whereas GP Regression has a closed-form solution?

Why: In GP regression, Gaussian prior multiplied by Gaussian likelihood yields a Gaussian posterior. In classification, the Bernoulli likelihood is non-conjugate to the Gaussian prior, making the posterior integral intractable.

Q2What occurs to the predicted class probability of a Gaussian Process Classifier when presented with an input far outside the training support?

Why: Far from training data, latent variance sigma_*^2 explodes. The probit convolution factor 1/sqrt(1 + pi/8 * sigma^2) dampens the latent mean toward zero, reverting the probability safely to 0.50.
