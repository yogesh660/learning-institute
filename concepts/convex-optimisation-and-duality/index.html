01 The idea

In general mathematical optimisation, finding the true global minimum is notoriously difficult because objectives are riddled with deceptive local valleys, plateaus, and saddle points. Convex optimisation defines the boundary of tractable mathematics: when both the objective function and constraint sets are convex, any local minimum is guaranteed to be a global minimum. Lagrange duality transforms difficult constrained primal problems into convex dual problems, providing certificates of optimality and foundational insights for algorithms like Support Vector Machines and LASSO.

Imagine walking through a hilly landscape shrouded in thick fog. If you are standing in a general non-convex terrain (like a mountain range full of craters and ravines), walking downhill until the slope is zero only lands you at the bottom of whichever small ditch you happened to step into—you have no idea if a much deeper valley lies just over the next ridge. But if the terrain is a giant smooth bowl (a convex function), gravity guarantees that descending in any downhill direction leads inexorably to the single lowest point in the entire landscape.

Real-world machine learning models must satisfy constraints—such as capping budget, enforcing non-negative weights, or bounding classification margins. A constrained problem asks: "What is the lowest point inside a fenced-off boundary?" Directly navigating the boundary fence in the primal space can be cumbersome.

Duality approaches the problem from the outside in. Imagine wanting to prove that a manufacturing cost cannot possibly fall below £500, no matter which choices you make. Instead of testing millions of designs, you construct a lower bound function (the Lagrange dual function) by adding penalty multipliers for each constraint. By maximising this lower bound across all possible multipliers (the dual problem), you push the floor upward until it meets the primal ceiling. Under standard conditions (such as Slater's condition), the dual maximum equals the primal minimum exactly—a phenomenon called strong duality ($p^* = d^*$). The difference between primal and dual objectives, the duality gap, acts as a real-time certificate proving how close any candidate solution is to true optimality.

In everyday terms

Verifying the exact floor of a subterranean cave by measuring how high you can raise a flat hydraulic jack from below until it firmly touches the bedrock ceiling above.

02 Step by step

  1. Verify convexity: ensure the objective function $f_0(x)$ is convex (its Hessian $\\nabla^2 f_0(x) \\succeq 0$ is positive semidefinite) and the constraint set is convex (convex inequalities $f_i(x) \\le 0$ and affine equalities $Ax = b$).
  2. Formulate the primal Lagrangian function by attaching Lagrange multipliers: $L(x, \\lambda, \\nu) = f_0(x) + \\sum_{i=1}^m \\lambda_i f_i(x) + \\sum_{j=1}^p \\nu_j (a_j^T x - b_j)$ with dual feasibility $\\lambda_i \\ge 0$.
  3. Derive the Lagrange dual function $g(\\lambda, \\nu) = \\inf_x L(x, \\lambda, \\nu)$ by finding the unconstrained infimum over $x$.
  4. Formulate the dual optimisation problem: $\\max_{\\lambda, \\nu} g(\\lambda, \\nu)$ subject to $\\lambda \\ge 0$. Note that $g(\\lambda, \\nu)$ is always concave, making the dual problem convex even if the primal is non-convex.
  5. Check constraint qualifications (e.g. Slater's condition: existence of a strictly feasible point where $f_i(\\tilde{x}) < 0$) to confirm strong duality ($p^* = d^*$).
  6. Solve the dual problem using dual ascent, interior-point methods, or coordinate descent, monitoring the duality gap $|f_0(x) - g(\\lambda, \\nu)| \\to 0$ as a stopping criterion.

03 The maths

  1. Convex set and convex function definition

    $$f_0\\big(\\alpha x + (1 - \\alpha) y\\big) \\le \\alpha f_0(x) + (1 - \\alpha) f_0(y) \\quad \\forall \\, \\alpha \\in [0, 1]$$

    A function is convex if the chord connecting any two points on its graph lies above or on the function. For twice-differentiable functions, convexity is equivalent to the Hessian matrix being positive semidefinite: $\\nabla^2 f_0(x) \\succeq 0$.

  2. The Lagrangian and Lagrange dual function

    $$L(x, \\lambda, \\nu) = f_0(x) + \\sum_{i=1}^m \\lambda_i f_i(x) + \\sum_{j=1}^p \\nu_j h_j(x), \qquad g(\\lambda, \\nu) = \\inf_{x} L(x, \\lambda, \\nu)$$

    where $\\lambda_i \\ge 0$. For any feasible primal $x$ and any dual feasible $(\\lambda, \\nu)$, $\\sum \\lambda_i f_i(x) \\le 0$ and $\\sum \\nu_j h_j(x) = 0$, guaranteeing that $g(\\lambda, \\nu) \\le f_0(x)$. Taking the infimum over $x$ establishes weak duality: $d^* \\le p^*$.

  3. Strong duality and Slater's condition

    $$p^* - d^* = 0 \\quad (\\text{zero duality gap})$$

    Strong duality holds for convex optimisation problems if Slater's condition is satisfied: there exists at least one point $\\tilde{x}$ in the relative interior of the domain such that $f_i(\\tilde{x}) < 0$ for all strictly convex inequality constraints and $A\\tilde{x} = b$.

04 Key takeaways

  • In convex optimisation, any local minimum is guaranteed to be a global minimum.
  • The Lagrange dual function $g(\\lambda, \\nu)$ is always concave, making the dual problem convex regardless of primal convexity.
  • Weak duality ($d^* \\le p^*$) always holds; strong duality ($d^* = p^*$) holds when Slater's condition is satisfied.
  • The duality gap $f_0(x) - g(\\lambda, \\nu)$ provides a computable, certified bound on how close an iterate is to the global optimum.

05 In code

python
import numpy as np

# Quadratic program: min 0.5 * x^T Q x - c^T x  subject to A x <= b
Q = np.array([[4.0, 1.0], [1.0, 2.0]])
c = np.array([3.0, 2.0])
A = np.array([1.0, 1.0])
b = 1.0
Q_inv = np.linalg.inv(Q)

# Solve via dual ascent on multiplier lambda >= 0
lam = 0.0
lr = 0.1
for _ in range(120):
    x_opt = Q_inv @ (c - lam * A)
    lam = max(0.0, lam + lr * (A @ x_opt - b))

# Reconstruct primal solution and evaluate duality gap
x_star = Q_inv @ (c - lam * A)
primal_obj = 0.5 * x_star @ Q @ x_star - c @ x_star
dual_obj = -0.5 * (c - lam * A) @ Q_inv @ (c - lam * A) - lam * b
gap = abs(primal_obj - dual_obj)

print(f"Primal optimal x*: {x_star.round(4)}")
print(f"Optimal dual multiplier lambda*: {lam:.4f}")
print(f"Constraint value A x - b: {(A @ x_star - b):.6f}")
print(f"Primal objective: {primal_obj:.4f}")
print(f"Dual objective: {dual_obj:.4f}")
print(f"Duality gap: {gap:.6f}")

Common pitfalls

  • Assuming all machine learning problems are convex: Deep neural networks, matrix factorisation with missing values, and clustering are highly non-convex, meaning duality gaps may remain non-zero and gradient descent can stall in local minima.
  • Failure of strong duality: Without constraint qualifications like Slater's condition, the dual bound can strictly underestimate the primal optimum ($d^* < p^*$), leaving a stubborn duality gap.
  • Unbounded dual functions: If the primal Lagrangian has no lower bound with respect to $x$ for certain multiplier values, the dual function evaluates to $-\\infty$. Enforcing dual domain constraints is essential when deriving analytical duals.
  • Non-unique dual solutions: Even when the primal problem has a unique strictly convex minimiser, the dual problem can have multiple equivalent multiplier configurations if constraints are linearly dependent.

06 Check yourself

Q1What is the most important operational advantage of a strictly convex optimisation problem over a non-convex one?

Why: In a convex function, all sub-level sets are convex. If a point satisfies the zero-gradient condition $\\nabla f(x) = 0$, the geometry guarantees that no other point in the domain can achieve a strictly lower objective value.

Q2What is always true about the Lagrange dual function $g(\\lambda, \\nu) = \\inf_x L(x, \\lambda, \\nu)$?

Why: The dual function is the pointwise infimum of a family of affine functions of $(\\lambda, \\nu)$. Because affine functions are concave and the pointwise infimum of concave functions is always concave, $g(\\lambda, \\nu)$ is concave.

Q3What does Slater's condition require in order to guarantee strong duality ($p^* = d^*$) for a convex optimisation problem?

Why: Slater's condition is a standard constraint qualification. For convex problems, the existence of a strictly feasible point in the interior of the constraint set guarantees that strong duality holds with a zero duality gap.

Q4What is the duality gap in an optimisation algorithm, and how is it used in practice?

Why: Because weak duality guarantees $g(\\lambda, \\nu) \\le p^* \\le f_0(x)$, the gap $f_0(x) - g(\\lambda, \\nu)$ bounds the maximum possible error of the current primal solution from true optimality, providing a rigorous stopping criterion.
