01 The idea

Without memory, an AI agent treats every interaction as a blank-slate event, unable to learn from past mistakes, retain user preferences, or execute long-running tasks. Structuring agent memory requires borrowing cognitive architectures: dividing memory into working memory (scratchpad context), episodic memory (chronological experience logs), and semantic memory (structured knowledge bases).

Language model weights are frozen after training; any knowledge acquired during an interactive session must be stored outside the model weights. The naive approach—stuffing the entire conversation history into the prompt—collapses once context length limits are reached or API costs skyrocket.

A principled agent memory architecture structures retention into distinct functional tiers: 1) Working Memory: the immediate active scratchpad (ReAct thoughts, tool responses); 2) Episodic Memory: logs of past agent runs, recording what goals were attempted, what tools succeeded, and what mistakes were corrected; 3) Semantic Memory: permanent distilled facts, user preferences, and domain rules stored in vector or relational databases and retrieved via semantic similarity.

In everyday terms

Think of human cognition: Working memory is your immediate train of thought while solving an equation. Episodic memory is your vivid recollection of your eighth birthday party or a mistake you made yesterday. Semantic memory is your timeless factual understanding that Paris is the capital of France. An AI agent requires all three systems to act intelligently over time.

02 Step by step

  1. Capture raw interaction events: record user utterances, agent thoughts, tool calls, and observations with timestamps into an append-only event stream.
  2. Maintain active working memory: keep recent turns and uncompleted goals inside the immediate prompt context window.
  3. Extract episodic memories: at task completion, prompt a reflection model to generate an episodic takeaway summary ("What did I learn from this run?").
  4. Index into semantic vector storage: embed facts, entity relationships, and user preferences, indexing them into vector databases with metadata filters.
  5. Query and assemble context: when a new task arrives, retrieve relevant semantic and episodic memories, formatting them into system prompt memory blocks.

03 The maths

  1. Memory Retrieval Relevance Function

    \text{Score}(m) = \alpha \cdot \text{Sim}(q, m) + \beta \cdot \text{Recency}(m) + \gamma \cdot \text{Importance}(m)

    Balances semantic cosine similarity to current query $q$, recency exponential decay, and self-evaluated importance rating.

  2. Recency Decay Formulation

    \text{Recency}(m) = e^{-\lambda (t_{\text{curr}} - t_m)}

    Applies exponential decay over elapsed time $(t_{\text{curr}} - t_m)$ to prioritize fresh memories, scaled by decay rate $\lambda$.

04 Key takeaways

  • Agent memory decouples active working context from long-term episodic and semantic external stores.
  • Memory retrieval ranks memories using a combination of semantic similarity, recency decay, and importance weighting.
  • Reflective episodic summarisation allows agents to learn across sessions without fine-tuning underlying model weights.

05 In code

python
import numpy as np

class AgentMemoryStore:
    """Demonstrates multi-attribute retrieval combining similarity, recency, and importance."""
    def __init__(self):
        self.memories = []

    def add_memory(self, text, embedding, importance, timestamp):
        self.memories.append({
            'text': text,
            'embedding': embedding,
            'importance': importance,
            'timestamp': timestamp
        })

    def retrieve(self, query_emb, current_time, top_k=2, alpha=0.5, beta=0.3, gamma=0.2, decay_rate=0.05):
        scored = []
        for m in self.memories:
            # Cosine similarity
            sim = np.dot(query_emb, m['embedding']) / (np.linalg.norm(query_emb) * np.linalg.norm(m['embedding']))
            # Exponential recency decay
            recency = np.exp(-decay_rate * (current_time - m['timestamp']))
            # Composite score
            score = alpha * sim + beta * recency + gamma * m['importance']
            scored.append((score, m['text']))
        scored.sort(key=lambda x: x[0], reverse=True)
        return scored[:top_k]

# Simulation
np.random.seed(42)
mem_store = AgentMemoryStore()

# Embeddings (dim=3)
q_emb = np.array([1.0, 0.2, 0.1])
mem_store.add_memory("User prefers responses in British English spelling", 
                     np.array([0.9, 0.3, 0.0]), importance=0.9, timestamp=10)
mem_store.add_memory("Yesterday user ordered pizza from Italian kitchen", 
                     np.array([0.1, 0.8, 0.5]), importance=0.3, timestamp=18)
mem_store.add_memory("User requested code examples in Python with typing", 
                     np.array([0.8, 0.1, 0.4]), importance=0.8, timestamp=19)

retrieved = mem_store.retrieve(q_emb, current_time=20, top_k=2)

print("Retrieved Salient Memories for Agent Context:")
for score, text in retrieved:
    print(f"  [Score: {score:.3f}] {text}")

Common pitfalls

  • Allowing memory stores to accumulate conflicting outdated facts without update or invalidation mechanisms.
  • Retrieving irrelevant memories that clutter the context window and distract the agent from the immediate task.

06 Check yourself

Q1What is the difference between episodic memory and semantic memory in an AI agent architecture?

Why: Episodic memory captures sequential personal experiences ("what happened when I ran this script yesterday"), while semantic memory captures general factual concepts.

Q2In cognitive agent memory retrieval (e.g. Generative Agents), what three factors are standardly combined to score memory relevance?

Why: The Stanford Generative Agents architecture demonstrated that weighting semantic fit, recency, and importance produces human-like contextual recall.

Q3Why cannot conversational agents rely entirely on prompt concatenation for long-term memory?

Why: Every added turn inflates input token fees and latency, and eventually hits maximum context window limits, requiring external retrieval systems.
