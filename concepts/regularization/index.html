Regularisation: L1, L2 and Beyond

Penalising complexity so models generalise. L2 shrinks, L1 selects, and early stopping, dropout and pruning do the same job.

01 The idea

Regularisation adds a cost for complexity to the training objective. The model then has to justify every bit of flexibility with a real improvement in fit, which keeps it from memorising noise.

L2 (ridge, weight decay) adds $\lambda\lVert w\rVert_2^2$: weights shrink smoothly toward zero, and correlated features share the load. L1 (lasso) adds $\lambda\lVert w\rVert_1$: weights hit exactly zero, so it selects features. The geometry explains the difference: the L1 ball has corners on the axes, the L2 ball is round.

Many other techniques are regularisation in disguise: limiting tree depth, pruning, early stopping, dropout, data augmentation, and averaging models. Each one restricts how much the model can adapt to the training sample.

In everyday terms

A spending limit on complexity: the model may only buy flexibility it can pay for with genuinely better predictions.

02 Step by step

  1. Standardise features so the penalty is fair.
  2. Choose the penalty type (L2 by default, L1 for selection, both for elastic net).
  3. Tune $\lambda$ on a log grid with cross-validation.
  4. Never penalise the intercept.

04 The maths

  1. Penalised objective

    $$\min_w \;\frac1n\sum_i\ell(y_i, w^\top x_i) + \lambda\,\Omega(w), \qquad \Omega_{L2} = \lVert w\rVert_2^2, \;\; \Omega_{L1} = \lVert w\rVert_1$$

    Equivalently, minimise the loss subject to $\Omega(w) \le t$: a constraint region in weight space.

  2. Bayesian view

    $$\text{L2} \leftrightarrow w_j \sim \mathcal N(0, \tau^2), \qquad \text{L1} \leftrightarrow w_j \sim \text{Laplace}(0, b)$$

    The penalised solution is the MAP estimate under these priors. The Laplace prior’s sharp peak at zero is why L1 produces exact zeros.

05 Key takeaways

  • Regularisation trades a little bias for a lot less variance.
  • Always tune its strength with validation data.
  • Scale matters: unscaled features make the penalty arbitrary.

06 In code

python
import numpy as np
from sklearn.linear_model import Ridge, Lasso
from sklearn.preprocessing import StandardScaler

Xs = StandardScaler().fit_transform(X_tr)
for lam in [0.001, 0.1, 1, 10]:
    r, l = Ridge(alpha=lam).fit(Xs, y_tr), Lasso(alpha=lam / 10, max_iter=10000).fit(Xs, y_tr)
    print(lam, "ridge |w|=%.2f" % np.abs(r.coef_).sum(), "lasso nonzero=%d" % (l.coef_ != 0).sum())

Common pitfalls

  • Penalising without scaling features first.
  • Tuning λ on the test set.

07 Check yourself

Q1Which penalty can set weights exactly to zero?

Why: The L1 constraint region has corners on the axes.

Q2Early stopping in gradient descent acts like:

Why: It limits how far weights move from their initialisation, similar to an L2 penalty.

Q3Why must the intercept (bias term $w_0$) NOT be penalised in regularised regression?

Why: The intercept merely centres the regression plane at the target mean. Penalising it shifts predictions towards zero without providing any protection against overfitting feature slopes.

Q4Why is feature standardisation (e.g. using StandardScaler) mandatory before applying L1 or L2 regularisation?

Why: If feature 1 is in metres ($w_1 = 1$) and feature 2 is in millimetres ($w_2 = 0.001$), the penalty $\lambda w_1^2 = \lambda$ penalises feature 1 a million times more than feature 2 despite measuring the exact same physical quantity.

Q5Geometric intuition: why does the L1 penalty (Lasso) set coefficients exactly to zero, while the L2 penalty (Ridge) only shrinks them smoothly?

Why: The diamond-shaped $L_1$ ball has sharp corners where one or more coordinates are zero. As smooth elliptical loss contours expand from the unconstrained OLS minimum, they almost always touch an $L_1$ vertex first.

Q6From a Bayesian perspective, L2 regularisation (Ridge) corresponds to Maximum A Posteriori (MAP) estimation under which prior distribution on the weights?

Why: Under a Gaussian prior $p(w) \propto \exp\left(-\frac{\lVert w\rVert_2^2}{2\tau^2}\right)$, taking the negative logarithm yields $\frac{1}{2\tau^2}\lVert w\rVert_2^2$, which is identical to the L2 penalty with $\lambda = 1/\tau^2$.

Q7When two input features $X_1$ and $X_2$ are strongly collinear, how do L1 (Lasso) and L2 (Ridge) regularisation handle them differently?

Why: The quadratic $L_2$ penalty prefers two moderate weights over one large weight (since $1^2 + 1^2 = 2 < 2^2 + 0^2 = 4$). The linear $L_1$ penalty has no preference between $(1, 1)$ and $(2, 0)$, so numerical noise leads it to pick one arbitrarily.

Q8What is Elastic Net regularisation, and when is it preferred over pure Lasso?

Why: Pure Lasso struggles with multicollinear groups by selecting one at random. Elastic Net's L2 component encourages grouped selection (correlated features enter together), while its L1 component maintains overall sparsity.

Q9How does Dropout in deep neural networks act as a form of regularisation?

Why: Dropout prevents neurons from relying on idiosyncratic co-dependencies with specific neighbours. Each iteration trains a thinned network, and testing averages their collective behaviour.

Q10For a 2D weight vector $w = [3.0, -4.0]$, what are the L1 norm $\lVert w\rVert_1$, the L2 norm squared $\lVert w\rVert_2^2$, and the Elastic Net penalty with $\lambda_1 = 2.0$ and $\lambda_2 = 0.5$ ($\Omega(w) = \lambda_1 \lVert w\rVert_1 + \lambda_2 \lVert w\rVert_2^2$)?

Why: $\lVert w\rVert_1 = |3.0| + |-4.0| = 3.0 + 4.0 = 7.0$. $\lVert w\rVert_2^2 = 3.0^2 + (-4.0)^2 = 9.0 + 16.0 = 25.0$. Elastic Net penalty $= \lambda_1 \lVert w\rVert_1 + \lambda_2 \lVert w\rVert_2^2 = 2.0(7.0) + 0.5(25.0) = 14.0 + 12.5 = 26.5$.

Q11In coordinate descent for Lasso regression with orthonormal features, the update rule uses the soft-thresholding operator $S_\lambda(\hat{w}) = \operatorname{sign}(\hat{w})\max(0, |\hat{w}| - \lambda)$. If the unregularised OLS coefficients are $\hat{w}_1 = 2.50$ and $\hat{w}_2 = -0.60$, what are their Lasso estimates when penalty threshold is $\lambda = 1.00$?

Why: For $\hat{w}_1 = 2.50$: $|\hat{w}_1| = 2.50 > 1.00$, so $S_1(2.50) = \operatorname{sign}(2.50)(2.50 - 1.00) = +1.50$. For $\hat{w}_2 = -0.60$: $|\hat{w}_2| = 0.60 \le 1.00$, so $\max(0, 0.60 - 1.00) = 0$, giving $S_1(-0.60) = 0.00$. The parameter whose unregularised magnitude is smaller than $\lambda$ is truncated exactly to zero.

Q12In a 1D linear regression with orthonormal data ($x^\top x = 1$), the OLS estimate is $\hat{w}_{\text{OLS}} = 6.0$. In Ridge regression, the estimate is $\hat{w}_{\text{Ridge}} = \frac{\hat{w}_{\text{OLS}}}{1 + \lambda}$. If $\lambda = 2.0$, what is the Ridge estimate, and by what percentage is the OLS weight shrunk?

Why: $\hat{w}_{\text{Ridge}} = \frac{6.0}{1 + 2.0} = \frac{6.0}{3.0} = 2.0$. The weight is reduced from $6.0$ to $2.0$, a drop of $4.0$, which corresponds to a shrinkage of $\frac{4.0}{6.0} = \frac{2}{3} \approx 66.7\%$.
