Gradient Boosting Regression (GBM)

01 The idea

Start with a constant prediction. Fit a small tree to the residuals, add a shrunken copy of it to the model, recompute the residuals, and repeat. Each tree fixes a bit of what the previous ones got wrong.

For squared error, the residuals $y - \hat y$ are exactly the negative gradient of the loss with respect to the prediction. So fitting a tree to residuals is gradient descent, not on weights, but in "function space". Swap the loss and you get boosting for absolute error, quantiles or classification, with the same algorithm.

The learning rate $\eta$ shrinks each tree’s contribution. Small $\eta$ with many trees almost always generalises better than large $\eta$ with few. Unlike a random forest, boosting can overfit if you add too many trees, so early stopping on a validation set is standard.

In everyday terms

A team of editors working in sequence, each one fixing only the mistakes the previous editors left behind.

02 How it works

  1. Initialise $F_0(x) = \bar y$.
  2. Compute pseudo-residuals $r_i = -\partial L/\partial F(x_i)$; for squared error that is $y_i - F(x_i)$.
  3. Fit a shallow regression tree to the pseudo-residuals.
  4. Update $F_m = F_{m-1} + \eta \cdot \text{tree}_m$.
  5. Repeat; stop when validation error stops improving.

Things to try
  1. Press Step a few times: each tree targets what is left in the residual plot.
  2. Set the learning rate to 1.0 and watch training error fall fast while the fit gets jagged.
  3. Use depth 1 trees (stumps): many more rounds are needed, but the result is smooth.

04 The maths

  1. Stage-wise additive model

    $$F_M(x) = F_0(x) + \eta\sum_{m=1}^M h_m(x)$$

    Each $h_m$ is a small tree. Nothing is ever refitted; the model only grows.

  2. Gradient in function space

    $$r_{im} = -\left.\frac{\partial L(y_i, F(x_i))}{\partial F(x_i)}\right|_{F = F_{m-1}}, \qquad L = \tfrac12(y - F)^2 \Rightarrow r_{im} = y_i - F_{m-1}(x_i)$$

    Each tree approximates the direction of steepest descent of the loss, evaluated at the training points.

06 When to use it

Strengths

  • State-of-the-art on tabular data.
  • Flexible loss functions.
  • Handles mixed features and interactions without scaling.

Limitations

  • Sequential, so slower to train than a forest.
  • Several interacting hyperparameters.
  • Can overfit with too many rounds.

Reach for it when

Tabular problems where accuracy matters and you can afford some tuning.

Think twice when

Very small data where a simpler model is easier to trust, or when you need extrapolation.

Common pitfalls

  • Using a large learning rate to save time; it usually costs accuracy.
  • Running without early stopping and over-fitting quietly.

09 Check yourself

Q1For squared-error loss, each new tree in gradient boosting is fitted to:

Why: Residuals are the negative gradient of squared error with respect to the predictions.

Q2Lower learning rate, same number of trees: what typically happens?

Why: Each tree contributes less, so more rounds are needed to reach the same fit, though the final model usually generalises better.

Q3What is the standard initial prediction $F_0(x)$ in Gradient Boosting for regression under squared-error loss?

Why: Gradient boosting begins with the best constant prediction that minimises the chosen loss function. For squared-error loss, the constant that minimises $\sum (y_i - c)^2$ is the sample mean $\bar{y}$.

Q4Why is Gradient Boosting called gradient descent in "function space"?

Why: In parametric gradient descent, $\theta_{m} = \theta_{m-1} - \eta \nabla_\theta L$. In boosting, $F_m(x) = F_{m-1}(x) + \eta h_m(x)$, where $h_m(x)$ is a tree approximating the negative gradient vector $-\nabla_F L$.

Q5Unlike Random Forests, why does Gradient Boosting require early stopping or careful tuning of n_estimators?

Why: Random forest trees are trained independently on bootstrap samples, so adding trees simply averages variance. Gradient boosting sequentially chases residuals; with enough iterations, it can overfit training noise down to zero error.

Q6What is "shrinkage" (learning rate $\eta$) in gradient boosting, and why is setting $\eta \le 0.1$ standard best practice?

Why: Friedman showed that shrinking each tree by $\eta \in [0.01, 0.1]$ significantly improves out-of-sample performance. Smaller steps require more trees, but the additive path explores the parameter space much more smoothly.

Q7When training GradientBoostingRegressor with loss='absolute_error' (MAE), what are the pseudo-residuals $r_i$ fitted by each tree?

Why: The loss is $L = |y - F|$. Its negative derivative with respect to $F$ is $-\frac{\partial |y - F|}{\partial F} = \operatorname{sign}(y - F)$. Thus each tree is trained to predict whether the current model under- or over-estimates each sample.

Q8What is "Stochastic Gradient Boosting" (setting subsample < 1.0 in GradientBoostingRegressor)?

Why: Friedman's stochastic gradient boosting samples a fraction of rows (e.g. 0.8) without replacement for each round. This injects beneficial variance into tree generation and prevents the ensemble from over-relying on influential training rows.

Q9Why do practitioners typically use shallow trees (e.g. max_depth=3 to 5) as base learners in gradient boosting, rather than deep trees (depth 15+)?

Why: A depth-3 tree captures up to 3-way feature interactions with low variance. Combining hundreds of low-variance weak learners allows boosting to build a flexible composite model without the explosive overfitting risk of deep trees.

Q10An observation has true target $y = 25.0$. The initial model prediction is $F_0 = 15.0$. In round 1, a regression tree is fitted to the residuals and predicts $h_1(x) = 8.0$. If the learning rate is $\eta = 0.20$, what are the updated prediction $F_1(x)$ and the new residual $r_2$ for round 2 under squared error?

Why: Round 1 residual: $r_1 = y - F_0 = 25.0 - 15.0 = 10.0$. Model update: $F_1(x) = F_0(x) + \eta h_1(x) = 15.0 + 0.20(8.0) = 15.0 + 1.60 = 16.60$. Round 2 residual: $r_2 = y - F_1(x) = 25.0 - 16.60 = 8.40$.

Q11Under Huber loss with threshold $\delta = 3.0$, the negative gradient pseudo-residual is $r_i = y_i - F(x_i)$ when $|y_i - F(x_i)| \le \delta$, and $r_i = \delta \operatorname{sign}(y_i - F(x_i))$ when $|y_i - F(x_i)| > \delta$. For two points with errors $e_1 = +2.0$ and $e_2 = -10.0$, what are their pseudo-residuals?

Why: For $e_1 = +2.0$: $|e_1| = 2.0 \le \delta = 3.0$, so $r_1 = e_1 = +2.0$. For $e_2 = -10.0$: $|e_2| = 10.0 > 3.0$, so $r_2 = \delta \operatorname{sign}(-10.0) = 3.0 \times (-1) = -3.0$. Huber loss clips the pseudo-residual of the outlier at $-3.0$, protecting subsequent trees from extreme gradient swings.

Q12A gradient boosting model uses learning rate $\eta = 0.10$ and squared error loss. After initialising at $F_0 = 20.0$, three consecutive trees predict $h_1(x) = 10.0$, $h_2(x) = 8.0$, and $h_3(x) = 6.0$ for a test point $x$. What is the final prediction $F_3(x)$?

Why: Additive update: $F_3(x) = F_0(x) + \eta(h_1(x) + h_2(x) + h_3(x)) = 20.0 + 0.10(10.0 + 8.0 + 6.0) = 20.0 + 0.10(24.0) = 20.0 + 2.40 = 22.40$.
