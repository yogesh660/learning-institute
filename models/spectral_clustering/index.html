Spectral Clustering

Turns the data into a similarity graph, embeds it with eigenvectors of the graph Laplacian, then runs k-means there.

01 The idea

Build a graph where similar points are connected. The eigenvectors of its Laplacian give each point new coordinates in which tightly connected groups become compact blobs. Run k-means on those coordinates.

Two interleaved crescents defeat k-means in the original space, but in the graph each crescent is a chain of strong connections with only weak links between them. Spectral clustering finds a cut of the graph that separates groups while cutting as few strong edges as possible (normalised cut).

Solving that exactly is NP-hard; relaxing it gives an eigenvector problem. The first few eigenvectors of the normalised Laplacian are nearly constant within each well-connected group, so plotted they look like tight, separate blobs.

In everyday terms

Finding communities in a social network by who talks to whom, not by where people live.

02 How it works

  1. Build an affinity matrix $W$ (RBF kernel or k-nearest-neighbour graph).
  2. Compute the normalised Laplacian $L_{\text{sym}} = I - D^{-1/2}WD^{-1/2}$.
  3. Take the $k$ eigenvectors with the smallest eigenvalues; normalise rows.
  4. Run k-means on the rows of this embedding.

04 The maths

  1. Graph Laplacian

    $$W_{ij} = e^{-\gamma\lVert x_i - x_j\rVert^2},\quad D_{ii} = \sum_jW_{ij},\quad L_{\text{sym}} = I - D^{-1/2}WD^{-1/2}$$

    $L$ is positive semi-definite; the number of zero eigenvalues equals the number of connected components.

  2. Normalised cut relaxation

    $$\min_{A}\;\text{Ncut}(A, \bar A) = \frac{\text{cut}(A,\bar A)}{\text{vol}(A)} + \frac{\text{cut}(A,\bar A)}{\text{vol}(\bar A)} \;\;\leadsto\;\; \min_{U^\top U = I}\operatorname{tr}(U^\top L_{\text{sym}}U)$$

    The relaxed problem is solved by the bottom eigenvectors.

06 When to use it

Strengths

  • Finds non-convex clusters.
  • Works from any similarity matrix (graphs, kernels).
  • Strong theory.

Limitations

  • Dense eigendecomposition is $O(n^3)$; memory $O(n^2)$.
  • Sensitive to the affinity parameter.
  • Still needs k.

Reach for it when

Non-convex shapes in small to medium data, image segmentation, community detection.

Think twice when

Large datasets without sparse graphs and approximate eigensolvers.

from sklearn.datasets import make_moons
from sklearn.cluster import SpectralClustering, KMeans

X, _ = make_moons(400, noise=0.06, random_state=0)
spec = SpectralClustering(2, affinity="nearest_neighbors", n_neighbors=10, random_state=0).fit_predict(X)
km = KMeans(2, n_init=10, random_state=0).fit_predict(X)   # compare: k-means cuts straight across

Common pitfalls

  • Using an RBF $\gamma$ so small that everything connects, or so large that nothing does.

09 Check yourself

Q1Why does spectral clustering succeed on two crescents?

Why: Points in a crescent are connected through neighbours even if the crescent’s ends are far apart.

Q2The number of zero eigenvalues of a graph Laplacian equals:

Why: Each component contributes one constant-on-component eigenvector with eigenvalue 0.

Q3At what stage of spectral clustering is the $k$-means algorithm actually executed?

Why: Spectral clustering uses graph Laplacian eigenvectors as a non-linear dimensionality reduction step to project points into an embedding where manifolds become compact, linearly separable clusters. Standard $k$-means is then run on these low-dimensional eigenvector coordinates.

Q4Why does standard SpectralClustering in scikit-learn provide a fit_predict method but no predict method for new, unseen points?

Why: The Laplacian eigenvectors are defined over the $n$ discrete graph nodes. A new query point is not a node in the original graph, so its embedding coordinates cannot be computed without re-solving or extending the graph eigendecomposition (e.g. via the Nyström method).

Q5Three points form a simple linear graph with edge weights $W_{12} = 1.0$ and $W_{23} = 1.0$ (with $W_{13} = 0.0$ and zero diagonal). What is the second row of the unnormalised graph Laplacian $L = D - W$?

Why: Node 2 connects to node 1 and node 3, giving degree $D_{22} = 1.0 + 1.0 = 2.0$. Row 2 of $W$ is $[1.0, 0.0, 1.0]$. Subtracting $W$ from $D$ gives $L_{2} = [-1.0, \, 2.0, \, -1.0]$. Note that every row of an unnormalised Laplacian sums to exactly zero.

Q6How does the "eigengap heuristic" help a practitioner choose the optimal number of clusters $k$ in spectral clustering?

Why: By spectral graph theory, a graph with $k$ completely disconnected components has exactly $k$ eigenvalues equal to 0, followed by a jump $\lambda_{k+1} > 0$. In real-world graphs with weak inter-cluster connections, a prominent gap between $\lambda_k$ and $\lambda_{k+1}$ strongly suggests $k$ well-separated clusters.

Q7When using the RBF kernel affinity $W_{ij} = \exp(-\gamma \|x_i - x_j\|^2)$, what happens if the parameter $\gamma$ is chosen to be excessively large?

Why: When $\gamma$ is very large, the exponential decay is so steep that even close neighbours have distance squared scaled up, making $W_{ij} \approx 0$ for all distinct pairs. The graph fragments into disconnected individual vertices, destroying clustering signals.

Q8Why does standard spectral clustering with a dense affinity matrix scale poorly to large datasets with $n > 50,000$ points?

Why: Storing an $n \times n$ pairwise affinity matrix requires $O(n^2)$ memory (several gigabytes at $n = 50{,}000$), while standard exact eigensolvers take $O(n^3)$ operations. For large datasets, practitioners must switch to sparse $k$-nearest-neighbour graphs and iterative eigensolvers (like Lanczos).

Q9Why does spectral clustering optimise the Normalised Cut (Ncut) objective rather than the simpler Minimum Cut (min-cut) objective?

Why: Min-cut only minimises the sum of cut edge weights $\text{cut}(A, \bar{A})$, which frequently cuts off a lone isolated vertex. Normalised Cut divides by the total volume $\text{vol}(A) = \sum_{i \in A} d_i$, heavily penalising lopsided partitions and encouraging balanced, meaningful communities.

Q10For any undirected graph with non-negative edge weights and unnormalised Laplacian $L = D - W$, what is the result of multiplying $L$ by the all-ones vector $\mathbf{1} = [1, 1, \dots, 1]^\top$?

Why: For each row $i$, $(L\mathbf{1})_i = D_{ii} - \sum_j W_{ij}$. By definition, the degree is $D_{ii} = \sum_j W_{ij}$, so $(L\mathbf{1})_i = D_{ii} - D_{ii} = 0$. Thus $L\mathbf{1} = 0\cdot \mathbf{1}$, demonstrating that $\mathbf{1}$ is always an eigenvector associated with eigenvalue $\lambda = 0$.

Q11Under the symmetric normalised Laplacian $L_{\text{sym}} = I - D^{-1/2} W D^{-1/2}$, two connected nodes have degrees $d_1 = 4.0$ and $d_2 = 9.0$, with edge weight $W_{12} = 3.0$. What is the off-diagonal matrix entry $(L_{\text{sym}})_{12}$?

Why: For $i \neq j$, $I_{ij} = 0$, so $(L_{\text{sym}})_{ij} = -\frac{W_{ij}}{\sqrt{d_i d_j}}$. Substituting the values: $-\frac{3.0}{\sqrt{4.0 \times 9.0}} = -\frac{3.0}{\sqrt{36.0}} = -\frac{3.0}{6.0} = -0.50$.

Q12In spectral graph bisection ($k = 2$ using the unnormalised Laplacian $L$), what role does the eigenvector $v_2$ associated with the second smallest eigenvalue $\lambda_2$ (the Fiedler vector) play?

Why: The smallest eigenvalue $\lambda_1 = 0$ corresponds to the trivial constant eigenvector $v_1 = \mathbf{1}$. The second eigenvector $v_2$ (the Fiedler vector) is orthogonal to $\mathbf{1}$ and solves the continuous relaxation of the graph bisection problem. Splitting nodes based on the sign of their component in $v_2$ yields the optimal relaxed cut.
