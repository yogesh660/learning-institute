Elastic Net Regression

A blend of ridge and lasso: sparse like lasso, but keeps groups of correlated features together like ridge.

01 The idea

Elastic net adds both penalties, $\lambda\big(\alpha\lVert\beta\rVert_1 + \tfrac{1-\alpha}{2}\lVert\beta\rVert_2^2\big)$. One dial ($\lambda$) controls how strong the penalty is; the other ($\alpha$, l1_ratio) controls the mix.

Lasso has two known weaknesses: with correlated features it picks one at random, and when there are more features than rows it can keep at most $n$ of them. Adding a little L2 fixes both. The L2 part makes the problem strictly convex, so correlated features share weight; the L1 part still zeroes out the ones that do not help.

In practice elastic net is the safe default for wide data (genomics, text, many engineered features): you get sparsity without lasso’s instability.

In everyday terms

An editor who cuts weak sentences (L1) but, when two sentences say the same thing well, keeps both in shortened form (L2).

02 How it works

  1. Standardise the features.
  2. Pick a grid for l1_ratio (e.g. 0.1, 0.5, 0.9, 1.0) and for $\lambda$.
  3. Fit by coordinate descent; each update is a soft-threshold divided by $(1 + \lambda(1-\alpha))$.
  4. Cross-validate both dials together (ElasticNetCV does this).

03 Try it

Same polynomial set-up as ridge and lasso. Two sliders: the penalty strength and the L1/L2 mix.

Things to try
  1. Set the mix to 1.0 (pure lasso), note the zero bars, then slide toward 0 and watch them come back as small values.
  2. Find a mix where the fit is good and only about half the terms are active.

04 The maths

  1. Objective

    $$\min_\beta \frac{1}{2n}\lVert y - X\beta\rVert_2^2 + \lambda\Big(\alpha\lVert\beta\rVert_1 + \frac{1-\alpha}{2}\lVert\beta\rVert_2^2\Big)$$

    $\alpha = 1$ gives lasso, $\alpha = 0$ gives ridge.

  2. Coordinate update

    $$\beta_j \leftarrow \frac{S\!\left(\tfrac1n x_j^\top r_{(j)},\; \lambda\alpha\right)}{\tfrac1n x_j^\top x_j + \lambda(1-\alpha)}$$

    The numerator is lasso’s soft-threshold; the extra term in the denominator is ridge’s shrinkage.

06 When to use it

Strengths

  • Sparse and stable at the same time.
  • Handles $p \gg n$ and correlated groups.
  • Includes ridge and lasso as special cases, so tuning can only help.

Limitations

  • Two hyperparameters to tune.
  • Still linear.
  • Coefficients are doubly shrunk, so less interpretable as effect sizes.

Reach for it when

Wide data with correlated feature groups where you still want a compact model.

Think twice when

Small, clean, low-dimensional problems where OLS or ridge is enough.

07 In code

python
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import ElasticNetCV

model = make_pipeline(StandardScaler(),
                      ElasticNetCV(l1_ratio=[.1, .5, .7, .9, .95, 1], cv=5, random_state=0))
model.fit(X_tr, y_tr)
enet = model[-1]
print("alpha", enet.alpha_, "l1_ratio", enet.l1_ratio_)

Common pitfalls

  • Confusing the names: scikit-learn calls the strength alpha and the mix l1_ratio, while many papers use $\lambda$ and $\alpha$.
  • Tuning only one dial while leaving the other at its default.

09 Check yourself

Q1Elastic net with l1_ratio = 1 is equivalent to:

Why: The L2 share is $1 - 1 = 0$, leaving only the L1 penalty.

Q2What does the L2 part add over plain lasso?

Why: The strictly convex L2 term rewards splitting weight evenly among similar features.

Q3What does setting l1_ratio = 0 correspond to in Elastic Net regression?

Why: Setting l1_ratio = 0 zeroes out the L1 regularisation component, leaving solely the quadratic $\frac{1}{2}\lVert\beta\rVert_2^2$ penalty, which is standard Ridge regression.

Q4In the mathematical formulation of Elastic Net, what is the role of the overall penalty strength $\lambda$ (called alpha in scikit-learn)?

Why: The multiplier $\lambda$ dictates the overall penalty scale; setting $\lambda = 0$ reduces Elastic Net to unregularised OLS, while increasing $\lambda$ shrinks all coefficients towards zero.

Q5What limitation does standard Lasso encounter when features outnumber samples ($p > n$), and how does Elastic Net resolve it?

Why: Because of the geometry of the L1 ball, standard Lasso cannot select more than $n$ non-zero predictors when $p > n$. The strictly convex L2 penalty in Elastic Net removes this rank constraint, allowing it to select all relevant correlated features.

Q6Why is feature standardisation essential before fitting an Elastic Net model?

Why: The regularisation penalty treats all coefficient magnitudes identically. An unscaled feature measured in large units will have artificially tiny coefficients that get penalised unfairly compared to features on smaller scales.

Q7In the coordinate descent update for Elastic Net, how does the soft-thresholding operator interact with the L2 regularisation term?

Why: In coordinate descent, L1 provides the soft-thresholding numerator $S(\frac{1}{n}x_j^\top r_{(j)}, \lambda\alpha)$, while the quadratic curvature from L2 adds $\lambda(1-\alpha)$ to the denominator, shrinking the non-zero updates smoothly.

Q8When tuning an Elastic Net model in scikit-learn using ElasticNetCV, why is it best practice to cross-validate l1_ratio and alpha jointly?

Why: The amount of shrinkage needed to balance bias and variance changes dramatically depending on whether the penalty is predominantly L1 or L2; tuning them on a 2D grid captures their strong mutual interaction.

Q9Suppose two features $x_1$ and $x_2$ are perfectly collinear ($x_1 = x_2$). How do pure Lasso ($\alpha = 1$) and Elastic Net ($\alpha = 0.5$) distribute their coefficients?

Why: Lasso's non-strictly-convex objective is indifferent to any split satisfying $\beta_1 + \beta_2 = c$, often assigning all weight to whichever feature appears first. The strictly convex L2 term in Elastic Net uniquely minimises $\beta_1^2 + \beta_2^2$ by splitting weight equally ($\beta_1 = \beta_2 = c/2$).

Q10Consider a standardised feature with $\frac{1}{n} x_1^\top x_1 = 1$ and correlation with the partial residual $\frac{1}{n} x_1^\top r_{(1)} = 3.0$. If Elastic Net is fitted with penalty $\lambda = 2.0$ and mixing ratio $\alpha = 0.5$, what is the updated coefficient $\beta_1$?

Why: The threshold is $\lambda\alpha = 2.0 \times 0.5 = 1.0$. The soft-thresholded numerator is $S(3.0, 1.0) = \operatorname{sign}(3.0)\max(|3.0| - 1.0, 0) = 2.0$. The denominator is $\frac{1}{n}x_1^\top x_1 + \lambda(1-\alpha) = 1.0 + 2.0(1 - 0.5) = 2.0$. Thus $\beta_1 = 2.0 / 2.0 = 1.0$.

Q11For a standardised feature with $\frac{1}{n} x_j^\top x_j = 1$ and inner product $\frac{1}{n} x_j^\top r_{(j)} = 1.2$, what is the minimum value of $\lambda$ under mixing parameter $\alpha = 0.8$ that forces coefficient $\beta_j$ to zero?

Why: The soft-thresholding condition sets $\beta_j = 0$ if and only if $|\frac{1}{n} x_j^\top r_{(j)}| \le \lambda\alpha$. Here $1.2 \le \lambda \times 0.8 \iff \lambda \ge 1.2 / 0.8 = 1.50$.

Q12Why does naive Elastic Net suffer from double shrinkage, and how did Zou & Hastie (2005) correct this in the final Elastic Net estimator?

Why: In naive Elastic Net, the L1 penalty shrinks estimates towards zero and the L2 denominator divides them further. To undo this excessive shrinkage and bias while keeping the grouping effect and sparsity, the solution is rescaled by $(1 + \lambda(1-\alpha))$.
