Lasso Regression (L1 Regularisation)

01 The idea

Lasso swaps ridge’s squared penalty for an absolute-value one, $\lambda\lVert\beta\rVert_1$. That small change means weak features get coefficients of exactly zero: built-in feature selection.

Think of each coefficient as having to pay a flat fee per unit of size. For a feature that only helps a little, the fee is never worth it, so the cheapest choice is to set its weight to precisely zero. Ridge’s fee grows with the square, so it is almost free near zero and nothing ever gets switched off completely.

The geometric picture: the L1 constraint region is a diamond with corners on the axes. The elliptical contours of the squared error usually touch the diamond first at a corner, and a corner means some coefficients are zero. With the round L2 ball there are no corners to hit.

In everyday terms

A strict editor with a word budget: weak sentences are not shortened, they are cut entirely.

02 How it works

  1. Standardise features so the penalty is fair across them.
  2. Minimise squared error plus $\lambda\sum_j|\beta_j|$.
  3. There is no closed form; solve with coordinate descent, cycling through the coefficients and applying soft-thresholding to each one.
  4. Choose $\lambda$ by cross-validation; the non-zero coefficients that remain are your selected features.

03 Try it

The same degree-9 polynomial as in the ridge lesson, now with an L1 penalty, solved live with coordinate descent. Watch coefficient bars snap to zero.

Things to try
  1. Increase $\lambda$ slowly and count how many bars are still non-zero.
  2. Find a $\lambda$ that keeps 3–4 terms and still fits the shape well.
  3. Compare which powers survive at high $\lambda$: lasso keeps the most useful terms, not the lowest ones.

04 The maths

  1. Objective

    $$\hat\beta_{\text{lasso}} = \arg\min_\beta \;\frac{1}{2n}\lVert y - X\beta\rVert_2^2 + \lambda\lVert\beta\rVert_1$$

    The absolute value is not differentiable at zero, which is precisely what lets solutions sit at zero.

  2. Coordinate update: soft-thresholding

    $$\beta_j \leftarrow \frac{S\!\left(\tfrac1n x_j^\top r_{(j)},\; \lambda\right)}{\tfrac1n x_j^\top x_j}, \qquad S(z,\lambda) = \operatorname{sign}(z)\max(|z| - \lambda, 0)$$

    $r_{(j)}$ is the residual ignoring feature $j$. If the feature’s correlation with that residual is smaller than $\lambda$, its coefficient is set to exactly 0.

06 When to use it

Strengths

  • Automatic feature selection gives a sparse, readable model.
  • Works when $p \gg n$.
  • The regularisation path shows the order in which features enter.

Limitations

  • Among a group of correlated features it picks one, somewhat arbitrarily.
  • Selects at most $n$ features when $p > n$.
  • Shrinks the coefficients it keeps, so they are biased.

Reach for it when

You suspect only a few features matter and want the model to tell you which.

Think twice when

Groups of strongly correlated features that should stay together: prefer Elastic net.

07 In code

python
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LassoCV

model = make_pipeline(StandardScaler(), LassoCV(cv=5, random_state=0)).fit(X_tr, y_tr)
lasso = model[-1]
kept = [c for c, w in zip(X.columns, lasso.coef_) if w != 0]
print(f"alpha={lasso.alpha_:.4f}, kept {len(kept)} of {X.shape[1]} features:", kept)

Common pitfalls

  • Treating the selected set as "the true features". With correlated inputs, a slightly different sample can pick a different member of the group.
  • Forgetting to scale, which turns the penalty into a units contest.
  • Reading kept coefficients as unbiased effect sizes. Refit OLS on the selected features if you need that.

09 Check yourself

Q1Why does lasso produce exact zeros while ridge does not?

Why: At zero, the L1 penalty’s slope jumps from $-\lambda$ to $+\lambda$. If the data’s pull on a coefficient is weaker than $\lambda$, zero is the optimum.

Q2Two features are almost identical. Lasso will most likely:

Why: For lasso, splitting weight across duplicates costs as much as putting it on one, with no benefit, so the solution usually concentrates on one of them. Elastic net spreads it.

Q3Soft-thresholding $S(z, \lambda)$ with $z = 0.3, \lambda = 0.5$ returns:

Why: $|z| < \lambda$, so $\max(|z| - \lambda, 0) = 0$.
