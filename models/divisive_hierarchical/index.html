01 The idea

Divisive clustering works top-down. Put everything in one cluster, split it in two, then keep choosing a cluster to split (typically the one with the largest error) until you have $k$.

Agglomerative clustering makes many local decisions first; divisive makes the big decisions first, using the global structure. Bisecting k-means, the practical version, runs 2-means on one cluster at a time, which is fast and tends to produce clusters of more even size than plain k-means.

In everyday terms

Splitting a company into divisions, then each division into departments, always reorganising the largest or messiest unit next.

02 How it works

  1. Start with all points in one cluster.
  2. Pick the cluster to split (largest SSE or largest size).
  3. Split it with 2-means (several trials, keep the best).
  4. Repeat until there are $k$ clusters.

03 Try it

Things to try

04 The maths

  1. Which cluster to split

    $$C^* = \arg\max_{C}\sum_{x \in C}\lVert x - \mu_C\rVert^2$$

    The "biggest inertia" strategy; scikit-learn also offers splitting the largest cluster.

06 When to use it

Strengths

  • Faster than agglomerative on large data.
  • Big decisions use global structure.
  • Produces a hierarchy as a by-product.

Limitations

  • Greedy splits are never revisited.
  • Inherits k-means’ shape assumptions.

Reach for it when

Document clustering and large datasets where you want a hierarchy cheaply.

Think twice when

Non-convex shapes.

07 In code

python
import pandas as pd
from sklearn.preprocessing import StandardScaler

df = pd.read_csv("datasets/raw/mall_customers.csv")
X = StandardScaler().fit_transform(df[["Annual_Income_k", "Spending_Score"]])
from sklearn.cluster import BisectingKMeans

bkm = BisectingKMeans(n_clusters=5, bisecting_strategy="biggest_inertia", random_state=0).fit(X)
print(bkm.labels_[:10])

Common pitfalls

  • Expecting identical results to agglomerative clustering; the trees are built very differently.

09 Check yourself

Q1Bisecting k-means splits which cluster next (default strategy)?

Why: It targets the cluster that explains the most remaining error.

Q2What is the top-down nature of divisive hierarchical clustering compared to agglomerative clustering?

Why: Divisive (top-down) clustering begins with one root cluster containing the entire dataset and iteratively partitions clusters until $k$ leaves or singletons remain.

Q3What core algorithm is typically executed at each step of bisecting k-means to partition a selected cluster?

Why: Bisecting k-means works by running 2-means ($k = 2$) on the selected cluster, splitting it into exactly two sub-clusters at each step.

Q4In scikit-learn's BisectingKMeans, which two strategies can be specified via the bisecting_strategy parameter to choose the next cluster to split?

Why: BisectingKMeans offers two splitting strategies: "biggest_inertia" (splits the cluster with largest sum of squared errors) and "largest_cluster" (splits the cluster containing the most data points).

Q5Why does bisecting k-means often scale much better to large datasets than agglomerative hierarchical clustering?

Why: Agglomerative clustering requires storing and updating an $n \times n$ distance matrix ($O(n^2)$ space, $O(n^2 \log n)$ time). Bisecting k-means only runs fast linear-time 2-means iterations, scaling as $O(n \cdot k \cdot p)$.

Q6What happens when bisecting k-means makes a poor split near the top of the tree?

Why: Like all greedy hierarchical methods, divisive splits are permanent. A point separated into branch A can never be grouped with points in branch B at subsequent levels.

Q7Why does bisecting k-means often produce more evenly sized clusters than standard Lloyd's k-means?

Why: By prioritising clusters with large SSE or large member counts for the next bisection, the algorithm repeatedly breaks down large, dispersed groups while preserving tight, naturally small clusters.

Q8What is the role of the n_init parameter in BisectingKMeans?

Why: Because standard k-means is sensitive to centroid initialisation, running 2-means multiple times (e.g. n_init=3) at each split ensures a robust, high-quality local bisection.

Q9In what scenario would you avoid using bisecting k-means?

Why: Because bisecting k-means uses 2-means at each step, it inherits k-means' linear Voronoi boundary assumption. It cannot trace non-convex shapes like concentric circles or crescents.

Q10To produce a final clustering with $k = 6$ clusters using bisecting k-means, how many individual 2-means bisection splits must be performed?

Why: Every binary split adds exactly one net cluster to the pool. Starting from 1 initial root cluster, achieving $k = 6$ clusters requires exactly $k - 1 = 5$ bisections.

Q11Suppose an intermediate step of bisecting k-means has three active clusters with the following properties: Cluster 1: $n_1 = 100$, SSE $= 240$ Cluster 2: $n_2 = 250$, SSE $= 180$ Cluster 3: $n_3 = 50$, SSE $= 310$ If bisecting_strategy="biggest_inertia" is used, which cluster is chosen for the next split; and which would be chosen if bisecting_strategy="largest_cluster" were used?

Why: biggest_inertia selects the cluster with the highest within-cluster SSE, which is Cluster 3 ($\text{SSE} = 310$). largest_cluster selects the cluster with the largest number of observations, which is Cluster 2 ($n = 250$).

Q12Consider 6 points on a line: $\{0, 2, 4, 20, 22, 24\}$. In the first bisection of bisecting k-means, a 2-means split partitions the data into $\{0, 2, 4\}$ and $\{20, 22, 24\}$. What is the total sum of squared errors (SSE) of this 2-cluster partition?

Why: The centroid of the first group is $\mu_1 = 2$, giving $\text{SSE}_1 = (-2)^2 + 0^2 + 2^2 = 8$. The centroid of the second group is $\mu_2 = 22$, giving $\text{SSE}_2 = (-2)^2 + 0^2 + 2^2 = 8$. Total inertia is $8 + 8 = 16$.
