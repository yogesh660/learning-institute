OPTICS (Ordering Points To Identify Clustering Structure)

01 The idea

OPTICS does not output clusters directly. It outputs an ordering of the points and a reachability distance for each, which, plotted, shows clusters as valleys. Cutting the plot at a height gives a DBSCAN clustering for that $\varepsilon$; the Xi method finds valleys automatically.

OPTICS walks through the data always moving to the closest unvisited point in density terms. Inside a cluster, the next point is close, so reachability is low; jumping to a new cluster requires a big step, which shows as a spike. The plot is a fingerprint of the data’s density structure at all scales at once.

In everyday terms

Walking through a city always to the nearest unvisited house and logging how far each step was; neighbourhoods are runs of short steps.

02 How it works

  1. Compute core distances.
  2. Start from an unvisited point; maintain a priority queue of reachability distances to its neighbours.
  3. Repeatedly visit the point with the smallest reachability, updating the queue.
  4. Plot reachability in visit order; extract clusters by a horizontal cut or with Xi.

03 Try it

Left: points coloured by the clusters extracted at your cut. Right: the reachability plot in OPTICS order, with the cut line.

Things to try
  1. Move the cut down: deep valleys split into sub-clusters.
  2. Move it up: neighbouring valleys merge.

04 The maths

  1. Reachability distance

    $$\text{reach}(o, p) = \max\{\text{core}(p),\; d(p, o)\}$$

    The distance at which $o$ becomes reachable from core point $p$.

05 Hyperparameters

SettingWhat it doesTypical choice
min_samplesDensity neighbourhood size.5–20.
max_epsLargest radius considered.Inf (default) or a limit for speed.
cluster_method, xiHow clusters are extracted.xi with 0.01–0.1, or dbscan with eps.

06 When to use it

Strengths

  • Reveals structure at all density scales in one run.
  • Handles varying densities better than DBSCAN.

Limitations

  • Slower than DBSCAN.
  • Extracting clusters from the plot needs another parameter.

Reach for it when

Exploring data with unknown or varying density; when you want to look at the structure before committing.

Think twice when

Large data with tight time budgets.

07 In code

python
import pandas as pd
from sklearn.preprocessing import StandardScaler

df = pd.read_csv("datasets/raw/mall_customers.csv")
X = StandardScaler().fit_transform(df[["Annual_Income_k", "Spending_Score"]])
from sklearn.cluster import OPTICS
import matplotlib.pyplot as plt

opt = OPTICS(min_samples=10, xi=0.05).fit(X)
plt.plot(opt.reachability_[opt.ordering_]); plt.ylabel("reachability"); plt.show()
print("clusters:", len(set(opt.labels_)) - (-1 in opt.labels_))

Common pitfalls

  • Reading every small dip as a cluster; look for valleys with enough points.

09 Check yourself

Q1In a reachability plot, a cluster appears as:

Why: Points inside a dense region are reached with small distances.

Q2What two primary outputs does the OPTICS algorithm compute to represent the multi-scale density structure of a dataset?

Why: OPTICS does not output explicit flat clusters directly; it generates an ordering of observations (ordering_) alongside reachability distances (reachability_) whose plot displays the entire density landscape.

Q3How is reachability distance $\text{reach}(o, p)$ defined from a core point $p$ to an observation $o$?

Why: The reachability distance from core point $p$ to $o$ is $\max\{\text{core}(p), d(p, o)\}$. It cannot be smaller than $p$'s core distance, which prevents sparse points from appearing prematurely close.

Q4In a reachability plot, what do sharp peaks (spikes of high reachability distance) between two valleys signify?

Why: Inside a cluster, reachability is low because neighbouring points are close. Moving to a new cluster or jumping across sparse noise requires a large step, creating a sharp upward spike in the plot.

Q5How can flat clusters equivalent to DBSCAN clusterings at a specific radius $\varepsilon$ be extracted from an OPTICS ordering?

Why: Cutting an OPTICS reachability plot with a horizontal threshold line at height $\varepsilon$ directly extracts the connected components that DBSCAN would find with that same $\varepsilon$.

Q6What is the purpose of the $\xi$ (Xi) parameter in scikit-learn's OPTICS(cluster_method="xi")?

Why: The $\xi$ (Xi) extraction method detects clusters as valleys bounded by steep downward and upward slopes. $\xi$ defines the minimum relative steepness ($1 - \xi$) required to recognise a cluster boundary.

Q7What happens if a point $p$ has fewer than min_samples neighbours within max_eps?

Why: If a point does not have at least min_samples neighbours within max_eps, it is not a core point; its core distance is undefined (infinity), so it cannot establish reachability to other points.

Q8Consider this Python snippet: from sklearn.cluster import OPTICS opt = OPTICS(min_samples=10, xi=0.05).fit(X) In which order must the reachability array be indexed to correctly display the classic reachability plot?

Why: opt.reachability_ stores distances in the original dataset order. To view the characteristic valleys of dense clusters, it must be indexed by the traversal order: opt.reachability_[opt.ordering_].

Q9How does nested hierarchical clustering appear visually in an OPTICS reachability plot?

Why: A broad, shallow valley represents a large diffuse cluster, while deeper depressions nested within that valley represent tighter, higher-density sub-clusters embedded inside it.

Q10Suppose min_samples=4. For a point $p$, the distances to its nearest neighbours (including itself at distance 0) are: $[0.0, 0.4, 0.7, 1.1, 1.6]$. For another point $o$, the distance to $p$ is $d(p, o) = 0.8$. What is $\text{core}(p)$, and what is the reachability distance $\text{reach}(o, p)$?

Why: The 4th nearest neighbour distance is $\text{core}(p) = 1.1$. The reachability distance from $p$ to $o$ is $\max\{\text{core}(p), d(p, o)\} = \max\{1.1, 0.8\} = 1.1$. Even though $o$ is only $0.8$ units away, reachability cannot drop below $p$'s core distance.

Q11Point $p$ has core distance $\text{core}(p) = 1.5$. Two candidate neighbours $A$ and $B$ have distances $d(p, A) = 1.2$ and $d(p, B) = 2.1$. What are the reachability distances $\text{reach}(A, p)$ and $\text{reach}(B, p)$?

Why: $\text{reach}(A, p) = \max\{1.5, 1.2\} = 1.5$ because $d(p, A) < \text{core}(p)$. For point $B$, $d(p, B) = 2.1 > 1.5$, so $\text{reach}(B, p) = \max\{1.5, 2.1\} = 2.1$.

Q12In an OPTICS reachability plot, points 60 to 170 inclusive all have reachability distance $\le 0.8$, while the surrounding points have reachability exceeding $1.5$. If clusters are extracted using a horizontal cut at $\varepsilon = 0.8$ with min_samples = 10, how many points form this cluster?

Why: Points 60 through 170 inclusive have reachability distances at or below the cut threshold $\varepsilon = 0.8$. The number of observations in this contiguous cluster segment is $170 - 60 + 1 = 111$.
