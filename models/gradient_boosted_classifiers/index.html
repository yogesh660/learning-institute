01 The idea

For classification, boosting builds an additive model of the log-odds. Each tree is fitted to the gradient of log-loss, $y - p$, so it focuses on the examples the model is most wrong about.

The model keeps a running score $F(x)$ for each row, starting from the log-odds of the base rate. Each tree nudges $F$ toward the truth; the sigmoid of $F$ is the probability. The pseudo-residual $y - p$ is large for confident mistakes and small for easy rows.

XGBoost, LightGBM and CatBoost all implement this with different engineering: second-order leaf values and explicit regularisation (XGBoost), histogram binning and leaf-wise growth (LightGBM), symmetric trees and ordered categorical encoding (CatBoost). The regression lessons go through each in detail; the classification versions only change the loss.

In everyday terms

Adjusting a running score for every applicant, with each new rule written specifically for the applicants the current score misjudges.

02 How it works

  1. Initialise $F_0 = \log\frac{\bar y}{1 - \bar y}$.
  2. Compute $p_i = \sigma(F(x_i))$, gradients $g_i = p_i - y_i$, Hessians $h_i = p_i(1 - p_i)$.
  3. Fit a tree to the gradients; set leaf values $-G/(H + \lambda)$.
  4. Update $F \leftarrow F + \eta\cdot\text{tree}$; repeat with early stopping.

04 The maths

  1. Gradient and Hessian of log-loss

    $$L = -[y\log p + (1-y)\log(1-p)], \;\; p = \sigma(F) \;\Rightarrow\; \frac{\partial L}{\partial F} = p - y, \;\; \frac{\partial^2 L}{\partial F^2} = p(1-p)$$

    Rows the model is unsure about ($p \approx 0.5$) have the largest Hessian, so they carry the most weight in leaf values.

06 When to use it

Strengths

  • Top accuracy on tabular classification.
  • Handles missing values, mixed types and interactions.
  • Mature libraries with GPU support and SHAP explanations.

Limitations

  • Needs tuning and early stopping.
  • Can overfit small data.
  • Probabilities may still need calibration.

Reach for it when

Tabular classification when accuracy matters: credit risk, churn, fraud, ranking.

Think twice when

Raw images, audio or text, where neural networks shine.

09 Check yourself

Q1In boosting for binary classification, each tree is fitted to:

Why: $y - p$ is the negative gradient of log-loss with respect to the raw score $F$.

Q2Which rows have the largest Hessian $p(1-p)$?

Why: $p(1-p)$ peaks at 0.25 when $p = 0.5$.

Q3On what scale do the additive trees in a binary Gradient Boosted Classifier predict?

Why: Trees output unconstrained real values $F_m(x)$ that accumulate additively. This raw ensemble score $F(x) = \sum \eta f_m(x)$ represents log-odds, transformed into probability $P(y=1) = \frac{1}{1 + e^{-F(x)}}$.

Q4What is the initial prediction $F_0(x)$ before any trees are added in binary Gradient Boosting with log-loss?

Why: Initialising the base score to the log-odds of the positive class prevalence $F_0 = \log(\frac{p}{1-p})$ minimises initial log-loss, ensuring the baseline model matches the empirical marginal class distribution.

Q5How does Gradient Boosting differ from AdaBoost in how successive trees are trained?

Why: While AdaBoost re-weights samples under exponential loss, Gradient Boosting performs gradient descent in function space, fitting each new regression tree directly to the negative gradients of any differentiable loss function (such as log-loss).

Q6For binary classification with labels $y \in \{0, 1\}$ and predicted probabilities $p = \sigma(F)$, why is the negative gradient of log-loss $r = y - p$ called a pseudo-residual?

Why: For negative log-likelihood, $-\frac{\partial L}{\partial F} = y - p$. When $y = 1$ and $p = 0.2$, the gradient is $+0.8$, pushing the tree to increase the log-odds; when $y = 0$ and $p = 0.9$, the gradient is $-0.9$, pushing log-odds down.

Q7In modern implementations like LightGBM or XGBoost, how is the optimal output value $\gamma_{jm}$ for leaf $j$ computed after finding the tree structure?

Why: Using a second-order Taylor expansion of the loss function, the optimal leaf weight is given analytically by $-\frac{\sum g_i}{\sum h_i + \lambda}$, where $g_i$ is the gradient, $h_i = p_i(1-p_i)$ is the Hessian, and $\lambda$ is an L2 regularisation parameter.

Q8What is subsample (stochastic gradient boosting) in gradient boosted trees?

Why: Subsampling (typically $0.5 \le \text{subsample} < 1.0$) fits each successive tree on a fresh random sub-sample of the training rows, reducing variance in a manner analogous to bagging.

Q9Why is early stopping based on a validation set considered essential when training Gradient Boosted Classifiers?

Why: Unlike random forests, boosting greedily minimises training loss at every step. Without early stopping on validation loss, adding hundreds or thousands of trees will eventually overfit noisy training points.

Q10A binary classification model currently outputs raw log-odds $F = 0.0$ for two training examples: Example 1 has label $y_1 = 1$, and Example 2 has label $y_2 = 0$. What are the predicted probabilities $p_1, p_2$ and their negative gradients (pseudo-residuals) $r_i = y_i - p_i$?

Why: $p = \sigma(0.0) = \frac{1}{1 + e^0} = 0.50$. For Example 1 ($y_1 = 1$): $r_1 = 1 - 0.50 = +0.50$. For Example 2 ($y_2 = 0$): $r_2 = 0 - 0.50 = -0.50$.

Q11A test sample starts with baseline raw score $F_0 = 0.0$ (so probability $p_0 = 0.50$). The first boosting tree outputs leaf value $f_1(x) = +2.0$ for this sample, and the learning rate is $\eta = 0.10$. What is the updated probability $p_1$? (Given $e^{-0.20} \approx 0.8187$).

Why: The raw log-odds updates to $F_1 = F_0 + \eta f_1(x) = 0.0 + 0.10(2.0) = +0.20$. The updated probability is $\sigma(0.20) = \frac{1}{1 + e^{-0.20}} \approx \frac{1}{1 + 0.8187} \approx 0.5498$ (or $0.550$).

Q12The Hessian of binary log-loss with respect to the raw score $F$ is $h = p(1 - p)$. What is the maximum possible value of the Hessian across all possible predictions $F \in (-\infty, \infty)$?

Why: The quadratic function $p(1 - p)$ reaches its maximum when $p = 0.5$, yielding $0.5(1 - 0.5) = 0.25$. Confident predictions ($p \to 0$ or $p \to 1$) produce Hessians near 0.
