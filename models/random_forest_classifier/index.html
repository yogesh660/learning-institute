01 The idea

Train many deep trees on bootstrap samples, each split considering only a random subset of features, and let them vote. The crowd is far more reliable than any single tree.

One deep tree overfits in its own particular way. A different tree trained on a slightly different sample overfits differently. Averaging their votes keeps the signal they share and cancels the noise they do not. Random feature selection at each split makes the trees disagree more, which makes the average better. See Random forest regressor for the variance maths.

The vote share is a probability-like score. Out-of-bag rows give a free validation estimate, and permutation importance shows which features the forest relies on.

In everyday terms

A committee of experts, each trained on different cases and told to focus on different symptoms.

02 How it works

  1. Draw a bootstrap sample for each tree.
  2. Grow each tree deep, sampling $\sqrt p$ features at each split.
  3. Predict by majority vote, or average the trees’ class probabilities.
  4. Check out-of-bag accuracy.

04 The maths

  1. Soft voting

    $$\hat P(c \mid x) = \frac1B\sum_{b=1}^B \hat P_b(c \mid x)$$

    scikit-learn averages each tree’s leaf class proportions rather than counting hard votes.

  2. Default feature sampling

    $$m = \lfloor\sqrt p\rfloor \text{ features considered per split}$$

    The classification default; fewer features means more decorrelated trees.

06 When to use it

Strengths

  • Excellent out-of-the-box accuracy.
  • Robust to noise, outliers and irrelevant features.
  • Parallel training; free OOB estimate.

Limitations

  • Large models; slower prediction.
  • Probabilities can be poorly calibrated near 0 and 1.
  • Less interpretable than a single tree.

Reach for it when

Almost any tabular classification problem, as a first serious model.

Think twice when

Very high-dimensional sparse data like text (linear models do better).

07 In code

python
from sklearn.ensemble import RandomForestClassifier

rf = RandomForestClassifier(n_estimators=500, min_samples_leaf=2, oob_score=True,
                            class_weight="balanced_subsample", n_jobs=-1, random_state=0)
rf.fit(X_tr, y_tr)
print("OOB accuracy:", round(rf.oob_score_, 3), "test:", round(rf.score(X_te, y_te), 3))

Common pitfalls

  • Trusting impurity importances for high-cardinality features.
  • Calibrating nothing and treating vote shares as true probabilities.

09 Check yourself

Q1Why does a random forest generalise better than one deep tree?

Why: Each tree overfits differently; averaging cancels the parts that are not shared.

Q2Out-of-bag accuracy is computed on:

Why: About 37% of rows are left out of each bootstrap sample.

Q3In scikit-learn's RandomForestClassifier, what is the default number of features considered at each split (max_features) for $p$ total features?

Why: By default, RandomForestClassifier sets max_features='sqrt', drawing a fresh random subset of $\sqrt{p}$ features at every node split to decorrelate individual trees.

Q4What is bagging (bootstrap aggregating) in the context of random forests?

Why: Bagging generates $B$ bootstrap datasets of size $n$ sampled with replacement from the training set, trains an independent tree on each, and aggregates their outputs to reduce model variance.

Q5Why does Random Forest randomly subset features at each split instead of using standard bagging where each tree can consider all features?

Why: If one or two dominant features exist, standard bagging trees all make the same initial splits, becoming structurally similar. Forcing each split to choose from a random feature subset decorrelates the trees, so their average achieves far lower ensemble variance.

Q6What mathematical property explains why approximately 36.8% of training rows are left out of each bootstrap sample in a Random Forest?

Why: In sampling with replacement of size $n$, the probability of not selecting row $i$ on any single draw is $1 - 1/n$. Over $n$ independent draws, the probability of never selecting it is $(1 - 1/n)^n \to e^{-1} \approx 0.3679$.

Q7What happens as you increase n_estimators (the number of trees) in a Random Forest Classifier?

Why: By the Law of Large Numbers, averaging more independent, identically distributed random trees converges to the expected tree output without increasing generalisation variance; adding trees costs computation but does not cause overfitting.

Q8In Random Forest classification, what is the difference between hard voting and soft voting?

Why: Hard voting assigns the label selected by the majority of individual trees ($\text{mode}(\hat{y}_b)$). Soft voting computes $\hat{P}(c \mid x) = \frac{1}{B}\sum_{b=1}^B \hat{P}_b(c \mid x)$ and takes the argmax, giving greater weight to trees that are confident.

Q9Why can default impurity-based feature importance (feature_importances_) in a Random Forest be misleading for high-cardinality categorical features?

Why: A categorical variable with many levels (like zip codes or IDs) offers exponentially many binary split combinations, allowing trees to overfit and artificially inflating their Gini impurity reduction score. Permutation importance on held-out data avoids this bias.

Q10Suppose individual trees in a Random Forest have variance $\sigma^2 = 1.0$ and pairwise correlation $\rho = 0.20$. What is the theoretical ensemble variance $\operatorname{Var}(\bar{T}) = \rho \sigma^2 + \frac{1 - \rho}{B}\sigma^2$ as the number of trees $B \to \infty$?

Why: The variance of the average of $B$ correlated random variables is $\rho \sigma^2 + \frac{1-\rho}{B}\sigma^2$. As $B \to \infty$, the second term $\frac{1-\rho}{B}\sigma^2 \to 0$, leaving $\rho \sigma^2 = 0.20 \times 1.0 = 0.20$. This demonstrates that the minimum achievable variance is strictly bounded by the tree correlation $\rho$.

Q11An ensemble of 3 trees predicts class probabilities for Class 1 on a test sample: Tree 1 ($P_1 = 0.90$), Tree 2 ($P_2 = 0.40$), Tree 3 ($P_3 = 0.35$). What are the predictions of hard voting (threshold 0.5) and soft voting (threshold 0.5)?

Why: Hard voting: Tree 1 votes 1 ($0.90 \ge 0.5$), Trees 2 and 3 vote 0 ($0.40, 0.35 < 0.5$). Majority is Class 0 (2 to 1). Soft voting: average probability is $(0.90 + 0.40 + 0.35) / 3 = 1.65 / 3 = 0.55 \ge 0.5$, predicting Class 1.

Q12In a small dataset of $n = 4$ observations $\{A, B, C, D\}$, what is the exact probability that observation $A$ is selected at least once in a bootstrap sample of size 4 drawn with replacement?

Why: On each draw, the probability of not selecting $A$ is $3/4$. Over 4 independent draws with replacement, the probability that $A$ is never selected is $(3/4)^4 = 81 / 256 \approx 31.64\%$. Therefore, the probability that $A$ is selected at least once is $1 - 81/256 = 175 / 256 \approx 68.36\%$.
