Agglomerative Hierarchical Clustering

Starts with every point alone and repeatedly merges the two closest clusters, building a tree (dendrogram) of the whole hierarchy.

01 The idea

Begin with $n$ singleton clusters. At each step merge the two closest clusters. The full history of merges is a dendrogram; cut it at any height to get any number of clusters.

The interesting part is how "closest clusters" is defined, the linkage. Single linkage uses the closest pair of points, which follows chains and long shapes but is prone to chaining through noise. Complete linkage uses the farthest pair, giving compact clusters. Average linkage sits in between. Ward linkage merges the pair that increases total within-cluster variance the least, which behaves like a hierarchical k-means.

You do not need to fix the number of clusters up front: inspect the dendrogram and cut where there is a big vertical gap.

In everyday terms

A family tree run backwards: individuals form families, families form clans, clans form tribes.

02 How it works

  1. Compute pairwise distances.
  2. Treat each point as its own cluster.
  3. Merge the two clusters with the smallest linkage distance; record the merge height.
  4. Update distances to the new cluster (Lance–Williams formula).
  5. Repeat until one cluster remains; cut the dendrogram to get labels.

04 The maths

  1. Linkage criteria

    $$d_{\text{single}} = \min_{a \in A, b \in B}d(a, b), \quad d_{\text{complete}} = \max_{a, b}d(a, b), \quad d_{\text{avg}} = \frac{1}{|A||B|}\sum_{a,b}d(a, b)$$

    Each choice produces a different hierarchy from the same distances.

  2. Ward’s criterion

    $$\Delta(A, B) = \frac{|A||B|}{|A| + |B|}\lVert\mu_A - \mu_B\rVert^2$$

    The increase in within-cluster sum of squares caused by merging $A$ and $B$.

06 When to use it

Strengths

  • No need to fix k in advance; the dendrogram shows all scales.
  • Deterministic.
  • Any distance and linkage combination.

Limitations

  • $O(n^2)$ memory and at least $O(n^2)$ time.
  • Greedy: a bad early merge is never undone.
  • Sensitive to linkage choice.

Reach for it when

Small to medium data where the hierarchy itself is interesting (taxonomies, gene expression, document topics).

Think twice when

More than about 20k points.

07 In code

python
import pandas as pd
from sklearn.preprocessing import StandardScaler

df = pd.read_csv("datasets/raw/mall_customers.csv")
X = StandardScaler().fit_transform(df[["Annual_Income_k", "Spending_Score"]])
from sklearn.cluster import AgglomerativeClustering
from scipy.cluster.hierarchy import linkage, dendrogram
import matplotlib.pyplot as plt

labels = AgglomerativeClustering(n_clusters=5, linkage="ward").fit_predict(X)
dendrogram(linkage(X, method="ward"), truncate_mode="lastp", p=20)
plt.show()

Common pitfalls

  • Using single linkage on noisy data: one bridge point chains two clusters together.
  • Using ward with a non-Euclidean metric (not valid).

09 Check yourself

Q1Which linkage is most prone to "chaining"?

Why: Two clusters merge if any single pair of points is close, so a trail of points links distant groups.

Q2How do you get 4 clusters from a dendrogram?

Why: The hierarchy contains every number of clusters from 1 to $n$.

Q3How does agglomerative hierarchical clustering begin its clustering process?

Why: Agglomerative (bottom-up) clustering starts with $n$ distinct clusters of 1 observation each and iteratively merges the most similar pairs.

Q4Which linkage criterion merges the two clusters that cause the smallest increase in total within-cluster variance (sum of squared errors)?

Why: Ward's criterion calculates the increase in within-cluster sum of squares $\Delta(A, B) = \frac{|A||B|}{|A| + |B|}\lVert\mu_A - \mu_B\rVert^2$ and merges the pair that minimises this variance inflation.

Q5How is complete linkage distance defined between two clusters $A$ and $B$?

Why: Complete linkage defines cluster dissimilarity as the maximum pairwise distance between their elements, ensuring that every point in the merged cluster will be within that distance of all other points.

Q6Why can Ward linkage only be used with Euclidean distance?

Why: Ward linkage specifically minimises variance (sum of squared Euclidean distances to the mean). Conceptually and mathematically, variance is tied to Euclidean geometry; using other metrics breaks the variance objective.

Q7What is the Lance-Williams formula used for in hierarchical clustering algorithms?

Why: The Lance-Williams recurrence expresses the distance $d(A \cup B, C)$ as a linear combination of $d(A, C)$, $d(B, C)$, and $d(A, B)$, enabling fast $O(1)$ distance updates after each merge.

Q8In a dendrogram, how do you identify a natural or robust clustering structure?

Why: A tall vertical gap between merges indicates that clusters remained distinct and separated across a wide range of dissimilarity thresholds before being forced to merge, signalling natural cluster separation.

Q9Why does agglomerative hierarchical clustering become impractical on datasets with more than 30,000 observations?

Why: Storing an $n \times n$ distance matrix for $n = 30,000$ requires $(30,000)^2 \times 8\text{ bytes} \approx 7.2\text{ GB}$ of RAM, and naive implementations scale as $O(n^3)$ or $O(n^2 \log n)$, making it computationally intractable for large datasets.

Q10Suppose cluster $A = \{1\}$ and cluster $B = \{5, 9\}$ in 1D. What are the linkage distances between $A$ and $B$ under single linkage, complete linkage, and average linkage?

Why: The pairwise distances from 1 to $\{5, 9\}$ are 4 and 8. Single linkage is the minimum ($\min(4, 8) = 4$), complete linkage is the maximum ($\max(4, 8) = 8$), and average linkage is the arithmetic mean ($(4 + 8)/2 = 6$).

Q11Two 1D clusters $A = \{2\}$ and $B = \{8\}$ have centroids $\mu_A = 2$ ($|A| = 1$) and $\mu_B = 8$ ($|B| = 1$). What is the increase in variance $\Delta(A, B) = \frac{|A||B|}{|A| + |B|}\lVert\mu_A - \mu_B\rVert^2$ under Ward's criterion if $A$ and $B$ are merged?

Why: The multiplier is $(1 \times 1) / (1 + 1) = 0.5$. The squared distance between centroids is $(2 - 8)^2 = 36$. Thus $\Delta(A, B) = 0.5 \times 36 = 18.0$.

Q12In a dataset of $n = 50$ observations, how many merge steps occur from the initial singleton state until all points belong to a single root cluster?

Why: Each agglomerative merge step decreases the number of active clusters by exactly one ($n \to n - 1$). Reducing $n = 50$ initial clusters down to 1 single cluster requires exactly $n - 1 = 49$ merges.
