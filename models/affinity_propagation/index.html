Affinity Propagation

Points send messages to each other until a set of exemplars emerges. The number of clusters is chosen by the data.

01 The idea

Every point considers every other point as a possible exemplar (representative). Two kinds of messages, responsibility and availability, are passed back and forth until each point settles on an exemplar.

Responsibility $r(i,k)$: how well-suited $k$ is to be $i$’s exemplar, compared with other candidates. Availability $a(i,k)$: how appropriate it would be for $i$ to pick $k$, given how many other points also support $k$. After convergence, exemplars are the points with positive $r(k,k) + a(k,k)$.

The preference $s(k,k)$ is each point’s prior willingness to be an exemplar. Using the median similarity gives a moderate number of clusters; the minimum gives few. Damping keeps the messages from oscillating.

In everyday terms

An election where everyone nominates and endorses candidates in rounds until a natural set of leaders emerges.

02 How it works

  1. Compute similarities $s(i,k) = -\lVert x_i - x_k\rVert^2$; set the diagonal to the preference.
  2. Update responsibilities from similarities and current availabilities.
  3. Update availabilities from accumulated positive responsibilities.
  4. Damp the updates; repeat until exemplars stop changing.

03 Try it

Messages are passed for you; lines connect each point to its current exemplar (large rings).

Things to try
  1. Lower the preference scale and watch exemplars disappear.
  2. Set damping to 0.5 and see if it oscillates.

04 The maths

  1. Message updates

    $$r(i,k) \leftarrow s(i,k) - \max_{k' \ne k}\{a(i,k') + s(i,k')\}$$ $$a(i,k) \leftarrow \min\Big\{0,\; r(k,k) + \sum_{i' \notin \{i,k\}}\max(0, r(i',k))\Big\}$$

    With $a(k,k) = \sum_{i' \ne k}\max(0, r(i',k))$ for self-availability.

06 When to use it

Strengths

  • No need to choose k.
  • Exemplars are real data points.
  • Works from any similarity matrix.

Limitations

  • $O(n^2)$ memory and time per iteration.
  • Sensitive to preference and damping.
  • Can fail to converge.

Reach for it when

Small datasets where you want representative examples and do not know k.

Think twice when

More than a few thousand points.

07 In code

python
import pandas as pd
from sklearn.preprocessing import StandardScaler

df = pd.read_csv("datasets/raw/mall_customers.csv")
X = StandardScaler().fit_transform(df[["Annual_Income_k", "Spending_Score"]])
from sklearn.cluster import AffinityPropagation
import numpy as np

ap = AffinityPropagation(damping=0.9, random_state=0).fit(X)
print("exemplars:", len(ap.cluster_centers_indices_))
fewer = AffinityPropagation(damping=0.9, preference=np.min(-((X[:, None] - X) ** 2).sum(-1)), random_state=0).fit(X)
print("with minimum preference:", len(fewer.cluster_centers_indices_))

Common pitfalls

  • Assuming the cluster count is "discovered": it is driven by the preference you set.

09 Check yourself

Q1Lowering the preference for all points tends to:

Why: Points become less willing to be exemplars.

Q2In Affinity Propagation, what are the representative prototypes of clusters called, and what form do they take?

Why: Affinity Propagation chooses actual data points from the sample to represent clusters; these representative instances are called exemplars.

Q3What does the "responsibility" message $r(i, k)$ communicate from point $i$ to candidate exemplar $k$?

Why: Responsibility $r(i, k)$ quantifies how well-suited candidate $k$ is to be point $i$'s exemplar relative to all other candidate exemplars.

Q4What does the "availability" message $a(i, k)$ communicate from candidate exemplar $k$ to point $i$?

Why: Availability $a(i, k)$ reflects how appropriate it is for point $i$ to select $k$ as its exemplar, derived from the positive responsibilities that other points have sent to $k$.

Q5What is the role of the damping parameter (typically between 0.5 and 0.9) in Affinity Propagation?

Why: Message-passing algorithms can enter periodic oscillations. Damping applies exponential smoothing: $M_t = \lambda M_{t-1} + (1 - \lambda) M_{\text{new}}$, stabilising convergence.

Q6By default in scikit-learn, what value is assigned to the diagonal elements $s(k, k)$ (the preferences) of the similarity matrix?

Why: In AffinityPropagation, setting preference=None defaults to the median of the input similarities, which yields a moderate number of clusters.

Q7After convergence, how does Affinity Propagation decide whether a specific point $k$ is an exemplar?

Why: Point $k$ identifies as an exemplar when its self-belief $r(k, k) + a(k, k) > 0$. Points then choose the exemplar $k$ that maximises $r(i, k) + a(i, k)$.

Q8Why is Affinity Propagation generally impractical for datasets with more than 10,000 observations?

Why: Maintaining dense $n \times n$ similarity, responsibility, and availability matrices requires $O(n^2)$ memory. For $n = 20,000$, storing three $20,000 \times 20,000$ float64 matrices requires nearly 10 GB of RAM.

Q9If an analyst sets preference to the minimum pairwise similarity $\min_{i \ne j} s(i, j)$, what effect does this have on the resulting clustering?

Why: Setting low preference makes points reluctant to volunteer as exemplars. When $s(k, k)$ is set to the minimum similarity, only the strongest candidate exemplars emerge, yielding few, large clusters.

Q10Suppose point $i$ evaluates two candidate exemplars $k_1$ and $k_2$ with similarities $s(i, k_1) = -2$ and $s(i, k_2) = -8$. The current availabilities are $a(i, k_1) = 0$ and $a(i, k_2) = 0$. Using the responsibility update formula $r(i, k) = s(i, k) - \max_{k' \ne k} \{a(i, k') + s(i, k')\}$, what is the updated responsibility $r(i, k_1)$?

Why: For $k = k_1$, the competing candidate is $k_2$ with $a(i, k_2) + s(i, k_2) = 0 + (-8) = -8$. Then $r(i, k_1) = s(i, k_1) - (-8) = -2 + 8 = +6$. The positive responsibility indicates that $k_1$ is substantially more suitable for $i$ than its rival $k_2$.

Q11Candidate exemplar $k$ receives positive responsibilities from other points: $r(1, k) = 3.0$, $r(2, k) = 1.5$, and $r(3, k) = -2.0$. Candidate $k$'s self-responsibility is $r(k, k) = -4.0$. What is the updated availability $a(4, k)$ sent to point 4 using $a(i, k) = \min\{0, \; r(k, k) + \sum_{i' \notin \{i, k\}} \max(0, r(i', k))\}$?

Why: The positive support from other points is $\max(0, 3.0) + \max(0, 1.5) + \max(0, -2.0) = 4.5$. Adding self-responsibility gives $-4.0 + 4.5 = +0.5$. Because availability cannot exceed zero ($a(i, k) = \min\{0, \dots\}$), $a(4, k) = \min(0, 0.5) = 0.0$.

Q12In an Affinity Propagation run with damping factor $\lambda = 0.8$, the old responsibility value was $r_{\text{old}} = 2.0$. The raw update calculation produces $r_{\text{new}} = 7.0$. What is the damped responsibility value $r_{\text{damped}} = \lambda r_{\text{old}} + (1 - \lambda) r_{\text{new}}$?

Why: Damping applies convex smoothing: $r_{\text{damped}} = (0.8 \times 2.0) + (0.2 \times 7.0) = 1.6 + 1.4 = 3.0$. This prevents wild jumps between iterations.
