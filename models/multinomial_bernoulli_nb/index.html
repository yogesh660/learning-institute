01 The idea

For text, the features are word counts (multinomial) or word presence (Bernoulli). Naive Bayes learns how often each word appears in each class and scores new documents by adding up word log-probabilities.

A spam filter learns that "winner" and "free" are far more common in spam than in normal mail. A new email is scored by summing, for each word, the log of how much more likely that word is under spam than under ham. Words never seen in a class would give $\log 0 = -\infty$, so counts are smoothed with a small $\alpha$ (Laplace smoothing).

Multinomial NB uses how many times each word appears. Bernoulli NB only uses whether it appears, but also counts the absence of words as evidence. Bernoulli tends to suit short texts; multinomial suits longer ones.

In everyday terms

Every word casts a weighted vote; rare-in-ham, common-in-spam words vote loudest.

02 How it works

  1. Turn documents into word counts (or 0/1 presence).
  2. For each class, count how often each word appears, plus $\alpha$.
  3. Normalise into per-class word probabilities.
  4. Score a new document: log prior plus the sum of log word probabilities.

04 The maths

  1. Smoothed word probabilities

    $$\hat\theta_{kw} = \frac{N_{kw} + \alpha}{N_k + \alpha V}$$

    $N_{kw}$ is the count of word $w$ in class $k$, $N_k$ the total words in class $k$ and $V$ the vocabulary size.

  2. Multinomial score

    $$\log P(k \mid d) \propto \log\pi_k + \sum_w x_{dw}\log\hat\theta_{kw}$$

    This is linear in the word counts, which is why Naive Bayes is a linear classifier in disguise.

06 When to use it

Strengths

  • Very fast to train and predict, even with huge vocabularies.
  • Strong text baseline with little data.
  • Easy to inspect: the most indicative words per class.

Limitations

  • Independence between words is clearly false.
  • Probabilities are overconfident.
  • Beaten by linear SVMs or transformers when data is plentiful.

Reach for it when

Text classification baselines: spam, topic tagging, sentiment, especially with little labelled data.

Think twice when

When word order and context matter; see LSTMs and Transformers.

07 In code

python
from sklearn.pipeline import make_pipeline
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.naive_bayes import MultinomialNB, BernoulliNB

texts = ["win a free prize now", "meeting moved to monday", "free entry to win cash",
         "lunch on friday?", "claim your free reward", "notes from the team meeting"]
labels = [1, 0, 1, 0, 1, 0]                       # 1 = spam

mnb = make_pipeline(CountVectorizer(), MultinomialNB(alpha=1.0)).fit(texts, labels)
bnb = make_pipeline(CountVectorizer(binary=True), BernoulliNB(alpha=1.0)).fit(texts, labels)
print(mnb.predict_proba(["free lunch meeting"]), bnb.predict_proba(["free lunch meeting"]))

Common pitfalls

  • Setting alpha to 0: one unseen word sets the class probability to zero.
  • Using Bernoulli NB on long documents where counts carry real information.

09 Check yourself

Q1Why is Laplace smoothing needed?

Why: A single zero in a product makes the whole product zero.

Q2What does Bernoulli NB use that Multinomial NB ignores?

Why: Bernoulli multiplies in $1 - \theta$ for every vocabulary word that does not appear.

Q3What type of input features does Multinomial Naive Bayes expect?

Why: Multinomial Naive Bayes models the probability of generating a bag of words from a multinomial distribution, requiring non-negative integer or count representations ($x_i \ge 0$).

Q4In Laplace smoothing for Multinomial NB, $\hat{\theta}_{kw} = \frac{N_{kw} + \alpha}{N_k + \alpha V}$, what does $V$ represent?

Why: $V$ is the total number of distinct words in the vocabulary. Adding $\alpha$ to each word count requires adding $\alpha V$ to the denominator so that the estimated probabilities $\sum_w \hat{\theta}_{kw}$ still sum strictly to 1.

Q5What setting for alpha corresponds to Lidstone smoothing rather than standard Laplace smoothing?

Why: Standard Laplace smoothing uses additive pseudo-count $\alpha = 1$. Using a fractional pseudo-count $0 < \alpha < 1$ is known as Lidstone smoothing, which adds less uniform smoothing when vocabularies are vast.

Q6Why does standard Bernoulli Naive Bayes struggle when applied to long documents compared to Multinomial Naive Bayes?

Why: In long documents, nearly all vocabulary words occur at least once, so binary presence vectors lose all discriminative power; whether a keyword appeared once by accident or 50 times deliberately cannot be distinguished by Bernoulli NB.

Q7Why will scikit-learn's MultinomialNB raise a ValueError if passed features preprocessed with StandardScaler?

Why: The multinomial log-likelihood is $\sum x_w \log\theta_w$. Negative values of $x_w$ have no probabilistic interpretation as occurrence counts and break the multinomial assumption. Count data should be scaled with MinMaxScaler or used directly as counts or TF-IDF.

Q8Can Multinomial Naive Bayes be trained on fractional TF-IDF feature weights rather than integer word counts?

Why: In practice, scikit-learn's MultinomialNB accepts non-negative continuous values such as TF-IDF features; the linear combination $\sum x_w \log\theta_w$ works effectively as a weighted log-likelihood.

Q9What happens during inference when a new test document contains words that never appeared anywhere in the training vocabulary?

Why: The fitted CountVectorizer has a fixed vocabulary mapping. Any token not seen during training is simply skipped during vectorisation and omitted from the dot product.

Q10A spam training corpus has vocabulary size $V = 100$. In the spam class, total word tokens count $N_{\text{spam}} = 400$. The word "prize" occurs $N_{\text{spam, prize}} = 8$ times. With Laplace smoothing ($\alpha = 1.0$), what is the smoothed probability $\hat{\theta}_{\text{spam, prize}}$?

Why: The Laplace smoothed formula is $\hat{\theta}_{kw} = \frac{N_{kw} + \alpha}{N_k + \alpha V} = \frac{8 + 1}{400 + 1 \times 100} = \frac{9}{500} = 0.0180$.

Q11A test document consists of two words: "win cash". Class A has prior $\pi_A = 0.60$, with word probabilities $\theta_{A, \text{win}} = 0.10, \theta_{A, \text{cash}} = 0.05$. Class B has prior $\pi_B = 0.40$, with word probabilities $\theta_{B, \text{win}} = 0.02, \theta_{B, \text{cash}} = 0.01$. Under Multinomial Naive Bayes, what is the unnormalised joint score $P(\text{class}, \text{doc})$ for Class A and Class B?

Why: Joint probability is $\pi_k \times \theta_{k, \text{win}} \times \theta_{k, \text{cash}}$. For Class A: $0.60 \times 0.10 \times 0.05 = 0.00300$. For Class B: $0.40 \times 0.02 \times 0.01 = 0.00008$. Class A is $37.5$ times more likely.

Q12In a Bernoulli Naive Bayes model with vocabulary $V = \{\text{free}, \text{meeting}\}$, Class 1 has $\theta_{1, \text{free}} = 0.8, \theta_{1, \text{meeting}} = 0.1$. A document contains only the single word "meeting" (so "free" is absent). If Class 1 has prior $\pi_1 = 0.5$, what is its joint score under Bernoulli NB?

Why: Bernoulli NB multiplies the presence probability for words in the document AND the absence probability $(1 - \theta)$ for vocabulary words NOT in the document: $\pi_1 \times (1 - \theta_{1, \text{free}}) \times \theta_{1, \text{meeting}} = 0.5 \times 0.2 \times 0.1 = 0.010$.
