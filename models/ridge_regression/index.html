Ridge Regression (L2 Regularisation)

Linear regression with a penalty on the size of the coefficients. Trades a little bias for a big drop in variance.

01 The idea

Ridge is OLS with one extra term: it also pays for large coefficients, $\lambda\lVert\beta\rVert_2^2$. The result is a smoother, more stable model that copes with correlated features.

When two features carry almost the same information, OLS can give one a coefficient of $+50$ and the other $-49$: they cancel on the training data, but the model is fragile. Ridge says "big weights cost money", so it prefers spreading the effect evenly, $+0.5$ and $+0.5$.

The penalty strength $\lambda$ (called alpha in scikit-learn) slides the model from plain OLS ($\lambda = 0$) toward predicting a constant ($\lambda \to \infty$). Somewhere in between, test error is lowest. Coefficients shrink smoothly toward zero but never reach it exactly; for exact zeros, see Lasso regression.

In everyday terms

A budget on how loudly each feature is allowed to speak. Nobody is silenced, but nobody gets to shout.

02 How it works

  1. Standardise the features. The penalty treats every coefficient equally, so features must be on comparable scales.
  2. Minimise squared error plus $\lambda$ times the sum of squared coefficients (the intercept is not penalised).
  3. Solve in closed form: $(X^\top X + \lambda I)\beta = X^\top y$.
  4. Pick $\lambda$ by cross-validation on a log grid, e.g. $10^{-3}$ to $10^{3}$.

04 The maths

  1. Penalised objective

    $$\hat\beta_{\text{ridge}} = \arg\min_\beta \;\lVert y - X\beta\rVert_2^2 + \lambda \lVert\beta\rVert_2^2$$

    The second term is a regulariser. Its only job is to punish complexity.

  2. Closed form

    $$\hat\beta_{\text{ridge}} = (X^\top X + \lambda I)^{-1} X^\top y$$

    Adding $\lambda I$ lifts every eigenvalue of $X^\top X$ by $\lambda$, so the matrix is always invertible, even with more features than rows.

  3. Shrinkage in the eigenbasis

    $$\hat y = \sum_j u_j \frac{d_j^2}{d_j^2 + \lambda} u_j^\top y$$

    Using the SVD $X = UDV^\top$: directions with small singular values $d_j$ (the noisy, collinear ones) get shrunk the most. That is exactly where OLS was unstable.

  4. Bayesian reading

    $$\beta \sim \mathcal N(0, \tau^2 I) \;\Rightarrow\; \text{MAP estimate} = \hat\beta_{\text{ridge}},\;\; \lambda = \sigma^2/\tau^2$$

    Ridge is the most likely $\beta$ under a Gaussian prior centred at zero. See Bayesian linear regression.

06 When to use it

Strengths

  • Stable when features are correlated.
  • Always has a unique solution, even when $p > n$.
  • Still closed-form and very fast.
  • Usually beats OLS on test data.

Limitations

  • Keeps every feature: no automatic selection.
  • Coefficients are biased toward zero, so they are harder to read as effect sizes.
  • Needs feature scaling.

Reach for it when

Many correlated features, or more features than you would like for the number of rows, and you want to keep all of them.

Think twice when

You believe only a handful of features matter and want the model to pick them: use Lasso regression or Elastic net.

07 In code

python
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import RidgeCV
import numpy as np

model = make_pipeline(StandardScaler(), RidgeCV(alphas=np.logspace(-3, 3, 25)))
model.fit(X_tr, y_tr)
print("chosen alpha:", model[-1].alpha_)

Common pitfalls

  • Skipping standardisation, so the penalty unfairly crushes features measured in small units.
  • Penalising the intercept (scikit-learn does not, but hand-written code often does).
  • Choosing alpha on the test set. Use cross-validation on the training data.

09 Check yourself

Q1What happens to ridge coefficients as $\lambda \to \infty$?

Why: The penalty dominates, so every slope is squeezed toward 0 (smoothly, never exactly), leaving only the unpenalised intercept: the mean of $y$.

Q2Why can ridge be solved when there are more features than rows?

Why: $X^\top X$ is singular when $p > n$, but adding $\lambda > 0$ to its diagonal makes every eigenvalue positive.

Q3Which statement about ridge vs lasso is right?

Why: The L2 penalty is smooth at zero, so there is no pull to land exactly on it. The L1 penalty has a corner at zero that captures coefficients.
