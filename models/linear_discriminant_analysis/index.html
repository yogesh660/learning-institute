Linear Discriminant Analysis (LDA)

Models each class as a Gaussian with a shared covariance. The result is a linear boundary and a handy projection.

01 The idea

LDA assumes each class is a Gaussian blob with its own centre but the same shape. Under that assumption, Bayes’ rule gives a linear decision boundary, and the same maths gives the best projection for separating classes.

Logistic regression models $P(y\mid x)$ directly (discriminative). LDA models how the data in each class is generated, $P(x\mid y)$, and flips it with Bayes’ rule (generative). Because all classes share one covariance matrix, the quadratic terms cancel and the boundary is a hyperplane.

LDA also finds the directions that maximise between-class spread relative to within-class spread (Fisher’s criterion). With $K$ classes that gives up to $K-1$ dimensions, a supervised alternative to PCA for visualisation.

In everyday terms

Each class is a cloud of the same shape, just in a different place. Classify a point by asking which cloud it most plausibly came from.

02 How it works

  1. Estimate each class prior $\pi_k$ and mean $\mu_k$.
  2. Estimate one pooled covariance matrix $\Sigma$ from all classes.
  3. Compute a linear score $\delta_k(x)$ for every class.
  4. Predict the class with the highest score; or project onto the top discriminant directions.

04 The maths

  1. Generative model

    $$x \mid y = k \sim \mathcal N(\mu_k, \Sigma), \qquad P(y = k) = \pi_k$$

    One shared covariance $\Sigma$ for all classes is the key assumption.

  2. Linear discriminant

    $$\delta_k(x) = x^\top\Sigma^{-1}\mu_k - \tfrac12\mu_k^\top\Sigma^{-1}\mu_k + \log\pi_k$$

    The $x^\top\Sigma^{-1}x$ term is the same for every class and cancels, so the boundary between two classes is linear.

  3. Fisher’s criterion

    $$w^* = \arg\max_w \frac{w^\top S_B w}{w^\top S_W w}$$

    Maximise separation between class means relative to spread within classes. For two classes, $w^* \propto \Sigma^{-1}(\mu_1 - \mu_0)$.

06 When to use it

Strengths

  • Closed-form, fast, no tuning in the basic form.
  • Works well with small samples when the assumption holds.
  • Doubles as supervised dimensionality reduction.

Limitations

  • Assumes Gaussian classes with equal covariance.
  • Sensitive to outliers (means and covariances are not robust).
  • Linear boundary only.

Reach for it when

Small datasets, roughly Gaussian features, or when you want a supervised 2-D projection.

Think twice when

Classes with very different spreads (use QDA) or heavy outliers.

07 In code

python
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis

lda = LinearDiscriminantAnalysis(solver="lsqr", shrinkage="auto").fit(X_tr, y_tr)
print("test accuracy:", round(lda.score(X_te, y_te), 3))

projector = LinearDiscriminantAnalysis(n_components=1).fit(X_tr, y_tr)  # supervised projection
Z = projector.transform(X_te)

Common pitfalls

  • Applying LDA to categorical features coded as numbers; the Gaussian assumption makes no sense there.
  • Forgetting shrinkage when features outnumber samples.

09 Check yourself

Q1Why is the LDA boundary linear?

Why: With equal $\Sigma$, $x^\top\Sigma^{-1}x$ appears in every class’s score and drops out of the comparison.

Q2How many discriminant directions can LDA find for 4 classes?

Why: The between-class scatter matrix has rank at most $K - 1$.

Q3What is the fundamental difference between LDA and Logistic Regression in how they model data?

Why: LDA models the generative class-conditional densities $P(x \mid y=k) \sim \mathcal{N}(\mu_k, \Sigma)$ and inverts them via Bayes' rule. Logistic Regression models the posterior class probabilities $P(y \mid x)$ directly without assuming Gaussian feature distributions.

Q4What objective function does Fisher's linear discriminant maximise when projecting data onto direction vector $w$?

Why: Fisher's criterion seeks a projection vector $w$ that spreads out the class means (maximising between-class scatter $S_B$) while keeping the spread within each individual class as tight as possible (minimising within-class scatter $S_W$).

Q5How does the dimensionality reduction performed by LDA differ fundamentally from PCA?

Why: PCA finds directions of maximum overall variance in $X$ without knowing about classes; if the direction of highest variance does not separate classes, PCA fails for classification. LDA explicitly uses class labels to find projection axes that separate classes.

Q6Why is shrinkage regularisation (Ledoit–Wolf shrinkage) crucial when applying LDA to high-dimensional data where $p > n$?

Why: When $p > n$, the sample covariance matrix $\Sigma$ has rank at most $n - 1$ and cannot be inverted. Shrinkage blends $\Sigma$ with a well-conditioned diagonal matrix, guaranteeing an invertible positive definite covariance matrix.

Q7In the linear discriminant score $\delta_k(x) = x^\top \Sigma^{-1} \mu_k - \frac{1}{2}\mu_k^\top \Sigma^{-1} \mu_k + \log\pi_k$, what effect does having a much larger prior $\pi_1 \gg \pi_2$ have on the decision boundary?

Why: The term $\log\pi_k$ acts as a class-specific threshold. When class 1 is much more common ($\pi_1 > \pi_2$), $\log\pi_1 > \log\pi_2$, so a test point must be substantially closer to $\mu_2$ for $\delta_2(x)$ to exceed $\delta_1(x)$. This shifts the boundary towards $\mu_2$.

Q8What is a major pitfall of applying standard LDA to categorical features that have been encoded as arbitrary integers (e.g. 1, 2, 3)?

Why: LDA assumes $x \mid y=k \sim \mathcal{N}(\mu_k, \Sigma)$. Treating discrete categorical states as numbers implies equidistant Gaussian distributions along that axis, which is statistically invalid and degrades classification.

Q9For two classes with means $\mu_1$ and $\mu_2$ and shared covariance $\Sigma$, in what direction is the normal vector $w$ of the LDA decision hyperplane aligned?

Why: The linear decision boundary occurs where $\delta_1(x) = \delta_2(x)$, which simplifies to $x^\top \Sigma^{-1}(\mu_1 - \mu_2) + c = 0$. The normal vector perpendicular to this hyperplane is $w = \Sigma^{-1}(\mu_1 - \mu_2)$.

Q10Consider a 1D two-class problem where Class 1 has mean $\mu_1 = 2.0$ and prior $\pi_1 = 0.50$, while Class 2 has mean $\mu_2 = 6.0$ and prior $\pi_2 = 0.50$. Both classes share common variance $\sigma^2 = 4.0$. At what coordinate $x$ does the LDA decision boundary lie?

Why: With equal priors $\pi_1 = \pi_2$, the $\log\pi_k$ terms cancel. The boundary satisfies $\delta_1(x) = \delta_2(x) \iff x = \frac{\mu_1 + \mu_2}{2} = \frac{2.0 + 6.0}{2} = 4.0$, exactly halfway between the two class means.

Q11Continuing from the 1D problem with $\mu_1 = 2.0, \mu_2 = 6.0, \sigma^2 = 4.0$, suppose the priors change to $\pi_1 = 0.80$ and $\pi_2 = 0.20$. Where does the decision boundary $x$ move? (Use $\log(0.80 / 0.20) = \log(4) \approx 1.386$).

Why: The boundary equation is $\frac{x(\mu_1 - \mu_2)}{\sigma^2} - \frac{\mu_1^2 - \mu_2^2}{2\sigma^2} + \log(\frac{\pi_1}{\pi_2}) = 0$. Substituting: $\frac{-4x}{4} - \frac{-32}{8} + 1.386 = 0 \implies -x + 4 + 1.386 = 0 \implies x = 5.386$. The boundary shifts towards $\mu_2 = 6.0$, widening the decision region for the dominant class 1.

Q12For two 1D classes with means $\mu_1 = 1.0, \mu_2 = 5.0$, within-class scatter $S_W = 8.0$, and between-class scatter $S_B = (\mu_1 - \mu_2)^2 = (1 - 5)^2 = 16.0$, what is Fisher's criterion score $J(w) = \frac{w^\top S_B w}{w^\top S_W w}$ for any non-zero projection $w$?

Why: In 1D, the projection vector $w$ is a non-zero scalar, so $J(w) = \frac{w^2 S_B}{w^2 S_W} = \frac{S_B}{S_W} = \frac{16.0}{8.0} = 2.0$, which is constant and independent of the scaling of $w$.
