01 The idea

To classify a point, find the $k$ training points nearest to it and let them vote. That is the entire algorithm.

k-NN draws boundaries that follow the data exactly. With $k = 1$ every training point owns the region closest to it (a Voronoi cell), so the boundary is jagged and every training point is classified correctly. Larger $k$ smooths the boundary by letting more neighbours outvote isolated points.

Because everything rests on distance, feature scaling and the choice of metric dominate performance. In high dimensions, distances between all points become similar and "nearest" loses its meaning.

In everyday terms

You are probably like the people who live closest to you.

02 How it works

  1. Scale the features.
  2. Store the training data (often in a KD-tree or ball tree).
  3. For a query, find the $k$ nearest neighbours.
  4. Return the majority class (or class proportions as probabilities).

04 The maths

  1. Vote

    $$\hat y(x) = \arg\max_c \sum_{i \in N_k(x)} w_i\,\mathbb 1[y_i = c], \qquad \hat P(c \mid x) = \frac{\sum_{i \in N_k(x)} w_i\mathbb 1[y_i = c]}{\sum_{i \in N_k(x)} w_i}$$

    $w_i = 1$ for a plain vote, or $1/d(x, x_i)$ to let close neighbours count more.

  2. Asymptotic error

    $$R^* \le R_{1\text{NN}} \le 2R^*(1 - R^*)$$

    With infinite data, 1-NN’s error is at most twice the Bayes-optimal error $R^*$: a remarkable guarantee for such a simple rule.

06 When to use it

Strengths

  • No training, easy to update.
  • Naturally multi-class.
  • Flexible boundaries; predictions are explainable by example.

Limitations

  • Slow prediction on large data.
  • Needs scaling; hurt by irrelevant features.
  • Weak in high dimensions.

Reach for it when

Low-dimensional data, recommendation by similarity, or a quick non-parametric baseline.

Think twice when

Large, high-dimensional datasets or strict latency budgets.

  • Even $k$ in binary problems: ties.

09 Check yourself

Q1With $k = 1$, training accuracy is:

Why: Every training point finds itself at distance 0.

Q2What usually happens to the boundary as $k$ grows?

Why: More voters mean isolated points get outvoted.

Q3What geometric structure divides the feature space into individual decision cells when $k = 1$?

Why: For 1-NN, the space is partitioned into Voronoi cells, where each cell consists of all points closer to one specific training example than to any other.

Q4Why is it common practice to choose an odd number for $k$ (e.g. $k = 3, 5, 7$) in binary classification problems?

Why: In binary classification with uniform weights, an even $k$ (like $k=4$) can result in a 2–2 tie, requiring an arbitrary tie-breaking rule. An odd $k$ guarantees a strict majority.

Q5How does KNeighborsClassifier estimate class probabilities (predict_proba) for a query point?

Why: With uniform weights, $P(y=c \mid x) = \frac{1}{k}\sum_{i \in N_k(x)} \mathbb{1}[y_i = c]$. For example, if 4 out of 5 neighbours belong to class 1, the predicted probability is $4/5 = 0.80$.

Q6According to the Cover & Hart (1967) theorem, what is the upper bound on the asymptotic error rate $R_{1\text{NN}}$ of a 1-Nearest Neighbour classifier as $n \to \infty$ relative to the optimal Bayes error rate $R^*$?

Why: Cover and Hart proved that with infinite data, the 1-NN error rate is bounded by at most twice the irreducible Bayes error: $R^* \le R_{1\text{NN}} \le 2R^*(1 - R^*)$. If the Bayes error is $0$, 1-NN also achieves $0$ error.

Q7Why does omitting feature standardisation severely harm k-NN classification accuracy?

Why: Distance is computed across all dimensions. If feature 1 has variance 10,000 and feature 2 has variance 1, distance along feature 1 completely dictates who the nearest neighbours are, ignoring feature 2.

Q8In scikit-learn, what distance metric does KNeighborsClassifier use by default with metric='minkowski' and p=2?

Why: The Minkowski distance is defined as $D(x, y) = (\sum |x_i - y_i|^p)^{1/p}$. Setting $p=2$ yields standard Euclidean distance $\sqrt{\sum (x_i - y_i)^2}$, while $p=1$ yields Manhattan distance.

Q9What challenge does a k-NN classifier face when applied to highly imbalanced datasets (e.g. 99% negative class, 1% positive class)?

Why: Because nearest neighbours are drawn from the overall population, the dense majority class surrounds isolated minority instances. Unless neighbours are weighted or balanced sampling is used, the majority class will routinely win the vote.

Q10A 3-NN classifier ($k=3$) with inverse-distance weighting $w_i = 1 / d(x, x_i)$ evaluates a test point. The 3 nearest neighbours have: Neighbour 1 (Class A, distance $d_1 = 1.0$), Neighbour 2 (Class B, distance $d_2 = 2.0$), Neighbour 3 (Class B, distance $d_3 = 2.0$). Which class wins the vote, and what is the predicted probability $P(\text{Class A} \mid x)$?

Why: $w_1 = 1 / 1.0 = 1.0$ (Class A). $w_2 = 1 / 2.0 = 0.5$ (Class B). $w_3 = 1 / 2.0 = 0.5$ (Class B). Total weight for Class A $= 1.0$; for Class B $= 0.5 + 0.5 = 1.0$. Both classes receive exactly equal weighted votes (a tie with $P = 0.500$).

Q11A query point is at $(0, 0)$. Two candidate training points are $P_1(2, 2)$ and $P_2(0, 3)$. Which point is closer under Euclidean distance ($L_2$), and which is closer under Manhattan distance ($L_1$)?

Why: For $P_1(2, 2)$: $L_2 = \sqrt{2^2 + 2^2} = \sqrt{8} \approx 2.828$, while $L_1 = |2| + |2| = 4.0$. For $P_2(0, 3)$: $L_2 = 3.0$ and $L_1 = 3.0$. Thus $P_1$ is closer under $L_2$ ($2.83 < 3.0$), while $P_2$ is closer under $L_1$ ($3.0 < 4.0$).

Q12If the optimal Bayes error rate for a two-class classification problem is $R^* = 0.10$ (10%), what is the theoretical upper bound on the asymptotic error rate of the 1-Nearest Neighbour classifier $R_{1\text{NN}}$ as sample size $n \to \infty$?

Why: By the Cover–Hart theorem: $R_{1\text{NN}} \le 2 R^* (1 - R^*)$. Substituting $R^* = 0.10$ gives $2 \times 0.10 \times 0.90 = 0.180$ (18.0%).
