01 The idea

An MLP stacks layers of "weighted sum, then a non-linear squash". With enough hidden units, it can approximate any smooth function. It learns its own features instead of you engineering them.

Each hidden unit computes $\text{ReLU}(w^\top x + b)$: a hinge that is flat on one side and sloped on the other. A layer of such hinges, added together, can trace any piecewise-linear curve; a second layer can combine those into more complex shapes.

Training uses Gradient descent: run a batch forward, measure squared error, use the chain rule (backpropagation) to get the gradient of the loss for every weight, nudge the weights downhill, repeat. Scaling inputs, a sensible learning rate and early stopping make or break the result.

In everyday terms

Building a curve out of many small adjustable hinges and letting the data decide where each hinge bends.

02 How it works

  1. Scale inputs (and often the target).
  2. Forward pass: $h = \sigma(W_1x + b_1)$, $\hat y = W_2h + b_2$.
  3. Compute the loss, e.g. mean squared error plus an L2 penalty.
  4. Backward pass: chain rule from the output to every weight.
  5. Update weights with Adam or SGD; repeat for many epochs with early stopping.

04 The maths

  1. Forward pass (one hidden layer)

    $$h = \sigma(W_1 x + b_1), \qquad \hat y = W_2 h + b_2$$

    $\sigma$ is the activation: ReLU $\max(0, z)$, tanh, or logistic.

  2. Backpropagation

    $$\frac{\partial L}{\partial W_2} = (\hat y - y)\,h^\top, \qquad \frac{\partial L}{\partial W_1} = \big[(W_2^\top(\hat y - y)) \odot \sigma'(z_1)\big]\,x^\top$$

    The error signal flows backwards and is multiplied by each layer’s local derivative.

06 When to use it

Strengths

  • Learns non-linear features automatically.
  • Scales to large data with mini-batches.
  • The foundation for every deep learning model.

Limitations

  • Needs scaling and tuning; sensitive to initialisation.
  • Usually beaten by gradient boosting on small tabular data.
  • Hard to interpret.

Reach for it when

Large datasets, smooth non-linear signal, or as a stepping stone to deep learning.

Think twice when

Small tabular datasets where boosting is faster and stronger.

07 In code

python
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.neural_network import MLPRegressor

mlp = make_pipeline(StandardScaler(),
                    MLPRegressor(hidden_layer_sizes=(64, 32), alpha=1e-3, learning_rate_init=1e-3,
                                 early_stopping=True, max_iter=2000, random_state=0))
mlp.fit(X_tr, y_tr)
print("test R2:", round(mlp.score(X_te, y_te), 3))

Common pitfalls

  • Not scaling inputs, which makes training slow or unstable.
  • Judging by one random seed; results vary with initialisation.
