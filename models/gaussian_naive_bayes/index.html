01 The idea

Naive Bayes applies Bayes’ rule with one bold simplification: given the class, every feature is independent. For continuous features, each one gets its own 1-D Gaussian per class.

Estimating a full joint distribution over many features needs huge amounts of data. Assuming independence breaks it into one tiny 1-D problem per feature and class: just a mean and a variance. Training is a single pass over the data.

The assumption is almost never true, but for classification you only need the ranking of class probabilities to be right, not the probabilities themselves. That is why Naive Bayes often classifies well while being badly calibrated.

In everyday terms

Judging each piece of evidence separately and multiplying the odds together, as if no two clues were related.

02 How it works

  1. For each class, compute the prior $\pi_k$.
  2. For each class and feature, compute the mean and variance.
  3. For a new point, add up the log-likelihood of each feature under each class plus the log prior.
  4. Predict the class with the highest total.

04 The maths

  1. Naive Bayes decision rule

    $$\hat y = \arg\max_k \;\log\pi_k + \sum_{j=1}^p \log \mathcal N(x_j;\, \mu_{kj}, \sigma_{kj}^2)$$

    Independence turns the joint likelihood into a product, so the log-likelihood is a sum over features.

06 When to use it

Strengths

  • Extremely fast; one pass to train.
  • Works with very little data.
  • Handles many features gracefully.

Limitations

  • Independence assumption ignores correlated features (they are double-counted).
  • Probabilities are poorly calibrated.
  • Each feature must be roughly Gaussian within a class.

Reach for it when

A fast baseline, streaming data, or very small datasets.

Think twice when

Strongly correlated features or when you need trustworthy probabilities.

07 In code

python
from sklearn.naive_bayes import GaussianNB
from sklearn.calibration import CalibratedClassifierCV

nb = GaussianNB().fit(X_tr, y_tr)
print("accuracy:", round(nb.score(X_te, y_te), 3))
calibrated = CalibratedClassifierCV(GaussianNB(), method="isotonic", cv=5).fit(X_tr, y_tr)

Common pitfalls

  • Feeding it duplicated or highly correlated features: their evidence is counted twice.
  • Trusting predict_proba as real probabilities without calibration.

09 Check yourself

Q1The "naive" assumption is that:

Why: Conditional independence lets the joint likelihood factor into per-feature terms.

Q2Why can Naive Bayes classify well even when its probabilities are off?

Why: The arg max can be correct even if the scores are overconfident.

Q3How many parameters per class does Gaussian Naive Bayes estimate for $p$ continuous features?

Why: Because Gaussian Naive Bayes assumes features are independent within each class, each feature $j$ requires only its own mean $\mu_{kj}$ and variance $\sigma_{kj}^2$, totalling $2p$ parameters per class.

Q4What is the training time complexity of Gaussian Naive Bayes with $n$ samples and $p$ features?

Why: Gaussian Naive Bayes computes sample means and variances in a single linear pass ($\mathcal{O}(n \cdot p)$), making it one of the fastest classification models to train on large tabular datasets.

Q5What happens when you train Gaussian Naive Bayes on a dataset containing two identical, perfectly correlated features ($x_2 = x_1$)?

Why: Because Naive Bayes assumes conditional independence, it multiplies probabilities $P(x_1 \mid y)P(x_2 \mid y) = P(x_1 \mid y)^2$. In log-space, this doubles the log-likelihood contribution of that attribute, effectively giving it twice the voting power of other features.

Q6Why are the predicted class probabilities (predict_proba) from Gaussian Naive Bayes often poorly calibrated (heavily pushed towards 0.0 or 1.0)?

Why: In real datasets, features are rarely completely independent given the class. Multiplying together many non-independent likelihood ratios compounds evidence exponentially, driving predicted probabilities to extreme values near 0 or 1 even when the true uncertainty is moderate.

Q7In scikit-learn's GaussianNB, what is the purpose of the var_smoothing parameter (default $10^{-9}$)?

Why: If a feature in a class is constant or has very low variance, $\sigma_{kj}^2 \approx 0$, causing division by zero in the exponent and $-\infty$ in log-likelihood. var_smoothing adds $\epsilon \cdot \max(\sigma^2)$ to each variance for numerical stability.

Q8What shape do the decision boundaries of Gaussian Naive Bayes form in 2D feature space when features have different variances across classes?

Why: Because covariances between features are zero, cross-product terms $x_1 x_2$ vanish, but the squared terms $x_1^2$ and $x_2^2$ remain. This produces quadratic boundaries whose principal axes are strictly parallel to the coordinate axes (axis-aligned conics).

Q9How can Gaussian Naive Bayes handle missing feature values during prediction without prior imputation?

Why: Under conditional independence, integrating out a missing feature $\int P(x_{\text{miss}} \mid y) dx_{\text{miss}} = 1$. In log space, $\log 1 = 0$, so missing features can simply be skipped in the summation without biasing the remaining observed evidence.

Q10A Gaussian NB model has two classes with equal priors ($\pi_1 = \pi_2 = 0.5$). Class 1 has $\mu_1 = 0.0, \sigma_1^2 = 1.0$, and Class 2 has $\mu_2 = 2.0, \sigma_2^2 = 1.0$. For a test point at $x = 0.5$, what is the difference in log-likelihoods $\log P(x \mid y=1) - \log P(x \mid y=2)$?

Why: Because variances are equal, normalising constants cancel. The difference is $\frac{(x - \mu_2)^2 - (x - \mu_1)^2}{2\sigma^2} = \frac{(0.5 - 2.0)^2 - (0.5 - 0.0)^2}{2(1.0)} = \frac{2.25 - 0.25}{2.0} = +1.0$. Class 1 is $e^{1.0} \approx 2.72$ times more likely.

Q11In a binary problem with equal priors, features are independent. For query point $x$, Class 1 yields feature likelihoods $P(x_1 \mid y=1) = 0.40$ and $P(x_2 \mid y=1) = 0.30$. Class 2 yields $P(x_1 \mid y=2) = 0.10$ and $P(x_2 \mid y=2) = 0.20$. What is the posterior probability $P(y=1 \mid x)$?

Why: Class 1 joint: $0.40 \times 0.30 = 0.12$. Class 2 joint: $0.10 \times 0.20 = 0.02$. Normalised posterior: $P(y=1 \mid x) = \frac{0.12}{0.12 + 0.02} = \frac{0.12}{0.14} = \frac{6}{7} \approx 0.857$.

Q12Consider Class 1 ($\mu_1 = 0, \sigma_1^2 = 1$) and Class 2 ($\mu_2 = 0, \sigma_2^2 = 9$) with equal priors in 1D. What are the decision boundaries between the two classes? (Given $\log(9) \approx 2.197$).

Why: Equating scores: $-\frac{1}{2}\log(1) - \frac{x^2}{2} = -\frac{1}{2}\log(9) - \frac{x^2}{18} \implies -\frac{4}{9}x^2 = -1.0986 \implies x^2 = \frac{1.0986 \times 9}{4} \approx 2.472 \implies x = \pm 1.572$. Any point with $|x| < 1.572$ is classified as Class 1; points outside are Class 2.
