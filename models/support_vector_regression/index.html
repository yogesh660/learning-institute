Support Vector Regression (SVR)

Fits a tube of width ε around the data and only penalises points outside it. Kernels make the tube bend.

01 The idea

SVR looks for the flattest function that keeps most points inside a tube of half-width $\varepsilon$. Errors inside the tube are free; only points on or outside it, the support vectors, shape the model.

Most regression losses punish every error. SVR’s ε-insensitive loss says "being within $\varepsilon$ is good enough". This makes the model ignore small noise and depend on only a subset of the data.

$C$ sets the price of points outside the tube. Small $C$ prefers a flat, simple function and tolerates violations; large $C$ bends hard to pull every point inside. With an RBF kernel the function can follow curves, with $\gamma$ controlling how local each support vector’s influence is.

In everyday terms

Laying a flexible pipe of fixed diameter through a scatter of points: you want it as straight as possible while keeping most points inside it.

02 How it works

  1. Scale the features and usually the target.
  2. Pick a kernel (RBF by default) and set $\varepsilon$ to the noise level you are happy to ignore.
  3. Solve the convex dual problem; only points on or outside the tube get non-zero coefficients.
  4. Predict with a weighted sum of kernel similarities to the support vectors.

03 Try it

An RBF-kernel SVR fitted live. The shaded band is the ε-tube; ringed points are support vectors.

Things to try
  1. Widen ε and count how many support vectors remain.
  2. Lower C to 0.1: the fit flattens and many points sit outside the tube.
  3. Raise γ: each support vector’s influence gets local and the curve wiggles.

04 The maths

  1. Primal problem

    $$\min_{w,b,\xi,\xi^*} \frac12\lVert w\rVert^2 + C\sum_i(\xi_i + \xi_i^*) \;\;\text{s.t.}\;\; |y_i - w^\top\phi(x_i) - b| \le \varepsilon + \xi_i^{(*)}$$

    $\tfrac12\lVert w\rVert^2$ asks for flatness; the slack variables $\xi$ measure how far each point sits outside the tube.

  2. Dual form and prediction

    $$f(x) = \sum_{i \in SV} (\alpha_i - \alpha_i^*)\, K(x_i, x) + b, \qquad K(x, x') = e^{-\gamma\lVert x - x'\rVert^2}$$

    Points strictly inside the tube have $\alpha_i = \alpha_i^* = 0$ and drop out. The kernel trick means $\phi$ is never computed explicitly.

06 When to use it

Strengths

  • Robust to small noise by design.
  • Sparse: depends only on support vectors.
  • Flexible non-linear fits via kernels.

Limitations

  • Training scales roughly $O(n^2)$–$O(n^3)$: impractical beyond tens of thousands of rows.
  • Three interacting hyperparameters.
  • No native uncertainty estimates.

Reach for it when

Small to medium tabular data with non-linear structure and noise of known size.

Think twice when

Large datasets; prefer gradient boosting, or approximate kernels (Nystroem) plus a linear model.

07 In code

python
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVR
from sklearn.compose import TransformedTargetRegressor

svr = make_pipeline(StandardScaler(), SVR(kernel="rbf", C=10, epsilon=0.1, gamma="scale"))
model = TransformedTargetRegressor(regressor=svr, transformer=StandardScaler()).fit(X_tr, y_tr)
print("support vectors:", len(model.regressor_[-1].support_))

Common pitfalls

  • Leaving the target unscaled, so $\varepsilon = 0.1$ means something very different from what you intended.
  • Tuning $C$ and $\gamma$ separately; they interact, so search them jointly.

09 Check yourself

Q1Which training points are support vectors in SVR?

Why: Points comfortably inside the tube incur no loss and get zero dual weight.

Q2Increasing ε usually leads to:

Why: A wider tube contains more points for free, so fewer points constrain the solution.

Q3What is the $\varepsilon$-insensitive loss function used in Support Vector Regression?

Why: The $\varepsilon$-insensitive loss assigns zero penalty to any prediction error smaller than or equal to $\varepsilon$, and penalises errors linearly as $|y - f(x)| - \varepsilon$ beyond the tube boundary.

Q4What does regularisation parameter $C$ control in Support Vector Regression?

Why: $C$ governs how heavily points lying outside the $\varepsilon$-tube are penalised. A large $C$ forces the model to fit every point strictly, while a small $C$ prioritises a flatter, smoother function.

Q5In the dual prediction formula $f(x) = \sum_{i \in SV} (\alpha_i - \alpha_i^*) K(x_i, x) + b$, what do the dual variables $\alpha_i$ and $\alpha_i^*$ represent?

Why: SVR uses two sets of non-negative Lagrange multipliers: $\alpha_i$ for points lying on or above the upper tube boundary, and $\alpha_i^*$ for points lying on or below the lower tube boundary. At most one can be non-zero for any given point.

Q6Why is target scaling particularly crucial in SVR when using a fixed default $\varepsilon = 0.1$?

Why: Because $\varepsilon$ is an absolute threshold in target units, $\varepsilon = 0.1$ is microscopic if targets range in hundreds of thousands, forcing nearly all data points to become support vectors. Standardising $y$ ensures $\varepsilon = 0.1$ represents $0.1$ standard deviations.

Q7In SVR with an RBF kernel $K(x, x') = \exp(-\gamma \lVert x - x'\rVert^2)$, what happens when $\gamma$ is set to an excessively large value?

Why: Large $\gamma$ means kernel similarity decays rapidly with distance. Each support vector acts only within an isolated narrow neighbourhood, producing a jagged function that collapses to the bias $b$ almost everywhere between training points.

Q8In the SVR dual formulation, what determines whether a support vector lies exactly on the boundary of the $\varepsilon$-tube versus strictly outside it?

Why: By the Karush–Kuhn–Tucker conditions, points strictly inside have $\alpha_i^{(*)} = 0$. Points exactly on the boundary have zero slack $\xi_i = 0$ but non-zero dual weight $0 < \alpha_i^{(*)} < C$ (free support vectors). Points violating the tube have positive slack $\xi_i > 0$ and their dual weight is capped at the box constraint $\alpha_i^{(*)} = C$.

Q9What is the computational bottleneck when training an SVR model on large datasets?

Why: Standard SVR solves a quadratic program with $2n$ variables and an $n \times n$ kernel matrix. While decomposition algorithms like SMO help, training time still scales roughly quadratically with sample size $n$, making exact kernel SVR slow for massive datasets.

Q10An SVR model with $\varepsilon = 1.5$ predicts the following values for three training samples: Sample 1 ($y_1 = 10.0, \hat{y}_1 = 11.0$), Sample 2 ($y_2 = 5.0, \hat{y}_2 = 1.0$), Sample 3 ($y_3 = 8.0, \hat{y}_3 = 9.5$). What is the total $\varepsilon$-insensitive loss $\sum_{i=1}^3 L_\varepsilon(y_i, \hat{y}_i)$?

Why: Sample 1 error is $|10.0 - 11.0| = 1.0 \le 1.5$, so loss is $0$. Sample 2 error is $|5.0 - 1.0| = 4.0 > 1.5$, giving loss $4.0 - 1.5 = 2.5$. Sample 3 error is $|8.0 - 9.5| = 1.5 \le 1.5$, so loss is $0$. Total loss is $0 + 2.5 + 0 = 2.5$.

Q11An SVR model with bias $b = 1.0$ has two support vectors: $x_1 = 0.0$ with $(\alpha_1 - \alpha_1^*) = +2.0$, and $x_2 = 2.0$ with $(\alpha_2 - \alpha_2^*) = -1.0$. Using a Gaussian RBF kernel $K(x, x') = \exp(-\gamma (x - x')^2)$ with $\gamma = 0.5$, what is the predicted value $f(x_*)$ at query point $x_* = 0.0$? (Note: $e^{-2.0} \approx 0.135$).

Why: $K(0, 0) = \exp(0) = 1.0$, and $K(2, 0) = \exp(-0.5 \times (2-0)^2) = \exp(-2.0) \approx 0.135$. The prediction is $(\alpha_1 - \alpha_1^*) K(x_1, 0) + (\alpha_2 - \alpha_2^*) K(x_2, 0) + b = (+2.0)(1.0) + (-1.0)(0.135) + 1.0 = 2.0 - 0.135 + 1.0 = 2.865$.

Q12Under the KKT conditions for SVR, why is it mathematically impossible for both $\alpha_i > 0$ and $\alpha_i^* > 0$ to hold simultaneously for the same training point $x_i$?

Why: By KKT complementarity, $\alpha_i > 0 \implies y_i - f(x_i) = \varepsilon + \xi_i$ and $\alpha_i^* > 0 \implies f(x_i) - y_i = \varepsilon + \xi_i^*$. Adding these equations yields $0 = 2\varepsilon + \xi_i + \xi_i^*$. Because $\varepsilon > 0$ and slacks are non-negative, $2\varepsilon + \xi_i + \xi_i^* > 0$, creating a contradiction. Thus at most one can be non-zero.
