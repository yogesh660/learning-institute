01 The idea

A regression tree asks a sequence of yes/no questions ("is income > 4.2?") and predicts the average target of the training rows that land in the same leaf. The result is a step function.

At each node the tree tries every feature and every threshold, and keeps the split that most reduces the squared error of the two children. It repeats this recursively on each side. Greedy, simple, and surprisingly effective.

Unchecked, a tree keeps splitting until each leaf holds one row: perfect on training data, poor on new data. Depth limits, minimum leaf sizes or cost-complexity pruning stop it early. Trees need no feature scaling and handle interactions naturally, which is why they are the building block of forests and boosting.

In everyday terms

A game of twenty questions where every answer narrows down the price range.

02 How it works

  1. For every feature and candidate threshold, compute the drop in squared error from splitting there.
  2. Make the best split and send rows left or right.
  3. Repeat on each child until a stopping rule triggers (max depth, min samples per leaf).
  4. Each leaf predicts the mean target of its training rows.
  5. Optionally prune back branches that do not pay for their complexity.

  2. At depth 10 the tree chases noise; watch test RMSE rise.
  3. Raise the minimum leaf size instead of lowering depth: a different way to regularise.

04 The maths

  1. Split criterion (variance reduction)

    $$\Delta = \sum_{i \in P}(y_i - \bar y_P)^2 - \Big[\sum_{i \in L}(y_i - \bar y_L)^2 + \sum_{i \in R}(y_i - \bar y_R)^2\Big]$$

    The tree picks the feature and threshold that maximise $\Delta$: the biggest drop in squared error from parent $P$ to children $L$ and $R$.

  2. Cost-complexity pruning

    $$R_\alpha(T) = \sum_{\text{leaves } m} \sum_{i \in m} (y_i - \bar y_m)^2 + \alpha\,|T|$$

    $|T|$ is the number of leaves. Larger $\alpha$ prefers smaller trees; scikit-learn exposes it as ccp_alpha.

06 When to use it

Strengths

  • Readable: the model is a flowchart.
  • No scaling needed; handles mixed feature types and interactions.
  • Fast to train and predict.

Limitations

  • High variance: small data changes can change the whole tree.
  • Predictions are piecewise constant (blocky).
  • Cannot extrapolate beyond the training range.

Reach for it when

You need an explainable model, or as the base learner for ensembles.

Think twice when

You need the best accuracy from a single model: use an ensemble instead.

07 In code

python
from sklearn.tree import DecisionTreeRegressor, export_text

tree = DecisionTreeRegressor(max_depth=4, min_samples_leaf=20, random_state=0).fit(X_tr, y_tr)
print("test R2:", round(tree.score(X_te, y_te), 3))
print(export_text(tree, feature_names=list(X.columns)))   # the whole model as rules

Common pitfalls

  • Growing the tree to full depth and being surprised by poor test scores.
  • Reading feature importances from a single deep tree; they are unstable.

09 Check yourself

Q1What does a leaf of a regression tree predict?

Why: The mean minimises squared error within the leaf.

Q2Why don’t trees need feature scaling?

Why: "Income > 4.2" and "income > 4200" partition the rows identically.

Q3What is the geometric nature of the prediction surface generated by a Decision Tree Regressor?

Why: Because every decision node splits on a single feature against a scalar threshold ($x_j \le t$), the input space is partitioned into orthogonal axis-aligned boxes. Within each box (leaf), the prediction is a constant scalar.

Q4How does cost-complexity pruning (controlled by ccp_alpha $\alpha$) regularise a regression tree?

Why: Cost-complexity pruning trades off training fit against tree size. A branch is collapsed into a single leaf unless its presence reduces the sum of squared errors by more than $\alpha$.

Q5Suppose the target values in your training set range between \$100k and \$500k. If a new test instance has an extreme feature value twice as high as any seen in training, what will a Decision Tree Regressor predict?

Why: Regression trees output the average of the training points falling into the matched terminal leaf. For extreme input values, the instance simply falls into the outermost bounding leaf, outputting that leaf's constant mean.

Q6Why are feature importances derived from a single unpruned decision tree notoriously unreliable?

Why: CART is a greedy algorithm. If two features offer nearly identical initial variance reduction, a tiny change in one row can swap which feature is chosen at the root, completely reshaping the tree and reallocating importance scores.

Q7What is the effect of increasing the min_samples_leaf hyperparameter in DecisionTreeRegressor?

Why: Larger min_samples_leaf smooths predictions by ensuring every leaf prediction is an average of a sufficiently large sample, preventing the tree from memorising isolated training points.

Q8If you want a decision tree regressor to predict the conditional median rather than the conditional mean in each leaf, which split criterion should you set in scikit-learn?

Why: Under criterion='absolute_error', the tree minimises the L1 loss within each terminal node. The constant value that minimises sum of absolute deviations $\sum |y_i - c|$ is the median.

Q9Why can a deep regression tree easily achieve a training $R^2$ of $1.0$ (zero Mean Squared Error) while performing terribly on validation data?

Why: With max_depth=None and min_samples_split=2, a tree splits until each leaf has 1 row (or identical $X$). The leaf prediction equals that row's exact label, giving zero training error but extreme variance.

Q10A parent node $P$ contains 4 observations with target values $\{2, 4, 6, 8\}$ (parent mean $\bar{y}_P = 5$). A candidate split partitions the data into a left child $L = \{2, 4\}$ and a right child $R = \{6, 8\}$. What is the reduction in sum of squared errors ($\Delta = \mathrm{SSE}_P - [\mathrm{SSE}_L + \mathrm{SSE}_R]$) achieved by this split?

Why: Parent $\mathrm{SSE}_P = (2-5)^2 + (4-5)^2 + (6-5)^2 + (8-5)^2 = 9 + 1 + 1 + 9 = 20.0$. Left child mean is $3$: $\mathrm{SSE}_L = (2-3)^2 + (4-3)^2 = 1 + 1 = 2.0$. Right child mean is $7$: $\mathrm{SSE}_R = (6-7)^2 + (8-7)^2 = 1 + 1 = 2.0$. Total child $\mathrm{SSE} = 2.0 + 2.0 = 4.0$. Reduction $\Delta = 20.0 - 4.0 = 16.0$.

Q11A decision tree has 3 terminal leaves with target samples: Leaf 1 has $\{10, 12, 14\}$ ($n_1 = 3$); Leaf 2 has $\{20, 24\}$ ($n_2 = 2$); Leaf 3 has $\{30\}$ ($n_3 = 1$). What are the model's predictions $\hat{y}$ for test instances that fall into Leaf 1, Leaf 2, and Leaf 3 respectively?

Why: Each leaf predicts the mean of its training observations. Leaf 1: $(10 + 12 + 14)/3 = 36/3 = 12.0$. Leaf 2: $(20 + 24)/2 = 44/2 = 22.0$. Leaf 3: $30/1 = 30.0$.

Q12In cost-complexity pruning, the penalised objective is $R_\alpha(T) = \sum_{m=1}^{|T|} \mathrm{SSE}_m + \alpha |T|$. Suppose an unpruned subtree with $|T| = 5$ leaves has total $\mathrm{SSE} = 50.0$. Collapsing this subtree into a single parent leaf ($|T_{\text{collapsed}}| = 1$) increases total $\mathrm{SSE}$ to $95.0$. What is the critical threshold $\alpha$ above which the collapsed 1-leaf tree has a lower cost-complexity score than the 5-leaf subtree?

Why: 5-leaf cost: $50 + 5\alpha$. 1-leaf cost: $95 + 1\alpha$. Collapsing is preferred when $95 + \alpha < 50 + 5\alpha \implies 45 < 4\alpha \implies \alpha > 45/4 = 11.25$. For any $\alpha > 11.25$, the 5-leaf complexity penalty outweighs its 45-unit SSE improvement, so pruning occurs.
