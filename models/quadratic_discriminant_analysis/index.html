Quadratic Discriminant Analysis (QDA)

01 The idea

Give each class its own covariance matrix and the quadratic terms no longer cancel. The boundary becomes a conic: an ellipse, parabola or hyperbola.

If one class is a tight cluster and the other is spread out, the natural boundary wraps around the tight one. LDA cannot do that; QDA can.

The cost is parameters: each class needs a full $p \times p$ covariance, about $Kp^2/2$ numbers. With few rows per class those estimates are noisy, so QDA overfits faster than LDA. reg_param blends each covariance with the identity to stabilise it.

In everyday terms

Each class is a cloud with its own shape. A tight cloud gets a tight fence around it.

02 How it works

  1. Estimate each class prior, mean and its own covariance $\Sigma_k$.
  2. Score each class with a quadratic function of $x$.
  3. Predict the highest score.

03 Try it

QDA fitted live, with one covariance ellipse per class. The boundary curves to wrap around the tighter class.

Things to try
  1. On "different spreads", the boundary closes into an ellipse around the tight class.
  2. Raise reg_param to 1: both ellipses become circles and the boundary straightens.

04 The maths

  1. Quadratic discriminant

    $$\delta_k(x) = -\tfrac12\log|\Sigma_k| - \tfrac12(x - \mu_k)^\top\Sigma_k^{-1}(x - \mu_k) + \log\pi_k$$

    The middle term is the squared Mahalanobis distance to class $k$’s centre, measured in that class’s own shape.

06 When to use it

Strengths

  • Captures classes with different spreads and orientations.
  • Closed-form and fast.
  • Gives class probabilities.

Limitations

  • Many parameters; needs enough rows per class.
  • Still assumes Gaussian classes.
  • Unstable when features are collinear.

Reach for it when

Moderate number of features, plenty of rows per class, and classes that clearly differ in spread.

Think twice when

Many features or small classes; prefer LDA or regularised logistic regression.

07 In code

python
from sklearn.discriminant_analysis import QuadraticDiscriminantAnalysis

qda = QuadraticDiscriminantAnalysis(reg_param=0.1).fit(X_tr, y_tr)
print("test accuracy:", round(qda.score(X_te, y_te), 3))

Common pitfalls

  • Using QDA with more features than rows in a class: the covariance is singular.

09 Check yourself

Q1QDA differs from LDA by:

Why: Separate covariances keep the quadratic term in each score, so boundaries curve.

Q2QDA with 50 features and 2 classes estimates roughly how many covariance numbers?

Why: Each symmetric $50\times 50$ matrix has $50\cdot 51/2 = 1275$ free numbers; two classes give 2,550.

Q3What geometric shapes can the decision boundaries of Quadratic Discriminant Analysis take in 2D space?

Why: Because each class has its own covariance matrix $\Sigma_k$, the quadratic terms $x^\top \Sigma_k^{-1} x$ do not cancel out, resulting in general quadratic equations whose 2D level sets are conic sections (ellipses, parabolas, and hyperbolas).

Q4What does the regularisation parameter reg_param in scikit-learn's QuadraticDiscriminantAnalysis do?

Why: reg_param prevents covariance matrix singularity when data is sparse by shrinking each class covariance towards an identity matrix, stabilising the determinant and matrix inversion.

Q5When is QDA strongly preferred over LDA?

Why: If class shapes and orientations differ substantially, LDA's forced pooled covariance assumption creates severe misclassification; QDA allows each class to have its own orientation and scale.

Q6Why is QDA much more prone to overfitting than LDA when sample sizes are small?

Why: In $p$ dimensions, each symmetric covariance matrix has $p(p+1)/2$ unique parameters. Estimating $K$ distinct matrices requires roughly $K$ times as many parameters as LDA, demanding significantly more training data per class to prevent noisy covariance estimates.

Q7What happens if a particular class $k$ in QDA contains fewer training samples than the number of features ($n_k < p$)?

Why: An empirical covariance matrix estimated from $n_k$ samples has rank at most $n_k - 1$. If $n_k < p$, $\Sigma_k$ is rank-deficient and singular, making its inverse and log-determinant undefined without shrinkage.

Q8In the QDA discriminant score $\delta_k(x) = -\frac{1}{2}\log|\Sigma_k| - \frac{1}{2}(x - \mu_k)^\top \Sigma_k^{-1}(x - \mu_k) + \log\pi_k$, what is the role of the $-\frac{1}{2}\log|\Sigma_k|$ term?

Why: The determinant $|\Sigma_k|$ measures the volume of the class's covariance ellipsoid. A large determinant means probability mass is spread over a wide region, reducing peak density; the $-\frac{1}{2}\log|\Sigma_k|$ term penalises this spatial dispersion.

Q9How does Gaussian Naive Bayes relate mathematically to Quadratic Discriminant Analysis?

Why: By assuming features are conditionally independent given the class, Gaussian Naive Bayes forces all off-diagonal covariance entries $\operatorname{Cov}(x_j, x_m) = 0$, reducing each class's full $p \times p$ covariance matrix to a diagonal matrix with only $p$ parameters.

Q10For a multiclass problem with $K = 4$ classes and $p = 10$ continuous features, how many total independent parameters must QDA estimate (including priors, means, and class covariance matrices), assuming priors sum to 1?

Why: Priors: $K - 1 = 3$ parameters. Means: $K \times p = 4 \times 10 = 40$ parameters. Covariances: each symmetric $10 \times 10$ matrix has $10(11)/2 = 55$ parameters; 4 classes give $4 \times 55 = 220$. Total $= 3 + 40 + 220 = 263$ parameters.

Q11In a 1D classification task, Class 1 has $\mu_1 = 0.0, \sigma_1^2 = 1.0, \pi_1 = 0.5$ and Class 2 has $\mu_2 = 0.0, \sigma_2^2 = 4.0, \pi_2 = 0.5$. What are the decision boundaries where $\delta_1(x) = \delta_2(x)$? (Use $\log(4.0) \approx 1.386$).

Why: Equating scores: $-\frac{1}{2}\log(1) - \frac{x^2}{2} = -\frac{1}{2}\log(4) - \frac{x^2}{8} \implies -\frac{3}{8}x^2 = -0.693 \implies x^2 = \frac{0.693 \times 8}{3} = 1.848 \implies x = \pm 1.359$. Points inside $[-1.36, 1.36]$ belong to the compact Class 1; points outside belong to the dispersed Class 2.

Q12For Class 1 with mean $\mu_1 = [0, 0]^\top$ and diagonal covariance $\Sigma_1 = \begin{pmatrix} 4 & 0 \\ 0 & 1 \end{pmatrix}$, what is the squared Mahalanobis distance $(x - \mu_1)^\top \Sigma_1^{-1} (x - \mu_1)$ for the test point $x = [4, 1]^\top$?

Why: $\Sigma_1^{-1} = \begin{pmatrix} 1/4 & 0 \\ 0 & 1 \end{pmatrix}$. The squared Mahalanobis distance is $\frac{(4 - 0)^2}{4} + \frac{(1 - 0)^2}{1} = \frac{16}{4} + \frac{1}{1} = 4 + 1 = 5.0$. (The standard Euclidean squared distance would be $4^2 + 1^2 = 17.0$).
