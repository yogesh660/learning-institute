01 The idea

Of all the lines that separate two classes, pick the one that leaves the widest empty street between them. Only the points on the edge of the street, the support vectors, determine where it goes.

A wide margin is a safety buffer: small perturbations of the data do not flip predictions. Real data overlaps, so a soft margin lets some points sit inside the street or on the wrong side, at a cost set by $C$. Small $C$ means a wide, tolerant street; large $C$ means a narrow street that tries hard to classify every training point.

The kernel trick replaces dot products with a similarity function $K(x, x')$. The RBF kernel makes the boundary a weighted sum of bumps centred on support vectors, so it can wrap around any shape. $\gamma$ sets how wide each bump is.

In everyday terms

Laying the widest possible road between two villages; only the houses at the roadside matter.

02 How it works

  1. Scale features (distances drive everything).
  2. Choose a kernel: linear for many features, RBF otherwise.
  3. Solve the convex dual problem (SMO-style algorithms).
  4. Keep only the support vectors; predict with the sign of their weighted kernel sum.
  5. Use Platt scaling if you need probabilities.

03 Try it

An SVM trained live with the SMO algorithm. Ringed points are support vectors; dashed lines are the margins (where $f(x) = \pm 1$).

Things to try
  1. With a linear kernel, drop C to 0.01: the margin widens and more points become support vectors.
  2. Switch to RBF on "moons" and raise γ until the boundary hugs individual points.
  3. Count the support vectors: they are usually a small fraction of the data.

04 The maths

  1. Soft-margin primal

    $$\min_{w,b,\xi}\;\frac12\lVert w\rVert^2 + C\sum_i\xi_i \;\;\text{s.t.}\;\; y_i(w^\top x_i + b) \ge 1 - \xi_i,\;\; \xi_i \ge 0$$

    The margin width is $2/\lVert w\rVert$, so minimising $\lVert w\rVert$ widens it. Equivalent to minimising hinge loss plus an L2 penalty.

  2. Dual and the kernel trick

    $$\max_\alpha \sum_i\alpha_i - \tfrac12\sum_{i,j}\alpha_i\alpha_j y_iy_j K(x_i, x_j), \quad 0 \le \alpha_i \le C,\; \sum_i\alpha_iy_i = 0$$

    Only dot products appear, so any valid kernel can be swapped in. Points with $\alpha_i > 0$ are the support vectors.

  3. Decision function

    $$f(x) = \operatorname{sign}\Big(\sum_{i \in SV}\alpha_i y_i K(x_i, x) + b\Big)$$

    Prediction cost grows with the number of support vectors, not the training set size.

06 When to use it

Strengths

  • Strong on medium-sized, high-dimensional data.
  • Convex: one global optimum.
  • Kernels give flexible boundaries with good generalisation.

Limitations

  • Training cost grows quickly with $n$ (roughly $n^2$ to $n^3$).
  • Needs scaling and joint tuning of C and γ.
  • No native probabilities.

Reach for it when

Text classification (linear), small to medium tabular or image-feature data (RBF).

Think twice when

Hundreds of thousands of rows (use LinearSVC or gradient boosting).

07 In code

python
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC
from sklearn.model_selection import GridSearchCV

pipe = make_pipeline(StandardScaler(), SVC(kernel="rbf"))
grid = {"svc__C": [0.1, 1, 10, 100], "svc__gamma": ["scale", 0.01, 0.1, 1]}
search = GridSearchCV(pipe, grid, cv=5).fit(X_tr, y_tr)
print(search.best_params_, "support vectors:", search.best_estimator_[-1].n_support_)

Common pitfalls

  • Forgetting to scale; the RBF kernel is meaningless when one feature dominates distances.
  • Turning on probability=True and assuming the probabilities are consistent with predict; they come from a separate internal CV.

09 Check yourself

Q1Which points determine an SVM’s decision boundary?

Why: Points with $\alpha_i = 0$ could be removed without changing the solution.

Q2Increasing $\gamma$ in an RBF SVM tends to:

Why: Each support vector’s influence narrows, so the boundary can curve around individual points.

Q3The SVM objective is equivalent to minimising:

Why: $\xi_i = \max(0, 1 - y_if(x_i))$ is the hinge loss.

Q4What is the geometric margin between two linearly separable classes with separating hyperplane $w^\top x + b = 0$ (normalised such that $y_i(w^\top x_i + b) \ge 1$)?

Why: The distance from the hyperplane to the closest points on either side is $\frac{1}{\lVert w\rVert}$, so the total width of the margin between the two support vector planes is $\frac{2}{\lVert w\rVert}$. Maximising $\frac{2}{\lVert w\rVert}$ is equivalent to minimising $\frac{1}{2}\lVert w\rVert^2$.

Q5What does regularisation parameter $C$ control in a soft-margin Support Vector Classifier?

Why: In the primal objective $\frac{1}{2}\lVert w\rVert^2 + C \sum \xi_i$, $C$ determines how heavily margin violations are penalised. Large $C$ tolerates few misclassifications (narrow margin, risks overfitting); small $C$ tolerates violations in exchange for a wider margin.

Q6Why does the SVM dual formulation enable the kernel trick?

Why: The dual problem depends strictly on $K(x_i, x_j) = \langle\phi(x_i), \phi(x_j)\rangle$. Mercer's theorem allows computing inner products in infinite-dimensional Hilbert spaces directly in input space in $\mathcal{O}(p)$ time.

Q7In the soft-margin SVM dual formulation with box constraint $0 \le \alpha_i \le C$, which points have dual coefficient $\alpha_i = C$?

Why: By KKT complementarity conditions: points correctly classified outside the margin have $\alpha_i = 0$. Points exactly on the margin boundary have $0 < \alpha_i < C$ and $\xi_i = 0$ (free support vectors). Points inside the margin or misclassified have positive slack $\xi_i > 0$ and their weight hits the upper bound $\alpha_i = C$ (bounded support vectors).

Q8Why is feature standardisation (StandardScaler) critical before training an SVM with an RBF kernel?

Why: Euclidean distance treats coordinate differences identically. If one feature spans $[0, 1000]$ and another spans $[0, 1]$, the first completely dominates the RBF kernel distance, effectively blinding the model to the second feature.

Q9How does SVC in scikit-learn handle multiclass problems with $K > 2$ classes by default?

Why: Scikit-learn's SVC wraps LIBSVM, which implements the One-vs-One (OvO) decision strategy, fitting $\binom{K}{2} = K(K-1)/2$ separate binary classifiers and taking a majority vote.

Q10A linear SVM separating hyperplane in 2D is given by $3 x_1 + 4 x_2 - 5 = 0$. The support vectors lie on $3 x_1 + 4 x_2 - 5 = \pm 1$. What is the geometric width of the margin between the two classes?

Why: The weight vector is $w = [3, 4]^\top$, so $\lVert w\rVert = \sqrt{3^2 + 4^2} = 5.0$. The margin width is $\frac{2}{\lVert w\rVert} = \frac{2}{5.0} = 0.40$.

Q11An RBF SVM with $\gamma = 0.5$ and bias $b = 0.0$ has two support vectors: $x_1 = 0.0$ (Class $y_1 = +1$, $\alpha_1 = 2.0$), $x_2 = 2.0$ (Class $y_2 = -1$, $\alpha_2 = 1.0$). Using $K(x, x') = \exp(-\gamma(x - x')^2)$, what is the raw decision score $f(x_*) = \sum \alpha_i y_i K(x_i, x_*) + b$ at test point $x_* = 0.0$? (Note: $e^{-2.0} \approx 0.1353$).

Why: $K(0, 0) = 1.0$, and $K(2, 0) = \exp(-0.5 \times 4) = \exp(-2.0) \approx 0.1353$. Decision score: $f(0) = (2.0)(+1)(1.0) + (1.0)(-1)(0.1353) + 0 = 2.0 - 0.1353 = +1.8647 \approx +1.865$.

Q12An SVM decision function produces raw score $f(x) = w^\top x + b = 0.40$. What is the hinge loss $L(y, f(x)) = \max(0, 1 - y f(x))$ if the true label is $y = +1$, and what is it if the true label is $y = -1$?

Why: For $y = +1$: $1 - (1)(0.40) = 0.60 \implies$ loss is $0.60$ (inside the margin). For $y = -1$: $1 - (-1)(0.40) = 1 + 0.40 = 1.40 \implies$ loss is $1.40$.
