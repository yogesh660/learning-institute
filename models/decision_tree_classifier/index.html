01 The idea

A classification tree splits the data with yes/no questions chosen to make each side as pure as possible, then predicts the majority class in each leaf.

"Purity" is measured by Gini impurity or entropy. A node with 50/50 classes is maximally impure; a node with one class is pure. At each step the tree picks the question that reduces impurity the most. Splits are always axis-aligned, so boundaries look like staircases.

Left alone, a tree grows until every leaf is pure, memorising noise. Depth limits, minimum leaf sizes and pruning keep it honest. The pay-off is a model you can print and read.

02 How it works

  1. For each feature and threshold, compute the impurity of the two children.
  2. Choose the split with the largest impurity decrease.
  3. Recurse until a stopping rule triggers.
  4. Each leaf predicts its majority class (and class proportions as probabilities).

04 The maths

  1. Impurity measures

    $$\text{Gini}(t) = 1 - \sum_c p_c^2, \qquad H(t) = -\sum_c p_c\log_2 p_c$$

    Both are 0 for a pure node and largest for an even mix. They usually choose the same splits.

  2. Information gain

    $$\Delta I = I(\text{parent}) - \frac{n_L}{n}I(L) - \frac{n_R}{n}I(R)$$

    A weighted average, so a pure but tiny child does not win by default.

06 When to use it

Strengths

  • Interpretable rules.
  • No scaling; handles interactions and mixed types.
  • Fast.

Limitations

  • High variance: unstable to small data changes.
  • Axis-aligned boundaries struggle with diagonal patterns.
  • Greedy: no guarantee of the best tree.

Reach for it when

When people need to read the model, or as a base learner.

Think twice when

As your final model when accuracy matters; use a forest or boosting.

07 In code

python
from sklearn.tree import DecisionTreeClassifier, plot_tree
import matplotlib.pyplot as plt

tree = DecisionTreeClassifier(max_depth=3, min_samples_leaf=10, random_state=0).fit(X_tr, y_tr)
print("test accuracy:", round(tree.score(X_te, y_te), 3))
plot_tree(tree, feature_names=list(X_tr.columns), class_names=["no", "yes"], filled=True)
plt.show()

Common pitfalls

  • Unlimited depth: perfect training accuracy, disappointing test accuracy.
  • Assuming the top split is the "most important feature" in a causal sense.

09 Check yourself

Q1Gini impurity of a node with 80% class A and 20% class B?

Why: $1 - (0.8^2 + 0.2^2) = 1 - 0.68 = 0.32$.

Q2Why do decision-tree boundaries look like staircases?

Why: Each split is perpendicular to one feature axis.

Q3What is the minimum possible Gini impurity of a leaf node in a decision tree, and what does it indicate?

Why: For a pure node where $p_1 = 1.0$ and all other $p_c = 0$, $\text{Gini} = 1 - 1.0^2 = 0.0$. Gini impurity is always non-negative and equals zero if and only if the node is completely pure.

Q4Which algorithm is standard in scikit-learn for building classification decision trees?

Why: Scikit-learn implements an optimised version of the CART algorithm, which constructs binary trees using feature threshold splits ($x_j \le t$ versus $x_j > t$).

Q5How do strictly monotonic transformations of a feature (such as taking $\log(x)$ or multiplying by a positive constant) affect the split selection in a decision tree?

Why: Tree splitting evaluates order thresholds $x_j \le t$. Any strictly monotonic transformation preserves the relative ordering of data points, leaving the optimal split point and impurity reduction completely unchanged.

Q6Which hyperparameter directly prevents a decision tree from growing arbitrarily deep leaves that memorise individual noisy training rows?

Why: Setting max_depth caps tree height, while min_samples_leaf ensures no leaf can be created unless it contains at least a threshold number of training samples, preventing leaves from isolating single outlier points.

Q7How does Shannon entropy $H(t) = -\sum p_c \log_2 p_c$ compare with Gini impurity $1 - \sum p_c^2$ as a split criterion?

Why: Gini impurity and entropy are mathematically very similar curves (Gini approximates entropy via a Taylor series expansion of $\log$). Both favour pure nodes; entropy takes slightly longer to compute due to logarithmic evaluations.

Q8In scikit-learn's DecisionTreeClassifier, how is feature_importances_ (mean decrease in impurity) computed?

Why: Mean Decrease in Impurity tallies the weighted impurity improvement $\frac{n_t}{n}\Delta I(t)$ for every internal node where that feature was chosen to split, then normalises so the importances sum to 1.

Q9Why do decision trees often struggle to fit a simple diagonal decision boundary such as $x_1 + x_2 > 2$?

Why: Standard CART trees use univariate, axis-aligned splits ($x_j \le t$). Approximating a diagonal line requires a complex staircase of horizontal and vertical cuts, requiring high depth and many training samples.

Q10A parent node has 40 samples (20 Class A, 20 Class B). A candidate split divides it into: Left child (20 Class A, 0 Class B), Right child (0 Class A, 20 Class B). Using Gini impurity, what is the Gini information gain $\Delta \text{Gini} = \text{Gini}(\text{parent}) - \frac{n_L}{n}\text{Gini}(L) - \frac{n_R}{n}\text{Gini}(R)$?

Why: Parent has $p_A = 0.5, p_B = 0.5 \implies \text{Gini} = 1 - (0.5^2 + 0.5^2) = 0.50$. Both children are pure ($\text{Gini} = 0.0$). Weighted child impurity is $0.0$. Information gain is $0.50 - 0.0 = 0.50$.

Q11What is the Shannon entropy in bits ($H = -\sum p_c \log_2 p_c$) of a node containing 50% Class A, 25% Class B, and 25% Class C?

Why: $H = -[0.5 \log_2(0.5) + 0.25 \log_2(0.25) + 0.25 \log_2(0.25)] = -[0.5(-1.0) + 0.25(-2.0) + 0.25(-2.0)] = -[-0.5 - 0.5 - 0.5] = 1.50$ bits.

Q12A parent node of 10 samples has 6 positive and 4 negative instances ($\text{Gini} = 1 - (0.6^2 + 0.4^2) = 0.48$). A split sends 4 samples to the Left (all 4 positive) and 6 samples to the Right (2 positive, 4 negative). What is the weighted child Gini impurity $\frac{n_L}{n}\text{Gini}(L) + \frac{n_R}{n}\text{Gini}(R)$?

Why: Left child is pure ($\text{Gini} = 0.0$). Right child has $p = (1/3, 2/3) \implies \text{Gini} = 1 - (1/9 + 4/9) = 4/9 \approx 0.444$. Weighted child impurity is $\frac{4}{10}(0) + \frac{6}{10}(4/9) = 24/90 = 4/15 \approx 0.267$.
