The Perceptron

01 The idea

The perceptron computes $\operatorname{sign}(w^\top x + b)$. Whenever it misclassifies a point, it adds that point (times its label) to the weights. If the classes can be separated by a line, this simple rule is guaranteed to find one.

Picture the weight vector $w$ as an arrow perpendicular to the boundary. A misclassified positive point lies on the wrong side, so adding it to $w$ swings the arrow (and the boundary) toward it. A misclassified negative point is subtracted, which swings the boundary away.

Rosenblatt’s convergence theorem says that if a separating line exists with margin $\gamma$, the perceptron makes at most $(R/\gamma)^2$ mistakes. But if no line separates the classes, it never settles: it keeps cycling. Fixing that, by adding hidden layers and smooth activations, led to the multi-layer perceptron.

In everyday terms

A doorman with a checklist who adjusts how much each item counts every time he lets in the wrong person.

02 How it works

  1. Initialise $w = 0$, $b = 0$.
  2. Loop over the training points in random order.
  3. If $y_i(w^\top x_i + b) \le 0$, update $w \leftarrow w + \eta y_ix_i$ and $b \leftarrow b + \eta y_i$.
  4. Stop when an epoch passes with no mistakes, or after a set number of epochs.

04 The maths

  1. Update rule

    $$\text{if } y_i(w^\top x_i + b) \le 0: \quad w \leftarrow w + \eta\,y_i x_i, \quad b \leftarrow b + \eta\,y_i$$

    Labels are $\pm 1$. This is stochastic gradient descent on the "perceptron loss" $\max(0, -y_if(x_i))$.

  2. Novikoff’s bound

    $$\#\text{mistakes} \le \Big(\frac{R}{\gamma}\Big)^2, \qquad R = \max_i\lVert x_i\rVert$$

    On separable data the number of updates is finite, however many points there are.

06 When to use it

Strengths

  • Very simple, online, and fast.
  • Guaranteed to converge on separable data.
  • Historically and conceptually foundational.

Limitations

  • Never converges on non-separable data.
  • No probabilities and no margin maximisation.
  • Linear boundaries only.

Reach for it when

Teaching, online learning on separable streams, or as a building block to understand neural nets.

Think twice when

Real problems; use logistic regression or a linear SVM instead.

07 In code

python
from sklearn.linear_model import Perceptron
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

model = make_pipeline(StandardScaler(), Perceptron(max_iter=1000, tol=1e-3, random_state=0)).fit(X_tr, y_tr)
print("test accuracy:", round(model.score(X_te, y_te), 3), "epochs run:", model[-1].n_iter_)

Common pitfalls

  • Expecting convergence on overlapping classes.
  • Reading the final weights as meaningful when training stopped at an arbitrary epoch.

09 Check yourself

Q1When does the perceptron update its weights?

Why: Correct points with $y_if(x_i) > 0$ cause no update.

Q2On the XOR problem a single perceptron will:

Why: XOR is not linearly separable, so no single line classifies it.

Q3Which geometric object defines the decision boundary of a perceptron in a 2D feature space?

Why: The decision boundary is the affine hyperplane $w^\top x + b = 0$, which is a straight line in two dimensions.

Q4Why is a standard perceptron unable to output calibrated class probabilities like logistic regression?

Why: The perceptron outputs hard binary decisions via the step function $\operatorname{sign}(w^\top x + b)$ and does not model posterior class probabilities $P(y=1 \mid x)$.

Q5A perceptron has current weights $w = [1.0, -1.0]^\top$, bias $b = 0$, and learning rate $\eta = 1.0$. It encounters a training example $x = [2.0, 1.0]^\top$ with true label $y = -1$. What are the updated weights and bias?

Why: The predicted score is $w^\top x + b = 1(2) - 1(1) + 0 = +1$, so $y(w^\top x + b) = -1(+1) = -1 \le 0$ (a mistake). The update rule gives $w \leftarrow w + \eta y x = [1, -1]^\top + (-1)[2, 1]^\top = [-1, -2]^\top$, and $b \leftarrow 0 + (-1) = -1$.

Q6In a standard perceptron initialised at $w = 0, b = 0$, what happens if you change the learning rate $\eta$ from $1.0$ to $0.01$ (with identical sample ordering)?

Why: Since both $w$ and $b$ start at 0, every update is linear in $\eta$. The score $w^\top x + b$ at every step is simply scaled by $\eta$, so the sign $\operatorname{sign}(w^\top x + b)$ and the sequence of mistakes are completely invariant to $\eta > 0$.

Q7If the training dataset contains two classes that overlap and cannot be separated by any straight line, how does the perceptron learning algorithm behave when run without an iteration limit?

Why: The perceptron stops only when an entire epoch passes with zero mistakes. If no separating hyperplane exists, at least one point will always be misclassified in every epoch, causing the algorithm to loop endlessly.

Q8Both the perceptron and a hard-margin Linear Support Vector Classifier find a separating hyperplane on linearly separable data. What is the key difference in the boundary they select?

Why: The perceptron terminates as soon as all training points are correctly classified, meaning its final boundary depends heavily on initialisation and data ordering. A linear SVM explicitly maximises the geometric margin $\frac{2}{\|w\|}$, yielding a unique, robust boundary.

Q9The perceptron update rule can be viewed as stochastic gradient descent on which loss function for a single example $(x_i, y_i)$ with $y_i \in \{-1, +1\}$?

Why: When $y_i(w^\top x_i + b) \le 0$, the loss is $-y_i(w^\top x_i + b)$, whose sub-gradient with respect to $w$ is $-y_i x_i$. Subtracting the gradient ($\times \eta$) yields the exact perceptron update $w \leftarrow w + \eta y_i x_i$. When correctly classified, loss and gradient are 0.

Q10A linearly separable dataset has all feature vectors bounded inside an origin-centred sphere of radius $R = 6.0$. A separating hyperplane exists with a geometric margin of $\gamma = 0.5$. According to Novikoff's theorem, what is the maximum number of mistakes (weight updates) the perceptron can make starting from $w = 0$?

Why: By Novikoff’s convergence theorem, the maximum number of mistakes is bounded by $(R / \gamma)^2 = (6.0 / 0.5)^2 = 12^2 = 144$. Notably, this bound is independent of the number of training samples $N$.

Q11A perceptron with $\eta = 1.0$ starts at $w = [0, 0]^\top, b = 0$. It encounters $x_1 = [1, 2]^\top$ ($y_1 = +1$), then $x_2 = [2, 0]^\top$ ($y_2 = -1$). Both trigger updates. What is the resulting score $w^\top x_3 + b$ when evaluated on a new point $x_3 = [1, 1]^\top$?

Why: After $x_1$, $w = [1, 2]^\top$ and $b = 1$. For $x_2$, score is $1(2) + 2(0) + 1 = 3 > 0$, misclassifying negative point $y_2 = -1$. Updating gives $w = [1, 2]^\top - [2, 0]^\top = [-1, 2]^\top$ and $b = 1 - 1 = 0$. Evaluating at $x_3 = [1, 1]^\top$ gives $(-1)(1) + 2(1) + 0 = +1.0$.

Q12If all training feature vectors $x_i$ are multiplied by a positive scalar $c = 3.0$ while labels remain unchanged, what happens to Novikoff's theoretical mistake bound $(R / \gamma)^2$?

Why: Scaling all input vectors by $c$ scales the maximum radius to $cR$ and also widens the geometric distance of the closest point to the separating hyperplane to $c\gamma$. Therefore, $\frac{cR}{c\gamma} = \frac{R}{\gamma}$, and the upper bound on mistakes $(R / \gamma)^2$ is strictly scale-invariant.
