01 The idea

Stack layers of neurons with non-linear activations between them, end with a softmax, and train everything jointly with backpropagation. Hidden layers learn intermediate features, which lets the network carve curved, even disconnected, decision regions.

Each hidden ReLU unit draws one line through the input space and outputs "how far past the line" a point is. The next layer combines these half-planes into polygons, curves and islands. That is how a two-layer network solves XOR, which no single perceptron can.

Training is Gradient descent on cross-entropy loss. Backpropagation applies the chain rule layer by layer to get every weight’s gradient in one backward sweep. Initialisation, learning rate, batch size, L2 penalty and early stopping all matter.

In everyday terms

A team where the first row of workers each draws one rule of thumb, and the second row learns how to combine those rules into a decision.

02 How it works

  1. Scale the inputs.
  2. Forward: $h = \text{ReLU}(W_1x + b_1)$, $p = \text{softmax}(W_2h + b_2)$.
  3. Loss: cross-entropy plus L2 penalty.
  4. Backward: propagate $\partial L/\partial z = p - y$ back through the layers.
  5. Update with Adam on mini-batches; stop early on validation loss.

04 The maths

  1. Softmax output and cross-entropy

    $$p_c = \frac{e^{z_c}}{\sum_{c'} e^{z_{c'}}}, \qquad L = -\sum_c y_c\log p_c, \qquad \frac{\partial L}{\partial z} = p - y$$

    The gradient at the output is simply "predicted minus true", just as in Logistic regression.

  2. Backpropagating through a hidden layer

    $$\delta_1 = (W_2^\top\delta_2)\odot\mathbb 1[z_1 > 0], \qquad \frac{\partial L}{\partial W_1} = \delta_1 x^\top$$

    The ReLU derivative is 1 where the unit was active and 0 elsewhere, so gradients only flow through active units.

06 When to use it

Strengths

  • Learns non-linear features automatically.
  • Scales with data and compute.
  • Same building block as modern deep learning.

Limitations

  • Many hyperparameters; sensitive to scaling and initialisation.
  • Often beaten by boosting on small tabular data.
  • Black box.

Reach for it when

Large datasets with complex structure, or when you will move on to deep architectures.

Think twice when

Small tabular datasets or when you need an interpretable model.

07 In code

python
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.neural_network import MLPClassifier

mlp = make_pipeline(StandardScaler(),
                    MLPClassifier(hidden_layer_sizes=(64, 32), alpha=1e-3, early_stopping=True,
                                  max_iter=1000, random_state=0)).fit(X_tr, y_tr)
print("test accuracy:", round(mlp.score(X_te, y_te), 3), "epochs:", mlp[-1].n_iter_)

Common pitfalls

  • Skipping input scaling.
  • Judging a network by a single training run; seeds matter.
  • Comparing to boosting without tuning either.

09 Check yourself

Q1Why can a two-layer network solve XOR but a perceptron cannot?

Why: Two hidden lines carve the plane into regions the output layer can combine.

Q2For softmax + cross-entropy, the gradient with respect to the logits is:

Why: A clean result that makes training stable and fast.

Q3What would happen if a multi-layer perceptron had 10 hidden layers, but every layer used a linear activation function ($f(z) = z$)?

Why: Without non-linear activation functions, multiplying successive weight matrices $W_{10} W_9 \dots W_1 x$ collapses into a single matrix $W_{\text{eff}} x$, restricting the model to linear decision boundaries.

Q4Why is it standard practice to apply StandardScaler to input features before feeding them into an MLP?

Why: Unscaled features create elongated, elliptical loss surfaces where gradient descent oscillates wildly. Standardising features to zero mean and unit variance makes the contours spherical and ensures L2 regularisation penalises weights fairly.

Q5What is the primary role of enabling early_stopping=True in MLPClassifier?

Why: Early stopping reserves a validation set from the training data. If validation score stops improving for a patience window, training halts and the best weights are restored, guarding against overfitting.

Q6A single hidden layer has 2 ReLU neurons. Given input $x = [2.0, -1.0]^\top$, weight matrix $W = \begin{bmatrix} 1.0 & 3.0 \\ 1.0 & 2.0 \end{bmatrix}$, and bias vector $b = [0.5, 1.5]^\top$, what is the activated hidden vector $h = \text{ReLU}(Wx + b)$?

Why: Pre-activation for neuron 1 is $1(2) + 3(-1) + 0.5 = -0.5$. Since $-0.5 \le 0$, $\text{ReLU}(-0.5) = 0.0$. For neuron 2, $1(2) + 2(-1) + 1.5 = +1.5$. Since $1.5 > 0$, $\text{ReLU}(1.5) = 1.5$. Thus $h = [0.0, 1.5]^\top$.

Q7A 3-class classification MLP produces output logits $z = [\ln 4, \, \ln 2, \, \ln 2]$. What are the resulting softmax class probabilities $[p_1, p_2, p_3]$?

Why: The unnormalised exponents are $e^{\ln 4} = 4$, $e^{\ln 2} = 2$, and $e^{\ln 2} = 2$. The normalising sum is $4 + 2 + 2 = 8$. Dividing each by 8 yields $p_1 = 4/8 = 0.50$, $p_2 = 2/8 = 0.25$, and $p_3 = 2/8 = 0.25$.

Q8What is the "dying ReLU" problem during MLP training?

Why: For any input where pre-activation $z \le 0$, the ReLU output is 0 and its derivative $\mathbb{1}[z > 0]$ is 0. If a large gradient knocks a neuron's weights such that $z \le 0$ for all training points, no gradient will ever flow back to update it, rendering the neuron permanently inactive ("dead").

Q9An MLP takes an input with 4 features, has a single hidden layer of 10 neurons, and outputs class scores for a 3-class classification problem. Including all weights and biases, how many learnable parameters does this network have?

Why: Input-to-hidden layer requires $4 \times 10 = 40$ weights plus 10 biases ($50$ parameters). Hidden-to-output layer requires $10 \times 3 = 30$ weights plus 3 biases ($33$ parameters). Total learnable parameters $= 50 + 33 = 83$.

Q10A network with softmax output for a 3-class problem computes predicted probabilities $p = [0.4, 0.4, 0.2]^\top$. The true target label is class 1 (one-hot vector $y = [1, 0, 0]^\top$). What is the exact gradient vector $\frac{\partial L}{\partial z}$ of the cross-entropy loss with respect to the logits $z$?

Why: For softmax cross-entropy, $\frac{\partial L}{\partial z} = p - y$. Here, $[0.4 - 1.0, \, 0.4 - 0.0, \, 0.2 - 0.0]^\top = [-0.6, +0.4, +0.2]^\top$. The negative gradient on the true class increases its logit under gradient descent, while the positive gradients on the other classes push their logits down.

Q11In a network with 2 hidden ReLU neurons and 2 outputs, the incoming gradient from the output layer is $\delta_2 = [0.5, -0.5]^\top$. The connecting weight matrix is $W_2 = \begin{bmatrix} 2.0 & -1.0 \\ 1.0 & 3.0 \end{bmatrix}$ (where row $k$ connects hidden units to output $k$). The hidden pre-activation was $z_1 = [1.2, -0.4]^\top$. What is the backpropagated error vector $\delta_1 = (W_2^\top \delta_2) \odot \mathbb{1}[z_1 > 0]$?

Why: First, $W_2^\top \delta_2 = \begin{bmatrix} 2.0 & 1.0 \\ -1.0 & 3.0 \end{bmatrix} \begin{bmatrix} 0.5 \\ -0.5 \end{bmatrix} = \begin{bmatrix} 2(0.5) + 1(-0.5) \\ -1(0.5) + 3(-0.5) \end{bmatrix} = \begin{bmatrix} 0.5 \\ -2.0 \end{bmatrix}$. Next, because neuron 2 was inactive ($z_{1,2} = -0.4 \le 0$), its ReLU derivative is 0, while neuron 1 was active ($z_{1,1} = 1.2 > 0$) with derivative 1. Multiplying elementwise yields $[0.5 \times 1, -2.0 \times 0]^\top = [0.5, 0.0]^\top$.

Q12In MLPClassifier, the loss function includes an L2 regularisation term with penalty parameter alpha ($\frac{\alpha}{2} \sum \|W\|^2$). During stochastic gradient descent with learning rate $\eta$, how does this regularisation term modify the weight update for each weight matrix $W$?

Why: The regularised loss is $L_{\text{total}} = L_{\text{data}} + \frac{\alpha}{2}\|W\|^2$. The gradient is $\nabla L_{\text{data}} + \alpha W$. The update step is $W \leftarrow W - \eta(\nabla L_{\text{data}} + \alpha W) = (1 - \eta \alpha)W - \eta \nabla L_{\text{data}}$, which acts as an exponential multiplicative shrinkage (weight decay) on each step.
