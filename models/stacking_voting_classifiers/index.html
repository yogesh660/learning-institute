Stacking and Voting Ensembles

Combine different kinds of model. Voting averages them; stacking trains a model to learn how to combine them.

01 The idea

Different model families make different mistakes. A voting ensemble averages their predictions; a stacking ensemble trains a small "meta-model" on their out-of-fold predictions to learn whom to trust, and when.

A linear model, a k-NN and a tree see the problem differently. Where one is confidently wrong the others may be right. Hard voting takes the majority label; soft voting averages probabilities, which usually works better because confidence counts.

Stacking goes further: it generates each base model’s predictions with cross-validation (so they are honest), then fits a meta-learner, usually logistic regression, on those predictions. Using in-sample predictions instead would leak, because the base models have already seen those labels.

In everyday terms

A panel of specialists. Voting counts their opinions; stacking hires a chair who has learned which specialist to believe on which kind of case.

02 How it works

  1. Pick diverse base models.
  2. Voting: average their probabilities (soft) or labels (hard).
  3. Stacking: get out-of-fold predictions for each base model with K-fold CV.
  4. Fit the meta-model on those predictions; refit base models on all data for inference.

04 The maths

  1. Soft voting

    $$\hat P(c \mid x) = \sum_m w_m\,\hat P_m(c \mid x), \quad \sum_m w_m = 1$$

    Equal weights by default.

  2. Stacking

    $$\hat y = g\big(\hat f_1^{(-k)}(x), \dots, \hat f_M^{(-k)}(x)\big)$$

    $\hat f_m^{(-k)}$ is base model $m$ trained without the fold containing $x$; $g$ is the meta-learner.

06 When to use it

Strengths

  • Often squeezes out extra accuracy.
  • Combines strengths of different families.
  • Voting is trivial to set up.

Limitations

  • More models to train, store and serve.
  • Gains are often small over one strong booster.
  • Stacking is easy to leak if done by hand.

Reach for it when

Competitions, or when you already have several decent, different models.

Think twice when

Latency- or maintenance-constrained production systems where the gain is marginal.

07 In code

python
from sklearn.ensemble import StackingClassifier, VotingClassifier, RandomForestClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.neighbors import KNeighborsClassifier
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

base = [("lr", make_pipeline(StandardScaler(), LogisticRegression(max_iter=1000))),
        ("knn", make_pipeline(StandardScaler(), KNeighborsClassifier(15))),
        ("rf", RandomForestClassifier(300, random_state=0))]
vote = VotingClassifier(base, voting="soft").fit(X_tr, y_tr)
stack = StackingClassifier(base, final_estimator=LogisticRegression(), cv=5).fit(X_tr, y_tr)
print("vote", vote.score(X_te, y_te), "stack", stack.score(X_te, y_te))

Common pitfalls

  • Training the meta-model on in-sample base predictions: classic leakage.
  • Stacking three near-identical models; without diversity there is nothing to gain.

09 Check yourself

Q1Why does stacking use out-of-fold predictions?

Why: Base models have memorised their training labels; the meta-model would learn to trust them too much.

Q2Soft voting averages:

Why: Averaging probabilities lets confident models outweigh uncertain ones.

Q3What is a meta-model (or blender) in a Stacking Classifier?

Why: Stacking uses a two-level hierarchy: Level 0 consists of several diverse base models, and Level 1 is the meta-model (often a simple Logistic Regression) trained on the base models' out-of-fold predictions.

Q4Why are simple linear models (like Logistic Regression) preferred as the meta-learner in stacking?

Why: The input features to the meta-model are already strong, low-dimensional predictions. A simple, regularised linear meta-model learns an effective weighted combination without overfitting.

Q5In scikit-learn's VotingClassifier, what does the voting='hard' setting do?

Why: voting='hard' uses majority rule: each base classifier casts a vote for its predicted class label, and the class with the most votes wins.

Q6Why does combining three identical Random Forests in a Voting Classifier provide virtually no benefit, whereas combining a Random Forest, an SVM, and Logistic Regression often works well?

Why: An ensemble succeeds when the errors of individual models are uncorrelated. If model A makes a mistake, diverse models B and C can outvote it; identical models make identical mistakes and reinforce each other's errors.

Q7What goes wrong if you train the meta-model on the base models' in-sample training predictions instead of out-of-fold predictions?

Why: In-sample predictions leak labels because flexible base models have near-zero training error. The meta-model learns that base model predictions are infallible, failing to learn which models generalise best on unseen data.

Q8In scikit-learn's StackingClassifier, what does setting passthrough=True do?

Why: By default, the meta-model only sees the base model predictions. Setting passthrough=True concatenates the original features with the base predictions, allowing the meta-model to learn context-dependent routing.

Q9Why is probability calibration important when using voting='soft' across heterogeneous base models (e.g. Naive Bayes and SVM)?

Why: Soft voting calculates an unweighted or weighted mean of probabilities. If one model's probabilities are pushed to $0.99$ while another's are well-calibrated around $0.65$, the overconfident model will dominate the vote regardless of whether it is more accurate.

Q10A weighted soft-voting ensemble combines three models with weights $w = [2, 1, 1]$ (normalised weights 0.50, 0.25, 0.25). For a test sample, their predicted probabilities for Class 1 are: Model 1 ($0.30$), Model 2 ($0.80$), Model 3 ($0.70$). What is the ensemble predicted probability for Class 1, and what class is predicted at threshold 0.50?

Why: Weighted average is $\frac{2(0.30) + 1(0.80) + 1(0.70)}{4} = \frac{0.60 + 0.80 + 0.70}{4} = \frac{2.10}{4} = 0.525$, which is above the $0.50$ threshold, so the ensemble predicts Class 1. (Unweighted soft voting would give $1.80 / 3 = 0.600$; counting Model 1 twice pulls the result down.)

Q11Three models vote on a binary classification problem: Model 1 ($P=0.49$, votes Class 0), Model 2 ($P=0.49$, votes Class 0), Model 3 ($P=0.98$, votes Class 1). What are the predictions of unweighted hard voting and unweighted soft voting?

Why: Hard voting: Models 1 and 2 vote Class 0, Model 3 votes Class 1. Class 0 wins (2 to 1). Soft voting: average probability is $(0.49 + 0.49 + 0.98) / 3 = 1.96 / 3 \approx 0.653 > 0.50$, predicting Class 1.

Q12By the Condorcet Jury Theorem, suppose 3 independent classifiers each have an accuracy of $p = 0.70$. What is the probability that a majority vote of these 3 classifiers is correct?

Why: A 3-voter majority is correct if all 3 are correct ($0.70^3 = 0.343$) or exactly 2 are correct ($3 \times 0.70^2 \times 0.30 = 0.441$). Total probability $= 0.343 + 0.441 = 0.784$ (78.4%). Ensembling improves accuracy from 70% to 78.4%.
