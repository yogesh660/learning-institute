01 The idea

A convolutional layer slides a small grid of weights (a filter) across the image and records how strongly each patch matches. Stacking such layers builds up from edges to textures to parts to objects.

A fully connected network on a 224×224 colour image would need 150,000 weights per neuron and would have to learn "cat ear" separately for every position. Convolution shares one small filter across all positions (weight sharing) and looks at local patches only (local connectivity). The same edge detector works everywhere: translation equivariance.

After convolution, a non-linearity (ReLU) keeps only positive evidence, and pooling summarises small neighbourhoods so the representation shrinks and becomes tolerant to small shifts. Deeper layers see larger regions of the original image (a larger receptive field), so they can respond to bigger structures. A classifier head on top turns the final features into class probabilities.

In everyday terms

Scanning a page with a magnifying glass that lights up whenever it passes over a particular shape.

02 How it works

  1. Convolve the input with $K$ learned filters to produce $K$ feature maps.
  2. Apply ReLU.
  3. Pool (e.g. 2×2 max) to downsample.
  4. Repeat conv–ReLU–pool blocks, increasing the number of filters.
  5. Flatten or global-average-pool, then a dense softmax layer.
  6. Train end-to-end with cross-entropy and backpropagation; augment data (flips, crops) to generalise.

06 The maths

  1. Discrete 2-D convolution (cross-correlation)

    $$S(i, j) = \sum_{m}\sum_{n} I(i + m,\, j + n)\,K(m, n) + b$$

    Each output pixel is the dot product of the filter with the patch under it. Deep-learning libraries use cross-correlation and still call it convolution.

  2. Output size

    $$H_{\text{out}} = \Big\lfloor\frac{H_{\text{in}} + 2P - F}{S}\Big\rfloor + 1$$

    $F$ = filter size, $P$ = padding, $S$ = stride. A 3×3 filter with padding 1 and stride 1 keeps the size.

  3. Parameter count

    $$\#\text{params} = (F\cdot F\cdot C_{\text{in}} + 1)\cdot C_{\text{out}}$$

    A 3×3 conv from 64 to 128 channels has about 74k weights, regardless of image size.

08 When to use it

Strengths

  • State of the art on images and other grid data.
  • Far fewer parameters than dense nets thanks to weight sharing.
  • Pre-trained backbones transfer well to new tasks.

Limitations

  • Needs lots of labelled data or transfer learning.
  • GPU-hungry training.
  • Hard to interpret; vulnerable to adversarial perturbations.

Reach for it when

Images, spectrograms, some time series and any data with local spatial structure.

Think twice when

Tabular data, where trees win.

09 In code

python
import torch, torch.nn as nn

class SmallCNN(nn.Module):
    def __init__(self, n_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 32, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),     # 28 -> 14
            nn.Conv2d(32, 64, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),    # 14 -> 7
        )
        self.head = nn.Sequential(nn.Flatten(), nn.Linear(64 * 7 * 7, 128), nn.ReLU(),
                                  nn.Dropout(0.3), nn.Linear(128, n_classes))

    def forward(self, x):
        return self.head(self.features(x))

model = SmallCNN()
print(sum(p.numel() for p in model.parameters()), "parameters")

Common pitfalls

  • Training from scratch on a few thousand images; start from a pre-trained backbone.
  • Forgetting to normalise inputs the way the pre-trained model expects.
  • Augmenting the validation set.

10 Check yourself

Q1Why do CNNs need far fewer parameters than dense networks on images?

Why: Weight sharing: the same $3\times3$ weights are applied everywhere.

Q2A 32×32 input, 5×5 filter, padding 0, stride 1 gives an output of:

Why: $(32 + 0 - 5)/1 + 1 = 28$.

Q3What does max-pooling add?

Why: Taking the max over a window keeps the strongest response wherever it occurs in that window.

Q4In a convolutional layer, if an object in an image shifts 5 pixels to the right, what happens to the resulting feature map?

Why: Convolution is translation equivariant: shifting the input causes the output feature map to shift by the corresponding amount, preserving the spatial layout of detected patterns. Pooling subsequently introduces local translation invariance.

Q5Why do modern CNN architectures often use Global Average Pooling (GAP) before the final classification layer instead of flattening all features into a massive dense layer?

Why: Flattening a $7 \times 7 \times 512$ tensor into a dense layer requires millions of parameters, making the classifier head prone to overfitting. Global average pooling reduces each spatial map to its mean scalar, producing a compact 512-dimensional vector with zero extra parameters.

Q6What is meant by the "effective receptive field" of a neuron in a deep convolutional network?

Why: The receptive field is the patch of pixels in the input image that feeds into that unit through successive convolutions and pooling layers. Deeper units possess wider receptive fields, enabling them to recognise high-level shapes and full objects.

Q7What is the primary purpose of using a $1 \times 1$ convolutional layer (pointwise convolution) in deep networks like ResNet or Inception?

Why: A $1 \times 1$ filter operates across all input channels at a single pixel location. It computes a linear combination of channels followed by a non-linearity, allowing the network to project channels up or down cheaply while leaving spatial dimensions $(H, W)$ intact.

Q8A convolutional layer receives a $64 \times 64$ feature map. It applies a $3 \times 3$ filter with padding $P = 1$ and stride $S = 2$. What is the spatial resolution of the output feature map?

Why: Using $H_{\text{out}} = \lfloor \frac{H_{\text{in}} + 2P - F}{S} \rfloor + 1$: here $\lfloor \frac{64 + 2(1) - 3}{2} \rfloor + 1 = \lfloor \frac{63}{2} \rfloor + 1 = 31 + 1 = 32$. A stride of 2 with padding 1 cleanly halves the spatial dimension from 64 to 32.

Q9When training a CNN on image classification, why is data augmentation (such as random horizontal flips and random crops) applied strictly to the training split and NEVER to the validation or test splits?

Why: Validation and test sets serve as ground-truth benchmarks for real-world generalisation. Augmenting them would introduce synthetic artefacts and prevent fair, reproducible measurement of model performance.

Q10A 2D convolutional layer receives an input with 32 channels and produces 64 output feature maps using $3 \times 3$ filters. Each output filter has an independent learnable bias term. How many learnable parameters does this layer contain?

Why: Each of the 64 filters spans all 32 input channels with a $3 \times 3$ kernel, giving $3 \times 3 \times 32 = 288$ weights per filter. Adding 1 bias per filter gives 289 parameters per filter. In total, $64 \times 289 = 18,496$ learnable parameters (completely invariant to the input image's spatial height and width).

Q11A $3 \times 3$ patch of an image channel has values $\begin{bmatrix} 1 & 0 & 2 \\ 0 & 3 & 1 \\ 2 & 1 & 0 \end{bmatrix}$. It is convolved with a filter kernel $\begin{bmatrix} 0 & 1 & 0 \\ 1 & -2 & 1 \\ 0 & 1 & 0 \end{bmatrix}$ with bias $b = 1.0$. What is the linear pre-activation value $S$ at this position?

Why: Compute the sum of elementwise products: row 1 gives $1(0) + 0(1) + 2(0) = 0$; row 2 gives $0(1) + 3(-2) + 1(1) = -5$; row 3 gives $2(0) + 1(1) + 0(0) = 1$. Adding the rows gives $0 - 5 + 1 = -4$. Finally, adding bias $b = 1.0$ yields $S = -4 + 1 = -3.0$.

Q12During the backward pass (backpropagation) through a $2 \times 2$ max-pooling layer with stride 2, how does the incoming gradient $\frac{\partial L}{\partial y}$ get routed to the 4 input units of the pooling window?

Why: The forward operation is $y = \max(x_1, x_2, x_3, x_4)$. The partial derivative $\frac{\partial y}{\partial x_i}$ is 1 for the winning unit ($x_i = \max$) and 0 for all other units. By the chain rule, the entire incoming gradient flows solely through the winning unit, while the losing units receive zero gradient.
