k-Medoids (PAM)

Like k-means, but every centre must be an actual data point. More robust to outliers and works with any distance.

01 The idea

k-medoids chooses $k$ real data points as cluster representatives (medoids) and assigns every other point to its nearest medoid, minimising total distance rather than squared distance.

A mean can be dragged anywhere by an outlier and can land in empty space. A medoid is always one of the points, the most central one, so it is a real, readable prototype ("this customer is typical of the segment") and one wild point cannot pull it away.

Because it only needs pairwise distances, k-medoids works with any dissimilarity: Manhattan, cosine, edit distance between strings, or a custom business metric.

In everyday terms

Picking a real person from each group as its spokesperson, rather than an imaginary "average person".

02 How it works

  1. Pick $k$ initial medoids (e.g. greedy BUILD step).
  2. Assign each point to its nearest medoid.
  3. SWAP step: try replacing each medoid with a non-medoid; keep any swap that lowers total distance.
  4. Repeat until no swap helps.

04 The maths

  1. Objective

    $$J = \sum_{k=1}^K\sum_{x_i \in C_k} d(x_i, m_k), \qquad m_k \in \{x_1, \dots, x_n\}$$

    Unsquared distance and medoids restricted to data points both add robustness.

06 When to use it

Strengths

  • Robust to outliers.
  • Works with any distance, including precomputed matrices.
  • Medoids are real, interpretable examples.

Limitations

  • PAM costs $O(k(n-k)^2)$ per iteration: slow for large $n$.
  • Still needs k and favours compact clusters.

Reach for it when

Small to medium data with outliers, non-Euclidean distances, or when prototypes must be real records.

Think twice when

Very large datasets (use CLARA/CLARANS or mini-batch k-means).

07 In code

python
import pandas as pd
from sklearn.preprocessing import StandardScaler

df = pd.read_csv("datasets/raw/mall_customers.csv")
X = StandardScaler().fit_transform(df[["Annual_Income_k", "Spending_Score"]])
# pip install scikit-learn-extra
from sklearn_extra.cluster import KMedoids

km = KMedoids(n_clusters=5, metric="manhattan", method="pam", random_state=0).fit(X)
print("medoid rows:", km.medoid_indices_)

  • Running PAM on 100k rows. Sample or use CLARA.

09 Check yourself

Q1Why is k-medoids more robust to outliers than k-means?

Why: An outlier cannot drag a medoid into empty space, and its cost grows linearly, not quadratically.

Q2Unlike k-means centroids, what is guaranteed about cluster prototypes in k-medoids?

Why: By definition, a medoid is chosen from the existing data observations ($\{x_1, \dots, x_n\}$), guaranteeing that prototypes represent real, interpretable instances rather than synthetic averages.

Q3What distance metrics can k-medoids accept that standard k-means cannot natively support without coordinate embedding?

Why: Standard k-means requires computing arithmetic means $\mu = \frac{1}{|C|}\sum x_i$, which requires Euclidean vector space coordinates. K-medoids only requires pair-wise distances $d(x_i, x_j)$, making it compatible with non-Euclidean metrics and precomputed dissimilarity matrices.

Q4In the classic PAM (Partitioning Around Medoids) algorithm, what occurs during the SWAP step?

Why: The PAM SWAP phase systematically tests swapping each current medoid with every candidate non-medoid, calculating whether replacing the prototype lowers the total cost objective $J$.

Q5Why is the standard PAM algorithm generally unsuitable for datasets with hundreds of thousands of observations?

Why: Testing every candidate swap between $k$ medoids and $n - k$ non-medoids costs $O(k(n - k)^2)$ per iteration. For $n = 100,000$, $(n - k)^2 \approx 10^{10}$, making each iteration prohibitively expensive. CLARA or mini-batch methods are used instead.

Q6What scaling approach does the CLARA (Clustering LARge Applications) algorithm use to extend k-medoids to large datasets?

Why: CLARA draws multiple independent random samples of size $40 + 2k$, runs PAM on each sample to identify candidate medoids, and evaluates which set of medoids gives the lowest total dissimilarity across the entire dataset.

Q7Consider the following Python snippet using scikit-learn-extra: from sklearn_extra.cluster import KMedoids km = KMedoids(n_clusters=3, metric="precomputed", method="pam") km.fit(D) What shape and structure must the input array D have?

Why: When metric="precomputed" is specified, the input to .fit() must be a square $(n \times n)$ pairwise dissimilarity matrix where entry $(i, j)$ represents $d(x_i, x_j)$.

Q8Which attribute of a fitted scikit-learn-extra KMedoids model returns the row indices of the selected exemplar instances?

Why: In scikit-learn-extra, km.medoid_indices_ contains the integer row indices in the training dataset corresponding to the $k$ chosen medoids.

Q9How does k-medoids behave when one cluster has a single extreme outlier with a feature value $100\times$ larger than all other points?

Why: Unlike the mean (which shifts substantially toward extreme outliers due to squared distance penalties), the medoid minimises unsquared distances $\sum d(x_i, m)$. The single outlier contributes linearly and is easily outvoted by the majority of dense points.

Q10Consider 5 points on a 1D line: $\{1, 2, 4, 8, 10\}$. If $k = 1$ medoid is chosen from these points under Manhattan distance $d(x_i, m) = |x_i - m|$, which point is the medoid and what is the minimum total distance?

Why: For Manhattan distance in 1D, the sum of absolute deviations is minimised at the sample median. Here the median is 4. The distances are $|1-4| + |2-4| + |4-4| + |8-4| + |10-4| = 3 + 2 + 0 + 4 + 6 = 15$.

Q11Suppose four customers $\{A, B, C, D\}$ have the following pairwise distance matrix: $d(A, B) = 2, d(A, C) = 5, d(A, D) = 6$ $d(B, C) = 4, d(B, D) = 5$ $d(C, D) = 3$ (with all $d(X, X) = 0$). If you must select $k = 1$ medoid to represent all four customers, which customer yields the minimum total distance, and what is that total distance?

Why: The sum of distances for each candidate is: $A: 0+2+5+6 = 13$; $B: 2+0+4+5 = 11$; $C: 5+4+0+3 = 12$; $D: 6+5+3+0 = 14$. Customer $B$ minimises total dissimilarity with a sum of 11.

Q12In a dataset with $n = 50$ points and $k = 3$ clusters, how many candidate swaps must the classic PAM algorithm evaluate in a single full pass of the SWAP step?

Why: In PAM, each of the $k = 3$ current medoids is considered for replacement by each of the $n - k = 47$ non-medoids. The number of candidate swap pairs tested in one pass is $k(n - k) = 3 \times 47 = 141$.
