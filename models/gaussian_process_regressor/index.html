01 The idea

A Gaussian process puts a prior directly on functions: any finite set of function values is jointly Gaussian, with correlations set by a kernel. Conditioning on data gives a posterior mean and a band of uncertainty.

The kernel encodes what kinds of functions you expect. The RBF kernel says "nearby inputs have similar outputs", with the length scale $\ell$ deciding how near is near. Before seeing data, the GP can draw any smooth wiggle; each observation pins the function down locally.

Between observations the mean interpolates smoothly and the uncertainty bulges; at the observations it pinches (down to the noise level). This makes GPs a favourite for small, expensive experiments and for Bayesian optimisation.

In everyday terms

A tent held up by poles at each data point: the fabric is pinned at the poles and sags (uncertainty) between them, by an amount set by how stiff the fabric is (the length scale).

02 How it works

  1. Choose a kernel, e.g. RBF plus a white-noise term.
  2. Build the covariance matrix $K$ between all training points.
  3. Fit kernel hyperparameters by maximising the marginal likelihood.
  4. Predict: mean $k_*^\top (K + \sigma^2 I)^{-1}y$, variance $k_{**} - k_*^\top (K + \sigma^2 I)^{-1}k_*$.

04 The maths

  1. Prior over functions

    $$f \sim \mathcal{GP}(0, k), \qquad k(x, x') = \sigma_f^2 \exp\!\Big(-\frac{\lVert x - x'\rVert^2}{2\ell^2}\Big)$$

    $\sigma_f^2$ sets how far the function strays from zero; $\ell$ sets how quickly it can change.

  2. Posterior predictive

    $$\mu_* = k_*^\top (K + \sigma_n^2 I)^{-1} y, \qquad \sigma_*^2 = k(x_*, x_*) - k_*^\top (K + \sigma_n^2 I)^{-1} k_*$$

    Computed with a Cholesky factorisation of the $n \times n$ matrix, which is where the $O(n^3)$ cost comes from.

  3. Learning the kernel

    $$\log p(y \mid X) = -\tfrac12 y^\top K_y^{-1} y - \tfrac12 \log|K_y| - \tfrac n2 \log 2\pi$$

    A data-fit term and a complexity penalty: the marginal likelihood automatically balances smoothness against fit.

06 When to use it

Strengths

  • Principled uncertainty for every prediction.
  • Very data-efficient on small problems.
  • Kernels can encode prior knowledge (periodicity, trends).

Limitations

  • $O(n^3)$ training and $O(n^2)$ memory: a few thousand points at most for exact GPs.
  • Kernel choice matters and takes thought.
  • Struggles in high dimensions.

Reach for it when

Small datasets, expensive experiments, Bayesian optimisation, anything where knowing "how sure" matters.

Think twice when

More than about 10k rows (unless you use sparse approximations) or very high-dimensional inputs.

07 In code

python
from sklearn.gaussian_process import GaussianProcessRegressor
from sklearn.gaussian_process.kernels import RBF, WhiteKernel, ConstantKernel as C

kernel = C(1.0) * RBF(length_scale=1.0) + WhiteKernel(noise_level=0.1)
gp = GaussianProcessRegressor(kernel=kernel, normalize_y=True, n_restarts_optimizer=5, random_state=0)
gp.fit(X_tr[:1000], y_tr[:1000])          # exact GPs scale as O(n^3)
mean, std = gp.predict(X_te, return_std=True)
print(gp.kernel_)                          # the fitted kernel

Common pitfalls

  • Fitting on all rows of a large dataset and waiting forever. Subsample or use sparse GPs.
  • Forgetting a noise term, which forces the mean to pass exactly through every noisy point.

09 Check yourself

Q1What does the RBF length scale $\ell$ control?

Why: Small $\ell$ means correlations die off quickly, so the function can wiggle; large $\ell$ means a smooth, slowly varying function.

Q2Why do exact GPs not scale to millions of rows?

Why: Inverting (or factorising) $K + \sigma^2 I$ is cubic in $n$ and quadratic in memory.

Q3What is the formal definition of a Gaussian Process (GP)?

Why: By definition, a Gaussian Process is a collection of infinitely many random variables such that any finite sub-collection $(f(x_1), \dots, f(x_k))$ has a joint Gaussian distribution fully specified by a mean function $m(x)$ and covariance function $k(x, x')$.

Q4What is the effect of adding a WhiteKernel to an RBF kernel in Gaussian Process Regression?

Why: A white-noise kernel models observation error $\epsilon \sim \mathcal{N}(0, \sigma_n^2)$. Adding it modifies the covariance to $K(x, x') + \sigma_n^2 \delta_{x, x'}$, allowing the GP mean function to smoothly approximate noisy points rather than being forced to interpolate through every noise spike.

Q5What happens to the posterior predictive uncertainty (variance $\sigma_*^2$) of a noise-free GP at an exact training location $x_* = x_i$?

Why: Without observation noise, observing $y_i = f(x_i)$ pins down the function completely at that coordinate, collapsing posterior uncertainty at $x_i$ to 0.

Q6How does Gaussian Process Regression learn its kernel hyperparameters (such as length scale $\ell$ and signal variance $\sigma_f^2$)?

Why: The log marginal likelihood decomposes into a data-fit term ($-\frac{1}{2}y^\top K_y^{-1}y$), a complexity penalty term ($-\frac{1}{2}\log|K_y|$), and a normalisation constant. Maximising it via gradient-based optimisers finds optimal hyperparameters without cross-validation.

Q7Suppose you train a GP with an RBF kernel where the learned length scale $\ell$ is extremely small relative to the spacing between data points. How will the predictive mean behave between training points?

Why: When $\ell$ is much smaller than the distance between points, covariance $k(x_i, x_*)$ vanishes as soon as $x_*$ moves slightly away from a training point. As cross-correlations vanish, the predictive mean reverts to the prior mean ($0$), and variance returns to prior variance $\sigma_f^2$.

Q8Why does scikit-learn's GaussianProcessRegressor provide an n_restarts_optimizer parameter?

Why: The marginal likelihood objective function is typically non-convex in kernel hyperparameters, often containing multiple local maxima (e.g. one representing short-scale noisy variations and another representing long-scale smooth trends). Random restarts help escape poor local optima.

Q9Why are Gaussian Processes widely used as surrogate models in Bayesian optimisation for hyperparameter tuning?

Why: In Bayesian optimisation, evaluating the objective function is expensive. GPs provide full posterior predictive distributions $\mathcal{N}(\mu(x), \sigma^2(x))$, allowing acquisition functions to mathematically quantify both where the objective is expected to be good (exploitation) and where uncertainty is large (exploration).

Q10You have a single training point $(x_1 = 0.0, y_1 = 4.0)$ and a GP with zero prior mean, RBF kernel $k(x, x') = \exp(-\frac{1}{2}(x - x')^2)$, and observation noise variance $\sigma_n^2 = 1.0$. What is the posterior predictive mean $\mu_*$ at $x_* = 1.0$? (Note: $e^{-0.5} \approx 0.607$).

Why: The training covariance scalar is $K = k(0, 0) + \sigma_n^2 = 1.0 + 1.0 = 2.0$. The cross-covariance is $k_* = k(1, 0) = \exp(-0.5) \approx 0.607$. The predictive mean is $\mu_* = k_* K^{-1} y = 0.607 \times (1 / 2.0) \times 4.0 = 0.607 \times 2.0 \approx 1.214$ (or $1.213$).

Q11For the same single-observation GP setup ($x_1 = 0.0, y_1 = 4.0, k(x, x') = \exp(-\frac{1}{2}(x - x')^2), \sigma_n^2 = 1.0$), what is the posterior predictive variance $\sigma_*^2$ at $x_* = 1.0$? (Using $e^{-0.5} \approx 0.607$, so $(e^{-0.5})^2 = e^{-1.0} \approx 0.368$).

Why: Prior variance at $x_*$ is $k(1, 1) = 1.0$. The variance reduction term is $k_*^2 / (k(0, 0) + \sigma_n^2) = (e^{-0.5})^2 / (1.0 + 1.0) = e^{-1.0} / 2.0 \approx 0.3679 / 2.0 \approx 0.1840$. Thus $\sigma_*^2 = 1.0 - 0.184 = 0.816$.

Q12In the log marginal likelihood formula $\log p(y \mid X) = -\frac{1}{2}y^\top K_y^{-1}y - \frac{1}{2}\log|K_y| - \frac{n}{2}\log 2\pi$, what happens if a model becomes overly complex by choosing an excessively tiny length scale $\ell \to 0$?

Why: As $\ell \to 0$, all off-diagonal correlations vanish and $K_y$ tends to the diagonal matrix $(\sigma_f^2 + \sigma_n^2) I$. The complexity term $-\frac{1}{2}\log|K_y|$ is then at its most lenient, but the data-fit term cannot use the correlation between neighbouring points, so structured data looks like pure white noise and the marginal likelihood falls well below that of a properly tuned length scale.
