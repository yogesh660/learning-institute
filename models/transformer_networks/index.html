01 The idea

A Transformer replaces "read step by step" with "look everywhere at once". Each token asks a question (a query), every token advertises what it contains (a key), and each token collects information (the values) from the tokens whose keys best match its query.

In "The animal did not cross the street because it was tired", the word "it" needs to find "animal". An RNN would have to carry "animal" through six steps of memory. Self-attention lets "it" compare itself with every word directly and pull in information from the best match, however far away it is. Distance stops mattering.

The comparison is a dot product between the query of one token and the key of another, scaled and turned into weights with a softmax. The output for a token is the weighted average of all value vectors. Several heads do this in parallel, each with its own query/key/value projections, so one head can track meaning ("which noun is this pronoun about?") while another tracks position ("what came just before me?"). Since attention ignores order, positional encodings are added to the inputs. Stack attention with small feed-forward layers, residual connections and layer norm, and you have a Transformer block.

In everyday terms

A room where everyone holds up a sign describing themselves (keys), each person has a question in mind (query), and each listens most closely to the people whose signs match their question.

02 How it works

  1. Tokenize the text into ids, turn each id into a vector with an embedding table and add positional encodings.
  2. For each token, compute query $q = xW_Q$, key $k = xW_K$ and value $v = xW_V$.
  3. Score every pair: $q_i \cdot k_j / \sqrt{d_k}$; mask future tokens in decoders.
  4. Softmax each row of scores into attention weights that sum to 1.
  5. Output for token $i$: $\sum_j a_{ij} v_j$. Do this in several heads, concatenate, and project.
  6. Add a feed-forward layer, residual connections and layer norm; stack many blocks; pool (or use a [CLS] token) and classify.

06 The maths

  1. Scaled dot-product attention

    $$\operatorname{Attention}(Q, K, V) = \operatorname{softmax}\!\Big(\frac{QK^\top}{\sqrt{d_k}}\Big)V$$

    Row $i$ of the softmax matrix is the attention distribution of token $i$ over all tokens.

  2. Why divide by √d

    $$q, k \sim \mathcal N(0, I_{d}) \;\Rightarrow\; \operatorname{Var}(q\cdot k) = d$$

    Without scaling, larger dimensions give larger scores, the softmax becomes nearly one-hot, and its gradients vanish. The lab’s temperature slider shows that effect.

  3. Multi-head attention

    $$\operatorname{MHA}(X) = [\text{head}_1; \dots; \text{head}_h]\,W_O, \qquad \text{head}_j = \operatorname{Attention}(XW_Q^{j}, XW_K^{j}, XW_V^{j})$$

    Each head can specialise in a different kind of relationship.

  4. One Transformer block (pre-norm, as in GPT-2)

    $$H = X + \operatorname{MHA}(\operatorname{LN}(X)), \qquad Y = H + \operatorname{FFN}(\operatorname{LN}(H)), \qquad \operatorname{FFN}(h) = \operatorname{GELU}(hW_1 + b_1)W_2 + b_2$$

    Attention mixes information between tokens; the feed-forward network (usually 4× wider) processes each token on its own. The residual additions keep a direct path for gradients through dozens of layers, and layer norm keeps every vector at a stable scale.

  5. Predicting the next token

    $$p(\text{next} = w \mid x_{\le t}) = \operatorname{softmax}\!\big(h_t E^\top / \tau\big)_w, \qquad \mathcal L = -\frac1T\sum_t \log p(x_{t+1} \mid x_{\le t})$$

    The last vector is scored against every row of the (tied) embedding table $E$. Training uses cross-entropy at every position at once; generation samples one token, appends it and repeats. $\tau$ is the sampling temperature.

  6. Cost

    $$\text{time and memory} \propto T^2 d$$

    Every token attends to every token, so long contexts are expensive; much current research is about making this cheaper.

08 When to use it

Strengths

  • Direct access between any two positions: long-range context is easy.
  • Fully parallel over the sequence, so training scales on GPUs.
  • Pre-trained models transfer to new tasks with little labelled data.

Limitations

  • Quadratic cost in sequence length.
  • Data- and compute-hungry when trained from scratch.
  • Large models are expensive to serve.

Reach for it when

Text, code, and increasingly images, audio and time series, especially when a pre-trained model exists.

Think twice when

Tiny datasets with no pre-trained model, or short simple sequences where a GRU or a linear model is enough.

09 In code

python
import torch, torch.nn as nn
from sklearn.datasets import load_digits

# read each 8x8 digit image as a sequence: 8 time steps, 8 pixels per step
digits = load_digits()
X = torch.tensor(digits.images / 16.0, dtype=torch.float32)    # (n, 8, 8)
y = torch.tensor(digits.target)

class TinyTransformer(nn.Module):
    def __init__(self, d=64, heads=4, layers=2):
        super().__init__()
        self.embed = nn.Linear(8, d)
        self.pos = nn.Parameter(torch.zeros(1, 8, d))                # learned positional encoding
        block = nn.TransformerEncoderLayer(d, heads, dim_feedforward=128, batch_first=True)
        self.encoder = nn.TransformerEncoder(block, layers)
        self.out = nn.Linear(d, 10)

    def forward(self, x):
        h = self.encoder(self.embed(x) + self.pos)                   # every row attends to every row
        return self.out(h.mean(dim=1))

# for real text, fine-tune a pre-trained model instead:
# from transformers import AutoModelForSequenceClassification

Common pitfalls

  • Training a Transformer from scratch on a few thousand examples; fine-tune a pre-trained one.
  • Forgetting positional information: without it, "dog bites man" and "man bites dog" look identical.
  • Reading attention weights as explanations. They show where information flows, not why the model decided.

10 Check yourself

Q1In self-attention, what does a token’s query get compared with?

Why: Scores are $q_i \cdot k_j$ for all $j$.

Q2Why are positional encodings needed?

Why: Shuffling the tokens would otherwise give the same set of outputs.

Q3How does attention’s cost grow with sequence length $T$?

Why: A $T \times T$ score matrix.

Q4What does a causal mask do?

Why: Needed for text generation, where the next token must not be visible.

Q5Why is the dot product $QK^\top$ divided by $\sqrt{d_k}$ in scaled dot-product attention?

Why: When components of $q$ and $k$ are independent with zero mean and unit variance, $\operatorname{Var}(q \cdot k) = d_k$. As $d_k$ increases, dot products have large magnitudes, driving softmax probabilities towards 0 and 1, which causes vanishing gradients during backpropagation.

Q6Token 1 has computed attention weights of $0.80$ to itself and $0.20$ to Token 2. The value vectors are $v_1 = [10.0, 0.0]^\top$ and $v_2 = [0.0, 20.0]^\top$. What is the resulting attention output vector for Token 1?

Why: The output is the weighted average of the value vectors: $0.80 \times [10.0, 0.0]^\top + 0.20 \times [0.0, 20.0]^\top = [8.0, 0.0]^\top + [0.0, 4.0]^\top = [8.0, 4.0]^\top$.

Q7What is the primary benefit of using Multi-Head Attention rather than a single large attention head with the same total dimension $d_{\text{model}}$?

Why: Multiple heads project queries, keys, and values into different lower-dimensional subspaces. This allows distinct heads to specialise in different relationships—such as grammatical dependencies, coreference resolution, or relative position—which a single averaging operation would blur together.

Q8Inside a standard Transformer block (such as GPT or BERT), what is the function of the position-wise Feed-Forward Network (FFN) that follows the multi-head attention layer?

Why: While attention mixes information across different token positions, the FFN operates position-wise: it applies the same two-layer MLP with non-linearity (e.g. GELU or ReLU) to each token vector separately, allowing complex feature processing per token.

Q9In modern Transformer blocks (Pre-LN formulation, as used in GPT-2 and LLaMA), how is the residual connection and Layer Normalisation (LN) structured for input $X$?

Why: In Pre-LN, normalisation is applied to the input branch before entering the attention sub-layer, and the original input $X$ is added directly via the residual connection: $H = X + \operatorname{MHA}(\operatorname{LN}(X))$. This preserves an unhindered gradient highway throughout dozens of stacked blocks.

Q10Given query vector $q = [2.0, -1.0, 2.0, 1.0]$ and key vector $k = [1.0, 2.0, 3.0, 2.0]$ with key dimension $d_k = 4$, what is the scaled attention score $\frac{q \cdot k}{\sqrt{d_k}}$ before softmax?

Why: The raw dot product is $q \cdot k = (2 \times 1) + (-1 \times 2) + (2 \times 3) + (1 \times 2) = 2 - 2 + 6 + 2 = 8.0$. Dividing by $\sqrt{d_k} = \sqrt{4} = 2.0$ yields $\frac{8.0}{2.0} = 4.0$. Failing to divide by $\sqrt{d_k}$ leaves the unscaled score $8.0$.

Q11In a Transformer with model embedding dimension $d_{\text{model}} = 768$ and $h = 12$ attention heads, how is each head's query, key, and value dimension $d_k$ typically configured, and why?

Why: Standard Transformer architectures split the model width across the heads: $d_k = d_v = d_{\text{model}} / h = 768 / 12 = 64$. Concatenating the twelve 64-dimensional outputs reconstructs a 768-dimensional vector, keeping parameter count and FLOPs roughly equal to a single full-rank head.

Q12In next-token generation with logit vector $z$, what happens mathematically to the probability distribution as the sampling temperature $\tau \to 0$ versus when $\tau \to \infty$?

Why: Dividing logits by small $\tau > 0$ magnifies differences between scores: in the limit $\tau \to 0$, the largest logit dominates the softmax sum, yielding probability 1.0 for the top token (greedy decoding). Conversely, as $\tau \to \infty$, $z / \tau \to 0$, and $e^0 = 1$ for all tokens, converging to a completely uniform random distribution.
