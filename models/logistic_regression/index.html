01 The idea

Compute a linear score $z = w^\top x + b$, squash it into a probability with the sigmoid $\sigma(z) = 1/(1 + e^{-z})$, and choose the weights that make the observed labels most likely.

Linear regression can output any number, but a probability has to live between 0 and 1. Logistic regression models the Log-odds (logit) as linear: $\log\frac{p}{1-p} = w^\top x + b$. Every unit increase in a feature multiplies the odds by $e^{w_j}$, which is why doctors and risk teams love it.

The decision boundary $w^\top x + b = 0$ is a straight line (a hyperplane). Points far from it on either side get confident probabilities; points near it get probabilities near 0.5. The model is trained by minimising log-loss (cross-entropy), which is the same as maximum likelihood under a Bernoulli model.

In everyday terms

A weighted checklist that adds up evidence for "yes", then converts the total into a calibrated chance.

02 How it works

  1. Compute $z_i = w^\top x_i + b$ for every row.
  2. Turn scores into probabilities $p_i = \sigma(z_i)$.
  3. Measure log-loss: heavily penalise confident wrong answers.
  4. Minimise it with L-BFGS or gradient descent (the loss is convex, so there is one optimum).
  5. Predict class 1 when $p \ge \tau$; pick the threshold $\tau$ for your costs, not by default.

04 The maths

  1. Model

    $$P(y = 1 \mid x) = \sigma(w^\top x + b) = \frac{1}{1 + e^{-(w^\top x + b)}}$$

    Equivalently $\log\frac{p}{1-p} = w^\top x + b$: linear in the log-odds.

  2. Loss: negative log-likelihood

    $$\mathcal L(w) = -\frac1n\sum_i \big[y_i\log p_i + (1 - y_i)\log(1 - p_i)\big] + \frac{1}{2C}\lVert w\rVert^2$$

    The second term is scikit-learn’s default L2 penalty; $C$ is the inverse regularisation strength.

  3. Gradient

    $$\nabla_w \mathcal L = \frac1n X^\top(p - y) + \frac{w}{C}$$

    The same "prediction minus truth" form as linear regression. No closed form exists, but the loss is convex, so L-BFGS converges reliably.

06 When to use it

Strengths

  • Outputs well-calibrated probabilities (usually).
  • Coefficients are interpretable as log-odds ratios.
  • Fast, convex, and a strong baseline.

Limitations

  • Linear boundary unless you engineer features.
  • Struggles with perfect separation (weights diverge) without regularisation.
  • Sensitive to correlated features, like linear regression.

Reach for it when

You need probabilities, interpretability, or a solid baseline, especially in regulated settings.

Think twice when

Strongly non-linear class boundaries with no clear features to engineer.

07 In code

python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.compose import make_column_transformer
from sklearn.preprocessing import OneHotEncoder, StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import classification_report, roc_auc_score

df = pd.read_csv("datasets/raw/titanic.csv")
X, y = df.drop(columns="Survived"), df["Survived"]
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.2, stratify=y, random_state=42)

prep = make_column_transformer((OneHotEncoder(), ["Sex", "Pclass"]), remainder=StandardScaler())
model = make_pipeline(prep, LogisticRegression(C=1.0, max_iter=1000)).fit(X_tr, y_tr)
proba = model.predict_proba(X_te)[:, 1]
print(classification_report(y_te, proba >= 0.5), "AUC", roc_auc_score(y_te, proba))

Common pitfalls

  • Using 0.5 as the threshold by default. The right threshold depends on the cost of each kind of mistake.
  • Reading coefficients without scaling, or without remembering they are on the log-odds scale.
  • Judging an imbalanced problem by accuracy. Look at precision, recall and AUC.

09 Check yourself

Q1A coefficient of $w_j = 0.7$ means that one unit more of $x_j$ (others fixed):

Why: The model is linear in log-odds, so a change of 0.7 in log-odds multiplies the odds by $e^{0.7}$.

Q2Why is log-loss used instead of squared error?

Why: Squared error on a sigmoid output is non-convex and penalises confident mistakes too weakly.

Q3On perfectly separable data with no regularisation, the weights:

Why: Scaling the weights up always makes the sigmoid sharper and the likelihood higher, so there is no finite optimum.

Q4What is the range of the standard logistic sigmoid function $\sigma(z) = \frac{1}{1 + e^{-z}}$?

Why: For any real input $z \in (-\infty, \infty)$, $e^{-z} > 0$, so $\sigma(z) = \frac{1}{1 + e^{-z}}$ is strictly bounded between 0 and 1, never reaching exactly 0 or 1.

Q5What does regularisation parameter $C$ represent in scikit-learn's LogisticRegression?

Why: In scikit-learn, $C$ multiplies the loss term (or divides the penalty): $\mathcal{L} = \text{Loss} + \frac{1}{2C}\lVert w\rVert^2$. Thus smaller $C$ strengthens regularisation, while large $C$ allows weights to grow to fit the training data.

Q6What is the logit (log-odds) function, which inverts the logistic sigmoid?

Why: The odds ratio is $\frac{p}{1 - p}$. Taking the natural logarithm gives the logit function $\log\frac{p}{1-p} = w^\top x + b$, mapping probability $p \in (0, 1)$ to real scores in $(-\infty, \infty)$.

Q7How does Multinomial Logistic Regression (softmax regression) model $K > 2$ classes compared to One-vs-Rest (OvR)?

Why: In Multinomial logistic regression (multi_class='multinomial'), the model directly estimates the joint categorical distribution using the softmax normaliser. OvR trains $K$ separate binary models whose independent probabilities may not sum to 1.

Q8Why is feature standardisation important before fitting regularised Logistic Regression?

Why: The penalty $\frac{1}{2C}\sum w_j^2$ treats every coefficient identically. If feature 1 is measured in metres and feature 2 in kilometres, $w_2$ must be 1,000 times larger to exert the same effect, causing it to be heavily penalised simply due to unit choice.

Q9Which solver in scikit-learn's LogisticRegression supports both L1 and L2 regularisation as well as Elastic Net?

Why: The saga (Stochastic Average Gradient Descent) solver handles non-smooth L1 penalties, L2 penalties, and Elastic Net combinations, while scaling well to large datasets. lbfgs only supports L2 (and no penalty).

Q10A logistic regression model has intercept $b = -0.5$ and weights $w_1 = 0.5, w_2 = -1.0$. For a test sample with features $x_1 = 4.0, x_2 = 1.0$, what is the predicted probability $P(y = 1 \mid x)$? (Given $e^{-0.5} \approx 0.6065$).

Why: The linear score is $z = 0.5(4.0) - 1.0(1.0) - 0.5 = 2.0 - 1.0 - 0.5 = +0.5$. The probability is $\sigma(0.5) = \frac{1}{1 + e^{-0.5}} \approx \frac{1}{1 + 0.6065} \approx 0.622$.

Q11In a medical logistic regression model, feature $x_1$ is blood pressure in tens of mmHg, with fitted coefficient $w_1 = 0.4055$ (so $e^{0.4055} \approx 1.50$). If a patient's blood pressure increases by 20 mmHg (2 units of $x_1$) with other factors held constant, by what factor are their odds of disease multiplied?

Why: For a change of $\Delta x = 2$ units, the change in log-odds is $2 w_1$. The odds are multiplied by $e^{2 w_1} = (e^{w_1})^2 = (1.50)^2 = 2.25$.

Q12For two test samples with true labels $y = [1, 0]$ and predicted probabilities $p = [0.80, 0.40]$, what is the exact average binary cross-entropy loss $\mathcal{L} = -\frac{1}{2}\sum [y_i \log p_i + (1 - y_i)\log(1 - p_i)]$? (Using $\log(0.80) \approx -0.223$ and $\log(0.60) \approx -0.511$).

Why: Sample 1 ($y=1$): $-\log(0.80) \approx 0.223$. Sample 2 ($y=0$): $-\log(1 - 0.40) = -\log(0.60) \approx 0.511$. Average loss is $\frac{0.223 + 0.511}{2} = \frac{0.734}{2} = 0.367$.
